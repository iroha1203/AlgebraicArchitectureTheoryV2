# Rising Sea — AAT の基礎論文

**Foundations of Algebraic Architecture Theory**（仮題）

Atom と Law から、相対的なアーキテクチャの幾何、局所整合性、診断、輸送、比較、
再構成を展開する長編の基礎論文を準備する。

- [論文構成マスター](paper-structure.md): 主題、収録方針、章構成、各章の役割、執筆順序。
- [AI 利用記録](ai-use.md): 構成作成と確認に用いた AI、その利用範囲。
- [論文作成ガイドライン](../../../docs/paper/guideline.md): 共通の執筆・検証・公開手順。
