**日本語原稿17パートの執筆・レビュー → 原稿全体の確認 → 英訳・TeX化 → 投稿前確認・公開**

日本語原稿は、公開する英語論文の下書きとする。日本語で内容を確定し、
同じ内容の英語版へ翻訳して投稿・公開する。

収録内容は[論文構成マスター](paper-structure.md)、数学の材料と接続項目は
[数学内容の棚卸し](mathematics-inventory.md)を参照する。共通の品質基準と手順は
[論文作成ガイドライン](../../../docs/paper/guideline.md)に従う。
初版は障害・診断比較と局所再構成までを収録し、比較群との整合と有限決定性の体系化を改訂版へ追加する。

## 5. 投稿前確認と公開

確認結果は[雛形](../../../docs/paper/templates/submission.md)を用いた `submission.md` に記録する。
詳細な確認基準は論文作成ガイドラインの「工程と状態」「実行手順と検証」に従う。

- [ ] 投稿先・論文種別を決め、最新の投稿要件、資格、license を確認する。
- [ ] 最終原稿に対する主張の証拠対応、全参考文献の確認、内容・読者向けレビューの指摘対応を完了する。
- [ ] 固定環境で検査・ビルドし、引用・参照・文字欠落を解消する。行幅・余白の警告を箇所ごとに確認する。
- [ ] 完成 PDF を全ページ目視し、数式・図表・書誌・ページ・編集指示の残存を確認する。
- [ ] 著者・所属・題名・要旨・版などの metadata と、実際の AI 利用に基づく開示文を確認する。
- [ ] 投稿用 source を明示したファイル一覧から作成し、展開先で再ビルドする。原稿・環境・証拠・成果物の版と hash を記録する。
- [ ] 人間の著者が最終版を確認して投稿する。arXiv を用いる場合は投稿画面の preview PDF も確認する。
- [ ] 投稿・公開した source・PDF・metadata、日時、識別子、URL、hash を保存し、公開物を確認する。

AI を利用した作業ごとに[AI 利用記録](ai-use.md)を更新する。
レビュー後に変更した箇所は、影響する主張・文献・英訳・組版を再確認する。
