# 第3章 標準解像度と診断不変性

## 本章の概要

本章の問いは、情報をまとめたり、局所的に読む範囲を分け直したりしたとき、
同じ障害を診断できる条件は何か、である。
第2章では、局所状態と遷移から貼り合わせの障害類を作った。
その判定を異なる解像度で共有するには、残す情報と、局所データを比較する写像を定める必要がある。

たとえば、状態が表示値と内部値の組であり、選んだLawが表示値だけを読むとする。
表示値が同じ状態をまとめても、Lawの値は失われない。
しかし、局所状態を置く範囲までまとめると、重なりの閉路が変わることがある。
Lawの値を保つことと、閉路上の障害を保つことには、それぞれ確認すべき条件がある。

前半では、Lawの評価を保つ最も粗い解像度を構成し、
その評価値から診断用の複体を生成する。次に、被覆の比較から実際のcochain写像を作り、
それが一次コホモロジーの同型となる十分条件を証明する。
後半では、すべての許容Lawに対する不変性を有限計算へ帰着し、
第2章の整数係数の障害と本章の有理数値の診断を結ぶ。

| 問い | 構成 | 得られるもの |
| --- | --- | --- |
| Lawを読むために、どこまで情報をまとめられるか | すべてのLaw値が等しいsourceを同一視する | 標準解像度の普遍性と、指定した抽出方法による表示の条件（§§3.1–3.2） |
| 解像度と局所構造の変更をどう比較するか | Law値ごとの係数と、辺・面の比較から写像を作る | 診断類を運ぶ写像と、条件Cによる同型（§§3.3–3.5） |
| どのLawを選んでも診断は保たれるか | 値の部分集合ごとに核と余核を計算する | 一様不変性の必要十分条件、有限判定、局所観測の反例（§§3.6–3.7） |
| 構造を固定すると障害も固定されるか | 構造側の台と、選んだ係数を分けて調べる | 構造nerveの不変性と、source別係数での消滅（§3.8） |
| 診断の零は、実際の障害の零を意味するか | 整数の生成子をLaw値の座標へ送り、有理補正から整数補正を作る | 指定障害類の対応と零性の同値（§§3.9–3.10） |
| 被覆を細かくしても同じ判定を得られるか | 三chartから四chartへの実際の細分を使う | 比較平方、障害判定の不変性、零・非零の具体例（§3.11） |

### 診断を比較する理由

ソフトウェアの同じ状態を、内部値まで含めて読む場合と、公開された値だけで読む場合がある。
局所的な整合性も、構成要素ごと、あるいは複数の構成要素をまとめた範囲ごとに調べられる。
こうした選択を変えながら結果を比較するには、診断値の意味を保つ写像が要る。

本章の診断は、Lawの値と重なりの情報から作る一次コホモロジーと、その中の指定した類である。
第1章のlensやプロトコルでは、必要な読取りや操作の結果を評価として選ぶことが、
何を残す解像度かを決める。第2章の貼り合わせ問題では、診断類の零性を
局所補正の存在へ戻せることが重要になる。
§§3.9–3.11は、その戻し方を同じ入力と具体的な写像によって与える。

## 3.1 Lawの評価を保つ標準解像度

解像度は、どのsourceを区別するかを定める。
ここでは、第1章のreadingが持つ選択のうち、この区別に関わる部分を全射で表す。
局所的な被覆と係数は、§3.3から追加する。

**定義3.1（解像度とLawの評価）.**
sourceの集合を $`S`$ とし、解像度を全射 $`q:S\to Q`$ で与える。
有限なLaw添字集合 $`L`$ と評価
$`v_\ell:S\to\mathrm{Val}_\ell`$ を固定する。
これらは、定義2.35で用いたLawの評価と同じ種類の入力である。
第1章の方程式を調べる場合には、選んだ残差などを評価に取れる。

$`q`$ が $`L`$-adequateであるとは、各 $`\ell\in L`$ に対し
$`\bar v_\ell:Q\to\mathrm{Val}_\ell`$ が存在して

```math
v_\ell=\bar v_\ell q
\qquad\text{(3.1)}
```

となることをいう。これは「$`q(s)`$ から各Lawの値を読み戻せる」という条件である。
被覆が情報と相互作用を読めることをいう第1章のadequacyとは、
対象となるデータを区別して $`L`$-adequacyと呼ぶ。

二つの解像度について

```math
q_c\preceq q_f
\quad\Longleftrightarrow\quad
\forall s,t\in S,\
q_f(s)=q_f(t)\Rightarrow q_c(s)=q_c(t)
\qquad\text{(3.2)}
```

と書き、$`q_c`$ は $`q_f`$ より粗いという。
細かい側で同一視した二つのsourceは、粗い側でも同一視される。

**補題3.2（評価の降下と比較写像）.**
次が成り立つ。

1. $`v:S\to V`$ が $`q`$ を通じて降下することと、
   $`q(s)=q(t)\Rightarrow v(s)=v(t)`$ は同値である。降下した写像は一意である。
2. $`q_c\preceq q_f`$ なら、一意な全射 $`\pi:Q_f\to Q_c`$ が存在して
   $`q_c=\pi q_f`$ となる。
3. 両側が $`L`$-adequateなら、$`\bar v_{\ell,c}\pi=\bar v_{\ell,f}`$ である。

**証明.**
1の順方向は写像の合成から従う。逆方向では、$`u\in Q`$ の代表 $`s`$ を取り、
$`\bar v(u)=v(s)`$ と置く。仮定から代表に依存せず、$`q`$ の全射性から一意である。
2は $`v=q_c`$ として1を適用すればよく、$`q_c`$ の全射性から $`\pi`$ も全射になる。
3の両辺は $`q_f(s)`$ で $`v_\ell(s)`$ に等しいので、全射性から一致する。□

**定義3.3（標準解像度）.**
source上の同値関係を

```math
s\sim_L t
\quad\Longleftrightarrow\quad
\forall\ell\in L,\ v_\ell(s)=v_\ell(t)
\qquad\text{(3.3)}
```

と定める。商写像 $`q_L:S\to S/{\sim_L}`$ を、
このLaw族の標準解像度と呼ぶ。

**定理3.4（標準解像度の普遍性）.**
$`q_L`$ は $`L`$-adequateであり、任意の $`L`$-adequateな $`q:S\to Q`$ に対して
一意な写像 $`u_q:Q\to S/{\sim_L}`$ が存在し、

```math
u_q q=q_L
\qquad\text{(3.4)}
```

を満たす。したがって $`q_L\preceq q`$ である。
この性質を持つ解像度は、sourceからの写像と可換な一意の全単射を除いて一意である。

**証明.**
$`[s]\mapsto v_\ell(s)`$ は式(3.3)により代表に依存しないので、$`q_L`$ はadequateである。
$`q`$ がadequateなら、$`q(s)=q(t)`$ からすべてのLaw値の一致、
したがって $`s\sim_L t`$ が従う。補題3.2によって $`u_q`$ が存在し、一意である。
二つの解像度が同じ普遍性を持てば、互いを通じた写像を得る。
両合成はsourceからの写像と可換であり、一意性から恒等写像となる。□

標準解像度は、選んだLawを読める解像度のうち最も粗い。
実装方法や局所被覆の選択に先立って、保持すべき区別そのものが決まる。

**例3.5（表示値と内部値）.**
$`S=\{0,1\}^2`$、一つのLaw $`v_\ell(v,h)=v`$ を取る。
標準解像度は第一成分を読む $`q_c(v,h)=v`$ と同じ同値関係を持つ。
恒等写像 $`q_f(v,h)=(v,h)`$ は細かいadequateな解像度であり、
比較写像は $`\pi(v,h)=v`$ である。
$`(v,0)`$ と $`(v,1)`$ はまとめられるが、Lawが区別する $`v=0`$ と $`v=1`$ は残る。
内部値も読むLawを追加すると、標準解像度は恒等写像と同じになる。

## 3.2 有限計算と抽出方法による表示

標準解像度の商を作れることと、利用できる抽出方法がその商を実現することは、
別々に確かめられる。有限なsourceでは、両方を同値関係の比較として計算できる。

**構成3.6（有限partitionの計算）.**
$`S`$ が有限で、各評価値の等号を判定できるとする。
各sourceについて、有限タプル $`(v_\ell(s))_{\ell\in L}`$ を計算する。
タプルの一致でsourceを分けて得られる、空でない部分集合の族を $`𝒫_L`$ とする。
写像 $`s\mapsto\{t\in S\mid t\sim_L s\}`$ は $`𝒫_L`$ への全射である。
二つの出力が等しいことと式(3.3)は同値なので、この計算は標準解像度を表示する。
Law添字集合が空なら、非空のsourceは一つの成分にまとまる。

**定義3.7（許容された抽出方法による表示）.**
第1章の抽出doctrineの、共通source $`S`$ 上の指定された族を $`𝒟`$ とする。
$`D\in𝒟`$ が誘導する解像度は、

```math
s\sim_D t
\quad\Longleftrightarrow\quad
\mathrm{Atomize}_D(s)=\mathrm{Atomize}_D(t)
\qquad\text{(3.5)}
```

による商である。ある $`D\in𝒟`$ について $`\sim_D=\sim_L`$ となるとき、
標準解像度はこの族で表示可能であるという。
有限な $`𝒟`$ と、抽出族の一致を判定する方法があれば、
すべてのsource対について式(3.3)と式(3.5)を比較することで表示可能性を判定できる。

**例3.8（adequateな抽出方法だけでは表示可能性は従わない）.**
sourceを $`a_0,a_1,a_2,b_0,b_1,b_2`$ の六点とし、
Law値を $`a_i`$ では0、$`b_i`$ では1とする。
次の各行を、抽出結果が等しくなるsourceのpartitionとする。

| 抽出方法 | 同じ結果を返すsourceの成分 |
| --- | --- |
| $`D_0`$ | $`\{a_0,a_1,a_2\},\ \{b_0,b_1,b_2\}`$ |
| $`D_a`$ | $`\{a_0\},\ \{a_1,a_2\},\ \{b_0,b_1,b_2\}`$ |
| $`D_b`$ | $`\{a_0,a_1,a_2\},\ \{b_0\},\ \{b_1,b_2\}`$ |

各成分に異なるAtomを一つ割り当て、その単元集合を抽出結果とすれば、
これらは実際のdoctrineから得られる。定義1.3では、正規化を恒等写像とし、
sourceの意味論を「割り当てたAtomである」と定め、残る許可条件を真とすればよい。

三つともLaw値を保つ。$`\{D_0,D_a\}`$ では $`D_0`$ が標準解像度を表示する。
一方、$`\{D_a,D_b\}`$ のどちらも、Lawには不要な区別を残している。
前者は $`a_0,a_1`$ を、後者は $`b_0,b_1`$ を分けるため、
この二つだけを許容した族では標準解像度を表示できない。

## 3.3 Law値から診断複体を作る

以降、sourceは有限とし、$`q:S\to Q`$ は $`L`$-adequateとする。
局所範囲ごとに、そこで読める相異なるLaw値を座標に取る。
同じ値を持つsourceが増えても、座標を重複させないことが構成の要点である。

**定義3.9（台を持つ有限nerve）.**
有限集合 $`N_0,N_1,N_2`$ を、それぞれchart、辺、面の集合とする。
辺 $`e`$ は始点 $`s(e)`$ と終点 $`t(e)`$ を持つ。
面 $`f`$ は、あるchart $`\alpha,\beta,\gamma`$ に対して
三辺 $`e_0:\alpha\to\beta`$、$`e_1:\alpha\to\gamma`$、
$`e_2:\beta\to\gamma`$ を持つ。平行辺や自己ループ、繰り返す頂点も許す。

各chartに空でない台 $`S_\alpha\subseteq Q`$ を指定し、辺と面の台を

```math
S_e=S_{s(e)}\cap S_{t(e)},\qquad
S_f=S_{e_0}\cap S_{e_1}\cap S_{e_2}
\qquad\text{(3.6)}
```

から作る。辺や面の台は空でもよい。
この台は、各セルで読める解像度の値を表す。
辺と面の存在は、選んだ局所比較のデータに含まれる。
実際の被覆に適用するときは、その交差からセルを取る。

**構成3.10（Law-value診断複体）.**
全体で現れるラベルの集合を
$`\Lambda=\{(\ell,v_\ell(s))\mid\ell\in L,\ s\in S\}`$ とする。
セル $`\sigma`$ で現れるラベルを

```math
\Lambda_\sigma
=\{(\ell,\bar v_\ell(u))\mid \ell\in L,\ u\in S_\sigma\}
\subseteq\Lambda
\qquad\text{(3.7)}
```

と定める。ラベルはLaw添字と値の組であり、値を実現する $`u`$ 自体は含めない。
診断のcochain群を

```math
D_L^n(q,N)=\prod_{\sigma\in N_n}ℚ^{\Lambda_\sigma}
\quad(n=0,1,2)
\qquad\text{(3.8)}
```

とし、微分を同じラベルの座標間で

```math
\begin{aligned}
(d^0b)_{e,\lambda}
&=b_{t(e),\lambda}-b_{s(e),\lambda},\\
(d^1z)_{f,\lambda}
&=z_{e_0,\lambda}-z_{e_1,\lambda}+z_{e_2,\lambda}
\end{aligned}
\qquad\text{(3.9)}
```

と定める。辺で現れるラベルは両端で、面で現れるラベルは三辺で現れるため、
右辺の各項は定義されている。

**補題3.11（微分と診断群）.**
$`d^1d^0=0`$ である。したがって

```math
H^1_{\mathrm{diag}}(q,N;L)
=\ker d^1/\mathrm{im}\,d^0
\qquad\text{(3.10)}
```

が定義される。

**証明.**
一つの面とラベルで式(3.9)を計算すると
$`(b_\beta-b_\alpha)-(b_\gamma-b_\alpha)+(b_\gamma-b_\beta)=0`$ となる。□

**命題3.12（Law値ごとの分解）.**
$`\lambda\in\Lambda`$ に対し、$`\lambda\in\Lambda_\sigma`$ となるセルだけを残した
部分nerveを $`N_\lambda`$ とする。その定数有理係数の複体との間に

```math
\begin{aligned}
D_L^\bullet(q,N)
&\cong\bigoplus_{\lambda\in\Lambda}C^\bullet(N_\lambda;ℚ),\\
H^1_{\mathrm{diag}}(q,N;L)
&\cong\bigoplus_{\lambda\in\Lambda}H^1(N_\lambda;ℚ)
\end{aligned}
\qquad\text{(3.11)}
```

が成り立つ。

**証明.**
式(3.8)の座標 $`(\sigma,\lambda)`$ を、$`\lambda`$ を先にして並べ替える。
有限集合なので、積と直和は一致する。
微分はラベルを変えないため、並べ替えは微分と可換である。
cocycle条件とcoboundaryへの所属もラベルごとに成立し、商にも同型を与える。□

この分解によって、診断の比較は「一つのLaw値が見える範囲の比較」に分かれる。
たとえば例3.5で各chartの台を全体に取れば、二つのLaw値0、1について
同じnerveの複体が一つずつ現れる。

## 3.4 解像度の比較からcochain写像へ

粗い側の診断を細かい側へ運ぶ写像は、評価値と局所範囲の対応から作れる。
解像度の値を送る向きと、cochainを引き戻す向きが逆であることに注意する。
以下では、粗い側をcoarse、細かい側をfineとも呼ぶ。

**定義3.13（局所比較のデータ）.**
$`q_c\preceq q_f`$ と、補題3.2の比較写像 $`\pi:Q_f\to Q_c`$ を取る。
両側の台を持つnerveについて、次を指定する。

- chart写像 $`r:N_{f,0}\to N_{c,0}`$。
- 各fine辺をcoarse辺へ送るか、縮約を表す記号 $`\bot`$ へ送る写像 $`r_1`$。
- 各fine面をcoarse面へ送るか、$`\bot`$ へ送る写像 $`r_2`$。

写る辺は始点と終点を、写る面は三つの辺の番号を保つ。
縮約される辺の両端は同じcoarse chartへ写る。
縮約される面では、その三辺もすべて縮約される。
また、

```math
\pi(S^f_\alpha)\subseteq S^c_{r(\alpha)}
\qquad\text{(3.12)}
```

を仮定する。辺と面についての台の包含は、式(3.6)と接続関係から従う。

**命題3.14（生成される診断比較）.**
定義3.13のデータと両側の $`L`$-adequacyから、線形写像
$`T^n:D_L^n(q_c,N_c)\to D_L^n(q_f,N_f)`$ が

```math
\begin{aligned}
(T^0b)_{\alpha,\lambda}&=b_{r(\alpha),\lambda},\\
(T^1z)_{e,\lambda}
&=\begin{cases}
z_{r_1(e),\lambda}&r_1(e)\ne\bot,\\
0&r_1(e)=\bot,
\end{cases}\\
(T^2w)_{f,\lambda}
&=\begin{cases}
w_{r_2(f),\lambda}&r_2(f)\ne\bot,\\
0&r_2(f)=\bot
\end{cases}
\end{aligned}
\qquad\text{(3.13)}
```

で定まり、$`T^1d_c^0=d_f^0T^0`$、$`T^2d_c^1=d_f^1T^1`$ を満たす。
よって、同じ写像から線形写像

```math
T_{\mathrm{diag}}:
H^1_{\mathrm{diag}}(q_c,N_c;L)
\longrightarrow H^1_{\mathrm{diag}}(q_f,N_f;L),
\qquad [z]\longmapsto[T^1z]
\qquad\text{(3.14)}
```

を得る。式(3.11)の分解の下では、これは各 $`N_\lambda`$ の比較の直和である。

**証明.**
fineセルで $`\lambda=(\ell,v)`$ を実現する $`u`$ を取る。
写るセルでは、式(3.12)と補題3.2により $`\pi(u)`$ がcoarse側で同じラベルを実現する。
したがって式(3.13)の座標は存在する。

写る辺では、両端を保つ条件から $`T^1d_c^0=d_f^0T^0`$ が従う。
縮約辺では、二つのchart値が同じ値になり、その差は零である。
写る面では三辺の番号を保つため、$`T^2d_c^1=d_f^1T^1`$ となる。
縮約面では三辺とも縮約され、三項すべてが零になる。
cocycleとcoboundaryを保つので商へ降り、ラベルを変えないため分解とも可換である。□

同じ議論は、アーベル群の係数を持つcochain写像にも使える。
微分と可換な比較は類を運び、零類を零類へ送る。
さらに各次数の比較が同型なら、その逆も微分と可換であり、類の比較は同型になる。
被覆の細分と切断の制限による標準的なČech比較は、
[Stacks, Tag 09UY](https://stacks.math.columbia.edu/tag/09UY)で与えられている。
§3.11では、第2章の実際の被覆に対して制限写像を計算する。

## 3.5 条件Cによる診断不変性

比較写像を作れた後の問題は、その写像がどの類も失わず、細かい側の類をすべて捉えるかである。
この二つを、それぞれ単射性と全射性として証明する。
そのために、一つのcoarse chartの内部へまとまるfine側の構造を調べる。

**定義3.15（座標fiberと条件C）.**
ラベル $`\lambda`$ を固定し、式(3.11)の部分nerveで考える。
coarse chart $`v`$ のfiberには、$`r(\alpha)=v`$ となるfine chartを取り、
両端がこのfiberにあるすべてのfine辺を入れる。
三辺がすべてfiber内にある面を内部面と呼ぶ。
fiber内の辺には、縮約辺のほか、coarse自己ループへ写る辺も含む。

条件Cは、次の七条件である。

| 条件 | 内容 |
| --- | --- |
| C0：台の合致 | 各coarse chart $`v`$ で $`S^c_v=\bigcup_{r(\alpha)=v}\pi(S^f_\alpha)`$ |
| C1：fiberの連結性 | 各 $`\lambda`$ のcoarse部分nerveの各chartについて、fiberは空でなく、辺の向きを忘れたグラフとして連結 |
| C2：辺の持ち上げ | 各coarse辺とそのラベルには、同じラベルを持ち、その辺へ写るfine辺が存在する |
| C3：fiber内のcycle | 各fiber内の有理1-cycleは、内部面の境界の有理線形結合である |
| C4：面の持ち上げ | 各coarse面とそのラベルには、同じラベルを持ち、その面へ写るfine面が存在する |
| C5：辺の持ち上げの一意性 | 一つのcoarse辺へ写るfine辺は高々一つである |
| C6：自己ループの反映 | coarse自己ループへ写るfine辺は、それ自体が自己ループである |

C0・C5・C6はnerve全体に課し、C1–C4はすべての $`\lambda\in\Lambda`$ に課す。
C3でのchainの境界は $`\partial e=t(e)-s(e)`$、
$`\partial f=e_0-e_1+e_2`$ とする。
1-cycleは有限な有理係数の辺の和で、各頂点への流入係数と流出係数が等しいものをいう。

**補題3.16（fiber内の補正）.**
一つのラベルの部分nerveでC1とC3を仮定する。fine側の任意の1-cocycle $`z`$ に対し、
0-cochain $`p`$ が存在し、$`z-d_f^0p`$ はすべてのfiber内の辺で零となる。

**証明.**
一つのfiber内で根となる頂点を選ぶ。
$`p(\alpha)`$ を、根から $`\alpha`$ へ進む道に沿った $`z`$ の符号付き和とする。
道はC1から存在する。二つの道の差は1-cycleであり、C3により内部面の境界の和である。
cocycleは各面の境界上で零となるので、$`p(\alpha)`$ は道の選択に依存しない。
辺 $`e:\alpha\to\beta`$ について、根から $`\alpha`$ への道に $`e`$ を付け足せば
$`p(\beta)-p(\alpha)=z(e)`$ を得る。
各fiberでこの構成を行い、fine側の全頂点に $`p`$ を定める。□

**定理3.17（診断不変性）.**
両側が $`L`$-adequateで、定義3.13の比較が条件Cを満たすなら、
式(3.14)の実際の比較写像 $`T_{\mathrm{diag}}`$ は同型である。
特に、任意のcoarse診断類 $`\alpha`$ に対して

```math
\alpha=0\quad\Longleftrightarrow\quad T_{\mathrm{diag}}(\alpha)=0
\qquad\text{(3.15)}
```

となる。

**証明.**
命題3.12と命題3.14により、ラベルを一つ固定して単射性・全射性を示せばよい。

**単射性.**
coarse cocycle $`z`$ の像が $`T^1z=d_f^0b`$ であるとする。
同じfiber内の辺が縮約されるなら、その上で $`d_f^0b=0`$ である。
縮約されないならcoarse自己ループへ写り、C6によりfine側でも自己ループなので、
やはり両端の $`b`$ は等しい。
C1から $`b`$ はfiberごとに一定であり、coarse頂点の値 $`\bar b`$ を定める。
各coarse辺にC2で持ち上げを取ると、
$`z(e)=\bar b(t(e))-\bar b(s(e))`$ を得る。
したがって $`z=d_c^0\bar b`$ であり、元の類も零である。

**全射性.**
fine cocycle $`w`$ を取る。補題3.16により、同じ類を表す
$`w'=w-d_f^0p`$ をfiber内で零にできる。
各coarse辺にはC2・C5により同じラベルを持つ持ち上げがただ一つある。
その $`w'`$ の値を $`z(e)`$ とする。
写るfine辺では $`T^1z=w'`$ であり、縮約辺はfiber内にあるので両辺とも零になる。
各coarse面をC4で持ち上げれば、三辺の一意性により
$`d_c^1z`$ は持ち上げた面での $`d_f^1w'=0`$ に等しい。
よって $`z`$ はcocycleで、$`[w]=T_{\mathrm{diag}}[z]`$ となる。□

条件Cは、局所的に消せる差をfiber内で補正し、
残った差を粗い側へ一意に読み戻すための条件である。
次節では、条件Cを使わずに比較そのものを計算する判定も与える。

**例3.18（三chartから四chartへの比較）.**
例3.5の二つの解像度を使い、chartの台はすべて解像度の値全体とする。
nerveは補題2.38の三chart・四chartの被覆から取る。
$`a_0,a_1`$ を $`a`$ へ、$`b,c`$ を同名のchartへ写す。
辺 $`e_{01}`$ を縮約し、$`ab,bc,ac`$ を同名の辺へ写す。

各ラベルの $`a`$ 上のfiberは二頂点を一本の辺で結ぶ木であり、
$`b,c`$ 上のfiberは一点である。
台は合致し、三つのcoarse辺の持ち上げは一意、両側の面とcoarse自己ループは空である。
よって条件Cが成立する。
両側のnerveには独立な閉路が一つあり、ラベルは0、1の二つなので、
両診断群は $`ℚ^2`$ となる。
比較は、三辺の値 $`(z_{ab},z_{bc},z_{ac})`$ を
$`(0,z_{ab},z_{bc},z_{ac})`$ へ送る。
periodは両側で $`z_{ab}+z_{bc}-z_{ac}`$ であり、非零類も保たれる。

**例3.19（Lawを保つことと診断を保つこと）.**
sourceを $`\{0,1,2\}`$、粗い解像度を
$`q_c(0)=q_c(1)=0,\ q_c(2)=1`$、細かい解像度を恒等写像とする。
Law $`v_0=q_c`$ は両側で読める。
すべてのchartの台を全体に取り、次の二つの比較を考える。

| coarse nerve | fine nerveと比較 | 一つのLaw値に対する $`H^1`$ の比較 |
| --- | --- | --- |
| 一頂点、一自己ループ、面なし | 二頂点を結ぶ一本の辺を、その自己ループへ送る | $`ℚ\to0`$。coarseの非零類が消える |
| 二頂点、一本の辺、面なし | 二頂点間の平行二辺を、coarseの一本の辺へ送る | $`0\toℚ`$。fineの非零類を捉えられない |

第一行ではfine辺の任意の値が頂点値の差となり、C6が破れる。
第二行ではcoboundaryは二辺で同じ値を持つため、その差が非零類を検出し、C5が破れる。
いずれも $`L=\{0\}`$ に対するadequacyは成立している。

ここへ $`v_1(1)=1,\ v_1(0)=v_1(2)=0`$ を読むLawを追加すると、
$`q_c`$ はこのLawを読めなくなる。
任意の解像度に対し、降下できるLawの部分族
$`L(q)=\{\ell\in L\mid v_\ell\text{が }q\text{を通じて降下する}\}`$
を使って診断を作ることはできる。この例では $`L(q_c)=\{0\}`$、
$`L(q_f)=\{0,1\}`$ である。
第一行のfine診断は追加Lawを含めても零、第二行では元のLawによる非零類が残る。
部分族を使えば計算は定義できるが、保持したLawと被覆の比較条件の両方を確認して、
元の診断との対応を判断する必要がある。

## 3.6 すべてのLawに対する不変性を判定する

一つのLaw族についての不変性を確かめた後、
同じ比較幾何がどのadequateなLaw族にも使えるかを問える。
Law族をすべて列挙する代わりに、粗い解像度の値の部分集合を調べればよい。

**定義3.20（値の部分集合で選ぶnerve）.**
解像度の対と定義3.13の比較を固定する。
$`A\subseteq Q_c`$ に対し、台が $`A`$ と交わるcoarseセルを残し、
台が $`\pi^{-1}(A)`$ と交わるfineセルを残す。
これらを $`N_{c,A}`$、$`N_{f,\pi^{-1}(A)}`$ と書く。
面が残ればその三辺も、辺が残ればその両端も残る。
写るfineセルの像も残るので、式(3.13)と同じ規則から

```math
T_A:H^1(N_{c,A};ℚ)
\longrightarrow H^1(N_{f,\pi^{-1}(A)};ℚ)
\qquad\text{(3.16)}
```

を得る。その核と余核の次元の組を

```math
J_A=\left(\dim_{ℚ}\ker T_A,\
\dim_{ℚ}\bigl(H^1(N_{f,\pi^{-1}(A)};ℚ)/\mathrm{im}\,T_A\bigr)\right)
\qquad\text{(3.17)}
```

と定める。第一成分は比較で消える類の次元、第二成分はfine側で捉えられない類の次元である。

**定義3.21（一様不変性）.**
同じsource上のすべての有限Law族について、
両解像度がadequateであるなら式(3.14)が同型となるとき、
この比較は一様不変であるという。
ここで量化するのは、各Lawの値集合と評価写像も含めたLaw族である。
解像度、nerve、台、セルの比較写像は固定する。

**定理3.22（一様不変性の有限部分集合への還元）.**
次は同値である。

1. 比較が一様不変である。
2. すべての空でない $`A\subseteq Q_c`$ について、$`T_A`$ が同型である。
3. すべての空でない $`A\subseteq Q_c`$ について、$`J_A=(0,0)`$ である。

**証明.**
まず2から1を示す。adequateなLaw族と一つのラベル $`\lambda=(\ell,v)`$ を取り、

```math
A_\lambda=\{u\in Q_c\mid\bar v_{\ell,c}(u)=v\}
\qquad\text{(3.18)}
```

と置く。この集合は、ラベルがsource上で実現されることから空でない。
coarseセルに $`\lambda`$ が現れる条件は、その台が $`A_\lambda`$ と交わることである。
fine側では補題3.2により、対応する条件は台が $`\pi^{-1}(A_\lambda)`$ と交わることである。
したがって、ラベルごとの複体と比較写像は、式(3.16)のものと一致する。
2と命題3.12から、全体の比較も同型である。

逆に1を仮定する。空でない $`A\subseteq Q_c`$ に対して、
一つのLawを $`v_A(s)=1`$ if $`q_c(s)\in A`$、それ以外は0、と定める。
このLawは両解像度で読め、その値1の部分nerveの比較がちょうど $`T_A`$ である。
全体の比較はLaw値ごとの直和なので、その全単射性から各成分の全単射性が従う。

2と3の同値は有限次元線形代数による。
核の次元が零なら単射、余核の次元が零なら全射であり、逆も成り立つ。□

**命題3.23（有限表示からの判定）.**
source・target・セルの有限列挙、両readingの値表、台の所属判定、
接続関係とセルの比較が計算できる形で与えられていれば、一様不変性は判定可能である。

**証明.**
各 $`u\in Q_f`$ のsource代表を有限探索し、$`\pi(u)=q_c(s)`$ を計算する。
補題3.2がその代表独立性を保証する。
各非空部分集合 $`A\subseteq Q_c`$ について、残るセルを列挙し、
式(3.9)・(3.13)から有理行列 $`d_c^0,d_c^1,d_f^0,d_f^1,T^1`$ を作る。

有理数の消去法で $`Z_c=\ker d_c^1`$、$`Z_f=\ker d_f^1`$、
$`B_c=\mathrm{im}\,d_c^0`$、$`B_f=\mathrm{im}\,d_f^0`$ の基底を求める。
各 $`B`$ の基底を $`Z`$ の基底へ延長すると、商の基底が得られる。
$`T^1`$ をその基底で表し、誘導写像の階数を $`r_A`$ とすれば

```math
J_A=(\dim Z_c-\dim B_c-r_A,\
\dim Z_f-\dim B_f-r_A)
\qquad\text{(3.19)}
```

である。有限個の $`A`$ について両成分が零かを検査する。
生成した行列は定義した微分と比較そのものなので、定理3.22が判定の正しさを与える。□

この判定は、単に両側の群の次元を比べるものではない。
同じ次元の間の写像でも零写像になり得るため、実際の比較の階数 $`r_A`$ を計算する。

**系3.24（すべての部分集合に対する条件C）.**
C0・C5・C6が全体で成立し、すべての空でない $`A\subseteq Q_c`$ について、
選ばれた二つの部分nerveでC1–C4が成立するとする。
このとき比較は一様不変である。
これらの幾何条件自体も、命題3.23と同じ有限表示から判定できる。

**証明.**
任意のadequateなLaw族について、式(3.18)の $`A_\lambda`$ を取る。
定理3.22の証明で用いた同定は頂点・辺・面とその接続、部分写像を保つため、
C1の道、C2・C4の持ち上げ、C3のchainと内部面を、そのままラベルの部分nerveへ移せる。
C0・C5・C6はすでに全体で成立している。定理3.17から一様不変性が従う。

有限判定には、C0・C2・C4・C5・C6の有限照合、C1のグラフ到達可能性を用いる。
C3では各fiberについて $`\ker\partial_1`$ と $`\mathrm{im}\,\partial_2`$ の基底を計算し、
前者が後者に含まれるかを検査する。$`\partial_1\partial_2=0`$ なので、
これは両空間の一致の判定でもある。□

**例3.25（条件Cは十分条件であり、各条項は必要条件ではない）.**
次の有限例は、各条項を破っても一様不変性が成立し得ることを示す。
解像度は例3.5の $`q_c,q_f`$ とし、すべてのchartの台を全体に取る。
各行の両側へ、比較が恒等である一頂点・一自己ループ $`h`$・面なしの成分を、
独立な成分として加える。この共通成分は非零の $`H^1\congℚ`$ を持つ。
表には、それに加える部分だけを記す。

| 破れる条項 | coarse側とfine側の追加部分、および比較 |
| --- | --- |
| C0 | coarse側に孤立頂点を一つ追加し、fine側には対応する頂点を置かない |
| C1 | coarse側の一つの孤立頂点へ、fine側の二つの孤立頂点を写す |
| C2 | coarse側を面付き三角形、fine側をその二辺からなる道とし、包含で比較する |
| C3 | 両側に一頂点・一自己ループ・面なしの成分を追加し、恒等で比較する |
| C4 | coarse側の三角形に同じ境界を持つ面を二つ置き、fine側には同じ三辺と面を一つ置く |
| C5 | coarse側を面付き三角形とし、fine側では一辺を平行二辺にして、それぞれを使う面を一つずつ置く。平行二辺を同じ辺へ送る |
| C6 | coarse側に一自己ループ $`e`$ と境界 $`e-e+e=e`$ の面を置く。fine側は二頂点を結ぶ一本の辺で、その辺を $`e`$ へ送る |

表の比較は、残る頂点・辺を同名のものへ送る。
C4ではfine面をcoarseの一方の面へ、C5では二つのfine面をcoarseの面へ送る。
いずれも定義3.13を満たす。

C3の行の追加部分では比較が恒等である。
それ以外の行では、追加部分の両側の $`H^1`$ は零となる。
C0・C1の行には辺がなく、C2の道と面付き三角形ではすべてのcocycleが頂点値の差である。
C4の二つの面は同じ方程式を課すため、面が一つの場合と核が同じになる。
C5では二つの面の方程式を引くと平行二辺の値が等しくなり、
残った三角形の方程式から頂点値の差として書ける。
C6ではcoarseの面の方程式が $`z_e=0`$ を課し、fine側は道なのでやはり零である。

すべての台が全体なので、空でない $`A`$ を選んでも両nerveのセルは変わらない。
各 $`T_A`$ は共通の非零成分で恒等、残りでは上記の同型である。
定理3.22により各行は一様不変であり、系3.24の十分条件が一様不変性より真に強いことが分かる。
これは各条項の非必要性の例であり、一度に一条項だけを破るという条件は課していない。

## 3.7 局所的な接続情報だけでは判定できない例

有限判定では、面の関係を複体全体として計算した。
接続の種類と個数を局所的に読むだけで、同じ判定ができるとは限らない。
どの情報を読むかを固定し、それが一致する二つの例を比較する。

**定義3.26（接続情報の局所観測）.**
次の規則による観測を $`\mathrm{Obs}_{\mathrm{loc}}`$ とする。

1. source・両target・両readingを記録する。
   各 $`A\subseteq Q_c`$、$`A\ne\varnothing`$ について、定義3.20の両部分nerveを作る。
2. 各セルの色として、次数、coarseかfineか、選んだ部分集合内での台を記録する。
   fineセルでは、比較によって同じ次数のセルへ写るか、縮約されるかも記録する。
3. 各セルについて、直接接続するセルの色を、
   辺の始点・終点、面の第0・第1・第2辺という接続の種類ごとに集計する。
   同じ項目の個数は0、1、2以上の三値にまとめる。
   セル自身の色とこの集計を、そのセルの局所型とする。
4. 各側の局所型の出現数も0、1、2以上にまとめる。
   すべての $`A`$ で得た表を観測値とする。

接続はchartと辺、辺と面の間で読み、セルの固有名は記録しない。
これは、隣接先の種類と切り詰めた個数を保持する、明示した観測規則である。

**構成3.27（長さ3と長さ6の面の列）.**
例3.19と同じ $`S=\{0,1,2\}`$ と解像度を取る。
両側にchart $`v_0,v_1`$ を置き、台を

```math
\begin{array}{c|cc}
&v_0&v_1\\ \hline
\text{coarse}&\{0\}&\{0,1\}\\
\text{fine}&\{0,1\}&\{2\}
\end{array}
\qquad\text{(3.20)}
```

とする。$`v_0`$ に自己ループ $`h`$ を一つ、
$`v_1`$ に自己ループ $`e_0,\ldots,e_{n-1}`$ を置く。
$`v_1`$ 上の面を $`f_0,\ldots,f_{n-1}`$ とし、
$`f_j`$ の三辺を $`(e_j,e_{j+1},e_{j+2})`$ とする。添字は $`n`$ を法として読む。
chart・辺・面の比較は同名のセルへの恒等写像とする。
式(3.20)は式(3.12)を満たすので、比較が定まる。
$`n=3,6`$ の二つの入力を、それぞれ $`P_3,P_6`$ と呼ぶ。

**命題3.28（同じ局所観測と異なる一様不変性）.**
$`\mathrm{Obs}_{\mathrm{loc}}(P_3)=\mathrm{Obs}_{\mathrm{loc}}(P_6)`$ である。
一方、$`P_3`$ は一様不変であり、$`P_6`$ は一様不変でない。
したがって、この観測値だけの述語によって一様不変性を判定することはできない。

**証明.**
まず観測を比べる。$`h`$ の成分は両入力で同一である。
$`v_1`$ の成分が残るとき、各 $`e_j`$ は同じ色のchartを両端に持ち、
面の三つの辺番号のそれぞれについて、ちょうど一つの面に接続する。
各面も、三つの番号で同じ色の辺に接続する。
$`v_1`$ に接続する辺の個数と、辺・面の局所型の出現数は、
いずれも $`n=3,6`$ で2以上となる。
部分集合ごとにこの成分が残る側は式(3.20)で決まり、$`n`$ に依存しない。
よってすべての観測表が一致する。

次にコホモロジーを計算する。すべての辺は自己ループなので $`d^0=0`$ である。
$`v_1`$ 上のcocycle条件は

```math
z_j-z_{j+1}+z_{j+2}=0
\qquad(j\ \bmod n)
\qquad\text{(3.21)}
```

である。$`z_0=a,z_1=b`$ から始めると、列は

```math
a,\ b,\ b-a,\ -a,\ -b,\ a-b,\ a,\ b,\ldots
\qquad\text{(3.22)}
```

となる。周期3を課せば $`a=-a,\ b=-b`$ から $`a=b=0`$、
周期6なら任意の $`a,b\inℚ`$ が許される。
したがって、この成分の $`H^1`$ の次元は、$`n=3`$ で0、$`n=6`$ で2である。

$`A=\{0\}`$ ではcoarse側に両成分が残り、fine側には $`h`$ の成分だけが残る。
$`T_A`$ は $`h`$ の値を保ち、$`v_1`$ の成分を捨てる。
$`A=\{1\}`$ では両側に $`v_1`$ の成分だけが残り、比較は恒等である。
$`A=\{0,1\}`$ では両側の全成分が残り、やはり恒等である。
よって

```math
\begin{array}{c|ccc}
&A=\{0\}&A=\{1\}&A=\{0,1\}\\ \hline
P_3:\ J_A&(0,0)&(0,0)&(0,0)\\
P_6:\ J_A&(2,0)&(0,0)&(0,0)
\end{array}
\qquad\text{(3.23)}
```

となり、定理3.22から結論を得る。
もし一様不変性が観測値だけの述語で決まれば、観測が等しいこの二入力で同じ真偽値になる。
上の計算と矛盾する。□

差を生むのは、面の関係を一周させたときの周期である。
この例では、局所型の一致からは読み取れない関係を、式(3.21)の全体が保持している。

## 3.8 構造の台と係数の役割

第2章では、構造相と意味相の障害を比較した。
ここでは、意味の選択を変えても残る構造の台を直接作り、
その上にどの係数を置くかが診断にどう影響するかを調べる。

**定義3.29（意味の変更に対して不変な台）.**
第1章の抽出doctrineについて、語彙・解像度・sourceの意味論・正規化を固定し、
意味readingとその許可述語だけを変える。これらの選択肢を集合 $`\Theta`$ で指定する。
基準の選択 $`\theta_0\in\Theta`$ を指定し、
$`E_\theta(s,a)`$ を「source $`s`$ からAtom $`a`$ が抽出される」とする。
構造の台を

```math
E_{\mathrm{str}}(s,a)
\quad\Longleftrightarrow\quad
E_{\theta_0}(s,a)\ \land\
\forall\theta\in\Theta,\
\bigl(E_\theta(s,a)\Longleftrightarrow E_{\theta_0}(s,a)\bigr)
\qquad\text{(3.24)}
```

で定める。

台 $`E(s,a)`$ から作るnerveは、共通のsourceで成立するAtomの順序付き組をセルとする。
次数0では $`(a)`$、次数1では $`(a,b)`$、次数2では $`(a,b,c)`$ を取り、
それぞれを同時に満たすsourceが存在することを条件とする。
重複するAtomも許し、辺と面の接続は組からの射影で与える。

**命題3.30（構造nerveの不変性）.**
$`E_{\mathrm{str}}`$ から得るnerveは、基準の意味readingを同じ族の別の元に変えても、
同じセルと接続関係を持つ。

**証明.**
式(3.24)は $`\forall\theta\in\Theta,\ E_\theta(s,a)`$ と同値である。
したがって基準の元に依存しない。台が同じなので、
共通sourceの存在で定めた頂点・辺・面と、組の射影もすべて一致する。□

**例3.31（全Atomのnerveは変わり得る）.**
sourceが一つ、Atomが $`a,b`$ の二つの場合を考える。
一方の意味readingが $`a`$ だけを、他方が $`a,b`$ を抽出するとする。
構造の台には $`a`$ だけが残るが、全Atomのnerveには後者で頂点 $`b`$ が加わる。
構造部分の不変性は、全体のnerveが等しいという結論とは区別される。

**命題3.32（source別に係数を分けた場合の消滅）.**
$`S`$ とAtom集合が有限であるとする。
定義3.29の順序付きnerveの各セルに、そのセルを同時に実現するsourceごとの有理座標を置く。
微分はsourceを変えず、

```math
\begin{aligned}
(d^0b)(a,b;s)&=b(b;s)-b(a;s),\\
(d^1z)(a,b,c;s)&=z(b,c;s)-z(a,c;s)+z(a,b;s)
\end{aligned}
\qquad\text{(3.25)}
```

とする。この複体の $`H^1`$ は零である。

**証明.**
台が空でない各source $`s`$ に対し、$`E(s,a_s)`$ を満たすAtomを一つ選ぶ。
cocycle $`z`$ について $`b(a;s)=z(a_s,a;s)`$ と置く。
辺 $`(a,b;s)`$ があれば面 $`(a_s,a,b;s)`$ も存在し、そのcocycle条件から
$`z(a,b;s)=z(a_s,b;s)-z(a_s,a;s)`$ を得る。
すなわち $`z=d^0b`$ である。台が空のsourceには座標がない。□

この構成では、同じsourceを持つ座標ごとに基準Atomから補正できる。
したがって、非零の貼り合わせ障害を診断するには、
source別に分けたこの係数と、実際の障害係数との関係を確かめる必要がある。
次節では、第2章の生成子関係から作った整数係数を使って、その比較を与える。

## 3.9 整数の障害係数をLaw-value診断へ写す

第2章の障害は、局所状態を実際に制限し、遷移で比較した差から生じた。
本節では、その差を構成する生成子のLaw値を読み、診断の座標へ移す。
係数の写像、cochainの写像、障害類の写像を順に構成する。

**構成3.33（係数比較）.**
定義2.35の生成子 $`G=L\times S`$、ラベルを保つ原始関係 $`R`$、
関係成分の集合 $`𝔅`$、整数係数 $`M_R`$ を取る。
成分 $`B\in𝔅`$ の共通ラベルを $`\lambda_B\in\Lambda`$ と書く。
生成子の類を、そのラベルの有理delta関数へ送る：

```math
\varepsilon_R:M_R\longrightarrow ℚ^\Lambda,\qquad
\varepsilon_R([e_g])(\lambda)
=\begin{cases}
1&\lambda=\lambda_g,\\
0&\lambda\ne\lambda_g.
\end{cases}
\qquad\text{(3.26)}
```

$`gRh`$ ならラベルが等しく、$`e_g-e_h`$ は零へ写るので、
これは商上の加法的準同型として定まる。
補題2.36の表示 $`M_R\congℤ^{𝔅}`$ の下では

```math
\varepsilon_R(m)(\lambda)
=\sum_{\lambda_B=\lambda}m_B
\quad\text{（整数を有理数へ含めて読む）}
\qquad\text{(3.27)}
```

である。同じLaw値を持つ関係成分の係数が、一つの診断座標へ加え合わされる。

**補題3.34（係数の単射性）.**
同じラベルを持つ任意の二生成子が、原始関係の有限列で結ばれるとする。
このとき $`B\mapsto\lambda_B`$ は $`𝔅\cong\Lambda`$ を与え、
$`\varepsilon_R`$ は単射である。

**証明.**
各ラベルには生成子が存在するので写像は全射である。
二成分のラベルが等しければ、仮定によりそれぞれの代表生成子が関係で結ばれ、成分も等しい。
したがって式(3.27)は $`\varepsilon_R(m)(\lambda_B)=m_B`$ となる。
整数から有理数への包含が単射なので、全座標を読み戻せる。□

**例3.35（同じLaw値へ異なる成分を送る場合）.**
sourceを二点、一つのLawを定数とし、原始関係を空にする。
このとき $`M_R=ℤ^2`$、$`\Lambda`$ は一元で、
$`\varepsilon_R(m,n)=m+n`$ である。
非零の元 $`(1,-1)`$ が零へ写る。
同じLaw値を読むことと、原始関係で同じ成分になることの一致が、補題3.34の役割である。

**構成3.36（実際のČech複体との比較）.**
空でない連結なchartからなる有限被覆 $`𝒰_q`$ を取り、
非空の二重交差は連結、異なる三chartの交差は空とする。
nerveには異なる二chartの非空交差を辺として取り、chartの順序で向きを付ける。
この被覆に、構成2.39の局所定数な $`M_R`$ 値の層 $`F_R`$ を置く。

連結性により、各切断は一つの $`M_R`$ 値で決まり、制限は同じ値を保つ。
したがって、第2章で用いた正規化したČech複体は

```math
C_{\mathrm{ob}}^0(q)=M_R^{N_{q,0}},\qquad
C_{\mathrm{ob}}^1(q)=M_R^{N_{q,1}},\qquad
C_{\mathrm{ob}}^2(q)=0
\qquad\text{(3.28)}
```

と表示できる。ここで $`d_{\mathrm{ob}}^0p`$ は実際の制限後の右値と左値の差である。
同じnerveに、$`L`$-adequateな $`q`$ のchart台を指定し、
構成3.10の診断複体を作る。
次数0、1の比較を

```math
(\phi_q^n c)_{\sigma,\lambda}
=\varepsilon_R(c_\sigma)(\lambda)
\quad(n=0,1),\qquad
\phi_q^2:0\longrightarrow0
\qquad\text{(3.29)}
```

と定める。診断では、そのセルに現れるラベルだけを読む。
$`\varepsilon_R`$ の加法性と制限の表示から

```math
\phi_q^1d_{\mathrm{ob}}^0=d_{\mathrm{diag}}^0\phi_q^0,\qquad
\phi_q^2d_{\mathrm{ob}}^1=d_{\mathrm{diag}}^1\phi_q^1
\qquad\text{(3.30)}
```

となる。後者は両側の次数2が零であることによる。
従って加法的準同型

```math
\Phi_q:\check H^1(𝒰_q,F_R)\longrightarrow
H^1_{\mathrm{diag}}(q,N_q;L),\qquad
[z]\longmapsto[\phi_q^1z]
\qquad\text{(3.31)}
```

を得る。始域は整数係数のアーベル群であり、この比較の構造は加法的準同型である。

**定理3.37（同じ局所データから作る障害類と診断類）.**
構成3.36の入力について、任意の局所状態とアフィン遷移
$`x=(\xi,p)`$ を取る。
命題2.41の障害cochainと、Law値から生成する診断cochainを、それぞれ

```math
\begin{aligned}
o_q(x)&=\xi+d_{\mathrm{ob}}^0p,\\
a_q(x)&=\phi_q^1\xi+d_{\mathrm{diag}}^0\phi_q^0p
\end{aligned}
\qquad\text{(3.32)}
```

とする。このとき

```math
\phi_q^1o_q(x)=a_q(x),\qquad
\Phi_q([o_q(x)])=[a_q(x)]
\qquad\text{(3.33)}
```

である。特に、$`[o_q(x)]=0`$ なら $`[a_q(x)]=0`$ である。

**証明.**
診断の辺座標 $`(e,\lambda)`$ の値は、
遷移のLaw値座標 $`\varepsilon_R(\xi_e)(\lambda)`$ と、
左右の状態のLaw値座標の差との和である。
式(3.30)と加法性から、これは $`\varepsilon_R(o_q(x)_e)(\lambda)`$ に等しい。
両側の次数2は零なので両cochainはcocycleであり、商に移れば式(3.33)を得る。□

この比較では、まず整数の遷移と状態を用意し、そのLaw値を読んで診断を作っている。
したがって式(3.33)は、抽象的に二つの群を比較するだけでなく、
第2章から受け取った具体的な障害類の行き先を定める。

## 3.10 診断の零から整数の補正を得る

逆方向には、診断で見えた補正を、元の整数係数の補正へ戻す必要がある。
そのために、関係成分をLaw値で区別できることと、
必要なLaw値をすべてのchartと辺で読めることを使う。

**定義3.38（零性を反映する二条件）.**
構成3.36の入力に、次の条件を課す。

- **$`R_q`$：関係成分の識別。** 同じラベルの二生成子は原始関係の有限列で結ばれる。
- **共通代表の存在。** 各 $`\lambda=(\ell,v)\in\Lambda`$ に対して、
  すべてのchart台に属し、$`\bar v_\ell(u_\lambda)=v`$ となる
  一つの $`u_\lambda\in Q`$ が存在する。

第二条件から、その代表はすべての辺の台にも属する。
したがって各ラベルは、全chartと全辺に一つずつ診断座標を持つ。
代表の選択が異なっても、構成3.10の座標は同じラベルとして扱われる。

**補題3.39（有理数の補正の整数化）.**
有向グラフ上の整数値1-cochain $`z`$ と、有理数値0-cochain $`b`$ が
$`b_{t(e)}-b_{s(e)}=z_e`$ を満たすとする。
$`n_\alpha=\lfloor b_\alpha\rfloor`$ と置けば
$`n_{t(e)}-n_{s(e)}=z_e`$ である。

**証明.**
$`b_{t(e)}=b_{s(e)}+z_e`$ と $`z_e\inℤ`$ から
$`\lfloor b_{t(e)}\rfloor=\lfloor b_{s(e)}\rfloor+z_e`$ が従う。□

たとえば $`1/2,3/2`$ の差は1であり、整数部分 $`0,1`$ も同じ差を持つ。
整数部分は、この特定の辺差を保つ補正を構成するために用いる。

**定理3.40（指定障害類の零性反映）.**
定義3.38の二条件の下で、任意の局所データ $`x=(\xi,p)`$ について

```math
[a_q(x)]=0
\quad\Longleftrightarrow\quad
[o_q(x)]=0
\qquad\text{(3.34)}
```

が成り立つ。

**証明.**
右から左は定理3.37である。
左を仮定すると、診断の0-cochain $`b`$ が存在して
$`a_q(x)=d_{\mathrm{diag}}^0b`$ となる。
$`o_q(x)_e`$ の関係成分 $`B`$ の整数係数を $`z_{e,B}`$ と書く。
共通代表によって辺上に座標 $`\lambda_B`$ が存在し、
$`R_q`$ と補題3.34によって

```math
\begin{aligned}
b_{t(e),\lambda_B}-b_{s(e),\lambda_B}
&=a_q(x)_{e,\lambda_B}\\
&=\varepsilon_R(o_q(x)_e)(\lambda_B)
=z_{e,B}
\end{aligned}
\qquad\text{(3.35)}
```

を得る。各成分に補題3.39を適用し、

```math
n_\alpha=\sum_{B\in𝔅}
\lfloor b_{\alpha,\lambda_B}\rfloor e_B\in M_R
\qquad\text{(3.36)}
```

と置くと、$`d_{\mathrm{ob}}^0n=o_q(x)`$ である。
$`𝔅`$ は有限なので、この和は $`M_R`$ の元を定める。
構成3.36の連結なchart上では $`n_\alpha`$ は実際の局所定数切断を与える。
従って元の障害類も零となる。□

これは補正そのものを与える証明である。
元の状態を $`p-n`$ に変えると、
$`\xi+d_{\mathrm{ob}}^0(p-n)=0`$ となり、遷移に関して局所状態が整合する。
命題2.41の状態の層では、この補正後の族が大域状態へ貼り合う。

**例3.41（反映条件を欠くと診断から差が失われる）.**
補題2.38の三chart被覆に、例3.35の $`M_R=ℤ^2`$ の局所定数係数と、
解像度の値全体を読むchart台を置く。
$`p=0`$、$`\xi_{ab}=(1,-1)`$、$`\xi_{bc}=\xi_{ac}=0`$ とすれば、
障害のperiodは非零だが、診断cochainは零である。これは $`R_q`$ を欠く例である。

共通代表の役割も同じ形で確かめられる。
今度は二つのLaw値0、1を持ち、$`R_q`$ を満たす $`M_R\congℤ^2`$ を使う。
各chartの台を値0だけが現れる集合とすれば、値1の座標は診断に現れない。
値1の基底 $`u`$ を $`\xi_{ab}`$ に置き、他を零とすると、
障害のperiodは $`u\ne0`$、診断は零になる。
係数比較が単射でも、その成分を読む座標が局所的に欠ければ、零性の反映は壊れ得る。

## 3.11 被覆の細分と障害判定の不変性

最後に、これまでの比較を同じAtom入力の上で結ぶ。
第2章の八点空間と生成子関係、例3.5の二つの解像度を使う。
これにより、整数の障害、有理数の診断、三chartから四chartへの細分が、
一つの可換な比較として現れる。

**構成3.42（同じ入力からの粗細比較）.**
sourceを $`S=\{0,1\}^2`$、Lawを $`v_\ell(v,h)=v`$、
原始関係を $`(v,0)`$ と $`(v,1)`$ を結ぶ二本とする。
係数は $`M_R\congℤe_{B_0}\oplusℤe_{B_1}`$ である。
構成2.37の点Atomと生成子Atomを用い、各文脈は対応する開集合の点と全生成子を読む。

粗い側では $`q_c(v,h)=v`$ と三chart被覆
$`𝒰_c=(U_a,U_b,U_c)`$、細かい側では $`q_f=\mathrm{id}_S`$ と四chart被覆
$`𝒰_f=(U_{a_0},U_{a_1},U_b,U_c)`$ を使う。
各chartは全生成子を読むため、診断のchart台はそれぞれ $`Q_c,Q_f`$ 全体とする。
以下、障害群を $`H^1_{\mathrm{ob}}(q)=\check H^1(𝒰_q,F_R)`$、
診断群を $`H^1_{\mathrm{diag}}(q)=H^1_{\mathrm{diag}}(q,N_q;L)`$ と略記する。

包含 $`U_{a_0},U_{a_1}\subseteq U_a`$ と、残るchartの恒等な包含が実際の被覆の細分を与える。
式(3.28)の座標では、切断の制限による写像は

```math
\begin{aligned}
T_{\mathrm{ob}}^0(p_a,p_b,p_c)&=(p_a,p_a,p_b,p_c),\\
T_{\mathrm{ob}}^1(z_{ab},z_{bc},z_{ac})&=(0,z_{ab},z_{bc},z_{ac}),\\
T_{\mathrm{ob}}^2&:0\longrightarrow0
\end{aligned}
\qquad\text{(3.37)}
```

となる。fine辺の順序は $`(e_{01},ab,bc,ac)`$ である。
内部辺 $`e_{01}`$ の値は、同じcoarse chartの自己比較なので零になる。
残る辺では、実際の重なりへの制限が同じ $`M_R`$ 値を保つ。

fine側の微分は

```math
d_f^0p=
(p_{a_1}-p_{a_0},\
p_b-p_{a_1},\
p_c-p_b,\
p_c-p_{a_0})
\qquad\text{(3.38)}
```

なので、$`T_{\mathrm{ob}}^1d_c^0=d_f^0T_{\mathrm{ob}}^0`$ を直接確認できる。
これにより $`T_{\mathrm{ob}}:H^1_{\mathrm{ob}}(q_c)\to H^1_{\mathrm{ob}}(q_f)`$ を得る。
診断側には、例3.18と同じセルの比較から生成する $`T_{\mathrm{diag}}`$ を用いる。

**定理3.43（障害・診断・細分の可換性）.**
構成3.42では、次の平方が可換である。

```math
\begin{array}{ccc}
H^1_{\mathrm{ob}}(q_c)&\xrightarrow{\ \Phi_{q_c}\ }&
H^1_{\mathrm{diag}}(q_c)\\
\big\downarrow T_{\mathrm{ob}}&&\big\downarrow T_{\mathrm{diag}}\\
H^1_{\mathrm{ob}}(q_f)&\xrightarrow{\ \Phi_{q_f}\ }&
H^1_{\mathrm{diag}}(q_f)
\end{array}
\qquad\text{(3.39)}
```

任意のcoarse局所データ $`x=(\xi,p)`$ に対して
$`x_f=(T_{\mathrm{ob}}^1\xi,T_{\mathrm{ob}}^0p)`$ と置けば、

```math
\begin{aligned}
T_{\mathrm{ob}}[o_{q_c}(x)]&=[o_{q_f}(x_f)],\\
T_{\mathrm{diag}}[a_{q_c}(x)]&=[a_{q_f}(x_f)]
\end{aligned}
\qquad\text{(3.40)}
```

となる。

**証明.**
両側の係数比較は同じ生成子 $`[e_g]`$ を同じLaw値のdelta関数へ送る。
写る辺とchartでは、先に式(3.37)を適用してからLaw値を読む場合と、
先にLaw値を読んでから式(3.13)で引き戻す場合は同じ座標を読む。
内部辺ではいずれも零、次数2も両側で零である。
従って各次数の比較が可換であり、類に移して式(3.39)を得る。

局所データについては、微分との可換性から

```math
o_{q_f}(x_f)
=T_{\mathrm{ob}}^1\xi+d_f^0T_{\mathrm{ob}}^0p
=T_{\mathrm{ob}}^1(\xi+d_c^0p)
\qquad\text{(3.41)}
```

となる。これが式(3.40)の第一式を与える。
第二式は第一式、定理3.37、式(3.39)から従う。□

**定理3.44（reading変更に沿う障害判定の不変性）.**
構成3.42の任意の局所データについて、次の四つは同値である。

```math
\begin{aligned}
[o_{q_c}(x)]=0
&\quad\Longleftrightarrow\quad[a_{q_c}(x)]=0\\
&\quad\Longleftrightarrow\quad[a_{q_f}(x_f)]=0\\
&\quad\Longleftrightarrow\quad[o_{q_f}(x_f)]=0.
\end{aligned}
\qquad\text{(3.42)}
```

**証明.**
粗い解像度・細かい解像度とも、Law値は第一成分から読めるのでadequateである。
同じLaw値の二生成子は、宣言した関係の一本で結ばれるため $`R_q`$ が成立する。
値 $`v`$ の共通代表には、粗い側で $`v`$、細かい側で $`(v,0)`$ を取れる。
これらは全chartの台に属する。よって両端で定理3.40を適用できる。

診断比較には例3.18で検証した条件Cが成立し、定理3.17により同型となる。
定理3.43が指定した診断類を対応させるので、その零性も同値である。
これら三つの同値を合成して式(3.42)を得る。□

この証明では、情報をまとめる $`\pi(v,h)=v`$ は単射ではない。
それでも、Law値、関係成分、被覆の比較が上の条件を満たすため、
同じ局所データの障害判定を両解像度で共有できる。

**例3.45（非零の差が消せる場合と、消せない場合）.**
$`u=e_{B_0}\in M_R`$ とし、chart状態をすべて零に固定する。
同じ係数・Law・被覆について、遷移だけを次のように変える。

| 局所データ | coarseの遷移 $`(ab,bc,ac)`$ | fineへ運んだ遷移 $`(e_{01},ab,bc,ac)`$ | 障害類と診断類 |
| --- | --- | --- | --- |
| 補正できる差 | $`(u,-u,0)`$ | $`(0,u,-u,0)`$ | 両側で零 |
| 補正しても残る差 | $`(u,0,0)`$ | $`(0,u,0,0)`$ | 両側で非零 |

第一行は、coarse側では $`d^0(0,u,0)`$、
fine側では $`d^0(0,0,u,0)`$ である。
したがって差そのものは非零だが、対応する0-cochainの負を局所状態へ加えると整合する。

第二行のcoarse periodは $`u`$、fine periodも $`u`$ である。
fine側のperiodは
$`z_{e_{01}}+z_{ab}+z_{bc}-z_{ac}`$ であり、
式(3.38)を代入するとすべてのcoboundaryで零になる。
一方、$`\varepsilon_R(u)`$ の値0の座標は1なので、診断のperiodも非零である。
これが表の非零判定を与える。

periodによる表示を使うと、この例の群と比較は
$`H^1_{\mathrm{ob}}\congℤ^2`$、$`H^1_{\mathrm{diag}}\congℚ^2`$、
$`\Phi:ℤ^2\hookrightarrowℚ^2`$ となる。
整数と有理数という係数の違いを保ちながら、式(3.42)は同じ零性を判定している。

### 係数と局所文脈を同型で移す場合

もう一つの基本的な比較は、選んだ局所文脈と係数を同型で運ぶ場合である。
被覆とその交差図式が対応し、各交差上の係数の同型が制限と可換なら、
切断の比較はČech複体の各次数の同型を与える。
微分は制限の交代和なので比較と可換であり、逆の係数同型から逆cochain写像を得る。
従って対応する障害類の零性は同値となる。

環とイデアルから係数を作る場合には、環の同型が係数を定めるイデアルを対応させれば、
その商にも同型が誘導される。Law、witness、軸の読取りも対応させることで、
指定した残差から作る類を同じ比較へ載せられる。
本章の細分による比較は、各次数の同型を直接持つ場合を越えて、
条件Cと整数補正の構成によって障害判定を保つ方法を与えている。

## 本章のまとめ

本章では、保持するLaw、局所構造、係数、指定した局所データを結んで、
解像度の変更に沿う診断を構成した。

- **標準解像度。** すべてのLaw値が等しいsourceをまとめた商は、
  任意の $`L`$-adequateな解像度を通じて一意に読める。指定した抽出方法で表示できるかは、
  抽出結果の同値関係との比較で決まる。
- **診断の比較。** セルで現れる相異なるLaw値から係数を作り、
  局所比較から微分と可換な写像を生成した。条件Cの下では、その写像が $`H^1`$ の同型となる。
- **一様不変性。** すべてのadequateなLaw族に対する同型性は、
  値の全非空部分集合について核・余核の次元が零であることと同値であり、有限表示から判定できる。
  条件Cはその十分条件であり、固定した局所観測が一致しても判定が異なる例がある。
- **係数の役割。** 構造の台が不変でも、どの係数で差を読むかは独立に指定する。
  source別に全組を生成する係数では $`H^1`$ が零となることを、補正の明示式で示した。
- **障害と診断の対応。** 整数の生成子関係からLaw値の係数への写像を作り、
  同じ局所データの障害類と診断類を対応させた。関係成分の識別と共通代表の条件の下では、
  有理補正を整数化して零性を反映できる。
- **具体的な不変性。** 三chartから四chartへの細分について比較平方を構成し、
  非単射のreading factorを持つ同じ入力で、零・非零の障害判定を両側へ運んだ。

### コードレビューへの応用可能性

本章の結果は、コードレビューで何を残して要約し、どの単位で確認するかを考える手掛かりになる。
たとえば、注文処理の変更で、在庫更新と注文保存を別々にレビューする場面を考える。
各処理の説明に加えて、両者が同じ注文と処理結果を扱うように、値や前提を受け渡しているかも確認したい。
関数ごとの実装と、モジュール間の受渡しをまとめた説明とで、同じ不整合を捉えられるだろうか。

この問いを本章の構成で扱うには、対象コードの版と意味論を固定し、
状態や振る舞いからsourceとLawの評価を定める。
標準解像度は、選んだ評価を保つために要約へ残すべき区別を与える。
レビューする範囲をchartとし、その重なりと範囲間の対応を本章のnerveと比較写像で表せれば、
定理3.17の条件Cによって、分割や統合に沿う診断類の保存を確認できる。

さらに、同じ局所データから障害と診断を作り、§§3.9–3.10の構成と仮定を満たすときには、
要約上の診断の零を、元の局所状態を整合させる補正の存在へ戻せる。
ここで零性が述べるのは、選んだLawと係数の下での補正可能性である。
その補正を実際のコード変更として実現する方法は、応用時に定める課題となる。

まず検証すべき対象は、同じコードを異なる粒度で読んだときの診断の一致である。
コードからモデルへの対応と比較の仮定を具体的に確かめることで、
レビュー用の要約や分割を評価する方法へつながる。
変更前後のプログラムを比較する応用へ進むには、両者の入力と指定した障害類を対応づける構成を加える。

第2章の貼り合わせ障害に対して、本章は、何を読み、どの条件の下で読みを変更しても
同じ判定を得られるかを明らかにした。次章では、readingの変更に沿って対象と射を輸送する構成を扱い、
その普遍性と、単位・合成との整合を調べる。
