# 第6章 冪等正規化と実現

## 本章の概要

本章の問いは、**正規化を含む比較が何を残し、いつ元へ戻せるか**である。
第5章では、構造の輸送と入力の選択から二つの経路を作り、
その間の可逆な標準比較 $`\alpha`$ を得た。
さらに、診断に応じて選んだ正規化 $`E`$ を組み込み、生成比較 $`\beta=E\alpha`$ を構成した。
本章では、この最後の一段が比較の意味をどう変えるかを調べる。

たとえば、注文・在庫サービスへ分割した設計を、共通の設計モデルへまとめる場面を考える。
取消要求、在庫予約の解除、取消完了という操作と、その依存関係を残し、
サービス内部のクラス構成や補助的なデータ表現は、選んだ標準表現へ揃えたい。
保持する操作・Law・評価値がこの処理で変わらないことを確かめられれば、
標準表現の上で二つの設計案を比較できる。
ただし、その比較から元のクラス構成まで復元できるかは、別に確かめる必要がある。

一度標準表現へ揃えたものを、もう一度揃えても結果が変わらないとき、正規化は冪等である。
冪等性は「標準化を繰り返しても安定している」という性質であり、
「元の表現を復元できる」という可逆性とは異なる。
本章では、この違いを、対象の写像、構造を保つ射、正規化後の像という三つの段階で説明する。

| 問い | 調べる構成 | 得られるもの |
| --- | --- | --- |
| 正規化後にどの対象が残るか | configurationごとに選んだ対象 | 固定点とconfigurationの対応、読み取りの一意な因子化 |
| 操作とLawも含めて正規化を繰り返せるか | core・完全幾何の自己射 | 射全体の冪等性 |
| 正規化を加えた比較はいつ可逆か | 標準比較と冪等因子の分解 | 正規化因子が恒等であることとの同値 |
| 非可逆な比較を、残った情報の間でどう読むか | 冪等完備化における像 | 同じ生成比較による像同士の同型 |
| 正規化と任意の設計変更の順序を交換できるか | 正規化関手と自然性の条件 | 常に成り立つ片側の等式と、操作の追加情報による反例 |
| 比較そのものを変更の対象にできるか | 射の圏と冪等完備化 | 第7章で比較を保つ変更を分類するための圏 |

§§6.1–6.4では一本の生成比較を分析し、完全幾何での可逆性分類まで進む。
§§6.5–6.7では対象間の変更と比較の圏を構成し、§6.8でLensとプロトコルの意味論へ戻る。

## 6.1 Configurationごとに一つの表現を選ぶ

第1章のarchitecture objectは、configurationに構造データと量を加えた対象であった。
同じconfigurationを持つ対象を一つに揃えると、何が残るだろうか。
まず、操作やLawを加える前の対象の写像として、この問いに答える。

**構成6.1（Configurationへの射影と選択）.**
Atomの語彙を固定し、architecture object全体を $`𝒜`$、
configuration全体を $`𝒞`$ と書く。Core $`P`$ に対し、

```math
\pi:𝒜\longrightarrow𝒞,\quad \pi(A)=C_A,
\qquad
s_P:𝒞\longrightarrow𝒜,\quad s_P(C)=\mathrm{Form}_P(C)
\qquad\text{(6.1)}
```

と置く。ここでは $`𝒜,𝒞`$ は対象の集まりであり、式(6.1)はその間の写像である。
対象形成の条件により $`\pi s_P=1_{𝒞}`$ となる。
従って、定義5.39の正規化は

```math
n_P=s_P\pi,\qquad \pi n_P=\pi,\qquad n_P^2=n_P
\qquad\text{(6.2)}
```

を満たす。最後の式は $`s_P\pi s_P\pi=s_P\pi`$ という計算である。

**命題6.2（固定点とconfiguration）.**
固定点の集まり $`\mathrm{Fix}(n_P)=\{A\mid n_P(A)=A\}`$ と $`𝒞`$ の間に、
互いに逆な対応

```math
\mathrm{Fix}(n_P)\xrightarrow{\ \pi\ }𝒞,
\qquad C\longmapsto s_P(C)
\qquad\text{(6.3)}
```

がある。また、$`A\sim B`$ を $`C_A=C_B`$ で定めると、
$`𝒜/{\sim}\cong𝒞`$ である。

**証明.**
$`n_Ps_P=s_P`$ なので $`s_P(C)`$ は固定点である。
$`\pi s_P=1`$ と、固定点での $`s_P\pi(A)=A`$ が両側逆を与える。
商については $`[A]\mapsto C_A`$ が定義でき、逆は $`C\mapsto[s_P(C)]`$ である。
対象とその選択表現のconfigurationは等しいので、こちらも両側逆となる。□

**定理6.3（正規化で変わらない読み取り）.**
任意の値の集合 $`Y`$ と写像 $`f:𝒜\to Y`$ に対し、

```math
fn_P=f
\quad\Longleftrightarrow\quad
\exists!\,\widetilde f:𝒞\to Y,
\qquad f=\widetilde f\pi.
\qquad\text{(6.4)}
```

**証明.**
左辺が成立するとき、$`\widetilde f=fs_P`$ と置けば
$`\widetilde f\pi=fn_P=f`$ となる。
別の因子 $`g`$ が $`g\pi=f`$ を満たせば、右から $`s_P`$ を合成して
$`g=fs_P`$ を得る。逆に $`f=\widetilde f\pi`$ なら、
$`\pi n_P=\pi`$ より $`fn_P=f`$ である。□

この定理は、正規化が残す情報を、読み取りの側から特徴づける。
正規化の前後で変わらない値は、configurationだけから一意に読める。
定義5.39で要求した残差・invariant・signatureの不変性にも、この命題を適用できる。
その際は、文脈・方程式添字・軸など、対象以外の引数を固定して読む。

**例6.4（二つの表現を持つ有限モデル）.**
Configurationの集合を $`\{c_0,c_1\}`$、表現の印を $`\{0,1\}`$ とし、
対象を $`(c_i,t)`$、選択表現を $`(c_i,0)`$ とする。

```math
n(c_i,t)=(c_i,0).
\qquad\text{(6.5)}
```

四対象のうち固定点は二つである。
読み取り $`f(c_i,t)=i`$ は正規化で変わらず、configurationから読める。
一方、$`f(c_i,t)=t`$ は元の表現を区別するため、正規化後には同じ値を回復できない。
ソフトウェアの例では、選んだ操作と依存関係を前者に、
その構成をどの補助データで表したかを後者に対応させて考えられる。

## 6.2 対象の正規化を、構造を保つ冪等射へ上げる

対象の写像が冪等であっても、それだけでは操作とLawを保つ射にはならない。
定義5.39の条件 $`\mathrm{Ad}(P)`$ は、そのために必要な保存則を与える。
本節では、その条件から作った射全体が冪等であることを示す。

**定理6.5（Coreの正規化の冪等性）.**
$`\mathrm{Ad}(P)`$ を満たすcore $`P`$ について、定義5.39の自己射
$`N_P:P\to P`$ は

```math
N_P^2=N_P,\qquad q(N_P)=1_{q(P)}
\qquad\text{(6.6)}
```

を満たす。ここで $`q:E_{\mathrm{core}}\to B`$ は底への射影である。

**証明.**
対象写像については式(6.2)を使う。
Atom・底・文脈・方程式添字・invariant添字・signature軸の写像は恒等なので、二回合成しても同じである。
方程式の環の対応とsignatureの値域の対応も恒等であり、残差の保存は $`\mathrm{Ad}(P)`$ による。

Operationには、$`\mathrm{Op}_P(A,B)`$ と
$`\mathrm{Op}_P(n_P(A),n_P(B))`$ の型の等号に沿う同一視を使っている。
二回の同一視を合成しても、$`n_P^2=n_P`$ で端点を揃えた後には一回の同一視と等しい。
そのconfiguration写像も、$`\mathrm{Ad}(P)`$ の操作保存条件によって同じである。
以上で、定義1.28の射の全データが一致する。
底の射は構成から恒等である。□

**補題6.6（対象写像についての自然性）.**
任意のcore射 $`h:P\to Q`$ の対象写像を $`H`$、Atomの全単射を $`e`$ とすると、

```math
Hn_P=n_QH.
\qquad\text{(6.7)}
```

この結論に $`\mathrm{Ad}(P)`$ や $`\mathrm{Ad}(Q)`$ は必要ない。

**証明.**
定義1.28の対象形成とconfigurationの保存から、

```math
H(n_P(A))
=H(\mathrm{Form}_P(C_A))
=\mathrm{Form}_Q(e_*C_A)
=\mathrm{Form}_Q(C_{H(A)})
=n_Q(H(A))
```

となる。□

式(6.7)は対象の対応についての等式である。
Operationの対応まで含めた $`hN_P=N_Qh`$ の条件は、§6.6で求める。

**命題6.7（同じconfiguration上の相異なる対象）.**
任意のconfiguration $`C`$ の上に、相異なるarchitecture objectが少なくとも二つ存在する。
従って、どのcore $`P`$ についても $`n_P`$ は単射でなく、
$`\mathrm{Ad}(P)`$ が成立すれば $`N_P`$ は同型でない。

**証明.**
構造データの型をそれぞれ一元集合 $`\{*\}`$ と二元集合 $`\{0,1\}`$ とし、
構造データの値を $`*`$ と $`0`$、量の型と値をどちらも一元集合に取る。
これらは同じ $`C`$ を持つ対象だが、構造データの型の濃度が違うため等しくない。
両方の正規化先は $`\mathrm{Form}_P(C)`$ なので $`n_P`$ は非単射である。
Core射の逆射があれば、その対象写像も両側逆を持つため、$`N_P`$ は同型になれない。□

ここで対象にしているのは、選択された表現だけでなく、定義1.6のarchitecture object全体である。
この集まりには、同じconfigurationを異なる構造データで表す対象が含まれる。
その区別を一つの選択表現へまとめることが、$`N_P`$ の非可逆性を生む。

**定理6.8（Coreの圏内では正規化は分裂しない）.**
$`\mathrm{Ad}(P)`$ が成立するとする。
Core $`Q`$ とcore射 $`r:P\to Q`$、$`i:Q\to P`$ であって、

```math
ri=1_Q,\qquad ir=N_P
\qquad\text{(6.8)}
```

を満たすものは存在しない。

**証明.**
存在すると仮定し、$`r,i`$ の対象写像をそれぞれ $`R,I`$ とする。
$`RI=1`$ なので $`I`$ は単射である。
補題6.6と $`IR=n_P`$ から、任意の対象 $`A`$ について

```math
I(n_Q(A))=n_P(I(A))=IR(I(A))=I(A)
```

を得る。単射性より $`n_Q(A)=A`$ となり、命題6.7に反する。□

対象の集まりでは、式(6.2)がconfigurationを介した分裂を与えていた。
しかし、coreはconfigurationの集合そのものではなく、全architecture objectについての
対象形成・操作・Lawの読みを備える。Configurationの集合を取り出しただけでは、
式(6.8)の中間coreを得たことにはならない。
正規化の像を圏の対象として扱うため、次節で対象と射を拡張する。

## 6.3 冪等完備化で、残った情報を対象にする

集合上の冪等写像なら、その固定点の集合を像として取り出せる。
一般の圏でも同じ役割を持つ対象を扱えるようにするのが、冪等完備化である。
この構成により、元の比較が失う情報と、像の間で保たれる対応を同じ式で表せる。

**定義6.9（Karoubi envelope）.**
圏 $`E`$ の冪等完備化 $`\mathrm{Kar}(E)`$ の対象は、
対象 $`X\in E`$ と冪等射 $`e:X\to X`$ の組 $`(X,e)`$ である。
射 $`a:(X,e)\to(Y,d)`$ は、$`E`$ の射 $`a:X\to Y`$ で

```math
dae=a
\quad\Longleftrightarrow\quad
da=a=ae
\qquad\text{(6.9)}
```

を満たすものとする。合成は $`E`$ の合成を使い、$`(X,e)`$ の恒等射は $`e`$ とする。
これらは、$`E`$ の圏の法則と式(6.9)により圏をなす。

**構成6.10（元の圏の埋込みと冪等射の分裂）.**
$`J:E\to\mathrm{Kar}(E)`$ を $`J(X)=(X,1_X)`$、$`J(f)=f`$ で定める。
これは充満忠実である。任意の $`(X,e)`$ について、元の射としてはいずれも $`e`$ である二射

```math
J(X)\xrightarrow{\ r_X\ }(X,e)
\xrightarrow{\ i_X\ }J(X)
\qquad\text{(6.10)}
```

があり、

```math
r_Xi_X=1_{(X,e)},\qquad i_Xr_X=J(e).
\qquad\text{(6.11)}
```

**証明.**
$`(X,1_X)`$ 間では式(6.9)は任意の射に成立するので、$`J`$ は充満忠実である。
$`r_X,i_X`$ に式(6.9)を確認すると、いずれも $`e^2=e`$ になる。
両合成の元の射は $`e`$ であり、それは $`(X,e)`$ では恒等、$`J(X)`$ では $`J(e)`$ である。□

**命題6.11（冪等射の像の実現）.**
$`\mathrm{Kar}(E)`$ では全ての冪等射が分裂する。
また、$`E`$ の中に $`ri=1_Z`$、$`ir=e`$ を満たす分裂があるときは、
$`(X,e)\cong J(Z)`$ である。

**証明.**
冪等な射 $`a:(X,e)\to(X,e)`$ は $`a^2=a`$ と $`ea=a=ae`$ を満たす。
対象 $`(X,a)`$ を作り、両方向とも元の射を $`a`$ とすれば、その分裂になる。
後半では、与えられた $`r,i`$ を $`(X,e)`$ と $`J(Z)`$ の間の射と見る。
$`re=r`$、$`ei=i`$ と両側逆の式は、分裂の等式から従う。□

従って $`(P,N_P)`$ は、coreの正規化が残す情報を扱う新しい対象になる。
定理6.8は、これが $`E_{\mathrm{core}}`$ の中で同じ正規化を分裂させた対象ではないことを示している。
冪等完備化では、恒等射を $`N_P`$ とすることで、その像に適した射を定めている。

**定理6.12（比較の正規化分解と像の同型）.**
任意の圏 $`E`$ において、同型 $`\alpha:X\xrightarrow{\sim}Y`$ と
冪等射 $`d:Y\to Y`$ を取る。

```math
\beta=d\alpha,\qquad e=\alpha^{-1}d\alpha
\qquad\text{(6.12)}
```

と置くと、$`e^2=e`$ であり、次が成立する。

```math
\begin{gathered}
\beta\text{ が }E\text{ で可逆}
\quad\Longleftrightarrow\quad d=1_Y,\\
\beta:(X,e)\xrightarrow{\sim}(Y,d)
\quad\text{in }\mathrm{Kar}(E).
\end{gathered}
\qquad\text{(6.13)}
```

像の間の逆射の元の射は $`\gamma=\alpha^{-1}d`$ である。

**証明.**
共役の計算により $`e^2=\alpha^{-1}d^2\alpha=e`$ となる。
$`\alpha`$ が可逆なので、$`\beta`$ が可逆であることと $`d`$ が可逆であることは同値である。
可逆な冪等射では $`d^2=d`$ から一つの $`d`$ を消去して $`d=1_Y`$ を得る。
逆は明らかである。

次に、$`d\beta e=\beta`$、$`e\gamma d=\gamma`$ を $`d^2=d`$ で確認する。
両合成は

```math
\gamma\beta=e=1_{(X,e)},\qquad
\beta\gamma=d=1_{(Y,d)}
\qquad\text{(6.14)}
```

なので、$`\gamma`$ は $`\mathrm{Kar}(E)`$ における逆射である。□

この結果で同型になるのは、正規化後に残った像同士である。
像の同型に用いる射は、元の圏で非可逆だったものと同じ $`\beta`$ であり、
両端の対象とその恒等射が変わっている。

**例6.13（四点から二点の像へ）.**
集合 $`X=\{a,b,c,d\}`$、$`Y=\{0,1,2,3\}`$ を取り、
同型 $`\alpha`$ と正規化 $`d_Y`$ を次の表で与える。

| $`x`$ | $`\alpha(x)`$ | $`\beta(x)=d_Y(\alpha(x))`$ | $`e_X(x)`$ |
| --- | --- | --- | --- |
| a | 1 | 0 | c |
| b | 3 | 2 | d |
| c | 0 | 0 | c |
| d | 2 | 2 | d |

ここで $`d_Y(0)=d_Y(1)=0`$、$`d_Y(2)=d_Y(3)=2`$、
$`e_X=\alpha^{-1}d_Y\alpha`$ である。
$`\beta`$ は $`a,c`$ と $`b,d`$ をそれぞれ同一視するので、四点の間では非可逆である。
一方、固定点の集合 $`\{c,d\}`$ と $`\{0,2\}`$ の間では全単射になる。
式(6.14)は、一般の圏でこの像の対応を表したものである。

## 6.4 完全幾何の生成比較を分類する

第5章の生成比較では、正規化するかどうかを診断と保存条件から選び、
その自己射を実際の経路に沿って運んだ。
この構成に定理6.12を適用するため、coreの操作とLawに加え、
被覆・重なり・係数・局所データを含む射について冪等性を確かめる。

**定理6.14（完全幾何の冪等正規化）.**
Core $`P=p(G)`$ が $`\mathrm{Ad}(P)`$ を満たす完全幾何 $`G`$ に対し、
定義5.39の自己射 $`N_G:G\to G`$ は

```math
N_G^2=N_G,\qquad p(N_G)=N_P,\qquad
qp(N_G)=1_{qp(G)}
\qquad\text{(6.15)}
```

を満たす。係数環への写像は恒等である。

**証明.**
Core成分の冪等性は定理6.5による。
幾何の射の残りの成分では、文脈・Atom・軸の写像は恒等であり、
被覆要件はそのまま保存され、overlapの比較は恒等同型である。
係数準同型とsupport・軸・observableの比較写像も恒等なので、二回の合成は一回に等しい。
Raw systemは恒等な再添字づけと恒等な係数変更で保存される。
従って定義1.30の全成分が一致する。射影の式は構成から従う。□

**補題6.15（生成された輸送と正規化の交換）.**
Exactな底射 $`\sigma:b\to b'`$ に沿う、第4・5章のcanonicalな輸送と引き戻しは、
$`\mathrm{Ad}`$ を保つ。また、許容されるcoreと完全幾何について

```math
\sigma_!(N_P)=N_{\sigma_!P},\qquad
\sigma^*(N_Q)=N_{\sigma^*Q},
\qquad\text{(6.16)}
```

が成立する。完全幾何でも $`P,Q`$ を $`G,H`$ に置き換えた同じ等式が成立する。
実際に生成したlift $`\iota_{\sigma,P}:P\to\sigma_!P`$、
$`\kappa_{\sigma,Q}:\sigma^*Q\to Q`$ には

```math
N_{\sigma_!P}\iota_{\sigma,P}=\iota_{\sigma,P}N_P,
\qquad
N_Q\kappa_{\sigma,Q}=\kappa_{\sigma,Q}N_{\sigma^*Q}
\qquad\text{(6.17)}
```

が成立し、幾何のliftにも同じ式が成立する。

**証明.**
底射のAtom写像を $`e`$、対象の再添字づけを $`T_e`$ と書く。
輸送された対象形成の定義から

```math
n_{\sigma_!P}(T_eA)=T_e(n_P(A))
\qquad\text{(6.18)}
```

となる。$`T_e`$ は $`T_{e^{-1}}`$ を逆に持つので、
輸送先の任意の対象についての保存則を、輸送前の対象についての保存則へ戻せる。
残差・invariant・signatureの不変性をこの対応で運べば、輸送先の同じ条件を得る。
Operationの型の等号とconfiguration写像の可換性も、同じ再添字づけで運ばれる。
これが $`\mathrm{Ad}`$ の保存である。引き戻しでは $`e^{-1}`$ を用いる。

生成したliftのoperation写像は、再添字づけと端点の型の等号による同一視から作られている。
正規化の同一視をその前後へ移しても、式(6.18)で端点を揃えると、元の同じoperationを得る。
他のcore成分は恒等写像または同じ再添字づけであり、これで式(6.17)を得る。
幾何では、定理6.14の恒等な局所比較を前後に合成するため、同じ等式が全成分で成立する。
最後にliftの普遍性を用いると、式(6.17)を満たすvertical射は一意なので式(6.16)を得る。□

この補題が扱うのは、同じ再添字づけから生成した輸送と引き戻しである。
対象以外にも独自のoperation写像を持つ一般の射については、§6.6で交換条件を調べる。

**定理6.16（生成比較の正規化分解と可逆性分類）.**
構成5.37・5.40と同じexactなpointed pullback square、比較図式の面 $`z`$、
cochain $`\omega`$、source core $`P_z`$、可換係数環 $`k`$、完全幾何 $`G_z`$ を固定する。
二経路の終点と標準比較を

```math
X=\overline D(G_z),\qquad Y=\overline V(G_z),\qquad
\overline\alpha=\overline\alpha_z:X\xrightarrow{\sim}Y
\qquad\text{(6.19)}
```

と略記する。正規化を選ぶ条件と、生成された射を

```math
\begin{aligned}
\chi&\Longleftrightarrow
   (\omega_z\ne1)\ \text{かつ}\ \mathrm{Ad}(P_z),\\
\overline d&=\overline V(\overline S_{z,\omega}),\qquad
\overline\beta=\overline d\,\overline\alpha,\qquad
\overline e=\overline\alpha^{-1}\overline d\,\overline\alpha
\end{aligned}
\qquad\text{(6.20)}
```

とする。このとき、$`\overline d^2=\overline d`$、$`\overline e^2=\overline e`$ であり、

```math
\overline\beta\text{ が }E_{\mathrm{geom}}\text{ で可逆}
\quad\Longleftrightarrow\quad
\overline d=1_Y
\quad\Longleftrightarrow\quad
\neg\chi.
\qquad\text{(6.21)}
```

また、同じ射 $`\overline\beta`$ が同型

```math
(X,\overline e)\xrightarrow{\ \overline\beta\ }(Y,\overline d)
\quad\text{in }\mathrm{Kar}(E_{\mathrm{geom}})
\qquad\text{(6.22)}
```

を与え、その逆の元の射は $`\overline\alpha^{-1}\overline d`$ である。
$`\chi`$ が成立するときは、両終点のcoreも $`\mathrm{Ad}`$ を満たし、

```math
\overline d=N_Y,\qquad \overline e=N_X.
\qquad\text{(6.23)}
```

$`\chi`$ が成立しないときは、両冪等射は恒等である。

**証明.**
構成5.40のsource自己射は、$`\chi`$ が成立すれば $`N_{G_z}`$、それ以外は恒等である。
定理6.14と関手性より、その像 $`\overline d`$ は冪等となる。
構成5.37の $`\overline\alpha`$ は同型なので、定理6.12が
式(6.21)の最初の同値、$`\overline e`$ の冪等性、式(6.22)を与える。

$`\chi`$ が成立するとする。補題6.15を四辺の輸送と引き戻しに使うと、
両終点の $`\mathrm{Ad}`$ が得られ、$`\overline d=N_Y`$ となる。
さらに、標準比較を特徴づける式(5.18)の幾何版

```math
\kappa_{\sigma_2,(\sigma_1)_!G_z}\,
\overline\alpha\,\iota_{\pi_2,\pi_1^*G_z}
=\iota_{\sigma_1,G_z}\,\kappa_{\pi_1,G_z}
\qquad\text{(6.24)}
```

に、各liftについての式(6.17)を代入する。
$`N_Y\overline\alpha`$ と $`\overline\alpha N_X`$ は、
両外側のliftと合成した後に同じ射になる。
Coreと幾何の各liftの一意性を順に使えば
$`N_Y\overline\alpha=\overline\alpha N_X`$ となり、式(6.23)の第二式を得る。

命題6.7より $`N_{p(Y)}`$ は恒等でない。
$`p(N_Y)=N_{p(Y)}`$ なので $`\overline d=N_Y\ne1_Y`$ である。
一方、$`\neg\chi`$ なら source自己射もその像も恒等であり、
共役した $`\overline e`$ も恒等となる。これで式(6.21)の残りの同値を得る。□

式(6.21)は、構成5.40で選んだ生成規則についての分類である。
診断が恒等でない場合でも、正規化の保存条件が満たされなければ、この規則は恒等射を選ぶ。
また、正規化を選ぶことと診断の値を消すことは、それぞれ別の命題である。
本定理が明らかにするのは、その選択から生成された比較の可逆性と像である。

**命題6.17（Coreの比較への射影）.**
定理6.16の入力について、$`\alpha=\alpha_{P_z}`$、$`E=E_{z,\omega}`$、
$`\beta=\beta_{z,\omega}`$、$`e=\alpha^{-1}E\alpha`$ と書く。
命題5.38の端点同型 $`j_D:pX\xrightarrow{\sim}DP_z`$、
$`j_V:pY\xrightarrow{\sim}VP_z`$ の下で、

```math
\begin{aligned}
j_Vp(\overline\alpha)&=\alpha j_D,&
j_Vp(\overline d)&=Ej_V,\\
j_Dp(\overline e)&=e j_D,&
j_Vp(\overline\beta)&=\beta j_D.
\end{aligned}
\qquad\text{(6.25)}
```

従って、幾何の像の同型をcoreへ射影すると、coreで構成した像の同型に一致する。

**証明.**
最初の二式と最後の式は、式(5.44)・(5.48)である。
残る式は、$`p`$ が合成と逆射を保つことを用いて
$`\overline e=\overline\alpha^{-1}\overline d\,\overline\alpha`$ を射影すれば得られる。
冪等完備化では、端点を揃える同型の元の射はそれぞれ $`e j_D`$、$`E j_V`$ である。
式(6.25)と冪等性により、これらは像の間の同型を定め、比較の平方を可換にする。□

**例6.18（正規化が実際に選ばれる場合）.**
Atomを一つとし、sourceを一つ、抽出族をその一元集合、source正規化を恒等とする。
Compositionは $`\mathrm{Comp}(F)=(F,\varnothing,\varnothing)`$、
対象形成は任意のconfigurationに一元集合の構造データと量を置くものとする。
Operationには $`\mathrm{Hom}(C_A,C_B)`$ を使う。
方程式添字とinvariant添字は空、signature軸は二つで、その値をどちらも整数0とする。
両方の軸を選択軸とする。

文脈は、抽出族の部分集合 $`U`$ とsignature軸の部分集合 $`T`$ の対 $`(U,T)`$ とし、
成分ごとの包含を射とする。Supportは $`U`$ で各Atomをそのまま読み、軸は $`T`$ の全てを読めるものとする。
Observableは読める一元集合とし、制限はsupport・軸で包含、observableで恒等を使う。
方程式の環は定値の $`ℤ`$、制限は恒等とする。添字が空なので、残差の条件とdetectorの指定は空である。

このcore $`P`$ は $`\mathrm{Ad}(P)`$ を満たす。
二つの軸を交換し、他の成分を固定する射 $`\tau:P\to P`$ は、
$`\tau^2=1`$、$`\tau\ne1`$ を満たす自己同型である。
恒等な底の平方と、一つの指定面を持つ比較図式を取り、$`\omega_z=\tau`$ と選ぶ。
恒等な再添字づけの単位比較で各終点を $`P`$ と同一視すると、二経路と標準比較は恒等になる。
生成規則は $`N_P`$ を選ぶため、$`\beta=N_P`$ は非可逆である。

完全幾何も具体的に加えられる。上の文脈でoverlapを成分ごとの共通部分、被覆要件を空とする。
係数を $`ℤ`$、各文脈のraw coordinateを一つ $`x`$、関係を $`x^2-x`$ とし、
座標の種別をsemantic、局所データの型を一元集合、全ての制限を恒等に取る。
制限は関係を保ち、恒等と合成に従うので、完全幾何 $`G`$ が得られる。
幾何の終点も同じ単位比較で揃えると、$`\overline\beta=N_G`$ となる。
これは $`E_{\mathrm{geom}}`$ では非可逆だが、$`(G,N_G)`$ 上では恒等射である。

## 6.5 正規化後の対象と変更を、一つの圏にする

一本の比較について像を構成できたので、次に複数のcoreと、その間の変更を同時に扱う。
設計変更のたびに像の間の射を選び直すのではなく、元の射から一貫して作ることが目的である。

**補題6.19（片側の吸収則）.**
$`\mathrm{Ad}`$ を満たすcoreの充満部分圏を $`𝒞_{\mathrm{ad}}`$ とする。
その任意の射 $`f:P\to Q`$ に対して、

```math
N_QfN_P=fN_P.
\qquad\text{(6.26)}
```

**証明.**
対象写像を $`F`$ とする。補題6.6により
$`n_QFn_P=Fn_P^2=Fn_P`$ である。
Operation $`o\in\mathrm{Op}_P(A,B)`$ は、まず正規化された端点へ同一視され、
その後 $`f`$ のoperation写像で送られる。
その行き先の対象 $`F(n_P(A)),F(n_P(B))`$ は、今の対象写像の等式により既に固定点である。
従って最後の $`N_Q`$ のoperation写像は、同じ型上での恒等な同一視になる。
底・Atom・文脈・方程式・invariant添字・軸・値域の成分には最後に恒等が合成されるだけである。
射の全成分が等しいので、式(6.26)を得る。□

**構成6.20（正規化されたcoreの圏）.**
$`𝒞_{\mathrm{nor}}`$ の対象には $`𝒞_{\mathrm{ad}}`$ と同じcoreを用いる。
その射と恒等射を

```math
\begin{aligned}
\mathrm{Hom}_{𝒞_{\mathrm{nor}}}(P,Q)
 &=\{a:P\to Q\text{ in }𝒞_{\mathrm{ad}}\mid N_QaN_P=a\},\\
1_P^{\mathrm{nor}}&=N_P
\end{aligned}
\qquad\text{(6.27)}
```

と定める。合成は元のcore射の合成である。
式(6.9)より、これは $`(P,N_P)`$ 間の全てのKaroubi射を使った圏である。
従って

```math
K:𝒞_{\mathrm{nor}}\longrightarrow\mathrm{Kar}(𝒞_{\mathrm{ad}}),
\qquad K(P)=(P,N_P),\quad K(a)=a
\qquad\text{(6.28)}
```

は充満忠実な関手になる。対象の表示に同じ記号 $`P`$ を使っても、恒等射と射の集合が変わっている。

**定理6.21（充満な正規化関手）.**
次の対応は充満な関手を定める。

```math
\begin{gathered}
\mathsf{N}_{\mathrm{core}}:𝒞_{\mathrm{ad}}\longrightarrow𝒞_{\mathrm{nor}},\\
\mathsf{N}_{\mathrm{core}}(P)=P,\qquad
\mathsf{N}_{\mathrm{core}}(f)=fN_P.
\end{gathered}
\qquad\text{(6.29)}
```

**証明.**
式(6.26)と $`N_P^2=N_P`$ より、$`fN_P`$ は式(6.27)の射になる。
恒等射は $`1_PN_P=N_P=1_P^{\mathrm{nor}}`$ へ移る。
$`f:P\to Q`$、$`g:Q\to R`$ に対し、

```math
(gN_Q)(fN_P)=g(N_QfN_P)=gfN_P
\qquad\text{(6.30)}
```

なので合成を保つ。
任意の射 $`a:P\to Q`$ in $`𝒞_{\mathrm{nor}}`$ は、式(6.9)により $`aN_P=a`$ を満たす。
その元のcore射 $`a`$ 自身を逆像に選べば、$`\mathsf{N}_{\mathrm{core}}(a)=a`$ である。□

充満性は、正規化後に許される全ての射に元のcore射がある、という主張である。
異なるcore射が同じ像を持つことはあり、§6.6でその例を示す。

**命題6.22（完全幾何への拡張と射影の整合性）.**
許容されるcoreを持つ完全幾何の充満部分圏を $`𝒢_{\mathrm{ad}}`$ とする。
任意の射 $`f:G\to H`$ に対し、

```math
N_HfN_G=fN_G.
\qquad\text{(6.31)}
```

このため、射を $`N_HaN_G=a`$ で定める圏 $`𝒢_{\mathrm{nor}}`$ と、
充満な関手 $`\mathsf{N}_{\mathrm{geom}}(f)=fN_G`$ が得られる。
Coreへの射影が誘導する関手を $`p_{\mathrm{ad}},p_{\mathrm{nor}}`$ と書くと、

```math
p_{\mathrm{nor}}\mathsf{N}_{\mathrm{geom}}
=\mathsf{N}_{\mathrm{core}}p_{\mathrm{ad}}.
\qquad\text{(6.32)}
```

また、正規化後の射の底と係数準同型は、元の射のものに等しい。

**証明.**
Core成分では補題6.19を使う。
幾何の成分では、最後の $`N_H`$ が係数・support・軸・observableへ恒等写像を合成するため、
元の $`fN_G`$ と等しい。これで式(6.31)を得る。
関手性と充満性は定理6.21と同じ計算である。
$`p(N_G)=N_{p(G)}`$ より、対象と射の両方で式(6.32)が成立する。
底と係数では、$`N_G`$ の成分が恒等なので、その合成は元の射を変えない。□

## 6.6 正規化と変更の順序を交換できる条件

正規化が関手になることは、任意の変更と正規化の順序を交換できることまでは意味しない。
前者に必要だったのは式(6.26)であり、後者はより強い等式である。
その差が、どの成分に現れるかを調べる。

**命題6.23（包含の自然性と射影の条件）.**
構成6.20の $`K`$ と、構成6.10を $`𝒞_{\mathrm{ad}}`$ に適用した埋込み $`J`$ を用いる。
元の射を $`N_P`$ とする包含
$`i_P:(P,N_P)\to J(P)`$ は自然変換

```math
i:K\mathsf{N}_{\mathrm{core}}\Longrightarrow J
\qquad\text{(6.33)}
```

を定める。逆向きの射 $`r_P:J(P)\to(P,N_P)`$ は対象ごとに
$`r_Pi_P=1_{(P,N_P)}`$ を満たし、その族が射 $`f:P\to Q`$ について自然であることは

```math
fN_P=N_Qf
\qquad\text{(6.34)}
```

と同値である。

**証明.**
包含の自然性の両辺の元の射は $`fN_P`$ と $`N_QfN_P`$ であり、補題6.19で等しい。
対象ごとの分裂は式(6.11)による。
逆向きの族の自然性は $`(fN_P)N_P=N_Qf`$ という等式であり、
$`N_P^2=N_P`$ を用いると式(6.34)になる。□

**命題6.24（Operationの対応による自然性の判定）.**
$`\mathrm{Ad}(P)`$、$`\mathrm{Ad}(Q)`$ が成立し、$`f:P\to Q`$ の対象写像を $`F`$ とする。
正規化のoperation写像を

```math
c^P_{A,B}:\mathrm{Op}_P(A,B)
\longrightarrow\mathrm{Op}_P(n_P(A),n_P(B))
\qquad\text{(6.35)}
```

と書く。このとき式(6.34)は、全ての $`A,B,o`$ について

```math
f^{\mathrm{op}}_{n_P(A),n_P(B)}(c^P_{A,B}(o))
=c^Q_{F(A),F(B)}(f^{\mathrm{op}}_{A,B}(o))
\qquad\text{(6.36)}
```

が成立することと同値である。両辺の端点は補題6.6によって同一視する。

**証明.**
式(6.36)は二つの合成射のoperation成分の等式である。
対象成分は補題6.6で等しく、底・Atom・文脈・方程式・invariant添字・軸・値域の成分では、
正規化の恒等写像が前または後ろに合成されるため等しい。
従ってoperation成分の一致が、射全体の一致と同値になる。□

式(6.36)では、operationのconfigurationへの作用だけでなく、operation自身を比較している。
第1章の例1.8と同様に、同じ作用を持つ操作にも、名前や追加情報の違いがあり得る。

**例6.25（操作の印によって順序が変わる）.**
例6.18のcoreのoperationを

```math
\mathrm{Op}_{P^{\mathrm{tag}}}(A,B)
=\mathrm{Hom}(C_A,C_B)\times\{0,1\}
\qquad\text{(6.37)}
```

へ置き換える。Configurationへの作用には第一成分だけを使い、他のreadingはそのままとする。
第二成分は、同じ作用を持つ二つのoperationを区別する印である。
このcoreも $`\mathrm{Ad}`$ を満たし、正規化はconfiguration写像と印をそのまま保つ。

あるconfiguration $`C`$ の上で、構造データの型が二元集合である対象を $`A_\bullet`$ とする。
その選択表現 $`n(A_\bullet)`$ の構造データの型は一元集合なので、
$`n(A_\bullet)\ne A_\bullet`$ である。
対象・底・他のreadingを恒等に保ち、operationだけに

```math
f^{\mathrm{op}}_{A,B}(u,t)=
\begin{cases}
(u,1-t),&A=A_\bullet,\\
(u,t),&A\ne A_\bullet
\end{cases}
\qquad\text{(6.38)}
```

を作用させる。第一成分 $`u`$ は変わらないので、定義1.28のconfigurationの可換平方を満たす。
他の成分も恒等であり、$`f`$ は実際のcore自己射である。二回作用させれば元に戻るため $`f^2=1`$ でもある。

始点と終点を $`A_\bullet`$、operationを $`(1_C,0)`$ に取ると、次の違いが生じる。

| 適用順序 | 正規化後の始点・終点 | 最後の印 |
| --- | --- | --- |
| 正規化してから $`f`$ を適用する | どちらも $`n(A_\bullet)`$ | 0 |
| $`f`$ を適用してから正規化する | どちらも $`n(A_\bullet)`$ | 1 |

従って $`fN\ne Nf`$ であり、命題6.23の逆向きの族は自然でない。
対象写像とconfigurationへの作用は両経路で一致している。
順序の違いを検出しているのは、operationに保持した印である。

さらに、全ての正規化先は一元集合の構造データを持つため、$`A_\bullet`$ にはならない。
このことから $`fN=N=1N`$ である。
異なる二射 $`f\ne1`$ が同じ正規化後の射へ移るので、
定理6.21の充満な関手は一般には忠実でない。

設計変更に読み替えると、標準表現へ揃えた後の操作の対応が同じでも、
元の表現に依存する操作の指定は異なり得る。
たとえば、同じ取消操作に対し、元の実装方式に応じて監査用のラベルを付け替える処理が考えられる。
実装方式の区別を先にまとめると、付け替えるべき操作を区別できなくなる。
正規化の前後を自由に交換したい場合、レビューでは対象の対応に加えて式(6.36)を確認する。

## 6.7 比較そのものの圏と、三段の射影

第7章では、一つの比較を保つ変更を調べる。
そのためには、比較射自体を対象とし、両端の変更を射として扱うとよい。
冪等完備化は、この比較の圏とも整合する。

**定義6.26（射の圏と比較の圏）.**
圏 $`E`$ の射の圏 $`\mathrm{Arr}(E)`$ は、射 $`c:X\to Y`$ を対象とする。
$`c`$ から $`c':X'\to Y'`$ への射は、$`a:X\to X'`$、$`b:Y\to Y'`$ の組で、

```math
bc=c'a
\qquad\text{(6.39)}
```

を満たすものである。恒等と合成は両端で成分ごとに定める。
正規化後の比較を扱う圏を

```math
ℳ(E)=\mathrm{Arr}(\mathrm{Kar}(E))
\qquad\text{(6.40)}
```

とする。

**定理6.27（比較と冪等完備化の交換）.**
任意の圏 $`E`$ に対して、自然な圏同値

```math
\Phi_E:\mathrm{Kar}(\mathrm{Arr}(E))
\simeq\mathrm{Arr}(\mathrm{Kar}(E))
\qquad\text{(6.41)}
```

がある。左辺の対象を、射 $`c:X\to Y`$ と冪等な可換平方 $`(e,d)`$、すなわち
$`e^2=e`$、$`d^2=d`$、$`dc=ce`$ で表すと、$`\Phi_E`$ はそれを

```math
(X,e)\xrightarrow{\ dce\ }(Y,d)
\qquad\text{(6.42)}
```

へ送る。

**証明.**
$`dc=ce`$ と冪等性から、$`dce`$ は式(6.9)を満たす。
左辺の射の両端を $`a,b`$ とすると、もとの可換平方に加えて
$`e'ae=a`$、$`d'bd=b`$ が成立する。
従って同じ $`a,b`$ をKaroubi射と見れば、
$`b(dce)=(d'c'e')a`$ が成立する。
恒等と合成は両端で同じ計算なので、これで関手を得る。

逆向きには、Karoubi射 $`u:(X,e)\to(Y,d)`$ から、元の射 $`u:X\to Y`$ と
冪等平方 $`(e,d)`$ を取る。$`du=u=ue`$ により平方は可換である。
射についても両端の元の射を取る。
この後に $`\Phi_E`$ を適用すると、$`due=u`$ なので元へ戻る。

逆の往復では、$`(c,e,d)`$ の比較が $`dce`$ へ変わる。
両端が $`(e,d)`$ である平方を両方向に置くと、これは冪等完備化内の同型になる。
両合成の両端は $`(e,d)`$ であり、それがそこでの恒等射だからである。
この同型の自然性も、射の両端の式 $`e'ae=a`$、$`d'bd=b`$ から従う。□

**命題6.28（関手と射影への適合）.**
関手 $`F:E\to E'`$ は、$`(X,e)\mapsto(FX,F(e))`$ と射への作用により
$`\mathrm{Kar}(F)`$ を誘導する。
この作用と式(6.41)は自然同型の下で可換である。
特に、三段の射影は関手

```math
ℳ(E_{\mathrm{geom}})
\longrightarrowℳ(E_{\mathrm{core}})
\longrightarrowℳ(B)
\qquad\text{(6.43)}
```

を誘導し、二段を続けた射影と合成射影が一致する。

**証明.**
関手は冪等性と式(6.9)を保つ。
式(6.42)に関手を適用した比較は $`F(dce)`$ であり、先に各成分を送った比較は
$`F(d)F(c)F(e)`$ である。関手の合成保存によって両者は等しい。
端点と射の両端の成分も同じであり、端点の恒等射を成分とする自然同型を得る。
二つの関手の合成についても同じ成分計算を行えば、最後の主張が従う。□

**構成6.29（可逆な比較の変更）.**
$`ℳ(E)`$ の対象を全て残し、その間の同型だけを射にすると最大亜群を得る。
対象となる比較 $`c`$ 自身の可逆性は問わない。
可逆であることを要求するのは、比較を対応づける両端の変更である。
実際、射の圏の同型は、両端が同型である可換平方と同値である。
片方向は両端への評価で従い、逆方向は両端の逆射が逆の可換平方を作ることから従う。

生成比較 $`\beta`$ には、二つの対象としての読み方がある。
元の射を埋め込んだ $`J(\beta):J(X)\to J(Y)`$ と、
定理6.12の像の間の射 $`\beta:(X,e)\to(Y,d)`$ である。
前者が非可逆でも、後者は同型となる。
これらの端点を明示しておくことで、第7章では「どの比較を、どの変更が保つか」を指定できる。

## 6.8 Lensとプロトコルでは何が像に残るか

像の構成をソフトウェアの意味へ戻すには、残った状態で読取り・更新・実行ができることを確かめる。
Lensとプロトコルは、これらの操作を第1章で独立に定義した意味論である。
同じ冪等像の定理を適用すると、状態をまとめる条件が、それぞれ更新と実行の保存条件になる。

**例6.30（更新を保つLensの正規化）.**
二元集合 $`V=R=\{0,1\}`$ の積lensを取り、状態を $`C=V\times R`$ とする。
基準viewを0とし、読取りは $`g(v,r)=v`$、更新は $`p((v,r),w)=(w,r)`$ とする。
第二成分を0に揃える写像

```math
h(v,r)=(v,0)
\qquad\text{(6.44)}
```

は、$`\mathrm{Lens}(V,0)`$ の自己射を定める。実際、

```math
gh=g,\qquad
h(p((v,r),w))=(w,0)=p(h(v,r),w),\qquad h^2=h.
\qquad\text{(6.45)}
```

読取りと更新を保ったまま、第二成分の区別を忘れている。
固定点の状態集合 $`C_0=V\times\{0\}`$ は更新について閉じており、同じ式でlensになる。
$`C\to C_0`$ を $`h`$、逆向きの写像を包含とし、viewではどちらも恒等を使うと、
Lensの圏内でこの冪等射が分裂する。

従って、定理6.12をLensの圏へ適用した像は、この例では実際のlens $`C_0\to V`$ として表せる。
読取りと更新だけを使う処理はその上で続けられ、元の第二成分を求める処理には元の状態が必要となる。
ここで分裂させたのは状態写像を持つLensの圏の射である。
定理6.8で扱ったcoreの正規化では、全対象についてのreadingを持つcoreとその射が中間対象の条件であった。
同じ冪等射の議論でも、像をどの圏で実現するかによって結論が変わる。

**命題6.31（実行を保つプロトコルの像）.**
定義1.36の経路の圏 $`𝒞_Q`$ と観測先 $`O`$ を固定し、実現
$`F:𝒞_Q\to{𝐒𝐞𝐭}`$ と観測 $`o_F:F\Rightarrow O`$ を取る。
各頂点の状態集合は有限とする。
意味保存adapter $`n:F\Rightarrow F`$ が $`n^2=n`$ を満たすとする。
特に、全ての実行との自然性と、観測の保存 $`o_Fn=o_F`$ を仮定している。
各頂点で

```math
F_n(x)=\{s\in F(x)\mid n_x(s)=s\}
\qquad\text{(6.46)}
```

と置くと、実行と観測を制限して、同じプロトコルの実現 $`(F_n,o_{F_n})`$ を得る。
写像 $`r_x(s)=n_x(s)`$ と包含 $`i_x`$ は、実行と観測を保つadapterとなり、

```math
ri=1_{F_n},\qquad ir=n.
\qquad\text{(6.47)}
```

**証明.**
実行 $`a:x\to y`$ と固定点 $`s\in F_n(x)`$ に対して、自然性より

```math
n_y(F(a)(s))=F(a)(n_x(s))=F(a)(s)
\qquad\text{(6.48)}
```

となるので、実行後も固定点に属する。
恒等と合成は $`F`$ の関手則を制限すればよい。
$`r`$ の自然性は $`n`$ の自然性であり、$`i`$ の自然性は制限の定義による。
観測を $`o_{F_n}=o_Fi`$ とすれば、$`o_{F_n}r=o_Fn=o_F`$ なので $`r`$ も観測を保つ。
各固定点集合は元の有限集合の部分集合なので、有限性も保たれる。
式(6.47)は固定点の定義と冪等性から従う。□

各頂点で冪等な状態写像があるだけでは、式(6.48)は得られない。
たとえば一頂点・一操作で宣言関係のないプロトコルを二状態、定値の観測で実現し、操作を0と1の交換、
正規化を0への定値写像とすると、固定点0からの実行は1へ出てしまう。
この場合は、状態の正規化と操作が可換でない。

Lensの式(6.45)とプロトコルの式(6.48)は、正規化後に残した情報だけで操作を続けられる条件を示している。
意味保存の同型 $`\alpha`$ と、このような冪等adapter $`d`$ があれば、
定理6.12の $`d\alpha`$ は両端の像を同型に対応づける。
第1章で操作の名前と作用を分けて保持した理由もここに現れる。
状態やconfigurationへの作用の一致に加えて、選んだoperationの対応も確かめることで、
正規化がどの意味を保つかを明確にできる。

## 本章のまとめ

Configurationごとに選択表現を取る写像は冪等であり、
その固定点とconfigurationは一対一に対応する。
正規化で変わらない読み取りは、configurationを通って一意に因子化する。
さらに操作・残差・invariant・signatureの保存条件を満たすとき、
この写像はcoreと完全幾何の冪等な自己射になる。

第5章で生成した比較は、可逆な標準比較と、この正規化因子の合成であった。
元の圏で可逆であるための必要十分条件は、正規化因子が恒等であることである。
正規化が選ばれた場合にも、同じ比較射は冪等完備化における像の間の同型を与える。
Coreへの射影は、その像と比較を端点同型の下で対応づける。

正規化後の対象と射は一つの圏をなし、元の変更からの充満な正規化関手が得られる。
一方、元の変更と正規化の順序を交換するには、operation自身の対応が必要であった。
対象やconfigurationへの作用が一致していても、操作の追加情報が違えば順序は交換できない。

冒頭の設計レビューでは、共通の設計モデルに残す操作・依存関係・Lawを先に定め、
それらを保つ標準化を選ぶ。
注文・在庫サービスの二つの分割案が、取消要求、在庫予約の解除、取消完了という
同じ流れと条件を保つと確認できても、各操作をどのクラスに置いたかまで同じとは限らない。
さらに、元の表現に応じて操作の対応を変える処理があるなら、
標準化の前後でその処理を移動できるかを、操作の式として確かめる必要がある。
Lensでは更新、プロトコルでは実行が残した状態の中に閉じることが、その具体的な確認になる。

次章では、ここで構成した比較の圏を使い、一つの比較を保つ変更を分類する。
正規化後には同じに見える変更を、元の対象ではどこまで区別できるかが次の問いとなる。
