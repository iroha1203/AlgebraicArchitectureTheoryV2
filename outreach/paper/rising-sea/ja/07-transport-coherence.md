# 第4章 輸送と合成の整合性

## 本章の概要

本章の問いは、**readingの変更に沿って構造を運び、その変更を続けて行ったときに、
同じ結果へ整合的に到達できる条件は何か**である。
第1章では、抽出・core・幾何の三段に対象と射を定めた。
本章では、抽出の変更と変更前の対象から、変更後のcoreと幾何を構成する。

たとえば、注文APIの項目名やデータ形式を整理するリファクタリングを考える。
変更後も同じ注文を読み書きでき、「合計金額は明細の合計と一致する」といった条件を保ちたい。
本章でいう輸送は、データの対応に加え、操作や条件も変更先へ引き継ぐ構成である。

さらに、旧版から中間版を経て新版へ移す経路と、旧版から新版へ直接移す経路があるなら、
同じ注文からは、どちらの経路でも同じ結果を得たい。
ところが、各変換を別々のチームが実装すると、一方の経路だけで配送先と請求先の対応が
入れ替わる、といった食い違いが起こりうる。
各変換を元に戻せても、二つの経路の結果が一致するとは限らないのである。

前半では、輸送を「その先のどの変更も一意に分解できる」という普遍性から特徴づける。
この一意性により、単位と合成の標準比較が整合する。
後半では、別に指定された比較と標準比較の差を自己同型として表し、
辺の選び直しでその差を消せることと、すべての比較図式を同時に可換にできることの同値を示す。

| 問い | 構成 | 得られるもの |
| --- | --- | --- |
| 抽出の変更から何を運べるか | Atomの全単射による再添字づけ | coreの輸送と一意な因子分解 |
| 被覆や係数も運べるか | 被覆要件の像、重なりと局所データの比較 | 幾何の輸送と成立条件 |
| 続けて運ぶとどうなるか | 普遍性から作る合成比較 | 単位・三重合成・段間の整合性 |
| 指定した比較の食い違いを消せるか | 辺の再選択と非可換なdefect | 整合する再選択の存在との同値 |
| 各段の整合性をまとめられるか | coreへの射影とその核 | 持ち上げと同じ辺の選択を用いた判定 |
| 操作の意味をどう保つか | lensとプロトコルの可換図式 | 読取り・更新・名前付き実行の同時保存 |

第3章の診断は、Law値から作る複体とその類を比較した。
本章の輸送は、対象形成・操作・方程式・局所幾何をまとめて比較する。
両者の共通点は、同じ値や同型な対象があると述べることではなく、
入力から作った実際の比較写像を調べる点にある。

## 4.1 輸送を一意な因子分解で特徴づける

第1章の射影を

```math
E_{\mathrm{geom}}\xrightarrow{p}E_{\mathrm{core}}
\xrightarrow{q}B
\qquad\text{(4.1)}
```

と書く。底の対象は抽出doctrineと選択sourceの組であり、
底の射は定義1.27のexactな変更である。
Atomの語彙は固定する。

**定義4.1（強いopcartesian射）.**
関手 $`r:E\to B`$ と射 $`\eta:X\to X'`$ を取り、
$`r(\eta)=\sigma:b\to b'`$ とする。
任意の対象 $`Y`$、底の射 $`\tau:b'\to r(Y)`$、射 $`h:X\to Y`$ について、
$`r(h)=\tau\sigma`$ ならば

```math
\exists!\,k:X'\longrightarrow Y,\qquad
r(k)=\tau,\quad k\eta=h
\qquad\text{(4.2)}
```

となるとき、$`\eta`$ を $`r`$ に関する強いopcartesian射と呼ぶ。
$`r(k)=\mathrm{id}_{b'}`$ のように底が恒等射となる射をvertical射と呼ぶ。

式(4.2)は、底の変更 $`\sigma`$ を先に済ませることで、
その先の変更 $`h`$ を残りの射 $`k`$ へ一意に分けられることを表す。
ここで $`\tau`$ は任意であり、その後も底が変わる場合を含む。
これは強いcartesian射の双対である
（[Stacks, Tag 02XJ, 定義4.33.1](https://stacks.math.columbia.edu/tag/02XJ)）。

**補題4.2（輸送の一意性と合成）.**
同じ対象 $`X`$ から同じ底の射 $`\sigma`$ を持ち上げる
強いopcartesian射 $`\eta:X\to X'`$、$`\eta':X\to X''`$ があれば、

```math
c:X'\xrightarrow{\sim}X'',\qquad
r(c)=\mathrm{id},\quad c\eta=\eta'
\qquad\text{(4.3)}
```

を満たす同型が一意に存在する。
また、恒等射は強いopcartesian射であり、そのような射の合成も強いopcartesian射である。

**証明.**
式(4.2)を底の恒等射に適用し、$`c`$ と逆向きの射 $`d`$ を作る。
$`dc\eta=\eta`$ と $`cd\eta'=\eta'`$ に一意性を適用すると、
$`dc=\mathrm{id}`$、$`cd=\mathrm{id}`$ となる。
合成については、$`X\xrightarrow{\eta}X'\xrightarrow{\zeta}X''`$ の先への射を、
まず $`\eta`$、次に $`\zeta`$ で因子分解する。
二回の一意性が合成に対する一意性を与える。恒等射の場合は $`k=h`$ である。□

## 4.2 Exactな変更に沿ってcoreを構成する

輸送先のcoreを得るために、Atomの名前を変更後の名前で読み直す。
入力をいったん元の名前へ戻し、元の構成を使い、出力を新しい名前へ送る。
この手順は、操作や方程式にも共通する。

**構成4.3（Atomの再添字づけ）.**
底のexact射を $`\sigma=(f,e):(D,s)\to(D',s')`$ とする。
$`e`$ はAtomの全単射であり、$`s'=f(s)`$ である。
族とconfigurationには第1章の直像 $`e_*`$ を使う。
対象には

```math
T_e(A)=(e_*C_A,S_A,Q_A)
\qquad\text{(4.4)}
```

を定める。構造データと観測される値は保ち、configurationを運ぶ。
$`T_{e^{-1}}`$ は $`T_e`$ の逆である。
configurationの射のAtom写像 $`d`$ は $`ede^{-1}`$ へ運ぶ。

core reading $`P`$ に対し、変更後のreadingを次で定める。

```math
\begin{aligned}
\mathrm{Comp}^{\sigma}(F)
 &=e_*\mathrm{Comp}_P(e_*^{-1}F),\\
\mathrm{Form}^{\sigma}(C)
 &=T_e\mathrm{Form}_P(e_*^{-1}C),\\
\mathrm{Op}^{\sigma}(A,B)
 &=\mathrm{Op}_P(T_{e^{-1}}A,T_{e^{-1}}B).
\end{aligned}
\qquad\text{(4.5)}
```

operationの名前はそのまま保持し、configurationへの作用を共役する。
invariantとsignatureの評価は $`T_{e^{-1}}`$ との合成で定め、
添字・値域・選択軸は保持する。

文脈 $`W`$ のsupport・軸・observableの集合も保持する。
supportがAtom $`a'`$ を読む条件を、元のsupportが $`e^{-1}(a')`$ を読む条件とする。
これにより、文脈圏の同値 $`\theta_e:𝒞_P\simeq 𝒞^\sigma`$ を得る。
逆向きの再添字づけを $`\bar\theta_e`$ と書く。
方程式添字・役割を保ち、

```math
\begin{aligned}
O^\sigma(W')&=O_P(\bar\theta_eW'),\\
\nu^\sigma_{W',i,a'}&=\nu_{P,\bar\theta_eW',i,e^{-1}(a')},\\
\varepsilon^\sigma_{W',A',i,a'}
 &=\varepsilon_{P,\bar\theta_eW',T_{e^{-1}}A',i,e^{-1}(a')}
\end{aligned}
\qquad\text{(4.6)}
```

と定める。制限写像も $`\bar\theta_e`$ に沿って再添字づけする。
detector codeでは、queryに現れる各Atomへ $`e`$ を作用させる。
正負の符号、論理演算、operation名は変えない。

**命題4.4（輸送先のcoreと標準射）.**
構成4.3は、底 $`(D',s')`$ 上のcore $`\sigma_!P`$ と、
底の射 $`\sigma`$ 上のcoreの射
$`\eta_{\sigma,P}:P\to\sigma_!P`$ を与える。
その抽出族、基点、生成対象族は

```math
F_{\sigma_!P}=e_*F_P,\qquad
A_{\sigma_!P}=T_eA_P,\qquad
\mathrm{Obj}_{\sigma_!P}=T_e(\mathrm{Obj}_P)
\qquad\text{(4.7)}
```

を満たす。

**証明.**
抽出の保存と反映、$`e`$ の全単射性から最初の等式を得る。
したがって抽出族は有限であり、式(4.5)を適用できる。
対象形成の式を続けて使うと基点の等式が得られる。
operationの有限列は $`T_e`$ と $`T_{e^{-1}}`$ で互いに移るため、
定理1.18から生成対象族の等式が従う。

標準射の対象写像は $`T_e`$、operation写像は式(4.5)の対応とする。
configurationの可換平方は $`(ede^{-1})e=ed`$ である。
式(4.6)は座標と残差を保ち、制限との可換性も元の可換性から従う。
queryの一致は正負の両符号で保存・反映されるので、
detectorの受理と健全性も運ばれる。
invariant・signatureの条件は逆写像との合成から得られる。
以上で定義1.28のすべての条件を満たす。□

**定理4.5（Core輸送の普遍性）.**
$`\eta_{\sigma,P}`$ は $`q:E_{\mathrm{core}}\to B`$ に関して
強いopcartesian射である。

**証明.**
$`q(h)=\tau\sigma`$ となる $`h:P\to R`$ を取る。
$`\sigma_!P`$ の各データを元の名前へ戻してから $`h`$ を適用し、因子 $`k`$ を作る。
たとえば、その対象写像は

```math
H_k=H_hT_{e^{-1}}
\qquad\text{(4.8)}
```

であり、operation写像も式(4.5)の対応で元のoperationへ戻してから $`\Phi_h`$ を適用する。
方程式の比較は $`\bar\theta_e`$ に沿って再添字づけし、
座標・残差・detectorのAtomには $`e^{-1}`$ を代入する。
invariant添字、signature軸と値域の写像は、$`h`$ のものを使う。
底の射には $`\tau`$ を使う。

式(4.5)–(4.6)にこれらを代入すると、$`h`$ の保存等式がそのまま
$`k`$ の保存等式になる。よって $`k`$ はcoreの射である。
$`T_{e^{-1}}T_e=\mathrm{id}`$ と各添字の逆対応から $`k\eta_{\sigma,P}=h`$ を得る。

逆にこの合成等式を満たす射の対象写像は、$`T_e`$ の全射性により式(4.8)に決まる。
operation、文脈、方程式の座標、invariantとsignatureの各成分も、
標準射の可逆な対応を通して一意に決まる。
底は $`\tau`$ に固定されているので、射全体が一意である。□

source写像 $`f`$ の全単射性は、この構成には要らない。
必要なのは、指定されたAtom対応で抽出が保存・反映されることである。

**例4.6（前向きの抽出保存だけでは足りない）.**
Atomを $`\{a,b,c\}`$ とし、sourceは一つ、正規化は恒等とする。
変更前の抽出族を $`\{a,b\}`$、変更後を $`\{a,b,c\}`$ とし、
Atomの対応は $`a,b`$ を交換して $`c`$ を固定する全単射とする。
抽出は前向きに保存されるが、$`c`$ について反映が失敗する。
変更後の族は元の族の直像ではないため、式(4.7)を満たすexactな輸送にはならない。

追加されたAtomを使う対象形成には、その追加部分についてのデータが必要になる。
その役割は次の構成で明示できる。

**構成4.7（抽出を増やす変更への追加データ）.**
抽出を前向きに保つ変更 $`(f,e)`$ を取り、$`e`$ は全単射とする。
変更後の抽出族 $`F'`$ が有限であることを、データとして与える。
式(4.5)の対象形成で $`F'`$ から作る基点を $`A'`$ とし、
次のデータを追加する。

1. 輸送したoperation readingにおける実際のoperation $`A'\to T_eA_P`$。
2. $`A'`$ の文脈上の方程式系と、元の方程式添字との全単射。
3. 元のdetector codeを $`e`$ で運んだcodeが、その方程式系に対して健全であること。

これらから変更後のcoreを構成できる。
また、元の生成対象の像は変更後の生成対象に含まれる。
実際、追加したoperationに元の有限operation列の像を続ければよい。
元の対象の像では、queryの一致とdetectorの受理が保存される。
これは、Atomの再添字づけに対するqueryとcodeの評価の可換性から従う。
operation、invariant、signatureも対応する写像で保存される。
この構成が与えるのは、以上の前向きの保存を備えた比較である。

## 4.3 Coreの輸送を幾何へ持ち上げる

coreを運んだ後には、どの局所データを一緒に見るかという選択を運ぶ。
被覆要件にはその像を、係数と環の表示には再添字づけを使う。
文脈の内部にあるsupport・軸・observableは、読めるものと制限写像も含めて比較する。

**構成4.8（幾何の成分の輸送）.**
幾何 $`G`$ とcoreの射 $`h:pG\to P'`$ を取る。
その文脈同値を $`\theta`$、指定した準逆を $`\bar\theta`$ とする。
変更後の被覆要件を、定義1.30の各写像に沿う存在量化による像で定める。
たとえば要求されるsupportと、その可視性は

```math
\begin{aligned}
\mathrm{Req}'(a')
 &\Longleftrightarrow \exists a,\ \mathrm{Req}(a)\land e(a)=a',\\
\mathrm{Vis}'(W',a')
 &\Longleftrightarrow
 \exists W,a,\ \mathrm{Vis}(W,a)\land\theta W=W'\land e(a)=a'
\end{aligned}
\qquad\text{(4.9)}
```

である。方程式座標、witness、軸、二文脈間の可視性も同じ規則で運ぶ。
重なりは

```math
\mathrm{Ov}'(U'\to W'\leftarrow V')
=\theta\bigl(\mathrm{Ov}(\bar\theta U'\to
\bar\theta W'\leftarrow\bar\theta V')\bigr)
\qquad\text{(4.10)}
```

とし、射影は余単位を用いて $`U',V'`$ へ写す。
重なりの普遍性は $`\theta,\bar\theta`$ の同値から従う。
係数環 $`k`$ は保持し、raw systemは $`ℬ'=\bar\theta^*ℬ`$ とする。
座標型、局所データ型、関係多項式と制限をすべて再添字づけする。
この幾何を $`h_*G`$ と書く。

**定義4.9（局所実現の輸送条件）.**
$`H_{\mathrm{geom}}(G,h)`$ を、各文脈での三つの比較写像

```math
\begin{aligned}
s_W&:\mathrm{Supp}(W)\to\mathrm{Supp}'(\theta W),\\
a_W&:\mathrm{Ax}(W)\to\mathrm{Ax}'(\theta W),\\
o_W&:\mathrm{Obs}(W)\to\mathrm{Obs}'(\theta W)
\end{aligned}
\qquad\text{(4.11)}
```

の族であって、定義1.30の読める元の保存と式(1.14)の自然性を満たすデータとする。
比較先の三つの集合と読みは、変更先coreの文脈が持つものを使う。

**命題4.10（幾何の射の存在条件）.**
$`H_{\mathrm{geom}}(G,h)`$ のデータが存在することと、
$`h`$ の上に幾何の射 $`G\to h_*G`$ が存在することは同値である。
また、$`h`$ 上の任意の幾何の射から $`H_{\mathrm{geom}}(G,h)`$ が得られる。

**証明.**
式(4.9)は被覆要件の前向きの保存を与える。
式(4.10)は重なりの比較を与え、係数には恒等写像、
raw systemには再添字づけの等式を使う。
残る比較は式(4.11)とその保存・自然性であり、これが
$`H_{\mathrm{geom}}(G,h)`$ のデータである。
逆向きには幾何の射からこの三比較族を取り出せばよい。□

**定理4.11（標準的な幾何輸送と普遍性）.**
coreの標準射 $`h=\eta_{\sigma,pG}`$ には
$`H_{\mathrm{geom}}(G,h)`$ が構成できる。
得られる幾何と射を
$`\sigma_!^{\mathrm g}G`$、$`\widetilde\eta_{\sigma,G}:G\to\sigma_!^{\mathrm g}G`$
と書く。この射は $`p:E_{\mathrm{geom}}\to E_{\mathrm{core}}`$ に関して
強いopcartesian射であり、

```math
p(\sigma_!^{\mathrm g}G)=\sigma_!(pG),\qquad
p(\widetilde\eta_{\sigma,G})=\eta_{\sigma,pG}
\qquad\text{(4.12)}
```

を満たす。

**証明.**
構成4.3の文脈輸送では、support・軸・observableの集合を保持した。
その恒等対応を式(4.11)に使う。supportの読みは $`e^{-1}`$ で定めたので
Atomを $`e`$ で写す条件を満たし、三つの自然性も元の構造写像から従う。
よって命題4.10が幾何の射を与える。

普遍性を示すため、任意のcoreの射
$`t:\sigma_!(pG)\to pK`$ と、
$`p(F)=t\eta_{\sigma,pG}`$ となる幾何の射 $`F:G\to K`$ を取る。
各文脈を $`\bar\theta_e`$ で戻し、標準射の三つの可逆な対応を逆にしてから
$`F`$ の比較写像を適用する。
これを因子のsupport・軸・observableの比較とする。
係数写像は $`F`$ の係数写像に等しくする。

輸送先の各被覆要件には、式(4.9)による元の要件の証拠がある。
その証拠へ $`F`$ の保存則を適用すれば、因子の保存則が得られる。
重なりの比較は二つの圏同値を合成して作り、
raw systemの等式は再添字づけと係数変更の可換性から得る。
したがって底が $`t`$ である幾何の射ができ、その標準射との合成は $`F`$ になる。

標準射の三比較は全単射であり、係数写像は恒等なので、因子の各写像は一意である。
文脈圏内の重なりの比較は、前順序圏の平行射の一意性によって決まる。
これで式(4.2)の存在と一意性を満たす。式(4.12)は構成から従う。□

一般のcoreの射に対しては命題4.10が存在条件を与え、
標準core輸送に対しては、その条件と普遍性の両方が構成されたことになる。

## 4.4 輸送の単位・合成・射影

輸送の普遍性は、対象の移し方だけでなく、比較射の移し方も決める。
同じ底にある対象の間の射を運ぶことで、fiber間の関手が得られる。

**補題4.12（塔における普遍性）.**
射 $`v:G\to G'`$ が $`p`$ に関して強いopcartesian射であり、
$`p(v)`$ が $`q`$ に関して強いopcartesian射なら、
$`v`$ は $`qp`$ に関して強いopcartesian射である。

**証明.**
$`qp`$ 上の因子分解問題をまず $`q`$ の普遍性でcoreの因子に分け、
次にそのcoreの因子を底の射として $`p`$ の普遍性を使う。
二段の存在と一意性が求める存在と一意性を与える。□

**構成4.13（Fiber間の輸送関手）.**
関手 $`r:E\to B`$ のfiber $`E_b`$ は、
$`r(X)=b`$ となる対象と、その間のvertical射からなる圏である。
各 $`\sigma:b\to b'`$ と $`X\in E_b`$ に強いopcartesianなlift
$`\eta_{\sigma,X}:X\to T_\sigma X`$ を選ぶ。
vertical射 $`v:X\to Y`$ の像を、唯一のvertical射

```math
T_\sigma(v):T_\sigma X\longrightarrow T_\sigma Y,\qquad
T_\sigma(v)\eta_{\sigma,X}=\eta_{\sigma,Y}v
\qquad\text{(4.13)}
```

とする。右辺は底 $`\sigma`$ 上にあるため、この射は存在する。
恒等射と二射の合成も同じ等式を満たすので、一意性から
$`T_\sigma:E_b\to E_{b'}`$ は関手である。
定理4.5・4.11と補題4.12により、この構成をcoreと、底を $`B`$ とした幾何に適用できる。

**構成4.14（合成比較と単位比較）.**
$`b\xrightarrow{\sigma}b'\xrightarrow{\tau}b''`$ に対し、
補題4.2を二度のliftと一度のliftに適用すると、同型

```math
\begin{aligned}
c_{\tau,\sigma,X}&:T_\tau T_\sigma X\xrightarrow{\sim}T_{\tau\sigma}X,\\
c_{\tau,\sigma,X}\eta_{\tau,T_\sigma X}\eta_{\sigma,X}
 &=\eta_{\tau\sigma,X}
\end{aligned}
\qquad\text{(4.14)}
```

が得られる。恒等射についても同様に

```math
\epsilon_X:T_{\mathrm{id}}X\xrightarrow{\sim}X,\qquad
\epsilon_X\eta_{\mathrm{id},X}=\mathrm{id}_X
\qquad\text{(4.15)}
```

を得る。これらをそれぞれcompositor、unitorと呼ぶ。

**定理4.15（合成比較の整合性）.**
$`c_{\tau,\sigma}`$ と $`\epsilon`$ は自然同型である。
さらに合成可能な三射 $`\sigma,\tau,\rho`$ について

```math
\begin{aligned}
c_{\rho,\tau\sigma,X}\,T_\rho(c_{\tau,\sigma,X})
 &=c_{\rho\tau,\sigma,X}\,c_{\rho,\tau,T_\sigma X},\\
c_{\mathrm{id},\sigma,X}&=\epsilon_{T_\sigma X},\\
c_{\sigma,\mathrm{id},X}&=T_\sigma(\epsilon_X)
\end{aligned}
\qquad\text{(4.16)}
```

が成立する。合成した底の射の結合と単位は、圏 $`B`$ の等式で同一視する。
fiber・輸送関手・これらの自然同型を合わせた構造を擬関手と呼ぶ。

**証明.**
$`c`$ の自然性の二経路を、出発点からの二度のliftへ合成する。
式(4.13)–(4.14)により、どちらも $`\eta_{\tau\sigma,Y}v`$ になる。
二度のliftは強いopcartesian射なので、二経路は等しい。
$`\epsilon`$ の自然性も同じ議論による。

式(4.16)の第一式の両辺は、$`T_\rho T_\tau T_\sigma X`$ から
$`T_{\rho\tau\sigma}X`$ へのvertical射である。
三度のliftへ合成すると、どちらも $`\eta_{\rho\tau\sigma,X}`$ になる。
再び一意性で等しい。単位の二式も、対応する二度のliftへ合成して確認できる。□

この標準的な構成は、cartesianな場合の
[Stacks, Tag 02XJ, 補題4.33.2・4.33.7](https://stacks.math.columbia.edu/tag/02XJ)
の双対である。整合性の理由は、比較を決めた因子分解の一意性にある。

**定理4.16（Coreへの射影との整合性）.**
幾何のfiberからcoreのfiberへの射影を $`p_b`$ とする。
幾何の輸送とcoreの輸送を、それぞれ $`T^{\mathrm g}_\sigma`$、$`T^{\mathrm c}_\sigma`$ と書く。
自然同型

```math
\chi_\sigma:p_{b'}T^{\mathrm g}_\sigma
\xRightarrow{\sim}T^{\mathrm c}_\sigma p_b
\qquad\text{(4.17)}
```

があり、合成と単位について

```math
\begin{aligned}
\chi_{\tau\sigma,G}\,p(c^{\mathrm g}_{\tau,\sigma,G})
 &=
c^{\mathrm c}_{\tau,\sigma,pG}\,
T^{\mathrm c}_\tau(\chi_{\sigma,G})\,
\chi_{\tau,T^{\mathrm g}_\sigma G},\\
p(\epsilon^{\mathrm g}_G)
 &=\epsilon^{\mathrm c}_{pG}\,\chi_{\mathrm{id},G}
\end{aligned}
\qquad\text{(4.18)}
```

を満たす。

**証明.**
$`p(\widetilde\eta_{\sigma,G})`$ と $`\eta_{\sigma,pG}`$ は、
同じ対象から同じ底の射を持ち上げる強いopcartesian射である。
それらを結ぶ一意な比較が $`\chi_{\sigma,G}`$ である。
標準構成では式(4.12)により両liftが対応する。
verticalな幾何の射を射影した後にも式(4.13)が成立するので、比較は自然である。
式(4.18)の両経路も、元のcoreからのliftへ合成すると同じ射になる。
一意性によって二式を得る。□

したがって、幾何を運んでからcoreを読む経路と、
coreを読んでから運ぶ経路は、対象・射・合成比較を含めて整合する。

## 4.5 指定した比較と標準比較の差

標準比較は、一意性によって整合した。
しかし、実際の比較では、状態名の対応や局所データの対応を別に指定することがある。
その対応が標準比較とどれだけ違うかを測るには、両者を同じ対象の自己同型として読む。

以後、$`r:E\to B`$ は関手とし、必要な辺に強いopcartesian射を選ぶ。
coreには $`r=q`$、幾何全体には $`r=qp`$ を使える。

**定義4.17（有限な比較データ）.**
有限な有向グラフの各頂点 $`i`$ に対象 $`X_i`$ を置き、
各辺 $`e:i\to j`$ に底の射 $`\sigma_e:r(X_i)\to r(X_j)`$ と、その上の強いopcartesian射
$`L_e:X_i\to X_j`$ を置く。
道 $`\pi`$ の合成を $`L_\pi`$ と書き、空の道の合成は恒等射とする。

さらに有限個の面 $`f`$ を指定する。
面は、同じ始点と終点を持つ二つの道 $`\ell_f,\rho_f:i\to j`$ であって、
底での合成が等しいものとする。
各面には、終点のfiber自己同型
$`u_f\in\mathrm{Aut}_r(X_j)`$ を指定する。ここで

```math
\mathrm{Aut}_r(X)
=\{a:X\xrightarrow{\sim}X\mid r(a)=\mathrm{id}_{r(X)}\}
\qquad\text{(4.19)}
```

である。$`u_f`$ は、その面で採用したい比較を表す。
この段階では、$`u_fL_{\ell_f}=L_{\rho_f}`$ を仮定しない。

**構成4.18（標準比較とraw defect）.**
補題4.2から、各面に一意なfiber自己同型

```math
\phi_fL_{\ell_f}=L_{\rho_f},\qquad
\phi_f\in\mathrm{Aut}_r(X_j)
\qquad\text{(4.20)}
```

が存在する。指定した比較との差を

```math
\delta_f=u_f\phi_f^{-1}
\qquad\text{(4.21)}
```

と定め、raw defectと呼ぶ。
したがって $`\delta_f=1`$ は、指定比較が標準比較に一致することを意味する。
積は射の合成であり、右側の因子から作用する。

自己同型群が非可換なら、比較の順序によって結果が変わる。
そのため、食い違いは一般に数値の差や可換群の元としては扱えない。
式(4.21)は、比較の順序も含む差である。

## 4.6 辺を選び直して食い違いを消す

比較を固定したまま、各辺で採用するliftを変えることを考える。
同じ始点と終点を持つ同じ底の射のliftは、補題4.2により、
終点のfiber自己同型を合成することで互いに移る。

**定義4.19（辺の再選択）.**
各辺 $`e:i\to j`$ に
$`a_e\in\mathrm{Aut}_r(X_j)`$ を選び、

```math
L_e^a=a_eL_e,\qquad
𝒜=\prod_{e:i\to j}\mathrm{Aut}_r(X_j)
\qquad\text{(4.22)}
```

とする。$`a=(a_e)_e`$ を辺の再選択と呼ぶ。
vertical同型 $`a_e`$ は、式(4.2)の因子が $`k=ha_e^{-1}`$ と一意に定まるので、
強いopcartesian射である。補題4.2から、その合成 $`a_eL_e`$ も強いopcartesian射となる。
各道の合成 $`L_\pi^a`$ に対して、式(4.20)–(4.21)を同じように定め、
$`\phi_f(a)`$、$`\delta_f(a)`$ と書く。
指定比較 $`u_f`$ は固定する。

**例4.20（独立な二辺の比較は一方に吸収できる）.**
群を一対象圏と見なし、底を終対象圏とする。
すべての射は可逆であり、強いopcartesian射である。
群の積には、右から作用する合成を使う。
二本の平行な辺 $`x,y`$ と、一つの面 $`x\Rightarrow y`$ を取る。
元のliftをともに恒等とし、指定比較を任意の群元 $`u`$ とする。
辺の選択を $`a_x,a_y`$ とすれば

```math
\phi(a)=a_ya_x^{-1},\qquad
\delta(a)=u\,a_xa_y^{-1}
\qquad\text{(4.23)}
```

である。$`a_x=1`$、$`a_y=u`$ とすればdefectは消える。
この二辺は独立に選び直せるため、一方の辺に指定比較を吸収できる。

一般の比較図式では、各辺の選択が複数の道と面に作用する。
そこで、道の終点に生じる変化を調べ、それが各面の比較をどう変えるかを求める。

**補題4.21（道の終点での変化）.**
再選択 $`a`$ の後に $`b`$ を行うと、各道 $`\pi:i\to j`$ に一意な自己同型

```math
A_\pi(a,b)L_\pi^a=L_\pi^{ba}
\qquad\text{(4.24)}
```

がある。ここで $`(ba)_e=b_ea_e`$ である。
この自己同型は

```math
\begin{aligned}
A_\pi(a,1)&=1,\\
A_\pi(ba,c)A_\pi(a,b)&=A_\pi(a,cb)
\end{aligned}
\qquad\text{(4.25)}
```

を満たし、各面について

```math
\begin{aligned}
\phi_f(ba)
 &=A_{\rho_f}(a,b)\phi_f(a)A_{\ell_f}(a,b)^{-1},\\
\delta_f(ba)
 &=\bigl(u_fA_{\ell_f}(a,b)u_f^{-1}\bigr)
   \delta_f(a)A_{\rho_f}(a,b)^{-1}
\end{aligned}
\qquad\text{(4.26)}
```

となる。

**証明.**
式(4.24)の存在と一意性は、道の合成が強いopcartesian射であることから従う。
式(4.25)の両辺を $`L_\pi^a`$ に合成すると同じ射になるため、再び一意性を使える。
式(4.26)の第一式は、
$`\phi_f(ba)A_{\ell_f}(a,b)L_{\ell_f}^a=A_{\rho_f}(a,b)\phi_f(a)L_{\ell_f}^a`$
に一意性を適用して得る。
その逆元を式(4.21)へ代入すれば第二式になる。□

**命題4.22（再選択の作用）.**
面の終点の自己同型の族を
$`𝒵=\prod_f\mathrm{Aut}_r(X_{\mathrm{end}(f)})`$ とする。
$`𝒜\times 𝒵`$ に

```math
\Gamma_b(a,z)=
\left(ba,\
\left(
u_fA_{\ell_f}(a,b)u_f^{-1}\,
z_f\,A_{\rho_f}(a,b)^{-1}
\right)_f\right)
\qquad\text{(4.27)}
```

で左作用が定まる。
特に、$`(1,\delta(1))`$ の軌道は
$`\{(a,\delta(a))\mid a\in 𝒜\}`$ である。

**証明.**
式(4.25)を代入すると、$`\Gamma_1=\mathrm{id}`$ と
$`\Gamma_c\Gamma_b=\Gamma_{cb}`$ を得る。
軌道の表示は式(4.26)による。□

この作用では、現在の辺の選択 $`a`$ も記録する。
複数の辺を通る道では、終点の変化 $`A_\pi(a,b)`$ が現在の選択に依存するためである。

たとえば、一対象群圏から終対象圏への関手を取り、二本の辺の初期liftをともに恒等とする。
辺1、辺2の順に進む道を $`12`$ と書くと、

```math
\begin{aligned}
L_{12}^{a}&=a_2a_1,\\
L_{12}^{ba}&=b_2a_2b_1a_1,\\
A_{12}(a,b)&=L_{12}^{ba}(L_{12}^{a})^{-1}
=b_2a_2b_1a_2^{-1}.
\end{aligned}
```

最後の式には現在の選択 $`a_2`$ が残る。
非可換な群では、同じ $`b_1,b_2`$ による再選択でも、$`a_2`$ によって終点での変化が異なりうる。

**定理4.23（障害消滅と整合する選択）.**
命題4.22の軌道を、この有限比較データの障害クラスと呼ぶ。
軌道が $`𝒜\times\{1\}`$ と交わるとき、障害が消滅するという。
この消滅は、すべての面について同時に

```math
u_fL_{\ell_f}^a=L_{\rho_f}^a
\qquad\text{(4.28)}
```

となる辺の再選択 $`a`$ が存在することと同値である。

**証明.**
障害の消滅は $`\delta_f(a)=1`$ がすべての面で成立することに等しく、
式(4.21)より $`u_f=\phi_f(a)`$ と同値である。
この等式は式(4.28)を与える。
逆に式(4.28)が成り立てば、$`u_f`$ と $`\phi_f(a)`$ はともに
$`L_{\ell_f}^a`$ を $`L_{\rho_f}^a`$ へ写す。
強いopcartesian射の一意性から両者は等しい。□

## 4.7 面を貼り合わせるときの追加条件

一つの面の比較に続けて別の面の比較を行うと、道を書き換える経路ができる。
たとえば三つの道を比較するとき、直接の比較と、第三の道を経由する比較がある。
この二経路の一致も、別の条件として調べる必要がある。

**補題4.24（後続する道への自己同型の輸送）.**
辺の選択 $`a`$ を固定する。
道 $`\beta:j\to k`$ と $`v\in\mathrm{Aut}_r(X_j)`$ に対し、
一意な自己同型 $`\beta_*v`$ が

```math
(\beta_*v)L_\beta^a=L_\beta^av
\qquad\text{(4.29)}
```

を満たす。写像 $`\beta_*`$ は群準同型である。

**証明.**
強いopcartesian射 $`L_\beta^a`$ の普遍性を使う。
$`v^{-1}`$ から得られる射が逆射になる。
恒等射と積についても式(4.29)と一意性を使えばよい。□

**構成4.25（比較の貼り合わせ）.**
道 $`\alpha\ell_f\beta`$ を $`\alpha \rho_f\beta`$ へ書き換える一歩を考える。
道は左から右へ進むものとする。射の合成は右から作用するので、

```math
L_{\alpha\ell_f\beta}^{a}
=L_\beta^{a}L_{\ell_f}^{a}L_\alpha^{a}
```

である。
この一歩の指定比較を $`\beta_*u_f`$、
標準比較を $`\beta_*\phi_f(a)`$ とする。
逆向きの書き換えでは、それぞれの逆元を使う。

書き換えの列 $`P`$ に沿って、これらを順に合成したものを
$`U_P(a)`$、$`\Phi_P(a)`$ と書く。
始めの道を $`\pi`$、終わりの道を $`\rho`$ とすると

```math
\Phi_P(a)L_\pi^a=L_\rho^a,\qquad
D_P(a)=U_P(a)\Phi_P(a)^{-1}
\qquad\text{(4.30)}
```

となる。$`D_P(a)`$ を貼り合わせたraw defectと呼ぶ。
標準比較 $`\Phi_P(a)`$ は、始めと終わりの道から一意に決まる。

二つの書換えを続ける場合、各段の指定比較を $`u_1,u_2`$、
標準比較を $`\phi_1,\phi_2`$、defectを $`\delta_1,\delta_2`$ とすると

```math
\begin{aligned}
U_P\Phi_P^{-1}
 &=u_2u_1(\phi_2\phi_1)^{-1}\\
 &=(u_2\delta_1u_2^{-1})\delta_2.
\end{aligned}
\qquad\text{(4.31)}
```

後の比較が、先のdefectを共役する。
そのため、貼り合わせたdefectを各面のdefectの単純な積に置き換えることはできない。

**命題4.26（関係式の間の整合条件）.**
同じ道から同じ道へ至る二つの書き換え列 $`P,Q`$ の組をsyzygyと呼ぶ。
有限個のsyzygyを指定し、辺の選択 $`a`$ において

```math
U_P(a)=U_Q(a)
\qquad\text{(4.32)}
```

がそれぞれ成り立つとする。このとき
$`D_P(a)=D_Q(a)`$ が成立する。

**証明.**
$`\Phi_P(a)`$ と $`\Phi_Q(a)`$ は、同じ強いopcartesian射を
同じ射へ写すので等しい。その共通の逆元を式(4.32)の右から掛ける。□

raw defectは式(4.21)だけで定義できる。
指定したsyzygyに沿うcocycle条件 $`D_P(a)=D_Q(a)`$ を得るには、式(4.32)が必要になる。
式(4.32)は指定比較どうしの関係であり、各面のdefectの消滅を仮定していない。

**命題4.27（閉じた比較の障害）.**
任意のsyzygyについて、共通の標準比較を $`\Phi`$ と置くと

```math
D_Q^{-1}D_P
=\Phi\,(U_Q^{-1}U_P)\,\Phi^{-1}
\qquad\text{(4.33)}
```

である。特に左辺が恒等であることと、式(4.32)は同値である。

**証明.**
$`D_P=U_P\Phi^{-1}`$、$`D_Q=U_Q\Phi^{-1}`$ を代入すればよい。□

式(4.33)は、辺の選択を固定したとき、
指定した貼り合わせの不一致が共役を通して残ることを示す。
すべての面が式(4.28)を満たせば、すべての指定した貼り合わせは標準比較に一致する。
したがって、式(4.32)の失敗は、その辺の選択での全体整合性を妨げる。

## 4.8 消せる食い違いと消せない食い違い

例4.20では、独立な二辺の一方を選び直すことで、一つの面の比較を整えられた。
複数の面が辺を共有すると、各面を単独で整えられても、同じ選択で同時に整えられるとは限らない。
以下も群を一対象圏と見なし、底を終対象圏とする。

**例4.28（同じ二本の辺への異なる要求）.**
群を三点の置換群 $`S_3`$ とし、同じ二本の辺に二つの面を置く。
指定比較をそれぞれ $`s=(12)`$、$`t=(23)`$ とする。
両面の標準比較は同じ $`a_ya_x^{-1}`$ なので、整合性には

```math
a_ya_x^{-1}=s,\qquad a_ya_x^{-1}=t
\qquad\text{(4.34)}
```

が必要になる。$`s\ne t`$ なので、同時に満たす選択は存在しない。
各面は例4.20によって単独では整えられる。
二つの面を同じ辺の選択で整えることが、新しい条件なのである。

**例4.29（三つの比較と順序）.**
三本の平行な辺 $`x_0,x_1,x_2`$ を取り、元のliftをすべて恒等とする。
$`x_0\Rightarrow x_1`$ の比較を $`s`$、
$`x_1\Rightarrow x_2`$ の比較を $`t`$、
$`x_0\Rightarrow x_2`$ の比較を $`st`$ と指定する。
間接の比較は $`ts`$、直接の比較は $`st`$ である。
$`s=(12)`$、$`t=(23)`$ では、この二つは異なる。

実際、最初の二面が整合すれば
$`a_1=sa_0`$、$`a_2=ta_1=tsa_0`$ である。
第三の面は $`a_2=sta_0`$ を要求するため、三面は同時には整合しない。
対応するsyzygyには後続の道がなく、指定した二経路は辺の選択によらない。
式(4.33)の内部の不一致は

```math
(st)^{-1}ts=t^{-1}s^{-1}ts\ne1
\qquad\text{(4.35)}
```

であり、どの選択でも残る。
この例では、各対応が全単射であることに加えて、合成順序を揃える必要がある。

## 4.9 Coreと幾何の整合性を同じ選択で満たす

幾何の比較をcoreへ射影すると、coreの比較が得られる。
coreで見える食い違いを直した後には、幾何だけに残る食い違いを直したい。
この二段階をつなぐ鍵は、coreで選んだ変更を幾何へ持ち上げ、
その同じ選択を使って残りの条件を調べることである。

**定義4.30（射影とその核）.**
対象 $`G`$ と $`P=pG`$ に対し、

```math
\begin{aligned}
C_G&=\mathrm{Aut}_{qp}(G),&
B_P&=\mathrm{Aut}_q(P),\\
\pi_G:C_G&\longrightarrow B_P,&
\pi_G(a)&=p(a),\\
H_G&=\ker\pi_G=\mathrm{Aut}_p(G)
\end{aligned}
\qquad\text{(4.36)}
```

と置く。$`C_G`$ は抽出を固定する幾何の変更、$`B_P`$ は抽出を固定するcoreの変更、
$`H_G`$ はcore全体を固定する幾何の変更を表す。
$`\pi_G`$ は群準同型であり、$`H_G`$ は正規部分群である。

定義4.17の各頂点に $`G_i`$ を置き、幾何の辺 $`L_e`$ とその射影 $`p(L_e)`$ が、
それぞれ $`qp`$、$`q`$ に関して強いopcartesian射であるとする。
§4.4で構成した輸送はこの条件を満たす。
指定比較を $`u_f\in C_{G_j}`$ とし、coreの指定比較には $`p(u_f)`$ を使う。
幾何の標準比較を $`\phi_f`$、coreの標準比較を $`\bar\phi_f`$ と書く。

**命題4.31（Defectの射影）.**
任意の幾何の辺の再選択 $`c`$ に対し、

```math
p(\phi_f(c))=\bar\phi_f(p(c)),\qquad
p(\delta_f(c))=\bar\delta_f(p(c))
\qquad\text{(4.37)}
```

が成立する。

**証明.**
$`\phi_f(c)L_{\ell_f}^c=L_{\rho_f}^c`$ を射影する。
coreの道も強いopcartesian射なので、比較の一意性から第一式を得る。
第二式は、$`p`$ が合成と逆元を保つことによる。□

**定義4.32（辺ごとの持ち上げと整列）.**
coreの辺の再選択 $`a_e\in B_{P_j}`$ に対し、
$`\widetilde a_e\in C_{G_j}`$ で $`p(\widetilde a_e)=a_e`$ を満たすものを選ぶ。
この有限個の辺ごとの持ち上げをedge sectionと呼ぶ。
各面について、coreの道の合成が

```math
p(u_f)\,\bar L_{\ell_f}^{\,a}
=\bar L_{\rho_f}^{\,a}
\qquad\text{(4.38)}
```

を満たすとき、このsectionは整列しているという。
$`\bar L^{\,a}`$ は、射影した辺を $`a`$ で選び直した道である。

整列は、coreで見える全比較が、その辺の選択で整合するという条件である。
定義4.32のとおり、edge sectionは、coreの再選択とあわせて、
それを幾何の側で実現する持ち上げを与えるデータである。

**定理4.33（順序を保ったdefectの分解）.**
整列したedge sectionを取り、
再選択前の比較を $`\phi_f^0=\phi_f(1)`$、
選んだsectionでの比較を $`m_f=\phi_f(\widetilde a)`$ と書く。このとき

```math
p(m_f)=p(u_f)
\qquad\text{(4.39)}
```

であり、元のdefectは

```math
\underbrace{u_f(\phi_f^0)^{-1}}_{\delta_f}
=
\underbrace{u_fm_f^{-1}}_{\delta_f^{\mathrm{in}}}
\underbrace{m_f(\phi_f^0)^{-1}}_{\widetilde\delta_f^{\mathrm{out}}}
\qquad\text{(4.40)}
```

と分解される。ここで
$`\delta_f^{\mathrm{in}}\in H_{G_j}`$ であり、
$`p(\widetilde\delta_f^{\mathrm{out}})=\bar\delta_f(1)`$ である。

**証明.**
命題4.31により $`p(m_f)=\bar\phi_f(a)`$ である。
式(4.38)と標準比較の一意性から
$`\bar\phi_f(a)=p(u_f)`$ を得る。これが式(4.39)である。
よって $`p(u_fm_f^{-1})=1`$ となる。
式(4.40)は中央の $`m_f^{-1}m_f`$ を消去すれば確かめられる。
最後の主張は
$`p(m_f(\phi_f^0)^{-1})=p(u_f)\bar\phi_f(1)^{-1}`$ による。□

この分解では、まずcoreで見えるdefectを持ち上げた因子が作用し、
次にcoreには見えない因子が作用する。
一般には二つの因子の順序を入れ替えられない。

**定理4.34（同時消滅の条件）.**
整列したedge section $`\widetilde a`$ を固定する。
そのcoreの選択 $`a`$ の上に、すべての面で整合する幾何の辺の選択が存在することと、
核の元の族 $`h_e\in H_{G_j}`$ で

```math
u_f=\phi_f(h\widetilde a)\qquad\text{（すべての面 }f\text{）}
\qquad\text{(4.41)}
```

となるものが存在することは同値である。
したがって、幾何の障害が消滅することは、
整列したedge sectionを選べて、その選択に対して式(4.41)を満たせることと同値である。

**証明.**
$`h`$ が核に入るので $`p(h\widetilde a)=a`$ である。
式(4.41)と定理4.23により、$`h\widetilde a`$ は求める整合した選択になる。
逆に $`p(c)=a`$ となる整合した選択 $`c`$ があれば、
各辺で $`h_e=c_e\widetilde a_e^{-1}`$ と置く。
その射影は $`a_ea_e^{-1}=1`$ なので $`h_e\in H_{G_j}`$ であり、
$`c=h\widetilde a`$ から式(4.41)を得る。
最後の同値の順方向では、整合した幾何の選択そのものをedge sectionに使えばよい。□

ここでは、coreと幾何で同じ辺の選択を使い、すべての面を同時に調べる。
各段だけで整合する選択が見つかっても、その選択を次の段へ持ち上げられるかという問題は残る。

**例4.35（四つの軸と持ち上がらない解）.**
この違いを、群を一対象圏とする有限の塔で示す。
四つの添字 $`1,2,3,4`$ を軸と見なし、その置換群 $`S_4`$ をcoreの変更群とする。
幾何では四つの軸のうち
$`\{1,2\}`$ を選択する。その選択を保つ置換と、二値の追加成分から

```math
\begin{aligned}
K&=\{\gamma\in S_4\mid\gamma\{1,2\}=\{1,2\}\}\times C_2,\\
\pi:K&\longrightarrow S_4,\qquad(\gamma,z)\longmapsto\gamma
\end{aligned}
\qquad\text{(4.42)}
```

を作る。$`C_2=ℤ/2ℤ`$ は加法で書く。
核は $`\{1\}\times C_2`$ であり、幾何だけを変える自由度を持つ。
底の圏は終対象圏とする。

一つの頂点と二本のloop $`e,g`$ を取り、元のliftは恒等とする。
面と指定比較を

```math
e^2\Rightarrow\varnothing:\quad u=(b,0),\quad b=(12)(34),
\qquad
g\Rightarrow\varnothing:\quad v=(1,1)
\qquad\text{(4.43)}
```

とする。$`\varnothing`$ は空の道である。
coreでの整合条件は $`a_e^2=b`$、$`a_g=1`$ であり、
$`a_e=(1324)`$、$`a_g=1`$ が解になる。

一方、幾何で許される置換は $`\{1,2\}`$ と $`\{3,4\}`$ をそれぞれ保つ。
したがって置換部分は $`S_2\times S_2`$ であり、どの元も二乗すると恒等になる。
幾何の選択 $`c_e`$ が $`c_e^2=(b,0)`$ を満たすことはできない。
coreの平方根 $`(1324)`$ は、選択した二軸を保っていないのである。

幾何だけに属する第二の面は、核の選択 $`c_g=(1,1)`$ で整合する。
こうして、coreの全条件と、幾何だけに属する条件にはそれぞれ解がある。
それでも全体の解は存在しない。
障害は、coreの解を持ち上げるedge sectionが存在しないことにある。

## 4.10 lensの読取りと更新を同じ写像で運ぶ

前節までの比較をソフトウェアの操作へ結びつけるには、
どの変更が操作の意味を保つかを定める必要がある。
第1章のlensでは、一つの状態が読取りにも更新にも現れた。
この共有によって、二つの可換図式の写像は結びつく。

**定義4.36（Viewの変更を含むlensの射）.**
三法則を満たすlens $`L=(C,V,g,p)`$ と
$`L'=(C',V',g',p')`$ の間の相対的な射を、写像
$`h:C\to C'`$、$`u:V\to V'`$ で

```math
g'h=ug,\qquad
h\,p=p'(h\times u)
\qquad\text{(4.44)}
```

を満たす組とする。
恒等と合成は成分ごとの恒等と合成であり、式(4.44)を保つ。
固定viewの場合は $`u=\mathrm{id}_V`$ として第1章の射を得る。

本章のlensの法則の下では、更新の保存から読取りの保存が従う。
実際、任意の状態 $`c`$ について、変更前の第一法則（式(1.16)）、
更新の保存、変更後の第二法則を順に使うと、

```math
\begin{aligned}
g'(h(c))
&=g'\bigl(h(p(c,g(c)))\bigr)\\
&=g'\bigl(p'(h(c),u(g(c)))\bigr)\\
&=u(g(c)).
\end{aligned}
```

となる。この導出に $`h,u`$ の可逆性は要らない。
次の構成では、読取りと更新を同じ写像で保つことを、一つの可換図式として表す。

**命題4.37（二つの操作を束ねる平方）.**
読取りと更新を、直和の型を持つ一つの写像

```math
c_L:C\sqcup(C\times V)\longrightarrow V\sqcup C,\qquad
c_L|_C=g,\quad c_L|_{C\times V}=p
\qquad\text{(4.45)}
```

にまとめる。右辺ではそれぞれ対応する直和成分への包含を用いる。
次の等式は、式(4.44)と同値である。

```math
(u\sqcup h)c_L
=c_{L'}\bigl(h\sqcup(h\times u)\bigr).
\qquad\text{(4.46)}
```

**証明.**
左の入力成分 $`C`$ で制限すると読取りの等式、
右の入力成分 $`C\times V`$ で制限すると更新の等式になる。
逆に二つの制限が等しければ、直和上の写像は等しい。□

式(4.46)では、読取りの入力、更新の入力の状態成分、更新の出力に、
同じ $`h`$ が使われる。これが共有された状態の保存条件である。

**命題4.38（両操作を保つ可逆な変更）.**
一つのlensの可逆な変更群は、$`\mathrm{Aut}(C)\times\mathrm{Aut}(V)`$ の部分群として

```math
\begin{aligned}
G_L
 &=G_{\mathrm{get}}\cap G_{\mathrm{put}}
 =G_{\mathrm{put}}\subseteq G_{\mathrm{get}},\\
G_{\mathrm{get}}&=\{(h,u)\mid gh=ug\},\\
G_{\mathrm{put}}&=\{(h,u)\mid hp=p(h\times u)\}
\end{aligned}
\qquad\text{(4.47)}
```

である。式(4.46)は、この同じ組 $`(h,u)`$ から作った入出力の変更が
$`c_L`$ と可換することを表す。

**証明.**
二つの条件はいずれも恒等・合成・逆写像について閉じている。
その共通部分がちょうど式(4.44)を満たす可逆な射である。
更新の保存から読取りの保存が従うため、共通部分は $`G_{\mathrm{put}}`$ に等しい。
命題4.37を適用すれば後半も従う。□

第1章の例1.35では、読取りを保つ四つの全単射のうち、
更新も保つものは二つだった。
したがって、式(4.47)の包含は一般には真の包含である。
更新まで保存すると、許される状態の対応がさらに制約される。

**例4.39（情報をまとめる意味保存射）.**
空でないview集合 $`V`$ 上の積lens $`C=V\times K`$、$`C'=V\times K'`$ に対し、
任意の写像 $`t:K\to K'`$ は

```math
h(v,k)=(v,t(k)),\qquad u=\mathrm{id}_V
\qquad\text{(4.48)}
```

によって式(4.44)を満たす。
読取りはどちらも $`v`$ であり、表示値 $`w`$ への更新後は、
どちらの順序でも $`(w,t(k))`$ となるからである。
とくに $`V=\{*\}`$、$`K=\{0,1\}`$、$`K'=\{*\}`$ とすれば、$`h`$ は単射でない。
一般の意味保存射にはこのような情報の集約も含まれ、
可逆なものを取り出したときに式(4.47)の群が得られる。

## 4.11 プロトコルの操作とadapterを運ぶ

プロトコルでは、共有されるのは各頂点の状態集合である。
そこへ入る操作とそこから出る操作に、同じ状態写像を使う。
さらにadapterが二つのプロトコルをつなぐなら、その接続も同時に保存する。

**命題4.40（名前付き操作から全実行への保存）.**
第1章の $`\mathrm{Prot}(Q,\Pi,O)`$ の実現 $`X,X'`$ と頂点写像
$`a_v:X(v)\to X'(v)`$ を取る。
各名前付き辺 $`e:v\to w`$ と観測について

```math
a_wX(e)=X'(e)a_v,\qquad
o_{X'}(v)a_v=o_X(v)
\qquad\text{(4.49)}
```

ならば、$`a`$ は一意にプロトコルの意味保存射を与える。
また、adapter $`q:X\to Y`$、$`q':X'\to Y'`$ と
意味保存射 $`a:X\to X'`$、$`b:Y\to Y'`$ に対して

```math
bq=q'a
\quad\Longleftrightarrow\quad
b_vq_v=q'_va_v\quad\text{（すべての頂点 }v\text{）}
\qquad\text{(4.50)}
```

である。

**証明.**
式(4.49)は命題1.38の条件であり、一意な意味保存射を与える。
式(1.23)のadapterの保存条件を、自然変換の各成分で読むと式(4.50)を得る。□

この確認では、異なる名前を持つ操作は、作用が同じ場合にも個別の生成辺として扱う。
adapterを続けて変更する場合、二つの可換平方を貼り合わせると
合成した変更についても式(4.50)が成り立つ。

## 4.12 意味論と型付き構成の比較

lensの意味保存射やプロトコルのadapterを保つ可逆な変更は、
型付き構成へ移した後も回復できる。
両者に共通して用いるのは、充満忠実関手による次の対応である。

**定理4.41（意味論と型付き構成の間で比較を保つ）.**
充満忠実関手 $`F:𝒞\to 𝒟`$ と射 $`c:X\to Y`$ に対し、
その比較を保つ群を

```math
\mathrm{Cmp}(c)=
\{(a,b)\in\mathrm{Aut}_{𝒞}(X)\times\mathrm{Aut}_{𝒞}(Y)
\mid bc=ca\}
\qquad\text{(4.51)}
```

と置く。このとき

```math
\mathrm{Cmp}(c)\xrightarrow{\sim}\mathrm{Cmp}(F(c)),
\qquad(a,b)\longmapsto(F(a),F(b))
\qquad\text{(4.52)}
```

は群同型である。
$`c`$ が同型なら、第一射影の逆
$`a\mapsto(a,cac^{-1})`$ もこの対応と可換する。

**証明.**
関手は等式 $`bc=ca`$ を保つので写像が定義でき、群準同型となる。
充満性により、$`F(X),F(Y)`$ の自己同型とその逆射は元の圏に持ち上がる。
忠実性から、持ち上げた二射の合成は恒等であり、
$`F(b)F(c)=F(c)F(a)`$ から $`bc=ca`$ も従う。
よって全射である。単射性も忠実性による。
同型 $`c`$ の場合には $`b=cac^{-1}`$ であり、
関手が合成と逆射を保つことから最後の主張を得る。□

第1章の命題1.43は、固定viewのlensと固定したプロトコルの意味論から、
それぞれ構成した型付き対象の圏への充満忠実関手を与える。
したがって、lensの意味保存射やプロトコルのadapterを保つ可逆な変更は、
型付き構成から正確に回復できる。
viewも変えるlensでは、定義1.42のview成分を $`u`$、
write成分を $`h\times u`$ とする。
式(4.44)と命題4.37により、役割の写像の取出しと組立てが互いに逆となり、
同じ結論を得る。

これらの意味保存の条件を持つ圏と底への関手を定め、
強いopcartesianな辺のliftと指定比較を選べば、
§§4.5–4.7のdefectは、実際の操作を保つ変更の間の食い違いを表す。
さらに幾何を伴うreadingの輸送へ接続するには、
coreの射と定義4.9の局所実現の比較を与える。
この順にデータを揃えることで、操作の意味、readingの変更、幾何の持ち上げを結べる。

## 本章のまとめ

本章では、readingの変更に沿う輸送を構成し、
複数の輸送と指定比較を同じ辺の選択で整合させる条件を示した。

- **輸送の存在と普遍性。** Exactな抽出変更からcoreを構成し、
  その標準射が強いopcartesian射であることを示した。
  幾何の標準輸送も構成し、一般のcoreの射については
  三つの局所実現の比較を存在条件として取り出した（§§4.2–4.3）。
- **単位と合成の整合性。** 因子分解の一意性から、fiber間の関手と
  単位・合成の自然同型を得た。三重合成とcoreへの射影も整合する（§4.4）。
- **指定比較の障害。** 標準比較との差を非可換な自己同型として表し、
  障害の消滅がすべての面を整合させる辺の再選択と同値であることを示した。
  面の貼り合わせには、指定比較の間の追加の整合条件が必要になる（§§4.5–4.8）。
- **段をまたぐ同時消滅。** Coreでの選択を幾何へ持ち上げた後、
  同じ選択に対して核の変更で残りを消せることが、全体の整合性に対応する。
  各段で独立に解があっても、持ち上げがなければ全体の解にはならない（§4.9）。
- **操作の意味を保つ比較。** lensでは読取りと更新に同じ状態写像を使い、
  更新の保存から読取りの保存も従う。プロトコルではすべての名前付き操作とadapterを同時に保つ。
  これらの比較を保つ可逆な変更は、構成された型付き圏との間で回復できる（§§4.10–4.12）。

冒頭の注文APIでは、旧版から新版へ直接移す経路と、中間版を経由する経路の食い違いをdefectとして取り出す。
独立な二辺なら一方で吸収できる食い違いも、その辺を別の面と共有すると、同時に整合させる必要がある。
定理4.23は、確認対象のすべての面で指定比較を実現する変換の組が存在することを、障害の消滅として特徴づける。
さらにcoreと幾何の両段を扱うときも、持ち上げと核の変更を同じ選択に対して行う。

次章では、入力の基底を変えてから構成する経路と、
先に構成してから変更する経路を比較する。
