# 第5章 基底変換と生成比較

## 本章の概要

本章の問いは、構造を移す操作と、対象とする入力を変更する操作の順序を交換できるか、である。
第4章では、一つの変更に沿う輸送と、輸送を続けたときの整合性を扱った。
本章では、二種類の操作からできる二つの経路を構成し、その間の比較を調べる。

たとえば、注文処理と在庫管理を持つモノリスを、注文サービスと在庫サービスへ分割するとする。
設計レビューでは、まず「注文取消」に関わる部分を調べたい。
その部分には、取消要求、在庫予約の解除、取消完了という操作と、
「取消完了なら、対応する在庫予約も解除済み」という条件が含まれる。
同じ分割方針の下で、この部分の設計を得る二つの経路を比べる。

| 手順 | 最初に行う処理 | 次に行う処理 |
| --- | --- | --- |
| 全体を分割してから範囲を選ぶ | モノリス全体を注文・在庫サービスへ分割する | 分割後の設計から注文取消に関わる部分を取り出す |
| 範囲を選んでから分割する | 元の設計から注文取消に関わる部分を取り出す | その部分へ同じ分割方針を適用する |

担当者が注文取消の部分に絞って作った分割案は、全体を分割した後の設計と整合するだろうか。
たとえば、分割後は注文サービスが在庫サービスへ予約解除を依頼し、
解除の完了を確認してから取消完了へ進む設計を考える。
二つの経路で得た設計の間で、この連携と上の条件が対応することを確かめたい。
注文サービスに置かれた処理だけを取り出すと、在庫予約の解除が範囲から外れ、
条件を確認するために必要な依存関係を見失う。

そこで、変更先で選んだ範囲に対応する変更前の入力を求める。
この例では、取消の条件に必要な操作と依存関係を、分割前の設計までたどることになる。
本章では、その対応を入力の対として構成し、その上へ対象・操作・Lawの構造を引き戻す。
これが基底変換である。
さらに、輸送と引き戻しの普遍性から、二経路の結果を比べる写像を作る。
この写像を標準比較と呼ぶ。

| 問い | 構成 | 得られるもの |
| --- | --- | --- |
| 二つの入力を同じ条件で対応づけられるか | 共通の像を持つsourceの対 | 抽出doctrineのfiber product |
| 変更先の構造を変更前で読めるか | Atomの逆向きの再添字づけ | cartesianな引き戻しと輸送との同値 |
| 輸送と引き戻しの順序を交換できるか | 二つの普遍性から作るmate | canonicalな可逆比較 |
| 複数の比較と診断も運べるか | 可換な底の図式と終点群の対応 | 整合性・defectの消滅・再選択軌道の保存と反映 |
| 抽出内容が増える変更でも戻せるか | 実際に構造を持つ入力での抽出の反映 | refinementの逆輸送の必要十分条件 |
| 幾何と正規化まで含めると何を比べるか | 同じ入力から作る完全幾何の二経路 | 第6章で分析する生成比較 |

前半のexactな変更では、選んだsourceから抽出されるAtomが名前の変更まで含めて一致する。
後半のrefinementでは、抽出内容の前向きの保存だけを要求する。
この違いが、どの構造を逆向きに運べるかを決める。
モノリスの分割を扱う際も、業務上の操作と条件を読むのか、通信・失敗・再試行まで読むのかを指定し、
そのreadingで抽出と構造の保存条件を確かめる。

## 5.1 対応する入力をfiber productで作る

抽出doctrineは、sourceを正規化してからAtomを抽出するreadingである。
第1章の圏 $`B`$ は、さらに一つのsourceを選んだ対象を持つ。
まず選択sourceを忘れたdoctrineの圏で構成し、続いて選択を戻す。

**構成5.1（Exact doctrineのfiber product）.**
共通のAtom集合 $`\mathrm{At}`$ 上で、exactな二射を取る。

```math
D_1\xrightarrow{\sigma_1}D_0\xleftarrow{\sigma_2}D_2,
\qquad \sigma_i=(f_i,e_i).
\qquad\text{(5.1)}
```

$`f_i`$ はsource写像、$`e_i`$ はAtomの全単射である。
新しいdoctrine $`D_{12}`$ のsourceと正規化を

```math
\begin{aligned}
\mathrm{Src}_{12}
 &=\{(s_1,s_2)\mid f_1(s_1)=f_2(s_2)\},\\
N_{12}(s_1,s_2)&=(N_1s_1,N_2s_2)
\end{aligned}
\qquad\text{(5.2)}
```

と定める。正規化がこの集合を保つのは、$`f_iN_i=N_0f_i`$ による。
語彙・意味・解像度の選択は $`D_1`$ から取り、sourceを読む述語には第一成分を渡す。
したがって

```math
\mathrm{Extracts}_{12}((s_1,s_2),a)
\Longleftrightarrow \mathrm{Extracts}_1(s_1,a).
\qquad\text{(5.3)}
```

二つの射影は

```math
\pi_1=(\mathrm{pr}_1,\mathrm{id}_{\mathrm{At}}),
\qquad
\pi_2=(\mathrm{pr}_2,e_2^{-1}e_1)
\qquad\text{(5.4)}
```

である。第二射影のAtom写像は、第一の名前を共通の底の名前へ移し、
そこから第二の名前へ戻す。Exactnessは

```math
\begin{aligned}
\mathrm{Extracts}_1(s_1,a)
&\Longleftrightarrow\mathrm{Extracts}_0(f_1(s_1),e_1(a))\\
&\Longleftrightarrow\mathrm{Extracts}_2(s_2,e_2^{-1}e_1(a))
\end{aligned}
\qquad\text{(5.5)}
```

から従う。SourceとAtomの両成分で $`\sigma_1\pi_1=\sigma_2\pi_2`$ となる。

**命題5.2（全てのconeに対する普遍性）.**
Exact射 $`h_i:T\to D_i`$ が $`\sigma_1h_1=\sigma_2h_2`$ を満たすなら、
$`\pi_i h=h_i`$ を満たすexact射 $`h:T\to D_{12}`$ が一意に存在する。
したがって $`D_{12}`$ は式(5.1)のfiber productである。

**証明.**
$`h_i=(g_i,d_i)`$ と書き、$`h`$ のsource写像を
$`t\mapsto(g_1(t),g_2(t))`$、Atom写像を $`d_1`$ とする。
Sourceの対はconeの可換性により式(5.2)に属する。
正規化との可換性は成分ごとに成立し、抽出の同値は $`h_1`$ のexactnessである。
第二射影については $`e_1d_1=e_2d_2`$ から
$`e_2^{-1}e_1d_1=d_2`$ を得る。
二つの射影との等式はsource写像を一意に決め、第一射影との等式はAtom写像を一意に決める。□

選択source $`s_i`$ が $`f_1(s_1)=f_2(s_2)`$ を満たすときは、
$`D_{12}`$ で $`(s_1,s_2)`$ を選ぶ。
任意のpointed coneの二射が選択sourceを保てば、上の普遍射もそれを保つ。
これにより、$`B`$ にも同じfiber productが得られる。

**例5.3（変更先の範囲に対応する入力）.**
構成5.1を、sourceが小さな有限集合の場合で確かめる。
変更前のsourceを $`\{a,b,c\}`$、変更後のsourceを $`\{0,1\}`$ とし、
対応を $`f(a)=f(b)=0`$、$`f(c)=1`$ とする。
変更後に対象 $`\{0\}`$ を選ぶ包含 $`j:\{0\}\to\{0,1\}`$ に沿うfiber productは

```math
\{a,b,c\}\times_{\{0,1\}}\{0\}
=\{(a,0),(b,0)\}.
\qquad\text{(5.6)}
```

全sourceが同じ有限のAtom集合を抽出し、正規化とAtom写像を恒等とすれば、
これは構成5.1の具体例になる。$`a,b`$ が同じ変更後のsourceへ送られても、
対応する変更前の入力としては両方が残る。
モノリスの分割に用いる際は、設計資料やコードをsourceとし、
設計変更と範囲の選択に使うreadingを指定して、式(5.5)を確かめる。

## 5.2 変更先のcoreを引き戻す

第4章の輸送 $`\sigma_!`$ は、変更前のcoreから出発した。
引き戻し $`\sigma^*`$ は、変更先のcoreから出発する。
いずれも同じ底の射 $`\sigma:b\to b'`$ に対応するが、対象を構成する向きが逆になる。

**定義5.4（強いcartesian射）.**
関手 $`r:E\to B`$ と射 $`\kappa:Y\to Q`$ を取り、
$`r(\kappa)=\sigma:b\to b'`$ とする。
任意の対象 $`R`$、底の射 $`\tau:r(R)\to b`$、射 $`h:R\to Q`$ について、
$`r(h)=\sigma\tau`$ ならば

```math
\exists!\,k:R\longrightarrow Y,\qquad
r(k)=\tau,\quad \kappa k=h
\qquad\text{(5.7)}
```

となるとき、$`\kappa`$ を強いcartesian射と呼ぶ。
これは、$`Q`$ への射を、底の $`\sigma`$ に対応する最後の一段と、そこまでの射に一意に分ける条件である
（[Stacks, Tag 02XJ, 定義4.33.1](https://stacks.math.columbia.edu/tag/02XJ)）。

**構成5.5（逆向きの再添字づけ）.**
$`\sigma=(f,e):(D,s)\to(D',s')`$ をexact射とし、
$`Q`$ を $`(D',s')`$ 上のcoreとする。選択された抽出族を $`F_D(s)`$ と書くと、

```math
F_{D'}(s')=e_*F_D(s),\qquad
F_D(s)=(e^{-1})_*F_{D'}(s').
\qquad\text{(5.8)}
```

右辺は有限なので、変更前にもcoreの入力となる有限族が得られる。
底を $`(D,s)`$ に置き、composition・対象形成・operationを次で定める。

```math
\begin{aligned}
\mathrm{Comp}_{\sigma^*Q}(F)
 &=(e^{-1})_*\mathrm{Comp}_Q(e_*F),\\
\mathrm{Form}_{\sigma^*Q}(C)
 &=T_{e^{-1}}\mathrm{Form}_Q(e_*C),\\
\mathrm{Op}_{\sigma^*Q}(A,B)
 &=\mathrm{Op}_Q(T_eA,T_eB).
\end{aligned}
\qquad\text{(5.9)}
```

ここで $`T_e`$ は構成4.3の対象の再添字づけである。
Operationのconfiguration写像を共役し、invariantとsignatureを $`T_e`$ と合成する。
文脈、方程式、残差、detector codeも同じ $`e^{-1}`$ で再添字づけする。
式(5.8)とcomposition・対象形成の式により、生成される基点は $`T_{e^{-1}}Q`$ の基点と一致する。
この一致で方程式readingの基点を揃える。

得られる射 $`\kappa_{\sigma,Q}:\sigma^*Q\to Q`$ は、底に $`\sigma`$ を持つ。
上段のreading写像 $`u`$ には、逆の再添字づけによる両側逆 $`u^{-1}`$ がある。
この構成が使うsourceの情報は $`f(s)=s'`$ と抽出の同値である。

**定理5.6（任意のexact射に沿うcartesian lift）.**
任意のexactな底射 $`\sigma:b\to b'`$ と任意の $`b'`$ 上のcore $`Q`$ に対し、
構成5.5の射 $`\kappa_{\sigma,Q}`$ は $`q:E_{\mathrm{core}}\to B`$ に関して強いcartesian射である。

**証明.**
式(5.7)の $`h:R\to Q`$ に対し、$`k`$ の底を $`\tau`$、上段を
$`u^{-1}h_{\mathrm{up}}`$ とする。
Atom成分は、$`h`$ の底が $`\sigma\tau`$ であることと $`u^{-1}`$ によって、
$`\tau`$ のAtom成分に一致する。
他の成分はreadingの射の合成なので、対象形成・operation・方程式・invariant・signatureを保つ。
$`uu^{-1}=1`$ より $`\kappa_{\sigma,Q}k=h`$ である。
別の因子も底は $`\tau`$ であり、上段の等式に $`u^{-1}`$ を合成すれば同じ $`k`$ となる。□

**補題5.7（引き戻し関手と合成比較）.**
各 $`\sigma,Q`$ にcartesian liftを選ぶと、fiber圏の間の関手
$`\sigma^*:E_{b'}\to E_b`$ が得られる。
Vertical射 $`v:Q\to Q'`$ の像は

```math
\kappa_{\sigma,Q'}\,\sigma^*(v)
=v\,\kappa_{\sigma,Q}
\qquad\text{(5.10)}
```

で一意に決まる。
$`\sigma:b_0\to b_1`$、$`\tau:b_1\to b_2`$ に対し、
単位と合成の自然同型

```math
1_{E_b}\xrightarrow{\sim}(1_b)^*,
\qquad
\sigma^*\tau^*\xrightarrow{\sim}(\tau\sigma)^*
\qquad\text{(5.11)}
```

があり、単位・三重合成の整合性を満たす。

**証明.**
恒等射と射の合成に式(5.10)を適用し、一意性を使えば関手則を得る。
Cartesian射の合成は、式(5.7)を二回適用することでcartesianとなる。
従って二段のliftと直接のliftの間には、その合成先への三角形を可換にする同型が一意にある。
三段のliftからできる二つの比較も、同じ三角形を満たすため等しい。
単位についても同じ一意性を使う。□

**命題5.8（輸送と引き戻しの随伴同値）.**
Exact射 $`\sigma:b\to b'`$ について、第4章の輸送と本節の引き戻しは

```math
\sigma_!:E_b\rightleftarrows E_{b'}:\sigma^*,
\qquad \sigma_!\dashv\sigma^*
\qquad\text{(5.12)}
```

という随伴をなし、単位 $`\eta^\sigma:1\to\sigma^*\sigma_!`$ と
余単位 $`\epsilon^\sigma:\sigma_!\sigma^*\to1`$ は可逆である。

**証明.**
Opcartesianな射を $`\iota_{\sigma,P}:P\to\sigma_!P`$ と書く。
両方の普遍性により、次の自然な全単射が得られる。

```math
\begin{aligned}
\mathrm{Hom}_{E_{b'}}(\sigma_!P,Q)
&\cong\{h:P\to Q\mid q(h)=\sigma\}\\
&\cong\mathrm{Hom}_{E_b}(P,\sigma^*Q).
\end{aligned}
\qquad\text{(5.13)}
```

第一の対応は $`v\mapsto v\iota_{\sigma,P}`$、第二の逆対応は
$`w\mapsto\kappa_{\sigma,Q}w`$ である。
恒等射を対応させて単位と余単位を作る。
三角等式は、それぞれのliftとの合成後に恒等射となることと一意性から従う。

さらに両方のliftの上段は、互いに逆のAtom再添字づけで作られている。
定理5.6の証明を逆向きの因子分解に用いれば、各liftはcartesianかつopcartesianである。
単位は同じ底射・同じ終点を持つ二つのcartesian liftの比較、
余単位は同じ底射・同じ始点を持つ二つのopcartesian liftの比較となる。
どちらも一意性から可逆である。□

**例5.9（底が非可逆でもfiberは同値になる）.**
Source集合 $`\{0,1\}`$ から $`\{*\}`$ への定値写像を取り、前者で $`0`$ を選ぶ。
全sourceが同じ有限族 $`F`$ を抽出し、正規化・Atom写像を恒等とする。
これはexact射だが、source写像に両側逆がないので底の同型ではない。
命題5.8は、それでも選択source上のfiber圏が同値になることを示す。
往復するのは、そのsourceで読む対象形成・操作・Lawである。
Source全体の区別を復元することとは、異なる問いなのである。

## 5.3 輸送と引き戻しを交換する標準比較

**構成5.10（型を揃えた二経路）.**
構成5.1のpointedなfiber productを

```math
\begin{array}{ccc}
b_{12}&\xrightarrow{\ \pi_2\ }&b_2\\
{\scriptstyle\pi_1}\downarrow&&\downarrow{\scriptstyle\sigma_2}\\
b_1&\xrightarrow{\ \sigma_1\ }&b_0
\end{array}
\qquad \sigma_1\pi_1=\sigma_2\pi_2
\qquad\text{(5.14)}
```

と書く。$`b_1`$ 上のcoreから $`b_2`$ 上のcoreへ至る二経路は

```math
D=(\pi_2)_!\pi_1^*,\qquad
V=\sigma_2^*(\sigma_1)_!,\qquad
D,V:E_{b_1}\longrightarrow E_{b_2}.
\qquad\text{(5.15)}
```

$`D`$ は対応する入力へ引き戻してから移す経路、
$`V`$ は共通の底へ移してから引き戻す経路である。
第4章の輸送の合成比較と式(5.14)から、自然同型

```math
\Sigma:(\sigma_2)_!(\pi_2)_!
\xrightarrow{\sim}(\sigma_1)_!(\pi_1)_!
\qquad\text{(5.16)}
```

を得る。これは両方を、同じ合成底射に沿う直接の輸送と比較して作る。

**定理5.11（Canonical Beck–Chevalley mate）.**
次の三段の合成は自然同型 $`\alpha:D\xrightarrow{\sim}V`$ を定める。

```math
\begin{aligned}
DP&\xrightarrow{\ \eta^{\sigma_2}_{DP}\ }
 \sigma_2^*(\sigma_2)_!DP\\
&\xrightarrow{\ \sigma_2^*(\Sigma_{\pi_1^*P})\ }
 \sigma_2^*(\sigma_1)_!(\pi_1)_!\pi_1^*P\\
&\xrightarrow{\ \sigma_2^*(\sigma_1)_!(\epsilon^{\pi_1}_P)\ }
 VP.
\end{aligned}
\qquad\text{(5.17)}
```

この比較をcanonical Beck–Chevalley mateと呼ぶ。
また、引き戻しの選択を替えても、一意なlift比較で両端を揃えたmateは一致する。

**証明.**
三つの矢印はそれぞれ単位、輸送の自然同型、余単位の関手による像である。
よって合成は自然変換である。命題5.8により単位と余単位は可逆であり、
関手は同型を保つので、三つの矢印すべてが可逆である。

選択からの独立性は、次の等式によって比較そのものを特徴づけると分かる。

```math
\kappa_{\sigma_2,(\sigma_1)_!P}\,
\alpha_P\,\iota_{\pi_2,\pi_1^*P}
=\iota_{\sigma_1,P}\,\kappa_{\pi_1,P}.
\qquad\text{(5.18)}
```

右辺をまず $`\iota_{\pi_2,\pi_1^*P}`$ で因子分解し、
次に $`\kappa_{\sigma_2,(\sigma_1)_!P}`$ で因子分解すれば、$`\alpha_P`$ を一意に得る。
随伴の単位・余単位の因子分解を代入すると、この射が式(5.17)である。
別のliftの選択を標準同型で揃えても式(5.18)は保たれるため、比較は一致する。□

可逆性の理由は、pullbackという図形だけでなく、実際のcore輸送の単位と余単位が可逆であることにある。
この証明は、比較のどの構成要素を確認すればよいかも示している。

**命題5.12（指定した比較との一致判定）.**
別に指定した射 $`a_P:DP\to VP`$ が式(5.18)を満たすことと、
$`a_P=\alpha_P`$ は同値である。
特に $`a_P`$ が可逆なら、

```math
\Delta_P=a_P\alpha_P^{-1}\in\mathrm{Aut}_{E_{b_2}}(VP),
\qquad
a_P=\alpha_P\Longleftrightarrow\Delta_P=1.
\qquad\text{(5.19)}
```

**証明.**
前半は式(5.18)の二回の一意性である。後半は右から $`\alpha_P`$ を合成すれば従う。□

**例5.13（比較を実装する際の取り違え）.**
注文と在庫を分けた後、二経路で得た設計を比較する際に、
二つの在庫予約の対応を取り違えたとする。選んだreadingでこの入替えが自己同型
$`s`$ となる場合、$`a_P=s\alpha_P`$ の不一致は $`\Delta_P=s`$ である。
このとき $`a_P`$ も $`\alpha_P`$ も可逆である。
可逆性と、指定された二経路を正しく対応づけることを、それぞれの式で確かめる必要がある。

## 5.4 構成の存在と有限表示の範囲

逆向きの再添字づけは、source全体を有限表で記述できなくても定義できる。
これに対し、有限の入力形式でどこまでの底射を表せるかは、その形式に依存する。
ここでは後の再構成にも使う、一つの具体的な形式を定める。

**定義5.14（有限例外表によるcode）.**
Sourceを有限集合として列挙し、正規化写像を表で与える。
正規化後の各sourceで使うAtom述語は、既定の真偽値と、それを反転する有限例外集合で表す。
既定値が偽なら有限集合、真なら余有限集合、すなわち補集合が有限の集合を表す。
Pointedなcodeには選択sourceを加える。
Code間の射にはsourceの有限表と、有限の台の上のAtom置換表を用い、
正規化との可換性、抽出の同値、選択sourceの保存を要求する。

Exact射 $`\sigma:b\to b'`$ がこの形式で表示可能であるとは、
codeから復号した射 $`\widehat\sigma:\widehat b\to\widehat b'`$ と底の同型
$`i:\widehat b\xrightarrow{\sim}b`$、$`j:\widehat b'\xrightarrow{\sim}b'`$ があって、

```math
\sigma i=j\widehat\sigma
\qquad\text{(5.20)}
```

となることをいう。同型 $`i,j`$ も含めて、射全体の表示を比べている。

**定理5.15（このcodeによる表示可能性）.**
Atomの等号判定を備えるとする。Exact射 $`\sigma=(f,e):b\to b'`$ が
定義5.14の意味で表示可能であるための必要十分条件は、次の二つである。

1. 両端のsource集合が有限である。
2. 変更先の全source $`t`$ について、抽出集合 $`F_{D'}(t)`$ が有限または余有限である。

**証明.**
表示があれば、sourceの列挙と端点同型によって両端の有限性を得る。
有限例外表の表す集合は有限または余有限であり、この性質はAtomの全単射で保たれる。
端点同型は全sourceを対応づけるので、変更先の全抽出集合に条件2が成立する。

逆に二条件を仮定する。Exactnessにより、変更前の各抽出集合は
$`e^{-1}_*F_{D'}(f(s))`$ であるから、これも有限または余有限である。
両端のsourceを列挙し、正規化とsource写像をその列挙で表す。
抽出の表は、正規化写像の像にあるsourceでは元の述語の連言を符号化する。
その連言は、そこへ正規化される入力の抽出述語に等しい。
像の外の表は偽にしてよい。復号時には必ず正規化してから表を読むためである。
この手順は、正規化の冪等性を必要としない。

端点同型のAtom成分を、変更前では恒等、変更先では $`e`$ と選ぶ。
変更先の表も $`e`$ に沿って読み直せば、code内のAtom置換には恒等を使える。
Sourceの表との組はexactであり、式(5.20)を満たす。□

この結論では端点の表示も選び直している。
あらかじめ二つのcodeを固定し、その間の全semantic射をcodeの射で表せるかという
Hom集合の充満性は、さらにその固定した表示について調べる問題となる。

**例5.16（有限のsourceだけでは足りない）.**
Atom集合を $`ℕ`$、sourceを一つとし、正規化を恒等、抽出集合を偶数全体とする。
このdoctrineの恒等射はexactだが、偶数も奇数も無限なので有限例外表では表示できない。
一方、同じsourceで抽出集合を $`ℕ\setminus\{1,3\}`$ とすれば、
既定値を真、例外を $`\{1,3\}`$ として表示できる。
後者の選択族は無限であり、第1章の有限族を要求するcoreはその点に存在しない。
有限codeによる底の表示と、その点のcoreの存在には、それぞれ固有の条件がある。

## 5.5 可換な平方を図式全体へ組み上げる

実際の変更では、一つの平方だけでなく、複数のAPI、変換、検査経路を同時に扱う。
そのためには、各辺の対応から道の対応を作り、二つの道の関係を保つ必要がある。

**定義5.17（底の図式とその変更）.**
有限の頂点・生成辺・指定された平行な二道の組を持つ形を固定する。
底の図式 $`X`$ は、頂点 $`v`$ に $`X_v\in B`$、辺 $`a:v\to w`$ に
$`X_a:X_v\to X_w`$ を割り当てる。
各面 $`f`$ の二道 $`\ell_f,\rho_f`$ には
$`X_{\ell_f}=X_{\rho_f}`$ を要求する。

同じ形の図式 $`X,Y`$ の間の変更は、頂点ごとのexact射 $`i_v:X_v\to Y_v`$ であって、
各生成辺について

```math
Y_a i_v=i_w X_a
\qquad\text{(5.21)}
```

を満たすものとする。このとき、任意の道 $`\gamma:v\to w`$ についても
$`Y_\gamma i_v=i_wX_\gamma`$ である。
空の道では恒等則を使い、一辺延ばすごとに式(5.21)を代入すれば証明できる。

ここで図式が指定するのは、底の対象・射と、その関係である。
Core、辺のlift、比較の自己同型は、次にその上へ置く。

**構成5.18（同じ平方から上段の辺を作る）.**
各頂点のcore $`P_v`$ と、各辺の強いopcartesian lift
$`L_a:P_v\to P_w`$ を持つとする。
頂点では $`P'_v=(i_v)_!P_v`$ と置き、canonical liftを
$`I_v:P_v\to P'_v`$ と書く。
変更後の辺 $`L'_a`$ は

```math
L'_a I_v=I_wL_a,\qquad q(L'_a)=Y_a
\qquad\text{(5.22)}
```

を満たす一意な射として作る。
$`I_v`$ のopcartesian性と式(5.21)が、その存在を与える。
さらに $`I_wL_a`$ がopcartesianなので、$`L'_a`$ もopcartesianである。
実際、$`L'_a`$ の先への射を $`I_v`$ と合成し、$`I_wL_a`$ で因子分解する。
その等式から $`I_v`$ を普遍性によって消去すれば、$`L'_a`$ の因子分解と一意性が得られる。

式(5.22)を道に沿って合成すると、$`L'_\gamma I_v=I_wL_\gamma`$ となる。
恒等・図式変更の合成・平方の横と縦の貼り合わせについても、
両方の構成が同じ因子分解の式を満たすため、標準比較の下で一致する。

**命題5.19（平方の族から関係を得る条件）.**
変更前の図式 $`X`$ と、変更先の頂点・辺、頂点射 $`i_v`$、式(5.21)だけを与えたとする。
面 $`f:v\Rightarrow w`$ の二道について得られる等式は

```math
Y_{\ell_f}i_v=i_wX_{\ell_f}
=i_wX_{\rho_f}=Y_{\rho_f}i_v.
\qquad\text{(5.23)}
```

$`i_v`$ がepiなら、$`Y_{\ell_f}=Y_{\rho_f}`$ が従う。
従って、生成辺または指定面の始点として現れる頂点で $`i_v`$ がepiなら、
平方の族から変更先の図式と図式の変更を構成できる。

さらに、一つの $`i:X\to Y`$ について、全ての対象 $`Z`$ と全ての平行射
$`u,v:Y\to Z`$ に対する性質

```math
ui=vi\Longrightarrow u=v
\qquad\text{(5.24)}
```

は、$`i`$ がepiであることと同値である。

**証明.**
道についての式(5.21)と変更前の関係から式(5.23)を得る。
Epiの消去則を適用すれば各面の関係が成立する。
最後の同値は、epiの定義そのものである。□

全ての平行射を対象にする式(5.24)と、今選んだ有限の道だけが一致することでは量化が異なる。
ある図式が整合するために、各 $`i_v`$ がepiであることまでは必要ない。

**例5.20（見ていない入力での食い違い）.**
全sourceで同じ有限族を抽出するdoctrineを使い、正規化・Atom写像を恒等とする。
Source写像

```math
i:\{*\}\to\{0,1\},\quad i(*)=0,\qquad
u=\mathrm{id}_{\{0,1\}},\quad v(0)=v(1)=0
\qquad\text{(5.25)}
```

を考える。全ての選択sourceを $`*`$ または $`0`$ とすれば、これは底の射になる。
変更前の二つの平行辺をともに恒等とすると、変更先の辺 $`u,v`$ は個別には可換な平方を作る。
しかし $`ui=vi`$ であっても $`u(1)\ne v(1)`$ である。
入力 $`0`$ だけで一致しても、入力 $`1`$ での一致は得られない。

変更先の二辺をともに $`u`$ にすれば、同じ非epiの $`i`$ でも関係は成立する。
この二例が、一様な消去条件と、個別の図式の整合性の違いを示す。

## 5.6 診断と辺の選び直しを往復させる

第4章では、指定比較と標準比較の差をdefectとして表した。
底の図式を変更するときには、この差も同じ入力から運びたい。
命題5.8のfiber同値によって、診断の値だけでなく、その値を変える辺の再選択も対応する。

**構成5.21（終点群、cochain、再選択の対応）.**
定義5.17の図式変更と構成5.18のcore・辺を固定する。
頂点 $`v`$ のvertical自己同型群を $`G_v=\mathrm{Aut}_{E_{X_v}}(P_v)`$、
変更後を $`G'_v`$ とする。輸送関手は群同型

```math
\Phi_v:G_v\xrightarrow{\sim}G'_v,
\qquad \Phi_v(g)=(i_v)_!(g)
\qquad\text{(5.26)}
```

を誘導する。充満性から全射性、忠実性から単射性を得る。
面のcochain $`\omega=(\omega_f)_f`$ と辺の再選択 $`a=(a_e)_e`$ は、
それぞれ終点でこの同型を適用して送る。

```math
(\Phi_C\omega)_f=\Phi_{t(f)}(\omega_f),
\qquad
(\Phi_R a)_e=\Phi_{t(e)}(a_e).
\qquad\text{(5.27)}
```

ここで $`t(f)`$、$`t(e)`$ は面と辺の終点である。
各 $`\Phi_v^{-1}`$ を成分ごとに用いれば、どちらにも両側逆がある。
指定比較 $`u_f`$ の変更先での値も $`u'_f=\Phi_{t(f)}(u_f)`$ とする。

**定理5.22（整合性と再選択軌道の保存・反映）.**
変更先の底の図式も指定された道の関係を満たすとする。
上の構成について、第4章の標準比較 $`\phi_f`$ とraw defectは

```math
\begin{aligned}
\phi'_f(\Phi_Ra)&=\Phi_{t(f)}(\phi_f(a)),\\
\delta'_f(\Phi_Ra)&=\Phi_{t(f)}(\delta_f(a))
\end{aligned}
\qquad\text{(5.28)}
```

を満たす。従って、次が同値となる。

1. $`a`$ で全ての面が整合することと、$`\Phi_Ra`$ で全ての面が整合すること。
2. 全ての面を整合させる再選択が変更前に存在することと、変更後に存在すること。
3. $`\omega`$ がraw defectの再選択軌道に属することと、$`\Phi_C\omega`$ が変更後の軌道に属すること。

任意の変更後のcochainについても、$`\Phi_C^{-1}`$ で戻した値に同じ判定が成立する。

**証明.**
再選択した辺は $`L_e^a=a_eL_e`$ である。
輸送の射への作用と式(5.22)により、その像は
$`\Phi_{t(e)}(a_e)L'_e`$ となる。
道へ延ばすと、変更前の標準比較を運んだ射は、変更後の二道を比較する式を満たす。
強いopcartesian liftの一意性から、これが変更後の標準比較である。
群準同型が積と逆を保つことにより
$`\delta_f=u_f\phi_f^{-1}`$ から式(5.28)の第二式を得る。

各 $`\Phi_v`$ は恒等元を保存・反映するので、全成分のdefectが恒等となることは同値である。
さらに $`\Phi_R`$ は全単射なので、変更後の任意の再選択も戻せる。
軌道所属の証拠 $`\omega=\delta(a)`$ を式(5.28)で運び、逆向きには
$`\Phi_R^{-1}`$ と $`\Phi_C^{-1}`$ を用いれば、三つの結論が従う。□

この診断は、固定した図式とそこから生成した比較を対象とする。
変更後に新しい面や新しいLawを追加した場合は、それも含む図式を改めて指定する。
係数環を含む幾何を扱う際には、本節では同じ係数環を固定する。

**例5.23（defectを消す再選択の対応）.**
第4章の一対象群圏の例で、自己同型群を三文字の置換群 $`S_3`$ とする。
恒等の二つの平行な辺に、指定比較 $`u=(12)`$ を置く。
左辺を $`a=1`$、右辺を $`b=(12)`$ に選び直すと、
標準比較は $`ba^{-1}=(12)`$ となりdefectは消える。

名前の変更 $`c=(123)`$ による群同型 $`\Phi(g)=cgc^{-1}`$ では、
指定比較と右辺の再選択がともに $`(23)`$ へ移る。
よって変更後も同じ面が整合する。単に「消えた」という真偽を保存するだけでなく、
それを実現した再選択を運んでいる。

## 5.7 Refinementで逆向きに運べる条件

抽出の規則を詳しくすると、それまで抽出されなかったAtomが現れることがある。
この変更をexact射と同じように逆向きに運べるとは限らない。
必要なのは、実際にcoreを置くsourceで、変更先の抽出を変更前へ戻せることである。

**定義5.24（Refinementと実現台）.**
底のrefinement $`r:(D,s)\to(D',s')`$ は、source写像 $`f`$ とAtomの全単射 $`e`$ を持ち、
$`f(s)=s'`$、$`fN_D=N_{D'}f`$ と前向きの含意

```math
\mathrm{Extracts}_D(t,a)
\Longrightarrow\mathrm{Extracts}_{D'}(f(t),e(a))
\qquad\text{(5.29)}
```

を満たすものとする。
Exactnessは、ここに逆向きの含意も加えた条件である。

Coreを一つ以上持つ底の対象の集まりを実現台と呼ぶ。
$`r`$ が実現台で抽出を反映するとは、$`E_{b'}`$ に対象があるとき、
全てのAtom $`a`$ について

```math
\mathrm{Extracts}_{D'}(s',e(a))
\Longrightarrow\mathrm{Extracts}_D(s,a)
\qquad\text{(5.30)}
```

が成立することをいう。対象があるかどうかの条件も含めて、この性質を $`R(r)`$ と書く。

Refinementの上のcore射では、底だけを式(5.29)へ緩め、
上段には定義1.28と同じreadingの保存条件を課す。
特に、選択族の比較は等号のまま要求する。
この射と対象は合成について閉じ、圏 $`E_{\mathrm{core}}^{\mathrm{ref}}`$ と
底への射影 $`q_{\mathrm{ref}}`$ を定める。

**定理5.25（実現台によるcartesian liftの分類）.**
一つのpointed refinement $`r:b\to b'`$ を固定する。
$`b'`$ 上の全coreに対し、$`q_{\mathrm{ref}}`$ に関する強いcartesian liftを選べることと、
$`R(r)`$ は同値である。

**証明.**
$`R(r)`$ を仮定し、$`b'`$ 上のcore $`Q`$ を取る。
式(5.29)と(5.30)を合わせると、$`F_{D'}(s')=e_*F_D(s)`$ を得る。
この等式から有限性を戻し、構成5.5と同じ逆再添字づけでcore $`P`$ を作る。
底を $`r`$ とする射 $`P\to Q`$ の上段には両側逆がある。
定理5.6と同じ因子分解は、任意のrefinement底射の後でも働く。

逆にliftを選べるとし、$`b'`$ 上のcore $`Q`$ を一つ取る。
そのlift $`P\to Q`$ の上段は、選択族について $`F_Q=e_*F_P`$ を満たす。
変更先で $`e(a)`$ が抽出されるなら、$`e`$ の単射性から $`a\in F_P`$ となり、
変更前でも抽出される。これが式(5.30)である。
$`b'`$ 上にcoreがない場合、liftを選ぶ対象もなく、両方の条件は空虚に成立する。□

**構成5.26（Refinementの前向きの基底変換）.**
Exactなcospan $`D_1\to D_0\leftarrow D_2`$ とrefinement $`r:D'_1\to D_1`$ を取る。
対応するsourceの対を

```math
\mathrm{Src}'_{12}
=\{(s'_1,s_2)\mid f_1(f_r(s'_1))=f_2(s_2)\}
\qquad\text{(5.31)}
```

とし、抽出を $`D'_1`$ の第一成分から定める。
第一射影 $`\pi'_1:D'_{12}\to D'_1`$ はexactであり、
$`(s'_1,s_2)\mapsto(f_r(s'_1),s_2)`$、Atom写像 $`e_r`$ はrefinement
$`r_{12}:D'_{12}\to D_{12}`$ を定める。
式(5.29)から抽出の保存が従い、次の平方は可換である。

```math
\begin{array}{ccc}
D'_{12}&\xrightarrow{\ r_{12}\ }&D_{12}\\
{\scriptstyle\pi'_1}\downarrow&&\downarrow{\scriptstyle\pi_1}\\
D'_1&\xrightarrow{\ r\ }&D_1.
\end{array}
\qquad\text{(5.32)}
```

この構成は $`R(r)`$ を必要としない。
式(5.31)の対を一つ選べば、四つの頂点のsourceとpointedな平方が定まる。

**命題5.27（実現台の移送と二つの逆経路）.**
式(5.31)のcompatibleな対を選び、その点で $`R(r)`$ が成立するとする。
このとき $`R(r_{12})`$ も成立し、$`D_1`$ 上のcoreから
$`D'_{12}`$ 上のcoreへ至る二つの関手と自然な比較

```math
(\pi'_1)^*r^*
\longrightarrow r_{12}^*\pi_1^*
\qquad\text{(5.33)}
```

が得られる。
全てのcompatibleな対で両方のrefinement liftを選べることは、
全てのその対で $`R(r)`$ が成立することと同値である。
また、実現台で抽出を反映するpointed refinementは恒等と合成について閉じる。

**証明.**
$`D_{12}`$ の選択点にcoreがあれば、exactな $`\pi_1`$ に沿って前向きに輸送できる。
これにより $`D_1`$ の対応点にもcoreが得られ、$`R(r)`$ を使える。
両pullbackの抽出は第一成分の抽出なので、式(5.30)はそのまま $`r_{12}`$ に移る。
定理5.25が二つのrefinement liftを、定理5.6が二つのexact liftを与える。
可換な平方に沿う二段のliftを因子分解すると式(5.33)を得る。
その自然性は、vertical射を合成した二つの因子が同じ三角形を満たすことから従う。
全ての対についての同値には、定理5.25を点ごとに用いる。

合成 $`b_0\xrightarrow{r}b_1\xrightarrow{t}b_2`$ では、
$`b_2`$ のcoreを $`t`$ に沿って引き戻して $`b_1`$ のcoreを作る。
これで $`R(r)`$ の実現条件も満たされる。
抽出を $`t`$、次に $`r`$ に沿って反映すれば $`R(tr)`$ を得る。
恒等の場合は式(5.30)が恒等の含意となる。□

**例5.28（前向きだけの変更と、戻せる範囲）.**
Atomを $`\{A,B,C\}`$、sourceを $`\{\mathrm{partial},\mathrm{all}\}`$ とする。
正規化を恒等とし、変更前と変更先の抽出を次で定める。

| source | 変更前 | 変更先 |
| --- | --- | --- |
| partial | A, B | A, B, C |
| all | A, B, C | A, B, C |

Source写像は恒等、Atom写像は $`A,B`$ を交換して $`C`$ を固定する全単射とする。
これはrefinementである。全抽出族は有限であり、各点にcoreを置ける。
たとえば $`\mathrm{Comp}(F)=(F,\varnothing,\varnothing)`$ とし、
対象形成はconfigurationを保って構造データと量にそれぞれ一元集合の元を置く。
Operationは同じ対象間の恒等だけ、方程式添字・invariant・signature軸は空とすれば、
読みの条件を満たすcoreを構成できる。

Partialを選ぶと、変更先の $`C`$ を変更前へ戻せない。
定理5.25により、変更先のcoreへのliftは存在しない。
両cospan legを変更先doctrineの恒等にすれば、構成5.26の前向きの平方はそれでも作れる。

一方、第二のcospan legを、一つだけsourceを持ち全Atomを抽出するdoctrineから
変更先のallへ入るexact射とする。
Compatibleな対では第一のsourceもallに限られ、そこでは式(5.30)が成立する。
従って、その平方には両方の逆輸送がある。
元のrefinementがpartialで抽出を増やすことは変わらない。
逆輸送が可能になった理由は、今回対応させる入力がallの範囲に絞られたことにある。

**例5.29（対象が存在しない場合の対照）.**
Sourceを一つ、Atomを $`ℕ`$、抽出族を $`ℕ`$ 全体とする恒等refinementを考える。
選択族が無限なのでcoreは存在しない。
定理5.25の両条件は成立するが、実際に往復するcoreの例にはならない。
例5.28では対象が存在することを確認したうえで、二つの振る舞いを比較している。

## 5.8 被覆と局所データを含む比較

Coreの比較には対象・操作・Lawが含まれる。
局所的な検査を同じ条件で比較するには、どの文脈で何を読み、どこを重ねるかも運ぶ必要がある。
第1章の完全幾何は、この被覆・重なり・係数・raw systemをcoreに加えた対象である。

**定義5.30（Refinementの上の幾何の射）.**
幾何 $`G\to H`$ の下段を $`E_{\mathrm{core}}^{\mathrm{ref}}`$ の射とし、
その上段のreading写像から文脈・方程式・Atom・軸の対応を取る。
幾何の成分には、定義1.30と同じ五条件を課す。
すなわち被覆要件の前向きの保存、overlapの比較、係数準同型、raw systemの輸送等式、
support・軸・observableの読みと自然性である。
これらは圏 $`E_{\mathrm{geom}}^{\mathrm{ref}}`$ と射影

```math
E_{\mathrm{geom}}^{\mathrm{ref}}
\xrightarrow{\ p_{\mathrm{ref}}\ }
E_{\mathrm{core}}^{\mathrm{ref}}
\xrightarrow{\ q_{\mathrm{ref}}\ }B^{\mathrm{ref}}
\qquad\text{(5.34)}
```

を定める。Exactな三段の圏は、底をexactな射に制限することでここへ入る。

**構成5.31（生成した逆輸送への幾何の引き戻し）.**
定理5.6または5.25で作ったcoreのlift $`K:P\to Q`$ と、$`Q`$ 上の幾何 $`H`$ を取る。
$`K`$ の上段とその生成された逆を $`u,u^{-1}`$、文脈の対応を $`\theta,\bar\theta`$ とする。
$`P`$ 上の幾何 $`K^*H`$ を次で作る。

| データ | 引き戻し方 |
| --- | --- |
| 被覆の要件と可視性 | Atom・方程式・軸を前向きに送ってから、Hの述語を読む |
| 二文脈のoverlap | θでHへ送り、Hのoverlapを取り、指定した準逆で戻す |
| 係数環 | Hと同じ環kを使う |
| raw system | 文脈Wで、HのθWにおける座標・関係・局所データを読む |
| support・軸・observable | 再添字づけに伴う同じcarrierの対応を使う |

Raw systemの制限写像には $`\theta`$ が送る射を使う。
恒等・合成則、関係多項式の保存は元のraw systemから従う。
Overlapの普遍性は文脈圏の同値によって戻せる。
こうして係数成分が恒等である射

```math
\widehat K:K^*H\longrightarrow H
\qquad\text{(5.35)}
```

を得る。この射は $`p_{\mathrm{ref}}`$ に関して強いcartesian射である。
実際、下段で $`K`$ を通る射に対し、被覆の条件は定義した逆像の条件へ戻り、
raw systemの等式は $`u^{-1}`$ の再添字づけで戻る。
局所データの比較写像も生成された両側逆で戻せる。
これらが因子を構成し、同じ逆を合成することで一意性が従う。

**定理5.32（同じ幾何から作る二つの逆経路）.**
命題5.27の点と実現台の条件を固定し、$`D_1`$ 上のcore $`Q`$ に幾何 $`H`$ を置く。
二経路で構成5.31を繰り返すと、幾何 $`H_B,H_P`$ と射
$`K_B:H_B\to H`$、$`K_P:H_P\to H`$ が得られる。
その間に自然な比較 $`m_H:H_B\to H_P`$ があり、

```math
K_Pm_H=K_B,
\qquad p_{\mathrm{ref}}(m_H)=m_Q
\qquad\text{(5.36)}
```

を満たす。$`m_Q`$ は、式(5.33)の二経路の端点を標準同型で揃えたcoreの比較である。
生成した両経路について $`m_H`$ は可逆であり、係数成分は $`1_k`$ である。

**証明.**
二経路のcoreの射は、それぞれ二つの強いcartesian射の合成である。
底の平方が可換なので、その始点と終点を揃えた比較 $`m_Q`$ と逆が一意に得られる。
幾何の二経路も、構成5.31によるcartesian射の合成である。
まず下段で $`m_Q`$ を作り、その因子分解を上段へ持ち上げると $`m_H`$ を得る。
逆向きにも同じ手順を行い、一意性を適用すれば両側逆になる。
各段の係数写像は恒等なので、その比較の係数写像も恒等である。□

図式全体を比べるときには、有限の根付き図式と各頂点への道を取り、
同じ底の点のfiber圏内のcore図式、その上の幾何、係数 $`k`$ を固定する。
さらに第4章の二段の輸送データを与える。
すなわち、coreと幾何の各辺はそれぞれの射影に関して強いopcartesian射であり、
辺と指定比較の係数成分は恒等とする。
各頂点で定理5.32を適用し、同じsourceの辺と指定比較を両経路へ引き戻す。
その結果、生成比較は辺だけでなく、面の指定比較も対応づける。

```math
\begin{aligned}
m_w L^B_e&=L^P_e m_v,\\
m_{t(f)}u^B_f&=u^P_fm_{t(f)}.
\end{aligned}
\qquad\text{(5.37)}
```

第二式は $`K_P`$ と合成すると、両側が一つのsource比較を運んだ同じ射になる。
Coreのcartesian性、次に幾何のcartesian性で等式を反映すると得られる。
第一式も同様であり、道への自然性は生成辺から帰納的に従う。
指定比較を両経路で別々に選ぶ場合には、第二式は確認すべき追加条件になる。

**補題5.33（端点同型による解の移送）.**
二つの経路の図式と別のその表示の間に自然同型
$`b_v:\widetilde H_{B,v}\xrightarrow{\sim}H_{B,v}`$、
$`c_v:\widetilde H_{P,v}\xrightarrow{\sim}H_{P,v}`$ があるとする。
同型は係数を固定し、経路の射と指定比較を対応づけるものとする。
固定した下段比較・三角形・式(5.37)を満たす比較族 $`s_v`$ は

```math
\widetilde s_v=c_v^{-1}s_vb_v,
\qquad
s_v=c_v\widetilde s_vb_v^{-1}
\qquad\text{(5.38)}
```

によって両方向に対応する。下段比較と三角形の端点も同じ同型で揃える。

**証明.**
辺の自然性に $`b,c`$ の自然性を代入し、隣り合う逆を消去する。
指定比較の式と三角形にも同じ計算を行う。
空の道では恒等則、道の連結と面の貼り合わせでは結合則を使えば、全ての条件が保たれる。
式(5.38)の二式は互いに逆である。□

再選択とdefectにも終点で同じ共役を使うと、式(5.28)と同じ理由で、
消滅と再選択軌道が双方向に対応する。
この対応が使うのは、同じsourceから生成した経路と、成分を保つ端点同型である。
任意に与えた幾何の射では被覆要件や局所データの保存が前向きだけのことがあり、
逆向きの解の移送には式(5.38)を作る逆射が必要となる。

## 5.9 Lensとプロトコルで順序の交換を読む

抽象的な二経路をソフトウェアの操作へ結びつけるため、
第1章の独立な意味論に戻る。Lensでは、対象を絞っても更新がその範囲に収まること、
プロトコルでは、残した名前付き操作の全実行が対応することを確かめる。

**命題5.34（Lensのviewの制限）.**
三法則を満たす全域lens $`g:C\to V`$、$`p:C\times V\to C`$ と部分集合 $`W\subseteq V`$ に対し、

```math
C_W=\{c\in C\mid g(c)\in W\}
\qquad\text{(5.39)}
```

と置く。読取りと更新の制限は $`C_W\to W`$ の全域lensを定める。
さらにlens同型 $`(h,u):(C,V)\to(C',V')`$ と $`W'\subseteq V'`$ に対し、
$`h`$ はlens同型

```math
(C_{u^{-1}(W')},u^{-1}(W'))
\xrightarrow{\sim}(C'_{W'},W')
\qquad\text{(5.40)}
```

を制限によって与える。

**証明.**
更新後の読取りは $`g(p(c,w))=w`$ なので、$`w\in W`$ なら更新後も $`C_W`$ に属する。
三法則の等式をこの部分集合で読めば、制限後の三法則を得る。
次に $`g'h=ug`$ より

```math
h^{-1}(C'_{W'})=C_{u^{-1}(W')}.
\qquad\text{(5.41)}
```

従って $`h`$ と $`h^{-1}`$ が対象の集合を対応づける。
更新の等式 $`h(p(c,v))=p'(h(c),u(v))`$ もそのまま制限される。□

**例5.35（四状態での制限と更新）.**
命題5.34の計算を、四状態の積lensで確かめる。
表示値を $`V=\{0,1\}`$、
更新で保たれる成分を $`R=\{0,1\}`$ とし、積lens
$`C=V\times R`$ を使う。
読取りは第一成分を返し、更新は第一成分だけを書き換える。
変更先の表示値を $`V'=\{A,B\}`$ とし、
全単射 $`u`$ は0をA、1をBへ送る。
第二成分の符号化も0・1から1・0へ入れ替える対応と、選択する表示値を

```math
h(v,r)=(u(v),1-r),\qquad W'=\{A\}
\qquad\text{(5.42)}
```

とする。元の表示値0の状態を選んでから対応させても、変更先で表示値Aの状態を選んでも、
同じ二状態に達する。制限後の更新は選んだviewに閉じ、$`h`$ は更新も保つ。
この例では、二経路を比べる際に「どの状態を残すか」と「どの更新を許すか」を同時に指定している。

これはlensの意味論内での制限である。
Coreの基底変換として使う際には、第1章の役割別のAtom・operation・Lawへの構成を行い、
底のexactnessと操作保存の図式を照合する。
式(5.40)の意味保存だけから、被覆や局所データの選択まで一意に決まるわけではない。

**命題5.36（プロトコルの制限とadapter）.**
第1章の表示されたプロトコル圏を $`𝒫`$ とし、
残す頂点・操作とその間の関係からなるプロトコルの包含を $`j:𝒬\to𝒫`$ とする。
二つの実現 $`F,F':𝒫\to{𝐒𝐞𝐭}`$ と意味保存adapter $`a:F\Rightarrow F'`$ は、
制限 $`Fj,F'j`$ とadapter $`aj:Fj\Rightarrow F'j`$ を定める。
比較の三角形や可換なadapter平方も制限によって保たれる。

**証明.**
残した生成辺 $`e:x\to y`$ について、元の自然性
$`a_yF(j(e))=F'(j(e))a_x`$ を使う。
恒等と有限の合成へ帰納的に延ばせば、全実行に自然性が成立する。
残した関係は元の圏でも等しい道なので、実現はその関係を保つ。
三角形と平方の等式は頂点ごとの等式を制限すればよい。□

モノリスの分割の例では、全体のプロトコルから、
取消要求・在庫予約の解除・取消完了と、それらの間の関係を残す。
分割前後の実現を与え、各操作についてadapterの自然性を確認すれば、
これらを連結した取消の実行にも対応が得られる。
この部分を選ぶ際は、在庫サービスが担う操作も含める。
そうして初めて、サービスをまたぐ取消処理を比較の対象にできる。
取消完了と予約解除の状態に関するLawは、対応する状態の上で併せて確認する。

通信の失敗や再試行を新たな操作・状態として読む場合は、それらを含むプロトコルと対応を指定する。
比較の整合性は選んだ操作と関係についての性質であり、
対象外の操作も含む図式については、例5.20と同じく別に確かめる必要がある。

## 5.10 二つの経路と正規化を含む生成比較

最後に、第6章で分析する比較を、ここまでの構成から定める。
必要なのは、同型な結果がどこかにあるという主張ではなく、
同じ入力からどの射が作られたかを追えることである。

**構成5.37（完全幾何の二経路）.**
式(5.14)のexactなpointed pullback square、有限の比較図式、その面 $`z`$ とcochain $`\omega`$、
$`b_1`$ 上の対応するcore $`P_z`$、可換係数環 $`k`$、$`P_z`$ 上の幾何 $`G_z`$ を固定する。
幾何は、被覆要件・overlap・raw systemを含めて指定する。
第4章のcanonicalな幾何の輸送と構成5.31を用い、

```math
\overline D(G_z)=(\pi_2)_!\pi_1^*G_z,
\qquad
\overline V(G_z)=\sigma_2^*(\sigma_1)_!G_z
\qquad\text{(5.43)}
```

を作る。添字の上下は幾何全体への操作を表す。
二経路とも係数環を $`k`$ に保つ。

完全幾何の標準比較 $`\overline\alpha_z:\overline D(G_z)\xrightarrow{\sim}\overline V(G_z)`$
は、式(5.18)に対応する三角形を満たす射として作る。
構成5.31のliftとcanonicalな幾何の輸送は、上段と局所データの比較に両側逆を持つため、
幾何の単位と余単位も可逆となる。
従って式(5.17)を幾何で行った三段の構成は可逆である。

この比較は、§5.8の二つの逆経路の比較からも得られる。
まず $`G_z\to\sigma_1^*(\sigma_1)_!G_z`$ という単位を $`\pi_1^*`$ で引き戻し、
$`(\pi_2)_!`$ で送る。
次に $`(\sigma_1)_!G_z`$ から同じ平方を逆向きにたどる二経路を比較し、
最後に $`(\pi_2)_!\pi_2^*\to1`$ の余単位を使う。
この途中で別のliftの選択を使った場合は、構成5.31から作る端点同型を前後に入れる。
順序は、単位、始点の同型、逆経路の比較、終点の同型、余単位、である。
式(5.36)と単位・余単位の三角形を代入すると式(5.18)の幾何版を得るので、
一意性により同じ $`\overline\alpha_z`$ となる。

**命題5.38（Coreへの射影の整合性）.**
幾何を忘れる関手 $`p`$ と生成された端点同型を
$`j_D:p\overline D(G_z)\xrightarrow{\sim}DP_z`$、
$`j_V:p\overline V(G_z)\xrightarrow{\sim}VP_z`$ と書く。
このとき

```math
j_V\,p(\overline\alpha_z)=\alpha_{P_z}\,j_D.
\qquad\text{(5.44)}
```

**証明.**
幾何のliftを射影すると、生成に使ったcoreのliftになる。
選択が異なる場合も、$`j_D,j_V`$ はそれらの一意な比較である。
幾何版の式(5.18)を射影し、この比較で揃えるとcoreの式(5.18)が得られる。
その射は一意なので、定理5.11のmateに一致する。□

**定義5.39（Configurationを保つ正規化）.**
Core $`P`$ は、configuration $`C`$ ごとに対象 $`\mathrm{Form}_P(C)`$ を選んでいる。
任意の対象 $`A`$ を、同じconfiguration上の選択対象へ送る写像を

```math
n_P(A)=\mathrm{Form}_P(C_A)
\qquad\text{(5.45)}
```

とする。対象形成の条件から $`C_{n_P(A)}=C_A`$、$`n_P^2(A)=n_P(A)`$ である。
この写像をcoreの射にするため、次の条件を $`\mathrm{Ad}(P)`$ とする。

- 全文脈・対象・方程式添字・Atomで、残差が $`A\mapsto n_P(A)`$ によって変わらない。
- $`\mathrm{Op}_P(A,B)`$ と $`\mathrm{Op}_P(n_P(A),n_P(B))`$ が同じ型であり、その同一視がconfiguration写像を保つ。
- Invariantの添字と種類を保ち、述語型では全対象で真偽を保つ。関数型では各invariantにつき一つの値域の全単射があり、全対象で元の値と正規化後の値を対応づける。
- 全てのsignature軸で、座標値が $`A\mapsto n_P(A)`$ によって変わらない。

このとき、対象には $`n_P`$、operationには上の型の同一視、
Atom・文脈・方程式添字・軸には恒等を使い、coreの自己射 $`N_P`$ を定める。
Configurationを保つためdetector codeも恒等に保たれる。
幾何 $`G`$ には、さらに係数・support・軸・observableの恒等写像を使って
自己射 $`N_G`$ を定める。被覆・overlap・raw systemの等式は恒等の比較で成立する。

**構成5.40（同じ診断から選ぶ生成比較）.**
固定した $`z,\omega,P_z,G_z`$ に対し、sourceで使う自己射を

```math
S_{z,\omega}=
\begin{cases}
N_{P_z},&\omega_z\ne1\ \text{かつ}\ \mathrm{Ad}(P_z),\\
1_{P_z},&\text{それ以外}
\end{cases}
\qquad\text{(5.46)}
```

で選ぶ。この選択は数学的な場合分けであり、$`\mathrm{Ad}(P_z)`$ の有限判定手順を仮定しない。
完全幾何でも、同じ条件で $`N_{G_z}`$ または恒等を選び、$`\overline S_{z,\omega}`$ と書く。
次に、実際の二番目の経路でこの自己射を運ぶ。

```math
\begin{aligned}
E_{z,\omega}&=V(S_{z,\omega}):VP_z\longrightarrow VP_z,\\
\overline d_{z,\omega}
 &=\overline V(\overline S_{z,\omega}):
 \overline V(G_z)\longrightarrow\overline V(G_z),\\
\beta_{z,\omega}&=E_{z,\omega}\alpha_{P_z},\\
\overline\beta_{z,\omega}
 &=\overline d_{z,\omega}\overline\alpha_z.
\end{aligned}
\qquad\text{(5.47)}
```

これは、指定したcochainの成分が恒等でないときに、許された正規化を組み込む一つの生成規則である。
Cochainとして現在のraw defectを選ぶこともできる。
構成に用いるsquare・面・cochain・係数・source geometryは、二経路で共通である。
同じ射影と端点同型の下で

```math
j_V\,p(\overline d_{z,\omega})=E_{z,\omega}j_V,
\qquad
j_V\,p(\overline\beta_{z,\omega})=\beta_{z,\omega}j_D
\qquad\text{(5.48)}
```

となる。第一式はsourceで同じ正規化を選んだことと、輸送の射影整合性から従う。
第二式は第一式と式(5.44)を合成したものである。

ここで三種類の比較が揃った。

| 比較 | 何から決まるか | 確認すること |
| --- | --- | --- |
| canonicalなα | 輸送と引き戻しの普遍性 | 二経路の三角形を満たし、可逆である |
| 別に指定したa | 実装や読みの選択による比較 | 三角形を満たすか、αとの差が何か |
| 生成比較β | 同じ入力のαと、診断が選んだ正規化 | 正規化を組み込んだ後の可逆性と像 |

たとえば、分割後の同じconfigurationを持つ複数の設計表現を、一つの標準表現へ揃える処理は、
必要な操作とLawを保っていても、元の表現の区別を戻せないことがある。
式(5.47)は、その処理をどちらの経路に、どの条件で加えたかを明示する。
第6章では $`N_P`$ と $`N_G`$ の射としての冪等性を示し、
この生成比較がいつ可逆で、可逆でないとき何を像として残すかを調べる。

## 本章のまとめ

基底変換は、共通の条件に対応する入力を作り、その入力へ構造を引き戻す構成である。
Exactな底射では、Atomの逆再添字づけにより任意のtarget coreへのcartesian liftが得られる。
これと第4章の輸送は随伴同値をなし、その単位と余単位から作る
Beck–Chevalley mateが、二経路を可逆に比較する。

複数の変更を扱う場合は、底の図式の関係を先に揃える。
個々の平方から変更先の全ての関係が従うかは、epiによる消去条件と個別の関係を分けて判断する。
整合する図式上では、終点群・cochain・辺の再選択が同じ輸送から対応し、
defectの消滅と再選択軌道への所属を保存・反映する。

Refinementでは、逆輸送の条件は実現台での抽出の反映であった。
変更先で新たに読むAtomがあれば、そのままでは逆輸送できない。
一方、今回対応させるsourceでは抽出が一致するなら、doctrine全体がexactでなくても逆輸送できる。
被覆と局所データも同じsource geometryから生成することで、比較を完全幾何まで揃えられる。

冒頭のモノリスの分割では、注文取消の部分から作った分割案と、
全体を分割した後で取り出す取消の部分を比較する。
コードレビューでは、取消要求・在庫予約の解除・取消完了という操作の対応と、
「取消完了なら、対応する在庫予約も解除済み」という条件が保たれるかを確認する。
在庫サービス側の処理まで含めて範囲を選ぶことが、この確認を可能にする。

本章の比較は、このような設計変更と範囲の選択を、対象・操作・Lawの構造として扱うためのものである。
Lensでは選んだ範囲に更新が収まる条件を、プロトコルでは残した操作の全実行の対応を示した。
分割に伴う通信・失敗・再試行を読む場合にも、それらを含む入力と保存条件を明示する。
さらに設計表現の正規化を行うなら、その処理を含む生成比較を調べる。
本章で構成した $`\beta=E\alpha`$ は、そのための比較射である。
次章では、正規化が残す情報と可逆性の関係を明らかにする。
