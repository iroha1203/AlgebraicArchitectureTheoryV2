# G-127：可逆な操作のholonomyと持ち上げの実装設計

[GOAL A–E](../../goals/G-127-aat-reversible-protocol-holonomy.md)を、
道の輸送、根での分類、実際の変更群、意味論への接続、有限構成へ分解する。
以下の新規宣言名・ファイル名は設計案である。既存宣言の型と利用条件は
[再利用対応表](reuse-map.md)に置く。

実装先を `research/lean/ResearchLean/AG/ProtocolHolonomy/`、
名前空間を `AAT.AG.ProtocolHolonomy` とする。

## 1. 構成の依存関係

| GOAL | 主な新規構成 | 証明を接続する先 |
| --- | --- | --- |
| A | 可変fiberの辺作用、`Lift F u`、対の群 `ChangeGroup F H` | 元の状態上の全単射と可視射影 |
| B | 逆向きを含む道の輸送、根での正規化、holonomy、中心化群表示 | 全閉路の輸送と、すべての辺を保つ変更 |
| C | `RootSolutions F u` と持ち上げの全単射 | 射影の像、実際の核、右torsor |
| D | 根・木の変更、実行圏への降下、恒等操作への特殊化 | 独立な `ProtocolRealization`、既存FixedF宣言 |
| E | 全域森、生成置換、中心化・持ち上げの有限判定 | B・Cと同じ入力・出力の停止と正確性 |

主な証明鎖は `A → 道の輸送 → B → C` とする。
Dの意味論構成はAから、有限表の全域森構成はグラフ入力から進められ、
最後に同じ `Lift F u` へ接続する。有限構成の仕様は§7に集める。

## 2. 原始入力と実際の変更群：A

グラフには、名前付き辺・始点・終点だけを持つ既存の `FixedFDirectedMultigraph` を使う。
可視変更には `FixedFGraphAutomorphism` とその群構造を使う。
型付き辺は `FixedFProtocolConnection.TypedEdge Q v w` とし、元の辺名を保つ。
この型付きグラフに `Π` を加えた `ProtocolSchema` を構成する。

`ReversibleData` のデータは頂点ごとの `Fiber v` と
`edgeEquiv e : Fiber (s e) ≃ Fiber (t e)` とする。有限性と生成経路等式の成立を
GOAL Aの入力条件として保持する。経路の輸送はこれらの全単射から構成する。
`H` の経路合同保存は、各 `u∈H` が各生成等式を実行圏内の等式へ送る条件で表し、
生成合同全体の保存との同値を示す。生成等式リストそのものの置換は要求しない。

`Lift F u` はGOAL (A1)を満たす頂点ごとの全単射族とする。
外延性は各頂点・各状態での値で与える。恒等、合成、逆を構成し、合成は(A2)、逆は

```math
(u,\varphi)^{-1}=(u^{-1},\chi),
\qquad
\chi_v=(\varphi_{u_V^{-1}(v)})^{-1}
```

とする。式中のfiberの同定は可視置換の逆法則による。
依存型の同定はこの基本APIに集め、以後は辺・道での評価式を使う。
`Σ_v Fiber v` 上の全単射へ送る写像と可視成分を合わせて
`ChangeGroup F H → H × Equiv.Perm (Σ v, Fiber v)` を構成する。
この写像の単射性と合成の評価式で群法則を確認する。

`verticalGroup` は `Lift F 1` の点ごとの合成、`projection` は可視成分への射影とする。
`verticalGroup ≃* projection.ker` を各頂点の写像を保って構成する。
この段階では `H` 全体への射影の全射性を用いない。

## 3. 道の輸送とholonomy：B

### 3.1 根へ移す式

型付きグラフの `Quiver.Symmetrify` と `Quiver.Path` を使い、元の辺を正向き、
追加された逆向き辺を逆全単射で解釈する。`transport γ` を道の帰納法で構成し、
空道・合成・反転・可視変更による付け替えの評価式を証明する。
この逆向き辺は輸送のための形式的な辺であり、`Π` の実行圏は元の有向辺から作る。

連結成分は既存の `FixedFComponent Q` を使う。
`FixedFUndirectedReachable` と、逆向きを含む道の存在の同値を証明する。
根での計算には、各成分の根と根から各頂点への道を持つ `RootedPaths` を用いる。
根への道は空道とする。全域木の唯一の道から、このデータを構成する。
分類の補題はこの道の族について先に証明し、GOAL Bには任意の根・全域木を代入する。

`P_v=transport τ_v` とする。同じ成分内の道 `γ:v→w` を

```math
N(\gamma)=P_w^{-1}\circ F(\gamma)\circ P_v
```

で根のfiber上の置換へ移す。`γ` の後に `δ` を進む道を `γδ` と書くと、

```math
N(e)=M_e,\qquad N(e^{-1})=M_e^{-1},\qquad
N(\gamma\delta)=N(\delta)N(\gamma)
```

が成り立つ。これを道の長さで帰納し、すべての `N(γ)` が辺から生成した部分群に
入ることを示す。根で閉じる道では `P_r=id` なので `N(γ)=F(γ)` となる。
逆方向には各 `M_e` の閉路 `γ_e` を使い、閉路の合成・反転で積・逆に対応させる。
これで(B1)の群と全閉路の輸送の群の一致を得る。

### 3.2 中心化群との群同型

holonomyを `Subgroup.closure` で構成し、
`Subgroup.centralizer_closure` により中心化条件を各 `M_e` との可換性へ移す。

1. `α∈verticalGroup` の辺の可換式を逆向き辺・道へ延長し、
   `α_v P_v=P_v α_r` を得る。閉路について根の値が各 `M_e` と可換であることを示す。
2. 中心化する根の置換族 `a_j` から(B2)の逆写像を作る。
   `T_e=P_t M_e P_s⁻¹` を代入し、`a_j M_e=M_e a_j` によって(A1)を証明する。
3. 根での評価と復元の両逆法則を証明する。根での評価は点ごとの積を保つので、
   得られた全単射を `MulEquiv` にする。

`Aut_Q(F)` の群構造はAで定めたものを使い、中心化群との同型を群構造の定義にしない。

## 4. 持ち上げ条件、像、torsor：C

`RootSolutions F u` は根の全単射族と(C1)の各辺の等式だけを持つ。
根の行き先は `F(u(r_j))` とし、`u(r_j)` が選んだ根に一致することは仮定しない。

持ち上げの辺の等式を道へ延長して、根での制限
`liftToRoots : Lift F u → RootSolutions F u` を作る。
逆写像 `rootsToLift` は(C2)とする。その辺の等式には

```math
T_e=P_{t(e)}M_eP_{s(e)}^{-1},\qquad
T_{u(e)}=F(u\tau_{t(e)})\,F(u\gamma_e)\,F(u\tau_{s(e)})^{-1}
```

を使い、(C1)を代入する。任意の `u` に対して、元の木の道を移した `uτ_v` を使う。
行き先で別に選んだ木の道への置換はDの表示変更で扱う。
両逆法則は根での空道と、持ち上げの道に沿う自然性から証明する。

`H_lift` の部分群構造には `projection.range` を使い、根での全単射から

```math
u\in\operatorname{range}(p)
\iff \operatorname{Nonempty}(\operatorname{Lift}_F(u))
\iff \operatorname{Nonempty}(\operatorname{RootSolutions}_F(u))
```

を示す。これでGOAL Cの条件で定めた集合と同定する。
射影をこの像へ制限し、Aの実際の核の同定を用いて(C3)を構成する。

fiberには右から核を掛ける。既存の `GroupHomRestriction` の一般定理を、
元の射影、定義域の全群、値域 `H_lift` に適用する。
Leanの左作用APIには核の反対群 `ᵐᵒᵖ` を使う。
自由性・推移性を `Lift F u` へ移し、作用の値が `φ_v∘α_v` になることを証明する。
二つの持ち上げ `φ,ψ` の間の一意の核元は `α_v=φ_v⁻¹∘ψ_v` として読み戻す。

## 5. 選択の変更と整合：D

古い根から新しい根への道を `κ_j`、その輸送を `q_j` とする。
holonomyは `g↦q_j g q_j⁻¹` で共役となり、分類の座標は

```math
a'_j=q_j a_j q_j^{-1},\qquad
b'_j=F(u\kappa_j)\,b_j q_j^{-1}
```

で移る。中心化群・持ち上げの座標変更は、古い座標から全頂点の変更を復元し、
新しい根で評価する写像として定義する。この定義と上式の一致を示す。
木だけを変えた場合も、同じ全頂点の変更を経由する。

恒等・合成・可視射影・核・torsor作用との整合は、両側を全頂点で評価して証明する。
三つの選択間の整合は制限・復元の両逆法則で示す。
holonomy群自体の共役には指定した `κ_j` を保持する。分類の座標変更が
道の選択によらないことは、二つの道の差が閉路となり、根の値が(B2)または(C1)を
満たすことから得る。

## 6. 意味論と既存結果への接続：D

### 6.1 商経路上の実現

`ProtocolSchema.pathFunctorOfEdgeAction` で元の `Fiber,T` から経路関手を作り、
生成等式の成立から `CategoryTheory.Quotient.lift` で実行圏へ降ろす。
定値一元観測を付けて `ProtocolRealization` を構成する。
可視変更からも同じ商への関手 `ρ_u` を構成し、`u` と `u⁻¹` の経路合同保存を使って
自己同型としての法則を示す。

`u*F := ρ_u ⋙ F` に対して(A1)の族を既存の `ProtocolRealization.GeneratorMap`
へ送り、`ext` によって `F→u*F` の自然変換を作る。
各成分の逆全単射も同様に延長して自然同型にする。
逆方向は `res` で各頂点を読み、`res_ext`・`ext_res` から全単射を得る。
商経路の自然性は既存の延長から導く。

異なる `u,u'` 上の同型の合成では、先に `u'` 上の同型を適用し、
その後 `u'` で再添字づけた `u` 上の同型を適用する。
各頂点での式が(A2)に一致することを示して、全対の群・射影・核・fiber作用を対応させる。

有限表の版では `ProtocolPresentation.decoder` を使う。
`Fin` 上の辺表を元の `T` と対応させ、`decoderObject_edgeAction` の `ULift` の
読み戻しによって同じ辺の等式を得る。任意の有限fiberの座標化を使うときは、
その全単射を頂点成分とする自然同型を構成する。

### 6.2 恒等操作への特殊化

`F(v)=K,T_e=id` ではすべての道の輸送と `M_e` を恒等に簡約する。
中心化群の表示を `FixedFComponentPermutationFamily Q K` と対応させ、
持ち上げ条件が空の制約になることから `H_lift=H` を得る。
恒等な隠れ状態変更が(A2)で合成を保つことを示してsectionを得る。

`Π=∅` で、元の辺名・各頂点の全単射をそのまま
`FixedFProtocolGroupConnection.ProtocolChangeGroup` へ送る群同型を作る。
既存の射影・section・核・fiberとの比較は、この群同型の評価式から証明する。
`Π` がある場合の分類はB・Cの特殊化から得る。

G-124の成分代表での読み取りは、代表を根に選んだときの `liftToRoots` と照合する。
`protocol_representatives_determining` の `Nontrivial K` はその既存判定を適用する箇所で
保持する。根での分類・復元そのものは空・一元の `K` にもB・Cを特殊化して得る。

## 7. 有限表からの構成：E

計算の入力は明示的な有限列挙を持つGOAL Eの表とする。
状態表を `Fin (card v)` で扱い、辺の全単射は順写像・逆写像の表で表す。
`Π` の成立と `H` の経路合同保存はAの入力条件として受け取る。
経路合同一般の等号判定を計算する手続きは必要としない。

### 7.1 名前付き辺を保つ全域森

未訪問の頂点を一つ根にし、現在の訪問集合とその外を結ぶ元の辺を探す。
見つかれば、向きと辺名を保持して未訪問側を子として加え、親への道を延ばす。
辺がなければその成分を閉じ、残る未訪問頂点を次の根として訪問済みにしてから再帰する。
未訪問頂点もなければ終了する。

訪問済み集合、根、各非根頂点の親と辺名・向き、深さを保持する。
新しい頂点だけに親を付けるため、親をたどると深さが減少する。
閉じた成分から外への辺がないことと到達可能性の帰納法で、得られた成分が
`FixedFComponent Q` に一致することを証明する。選択した辺が各成分の全域木であることと、
記録した道がその根からの道であることを示して `RootedPaths` へ接続する。
再帰の停止は未訪問頂点数の減少で証明する。

### 7.2 根での有限探索

各辺から `M_e` を計算する。中心化群は根の置換を列挙して各生成置換との可換性で
絞り込み、§3.2によってその列挙と(B2)を対応させる。
持ち上げでは、各根について `Fin (card r)→Fin (card (u r))` の写像表を列挙し、
全単射性と各辺の(C1)を判定する。逆写像表は有限探索で作る。
異なる成分の条件は独立なので、それぞれの根で解を探して組み合わせる。

`findLift u` は解があれば(C2)による全頂点の表を返し、なければ不存在を返す。
次の二つを独立な `Lift F u` に対して証明する。

- 成功時の読み戻しは(A1)を満たす。
- 任意の持ち上げを根で読んだ全単射は有限探索の候補に現れる。したがって、
  不存在を返すことと `Lift F u` が空であることが同値である。

各 `u∈H` への判定を列挙して `H_lift` の元を得る。
一つの成功表と中心化群の全元からCの右作用で全持ち上げを復元する。
生成置換と群の構成・射影・作用により、得られた有限表示をA–Cと対応させる。

`V=∅` では根の族を空族、各空fiber上の置換を唯一の空写像として処理する。
根とその行き先の状態数が異なる場合は全単射の候補が空になる。
探索は有限リストの再帰で停止させ、実行関数には `Classical.choose` や
`Fintype.ofFinite` による非計算的な選択を入れない。
計算に関する証明はGOAL Eの停止・正確性とし、計算量・RAM操作数・表の生成費用は追加しない。

## 8. 固定例の証明方針

入力はGOAL完了条件2・3のものを使う。

**持ち上げ不存在。** 一頂点二ループでは、可視交換に対する `a` の(C1)が
`b=τb` になる。`b` の全射性から `id=τ` が従うが、二元集合の一点で矛盾する。
両実現のholonomyは交換が生成する同じ群であることを示し、
群の一致と名前付きの同時対応の違いを具体化する。`findLift` の不存在判定へ接続する。

**非分裂。** 根を0、木の道 `τ_1` を辺 `a` とする。
根での解 `b=id` を(C2)へ入れ、可視交換の持ち上げ `g` を得る。
その成分は `φ_0=id, φ_1=τ` となり、全状態での作用は

```math
(0,0)\mapsto(1,0)\mapsto(0,1)\mapsto(1,1)\mapsto(0,0)
```

である。核は恒等と両fiberでの交換の二元で、`g²` が後者に一致することを示す。
根での分類から全群を `1,g,g²,g³` と列挙し、
`Multiplicative (ZMod 4)` との群同型と、射影の指数mod 2への対応を構成する。
可視交換のfiberは `g,g³` であり、どちらも平方が恒等でないため、sectionの群準同型性と
矛盾する。有限探索がこの二つのいずれかを返し、核作用が両者を交換することを示す。
