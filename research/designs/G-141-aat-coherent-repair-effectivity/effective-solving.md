# 有限還元・全解・幾何的像の有効計算

## D1 — 原始候補から有限式を生成する

入力はG-140 Eの原始規則 `H`、固定source `a`、型付き評価 `v` と条件 `P` である。有限算法を適用する域では、規則数・sort・operation・Law・候補係数が有限で、担体と実state mapのchartを有効に列挙できるものとする。有限free moduleのmatrix、有限集合の全関数、指定次数・supportの多項式mapなどが該当する。次数・supportの制限を使う場合はそれ自体を `H` に含め、その域の全候補を回収する。無制限次数の全regular mapを一つの有限chartで尽くすとはしない。

有限構文木を葉から評価し、補助定義は依存順に代入する。各Law、固定部分、原始操作の可換式、観測・評価条件、有限図式の可換式・移送式の残差を生成する。matrixなら各成分、多項式恒等式なら各単項式係数を取る。商環上のregular mapならG-140 B4のように、引き戻したLawの**ideal所属**を使う。単にambient多項式が零という条件へ強めない。

有限木・有限図式の走査は停止する。型・domainを保つ原始操作の可換式から、語の長さの帰納法で全操作語の可換式を得る。逆は一文字の語から従う。従ってこの検査は全語を有限長で打ち切るものではない。固定phase・domainの保持も同じ原始検査に残す。

得た解tupleから、chartの基底・商・matrix・state map `h`・語翻訳 `τ`・固定部分の同定を読み戻す。G-139の原始実現比較とG-140の全Hom比較により、読み戻した候補は `F_(a,H,P)` の実際の点であり、逆にその域の全候補はこのtupleを与える。補助逆元の値は一意、Law導出やideal所属の証明は射の余分なdataに数えない。複数chartの重複は元の実際のmapの等号で比較する。

## D2 — 無限表示から有限還元が導ける場合

ML性はA3の `lim¹` を消すが、有限段階で全自由が決まるとは限らない。例えば `H_n=R^(n+1)`、制限を末尾成分の削除とすると、全制限は全射でMLである。一方、`lim H_n=R^N` は任意の有限段階に独立な尾部を持つ。非零環なら有限射影は単射でない。

次は原始再帰構造から有限還元と停止を同時に導く十分条件である。計算可能な体 `k`、有限変数多項式環 `B=k[z_1,…,z_m]`、有限seed残差 `f_1,…,f_s`、有限個の明示的な `k` 代数代入 `σ_1,…,σ_d:B→B` を入力とする。全Lawは全有限語 `w` による `σ_w(f_i)=0` と宣言されているとする。有限idealを

```math
I_0=(f_1,\ldots,f_s),\qquad
I_{n+1}=I_n+\sum_{j=1}^d \sigma_j(I_n)
```

で生成する。ここで `σ_j(I_n)` は集合像が生成するidealを意味する。有限生成系の像を取れば次の有限生成系を計算できる。各元にはseedと代入語、さらに生成元の線形結合を保持する。

各段でGröbner所属判定により `I_(n+1)=I_n` を判定する。`B` のNoetherian性でこの増大列は有限段 `N` で安定し、算法は停止する。安定性は `σ_j(I_N)⊆I_N` なので、語の長さの帰納法で全 `σ_w(f_i)∈I_N`。逆に `I_N` の各生成元は有限個の原始Lawの組合せとして構成済みである。従って任意の `k` 代数 `R` で全無限Lawの成立と `I_N` の有限生成元の成立が同値となる。

例えば有限tuple `y_0` と再帰 `y_(n+1)=F(y_n)`、全 `q(y_n)=0` では、代入 `σ(q)=q∘F` を使う。各 `y_n` は `y_0` から一意に復元されるため、有限係数tuple・全Law比較・全解復元が揃う。尾部を一意に定義する宣言だけなら、定義の逐次消去で直ちに初期tupleへ戻る。停止の証明には「無限idealが有限生成」という存在だけでなく、この安定判定可能な有限代入構造を使った。

## D3 — 周期adapterの有限certificate

Bの整数adapterで `a_(n+p)=a_n` とする。周期 `p≥1` と有限blockを原始入力に持ち、`Q=2^p`、`A=Σ_(j=0)^(p−1)2^j a_j` と置く。有限個の遷移式 `c_n−2c_(n+1)=a_n` の加重和から

```math
c_0-Qc_p=A,\qquad
(Q-1)c_0+A=Q^m\bigl((Q-1)c_{mp}+A\bigr)\quad(m\ge0)
```

を得る。第二式は第一式を各blockに使う帰納法であり、有限blockの証明が全段を覆う。

整数解なら左辺は全 `Q^m` で割り切れ、零である。従って必要条件は `Q−1 | A`。逆に `c_0=−A/(Q−1)∈Z` と置く。`A_j=Σ_(k<j)2^k a_k` とすれば

```math
c_j=(c_0-A_j)/2^j\quad(0\le j\le p)
```

は整数である。実際 `c_0−A_j=Q c_0+Σ_(j≤k<p)2^k a_k` は `2^j` の倍数であり、`c_p=c_0`。このblockを周期的に延ばせば全解となる。二解の差は全 `2^n` で割り切れる `c_0` から決まるので整数では一意。有限certificateはblock和、割切りまたは非零剰余、復元blockとその周期等式である。

有理数では任意の `c_0∈Q` から再帰的に一意に延ばせ、全解は `Q` のtorsorとなる。周期解だけを全有理解と取り違えない。Cの交互列は `p=2,Q=4,A=1` なので整数解がないことを、この有限certificateでも検出する。

## D4 — 有限体とaffine全解

有限体 `F_q` 上では、D1–D2が生成した有限個 `m` の係数を全 `q^m` 通り列挙し、有限検査を実行する。全関数chartなら全関数の有限tableも列挙する。商環ideal所属を含む場合は各候補で所属を検査する。終端は有限候補数と各検査の停止から従い、正しさ・完全性はD1–D2の同値から従う。異なる候補名を意図的に残す規則では、その区別も出力する。

有理affine系 `Lx=b` は行基本変形で解く。非整合なら零行と非零右辺、すなわち `ℓL=0,ℓb≠0` という行ベクトルが不存在のcertificate。整合なら特解 `x_0` とkernel基底 `v_i` を出力し、全解を `x_0+Σt_i v_i` とする。行変形の可逆性が全解比較を証明する。

整数ではEuclid算法による行・列の可逆整数操作でSmith形 `ULV=diag(d_1,…,d_r,0,…,0)` を作る。`β=Ub` とすると、全解が存在する条件は `d_i|β_i` と残りの `β_j=0`。不成立時は非零剰余または零行の非零右辺がcertificateとなる。成立時は `y_i=β_i/d_i`、残りを自由整数として `x=Vy` を出力する。`U,V` の整数逆行列も保持する。Euclidの正の剰余の減少と有限matrixのpivot処理が停止を与える。

許容域・固定成分は初めから変数の削除または有限加群表示として系に入れる。解の自由変数を元の成分へ戻し、D1の同じ `h,τ` と操作を回復する。有限表示加群を商で表した場合は、その関係による同値も保持し、表示の自由変数の個数を実解の自由度としない。

## D5 — 多項式chart、ideal所属、実際の成立locus

以下の有効計算は `Q` 上の有限多項式chartとその幾何点を対象とする。可逆条件 `g≠0` は新変数 `u` と `ug−1=0` で表す。これは全係数環で「`g` がunit」と同値であり、field上では非零と同値である。

有限ideal `I=(f_i)` のGröbner基底計算では、新しい非零remainderを加えるたびleading monomial idealが真に増える。有限変数の単項式順序の整礎性とDicksonの補題による昇鎖停止から算法は停止する。全S-pairのremainderが零なら、leading termの相殺をS-pairで下げる帰納法がdivisionによる所属判定を証明する。生成元の組合せを追跡すれば、所属時に `f=Σh_i f_i` を出力できる。これはideal所属であり、radical所属への置換ではない。

原始mapの保存条件が、parameter `c` ごとに `h^*J_target⊆J_source` となる場合を考える。この条件を `h^*f=0` というambient条件へ強めず、次の有限層別で実locusを計算する。

有限型parameter空間のreducedな各既約成分で、その関数体上の `J_source` のGröbner基底を計算する。基底と原始生成元の相互表示、leading coefficient、S-pairの零remainder証明に現れる有限個の分母・非零係数の積 `g` をinvertする。このdense open `D(g)` では各fieldへの特殊化後も同じleading monomialと所属証明が有効である。引戻し残差をその基底で割り、remainderの全係数が零になる部分を取ると、そこが正確な所属locusとなる。

残る `V(g)` の有限個の既約成分について同じ処理を行う。各枝で真の閉部分へ移るため次元が減り、有限次元と有限分岐から停止する。有理係数の因子分解・idealの既約成分分解も有限多項式算法で実行できる。成分の重複は差集合で細分してlocally closedな分割へ直す。各片には元のideal表示と所属証拠を残す。これは幾何的成立集合の算法であり、非reducedな任意 `R` のHom関手全体をreduced locusだけで置き換える主張ではない。

有限chartの代数閉包上の空性は `1∈I` と同値である。前向きは[Nullstellensatz](https://stacks.math.columbia.edu/tag/00FS)、逆は評価で `1=0` となる不可能性から従う。所属のときは `1=Σh_i f_i` が不存在certificate。非空のときは元の方程式系を保ったfiberに点があり、閉点の有限代数的な残留体と座標をwitnessとして保持できる。

## D6 — 評価の全fiberと構成可能な像

D1の実評価式から `v:X→C` を作る。指定parameter `c` の全fiberは、元の全変数・全式に `v(x)=c` を加えた系である。可逆条件も補助変数付きで保持し、その解からD1の操作へ戻す。

像はparameter空間でD5と同じ層別を行い、未知変数についてfiber idealのGröbner基底を計算して求める。各dense openで、特殊化した基底が `1` を含むか否かを一定にできる。含まなければ全幾何fiberは非空、含めば空である。閉じた残部へ再帰する停止性もD5と同じ。したがって実際の像を有限個のlocally closed集合の和として計算できる。消去idealはその閉包を与えるが、ここでは分母・leading coefficientが消える枝も検査して実像を回収する。

例えば `xy=1` の `x` への像は `D(x)`。`x≠0` では `y=x^(-1)`、`x=0` では `−1=0` で空である。消去idealだけなら零idealとなり、閉包 `A¹` しか得られない。

各像の点では、同じ元のfiber方程式と射を保持する。代数的parameterでは有限代数的拡大上の座標を計算でき、一般の代数閉体 `Ω` のparameterでは `Ω` 上の元のfiberの点としてwitnessを読む。全像上で一つのregularな選択を得るとは限らず、必要な残留体拡大・局所選択を捨てない。C9の `z²=t` がその区別を示す。

`x²+1=0` はこの意味で非空だが `Q` 点を持たない。整数・有理数上の一般非線形方程式の全点探索を、代数閉包上の空性算法から結論しない。B–Cの無限adapterでも全有限段の非空性だけでは整数点を得られない。

順序付き評価では、評価mapと比較する前順序を入力に保持する。有限解の列挙ならその順序で比較し、affine・多項式の全解では同じparameter表示上に順序条件を引き戻す。任意の順序に対する最適元の存在や計算可能性まで、方程式の算法からは主張しない。

## D7 — 共有候補の四分類

Noetherianな `B` 上の有限型family `U→B,C→B` を取り、`W=U×_B C`、`π:W→C` とする。D1–D5の有効な有限還元で、Law・全操作語・評価条件の成立集合 `E⊆|W|` を構成可能集合として生成する。

補完の存在が条件なら、元の未知数を加えた全解family `F→W` を作る。有限個の変数・方程式・open chartで構成したので、この射は有限型である。各 `(u,c)` の全補完をそのfiberに保持し、`E` をこの射の幾何的像とする。[Chevalleyの定理](https://stacks.math.columbia.edu/tag/054K)により `E` は構成可能であり、D6の適用域ではその実像を計算できる。

`W` はNoetherian、`π` は有限型なので、再び同じ定理から

```math
P=\pi(E),\qquad N=\pi(|W|\setminus E)
```

は構成可能となる。幾何点 `c:Spec Ω→C` のfiberは有限型 `Ω` schemeである。構成可能部分が非空なら、そのlocally closedな非空片に閉点があり、代数閉性により `Ω` 点がある。従って次の四条件は集合の定義から厳密に同値である。

| `c` の所属 | 同じ候補を適用する実現fiber |
| --- | --- |
| `P\N` | 非空で、全幾何的実現が成立 |
| `N\P` | 非空で、全幾何的実現が不成立 |
| `P∩N` | 成立する実現と不成立となる実現が両方存在 |
| `C\(P∪N)` | 実現が空 |

幾何的field拡大で、有限型の非空な構成可能集合は非空を保ち、faithfully flatなfield拡大から非空を反映する。これを成立片・不成立片に適用すると、分類は幾何fiberの係数変更と可換である。任意の `R` 点での全称・存在量化はG-140 E4–E5の別の条件であり、この表から有理点等の分類へ置き換えない。

D6の有効な係数域では、`E` とその補集合の各locally closed片にその算法を適用して `P,N` を計算する。各像の点では元の `(u,c)` を回収し、成立理由が補完存在ならさらに `F_(u,c)` の実補完witnessを回収する。不成立側にはその同じfiberの空性証明または非零な原始残差を保持する。混在を報告するときは同じ `c` に対する二つの実現を保持する。

## D8 — 有限候補だけでは停止性は得られない

`F₂` 上に一つの候補係数 `c` と、固定列 `a_n∈F₂` による全Law `a_nc=0` を置く。`c=0` は常に解、`c=1` が解であることは全 `a_n=0` と同値である。

有限個の値を読む検査を全零列へ適用し、読んだ添字集合を `S` とする。`n∉S` の一点だけ1となる列は検査中の全応答が同じだが、正しい全解集合は異なる。従って任意列の全解を有限queryで常に返す算法はない。

さらに指定機械について、`a_n` を「`n` 段以内に停止した」指示値とする。この列は有効に計算できる。全解を返して常に停止する一様算法があれば、出力に `1` が含まれるかで非停止を、含まれないかで停止を判定でき、停止問題に反する。

生成idealは `0` または `(c)` で、いずれも有限生成である。それでもこの無限表示からどちらかを一様に判定することはできない。D2の有限代入による安定検出の条件がここにはない。全変更関手とその分類はこの入力も保持する。

非線形の高次liftでは、指定された有限Artin環の有限個のnilpotent層をEの平方零問題として順に扱える。各段の全解familyと次段への全lift fiberを保持して進み、一つのliftを任意選択して失敗しただけで全体の不存在とはしない。各層でD1の有限還元と係数域の算法が使えるなら、その指定環までの検査は停止する。全次数を有限で尽くすにはFの自由chartの構文上界等を別に証明する必要があり、有限表示を外したH7や全fragmentのB–Cをこの結論に含めない。
