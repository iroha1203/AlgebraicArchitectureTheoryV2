# 指定例と同じ原始写像による比較

## H1 — 許容域が変える全修復

`Q` 上で `c+d=1`、基準 `(0,0)` とする。原始残差の線形部分は `L(a,b)=a+b`。E6の式から、全変更域では

```math
(\Delta c,\Delta d)=(s,1-s),\quad s\in\mathbb Q.
```

`Δd=0` を固定すれば唯一の `(1,0)`、両方を固定すれば空である。Lawを既に満たす点の間の差、または観測 `c+d` を固定する補正は `ker L={(s,−s)}`。さらに一方を固定するとこの部分加群は零となる。従って全解と合法差分を、同じ原始式・許可成分から計算できる。

## H2 — 一次自由と二次障害、冗長Law

任意の体 `k`、`R=k[ε]/(ε²)`、`R'=k[ε]/(ε³)`、`M=(ε²)` とする。Law `t²=0` の `t=ε` は `R` 上の実現である。任意のambient liftは `ε+aε²` だが、その平方は `ε²≠0`。E3のJacobian作用は `2εM=0` なので、非零残差 `ε²` を補正できない。標数2でも同じ証明である。

一方、原点 `t=0` から双対数への一次liftは `t=aε` が全て許される。Law `t=0` では `a=0` だけなので、同じ基点でも一次自由が異なる。

`(t²,t³)` の全syzygyは `(t,−1)` の倍数である。実際 `at²+bt³=0` から多項式環で `a=−bt`。E2の許容残差は `(r_2,r_3)=(r_2,tr_2)` となり、第一成分への射影と `r↦(r,tr)` は相互逆である。基点が `t²=0` を満たすため、このmapはJacobian `(2t,3t²)` と一Lawの `2t` を比較し、`H⁰,H¹` を同定する。実際のliftでも `\widetilde t³=t\widetilde t²` が `M` 内で成立するので、障害も同じmapで一致する。

整数上の `(z²,2z²)` では同様に全syzygyが `(−2,1)` の倍数であり、残差は `(r,2r)`。第一成分への射影が一Law版との `H⁰,H¹` と指定障害の同定を与える。`F₂` への特殊化ではsyzygyは `(0,1)`、許容残差は `(r,0)` となる。第二Lawが恒等的に零になっても、この同じ比較は第一Lawの障害を保持する。

## H3 — 同じ基点の値・支持と異なるsyzygy

`k=Q[t]`、`R=k/(t)`、`R'=k/(t²)`、`M=(t)/(t²)≅Q`、基点 `x_0=x_1=x_2=0` とする。三contextのLawを

```math
f_1=x_1-x_0,\qquad f_2=x_2-x_1,\qquad f_3=x_0-x_2
```

とする。原始恒等式 `f_1+f_2+f_3=0` がある。Jacobianは

```math
d^0(a_0,a_1,a_2)=(a_1-a_0,a_2-a_1,a_0-a_2).
```

像は成分和が零の平面、kernelは対角 `Q`。E8により `H¹(T_raw)≅Q` で、その同型は成分和で与えられる。一方、syzygy `(1,1,1)` は `ker d¹` をこの平面に制限し、`im d⁰⊆ker d¹` でもあるから `H¹(D)=0`。原点をそのままliftすれば全Lawが成立する。

最後のLawを `f'_3=x_0−x_2−t` に変える。Jacobianと、各Lawの状態変数supportは同じで、基点のLaw値も全て零である。contextには共通の係数環 `Q[t]` を初めから保持するので、係数のreadingも同じである。しかし今度は `f_1+f_2+f'_3=−t` である。

生成元を可逆線形変換すると `(x_1−x_0,x_2−x_1,t)` となり、これは `Q[t,x_0,x_1,x_2]` のregular sequenceである。Koszul syzygyが全関係を生成し、その係数は基点で全て零。従って `d¹=0`、`H¹(D)=coker d⁰≅Q`。零tupleのambient liftの残差は `(0,0,−t)` で、成分和は `−t≠0`。これが同じE3の非零障害である。

各contextだけならliftできる。初めの二Lawは零tuple、第三は例えば `x_0=t,x_2=0` を取ればよい。しかし大域ではLawを足して `t=0` が必要となり不可能である。基点のLaw値とsupportの一致から、全syzygyやこの障害を復元することはできない。

## H4 — 二contextの差と相対障害

観測表示は自由座標 `T`、追加表示は `Y=T²,Y=0` とする。消去idealは `J=(t²)` なので、F2–F3の検出次数は `ν=2`。

`R=k[ε]/(ε²)` 上で `T=ε,Y=0` とし、任意の指定観測lift `T'=ε+aε²` を固定する。`R'=k[ε]/(ε³)` 上で、`Y=T²` のcontextには `Y=ε²`、`Y=0` のcontextには `Y=0` という局所liftがある。観測を固定すると各contextで `Y` も一意なので、合法な局所補正は `C⁰=0`。共有変数 `Y` の差の係数は `C¹=M=(ε²)` となる。

零Lawのcontextを左、定義Lawのcontextを右に並べると、右−左の差は `ε²`。conormalの生成元 `[t²]` の像も `κ_u([t²])=ε²` なので、このČech類とF4・E5の相対障害は同じmapで一致する。一次の観測liftの選び方 `a` に依存せず非零であり、大域liftはない。

## H5 — 高い初回検出次数

任意の `N≥1` に対し、自由観測 `T` と有限列

```math
Y_1=T^2,\quad Y_{j+1}=Y_j^2\ (1\le j<N),\quad Y_N=0
```

を取る。定義の逐次代入で `Y_j=T^(2^j)`、従って `J=(t^(2^N))`。多項式局所環でのorderは `ν=2^N` である。構文木の積で次数を加えるF7の上界も `2^N` なので、この上界は鋭い。

最初に失敗する指定試験は

```math
k[t]/(t^{2^N+1})\longrightarrow k[t]/(t^{2^N}).
```

右辺では全Lawを満たし、左辺の普遍観測liftの残差は `t^(2^N)≠0`。そのkernelを `m` が消し、全変数補正のLawへの寄与が零になるため、実現そのもののliftもない。

観測表示自身に `Y=T^N` を含め、追加Lawだけを `Y=0` とした場合は、観測局所環が `k[t]_(t)`、追加idealが `(t^N)` なので `ν=N`。追加Lawの見かけの次数1から、自由観測chartで消去した次数の代わりに上界を作ることはできない。

## H6 — 非flatな係数変更でのkernel

`Z[t]`、augmentation `t↦0`、`J=(2t²+t³)` とする。最低非零次数は `Z,Q` 上で2、`F₂` 上で3。二次商では

```math
D_2=\ker\!\left(
\mathbb Z[t]/(t^3)\longrightarrow
\mathbb Z[t]/(t^3,2t^2+t^3)\right)
=2\mathbb Zt^2.
```

抽象加群 `2Zt²⊗F₂≅F₂` は非零だが、`F₂[t]/(t³)` へのmapは零となる。変更後のkernelはその**像**であり零である。F8の像による係数比較と一致し、非flatなtensorがkernelをそのまま保存するという主張にはならない。

## H7 — 無限表示は全Artin試験でも検出されない

任意の体 `k` 上の原始式 `T_i=T_(i+1)²` から

```math
A_\infty=\operatorname*{colim}
\bigl(k[t_0]\xrightarrow{\,t_0\mapsto t_1^2\,}
k[t_1]\longrightarrow\cdots\bigr)
```

を作る。各mapは単射であり、非負dyadic有理数を指数に持つ単項式環 `k[t^q:q∈Z[1/2]_(≥0)]` の部分環として、このcolimitを同定できる。したがって整域で `t_0≠0`。

原点ideal `m=(t_i:i≥0)` では各 `t_i=t_(i+1)²∈m²` なので `m=m²`。原点で局所化しても同じ等式と `t_0≠0` が残る。局所化の分母は非零定数項を持つため、その最小指数は0である。

任意のresidue-`k` 局所Artin環 `(S,n)` と原点を持ち上げるmapを取る。`n^d=0` とし `2^N≥d` を選ぶと、各 `i` で

```math
T_i=T_{i+N}^{\,2^N}=0.
```

従って全有限Artin変形はaugmentationからの定値mapだけである。`T_0=0` を追加しても、全次数の比較は同じ一元集合の同値となる。

しかし `A_∞/(t_0)` の `t_1` は非零平方零である。平方は `t_0`、非零性は `t_1` の最小指数 `1/2` が `(t_0)` の非零元の最小指数 `≥1` と異なることから従う。原点局所化後も分母の最小指数0により同じ証明が通る。整域と非reduced環は同型でないので、両schemeも同型でない。F3のNoetherian有限表示の仮定を外せないことを、同じ原始Lawで示している。

## H8 — 三角形の全操作、holonomy、許容修復

`0→1→2→0` の三角形では

```math
d^0(\lambda_0,\lambda_1,\lambda_2)
=(\lambda_1-\lambda_0,\lambda_2-\lambda_1,\lambda_0-\lambda_2).
```

任意環で像は成分和零のtuple全体。逆向きには、そのtuple `(a,b,c)` に `λ=(0,a,a+b)` を与えればよい。従って `H¹(Γ;R)≅R` を `[r]↦−Σr_e` とすれば、G4の `o_b=[−b]` は `Σb_e` に対応する。

adapterの一周合成は `g_(Σb_e)`。これが大域apply係数 `i_λ` を固定する条件も `i_λ+(Σb_e)v=i_λ`、すなわち `Σb_e=0` である。`v` の第一成分が1なので零因子の場合も同じ同値となる。

`Z,Q` 上の `b=(1,2,−3)` の全解は

```math
\lambda=(t,t+1,t+3).
```

`b=(1,0,0)` は和1であり、大域操作がない。それでも各chartの局所操作とG2の層 `E_b` は構成できる。

後者を `Q` 上でoffset修復すると、全辺が許される場合は

```math
\Delta b_1+\Delta b_2+\Delta b_3=-1
```

という平面。一辺だけならその成分が `−1` となる一点、許可辺がなければ空である。どのoffset解にも、その後の全操作を同時に平行移動する `t∈Q` の一自由度が残る。

基準 `λ=0`、`b=(1,2,−3)` の頂点変更では、全解 `(t,t+1,t+3)` の固定成分が零でなければならない。固定頂点なしなら全 `t`、一つだけなら `t=0,−1,−3` の該当する一値。二つ以上固定すると相異なる二値を同時に要求して不能である。任意の許可頂点集合はこのいずれかなので、全ての場合を尽くす。

## H9 — 同じ候補fiberの四分類

`B=C=A¹_(Q,b)`、`U=D(b)×A¹_(Q,u)` とし、原始Law

```math
(b-1)((b-2)u-1)=0
```

の成立集合を `E` とする。`b=0` では `U_b` 自体が空。`b=1` では任意の `u` が成立、`b=2` では残差 `−1` となり全て不成立である。`b≠0,1,2` では `u=1/(b−2)` が成立、`u=0` では残差 `−(b−1)≠0` となる。

従ってD7の四集合は順に

```math
P\setminus N=\{1\},\quad
N\setminus P=\{2\},\quad
P\cap N=D(b(b-1)(b-2)),\quad
C\setminus(P\cup N)=\{0\}.
```

混在の二witnessは同じ `b` のfiberに属し、評価parameterだけから別々に選んだ実現ではない。

## H10 — Snapshotの同じ障害と特異性

[G-140 P](../G-140-aat-semantic-change-category/ledger-specialization.md)の原始台帳、固定 `p=B+C`、`δ=1−λ`、begin/finishを空語、applyを同じapplyへ送る翻訳を使う。G1のmarked比較により、これは一型の自由係数 `δ,μ` と同じfamilyである。

旧snapshotのBusy Lawは `g=μ(h−C)=0`、beginは `h=C` を保存し、applyは `g↦g−μδu`、finishのread差は `g`。従って全宣言domainの閉性と全語保存は `μδ=0` と同値である。必要性は零Idleからの `begin;apply_1`、十分性は各原始遷移と語帰納法による。

追加演算 `E=μδ`、Law `E=0` をF1で消去すると `J=(μδ)`。これで同じ意味保存係数fiberを `V(μδ)` へ同定する。体上の原点の局所次元は1、接空間は `m/m²` の次元2なので特異点である。orderは `ν=2`。各軸 `μ=0` または `δ=0` 上では任意の係数環・全次数で残差が零となる。

一方 `k[ε]/(ε²)` 上の `δ=μ=ε` はlawfulだが、`k[ε]/(ε³)` 上の任意の観測lift

```math
\delta=\varepsilon+a\varepsilon^2,\qquad
\mu=\varepsilon+b\varepsilon^2
```

で `μδ=ε²≠0`。同じ原始列のraw read差は `−μδ=−ε²` である。これは合法Busyへの閉性が失敗する証拠でもあり、不正な中間状態を合法経路として数えているのではない。

相対conormal mapは `κ_u([μδ])=ε²`。二context `E=0`、`E=μδ` の順に並べ、上記観測liftを固定すると、局所liftは `E=0` と `E=ε²` に一意で、合法補正は `C⁰=0`、差分係数は `C¹=(ε²)`。右−左が `ε²` なので、E5・F4の相対障害、二contextのČech類、消去後の残差がこの同じ評価mapで一致する。raw read差との比較は負号を持つ。

finishを `finish_snap(B,C,h)=(B+μh,C−μh)` とし、旧Busy Lawを除くG-140 P4の規則では、read差が恒等的に零でBusyは全 `R³` となる。同じ観測・状態比較・語翻訳に対する係数familyは全 `A²_(δ,μ)` なので、上の観測liftも全て存在する。旧Lawを固定してfinishだけを変えた場合は、applyの `−μδu` が残り、この修復にはならない。

## H11 — 評価条件と変更追加による成立回復

before、`p`、語翻訳を固定し、評価条件 `D(μ)`、`D(δ)` をG-140 E2の探索fiberとして課す。旧family `V(μδ)` では、`μ` がunitなら `δ=0`、`δ` がunitなら `μ=0`。従ってそれぞれのfiberは `G_m`、両方unitのfiberの表示環は零環、schemeは空である。全 `R` 点では、両方unitかつ `μδ=0` は `1=0` と同値で、非零環には解がなく零環には一つの点がある。

許容規則に係数 `ρ` と原始式

```math
finish_\rho(B,C,h)
=\bigl(B+\mu h,\ C-\mu((1-\rho)C+\rho h)\bigr)
```

を加え、そのread差からBusy Law `g_ρ=μ(1−ρ)(h−C)=0` を生成する。原始代入で

```math
begin^*g_\rho=0,\qquad
apply_u^*g_\rho=g_\rho-\mu\delta(1-\rho)u.
```

finishのread差は `g_ρ`、零Idleからの `begin;apply_1;finish_ρ` のraw read差は `−μδ(1−ρ)`。したがって全domainの閉性と全語保存は

```math
f=\mu\delta(1-\rho)=0
```

と同値である。

非零係数環上の全係数による座標面判定では `f=μδ−μδρ`。singletonの全座標面では零、`{μ,ρ}` と `{δ,ρ}` でも零だが、`{μ,δ}` では `μδ` が残る。F11–F12の極小不成立部分族は `{{μ,δ}}` である。全面でも多項式は非零だが、体上の固定配置 `(μ,δ,ρ)=(1,1,0)` は不成立、`(1,1,1)` は成立する。全座標面上の恒等式と一点での成立はこのように異なる。

Boolean係数ではF13の直交冪等元分解を使う。残差は不成立配置 `(1,1,0)` の冪等元そのものであり、その開閉成分が空となることが成立条件である。連結な非零環の0/1配置では、八配置中その一点だけが不成立。零環では全配置が一致する。

`μ,δ∈R` を固定し `ρ` を補正変数として許せば、全解fiberは

```math
\{\rho\mid\mu\delta(1-\rho)=0\}
=1+\operatorname{Ann}_R(\mu\delta).
```

よって常に非空で、`ρ=1` が一つの解である。この操作はBusy Lawの変更を許しており、旧不成立fiberへ解を制限するmapはない。従ってF12の実restrictionがある場合の不存在伝播と矛盾しない。

評価条件 `D(μδ)` を課すと `μδ` がunitなので `ρ=1` が強制され、全解は `G_m²_(μ,δ)`。このとき `g_ρ` は恒等的に零、Busyは全 `R³`、finishは `finish_snap` となる。旧Busy Lawを固定する規則ではapply閉性に `μδ=0` が必要なままなので、同じ評価条件の表示schemeは空である。体上の非零条件を、任意環上の単元条件と区別して計算した。これらはD5–D6の可逆条件と全fiberの直接の例でもある。

## H12 — 原子操作のadapterを拡張言語へ移せない例

`Q` 上で `g_1=I+vp` は `λ=μ=1` の原子台帳を `λ'=2,μ'=1` へ運び、全固定入力のapply・compactを可換にする。後者では `δ'=−1`。旧snapshotのraw遷移を零Idleから評価すると

```math
(0,0)\xmapsto{begin}(0,0,0)
\xmapsto{apply_1}(2,-1,0)
\xmapsto{finish}(2,0).
```

最後のreadは2で、beforeのreadは1。中間状態のBusy Lawも `1` であり、宣言された全域applyの合法性が失われる。原子操作のadapterから、この拡張phase protocolの比較を得ることはできない。

同じ `μ=1` の `compact_all(B,C)=(B+C,0)` についても

```math
g_1(compact_{all}(1,0))=(2,-1),\qquad
compact_{all}(g_1(1,0))=(1,0).
```

前者は `compact_all(1,0)=(1,0)` の後に `g_1` を適用し、後者は `g_1(1,0)=(2,−1)` の後に現在の `C` を引数として使った結果である。固定外部引数のtranslationの可換式は、このruntime引数の式を保存しない。比較する操作言語・phase・全domainを、同じ原始dataに保持する必要性が具体的に確認できる。
