# Atlas細分化と評価を含む全修復fiber

## F1 — 有限空間の縮約と同じ空間上の二被覆

まず三角形 `0→1→2→0` の頂点0を `0a,0b` に分ける。細graphの辺を

```math
t:0a\to0b,\quad 01:0b\to1,\quad
12:1\to2,\quad20:2\to0a
```

とする。粗側は六点、細側は八点のE1の有限空間である。`f:X_f→X_c` を `0a,0b,t↦0`、他の頂点・辺では同名の点へ送るmapとする。各頂点とincident edgeの順序関係は保たれるので `f` は連続である。

細側の同じ八点空間で、粗被覆の逆像は
`f^(-1)U_0=U_(0a)∪U_(0b)`、`f^(-1)U_1=U_1`、`f^(-1)U_2=U_2`。
これを四chartの細被覆と比較する。粗側の `E_b` を引き戻し、二つの0 chartに同じ座標を入れると、内部辺では `g_0=id`、他の辺では元の `g_(b_e)` がtransitionとなる。従って

```math
f^{-1}E_b\cong E_{b_f},\qquad
b_f=(0,b_{01},b_{12},b_{20}).
```

同型は局所座標の恒等であり、`p,v,j_μ` を保つ。従って `Ob,State` にも同じ比較を得る。逆像の0 chartは連結で、二つの局所座標が内部辺で恒等により貼られるため、そのsectionは一つの粗側座標に一致する。

## F2 — 実現・実操作・全修復の原始比較

原始表示で粗側の0の操作係数を二つのchartに代入し、内部辺のoffsetを0とする。内部辺の実操作Lawは `λ_(0b)−λ_(0a)=0` だから、逆に細側の合法操作から `λ_0=λ_(0a)=λ_(0b)` が一意に復元される。`μ`、他の操作、旧offsetはそのまま読む。この二つのmapは互いに逆であり、環の全 `R` 点で自然である。

粗側基準 `λ` は `p⁰λ=(λ_0,λ_0,λ_1,λ_2)` に送る。許容頂点 `A⊆V_c` はchart map `φ:V_f→V_c` の逆像とし、許容辺は旧辺の一意なliftとする。内部offsetは変更せず常に0とする。G-141 G5の同じ修復を、操作も含めて

```math
\mathcal F_c(R)=
\{(a,\Delta b)\in H_{V,c}\times H_{E,c}:
d_c^0(\lambda+a)=b+\Delta b\}
```

と表示する。片方を固定する修復は対応する成分を零にすればよい。細側の `\mathcal F_f` は同じ式から生成し、

```math
\Phi_R:\mathcal F_c(R)\longrightarrow\mathcal F_f(R),\qquad
(a,\Delta b)\longmapsto
\bigl(p^0a,\ (0,\Delta b_{01},\Delta b_{12},\Delta b_{20})\bigr)
```

で比較する。細側の内部式と基準値の一致から `a_(0a)=a_(0b)`。この共通値を粗側の `a_0` として復元すると許容条件も一致する。従って上のmapは全 `R` で全解の自然な同型である。

mapは加法を保つ。よって非空な修復fiberへの同次解の自由推移作用、offsetだけの解のfiber、その各点上の全操作の `H⁰` torsorをすべて運ぶ。固定頂点を含む場合も、二つの分割頂点は同時に固定されるため同じ証明である。

## F3 — Cochainと指定類

graphの向きで次を定める。

```math
p^0(x_0,x_1,x_2)=(x_0,x_0,x_1,x_2),\qquad
p^1(y_{01},y_{12},y_{20})=(0,y_{01},y_{12},y_{20}).
```

内部辺の差は零、他の辺の差は元の差なので `d_f⁰p⁰=p¹d_c⁰`。次数2は双方零である。これはF1の同じ空間上の被覆細分化による実Čech mapでもある。内部pairは粗側の対角pairへ写り、その正規化cochainは零になる。

H¹で全射であることを示す。細側cochain `η` に対し、頂点 `0b` の値だけを `η_t` とした `h` を取ると `(η−d⁰h)_t=0`。残る三成分は一意な `p¹y` である。単射性について、`p¹y=d⁰ξ` なら内部式が `ξ_(0a)=ξ_(0b)` を与え、`ξ=p⁰x`。よって `y=d⁰x` である。H⁰も同じ一致式から同型となる。これらは全 `R` 上の証明である。

さらに `b_f=p¹b` と `λ_f=p⁰λ` だから、実residualについて
`r_f=p¹r_c`、従って `o_f=p¹o_c`。Eの各cellの `av↦a e_(Law,0)` とこのmapは、旧cellの恒等と内部edgeの零で直接可換する。SAGAの増加pairの符号map `T_c,T_f` を入れると、Čech mapは `T_f^(-1)pT_c`。従ってSAGA、実Ob、整数診断、有理K0、指定類の全比較は同じ図式で可換する。

## F4 — 同じ支持からAtlasのC0–C6を証明する

共通のSourceを `S={s20,t,s01,s12}` とし、Law値はすべて `p(v)=0` とする。細readingは恒等、粗reading `q_c` は `t↦s01`、他は恒等で、targetは `{s20,s01,s12}`。どちらも全射かつadequateである。細側支持は

| chart | 支持 |
| --- | --- |
| 0a | `{s20,t}` |
| 0b | `{t,s01}` |
| 1 | `{s01,s12}` |
| 2 | `{s12,s20}` |

粗側支持は `S_0={s20,s01}`、`S_1={s01,s12}`、`S_2={s12,s20}`。chart mapは `0a,0b↦0`、他は恒等。旧edgeは同名のedgeへ、内部edgeは `none` へ送る。両nerveのface集合は空。各chartの支持像は対応する粗支持に含まれ、端点条件も成立するので `TargetSupportedNerveMorphism` を得る。

このSource mapは補正のラベルを比較する。F1の空間mapは内部edge点 `t` を頂点0へ送り、ここではSource `t` を `s01` へ送る。対象の異なるこの二つのmapが、Eの係数同定を通じて同じcochain mapを誘導することを証明する。

原始整数表示群もこのmapで比較できる。細側の `[e]` を粗側の `[q_c(e)]` へ送ると、細側の共有頂点relationは粗側の共有頂点relationまたは等号へ写る。逆は旧三辺の生成元を同名の細生成元へ送る。粗側0での `[s20]=[s01]` は細側では `[s20]=[t]=[s01]` と導けるため、この逆もwell-definedである。二つの合成は `[t]=[s01]` を使って恒等となり、E2の和による `Z` との同定と可換する。従って実Obの係数比較に隠れた追加生成元はない。

既存 `ConditionC` の各fieldは次のように放電する。値blockは唯一の `(Law,0)` である。

| 条件 | この入力での証明 |
| --- | --- |
| C0：支持像 | 0上の二支持の像の和集合は `{s20,s01}`。1、2上は元の支持そのもの。従って粗支持の各targetは、かつそのときに限り細支持の元を持つ。 |
| C1：block fiber | 0のfiberは二頂点と内部辺からなる連結な一辺のtree。1、2のfiberは一点。各fiberは非空で、任意の二頂点を辺の対称な道で結べる。 |
| C2：edge lift | 各粗edgeは同名の細edgeを唯一のliftとして持ち、支持とlabelも一致する。 |
| C3：fiberの有理1-cycle | fiber外の係数は定義により零。0のfiberでは端点の流入和＝流出和を片端に適用すると内部辺の係数も零。一点fiberも全係数零。従ってcycleは零で、空のface線形結合で表せる。 |
| C4：face lift | 粗側face集合が空なので全称条件は成立する。 |
| C5：edge liftの一意性 | 旧三辺はそれぞれ異なる粗edgeへ写り、内部辺は `none`。従って一つの粗edgeの二つのliftは等しい。 |
| C6：self-loop | 粗側三辺の端点は相異なるため、self-loopを前提とする条件は成立する。 |

これで `generatedComparisonH1Map_bijective` を**この同じ入力**に適用できる。定理の係数は `Q` である。そのgenerated cochain mapは粗側のlabel係数を対応する旧cellで読み、退化edgeでは零なので、E3の比較の下でF3の `p` に一致する。したがってこの既存の単射・全射は実Čech比較と可換し、指定類 `κ_b` を運ぶ。

## F5 — 探索fiber、評価条件、全候補

[G-140 E](../G-140-aat-semantic-change-category/conditional-changes.md)の探索fiberを、F2の**同じ**許容係数と修復適用から作る。候補の全係数を保持し、細側では粗係数を原始代入で複製して、分割chartの対応する係数に一致Lawを課す。操作係数の一致は内部adapter Lawそのもの。ほかの指定した変換係数を候補に含める場合も、その同じ代入と一致Lawを表示に含める。

F2の逆mapは分割chartの共通係数を読むため、この候補比較はaffineな表示のmapと逆mapを持つ。必要な可逆条件の局所化とも可換する。全 `R` 点での自然な同型は、G-140の独立な実変更modelへのdecodeとも可換する。これはここで指定した修復規則の候補fiberであり、一般の変更圏が保持する全sort mapのHomはG-140のままである。

粗側の変換係数と修復後の操作のregular式から `v_c:\mathcal F_c→T` を作り、条件 `P↪T` を有限個の等式と可逆条件で定めるlocally closed subschemeとする。F2の自然な全解同型を `Φ` と書き、細側では `v_f=v_c∘Φ^(-1)` と同じ式を引き戻す。すると全 `R` に自然に

```math
\mathcal F_c\times_TP\ \cong\ \mathcal F_f\times_TP .
```

実際、候補を代入すると修復適用後の旧操作が同じで、新しい二操作も一致するから評価値が等しい。逆は追加一致Lawから一意に回復する。指定障害へのmapもF3の残差の等式により可換である。順序付き評価の場合は値域とその順序を同じものに取り、値そのものが等しいので、全候補間の比較も保存・反映する。

groupoidを使う場合、対象だけでなく局所状態の同型にも同じ複製と一致を課す。内部恒等adapterとの可換性が二つの同型成分の一致を強制するので、射も一意に回復できる。従って全候補groupoidの同値であり、自己同型も保持する。

## F6 — 有限回の細分化

cycleの任意の頂点を同様に分ければ、同じ証明が適用できる。有限反復では各元の頂点の逆像はtreeで、全内部offsetは零である。tree辺の一致Lawに沿って、操作と許容候補はそのfiber上で一定となる。各fiberの共通値を取るmapが全反復の逆である。

複製と旧辺のliftは恒等を保ち、合成した複製は一度に行う複製と等しい。tree上の零cochainを入れるmapも同じ合成則を持つ。従って指定類、全修復、評価fiber、torsor作用の比較は恒等・合成に整合する。Atlas側では各段階にC0–C6を適用し、generated comparisonの合成則で同じmapを得る。

## F7 — 情報を落とすreadingで必要な条件

Law評価のadequacy、C0–C6によるH¹同型、全修復fiberの同値は別の命題である。体 `k` 上で、Law・観測に現れないrank1の補助sortを原始表示に加え、そのsortにoperationを置かず、全線形state map `h_t(x)=tx` を許容する。この実際の変換係数 `t` を `A¹_k→Spec k` で忘れる。Law値とnerveは同じなのでadequacyと恒等のC0–C6は成立する。しかし全候補のfiberは `A¹` と一点で異なる。評価 `v(t)=t` は定数でないため一点へ降下しない。条件 `t=1` も同じ忘却fiber内の0と1を区別するため、粗候補の条件として同じ判定を返せない。

一般の候補reading `r:Y→Z` では、指定 `R` で像 `r_R(Y(R))` と全fiber `r_R^(-1)(z)` を保持する。評価 `v_R` が集合として像へ降下する必要十分条件は、各fiberで一定であること。存在はその共通値を取り、一意性は像への全射性による。schemeのregular評価を運ぶ場合には、さらに `v=\bar v r` を満たす**regularな** `\bar v` を構成するか、有効なdescentを証明する。幾何点上の一定性だけではその結論を出せない。

条件だけを運ぶなら `Y×_TP=r^(-1)(Z_P)` という部分関手の等式を証明すればよい。条件がfiberで一定でない場合は、「fiberのどれかが満たす」と「fiberの全てが満たす」を別々の像として扱い、元の全候補fiberを残す。有限表示と有効な係数域ではG-141 Dの算法で有限候補または構成可能な幾何像を求め、各fiberの元の方程式も出力できる。任意の `R` 点の存在を、幾何像の非空性から代用することはしない。
