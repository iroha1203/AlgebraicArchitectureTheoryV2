# 観測に相対的な判定と十分な追加観測

## G1 — 原始実現・共有規則・全解

G-139の原始表示を、独立なmodelへのencode/decodeを保って係数的に実現する。その全実現を `U` とし、選んだ宣言・係数・termの評価とrestrictionからreading `q:U→B` を生成する。Lawを後で検査するraw表示を使う場合は、それを `U` の入力に明記する。

[G-140 E1–E3](../G-140-aat-semantic-change-category/conditional-changes.md)の許容規則に、共有する係数、固定宣言の像、語翻訳の選択、必要な補助dataを記述し、その型付きtupleの族を `C→B` とする。これは指定規則の共有候補であり、G-140の変更圏の全Homをこのfamilyへ制限するものではない。

`Z=U×_BC` 上で候補を生成し、次の二通りの判定を構成する。

- 状態map `h`、語翻訳 `τ` 等まで規則が与える場合は、それらを実際に評価し、両端のLaw、domain、原始操作、観測、固定部分、評価条件を満たす組を `E_dir⊆Z` とする。
- `c` が共有規則のparameterだけを持つ場合は、残る**全ての実際の**状態map・翻訳・補助選択を保持したG-140の全解族 `F→Z` を作り、`E_exists,R(u,c)⇔F_(u,c)(R)≠∅` とする。

線形mapではmatrix、regular mapでは全supportを含むG-140の表示を用い、商環では引き戻したLawのideal所属を検査する。原始操作の保存とdomainの閉性から、語の長さの帰納法で全許可語の保存を得る。有限語長での打切りは用いない。

候補tupleから独立な変更へ戻ると、同じ `h,τ` と操作、sourceの同定を回復する。逆に独立な変更はその全dataを同じtupleへencodeする。従って `F` のfiberは実際の全補完の族であり、存在判定はこの忘却写像の**指定R点での像**である。直接指定した候補を忘れれば存在判定へ写り、存在の証人から直接指定した候補を回復できる。

以後 `E_ok` はこのどちらかを明示して用いる。どちらも原始評価の自然性と解の係数移送により部分関手である。存在判定の証拠には、問われた各 `(u,c)` の `F` の点を保持し、真偽だけを実際の変更の代わりとしない。一般の関手をscheme、存在の像を層とする追加主張はしない。

## G2 — 指定Rでの三つの量化

可換環 `R` と `b∈B(R)` を固定する。
`U_b(R)={u:q(u)=b}`、`C_b(R)={c:c↦b}` を作り、整合実現 `w∈U_b(R)` を保持する。三つの条件は

```math
\begin{aligned}
\operatorname{Valid}_R(c)
&\iff\forall u\in U_b(R),\ E_{{\rm ok},R}(u,c),\\
\operatorname{Pointwise}_R(b)
&\iff\forall u\in U_b(R)\ \exists c\in C_b(R),\
 E_{{\rm ok},R}(u,c),\\
\operatorname{Common}_R(b)
&\iff\exists c\in C_b(R)\ \forall u\in U_b(R),\
 E_{{\rm ok},R}(u,c).
\end{aligned}
```

共通候補の証人 `c` を各 `u` に用いれば各実現での可解性を得る。逆はW4で偽である。存在型の `E_ok` では、それぞれの `u` に対する補完も同じ `F_(u,c)` から保持する。一つの規則parameter `c` の共有は、実現ごとの補完が一つのregularな選択になることまでは要求しない。

`U_b(R)=∅` なら、指定候補の全称条件と各実現での可解性は空虚に真、共通候補の存在は `C_b(R)≠∅` と同値である。これを整合実現の不存在として記録する。`U_b(R)≠∅`、`C_b(R)=∅` なら後二者は偽である。

同型を持つmodelでは、sourceの同定を含む2-fiberを用い、評価の同型不変性を原始式から検査する。真偽は対象の同型で変わらず、補完の対象・射を全て `F` に保持する。同値な `U,C,F` の図式では対象を相互に運んで三量化を保存・反映でき、fully faithful性により補完の全射と自己同型も対応する。真偽の証明や検証用の `w` を、候補の余分な自己同型として加えることはしない。

## G3 — 全係数移送で保存される判定

固定した宇宙内の全 `R` 代数を用い、

```math
\mathcal R(R)=
\left\{c\in C(R):
\forall(R\to S)\ \forall u\in U_{b_S}(S),\
E_{{\rm ok},S}(u,c_S),\ b=\pi(c)\right\}
```

を定める。これは `C` の自然な部分関手である。実際 `c∈mathcal R(R)`、`R→S` に対し、任意の `S→T` と `u∈U_(b_T)(T)` を取ると、元の条件を合成 `R→T` に適用できる。原始評価の自然性により `(c_S)_T=c_T` だから `c_S∈mathcal R(S)`。恒等・合成の則もこの制限で成り立つ。

確定判定の候補は
`mathcal R_dec(R)={c∈mathcal R(R):U_(π(c))(R)≠∅}`
とする。実現 `w` は係数移送で `w_S` へ送れるので、これも部分関手である。候補としての条件は非空性であり、検証用には `w` と全称条件の証明・各補完の証人を別に出力する。

恒等環射から `mathcal R(R)⊆{c:Valid_R(c)}`。W6は、同じ原始残差で全 `k` 点に成立しても冪零元を持つ `k` 代数上では不成立となる例を与える。したがって固定 `R` の全称条件を、係数移送に自然な全称条件へ置き換えるには上の追加検査が必要である。

## G4 — Reading、全解、選択の比較

細reading `q':U→B'` と `r:B'→B`、`q=rq'` を指定し、`C'=B'×_BC` とする。細側では実現 `u` と `b'=q'(u)`、元の候補 `c` を組にする。原始term、状態map、語翻訳の生成は同じtupleを評価するので、細側の `E_dir` と全補完 `F` は粗側からのpullbackになる。存在型でも、対応する同じ組のfiberは同型だから全 `R` で真偽が一致する。

固定 `b'∈B'(R)` に対し `U_(b')(R)⊆U_(r(b'))(R)`。粗fiberで全実現に成立する候補は細fiberでも成立する。細fiberが非空ならその実現証人も保持できる。逆を一つの細fiberだけから結論することはできず、全粗実現の持上げ・被覆を別に必要とする。全係数移送の条件にも、任意の `S` 上で同じ包含を使える。

実現・共有候補・全補完を相互に回復できる比較では、G2の同値の証明を各 `R,b` に適用する。原始表示の改名は宣言・termの再帰的な改名とその逆、係数移送は同じ式の評価、恒等・合成は代入則である。従って候補のdecode、残差、reading、全解のmapは同じ図式で可換する。係数移送に際して固定 `R` の量化を自動的に保存するとはせず、全称条件にはG3を使う。

局所的に選んだ補完は、重なり上の同型とcocycle、固定規則・観測・評価の一致を持つとき、G-141 Cの有効なdescentの適用域で族のsectionへ貼れる。点ごとの非空性だけはこのdataを与えない。W5では同じ平方根の局所選択から、その差のcocycleと大域選択の不存在を計算する。

## G5 — 追加観測のkernel条件

固定 `R` で `X=U(R)×_(B(R))C(R)` とし、`χ_E:X→Bool` を `E_ok,R` の真偽とする。一般の存在命題からこの関数を作る際は古典論理を使い、算法が得られる条件はG6で指定する。

原始termとrestrictionから追加観測 `e_i:U→V_i` を生成する。`J⊆I` について

```math
Q_J:X\longrightarrow Y_J,\qquad
(u,c)\longmapsto\bigl(q_R(u),c,(e_{i,R}(u))_{i\in J}\bigr)
```

とし、`Y_J` はこのmapの像と定義する。従って `Q_J` は全射で、既存 `Reading` の入力となる。異判定対は

```math
\mathcal D_R=
\{(u,u',c):q(u)=q(u')=\pi(c),\
\chi_E(u,c)\ne\chi_E(u',c)\}.
```

次が必要十分である。

```math
\chi_E\text{ が }Q_J\text{ を通じて因子分解する}
\quad\Longleftrightarrow\quad
\forall d=(u,u',c)\in\mathcal D_R,\
\exists i\in J,\ e_i(u)\ne e_i(u').
```

**証明。** 因子分解があれば、全 `e_i` が等しい二点は `Q_J` の同じ値を持つので判定も等しく、異判定対ではない。逆に右辺が成立し `Q_J(u,c)=Q_J(u',c')` なら、候補・粗観測・全追加値が等しい。判定が異なれば右辺に矛盾するため同じ判定を持つ。各 `y∈Y_J` の任意の逆像の判定を `barχ(y)` と置けば、選択に依存せず `χ_E=barχQ_J`。全射性からこの `barχ` は一意である。□

これは [Reading.factors_iff_kernel](../../lean/ResearchLean/AG/CanonicalResolution/Reading.lean) に `Source=X` を入れた同じ証明である。既存APIはSourceと値域を同じuniverseに置くため、`X : Type u` では `f=ULift.up∘χ_E : X→ULift.{u} Bool` として適用する。`ULift.up` の単射性からkernel条件は元のBool評価と同じである。有限 `X` では一Law・値域 `ULift.{u} Bool`・この評価の `FiniteLawFamily` を作れば、同じ条件が `adequate_iff_kernel` に一致する。有限な元の実現集合だけでなく、候補も含めた `X` が派生判定のsourceである。

元のLaw値へのadequacyは、その元の評価がreadingのkernelで一定である条件。共有候補の判定へのadequacyは、ここで生成した別の評価 `χ_E` の条件である。W6の一定readoutと変動する保存残差は、前者だけから後者が従わないことを示す。

## G6 — 全ての包含極小な十分観測を得る有限算法

実現・候補・観測添字が有限で列挙可能とする。G-141 Dの有限還元と同じ有効係数域で各原始観測を評価し、その値の等号判定も生成する。具体的には有限個の `e_i(u)=e_i(u')` を同じ型付き構文の評価へ加え、scalarなら差が零、有限tuple・matrixなら全成分の差が零、有限集合ならtableの値が等しいという検査へcompileする。有限体、整数・有理数、指定された代数的係数では、同じ体・環の演算と等号判定で実行できる。さらに全保存条件と、存在型なら同じ全補完fiberの非空性に停止する決定手続きを得ているとする。例えば有限体の有限候補全列挙がこれを満たす。任意の値域での観測の等号や補完の存在判定を、有限な `U,C` だけから推論することはしない。

全 `(u,u',c)` を列挙し、原始評価に戻して `mathcal D_R` を作る。各異判定対 `d` に

```math
D_d=\{i\in I:e_i(u)\ne e_i(u')\}
```

を付ける。成功判定には実際の `h,τ` 等の補完、失敗には有限検査の失敗証拠を保持する。G5により十分集合は、すべての `D_d` と交わる `J` に正確に一致する。

1. `D_d=∅` があれば、その `(u,u',c)` と全観測値の一致を返す。これは全観測でも判定を定められない証人である。
2. それ以外では全 `2^|I|` 部分集合を列挙し、すべての `D_d` と交わるものを残す。
3. 各残った `J` について、すべての `j∈J` の `J\{j}` が不十分である場合だけ出力する。その不十分性を示す異判定対も出力する。

全走査は有限で、各判定が停止するので算法は停止する。出力の十分性はG5による。十分性は集合包含について単調なので、一要素を除いたすべての集合が不十分なら、任意の真部分集合も不十分。逆に包含極小な十分集合は列挙に現れ、どの一要素除去も不十分なので必ず出力される。従って全ての包含極小解を過不足なく得る。

異判定対がなければ空集合が唯一の包含極小解である。これは最小要素数の解だけを返す算法ではない。W4の `{e₁}` と `{e₂,e₃}` のように異なる大きさの極小解を両方返す。

## G7 — 幾何点での四分類

Noetherian基礎環 `k` 上の有限型schemeの図式 `U→B←C` と、原始有限表示から得た構成可能集合 `E⊆|Z|`、`Z=U×_BC` を取る。全補完が有限型 `F→Z` で表示される存在問題では、その**幾何的像**を `E` とする。`π:Z→C` により

```math
P_+=\pi(E),\qquad P_-=\pi(|Z|\setminus E)
```

を定める。射は有限型、空間はNoetherianなので、[Chevalleyの定理](https://stacks.math.columbia.edu/tag/054K)により両者は構成可能である。

幾何点 `c:Spec Ω→C` の有限型fiberで、非空の構成可能部分は非空locally closed片を持つ。その片に閉点があり、`Ω` が代数閉体なので `Ω` 点を得る。従って

| 候補の所属 | 同じ観測に整合する実現 |
| --- | --- |
| `P_+\P_-` | 非空で全て成立 |
| `P_-\P_+` | 非空で全て不成立 |
| `P_+∩P_-` | 成立する実現と不成立の実現がある |
| `C\(P_+∪P_-)` | 整合実現がない |

各行は `E` とその補集合のfiberの非空性から従い、四者は互いに素で全候補を尽くす。指定した代数閉体上ではG2の各固定候補の分類と一致する。

G-141 D5–D7の有効な係数域と有限表示では、同じ原始式の像・補集合の像を層別計算し、この四集合を計算できる。任意のNoetherian基礎環というだけでは計算可能性を結論しない。各像の点では元の全fiber方程式を保持し、補完の座標から独立な変更を復元する。

この分類は指定した一般の `R` 点の判定とは異なる。W5では幾何的補完があっても有理補完がなく、W6では全幾何点で零となる残差が冪零元として非零になる。同じ式の評価と係数移送を通してこれらを比較し、幾何像を `F(R)→Z(R)` の像やG3の全代数条件に置き換えない。
