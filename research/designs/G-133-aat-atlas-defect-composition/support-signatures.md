# G-133：台署名・商・Law族の普遍性

[GOAL E](../../goals/G-133-aat-atlas-defect-composition.md#e-台署名の商普遍性欠損の輸送)の構成を具体化する。
§4の対象・射・加法的評価はカードが参照する固定targetの一部である。
以下の新規構成・同定は証明義務である。

## 1. 全セルから署名を作る

粗targetをQ、細targetをQ′、比較因子を $`\pi:Q'\to Q`$ とする。
$`\Omega_M`$ は粗細それぞれのchart・edge・faceの六つの型の直和である。
辺の両端、面の三辺、比較のchart写像・部分edge/face写像を固定したまま扱う。

各 $`t\in Q`$ の $`S_t`$ は次のmembershipで決まる。

| セル | $`S_t`$ に属する条件 |
| --- | --- |
| 粗セルc | $`t\in\operatorname{support}(c)`$ |
| 細セルc′ | $`\exists t'\in\operatorname{support}(c'),\ \pi(t')=t`$ |

したがって $`\alpha(A)`$ は、粗A-subnerveと細 $`\pi^{-1}A`$-subnerveの
名付きセルをそのまま与える。辺・面の台は交差なので、選択セルは端点・面の辺に閉じる。
mappedな細セルの像が選択粗セルに入ることは、既存の台適合定理から示す。
`none` は同じ原始比較の宣言を保持する。これで制限された比較幾何を復元できる。

セルの**個数**だけ、粗側だけ、次数1だけの署名にはしない。
もとのセル名を保持しているため、incidenceと部分比較を独立に選び直す余地がない。

## 2. 閉包と二つの普遍性の向き

Galois接続は、任意のXについて
$`\bigcup_{t\in A}S_t\subseteq X`$ を各tの条件に展開して証明する。
その後 $`\alpha\gamma\alpha=\alpha`$ から閉包の冪等性と
$`\sigma(A)=\sigma(\mathrm{cl}(A))`$ を得る。

$`\operatorname{im}\alpha`$ は空集合と有限和集合に閉じる。
一方 `Fix(cl)` のjoinは $`\mathrm{cl}(B\cup C)`$、bottomは
$`\mathrm{cl}(\varnothing)`$ である。台に一度も現れないtargetがあれば、後者は非空になりうる。
共通部分がそのまま像半束のmeetになるという追加主張は置かない。

カードEの商の圏で、任意の $`(L,p,d)`$ からΣへの射は
$`h(l)=d(l)`$ を $`\operatorname{im}\alpha`$ にcorestrictして作る。
$`p`$ の全射性から $`d(l)`$ が必ず像にあると分かり、一意性も同じ全射性から従う。
復元図式は次の向きである。

```text
P(Q) --p--> L --h--> Σ_M --ι--> P(Ω_M)
  \----------------σ-->/
          d = ι ∘ h,  α = ι ∘ σ
```

これは「セル選択を復元する他の商よりΣが粗い」という終対象の主張である。
別に、$`\alpha(A)=\alpha(B)\Rightarrow k(A)=k(B)`$ を満たすjoin準同型kは
$`\bar k:\Sigma_M\to L`$ を一意に持つ。こちらは通常の商の因子化で、射の向きが逆になる。
二つを同じ普遍性の言い換えとして混ぜない。

同じ署名ならセルsubtype間の同値を元のセルを固定して作り、incidence・部分比較・
全次数のcochain引き戻しを可換にする。この同値がCの錐へ誘導する同型まで証明する。
$`D_A=D_{\mathrm{cl}(A)}`$ をLeanのdefinitional equalityとして要求せず、
証明引数とsubtypeのtransportを含む指定の同型で表す。

## 3. 包含による制限と三段の共通署名

Σは名付きセル集合の包含で順序づける。$`s\subseteq t`$ なら、各側のセル包含から
cochain関数の制限を作る。辺・面に閉じることから微分と可換になり、原始比較の制限も可換になる。
これを `Σ_Mᵒᵖ ⥤ CochainComplex (ModuleCat ℚ) ℤ` の二つの関手と自然変換へまとめる。
錐を実chain mapの可換正方形から作り、H¹のkernel・cokernelを点ごとに取る。
対象ごとに任意の基底・同型を選ぶだけでは射の可換性は得られない。

三段で使う $`\Sigma_{012}`$ は三つのnerveの全セルを段階・次数・セル名で区別する。
段階iのセルcにtが対応する条件は
$`\exists a\in\operatorname{support}_i(c),\ \pi_{0i}(a)=t`$ とする。
この署名から(0,1)、(0,2)の署名、および $`A_1=\pi_{01}^{-1}A`$ に対する(1,2)の署名へ
射影できる。逆に(0,2)だけでは中間セルを復元できないことがW1からも分かる。

六項列の各射は同じ制限と可換になり、相殺写像も自然変換になる。
有限多段は全段のセルを含む同じ方式で構成する。pairごとに独立のAを選んで合成しない。

## 4. Lawの再添字づけと加法的な普遍性

ここでは幾何Mを固定し、有限な**selected block族**を扱う。
対象は有限集合Λと部分集合族 $`(A_\lambda\subseteq Q)_{\lambda\in\Lambda}`$。
各blockの比較は既存A-subnerveから生成する。
実Law族からはSourceで発生するLaw・値をΛとし、その値のfiberを割り当てる。
selected block族一般はLawの全fiber分割より広い対象であることを明記する。

$`\Lambda_+=\{\lambda:\sigma(A_\lambda)\ne\bot\}`$ とする。
二対象間の射は $`\Lambda_+\simeq\Lambda'_+`$ という全単射βで、
各λの署名がβ(λ)の署名と等しいものとする。
零署名のblockは両側とも零複体であり、削除・挿入はそのcanonicalな同型で扱う。
射は元のセルを固定したblock比較同型と直和の並べ替えを誘導する。
任意の線形同型を追加の射としては採用しない。

この対称モノイド圏の積は添字の非交和、単位は空の族である。
同型類は有限supportの多重度関数

```math
m:\Sigma_M\setminus\{\bot\}\longrightarrow\mathbb N
```

で分類される。これから生成比較の直和、Dの錐の直和をcanonicalな並べ替え同型の下で
復元する。各ラベルを元の署名blockへ送る射は、既存cochain同値と比較自然性を通す。
単なる署名の集合への圧縮は重複度を失う。

加法的評価の対象は、任意の可換加法モノイドBと、次を満たすblock族の評価Iとする。

1. 上記の射で不変である。
2. 添字の非交和を加法へ、空の族と零署名の単独blockを零へ送る。

任意の $`v:\Sigma_M\to B`$、$`v(\bot)=0`$ に対し
$`I((A_\lambda)_\lambda)=\sum_\lambda v(\sigma(A_\lambda))`$ を定めると上記条件を満たし、
すべてのIはこの形に一意に表されることを証明する。
この自由可換モノイドの標準普遍性と、実Lawからの比較・錐の復元を接続する。
診断 $`J_L`$ は $`B=\mathbb N\times\mathbb N`$ の適用である。

値vの一意性は**単独selected block**への評価で決まる。
非bottom署名は非空Aで実現され、そのAは指示Lawのtrue blockで得られる。
指示Law全体の評価はAと補集合のblockの和なので、Law全体の合計値だけから
各vが一意に復元されるという主張へ置き換えない。

## 5. 診断一致による同一視との照合

比較複体の構造を復元する同値関係、抽象的な複体同型、H¹比較の同型、
欠損の次元一致、欠損の零性一致を別々に扱う。
カードEが最粗性を主張するのは最初の対象・射である。
[W2](witnesses.md#2-w2台の商と診断値だけの同一視)では
$`\sigma(A)\ne\sigma(B)`$ かつ $`J_A=J_B=(0,0)`$ となる。
その診断値による商からは異なる名付きセル集合を復元できず、Eの圏の対象にはならない。
また、診断値の等号が一般にjoin合同になるとは仮定しない。
