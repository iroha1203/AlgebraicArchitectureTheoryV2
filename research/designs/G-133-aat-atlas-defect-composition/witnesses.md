# G-133：同じ原始入力から構成する指定例

[GOAL W](../../goals/G-133-aat-atlas-defect-composition.md#w-同じ生成経路を通る指定例)が参照する
固定データ・同時成立条件を定める。ここに記す評価は実装時に証明するtargetである。
行列はLaw・台・セル・部分比較から導く出力であり、H¹写像を原始入力にはしない。

全例で辺ijはi→jと向ける。面ijk（i<j<k）は
`faceEdge0 = ij`、`faceEdge1 = ik`、`faceEdge2 = jk` とし、
$`d^0x(ij)=x_j-x_i`$、$`d^1z(ijk)=z_{ij}-z_{ik}+z_{jk}`$ を使う。
セル表は既存 `CoverNerve`、支持表は `TargetSupportedNerve`、射の表は
`TargetSupportedNerveMorphism` に構成し、既存生成APIを通す。

## 1. W1：非零の中間欠損が直接比較で消える

### 1.1 一つの原始Sourceと三つのreading

$`\mathrm{Source}=\{s_{abc}:a,b,c\in\{0,1\}\}`$ とし、
$`q_0(s_{abc})=a`$、$`q_1(s_{abc})=(a,b)`$、$`q_2(s_{abc})=(a,b,c)`$ とする。
各全射性と二つの真の細分化をこの表から証明する。
Lawは一つ、評価は $`\ell(s_{abc})=a`$。値0・1の二ラベルがあり非定数である。
全三段で全chart台をその段の全targetとする。K1から各実在辺の台も全targetとなる。
各ラベルの部分集合は非空で、各ラベルが三段の全セルを選ぶ。

| 段階 | chart | edge | face |
| --- | --- | --- | --- |
| 0 | 0,1,2 | 01,02,12 | 空 |
| 1 | 0,1,2,3,4 | 01,02,12,03,04,34 | 空 |
| 2 | 0,1,2 | 01,02,12 | 空 |

原始の比較セル表を次で固定する。

| 写像（細→粗） | chart | edge |
| --- | --- | --- |
| $`M_{01}`$ | 0,1,2を同じ番号へ、3,4を0へ | 01,02,12を同名辺へ `some`、03,04,34を `none` |
| $`M_{12}`$ | 0,1,2を同じ番号へ | 全三辺を同名の段階1の辺へ `some` |

face写像は空型からの写像である。退化辺03・04・34の両端は段階0の0へ写り、
chart台の適合は各reading因子が全targetを送ることから従う。
直接比較の**セル写像**は同名セルを保つ。readingは異なるので、
`M02 = identityMorphism` という型の違う等式は要求しない。
直接生成したHomがcanonicalなLaw座標同定の下で恒等になることを示す。

### 1.2 類・相殺・錐を同時に評価する

各ラベルについて、三角形のperiodを $`z_{01}-z_{02}+z_{12}`$ とする。
中間段ではこのperiodと $`z_{03}-z_{04}+z_{34}`$ の組を取る。
このperiod写像がcoboundaryをちょうど核とし、H¹の線形同型を誘導することを証明する。
既存の生成cochain式をその同型へ通すと

```math
\mathbb Q\xrightarrow{f:x\mapsto(x,0)}\mathbb Q^2
 \xrightarrow{g:(x,y)\mapsto x}\mathbb Q
```

を得る。各ラベルで以下を**同じ三比較**について同時に示す。

| 評価対象 | 固定する結論 |
| --- | --- |
| H¹の次元 | 1,2,1 |
| `blockDefect f`、`blockDefect g`、直接比較の欠損 | (0,1)、(1,0)、(0,0) |
| 指定した中間cocycle | 辺34だけ1、他辺0。第二periodが1 |
| 相殺写像 | この類を $`\mathbb Q^2/(\mathbb Q\times0)`$ の非零類へ送り、rankが1 |
| 錐の $`(\dim H^0,\dim H^1)`$ | 前段(0,1)、後段(1,0)、直接比較(0,0) |
| Cの追加項 | 各段の $`\operatorname{coker}H^0=0`$、$`\ker H^2=0`$ |

両段の各欠損成分をすべて非零にする要求は置かない。
直接比較が同型ならfは単射、gは全射であり、この例で相殺するのは前段の余核と後段の核である。
全Sourceで非空な二ラベルを持つため、Law全体ではH¹次元が2,4,2、
欠損が(0,2)、(2,0)、(0,0)、相殺rankが2となる。
二ラベルの台署名は等しい。D・Eによる再添字づけ後も二成分を残すことを示す。

これらの値は、一般の完全列と、個々のcocycleの生成比較による評価の両方へ接続する。
三つのH¹空間やf・gを最初から上の行列として定義した例はW1の完了証拠にならない。

## 2. W2：台の商と診断値だけの同一視

$`\mathrm{Source}=Q=\{a,b,c\}`$、粗細のreadingは恒等、Lawは一つで
値をそのSource自身とする。chartはL,Rの二つ、台はそれぞれ $`\{a,b\}`$、$`\{c\}`$、
辺・面は空、比較は既存の恒等比較である。

粗細を区別したLセルの組を $`\Omega_L`$、Rセルの組を $`\Omega_R`$ と書く。
$`S_a=S_b=\Omega_L`$、$`S_c=\Omega_R`$ から次を同時に示す。

- $`\sigma(\{a\})=\sigma(\{b\})`$、$`\mathrm{cl}(\{a\})=\{a,b\}\supsetneq\{a\}`$。
- $`\sigma(\{a\})\ne\sigma(\{c\})`$、一方で全Aについて $`J_A=(0,0)`$。
- Σは $`\varnothing,\Omega_L,\Omega_R,\Omega_L\cup\Omega_R`$ の四要素。
  全部分集合の八要素から名付きセルを保つ商を構成し、カードEの因子化へ接続する。
- 零欠損の一つの値だけから $`\Omega_L`$ と $`\Omega_R`$ の双方を復元するdecoderは存在しない。

各選択複体は辺を持たないためH¹は零だが、次数0と元のセルへの包含は異なる。
同じ次元の抽象ベクトル空間の同型だけではこの区別を保持しない。
W2で使うLaw値a,bのblockも、同署名でありながら別の直和成分として残る。

## 3. W3：錐の他次数が実際に寄与する

W3a・W3bの各比較でSourceを $`\{0,1\}`$、粗readingを一点への全射、
細readingを恒等、Lawを一つの定数Lawとする。
すべてのchart台はその段の全targetである。
細分化、adequacy、K1、全incidence条件をこの原始表から証明する。

### W3a：次数0の余核

粗側は一つのchart、細側は二つの孤立chartとする。両側の辺・面は空。
両細chartを粗chartへ送る。
生成 $`H^0`$ 比較は $`\mathbb Q\to\mathbb Q^2,\ x\mapsto(x,x)`$、
H¹比較は零空間間の同型である。
$`J=(0,0)`$ と $`\dim H^0D=\dim\operatorname{coker}H^0(u)=1`$、
他の錐コホモロジーの消滅を同時に示す。

### W3b：次数2の核

粗側のchartは0,1,2,3、辺は全六組、面は012,013,023,123の四つとする。
細側はchart 0,1,2と辺01,02,12、面012の一つ。
全細セルを同名の粗セルへ `some` で送る。
既存の三項複体（次数0–2、外は零）で次を示す。

| 対象 | $`\dim C^0,\dim C^1,\dim C^2`$ | $`\mathrm{rank}d^0,\mathrm{rank}d^1`$ | $`\dim H^0,\dim H^1,\dim H^2`$ |
| --- | --- | --- | --- |
| 粗側 | 4,6,4 | 3,3 | 1,0,1 |
| 細側 | 3,3,1 | 2,1 | 1,0,0 |

H¹欠損は(0,0)、$`\ker H^2(u)`$ は1次元、$`H^1D`$ も1次元となる。
錐の空間の次元は次数−1,0,1,2で4,9,7,1、微分rankは4,5,1、
コホモロジー次元は0,0,1,0である。
四面体の全四面を同じK1・Law生成手続きへ通し、任意の三項行列の例へ置き換えない。

W3bのH²は指定された三項複体の終端の商である。
別の高次セルを追加した複体のH²へ暗黙に読み替えない。

## 4. 設計時の検算とLeanで残る義務

有理行列による検算は、上のセル表からincidence行列を作り、部分写像の引き戻し行列を生成して行う。
微分の二乗、比較との可換性、直接比較と合成の一致、rankと次元を確認できる。
これは固定例の式の整合性確認である。

Leanでの受入には、原始Source・Law・台から既存座標型への同定、全入力fieldの放電、
既存H¹商でのperiod・類の非零性、B・C・D・Eへの適用を別途証明する。
有理行列の実行結果だけを `Research-proved` として数えない。
