## 1. 対象をここまでに絞る理由

n1016 §4.3の中心は、診断を保つ選択肢全体と自然選択の可否である。
初回は有限有向グラフの商に固定する。これによりすべてのtarget分割・chart分割を
同じ規則で扱え、共通粗化を作るときの面生成の選択を研究中に変えずに済む。
台は任意の非空部分集合で、K1による辺選択と全Law量化を保つ。
恒等粗化、商の合成、同型輸送を含む有限の対象クラスになることはAで証明する。

このGOALの結論はT0の規則について述べる。混在面を持つ商、meetについての閉性、
閉包作用素と内部作用素の双方の固定点集合を否定するNo Complete-Shell、
極大元数の指数増大は、今回の固定targetに含めない。
共通粗化の結果だけで、それらまで解決したとは扱わない。

## 2. 証明の構成

```text
有限S/T/V・全射q・辺関係E・台
  → 全分割対と商nerve、原始部分セル比較
  → 既存subset/Law比較・実核余核・G-135有限判定
  → 安全半順序、全極大元、joinと全共通上界
  → 原始同型の作用、固定極大元と同型類上の選択
  → 指定例の評価、P_G / P_J / P_N の成立または反証
```

Aの射の合成と、Bの二つの粗化のjoinは異なる構成である。
前者は既存の同じ三H¹空間の2-out-of-3を使う。後者は異なる二分割から新たな商を作り、
その実比較を改めて判定する。

## 3. 到達点と新規module候補

ファイル分割と名前は実装時に選べる。表は新規宣言の存在を意味しない。

| 到達点 | 候補module | 終了条件と依存 |
| --- | --- | --- |
| 原始商と因子化 | `PrimitiveInput`, `QuotientNerve`, `Factorization` | T0の全RからAの原始比較を生成。直接商・二段商の全成分を同定 |
| 既存診断への接続 | `GeneratedComparison`, `UniformSafety` | 全A・全Law、G-135の同じ射への接続。既存rank計算の正しさを再証明しない |
| 安全posetの分類 | `SafeOrder`, `MaximalCoarsening`, `CommonUpperBounds` | Bの全列挙・極大性・最大元・join判定と失敗証拠 |
| 対称性と選択 | `IsomorphismAction`, `NaturalSelection` | Cの実比較の共役、全極大元への作用、固定点による存在判定 |
| 原始例と決着 | `CycleInputs`, `CycleEvaluation`, `WidthRegression`, `Resolution` | Eの固定評価、Dの各結果と根拠。評価値を原始入力から導く |

到達点ごとにproof obligationを切る。Dの候補が外れたときは同じT0内で別の反例を探すか、
一様成立の証明へ進める。入力クラス・商規則・安全性の変更が必要ならGOAL改訂として扱う。

## 4. 検証の焦点

- quotientの同型はfine入力からの商写像を保持する。自己同型軌道で先に商を取ると、選択問題が変わる。
- 実比較のrankと核・余核を検査する。両端H¹の次元が同じという検査では安全性を判定できない。
- join不安全、最大元不存在、固定極大元不存在を、それぞれの証拠へ対応させる。
- 全Law量化の範囲は各粗readingにadequateな族であり、粗化間の比較では部分集合の逆像を追う。
- 面なし・有向辺の規則を保つ。R10の無向図の対称性や数値を、そのまま移さない。
- W3では台に依存する全A判定を検査し、全台を一律に置くW1・W2だけで実装を確認しない。

将来のLean検証は[AAT guideline](../../../docs/aat/guideline.md)のfocused checkに従う。
この設計の有限構成は数学的要求であり、大量探索・性能測定やResearch全体のelaborationを必要としない。
