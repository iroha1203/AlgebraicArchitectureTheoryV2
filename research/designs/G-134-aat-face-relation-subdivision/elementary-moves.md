# G-134：基本変形、台条件、比較とホモトピー

[GOAL B・C](../../goals/G-134-aat-face-relation-subdivision.md)の許容操作を定義する。
以下の式から支持chainとLaw診断の定理を構成することが証明義務である。

## 1. 符号と台

基底セルをその名前で書き、$`\partial e=\operatorname{right}e-\operatorname{left}e`$、
$`\partial F=e_0-e_1+e_2`$ とする。$`\sigma_0=1,\sigma_1=-1,\sigma_2=1`$。
$`S(e)=S(\operatorname{left}e)\cap S(\operatorname{right}e)`$、
$`S(F)=S(e_0)\cap S(e_1)\cap S(e_2)`$ はK1から作る。

すべての基本変形で、元の辺 $`e:v\to w`$ の始点 $`v`$ を指定して
freshな頂点 $`v'`$ の台を $`S(v')=S(v)`$ にする。
freshとは既存セル名および同じ次数で新設する他のセル名と異なることをいう。
chart台の非空性は $`S(v)`$ から得る。$`S(e)`$ の非空性は必要ない。
端点 $`v=w`$ も許す。全旧セルの台・incidenceは、操作が明示して変更する箇所以外は保持する。

基底式を支持部分複体へ制限する際は、非零係数で現れる像のセルについて
「元セルの台が像セルの台に含まれる」を証明する。
ホモトピーでも同じ条件を使う。これにより任意の $`A`$ と各Law値で式が定義できる。

## 2. 三角形追加

元の辺を $`e_1:v\to w`$ とする。旧セルをすべて保ち、次を加える。

| 次数 | 新セル | incidence | K1台 |
| --- | --- | --- | --- |
| 0 | $`v'`$ | fresh | $`S(v)`$ |
| 1 | $`c`$ | $`v\to v'`$ | $`S(v)`$ |
| 1 | $`e_2`$ | $`v'\to w`$ | $`S(e_1)`$ |
| 2 | $`f`$ | $`(e_0,e_1,e_2)=(c,e_1,e_2)`$ | $`S(e_1)`$ |

したがって $`\partial f=c-e_1+e_2`$。
新セルと元セルの接続は表で尽くし、旧面には新しい辺を挿入しない。
元の辺 $`e_1`$ が既存面に何回現れていてもよい。

収縮 $`r:K'\to K`$ は旧セル上の恒等と
$`r(v')=v,r(c)=0,r(e_2)=e_1,r(f)=0`$ から作る。
section $`s:K\to K'`$ は旧セルの包含である。
ホモトピーは

```math
h_0(v')=c,\qquad h_1(e_2)=f
```

とし、他の基底で零にする。$`h_2=0`$。符号の検算式は

```math
\begin{aligned}
(1-sr)v'&=v'-v=\partial c,\\
(1-sr)c&=c=h_0(v'-v),\\
(1-sr)e_2&=e_2-e_1=\partial f+h_0(w-v'),\\
(1-sr)f&=f=h_1(c-e_1+e_2).
\end{aligned}
```

$`r_1\partial f=0-e_1+e_1=0`$ は新比較の退化面条件そのものである。
$`S(v')=S(c)`$、$`S(e_2)=S(f)`$ により、$`h`$ は全支持成分で定義できる。
$`c`$ だけが支持されて $`e_1,e_2,f`$ が支持されない成分では、追加部分は頂点と辺の対になる。

## 3. 面に接する辺の分割と再三角形化

任意の $`e:v\to w`$ を取り、元の辺 $`e`$ を除き、freshな
$`v',c:v\to v',b:v'\to w`$ を置く。
各旧面の出現位置を保持した集合

```math
O_e=\{(F,i)\mid i\in\{0,1,2\},\ e_i(F)=e\}
```

を作る。同じ面で三回現れる場合も三要素である。
各 $`o=(F,i)\in O_e`$ に、freshな対角辺 $`d_o:v\to w`$ と
三角面 $`t_o=(c,d_o,b)`$ を作る。各旧面 $`F`$ は一つの中心面 $`F^\circ`$ に置き換え、
その第 $`i`$ 辺は、元が $`e`$ なら $`d_{F,i}`$、それ以外なら元の辺とする。
各出現の $`d_o,t_o`$ は、同じ端点・台を持っていても識別する。

この構成の中間表示は、各 $`+e`$ を $`+(c+b)`$、各 $`-e`$ を
$`-(c+b)`$ に置き換えた2-cellの貼付け語である。
各出現に対角辺 $`d_o`$ を挿入して $`t_o`$ と中心面へ分けることで、終点は再び
既存 `TargetSupportedNerve` の三角面表示になる。
図形の埋め込みや面の三頂点の相異性は仮定せず、名前付きincidenceでこの再三角形化を定義する。

台はK1から次の通り導く。

```math
S(c)=S(v),\quad S(b)=S(d_o)=S(t_o)=S(e),\quad S(F^\circ)=S(F).
```

収縮の原始セル表は

```math
\begin{array}{c|ccccc}
x&v'&c&b&d_o&t_o\\\hline
r(x)&v&0&e&e&0
\end{array}
\qquad r(F^\circ)=F.
```

旧頂点・$`e`$ 以外の旧辺は恒等に送る。中心面は三辺の番号を保ち、
追加三角面では $`r(c)-r(d_o)+r(b)=0-e+e=0`$ となる。
sectionとホモトピーは次の基底式で作る。

```math
\begin{aligned}
s(v_0)&=v_0 &&\text{（全旧頂点）},\\
s(e)&=c+b, &s(a)&=a\quad(a\ne e),\\
s(F)&=F^\circ+\sum_{(F,i)\in O_e}\sigma_i t_{F,i},\\
h_0(v')&=c, &h_1(d_o)&=-t_o.
\end{aligned}
```

$`h`$ は表にない基底で零にする。
特に $`h_1(b)=0`$ であり、§2の三角形追加の式と取り違えない。

```math
\begin{aligned}
\partial s(F)&=s(\partial F),\\
(1-sr)b&=-c=h_0(w-v'),\\
(1-sr)d_o&=d_o-c-b=-\partial t_o,\\
(1-sr)F^\circ&=-\sum_{(F,i)\in O_e}\sigma_i t_{F,i}=h_1\partial F^\circ,\\
(1-sr)t_o&=t_o=h_1(c-d_o+b).
\end{aligned}
```

これらをセルの全場合で証明し、$`rs=1`$ と収縮式へ結ぶ。
支持について、$`s(F)`$ に現れる各追加面には $`S(F)\subseteq S(e)=S(t_o)`$ があり、
$`h_1(d_o)`$ では台が等しい。面が選択されないがその辺は選択される場合も式は保たれる。
面に接しない辺では $`O_e=\varnothing`$ となり、通常の二辺への分割になる。

中間2-cellを直接扱う場合の式も固定できる。置換後の面 $`\widetilde F`$ に
$`r(\widetilde F)=F,s(F)=\widetilde F`$、$`h_1=0,h_0(v')=c`$ と置く。
三角形表示への写像は $`\widetilde F\mapsto F^\circ+\sum_i\sigma_i t_{F,i}`$。
中間表示を実装に使う場合は、この写像と支持・微分の一致を証明する。
完了対象の比較は、上の三角形表示の実Law複体に着地させる。

## 4. 逆縮約の許容条件

逆操作の入力は、次の局所パターンを原始セル表から特定したものである。
H¹同型や「削除してよい」という証明を入力にしない。

- §2の逆では、指定 $`v'`$ に接する辺は $`c,e_2`$ だけで、これらを使う面は
  指定 $`f`$ だけとする。$`e_1`$ と他の旧セルは残す。端点・面の三辺・
  $`S(v')=S(v)`$ を検査し、$`v',c,e_2,f`$ を除く。
- §3の逆では、$`v'`$ に接する辺は $`c,b`$ だけ、これらを使う面は指定された
  $`t_o=(c,d_o,b)`$ だけとする。各 $`d_o`$ はその $`t_o`$ と、対応する
  一つの中心面の指定位置にだけ現れる。全 $`d_o`$ は同じ端点 $`v,w`$ を持つ。
  中心面の指定位置を新たな共通辺 $`e:v\to w`$ に戻し、$`v',c,b,d_o,t_o`$ を除く。
  中心面と他の旧セルは残す。$`O_e=\varnothing`$ の場合も含む。

各パターンは列挙した局所セルの**すべての**接続を検査する。
残るセルの台は保持し、復元する辺の台はK1で作る。
この原始条件から、復元した入力に§2・3を適用すると元のセル表示を得る同型を構成する。
その同型を通じて同じ $`r,s,h`$ を逆向きの比較に用いる。

## 5. reading変更と全支持への適用

$`q_c\preceq q_f`$ に対して、同じセル・incidenceを使い
$`S_f(v)=\pi^{-1}S_c(v)`$ とする。$`\pi`$ の全射性からchart台の非空性を導く。
K1と逆像の交差保存から辺・面でも同じ台等式を得る。

$`A_f=\pi^{-1}A`$ とすると、各次数のセルが選択されることは粗細で同値である。
比較と逆は同じセル名、ホモトピーは零とし、Law・値は降下の等式で同定する。
この操作と§2–4を有限合成することで、真に異なるreadingの間でも同じ構成を用いる。

空の $`A`$ では全次数が零。空の辺台・面台からはLaw座標が生成されない。
空Sourceでは非空chart台を持つchartが存在せず、辺を指定する基本操作のinstanceもないが、
空列とその恒等比較は定義できる。
繰り返されたtargetの出現は `CellCoordinate.ext` によって一座標となる。
一方、異なるセル名、面内の出現位置、異なるLawラベルはそれぞれ保持する。

## 6. H¹のみを保存する対照操作

既存面 $`F`$ の複製 $`\widehat F`$ を、同じ三辺と台で追加する。
$`r(\widehat F)=F`$、旧セルは恒等、$`s`$ は包含とする。
新しいchain複体の基底を $`\widehat F-F`$ と旧セルへ取り直すと、選択された成分で
$`K'=K\oplus\mathbb Q[2]`$、$`r`$ は第一成分への射影になる。
面が選択されない成分では $`K'=K`$。

この式から実生成cochain比較のH⁰・H¹同型、H²の単射性と余核ℚを導く。
複製のincidenceは旧hereditary比較にも属するため、GOAL Aの埋め込みで旧生成比較との
一致も示せる。§2–5の強い基本変形には加えず、GOAL Eの比較対象として使う。

## 7. 持ち上げの選択とcochain代表

§2では $`e_1`$ と、始点を $`c`$ でそろえた道 $`c+e_2`$ の差が $`\partial f`$ である。
任意のcocycle $`z`$ に対して $`z(c)+z(e_2)=z(e_1)`$ を導く。
fine側で $`v'`$ のpotentialを $`z(c)`$、旧頂点のpotentialを零にしてcoboundaryを引くと、
$`z'(c)=0`$、$`z'(e_2)=z(e_1)`$ になる。
この補正は各支持成分で定義し、$`c`$ が選択されない成分では零とする。

sectionの選択そのものも比較する。§2の $`s`$ に対して、degree 1の写像
$`t_1(e_1)=f`$、他の基底で零とし、$`s'=s+\partial t+t\partial`$ と置く。
すると $`s'(e_1)=c+e_2`$、旧面 $`F`$ では
$`s'(F)=F+(\sum_{i:e_i(F)=e_1}\sigma_i)f`$ となる。
支持包含とchain式を証明し、$`s'^*`$ と $`s^*`$ が同じH¹の読み戻しを与えることを示す。

§3では $`c+b`$ と各 $`d_o`$ の差が $`\partial t_o`$。
元の辺 $`e`$ の持ち上げを $`c+b`$ から指定 $`d_o`$ へ替える場合は、
$`t_1(e)=-t_o`$ として同じ式を用いる。どの $`o`$ を選んでも
$`S(d_o)=S(t_o)=S(e)`$ であり、支持を保つ補正が作れる。
ここで比較するのは、構成した三角面で結ばれるこれらの道とその有限合成である。
