# 条件付き変更とreadingを共有する候補

## 定義 E1 — 原始規則からの候補生成

許容規則 `H` は小さい添字族である。各規則は、参照する原始宣言、保持する部分表示、そのsort・型・Law support、変更してよい宣言、導入・忘却する補助sort・operation・phase、代入してよい型付きterm、共有係数と保持する補助選択を記述する。参照はG-139 N5と同じ依存閉包を取る。固定宣言はその像も指定し、宣言名だけを固定して解釈の変更を許すことはしない。

一つの規則 `r` に対して、以下の順序でraw候補 `E_r` を作る。

1. 両端のsort担体・operation・quantity・状態を、指定された係数的実現で選ぶ。
2. 規則の型に合う共有係数・補助選択・語翻訳 `τ` を選び、固定宣言の像を同定する。
3. 各比較sortについて**全ての実際のmap** `h` を選ぶ。copyingの全profile、linearの全matrixまたはmodule表示、regular mapの全有限多項式supportを使う。
4. 選んだmapと原始式を評価し、両端のrequired Law、固定部分の一致、domain・operation・観測・quantityの保存式を課す。

1–3の点ごとの直和 `E_H=∐_(r∈H)E_r` がraw候補、4を課したものが `C_H` である。ここで規則 `r` は大域的に指定された編集指示として保持する。規則が実際の候補の区別として指定する名前・補助選択は添字とdataに残す。導出証拠や同じ商環射のambient代表だけはB4.2に従って同一視する。両端を読むと `s,t:C_H⇉M` を得る。

この規則付き表示関手はC3の全意味圏へ自然に写る。固定構文はC3.1の一つのラベルだけを持つsectionとして解釈する。任意の `H` の全候補自体がsheafであるとは要求しない。clopen片ごとに異なる規則を許す別の仕様では `ΔH` 上の候補を明示して用い、その独立な意味にも同じ局所選択を含める。全意味圏のdescentと、指定された大域規則の候補を区別する。

ここで `τ` をtermから作ることは、状態map `h` をtermで書けるものに制限することを意味しない。例えばoperationなしのcopying sortでは、規則が追加制限しない限り、全関数を含む。規則自身が「このtermの評価をstate mapとする」と指定した場合だけ、その等式を3の全mapに課す。

独立な変更は、同じ両端の原始model・実際のmap・翻訳・補助選択を与えて4の各保存条件を満たすものと定義する。B3の読み戻しは1–3の全dataを回復し、4の係数式はそのdataの原始評価と一致する。従って全係数環上で、独立な変更と `C_H` の点が自然に同値となる。有限表示を仮定しない場合は表示関手の同値であり、scheme性の追加主張ではない。

## 定理 E2 — 評価条件のfiber

`T` を係数環上の集合値関手、`P↪T` を部分関手とする。指定された型付き評価規則は、各原始termまたはquantityの評価を全係数環上で `T` の値として読むものとする。固定規則の各候補についてその原始dataを実際に評価し、`v:C_H→T` を作る。各termの変数・定数・operation適用の帰納法と、quantityの係数変更則により `v(c)_S=v(c_S)`。自由な「評価値」というfieldを入力するのではなく、原始評価からこのmapを生成する。

この構成に `T` のsheaf性は要らない。E1の規則付き候補を自動的にsheafifyしてから評価しているわけではない。局所規則も許す仕様では、その全候補に対して型付き評価が定義され自然であることを同じく検査する。raw chartでの値だけから任意の `T` へ評価を延長できるとは主張しない。例えば二つの規則を区別する定数集合値の評価は、二つのclopen片で規則を混合した候補へ一般には延長できない。

`a∈M(R)` を固定する。`R`-代数上で

```math
\mathcal F_{a,H,P}
=\bigl(C_H\times_{s,M,a}\operatorname{Spec}R\bigr)
 \times_{T_R}P_R
```

を構成する。marked集合版の `S`-点は、`s(c)=a_S` と `v(c)∈P(S)` を満たす候補そのものである。独立な問題の解からはその全dataを読み、fiberからは `h,τ,t(c)` と全補助選択を取り出す。E1の同値と評価の一致により互いに逆となる。

unmarked版ではsource固定を2-fiberとし、対象は `(c,α:s(c)≅a_S)` とする。候補間の比較は `α` と可換な同型である。`T,P` をdiscrete groupoidと読む際は、評価値を候補の同型で不変に選ぶか、評価に使うmarkingを候補に保持し、その不変性を原始式で検査する。こうして `v` がgroupoidの関手になる。評価条件のliftは条件が偽なら空、真なら一点groupoidであり、解に余分な証拠自己同型を付加しない。source同定 `α` は保持し、sourceの自己同型を勝手に消さない。部分関手という仮定を外して `P→T` の二つの異なる点を同じ値へ送ると、同じ候補に二つの評価liftができるので、この単純な条件解釈にはならない。

### E2.1 — 自然性とsourceの変更

環射 `R→S`、source family `A→M` の基底変更 `A'→A`、規則の包含 `H↪H'`、評価条件の引戻しについて、同じ候補tupleを運ぶmapがある。fiber productのtupleを直接比べると、source familyの引戻しと解の引戻しが可換になる。規則包含は新しい規則を追加して旧候補を保持する包含であり、旧候補の固定Lawを変更する操作ではない。

sourceの変更を、別の実際の意味保存射との**前合成**として行う場合は、任意の `H` が合成で閉じるとは限らない。前合成した `h` と合成翻訳を許す規則族へ `H` を移し、その保存式がA3により成立することを使う。sourceの同型でも固定宣言・補助選択を同じ同型で運ぶ。この区別により、moduliの基底変更とstate mapの前合成を同一視しない。

### E2.2 — 同時条件、直列合成、順位

同じsourceに二候補 `c₁,c₂` を置く問題は `C_(H₁)×_M C_(H₂)` のfiberである。実際の併用先と二つの比較射を要求する場合はF1の可換四角形の補完を使う。中間端点を同定した直列合成は `t(c₁)=s(c₂)` に沿う別のfiberであり、A3の合成に送る。

評価による順位は、固定環 `R` の解集合上で選んだ前順序から定める。評価比較 `f:T(R)→T'(R)` が単調なら `v(c)≤v(d)⇒f(v(c))≤f(v(d))` が成り立つ。順位・同順位まで回復するには解の比較がこの前順序を反映する必要があり、順序同型なら全順位を保つ。単調な定値mapは `0<1` を同順位にするため、単調性だけから順位の完全な保存は主張できない。

## 定義 E3 — 同じreading上の共有規則

原始表示の係数的実現を全て保持する関手を `U` とする。宣言の選択、係数の評価、指定した関係の忘却等を原始dataに適用してreading `q:U→B` を生成する。例えば型とoperation署名を選ぶreadingは、値の式やLaw成立を読むreadingとは異なる。比較する問題に応じて `U` はraw表示の候補でもよく、その場合、Law成立は後段の検査に含める。

`C→^π B` は共有する規則係数と補助選択の関手である。共有候補 `c` を `q(u)=π(c)` の各 `u` に適用する際、候補生成に必要なstate map・翻訳・補助選択を規則が一意に生成できるだけのdataを含める。全候補に共通の多項式を代入する場合はその係数、複数の補助選択が可能な場合は選択そのものを保持する。「規則名」だけから存在未証明のmapを取り出すことはしない。

この生成による候補をE1で評価し、全required Law・観測・評価条件を満たす組の部分関手を

```math
E_{\mathrm{ok}}\hookrightarrow U\times_B C
```

とする。係数変更は原始評価と可換なので部分関手になる。共有規則の像が独立な全Homを尽くす必要はない。全HomはE1に残し、共有規則はその中の指定されたfamilyとして扱う。

規則だけでは実際の候補が一意に決まらず、残るmapや補助選択の**存在**を問う場合は、全解を保つ `F→U×_B C` をE2で生成する。そして

```math
E_{\mathrm{exists}}(R)
=\{(u,c)\in(U\times_B C)(R)\mid F_{u,c}(R)\ne\varnothing\}
```

とする。解の係数変更があるので、これも部分関手である。局所的な解の存在を `R`-点の存在に置き換えず、解集合への全射や局所性も無条件には主張しない。報告する実際の変更は `F` の点から回復する。`E_exists` の真偽だけから任意の解を構成したとすることはない。

## 定理 E4 — 三つの量化

固定 `R,b∈B(R)` に対し `U_b={u:q(u)=b}`、`C_b={c:π(c)=b}` とし、まず `U_b≠∅` とする。`E` は `E_ok` または `E_exists` のどちらでもよい。

| 問題 | 条件 |
| --- | --- |
| 指定した共有候補 `c∈C_b` | `∀u∈U_b, E(u,c)` |
| 実現ごとに候補を選べる | `∀u∈U_b, ∃c∈C_b, E(u,c)` |
| 一つの候補を共有できる | `∃c∈C_b, ∀u∈U_b, E(u,c)` |

第三条件のwitness `c` を各 `u` に用いれば第二条件を得る。逆は成り立たない。`U_b=C_b={0,1}`、`E(u,c)⇔u=c` とすると各 `u` に `c=u` があるが、二つの `u` に共通する `c` はない。これは定数集合関手としても作れ、候補生成を対角条件にすれば `E_ok` の例、解fiberを真のとき一点・偽のとき空とすれば `E_exists` の例になる。

`U_b=∅` のとき指定候補の全称条件と第二条件は空虚に真であり、第三条件は `C_b≠∅` と同値になる。意味実現が存在するという主張はどれからも得られない。従ってreadingの実現fiberとその非空witnessを別に保持する。`u∈U_b(R)` があれば全係数変更後にも `u_S` があり、非空性を保つ。

## 定理 E5 — 全係数変更で安定な全称条件

`E_ok` について

```math
\mathcal R(R)=
\left\{c\in C(R)\ \middle|\
\forall(R\to S)\ \forall u\in U(S),\
q(u)=\pi(c)_S\Rightarrow E_{\mathrm{ok}}(u,c_S)
\right\}
```

を定義する。これは `C` の部分関手である。

**証明。** `c∈R(R)` と `R→S` を取る。さらに `S→T` と `q(u)=π(c_S)_T` を満たす `u∈U(T)` を取ると、合成 `R→T` に元の全称条件を適用できる。自然性から `(c_S)_T=c_T` なので必要な条件を得る。恒等・合成の則は `C` のものを制限したものである。環全体への量化は固定した宇宙内で行う。□

恒等環射を使うと、`R(R)` から固定 `R` 上で指定候補を検査した集合への包含を得る。逆は一般にはない。基礎環を `F_p`、`U= A¹`、`B=C=1`、`E_ok(u,*)⇔u^p=u` とする。`R=F_p` の全点では真だが、係数変更 `F_p→F_p[t]` と `u=t` では偽となる。この例は同じ多項式評価で生成される。

`E_exists` に置き換えても、部分関手性と環射の合成から全く同じ証明が通る。ただし、その全称条件は各拡大後・各実現で解が存在するという意味であり、全ての解を一つの自然な選択へまとめることは要求も結論もしない。

### E5.1 — Reading比較への受渡し

別のreadingについて自然な比較 `f:U'→U`、`b:B'→B`、`k:C'→C` があり、`qf=bq'`、`πk=bπ'` とする。各候補の生成・Law・評価がこの比較で対応し、同じ組について `E(fu',kc')⇔E'(u',c')` と確認できているとする。`kc'` が全拡大上でrobustなら、任意 `u'` を `fu'` へ送って `c'` のrobust性を得る。

逆向きに全 `u` への主張を移すには、各係数拡大・対象fiber上で `f` が全射である等の持上げ条件が必要である。一方向のLaw保存しか得られない比較では、その向きの含意だけを移す。この比較dataと実現非空性をG-142 Fの入力にする。型署名だけから評価条件の同値を推定することはできない。台帳における同じ `q_type` と異なる残差は [P7](ledger-specialization.md#p7--型署名だけのreading) で原始式から計算する。
