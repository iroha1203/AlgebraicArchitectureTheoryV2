# 図式の補完、許容経路、合法状態の移送

## 定理 F1 — 独立な図式補完と2-fiber

小さい圏 `J`、部分圏の包含 `i:K↪J`、固定図式 `d:K→C_R` を入力とする。独立な補完とは、次のdataである。

- 各 `j∈J` の原始model `D_j`。
- 各射 `a:j→j'` の実際の意味保存射 `D_a`。state maps、翻訳、保持すべき補助選択を含む。
- `D_id=id` と `D_(ba)=D_bD_a`。圏 `J` が生成射・関係で与えられるなら、その全関係の成立。
- 自然同型 `α:D|K≅d`。

補完間の射 `η:(D,α)→(D',α')` は自然同型 `η:D≅D'` で `α'η|K=α` を満たすものとする。元の `D_a` の可逆性は要求しない。

`D_J(R)=Fun(J,C_R)^≃` とすると、2-fiber productの対象を直接展開して

```math
\operatorname{Comp}_{J,K,d}(R)
\simeq
\mathcal D_J(R)\times^2_{\mathcal D_K(R)}\{d\}
```

を得る。実際、右辺の対象は `(D,*,α:res(D)≅d)`、その射は上の `η` そのものである。従って対象と全Homで互いに逆の関手があり、固定部分の同定を忘れない。

この同値は、全補完を最初からfiberと呼ぶことだけに依存しない。G-139 N5とE1の原始候補生成を各頂点・各射へ適用し、恒等・合成・関係の二経路を実際のmapと翻訳で評価して等式を課す。規則付き候補 `C_(J,H)→D_J` をこうして生成すると、その各点を読むことで独立な `D` を得る。逆に各 `D` の全mapはB3の全profileに表され、全図式関係が課した式に一致する。Law・評価条件を満たす候補の

```math
C_{J,H}\times^2_{\mathcal D_K}\{d\}
```

が、その規則で許された全補完を分類する。候補の各射・翻訳・規則名・指定補助選択は全て回復される。

### F1.1 — 四角形と鎖

四角形では、まず実際のfork `b→^f a←^g c` と共通の固定部分を `d` に保持する。補完は `z`、射 `u:z→b`、`v:z→c` と `fu=gv` からなる。共通の固定部分の全ての射も固定する。二つの枝の観測値が一致するだけでは、指定された `f,g` を含む四角形は得られない。合成式は原始sort mapと語翻訳の両方について検査する。

鎖では両端、必要なら指定された中間頂点・部分図式を `K` に置き、各辺に許容規則と評価条件を置く。補完は全中間modelと実際の辺を持つ。両端の観測が同じという条件からこれらを補わない。

### F1.2 — 自然性と有限方程式

環射により全頂点・辺・自然同型を係数変更すると全関係を保つ。形の関手 `f:J'→J` と `K'→K` が可換な正方形を作るなら `D↦Df` が補完を引き戻す。固定部分を `K'⊂K` に制限するmapは `α` の成分を制限する。これらの二順序は同じtupleを与える。

有限対象・有限生成射・有限関係の図式に対し、各成分が有限係数表示を持ち、全required Lawの**有効な有限還元**が既に与えられていれば、原始term評価・matrix積・保存残差の有限個の係数式を作れる。関係の残りは生成関係と合成保存から帰納的に従う。これがG-139 P6の生成手順である。実際のmapを一意に表すchartではその解と対応する全補完が同値になる。

ideal所属witnessを使う場合、単一の有限chartで全補完を回収するには、有限還元がwitness係数の次数・support上界も与えることを要する。一般にはB4.2の全有限support表示系を保持し、その全体を導出witness・ambient代表の同値関係で商にした解が全補完に対応する。体上の有限多項式表示では、G-141 D5のGröbner層別による有限検査も使える。rawなwitness選択の重複を全Homの相違と数えない。この表示と商をG-141 Dへ渡す。有限の図式であることだけから、無限Law全体の有限還元やwitnessの一様次数上界を導くことはしない。

## 定理 F2 — 一段変更から生成する経路

原始一段規則からE1で合法な候補 `E_(1,H)⇉M` を作る。向きは実際の状態射、または時間順の反対圏のいずれかに固定する。以後の端点mapと合成はその向きで統一する。

`n≥1` に対し

```math
\operatorname{Path}_{n,H}(a,b)
=\left(
\mathcal E_{1,H}\times^2_M\cdots\times^2_M\mathcal E_{1,H}
\right)\times^2_{M\times M}\{(a,b)\}
```

を取る。対象を展開すれば `n` 個の実際の一段変更、隣り合う端点の同型、始点と `a`・終点と `b` の同型である。射は全ての同定と可換な候補比較である。つなぎ同型を含めて全圏 `C_R` で合成できる。規則 `H` 自体が端点の同型による輸送を許し、その輸送を原始規則から構成できる場合にはB1と同じstrictificationが規則内でも通る。任意の `H` ではその閉性を仮定せず、つなぎ同型を保持した列を用いる。

`n=0` は恒等射の族、すなわち `M→^Δ M×M` の `(a,b)` 上の2-fiberとする。これは `a≅b` の同型groupoidに対応する。marked集合版では `a=b` のとき一点、異なるとき空である。

二つの経路は共通端点の同定を使って連結できる。列の連結は恒等列を単位とし、括弧を外した同じ全辺tupleにより結合的である。`C_R` 内で全辺を合成すると、B1のnerveから一般の一つの意味保存射へのmapを得る。規則 `H` が合成で閉じなければ、その合成が再び許容**一段**候補であるとは限らない。

## 定理 F3 — 細分化の全fiber

指定された辺 `e:a→b` の `n` 段細分化候補は `Path_(n,H)(a,b)` から生成し、合成を `C_R` の全射へ送るmapの `e` 上のfiberを取る。marked版は実際の合成と `e` の等式、unmarked版は固定両端と可換な矢印同型を保持した2-fiberである。語翻訳・指定補助dataについても、比較対象の圏で要求される一致を課す。

このfiberから各細分辺を回復でき、独立な因子分解から元の点を戻せる。複数辺を細分化する場合、各細分列を連結した後の合成は、先に各列を合成してから全体を合成したものと一致する。これはA3の結合則であり、さらに細分化しても同じ全辺tupleで可換になる。係数変更や、候補・Law・評価を保つreading比較は各辺・合成式を運ぶため同じfiberを自然に比較する。細分化fiberの非空性は追加の存在問題である。

### F3.1 — 係数曲線だけから経路は生まれない

marked対象のfamily `M=A¹` とし、一段規則を恒等だけにする。非零環 `k` 上の点 `0,1` は係数曲線 `A¹` に含まれ、その二点を読むことができる。しかし有限個の恒等を合成しても始点は変わらないから、全 `n≥0` で `Path_(n,H)(0,1)=∅`。曲線から意味変更経路を作るには、指定点に加えて各段の実際の比較射と必要な翻訳を与えなければならない。

## 定理 G1 — 合法状態の移送fiber

意味保存射 `h₀₁:X₁→X₀` と、合法な開始状態の包含 `ι₀:D₀↪X₀` を固定する。移送規則が指定する原始式・補助選択と、実際の候補 `m:D₀→X₁` をE1と同じ全Hom表示で生成する。定められたphase・状態Lawと

```math
h_{01}m=\iota_0
```

を課す。この全体は、規則・phase条件を課したmap familyから `Hom(D₀,X₀)` への `m↦h₀₁m` の、`ι₀` 上のfiberである。観測が一致するだけの条件に置き換えない。

独立な移送とは、指定規則を満たす実際の `m` と上の条件を満たす全補助選択である。全Homの表示同値は `m` を回復し、合成残差は原始mapの合成と一致するので、fiberとの同値を得る。context制限・係数変更は `h,ι,m` とその保存式を運ぶため、この同値と可換である。mapの存在を仮定するfieldは用いず、fiberが空の場合も含める。

## 定理 G2 — 移送後の共通操作語

`h₀₁` の語翻訳を `τ:Words₁→Words₀`、観測を `o₁=o₀h₀₁` とする。新側の許可語 `w` について、全prefixのphaseとoperation domainを反復pullbackして `Dom₁(w)`、`Dom₀(τw)` を作る。開始domainを

```math
D_w=
m^{-1}\operatorname{Dom}_1(w)
\cap
\iota_0^{-1}\operatorname{Dom}_0(\tau w)
\ \subseteq D_0
```

とする。この交差は、両評価が定義される最大の部分域である。schemeの状態では指定domainのfiber productとして、集合の状態では逆像と交差として読む。

A2の語保存を `m` の像に適用し、`h₀₁m=ι₀` を代入すると `D_w` 上で

```math
h_{01}\operatorname{eval}_1(w)m
=\operatorname{eval}_0(\tau w)h_{01}m
=\operatorname{eval}_0(\tau w)\iota_0.
```

両辺に `o₀` を合成して

```math
o_1\operatorname{eval}_1(w)m
=o_0\operatorname{eval}_0(\tau w)\iota_0
```

を得る。状態の初期移送と、その後の共通語の評価を、同じ `m` の上で比較できる。

旧側の指定語 `v` を移送後にも実行する要求は別の存在条件を持つ。原始語規則から全ての新側の型付き有限語 `w` を生成し、`τw=v`（選択した語の等式の意味で）と指定開始域が `D_w` を経由する条件を課す。語の選択、必要なdomain同定・補助data、移送 `m` を保持した全fiberがその全解である。固定した `m` に対するfiberでも同じ構成を使う。`h` が意味保存だからという理由だけで、旧語のpreimageやdomain liftの存在は導けない。

## 定理 G3 — 移送の合成

続く `h₁₂:X₂→X₁`、`ι₁:D₁↪X₁`、`m₁₂:D₁→X₂` が `h₁₂m₁₂=ι₁` を満たすとする。定義

```math
D_{02}=D_0\times_{m_{01},X_1,\iota_1}D_1,\qquad
m_{02}=m_{12}\operatorname{pr}_2
```

から、fiber productの等式 `ι₁pr₂=m₀₁pr₁` を使って

```math
h_{01}h_{12}m_{02}
=h_{01}\iota_1\operatorname{pr}_2
=h_{01}m_{01}\operatorname{pr}_1
=\iota_0\operatorname{pr}_1
```

を得る。従って `m₀₂` は `D₀₂` 上の合法なliftである。各phase・word domainはこのfiber productへ引き戻し、両段で定義される共通域を取る。G2を二度適用すれば合成翻訳 `τ₀₁*τ₁₂` について同じ観測保存が成立する。

第三の移送を続けると、どちらの括弧でも対象は `(x₀,x₁,x₂)` で `m₀₁(x₀)=ι₁(x₁)`、`m₁₂(x₁)=ι₂(x₂)` を満たすものになる。canonicalなfiber product同型で合成mapと引き戻したphase・domainが一致し、結合則を得る。単位は `D=X`、`ι=m=id`。

もし `m₀₁=ι₁\bar m₀₁` なら、`D₀→D₀₂` を `x↦(x,\bar m₀₁x)` と定める。`pr₁` との一方の合成は恒等。他方も `ι₁` の単射性・monomorphism性によって第二成分が一意に決まるので恒等となり、`D₀₂≅D₀` を得る。係数点が合法であるだけではこの因子分解は保証されず、台帳のBusy例で実際に失敗する。
