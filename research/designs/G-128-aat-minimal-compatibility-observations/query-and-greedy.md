# G-128：問い合わせと有限アルゴリズム

[実装設計](README.md)のB・Cを、同じ群作用・適合部分群・点観測について構成する。
問い合わせ回数と選択した観測点数を定量化し、有限表を処理する各関数には停止と正確性を証明する。

## 1. 有限入力と共通の観測表

数学的対象には `Group G`、`MulAction G X`、`Gamma : Subgroup G` を使う。
実行入力にはG-127の `ExplicitEnumeration G`、`ExplicitEnumeration X`、
両型の等号判定、`Gamma` の所属判定、群演算と作用の表を使う。
表の群・作用・部分群公理がGOAL Cの入力条件である。

`ExplicitEnumeration` が要求するのは列挙の完全性であり、重複がないことは要求していない。
濃度・集合演算は `values.toFinset` 上で行い、greedyの同数処理には元のリスト順を使う。
有限量化用の `Fintype` は既存の `ExplicitEnumeration.toFintype` で構成する。

共通の関数は次の責務を持つ。名称は設計上の案である。

| 関数 | 入力 | 実行して返すもの |
| --- | --- | --- |
| `observe` | `B,g` | 点ごとの作用値からなる表 |
| `findExtension` | `B,t` | `O_B(g)=t` を満たす `Option G` |
| `findCompatibleExtension` | `B,t` | 上の条件と `g ∈ Gamma` を満たす `Option G` |
| `classify` | `B,t` | `findCompatibleExtension` の成功を表す `Bool` |
| `minimumObservation` | 群・作用・部分群の表 | 十分な最小 `B`、または全点を固定する不適合な `k` |
| `greedyObservation` | 同じ表 | greedyが選んだ十分な `B`、または同じ種類の `k` |

選択手続きの結果は集合または元を持つ和型とし、正確性は返された値についての定理として証明する。
`minimumObservation` の有限値は返した集合の `card` とする。

## 2. B：適応的手続きを有限な実行記録で扱う

### 2.1 問い合わせモデル

履歴を質問と答えの有限リスト `List (X × X)` とする。
決定的手続きの次の動作は

```text
next : List (X × X) → Bool ⊕ X
```

で表す。左側は適合性の判定結果、右側は次に問い合わせる点である。
`next` は既知の入力表を利用できるが、未知の `g` は引数に持たない。
未知の変更が情報として入る箇所は、質問 `x` に答え `g • x` を追加する操作だけとする。

`Run next g history result count` を次の二つの規則による帰納的関係として定義する。

1. `next history = inl result` なら、追加の問い合わせ0回でその結果を返す。
2. `next history = inr x` で、`(x,g • x)` を履歴に追加した実行が `n` 回で終了するなら、
   元の履歴からは `n+1` 回で同じ結果を返す。

決定性から、同じ `next,g,history` の終了結果と回数の一意性を証明する。
許された手続きの条件は、各 `g : G` について空履歴から有限の `Run` が存在し、
結果が `g ∈ Gamma` の真偽と一致することである。
同じ点を繰り返したときも規則2を一回ずつ適用する。

各 `g` の有限回数を一意に定め、有限な `G` 上の最大値を `worstQueries` とする。
全ての許された手続きについてその値の `ℕ∞` での下限を取り、`D_Gamma` とする。
全入力での停止から有限な最大値を導出し、一様な回数上限を追加の入力条件にしない。
許された手続きがない場合は空の下限が `∞` になる。

このモデルは、質問が過去の答えに依存する手続きをそのまま扱う。
一般の手続きを固定質問列に制限せず、また全ての手続きを列挙する関数も作らない。
実行記録の帰納法と有限な最大値だけを問い合わせ下限の証明に使う。

### 2.2 恒等元での実行による下限

任意の許された `next` を恒等元 `1` に実行する。この実行で質問された点の集合を
`B₁`、問い合わせ回数を `q₁` とする。重複を除くことで $`|B_1|\le q_1`$ となる。

新しい主要補題は、**`B₁` の全点を固定する元に対して、同じ質問と答えの列が生じる**
という実行の一致である。実行記録に沿う帰納法で、次の質問は同じ履歴から選ばれ、
その答えも $`k\cdot x=x=1\cdot x`$ となることを示す。
最終結果も恒等元の場合と同じなので、正答性から $`k\in\Gamma`$ を得る。
従って `B₁` は十分であり、

```math
b_\Gamma\le |B_1|\le q_1\le\operatorname{worstQueries}(\mathrm{next})
```

となる。適応的な手続き全体について下限を取って $`b_\Gamma\le D_\Gamma`$ を得る。

### 2.3 固定集合による上限

十分な有限集合 `B` を重複なく一巡して観測表を作り、`classify B` を呼ぶ手続きを構成する。
履歴から次の質問位置を決め、実現しない履歴にも既定の終了動作を与えて `next` を全域にする。
この手続きの全ての実際の実行について、問い合わせ回数がちょうど `B.card` であることを示す。
`classify` の正答性は3.1の延長探索とA1から得る。

Aの最小集合を用いて $`D_\Gamma\le b_\Gamma`$ を証明する。
$`b_\Gamma=\infty`$ の場合には2.2が全ての有限停止・正答手続きを排除する。
以上からGOAL B1を得る。Cの最小集合をこの固定質問列へ変換すれば、
有限表から最適な手続きも構成できる。

## 3. C：共通の有限探索

### 3.1 観測表の延長と正確な判定

`findExtension` は入力された全 `g` の列を走査し、全ての `x∈B` で
`g • x = t x` となる最初の候補を返す。
`findCompatibleExtension` は同じ走査に `g ∈ Gamma` の条件を加える。
列の長さに沿う再帰で停止し、列挙の完全性から次を証明する。

- `some g` のとき、返した同じ `g` が指定された全ての等式を満たす。
- `none` のとき、独立に定義した `G` または `Gamma` の中に延長は存在しない。
- 成功と延長の存在が同値になる。

任意の表 `t` を対象とし、実現可能性や整合性を事前条件に加えない。
`B` が十分な場合、`classify B (observe B g)` が適合性を正確に返すことをA1から示す。
`classify` は適合する変更を一つ探せばよく、未知の `g` 自身を特定する必要はない。

### 3.2 集合被覆への対応

入力列を集合にして

```math
U=\{g\in G\mid g\notin\Gamma\},\qquad
S_x=\{g\in U\mid g\cdot x\ne x\}
```

を `Finset` で構成する。Aの `Sufficient B` と
$`U=\bigcup_{x\in B}S_x`$ の同値を元ごとに証明する。
これにより、選ぶ点を評価する基準が元の適合性判定と一致する。

有限な `X` 全体でも被覆できない場合、未被覆の `k∈U` は全 `x : X` を固定する。
逆にそのような `k` があれば全ての `B` が不十分になる。
この同値とA・Bを使い、Cの失敗結果を $`b_\Gamma=D_\Gamma=\infty`$ に接続する。
一般の無限作用での「全点を固定する一つの元」の存在を主張せず、有限なCの入力で証明する。

### 3.3 最小集合

`X` の有限全集合の `Finset.powerset` を走査し、被覆する集合のうち濃度が最小のものを返す。
有限走査の帰納法で、保持中の候補が既に調べた被覆集合の中で最小であることを示す。
全集合が被覆しない場合は3.2の未被覆元を返す。

最小性は全ての `Finset X` について証明する。候補が入力の冪集合列挙に含まれることを使い、
列の一部だけに対する最小性で終わらせない。
出力の濃度とAの `b_Gamma` を一致させ、Bの固定質問列へ渡す。

## 4. C：greedyの実行関数と停止・正確性

### 4.1 選択規則

再帰の状態は未被覆集合 `R⊆U` とする。初期値は `U` である。
各 `x` の新規被覆数を $`c_R(x)=|S_x\cap R|`$ とする。
入力の点リストを先頭から走査して最大の候補を保持し、**厳密に大きい場合だけ更新する**。
これにより、同数の最大値なら入力列挙で最初に現れた点を選ぶ。
入力リストの完全性から、返した点が全 `X` で最大であることを示す。

| 状態 | 動作 | 証明する性質 |
| --- | --- | --- |
| `R=∅` | 空の選択列を返す | 残りは被覆済み |
| `R≠∅`、最大新規被覆数が正 | 最大の点 `x` を選び、`R \ S_x` へ再帰する | `R.card` が厳密に減少する |
| `R≠∅`、点がない、または最大値が0 | `R` の元 `k` を入力の群列挙から選んで返す | `k∉Gamma` かつ全点を固定する |

停止測度は `R.card` とし、外部から探索回数を与えない。
選択済みの点は残りの元を一つも覆わないため、正の新規被覆数を持つ点として再選択されない。
成功時の点列が重複を持たないことを示し、その長さと返す `Finset` の濃度を一致させる。

失敗時には、既に選んだ点があっても、最後に残った `k` が全ての点に固定されることを
最大値0の性質から示す。成功時には再帰で除いた集合を合わせて初期の `U` 全体を覆う。
従って両方の分岐が3.2の同じ十分性・判定不能の命題を返す。

### 4.2 最小探索との独立性

greedyは作用表、被覆集合、新規被覆数だけから点を選ぶ。
実行中に `minimumObservation`、最適集合、`b_Gamma` の値を参照しない。
最適集合は次節の証明で比較対象としてのみ使う。
`U=∅` は直ちに空集合を返すため、`Gamma=G` の場合も同じ実行関数で扱える。

## 5. C：調和数による近似保証

被覆可能な `U≠∅` を考える。最適集合に限らず、任意の被覆集合 `B*` を固定し、
$`b=|B^*|>0`$ とする。最初に次の強い形を証明し、その後Aの最小集合を代入する。

```math
|B_{\mathrm{gr}}|\le b\,H_{|U|}.
```

### 5.1 一回の選択で覆う数

残りを `R`、$`n=|R|>0`$、greedyが覆う数を `k` とする。
`B*` は `R` も覆うため、

```math
n=\left|\bigcup_{x\in B^*}(S_x\cap R)\right|
\le\sum_{x\in B^*}|S_x\cap R|
\le b k.
```

最後の不等式に最大新規被覆の選択規則を使う。
mathlibの `Finset.card_biUnion_le`、`Finset.card_biUnion_le_card_mul` を使い、
有限和と濃度の一般論を再実装しない。ここから $`k>0`$ と $`k/n\ge1/b`$ を得る。

### 5.2 調和数の減少量

mathlibの `harmonic : ℕ → ℚ` と `harmonic_succ` を使い、
$`0<k\le n`$ に対する次の補題を新しく証明する。

```math
H_n-H_{n-k}
=\sum_{j=n-k+1}^{n}\frac1j
\ge\frac{k}{n}
\ge\frac1b.
```

逆数の比較には $`1\le j\le n`$ を使う。
自然数の引き算を扱う箇所では `k≤n` を先に証明し、各除算の分母が正であることを明示する。
数値比較は `ℚ` で完結させる。

一回の選択ごとに $`bH_{|R|}`$ は少なくとも1減り、終了時には $`H_0=0`$ になる。
`R.card` による強い帰納法で、残りからの選択回数が $`bH_{|R|}`$ 以下であることを示す。
4.1で得た選択列の重複のなさから、回数を最終集合の濃度に置き換える。

最後にAの達成された最小集合 `B*` を用い、$`|B^*|=b_\Gamma`$ の有限値を
自然数として取り出して `ℚ` に写す。これによりGOAL C1を得る。
`∞` を `toNat` で無条件に数値化せず、被覆可能性から有限性を導出してから比較する。
`U=∅` は実行関数の空集合出力で扱い、除算を含む証明に入れない。

## 6. 証明と実行を確認する単位

| 対象 | 確認する内容 |
| --- | --- |
| 問い合わせモデル | 次の質問が未知の元を直接読めないこと、全入力での停止から最悪回数を作ること、再問い合わせも数えること |
| 下限 | 恒等元の実行から得た同じ `B₁` が十分となること、適応的な全手続きを量化していること |
| 延長・判定 | 任意の表の実現可能性と適合する延長の存在を別々に判定し、返した元が元の作用の等式を満たすこと |
| 最小探索 | 冪集合列挙の完全性、空集合、最小濃度と `b_Gamma` の一致、判定不能の実際の元 |
| greedy | 最大値・入力順の同数処理・重複列挙・`X=∅`・`U=∅`・途中で被覆不能になる場合 |
| 近似保証 | 実際の選択規則から `n≤bk` を証明し、同じ実行の点数へ調和数の帰納法を適用していること |
| 操作系への適用 | [固定例](README.md#6-固定例の再利用と新しい結論)の原始表から生成した群・作用で、同じ各関数の出力を証明すること |

実装する費用のモデルは点評価の回数である。手続き間の計算、群の候補表生成、
有限集合や有理数の演算については、GOAL Cの範囲で停止と正確性を扱う。
問い合わせモデル、有限集合の再帰、既存の調和数APIが、この結論に必要な構成となる。
