# G-132：有限Alexandrov実被覆と指定例

[GOAL W1–W3](../../goals/G-132-aat-visible-cycle-reflection.md)の原始表、実被覆への構成、
局所データの計算を固定する。以下の計算は証明設計であり、実切断・既存障害類へのLean接続を
含む全証明は後続の構成義務である。

## 1. 有限単純グラフを実被覆にする

有限単純グラフの頂点集合 $`V`$ と無向辺集合 $`E`$ から、点集合
$`X=V\sqcup E`$ に反射律と、頂点がその接続辺点以下である関係を入れる。
それ以外の異なる点間の順序はない。上集合を開とするAlexandrov位相を使い、

```math
U_i=\uparrow i=\{i\}\cup\{e:i\text{ は }e\text{ の端点}\}
```

とする。各 $`U_i`$ は最小点 $`i`$ を持つので非空連結であり、全点を被覆する。
異なる $`i,j`$ に対し、$`ij\in E`$ なら交差は一つの辺点 $`\{ij\}`$、
そうでなければ空である。相異なる三頂点に接続する辺はなく、三重交差は空になる。
したがって全非空二重交差を収載したnerveは元の単純グラフそのものである。

この構成は、図に三角形があっても実三重交差を作らない。
平行辺を許すと同じ二chartの交差が複数の孤立した辺点になり連結性を失うので、
T0の実現には単純グラフを用いる。

point Atomと後述の原始生成子Atomから[構成方針 §2.2](README.md#22-aat-siteと層の生成経路)の
siteを作り、開集合contextとproduct context、実restriction、admissible cover、
support functorのcontinuityを証明する。target台は以下の表から `TargetSupportedNerve`
へ載せる。全原始データから係数層を作り、定数関数を実局所切断として使用する。
target台が共通targetを含むことは、幾何点の三重交差を意味しない。

## 2. W1：三角形と樹木

頂点は $`0,1,2,3`$、向き付き辺の表示順は $`01,02,12,23`$ とする。
実空間は4頂点点と4辺点の計8点である。

Sourceは $`\{c,r_{01},r_{02},r_{12}\}`$、readingは恒等、一つのLawを
$`v(c)=0`$、$`v(r_{ij})=1`$ とする。原始関係は
$`r_{01}Rr_{02}`$、$`r_{02}Rr_{12}`$ の二本で、対称・推移閉包から $`R_q`$ を証明する。
Law indexは一つなので、生成子の表示ではそれを省略する。
係数商は同じ原始関係から $`M_R\cong\mathbb Zu_0\oplus\mathbb Zu_1`$ となる。

| chart | 実開集合 | 原始target台 |
| --- | --- | --- |
| 0 | $`\{0,01,02\}`$ | $`\{c,r_{01},r_{02}\}`$ |
| 1 | $`\{1,01,12\}`$ | $`\{c,r_{01},r_{12}\}`$ |
| 2 | $`\{2,02,12,23\}`$ | $`\{c,r_{02},r_{12}\}`$ |
| 3 | $`\{3,23\}`$ | $`\{c\}`$ |

実辺のtarget台は順に $`\{c,r_{01}\},\{c,r_{02}\},\{c,r_{12}\},\{c\}`$。
ラベル0は全体、ラベル1は三角形012だけに現れる。23は唯一の橋なので、全ラベルで
(B3)が成立する。$`N_1`$ の閉路 $`0,1,2,0`$ は $`H_1(N;\mathbb Q)`$ を生成する。
ラベル1はchart 3で現れず、`CommonLabelChartSupport` は偽となる。

整数chart値 $`h=(0,u_1,0,u_1)`$ とし、実切断として $`p=0`$、
$`\xi=d^0h=(u_1,0,-u_1,u_1)`$ を作る。mismatchは非零で、可視三辺の診断も
非零cochainである。その類は零であり、可視ラベル1の有理証人

```math
(b_{0,1},b_{1,1},b_{2,1})=(1/2,3/2,1/2)
```

を使える。ラベル0の証人は全chartで零とする。
不可視chart 3のラベル1の値を $`3/2`$ と構成すると、全Nで整数辺差が一致し、floorは
ちょうど $`h`$ を返す。ここでchart 3へ単に零を補うと辺23の差が合わない。
整数補正 $`n=h`$ により補正後の状態は $`-h`$ となり、
$`\xi_{ij}+(-h_j)-(-h_i)=0`$ から $`\mathcal T_\xi`$ の大域状態へ貼り合う。

可視条件がすべての入力で有効であることはBへ適用して証明し、上の一つの零障害例だけでは
済ませない。補助計算として $`\xi_{01}=u_1`$、他を零に変えると、可視三角形のperiodが
$`u_1`$ になり、障害・診断とも非零となる。

## 3. W2：二三角形の片方だけが可視

頂点は $`0,1,2,3,4`$、辺集合は $`\{01,02,12,03,04,34\}`$。
実空間は5頂点点と6辺点の計11点で、二三角形012・034が頂点0を共有する。
Source・Law・reading・原始関係はW1と同じにする。

| chart | 実開集合 | 原始target台 |
| --- | --- | --- |
| 0 | $`\{0,01,02,03,04\}`$ | $`\{c,r_{01},r_{02}\}`$ |
| 1 | $`\{1,01,12\}`$ | $`\{c,r_{01},r_{12}\}`$ |
| 2 | $`\{2,02,12\}`$ | $`\{c,r_{02},r_{12}\}`$ |
| 3 | $`\{3,03,34\}`$ | $`\{c\}`$ |
| 4 | $`\{4,04,34\}`$ | $`\{c\}`$ |

全辺が非橋辺で、ラベル1は012の三辺のみ可視となる。
$`\dim H_1(N;\mathbb Q)=2`$、$`\dim H_1(N_1;\mathbb Q)=1`$ で、包含は全射でない。

実辺34の定数切断を $`\xi_{34}=u_1`$、他辺とchart状態を零にする。
34の診断にはラベル0しかなく、$`\varepsilon_R(u_1)(0)=0`$ であるため診断cochainは零。
閉路 $`\gamma=(0,3,4,0)`$ のperiodは

```math
\xi_{03}+\xi_{34}-\xi_{04}=u_1\ne0
```

となる。任意のcoboundaryではこの式が望遠和で零になるので、実Čech障害類と
`existingDescentAdditiveClass` は非零である。ここで $`R_q`$ と係数比較の単射性は
成立している。失われた情報はラベル1の可視辺が欠けることから生じる。

Cの決定的な検算では、ラベルを0,1、辺の探索順を01,02,12,34,03,04とし、
最初の欠落対を $`(1,34)`$ にする。34を除いて3から4へ進む道 $`3,0,4`$ と34から
同じ閉路を向きの反転まで得る。戻される実入力のperiodはその向きに応じて
$`u_1`$ または $`-u_1`$ となり、いずれも非零である。
探索順の違いは一般定理Cの正確性を変えない。

## 4. W3：森での成立

道 $`0-1-2`$ を取り、実空間は3頂点点と2辺点の計5点とする。
Sourceは $`\{c,r_0\}`$、恒等reading、一つのLawで $`v(c)=0,v(r_0)=1`$。
原始関係は空で、同ラベルの生成子は元から等しいため $`R_q`$ が成立する。
target台は $`T_0=\{c,r_0\}`$、$`T_1=T_2=\{c\}`$ とする。

両辺は橋で、ラベル1の可視部分は孤立頂点0のみである。
H₁は零なので(B2)・(B3)が成立する。
$`p=0,\xi_{01}=0,\xi_{12}=u_1`$ とし、
$`n=(0,0,u_1)`$ を実切断にすると $`d^0n=\xi`$ である。
診断cochainは零、mismatchは非零で、補正後 $`-n`$ は同じ遷移の下で貼り合う。
Cは成功を返す。全零cochainだけを例示することは避ける。

## 5. 台の読取りを区別する補助例

三角形012に、一つのLaw、target $`c,s_0,s_1,s_2`$、値
$`v(c)=0,v(s_i)=1`$、$`T_i=\{c,s_i\}`$ を置く。
原始関係 $`s_0Rs_1,s_1Rs_2`$ で $`R_q`$ を満たす。
ラベル1は全頂点で見えるが、すべての実辺のtarget台は $`\{c\}`$ である。
従ってラベル1の可視辺は一本もない。
この補助例は「両端に同ラベルがあれば可視辺」という誤った生成を検出する。
W1–W3の代わりにせず、座標同値と表decodeの確認に使う。

## 6. Leanで対応させる証拠

各例で、原始表、adequacyと $`R_q`$、Atom carrierと原始関係、open coverと全交差、
`FaceEmptyAATCechCover`、Law座標、実切断、既存descent類を同じ入力から作る。
有限graphのrank・橋だけで確認を終えず、Aの実比較を明示適用する。
W1・W3では補正後の状態層の大域切断、W2では同じ既存類の非零性まで追う。
各例の有限表をCへ渡し、返された証拠の実入力への復元と停止・正確性を確認する。
