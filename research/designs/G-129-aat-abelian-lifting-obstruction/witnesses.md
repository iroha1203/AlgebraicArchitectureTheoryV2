# G-129：3-cellと具体例の構成

[GOALの完了条件2–4](../../goals/G-129-aat-abelian-lifting-obstruction.md#完了条件)に対し、
同じ一般定理へ渡す原始入力、仮定の証明、評価する写像を定める。
既存宣言の所在と再利用の単位は[再利用対応表](reuse-map.md)を参照する。

## 1. 共通の面と3-cell

`SquarePresentation` は一頂点、一ループ $`e`$、面
$`f:e^2\Rightarrow\varnothing`$、一つの3-cell $`\sigma`$ から作る。
3-cellの二つの貼り合わせは同じ $`e^3`$ から同じ $`e`$ へ至る。

| 貼り合わせ | incoming | localBefore | outgoing | 書き換え |
| --- | --- | --- | --- | --- |
| $`P_\sigma`$ | 空道 | $`e^2`$ | $`e`$ | 先頭の二辺を消す |
| $`Q_\sigma`$ | $`e`$ | $`e^2`$ | 空道 | 末尾の二辺を消す |

各行を `WhiskeredFace.asStep` と、一段の `RewritePasting.cons` で作る。
`before_eq`・`after_eq` を同じ道の定義から証明して `threeLeft`・`threeRight` に格納する。
それぞれの貼り合わせの面の出現は一つで、二つの接尾辞の違いを保持する。

一頂点の係数を $`A`$、辺の輸送を $`\rho`$ とすると、面への降下は $`\rho^2=1`$ となる。
各次数の一成分への評価を加法群同型にし、一般の微分が次の写像になることを証明する。

```math
d^0=1-\rho,\qquad d^1=1+\rho,\qquad d^2=\rho-1.
```

$`P_\sigma`$ の面の値は後続の $`e`$ で輸送され、$`Q_\sigma`$ の値はそのままなので、
最後の符号は $`\rho-1`$ である。表示の型付きデータからこの式を導く。
面の繰り返しを集合として潰すと $`d^1`$ が変わるため、道の各出現を再帰式で数える。

三つの例はいずれもこの表示を使う。
空道・接尾辞・同一辺の反復を含む微分の評価と、条件4の貼り合わせ等式を同じ入力で確認する。

## 2. G-127の実際の非分裂拡大

原始入力は `twoVertexInput`・`twoVertexData` とし、
元の可視射影 `twoVertexActualProjection` を使う。
`twoVertexC4`、`twoVertexC2`、`twoVertex_projection_is_mod_two` を組み合わせて、
同じ射影を $`C_4\to C_2`$ の表示へ移す。

一般の群拡大アダプタはG-127の `projectionToLiftable` を入力とする。
指定例では `twoVertex_projection_surjective` から持ち上げ可能な像と元の可視群の
群同型を作り、両射影との可換式を示す。係数の核はこの可換図式から移す。

有限表示への割当ては $`a_e=1\in\mathbb Z/2`$、基準の持ち上げは
$`1\in\mathbb Z/4`$ とする。元の辺と指定比較は恒等とする。
核の元 $`1\in C_2`$ は $`2\in C_4`$ に対応する。

| 評価対象 | 求める値 |
| --- | --- |
| 核・輸送 | $`A=C_2,\ \rho=1`$ |
| 辺の持ち上げ | 同じ可視元上の $`1,3\in C_4`$ |
| 面の標準比較 | $`m_f=-2=2\in C_4`$ |
| 実際のdefect | $`u_fm_f^{-1}=2`$、核表示では $`\delta=1`$ |
| 微分 | $`d^0=0,\ d^1=2=0,\ d^2=0`$ |
| 二次障害 | $`H^2(K;C_2)\cong C_2,\ [\delta]=1\ne0`$ |
| 3-cell | 指定比較の両貼り合わせは恒等、$`d^2\delta=0`$ |

二つの持ち上げで同じdefectとなることを、実際の群の平方と補正公式の双方で確認する。
非零障害から一般定理Bを用いて整合する持ち上げの不存在を導く。
元の射影の群準同型sectionがあれば、非自明な可視元の像は平方が恒等の持ち上げを与えるため矛盾する。
これを既存の `twoVertex_no_group_section` と同じ元・射影について対応させる。

## 3. 非自明な係数作用を持つ `S_3` の例

群は `Equiv.Perm (Fin 3)`、射影は `Equiv.Perm.sign` とする。
mathlibの符号の行先は `ℤˣ` なので、
$`0\mapsto1,\ 1\mapsto-1`$ による `Multiplicative (ZMod 2)` との群同型を構成する。

$`r=(012)`$、$`s=(01)`$ を実際の置換として定義する。
`Multiplicative (ZMod 3)` から符号の核への写像を $`k\mapsto r^k`$ で構成し、
三つの偶置換の列挙から全射性、次数3から単射性を証明する。
これを係数の同型として使い、核を別の抽象群で置き換えるだけの適用にしない。

可視辺の値を非自明元、基準の持ち上げを $`s`$、指定比較を恒等とする。
実際の置換の積から $`srs^{-1}=r^{-1}`$ と $`s^2=1`$ を示す。
同じ群拡大アダプタの輸送の特徴づけによって $`\rho=-1`$ を得る。

```math
\delta=0,\qquad d^0=2,\qquad d^1=0,\qquad
d^2=-2=\operatorname{id}_{C_3}.
```

ここでは3-cellによる二次微分は非零である。
条件4を実際の恒等比較の貼り合わせで証明し、
$`d^2\delta=0`$ と $`H^2(K;C_3)=0`$ を同じ微分から計算する。

解集合は $`\{s,rs,r^2s\}`$、すなわち三つの互換に一致する。
辺の核補正 $`h`$ は添字 $`i`$ を $`i+h`$ へ移し、
頂点での共役 $`b`$ は $`i`$ を $`i+2b`$ へ移す。
これを一般の作用の評価として示し、$`Z^1\cong C_3`$ の自由・推移性と
$`H^1=0`$ による単一の同値類を得る。

## 4. 第4章の幾何package

### 4.1 再利用する原始データ

第一候補は `FiniteCrossStageWitness.package` とする。
有限Atom carrier、対角的な `Int × Int` 係数の `symmetricRaw`、
`site_nonempty`、`has_actual_cover`、`raw_relation_nonzero`、
非恒等な `innerSwap` を再利用できる。

このpackageの実際の核を $`A=\operatorname{InnerFiberAut}(G)`$ とする。
核の可換性は以下の全成分の証明を通じて確認し、一般定理への入力にはその証明を渡す。

### 4.2 核全体の可換性

`GeomReadHom` の計算成分は係数写像だけではなく、全site対象にわたる
`supportComp`・`axisComp`・`observableComp` を含む。
`innerSwap_ne_one` と係数環の自己同型群の計算は、核全体の可換性を証明する一部である。

任意の $`\alpha,\beta\in A`$ について、core上の射が恒等であることを用いて型変換をそろえ、
次を証明する。

| 成分 | 必要な等式と証明経路 |
| --- | --- |
| 係数 | `Int × Int` の環自己同型を恒等と交換に分類し、二つの係数写像の合成が可換と示す |
| support | 各文脈・各supportで二つの比較写像の合成が可換と示す。読み取り保存と文脈射への自然性を使う |
| axis | 同じく各文脈・各axisで合成の可換性を示す |
| observable | 反変の制限への自然性を保持して、各文脈・各observableで合成の可換性を示す |

三つの文脈成分が恒等に強制されることを示せれば、係数写像への単射性から核の可換性を得られる。
その強制を使う場合は、各元を区別する文脈と選択された読み取り射を明示して証明する。
有限Atom carrierや署名の有限性だけで、任意のsite対象にわたる自然性を代替しない。
最後に `GeomReadHom.ext`・`GeometryTotalHom.ext` と自己同型の外延性を適用する。

この全成分の証明が第一候補の採用条件である。核の一部の可換部分群を係数に採用する変更は
GOALの実際の核を変えるため行わない。第一候補に非可換な核成分がある場合は、
GOALが許す具体入力の選択として別の幾何packageを構成し、同じ全成分の可換性と
完了条件4の非自明性を証明する。一般定理へ渡す可換性を追加の未放電仮定にしない。

### 4.3 辺・指定比較・3-cell

同じ `SquarePresentation` と採用packageに
`IdentityEdgeLiftSpecialization.data` を適用する。
すべての辺を恒等、coreの再選択とその持ち上げを恒等、
唯一の指定比較を $`u_f=\operatorname{innerFiberInclusion}(s)`$ とする。
第一候補では $`s=\texttt{innerSwap}`$ とする。

| 条件 | 原始入力からの証明 |
| --- | --- |
| 強いopcartesian性 | 既存の恒等辺の構成が `IsStronglyCocartesian.of_iso` から生成する |
| (A2) | 核自己同型の射影と、二つの恒等のcore道の計算 |
| 条件1 | 4.2で証明する実際の核全体の可換性 |
| 条件2 | 恒等の辺に沿う輸送の特徴づけから `ρ=id` を導き、全単射性を得る |
| 条件3 | `u_f` が実際の核に属することと条件1 |
| 条件4 | 二つの接尾辞の輸送が恒等なので、両貼り合わせが同じ非恒等な `s` になる |

標準比較は `upper_canonical_eq_one` から恒等となる。
`sectionInnerObstruction` の包含を計算し、$`\delta=s`$ を得る。
係数を加法で書けば

```math
d^0=0,\qquad d^1=2,\qquad d^2=0,\qquad
H^2(K;A)\cong A/2A,\qquad o=[s].
```

第一候補の係数交換では $`[s]\ne0`$ を次の経路で判定する。
任意の核自己同型から、実際の係数写像と逆写像により `Int × Int` の環自己同型を作る。
その平方は $`(1,0)`$ を固定する一方、`innerSwap` は $`(0,1)`$ へ送る。
従って核に $`2h=s`$ の解はなく、同じ商の障害は非零となる。
一般定理Bから整合する持ち上げが存在しないことを得る。

この判定には核全体が $`C_2`$ であるという追加の分類は必要ない。
必要なのは実際の核の可換性、非恒等な比較、同じ係数写像での平方の評価である。
既存の `RootEffectivityWitness` の平方の補題は別packageの宣言なので、
環自己同型についての共通補題と、採用packageの係数写像との接続を作って使う。

## 5. 具体例の受入条件

三つの例では `SquarePresentation`、一般の微分・defect・障害類をそのまま特殊化する。
各例の簡単な座標表示は、元の群・核・射影への同型と、その写像の評価式を介して使う。

G-127では障害から元の可視射影の非分裂へ戻り、`S_3` では実際の三つの互換への作用を評価する。
幾何packageでは、同じ原始データからAの全仮定を証明し、
第4章の `sectionInnerObstruction` と同じ自己同型が障害の代表になることを確認する。
これらの計算結果と宣言・仮定の使用先を対応するreportへ記録する。
