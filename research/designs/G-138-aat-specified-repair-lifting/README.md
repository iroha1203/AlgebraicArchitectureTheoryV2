# G-138：指定補正の持ち上げと比較

研究目標と量化は[GOAL](../../goals/G-138-aat-specified-repair-lifting.md)にある。
本設計は[接続・有限構成](connections-and-computation.md)、[指定例](witnesses.md)、
[再利用対応](reuse-map.md)と合わせて読む。条項記号はGOALを指す。

## 1. 三つの構成経路

| 経路 | 入力から作る対象 | 到達点 |
| --- | --- | --- |
| 一般理論 | 非負アーベル複体、φ、z,b → 標準錐・指定類・kφ | A–Cの同値、全解、自然性 |
| AAT適用 | 元のG-125係数層・実Čech・Law → 実cochain比較 | Dの同じ補正と余核類 |
| 整数算法 | 生成元・関係・行列・代表 → 商複体・同時方程式 | Eの停止判定と元の全解への復元 |

先に一般理論を証明し、後二経路を同じ対象へ接続する。AAT入力からの比較を、
一般定理へ入れやすい別の線形写像で置き換えない。算法の出力でLiftを定義しない。
Liftは元のcochain等式から独立に定義し、出力との両方向対応を証明する。

## 2. 標準複体と符号

共通の圏は `ModuleCat ℤ` を第一候補とし、加法準同型を整数線形写像へ移す。
`AddCommGrpCat`を採る場合も同じ標準cohomology・mapping coneへ接続する。
一般入力はℕ次数の複体、標準錐はℤ次数。零延長が元の次数0・1のcohomologyを保つ
同型と、その代表元評価式を構成する。一般C,Dの次数2以降を零に置き換えない。

G-133の `coneCoordinateEquiv` はtarget/source順の座標を与えるが係数ℚに固定される。
その証明方針を整数加群へ一般化し、標準mappingConeのinr/inlと射影から同型を構成する。
公開APIは微分、次数−1の包含、可換平方の写像を元ごとに評価できるものとする。

oの代表は(b,−z)。その微分は(d_Db−φ¹z,d_Cz)=0である。
次数−1の元aの微分は(φ⁰a,−d_Ca)だから、Aの零性は二つの厳密等式に等しい。
次数−1を切り落とした錐や、H¹(φ)だけでAを証明しない。

## 3. 余核と解の作用

kφはZ⁰上の制限。jはc∈Z⁰Dを(c,0)の錐類へ送る写像から商に降ろす。
pは錐の第二成分をCのH¹へ送る標準写像を採り、p(o)=−[z]とする。
元のa₀があるとき、(b,−z)−d(0,a₀)=(b−φ⁰a₀,0)がBの比較式を与える。
a₀′との差はZ⁰Cに入り、余核で消える。完全列は標準錐長完全列と代表元式を併用し、
単に同型な群を選ぶだけでj,pの可換性を済ませない。

H=ker kφに対しh+aで作用する。二解a,a′の差a′−aはHに入り、作用元を一意に与える。
空なLiftにも型は定義するが、AddTorsor instanceはNonemptyの下でのみ構成する。
全射性・単射性の必要方向はz=0、任意b∈Z⁰D、およびLift(0,0)から導く。
固定された空fiberの「高々一元」だけでkφの単射性を結論しない。

Cでは可換平方から解の写像を先に作り、錐・Z⁰・核・余核・j,pへの写像を構成する。
同型の場合に限る反映と、一般写像での保存を区別する。

## 5. 固有の弱化検出

| すり替え | 検出箇所 |
| --- | --- |
| Aにa₀を入力する | W4とAの量化の照合 |
| ℚの次元論・free群だけで閉じる | T0とW1・W3、Eの関係行列 |
| bをφ⁰の像から選ぶ | 全適合bの量化、W1・W3の不能例 |
| 厳密一致をcohomologyの一致にする | Aの二等式、元cochainへの復元 |
| 群の濃度やrankだけでtorsorを名乗る | Bの作用・差・両逆、W2・W3の全元式 |
| 同次数の別比較に差し替える | Dの既存次数別射とH¹の可換図式 |
| SNF証明書・解・完全性を入力fieldへ置く | Eの原始行列からの生成と停止証明 |
| 補助未知数・関係の代表を別解として数える | Eの元C⁰での全解同値、W3 |
| 補正の一意性をパラメータ表示の一意性へ移す | W6の非単射な準同型 |

数学的反例はその原始入力と破れる固定条項を記録する。失敗後に適用入力を縮める形で
当初の目標を達成と扱わない。共通のレビューと停止処理はGOALから参照する検査基準に従う。
