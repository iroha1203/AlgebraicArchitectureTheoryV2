## 研究目的

Atom・Law・operationから独立に定めた実現について、対象だけでなく射、比較、
比較を保つ変更まで、明示したパラメータに相対的な有限表示から回復する。
底への投影と観測を同じ対応で運び、G-122の生成比較と変更の分類を表示側から得る。

CS側では、モデル同期の読み出し・更新と、プロトコルの操作・adapterの意味を先に定め、
その意味を保つ変更をAATの比較群へ対応させる。操作で結ばれる状態の間で変更が
一貫する条件から、追随変更の存在と選択の自由度を二つの問題に共通する定理で分類する。
これをn1010のS5、n1012の表示・再構成の主結果とする。

G-119の比較と冪等完備化の交換、G-120の群準同型による分類、G-121の表示可能性、
G-122の完全幾何の生成比較を使う。新しい仕事は独立な実現・構文の構成、
再構成原理の仮定の放電、およびCSの意味との対応である。

## 固定target案

A–Fを一つの主定理の構成部分とする。数学的な対象範囲と構文をAで定め、
その同じ定義についてB–Fを証明する。合成順は `gf=g∘f` とする。
`Arr(C)` は対象が `C` の射、射が可換正方形である圏、`Kar(C)` は冪等完備化を表す。

### A. 独立な実現、入力条件、有限表示

パラメータの型を指定する一つの宣言と、Atom・Law・operation・完全幾何の
データ条件 `D` を構成する。その宣言の任意のパラメータ `Θ` について、
条件 `D_Θ` を満たす実現と、指定した構造を保つすべての写像から圏 `R_Θ` を定める。
対象・射の条件には、表示の存在、decoderの像、冪等射の分裂、retract生成を用いない。

入力宣言では、次の成分ごとに、保持するパラメータの型、有限な生成データ、
評価、射が保つ等式を特定する。

| 成分 | 実現に保持する情報 |
| --- | --- |
| Atom・対象 | configuration、抽出・合成、構造と量のreading、対象形成の選択値 |
| operation | 両端、operationそのものの同一性、configurationへの作用 |
| Law・invariant・signature | 添字、評価、残差、選択条件、座標とそれらの輸送 |
| 完全幾何 | context、coverage、overlap、Support・Axis・Observableと読取り・制限 |
| 係数・raw data | 係数環、座標・関係式、restrictionとその整合 |

同じ `Θ` に対して、有限表示の圏 `P_Θ` とdecoder `F_Θ:P_Θ→R_Θ` を構成する。
対象と射の構文、有限個のパラメータ参照、構文上の等式・合同、恒等・合成、評価を与える。
有限性は各表示の構文・table・参照数について示す。パラメータとして残す無限データと
その許容写像の型も入力宣言に含める。

任意の完成したcore/geometry射を一つの定数として受け取る構成は採らない。
各写像族を生成データから回復する方法を特定し、全域の対象写像、全端点のoperation写像、
全contextの幾何の写像のどれを回復したかを、既存の射の等号に沿って示す。
G-121の可算構文の非全射性を使い、無限の自己同型群を扱う入力宣言との整合を確認する。

`D_Θ` の必須の収録対象は第D条の生成比較の固定例、Cのoperation分離例、Eの二つのCS入力族とする。
これらが条件を満たすことも構成・証明する。`D` を再構成の結論から定めない。

### B. 対象・射・比較の再構成

Aの任意の `Θ` について、次の四つを個別に証明する。

1. **充満性**：任意の `p,q:P_Θ` と `h:F_Θ(p)→F_Θ(q)` に対し、
   同じ端点の表示射 `f:p→q` を構成し、`F_Θ(f)=h` を示す。
2. **忠実性**：任意の表示射 `f,g:p→q` について、`F_Θ(f)=F_Θ(g)` から
   Aで定めた構文の等号 `f=g` を導く。
3. **冪等完備性**：任意の `X:R_Θ` と冪等射 `e:X→X` に対し、
   実現のデータから分裂対象と両射を構成し、`D_Θ` と射の保存則を証明する。
4. **retract生成**：任意の `X:R_Θ` に対し、`p:P_Θ` と
   `i:X→F_Θ(p)`、`r:F_Θ(p)→X` を構成し、`ri=1_X` を示す。

この四つから、同じdecoderを延長する同値

\[
 \overline F_\Theta:\operatorname{Kar}(P_\Theta)\simeq R_\Theta,
 \qquad
 \operatorname{Kar}(\operatorname{Arr}(P_\Theta))
       \simeq\operatorname{Arr}(R_\Theta)
 \tag{B1}
\]

を構成する。後者にはG-119の `karoubiArrowEquivalence` を接続する。
対象の選んだ分裂を `i_p:X_p→F_Θ(p)`、`r_p:F_Θ(p)→X_p` とするとき、
sandwich射 `f:(p,e)→(q,d)` の像を `r_q F_Θ(f) i_p` と同定する。
分裂の選択を変えた場合の自然同型と、その単位・合成の整合も示す。

一般の圏に対する再構成原理では四つの性質を仮定してよい。
AATへの適用ではAのデータから得た証明を渡す。

### C. operationを忘れると失われる変更

G-117の `taggedOperationPackage` とそのcanonical正規化 `e` を固定する。
全端点で一様にBoolタグを反転する自己同型 `t` を構成し、

\[
 t^2=1,\qquad et=te,\qquad et\ne e
 \tag{C1}
\]

を同時に証明する。最後の不等式は `taggedBoolOperation` の初期タグ `false` で評価する。
`et` がKaroubi対象の自己同型であることを示し、対象の固定点だけを読む関手では
`et` と恒等射 `e` の像が一致する一方、Aのoperationを保持する実現では異なることを示す。
既存の端点依存flipとは区別し、この一様flipの可換性を証明する。

### D. 底・観測との整合とG-122の分類の回復

実現側に独立に定めた底への投影・観測と、表示側から生成するそれらについて、
(B1)に沿う自然同型を構成する。底を固定する版では、retractの両射と端点同型の
底での値を計算し、その資格を保存・反映する。同じ対応で係数写像も運ぶ。

`c:X→Y` の比較群を

\[
 \Gamma_c=\{(u,v)\in\operatorname{Aut}(X)\times\operatorname{Aut}(Y)
                  \mid vc=cu\}
 \tag{D1}
\]

とする。(B1)による比較群の同型を構成し、両端の自己同型、底・観測への評価、
許容変更を指定する部分群への制限と整合することを証明する。

G-122への一般接続は、[G-122カードの共通入力とA–D](G-122-aat-full-geometry-normalization.md)
を用い、Aのデータ条件を満たす任意の入力について与える。
対象範囲の宣言から、その条件を満たすG-122入力と許容射を判定できるようにする。
`χ_z` が成立する場合、成立しない場合、canonical正規化の場合について、
実際に生成された `barAlpha`、`barBeta` と両端の冪等射の表示、端点同型を構成する。

この同じ対応で、次を回復する。

- 可逆性と反映の判定、比較を保つ変更のsection、sectionの底・係数成分。
- 制限準同型の分裂短完全列と、各lift fiber上の核の自由かつ推移的な作用。
- 反映不成立を示すambientな核の元と、その元が元の比較を保たないという判定。

元の全比較群と底を固定する比較群を区別し、それぞれについて対象とした群の全元を運ぶ。
ambientな核と制限準同型の核は、型・写像・作用をそれぞれ保つ。
特定のsectionや核の元だけの表示から、比較群全体の回復を結論しない。

必須の生成比較例は、G-122の `finiteAxisFoldBCDatumSquare`、
`finiteAxisFoldFixedCoefficientGeometryFamily`、cell `second`、係数 `ℤ` とする。
生成cochain `initialRawDefectCochain` による `barBeta`、同じ幾何で定数 `1` のcochainを
用いた `barBeta`、同じ入力の `barAlpha` とcanonical正規化を表示する。
これにより三つの場合の入力条件と分類の対応を、具体的な同一入力の族で検証する。

### E. 二つのCS意味論からの入力構成と再構成

次の二族を独立に定める。完全な定義とdecoderの式はn1015の指定節を用いる。

| 族 | 入力・実現の条件 | 表示・要求する結論 |
| --- | --- | --- |
| モデル同期：n1015 §2 | 任意の集合 `V` と `v₀:V`。全域get/putの三法則 (L1)、有限fiber `K_L=g⁻¹(v₀)`。射は (L2) | 有限補完tableの `P_lens`、積lensへの `F_lens`。`c↦(g(c),p(c,v₀))` とその逆を構成し、圏同値とBの四性質を示す |
| プロトコル：n1015 §3 | 有限多重グラフ `Q`、有限経路等式 `L`、商経路圏上の観測 `O`。有限carrier値関手 `X` と `o:X→O`、射は観測を保つ自然変換 | 生成辺・観測のtableによる `P_proto` と経路評価decoder。経路帰納法と有限列挙から圏同値とBの四性質を示す |

各族からAのAtom・Law・operation・完全幾何への入力構成を与え、CSの法則とAATの
保存条件の両方向の対応を証明する。射の翻訳と読み戻しを構成し、独立に指定した
許容射の全範囲で互いに逆、かつ恒等・合成と整合することを示す。
operationの名前と対象形成の選択値を保持する。

モデル同期では任意の `H≤Sym(V)` と可視変更 `u∈H` に対し、(L5)のget・put保存を扱う。
対象形成の基準値を保つ版にはn1015 §2.3のsection `s` とその保存条件を加える。
プロトコルでは既存adapter `q:X→Y`、変更後 `q':X'→Y'` と可逆変更 `a,b` を用い、
状態ごとのadapter維持と全操作の実行保存から `bq=q'a` との対応を証明する。

これらの変更群をDの比較群の許容部分群に対応させる。getとputを一射にまとめる場合は、
`C⊔(C×V)→V⊔C` の端点変更を `h⊔(h×u)` と `u⊔h` に連動させる。
このコピー間・積上の条件と底を固定する条件を別に定め、対応する部分群を構成する。
二つのCSの圏と完全幾何の実現圏の接続には、上の翻訳定理を使う。

### F. 操作の連結性による追随変更の共通分類

任意の有向多重グラフ `Q=(V,E,s,t)`、集合 `K`、`H≤Aut(Q)` を量化する。
状態を `V×K`、観測を `q(v,k)=v`、辺 `e:v→w` の操作を `(v,k)↦(w,k)` とする。
操作名は `e` として保持する。`u∈H` と全単射 `h` の組で `qh=u_Vq` を満たすものは、
唯一の族 `φ_v∈Sym(K)` によって `h(v,k)=(u_V(v),φ_v(k))` と表されることを示す。

操作の実行を保つことと `φ_s(e)=φ_t(e)` が全辺で成り立つことの同値を証明する。
操作の写像も `(e,k)↦(u_E(e),φ_s(e)(k))` として計算する。
向きを忘れた連結成分の集合を `π₀(Q)`、操作も保つ組の群を `A_Q` とすると、

\[
 1\longrightarrow\prod_{j\in\pi_0(Q)}\operatorname{Sym}(K)
 \longrightarrow A_Q\longrightarrow H\longrightarrow1
 \tag{F1}
\]

はsection `u↦(u,((v,k)↦(u_V(v),k)))` により分裂することを示す。
各 `u` 上の追随変更は核のtorsorであり、`V,K` が有限なら個数は
`(|K|!)^{|π₀(Q)|}` となる。`k₀:K` を保つ版では、各置換群をその固定部分群に置き換える。
群の合成では `H` の連結成分への作用を保持する。

Eの積lensには全view間のput操作、プロトコルにはセッションの操作を対応させ、
同じ(F1)を適用する。D・Eの群同型を通じ、表示側からも同じsection・核・fiberを回復する。
群準同型の核・完全性・fiberへの整理にはG-120の `GroupHomRestriction` を接続する。

次の有限例を固定し、各個数と操作保存の失敗を一般定理に接続する。

| 例 | 固定データ・評価 | 同時に成立させる条件 |
| --- | --- | --- |
| lens | `V=K=Bool`、積get/put、`h(v,k)=(v,k xor v)`。`(false,false)` を `true` へ更新 | `h` はgetを保存し、putの二つの順序は `(true,true)` と `(true,false)`。可視変更が恒等・Bool反転の各場合、get保存4個、get/put保存2個 |
| 選択値を保つlens | `V=Bool`、`K=Fin 3`、`s(v)=(v,0)`。`true` のfiberだけで `1,2` を交換し、`(false,1)` を `true` へ更新 | getとsectionを保存し、putを保存しない。同じsection保存の資格で、get保存4個、get/put保存2個。両群に非恒等元がある |
| プロトコル | `V=Fin 4`、辺 `0→1` と `2→3`、`K=Bool` | 可視変更が恒等なら観測保存16個、操作も保存4個。二つの辺を交換する可視変更上の追随変更も4個 |
