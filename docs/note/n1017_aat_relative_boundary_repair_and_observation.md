# n1017: AAT相対境界修復と修復・観測双対性

[n1016](n1016_rising_sea_v2_paper_plan.md) §2.7・§5.4の二つの定理候補に絞り、
数学的な対象、構成と証明、既存研究との差分、CS・ソフトウェア工学への帰結を記述する。
中心となる問いは、次のものである。

> 固定した公開部分と可視の変更を保持しながら、どの操作の補正を許せば全体を修復できるか。
> 各部分から生成した一つの表現で、全ての変更範囲について全修復と不能証拠を回復し、
> 内部の修復を列挙せずに統合可否を判断できるか。その判断と修復の出力に必要な観測を、
> 同じ記号的表現から導けるか。

主定理を**AAT相対境界修復定理**、接続定理を**修復・観測双対性定理**と呼ぶ。
有限体上で線形な全核輸送を持つ入力について、両定理を定義・構成・証明として述べる。
相対化と内部辺分割には可換群で成立する部分もある。既存の数学を用いる箇所と、
元の名前付き操作・固定条件・再同定まで保持する対応を分ける。

## 1. G-127〜129から、何を新しく得るか

三つの出発点を、固定部分を保つ修復という一つの問題へ接続する。

| 出発点 | 用いる構造 | 本構想で加える結論 |
| --- | --- | --- |
| [G-127](../../research/goals/G-127-aat-reversible-protocol-holonomy.md) | 名前付き可逆操作からのholonomy、変更群、持ち上げの群拡大 | 閉路の作用が各補正の有効な方向と極小修復範囲を変えることを示す |
| [G-129](../../research/goals/G-129-aat-abelian-lifting-obstruction.md) | 実射影の核と輸送、面のdefect、核補正、整合持ち上げとその分類 | 名前付き操作の変更範囲を保ち、全ての許容範囲に対する修復groupoidを局所から再構成する |
| [G-128](../../research/goals/G-128-aat-minimal-compatibility-observations.md) | 点安定化群による観測十分性、最小観測数、適応的問い合わせの最悪時下限 | 同じ修復方向と実入力族から、既知の局所情報を条件とする観測十分性・最悪時最適値を導く |

主結論は、**変更範囲を保った全修復の合成**と、その帰結である
**修復可能な変更範囲の完全分類**に置く。各部分から、名前付き辺の補正値、
内部への復元、再同定が辺へ及ぼす作用を持つ修復インターフェースを生成する。
一つの局所表現から、追加補正を許す全ての辺集合について大域修復を回復する。
さらに、包含極小の修復可能範囲を、不能証拠の支持集合族の極小横断集合として特徴づける。
統合判断には公開した境界・候補座標の関係だけを使い、内部自由度と復元データは
各部分に保持する。値を取得する前の記号的生成から、必要な原始観測、存在判定、
数値補正の出力までを同じ実方程式で結ぶ。

構成上の要点は、再同定を延長する貼り合わせが、禁止された辺の変更を必要とし得る点にある。
§2.5の反例を踏まえ、共有部分の再同定と、その実現に必要な実補正を一緒に扱う。
内部の置換についても、各変更範囲の修復とその復元を保持する条件を定める。

数学的な中心は、相対コホモロジー、groupoidのdescent、線形関係の消去と双対性である。
AATで構成する対応は、元の射と保存条件を保持する次の一連の写像である。

```math
\text{実操作・指定比較・固定部分・候補辺}
\longrightarrow\text{実核・輸送・相対複体}
\longrightarrow\text{変更範囲を保持する局所表現と合成}
\longrightarrow\text{全修復・極小修復範囲・障害・観測}
\longrightarrow\text{元の操作への補正}.
```

## 2. 主定理の対象と主張

### 2.1 原始入力と、固定する部分

G-129の `FiniteTransportPresentation` と同じ種類の有限表示を $`K`$ とする。
頂点、名前付き辺、平行な二つの経路を持つ面、面の型付き書き換え列を比較する3-cellを含む。
圏の塔 $`\mathcal E\xrightarrow p\mathcal B\xrightarrow q\mathcal D`$、頂点の対象、
元の辺の射、coreの整合する選択、その辺ごとの持ち上げ $`\widetilde L_e`$、
面の指定比較 $`u_f`$ を固定する。合成は $`yx=y\circ x`$ の順で書く。

具体的には、元辺 $`L_e^{\mathrm{orig}}:X_{s(e)}\to X_{t(e)}`$ は $`qp`$ に関して
強いopcartesian射、その像 $`p(L_e^{\mathrm{orig}})`$ は $`q`$ に関して強いopcartesian射とする。
core再選択とその持ち上げを

```math
\kappa_e\in\operatorname{Aut}_q(pX_{t(e)}),\qquad
\widetilde c_e\in\operatorname{Aut}_{qp}(X_{t(e)}),\qquad
p(\widetilde c_e)=\kappa_e,\qquad
\widetilde L_e=\widetilde c_eL_e^{\mathrm{orig}}
```

で与える。終点のfiber自己同型との合成なので、基準辺も上の二つの強さを持つ。
各面について、底の両経路が一致し、指定比較は
$`u_f\in\operatorname{Aut}_{qp}(X_{t(f)})`$ に属し、coreの整合は
$`p(u_f)p(\widetilde L_{\ell_f})=p(\widetilde L_{r_f})`$ とする。

係数群は実射影の全核

```math
A_v=\ker\bigl(\operatorname{Aut}_{qp}(X_v)
\longrightarrow\operatorname{Aut}_q(pX_v)\bigr)
```

から作る。各核の可換性、強いopcartesian射から構成する核輸送の全単射性、
指定比較が終点の核と可換であること、指定比較の3-cell整合条件を仮定とする。
核輸送 $`\rho_e`$ は実際の辺と可換な平方から構成し、その面の関係への降下を用いる。

**部分表示**は、所属する辺の端点、面の両経路、3-cellの両書き換え列に現れる面と
前後の経路を全て含むものとする。部分表示には同じ対象・射・比較・係数を制限する。
被覆 $`K=U\cup V`$ は0〜3-cellの全てを覆い、$`W=U\cap V`$ とする。
この閉包条件により、所属セルの微分を計算する全ての辺・経路・面も所属する。
係数と輸送は同じものなので、制限写像は各微分と交換する。
同じ理由で実defectと辺補正の実合成も制限と交換する。

固定部分 $`P\subseteq K`$ は上の意味で閉じた部分表示とし、
そこで与えられた実操作が指定比較に整合しているとする。
基準持ち上げもその実操作に一致させる。固定するのは $`P`$ 上の対象と辺の実射であり、
可視のcoreを保つことに加えて、この一致を要求する。
§2.2〜2.4では $`P`$ 外の任意の核補正と、$`P`$ 上で恒等な頂点再同定を扱う。
主定理では§2.5のように、同じ有限表示の既存辺について、追加補正を許す範囲を変える。
新しい辺・面を加える変更は、表示間の比較と修復の保存・反映を別に構成して扱う。

### 2.2 相対複体と実修復の対応

G-129の局所係数 $`A_\rho`$ と複体から

```math
C^\bullet(K,P;A_\rho)
=\ker\bigl(C^\bullet(K;A_\rho)\longrightarrow C^\bullet(P;A_\rho)\bigr)
```

を構成する。$`C^0`$ は頂点、$`C^1`$ は辺、$`C^2`$ は面、$`C^3`$ は3-cellの
終点の核の積であり、相対部分は $`P`$ の成分を零にする。
以後、相対複体でも微分を $`d^0,d^1,d^2`$ と書く。
固定部分の整合から $`\delta|_P=0`$、3-cell条件から $`d^2\delta=0`$ を導き、
相対障害 $`[\delta]\in H^2(K,P;A_\rho)`$ を作る。

**実修復**は、各終点のfiber自己同型 $`c_e\in\operatorname{Aut}_{qp}(X_{t(e)})`$ で
指定したcore選択を持ち上げ、元の辺から $`L_e=c_eL_e^{\mathrm{orig}}`$ と構成する族のうち、
$`P`$ 上の実射と一致し、全ての指定面で $`u_f L_{\ell_f}=L_{r_f}`$ を満たすものと独立に定める。
実修復から基準持ち上げとの差を核へ戻し、逆に核補正を元の辺へ合成することで

```math
\{\text{実修復}\}
\longleftrightarrow
\{h\in C^1(K,P;A_\rho):d^1h=-\delta\},\qquad
\widetilde L_e^h=\iota_{t(e)}(h_e)\widetilde L_e
```

を構成する。$`\iota_v`$ は核から実自己同型への包含である。
基準辺を $`\widetilde L_e=\widetilde c_eL_e^{\mathrm{orig}}`$ と書くと、
同じcoreを持つ $`c_e`$ に対して $`c_e\widetilde c_e^{-1}`$ は射影の全核に属する。
これを加法記法で読んだものが $`h_e`$ であり、逆は $`c_e=\iota(h_e)\widetilde c_e`$ である。
原始辺の強いopcartesian性による因子分解の一意性から、
$`c_eL_e^{\mathrm{orig}}=c'_eL_e^{\mathrm{orig}}`$ なら $`c_e=c'_e`$ となる。
従って選択 $`c_e`$ と実射の族は同じ修復を表し、固定辺の実射の一致は $`h_e=0`$ と同値である。
経路に沿って核元を実輸送で終点へ移すと、基準経路の後ろにその経路の補正和が残る。
指定比較の中央化条件と可換核により、面のdefectは $`\delta^h=\delta+d^1h`$ に変わる。
従って上の対応は面の実射の等号を保存・反映し、coreと $`P`$ 上の実射を保つ。

実修復を対象とし、$`P`$ 上で恒等な頂点再同定を射とするgroupoidを
$`\mathscr R_P(K)`$ とする。補正座標での射は
$`b:h\to h+d^0b`$、$`b\in C^0(K,P;A_\rho)`$ であり、実射には

```math
\widetilde L_e^h\longmapsto
\iota_{t(e)}(b_{t(e)})\widetilde L_e^h\iota_{s(e)}(b_{s(e)})^{-1}
```

として作用する。存在・分類は次のようになる。

```math
\begin{aligned}
\mathscr R_P(K)\ne\varnothing
&\Longleftrightarrow [\delta]=0\in H^2(K,P;A_\rho),\\
\pi_0\mathscr R_P(K)&\text{ は、非空なら }H^1(K,P;A_\rho)\text{ のtorsor},\\
\operatorname{Aut}_{\mathscr R_P(K)}(h)&\cong H^0(K,P;A_\rho).
\end{aligned}
```

ここで $`\pi_0`$ は修復の同型類を表し、$`H^0=\ker d^0`$ とする。
証明は、解が一つあれば全解が $`Z^1`$ の自由推移的な作用を受け、再同定が
$`\operatorname{im}d^0`$ だけ補正を動かすことによる。各解を固定する射は $`\ker d^0`$ である。
基準持ち上げを $`\widetilde L^a`$ へ変えると、同じ実射の補正座標は $`h-a`$、
defectは $`\delta+d^1a`$ になる。$`P`$ の実射を保つと $`a|_P=0`$ なので、
相対障害類と実修復groupoidが同じ写像で対応する。

### 2.3 基礎となる、全核補正を許す貼り合わせ

$`P_X=P\cap X`$ と略記する。全核補正を許す場合の基礎となる対応は、制限関手から作る同値

```math
\mathscr R_P(K)\simeq
\mathscr R_{P_U}(U)\times^h_{\mathscr R_{P_W}(W)}\mathscr R_{P_V}(V)
\tag{M}
```

である。右辺の対象は、二つの局所修復と、重なりでそれらを結ぶ一つの同型からなる。
射はその同型と可換な局所再同定の対である。

証明の要点は、各次数のcochainがセル上の値の積であることにある。
同じセルの係数を保持する制限から、次数ごとに短完全な複体の列

```math
0\longrightarrow C^\bullet(K,P)
\longrightarrow C^\bullet(U,P_U)\oplus C^\bullet(V,P_V)
\xrightarrow{r_U-r_V} C^\bullet(W,P_W)\longrightarrow0
\tag{E}
```

を作る。最後の全射性はセルの値の零延長で示す。零延長そのものを複体の写像とする
必要はなく、制限・差写像が微分と交換し、各次数で全射になることを用いる。

重なりの再同定 $`b_W`$ を一方の領域の0-cochainへ延長し、その局所修復を再同定する。
すると二つの補正は重なりで厳密に一致し、辺ごとに貼り合わせられる。
これが全ての局所貼り合わせデータから大域修復を作る方法となる。
射の全忠実性は、重なりで一致する0-cochainの一意な貼り合わせで示す。
最初から $`H^1`$ の同値類だけへ移ると失う再同定と自己同型を、(M)では保持する。

有限被覆 $`K=\bigcup_i U_i`$ では、二重交差の同型 $`b_{ij}`$ に三重交差での
$`b_{ij}+b_{jk}=b_{ik}`$ を課す。被覆の細分化、組立ての順序・括弧づけを変える
対応は、全て同じ $`\mathscr R_P(K)`$ への復元と整合させる。
この整合が対象とするのは修復データの組立てである。
変更範囲を制限した主定理では、再同定の延長がその範囲を保つかを追加で扱う。

### 2.4 統合障害と、指定した局所案の接続を区別する

局所修復 $`h_U,h_V`$ があるとき

```math
z=h_V|_W-h_U|_W\in Z^1(W,P_W;A_\rho)
```

とする。**この二案を頂点再同定だけで接続する条件**は
$`[z]=0\in H^1(W,P_W;A_\rho)`$ である。
一方、局所修復をそれぞれ選び直してよい場合には

```math
\Omega_{U,V,P}=
\frac{H^1(W,P_W;A_\rho)}
{\operatorname{im}(H^1(U,P_U;A_\rho)\to H^1(W,P_W;A_\rho))
+\operatorname{im}(H^1(V,P_V;A_\rho)\to H^1(W,P_W;A_\rho))}
```

における $`\omega`$、すなわち $`[z]`$ の像を取る。
局所解の差は1-cocycleなので、$`\omega`$ は局所解の選択によらない。
列(E)の完全性から得る結論は

```math
\omega=0\quad\Longleftrightarrow\quad\mathscr R_P(K)\ne\varnothing.
```

列(E)の接続写像を $`\partial:H^1(W,P_W)\to H^2(K,P)`$ とする。
$`z`$ の持ち上げに $`(-h_U,-h_V)`$ を取ると、その微分は
$`(\delta|_U,\delta|_V)`$ である。したがって符号を含めて

```math
\partial[z]=[\delta],\qquad
\Omega_{U,V,P}\cong
\ker\bigl(H^2(K,P)\longrightarrow H^2(U,P_U)\oplus H^2(V,P_V)\bigr)
```

を対応させる。大域の二次障害のうち、局所では消える部分を、重なりの一次の差で記述する。
ここでの境界は重なり $`W`$ を指し、閉路に加え、$`P_W`$ の固定端点を結ぶ経路も読む。

### 2.5 変更範囲と、通常の貼り合わせが失う情報

$`P`$ 外の辺を、常時補正を許す集合 $`E_0`$ と、追加補正の候補集合 $`\mathsf E`$ に分ける。
各辺について変更の基準となる実操作を固定し、最初の補正座標の零をその操作に一致させる。
$`S\subseteq\mathsf E`$ に対する実修復groupoid $`\mathscr R_{P,S}(K)`$ は、
$`\mathscr R_P(K)`$ のうち

```math
h_e=0\quad(e\in\mathsf E\setminus S)
```

を満たす対象からなるfull subgroupoidとする。各 $`h_e=0`$ が基準実操作との一致に
相当することも、実修復との対応で示す。射 $`b:h\to h+d^0b`$ は $`P`$ 上で零であり、
両端の対象が同じ条件を満たすため

```math
(d^0b)_e=0\quad(e\in\mathsf E\setminus S)
```

を満たす。固定するのはこれらの辺の実射であり、端点の再同定はこの式で制約する。
$`S\subseteq T`$ に対し包含関手 $`\mathscr R_{P,S}(K)\to\mathscr R_{P,T}(K)`$ がある。
$`S=\mathsf E`$ で§2.2の修復groupoidに戻る。

この制限を(M)の各項へ入れただけでは、貼り合わせは一般に成立しない。
非零の可換群 $`A`$、恒等輸送、面を持たない経路
$`p\xrightarrow{e_1}w\xrightarrow{e_2}q`$、$`P=\{p,q\}`$ を取る。
基準辺は恒等、$`E_0=\varnothing`$、$`\mathsf E=\{e_1,e_2\}`$、$`S=\varnothing`$ とする。
大域の無変更修復は一つで、内部頂点の再同定 $`b`$ は二辺に $`(b,-b)`$ を加えるので、
許された自己同型も恒等だけである。左右の一辺領域でも無変更修復groupoidは一点となる。
一方、重なり $`W=\{w\}`$ には辺の制約がなく、その修復groupoidは $`BA`$ である。

```math
\mathscr R_{P,\varnothing}(K)\simeq *,\qquad
*\times^h_{BA}*\simeq A
```

右辺の $`A`$ は離散groupoidであり、左辺とは同値にならない。
重なりの再同定を延長して厳密一致へ直す際に、禁止された辺の補正が必要になるためである。
この例は、(M)を変更範囲付きの主張へ移す際に保持すべきデータを特定する。
補正座標を保った厳密な貼り合わせは可能であり、生成する表現でもその対応を追う。

変更の支持は基準となる実操作に相対的である。別の参照持ち上げを用いて
$`h'=h-a`$ と座標変換するなら、固定条件は $`h'_e=-a_e`$ へ移す。
同じ物理的な基準操作を保持したまま、座標と固定条件をともに輸送する。

### 2.6 主定理：全ての変更範囲を保つ生成と合成

§2.1の原始入力を取り、各実全核 $`A_v`$ に同一の有限体 $`k`$ 上の有限次元
ベクトル空間構造を与え、実核輸送を $`k`$ 線形とする。実核の演算と基底、核の包含、
実輸送とdefectの座標を扱える有限データを与える。閉じた部分表示の有限被覆
$`\mathcal U=(U_i)_{i\in I}`$ を取り、$`P_i=P\cap U_i`$、
$`W_i=\bigcup_{j\ne i}(U_i\cap U_j)`$ と置く。実核・輸送・実defectの座標を原始の射から得た後の構成は、有限線形消去によって停止する。
実操作の有限表示からこの座標も計算する適用族を§5.1・§5.8で与える。

**定理。** この入力から、候補辺の名前と補正値を保持する局所表現 $`\mathcal I_i`$ を
一度生成できる。全ての $`S\subseteq\mathsf E`$ に対して、生成した表現の厳密な共有条件から
定めるgroupoid $`\operatorname{Glue}_S(\mathcal I_i)`$ と実修復groupoidの間に、相互逆な関手

```math
\operatorname{coord}_{\mathcal U,S}:\mathscr R_{P,S}(K)
\ \rightleftarrows\
\operatorname{Glue}_S(\mathcal I_i):\operatorname{rec}_{\mathcal U,S}
\tag{M_S}
```

がある。これらは候補辺の値、元の実辺、頂点再同定を保存し、$`S\subseteq T`$ の包含と交換する。
存在判定は各領域の公開アフィン関係と共有座標だけででき、その解を選んだ後には、
局所に保持した復元データから全実修復と全ての射を回復できる。
被覆の細分化、組立て順序、基底と線形sectionの変更に沿う比較も、この同じ復元と交換する。

証明は§3.1で与える。全変更範囲の双対分類は§3.4、内部辺分割は§3.6で同じ構成へ接続する。

## 3. 局所から生成する修復インターフェース

### 3.1 局所表現の生成と主定理の証明

**構成と証明。** 閉包条件により、領域内の面の両経路と、3-cellの各書き換え・前後の経路は
その領域内にある。実核輸送による経路補正は、長さ零で零、経路の合成で

```math
T_{vw}(h)=\rho_wT_v(h)+T_w(h)
```

と計算する。したがって $`d^0b(e)=b_{t(e)}-\rho_e b_{s(e)}`$、
$`d^1h(f)=T_{\ell_f}(h)-T_{r_f}(h)`$ と、型付き書き換え列の符号付き輸送和による $`d^2`$ は
制限と交換する。実defectも同じ実経路と指定比較から作るので制限と交換する。
$`P`$ 上の整合から $`\delta|_P=0`$、面と3-cellの条件から
$`d^1d^0=0`$、$`d^2d^1=0`$、$`d^2\delta=0`$ を得る。

各領域の相対辺空間を、名前付き辺に沿って

```math
C_i^1=X_i\oplus Z_i,\qquad
X_i=\prod_{e\in E_0\cap(U_i\setminus W_i)}A_{t(e)},\qquad
Z_i=\prod_{e\in(E_0\cap W_i)\cup(\mathsf E\cap U_i)}A_{t(e)}
```

と分ける。積の添字は辺を意味し、$`P`$ の成分は相対空間の定義により零である。
消去する $`X_i`$ の辺は他領域に属さず、候補辺は全て $`Z_i`$ に残る。
$`V_i=C^2(U_i,P_i)`$、$`B_i=C^0(U_i,P_i)`$、$`r_i=-\delta|_{U_i}`$ とし、
実微分を上の分解で書いて

```math
d_i^1(x,z)=D_ix+F_iz,\qquad
 d_i^0b=(a_ib,c_ib),\qquad D_ia_i+F_ic_i=0
```

を得る。行簡約から商写像 $`q_i:V_i\to\operatorname{coker}D_i`$ と、
$`D_is_i=\operatorname{id}_{\operatorname{im}D_i}`$ を満たす線形section
$`s_i:\operatorname{im}D_i\to X_i`$ を構成する。ここでは独立な像の基底を選び、
対応する列の逆像を線形に延ばせばよく、求める修復や復元同値は入力として用いない。

$`N_i=\ker D_i`$ と置き、公開関係と局所対象を

```math
R_i=\{z\in Z_i:q_iF_iz=q_ir_i\},\qquad
\operatorname{Ob}\mathcal I_i=R_i\times N_i
```

と定める。$`R_i=\varnothing`$ も許す。復元と座標化は

```math
\begin{aligned}
\operatorname{rec}_i(z,k)&=(s_i(r_i-F_iz)+k,z),\\
\operatorname{coord}_i(x,z)&=(z,x-s_i(r_i-F_iz))
       &&(D_ix+F_iz=r_i)
\end{aligned}
\tag{C}
```

である。第一式の $`s_i`$ の引数は $`\operatorname{im}D_i`$ にあり、第二式の第二成分は
$`N_i`$ に属する。代入により両合成が恒等になる。従って局所解を列挙せず、
任意の解に唯一の座標を与え、各座標から一つの解を復元できる。

再同定の作用も消去行列から構成する。$`D_i a_i b\in\operatorname{im}D_i`$ なので

```math
\gamma_i b=a_i b-s_iD_i a_i b\in N_i
```

と置ける。$`b\in B_i`$ による作用を

```math
b\cdot(z,k)=(z+c_ib,k+\gamma_ib)
\tag{A}
```

と定める。$`F_ic_ib=-D_ia_ib`$ から第一成分は再び $`R_i`$ に入り、
$`\operatorname{rec}_i(b\cdot(z,k))=\operatorname{rec}_i(z,k)+d_i^0b`$ が従う。
$`\gamma_i,c_i`$ は線形なので零が恒等、和が合成、負号が逆射となる。
$`\mathcal I_i`$ はこの作用groupoidであり、(C)は射 $`b`$ を同じ $`b`$ へ送る
groupoidの相互逆な関手に拡張する。異なる $`b`$ が同じ対象を結ぶ場合も同一視しないので、
自己同型を保持する。共有部分への関手は、補正座標で

```math
\beta_i(z,k)=\operatorname{rec}_i(z,k)|_{W_i}=z|_{W_i},\qquad
\beta_i(b)=b|_{W_i}
```

である。等式は共有辺が $`X_i`$ に含まれないことによる。制限と微分の可換性から
対象と射の条件を保つので、これは $`\mathscr R_{P\cap W_i}(W_i)`$ への関手になる。
従って公開側で共有辺の補正を照合でき、内部の $`k_i`$ を渡す必要はない。

$`S`$ に対して、候補座標が $`z_e=0\ (e\in\mathsf E\setminus S)`$ を満たす対象上の
full subgroupoid $`\mathcal I_{i,S}`$ を取る。対象間の射 $`b`$ は、(A)から
$`(c_ib)_e=0\ (e\in(\mathsf E\setminus S)\cap U_i)`$ を満たす。
これは元の $`(d^0b)_e=0`$ と同じ条件である。候補を消去していないため、
一つの生成済み表現に対象と射の線形条件を加えるだけで全 $`S`$ を扱える。

$`\operatorname{Glue}_S(\mathcal I_i)`$ の対象は $`(z_i,k_i)_i`$ の族で、
共有辺上の $`z_i`$ が同じ核要素として厳密に一致するものとする。射は局所射 $`(b_i)_i`$ の族で、
共有頂点上で厳密に一致するものとする。恒等・合成・逆射は成分ごとに定める。
復元した局所補正 $`h_i=\operatorname{rec}_i(z_i,k_i)`$ は共有辺上で一致するので、

```math
h_e=(h_i)_e\quad(e\in U_i),\qquad
b_v=(b_i)_v\quad(v\in U_i)
\tag{G}
```

はそれぞれ一意な大域cochainを定める。各面は被覆のいずれかに全体として属するため、
$`d^1h=-\delta`$ はその領域の式から従う。辺の固定条件も局所から従う。
射についても $`h'-h=d^0b`$ を、各辺を含む領域で確認できる。
逆に大域の $`h,b`$ を各領域へ制限し、(C)で座標化すればGlueの対象・射を得る。
(C)の相互逆性と(G)の一意性から、大域の両合成も対象・射の双方で恒等である。
重なり上の任意の再同定を新たに許す段階はなく、§2.5の反例を生む
homotopy pullbackへの置換は行わない。

最後に実射へ戻す。基準のfiber自己同型を $`c_e^0`$、実修復の選択を $`c_e`$ とすると、
両者のcore像が同じなので $`c_e(c_e^0)^{-1}`$ は実全核に属し、唯一の補正 $`h_e`$ を与える。
逆は $`c_e=\iota(h_e)c_e^0`$ であり、二つの式は群の演算から相互逆である。
実辺については

```math
L_e=\iota_{t(e)}(h_e)\widetilde L_e,
\qquad
L'_e=\iota_{t(e)}(b_t)L_e\iota_{s(e)}(b_s)^{-1}
```

となる。強いopcartesian性の一意性により、$`h_e=0`$ は基準実辺との一致と同値である。
実輸送の可換平方を経路に沿って合成すると
$`L_w^h=\iota(T_w(h))\widetilde L_w`$ を得る。指定比較と核の可換性から
実defectは $`\delta+d^1h`$ へ変わるので、(G)で得た解は全ての元の面を満たす。
頂点再同定の実辺への作用も同じ可換平方から $`h\mapsto h+d^0b`$ となる。
従ってcochain上で構成した相互逆は、独立に定義した実修復とその全ての射へ移る。

**公開関係による判定。** Glueの対象があれば共有する $`z_i`$ と禁止候補の零条件が得られる。
逆にそれらがあれば、各 $`k_i=0`$ を選んで(C)・(G)で大域解を構成できる。
ゆえに次が従う。

```math
\mathscr R_{P,S}(K)\ne\varnothing
\quad\Longleftrightarrow\quad
\exists(z_i)\in\prod_iR_i:\quad
z_i|_{W_{ij}}=z_j|_{W_{ij}},\qquad (z_i)_e=0\quad(e\in\mathsf E\setminus S)
\tag{B}
```

ここで $`W_{ij}=U_i\cap U_j`$、候補の零条件はその候補が属する各領域で課す。
任意の $`k_i\in N_i`$ に取り直した全ての族が、その境界解から得られる
全実修復を与える。$`m_i=\dim Z_i`$ とすると、非空の $`R_i`$ は高々 $`m_i`$ 本の
独立なアフィン方程式で公開できる。これは存在判定用の関係のサイズであり、
$`N_i`$、射の作用、実操作への復元データは局所に保持する。

**変更範囲と表示選択との整合。** $`S`$ に依存するのは対象の候補零条件と射の対応する
零条件だけなので、同じ(C)・(G)は $`S\subseteq T`$ の包含と交換する。
新しいsection $`s_i'`$ への変更は

```math
(z,k)\longmapsto
\bigl(z,k+(s_i-s_i')(r_i-F_iz)\bigr),\qquad b\longmapsto b
\tag{S}
```

であり、逆は二つのsectionを交換した式である。第二成分の差は $`N_i`$ に入る。
この式は(C)の復元と交換するため、(A)の作用とも交換する。基底変更は各セルの実核の座標を
運ぶ線形同型から生成し、候補辺の名前と物理的な固定条件も同時に運ぶ。
いずれも $`\operatorname{coord}'\operatorname{rec}`$ という具体的な相互逆を持つ。

細分被覆 $`\mathcal V`$ への比較は、(G)で貼り合わせた補正を細分領域へ制限し、
その(C)で座標化する関手

```math
T_{\mathcal V\mathcal U}
=\operatorname{coord}_{\mathcal V}\operatorname{rec}_{\mathcal U}
```

とする。逆は $`T_{\mathcal U\mathcal V}`$ であり、三つの被覆について
$`T_{\mathcal W\mathcal V}T_{\mathcal V\mathcal U}=T_{\mathcal W\mathcal U}`$ が成立する。
ここでは大域修復の列挙を使わず、セルごとの一意な貼り合わせと制限だけを使う。
二項の組立てを反復する表示でも、flatten/unflattenが共有セルの同じ一致条件を保ち、
どの括弧づけ・順序でも(G)で同じ $`h,b`$ を得る。中間で再消去する場合も、未組立て領域との共有辺と全候補辺を残して
その(C)を挿入すれば、同じ相互逆性から比較の合成則が従う。
参照持ち上げを $`a`$ だけ変える場合は $`h\mapsto h-a`$、
$`\delta\mapsto\delta+d^1a`$ とし、物理的な固定条件を $`h_e=0`$ から
$`h_e^\prime=-a_e`$ へ同時に運ぶ。これは同じ実修復を表すアフィン座標変換であり、
(C)・(G)を通じて同じ関手比較を与える。∎

**系（各変更範囲の存在・同型類・自己同型）。**

$`C_P^j=C^j(K,P;A_\rho)`$ と略記し、各 $`S`$ について

```math
C_S^1=\{h\in C_P^1:h_e=0\ (e\in\mathsf E\setminus S)\},\qquad
C_S^0=(d^0)^{-1}(C_S^1),\qquad C_S^j=C_P^j\ (j=2,3)
```

とする。微分を制限して得る複体のcohomologyを $`H_S^j`$ と書く。
$`\delta\in\ker d^2`$ は共通なので、主定理の同じ表現から

```math
\begin{aligned}
\mathscr R_{P,S}(K)\ne\varnothing
&\Longleftrightarrow[\delta]=0\in H_S^2,\\
\pi_0\mathscr R_{P,S}(K)
&\text{ は、非空なら }H_S^1\text{ のtorsor},\\
\operatorname{Aut}_{\mathscr R_{P,S}(K)}(h)
&\cong H_S^0=H^0(K,P;A_\rho)
\end{aligned}
```

を得る。第一式は $`d^1h=-\delta`$、第二式は二解の差が
$`\ker(d^1|_{C_S^1})`$ に属し、同型である条件が $`d^0C_S^0`$ の差であることによる。
第三式は自己射が $`d^0b=0`$ と同値であり、この条件は全ての $`C_S^0`$ に属することによる。
禁止辺があるときは $`C^1`$ とともに $`C^0`$ もこの形で制限する。
$`S\subseteq T`$ の包含は複体の写像を与え、これらの対応と交換する。


### 3.2 外部との合成を保つ内部置換

まず、変更範囲を区別しない通常の貼り合わせに対する置換を述べる。
共通の境界groupoid $`\mathcal B`$ に対し、二つの局所表現
$`\beta:\mathcal I\to\mathcal B`$、$`\beta':\mathcal I'\to\mathcal B`$ を取る。
同値 $`F:\mathcal I\simeq\mathcal I'`$ と自然同型 $`\beta'F\cong\beta`$ があれば、
任意の適用可能な外部表現 $`\mathcal J\to\mathcal B`$ について

```math
\mathcal I\times^h_{\mathcal B}\mathcal J
\simeq
\mathcal I'\times^h_{\mathcal B}\mathcal J
```

を構成する。抽象的なgroupoidの同型型だけでなく、境界への写像との対応が必要である。
この同値を復元と可換にすることで、内部の置換後も大域修復・再同定・自己対称性を追う。
ここでの2-fibre productの同値不変性は標準的な性質である
（[Stacks Project, Lemma 4.31.7](https://stacks.math.columbia.edu/tag/02XB)）。

存在判定だけなら、$`\pi_0\mathcal B`$ における二つの本質的像の一致で足りる。
各像は、実現できる境界修復を同型まで集めたものである。
この一致は内部の解の個数・自由度・自己同型まで決定するものではない。
同じ境界条件に自由な内部変数を一つ加える例で、この区別を示す。

逆向きの「全ての外部から区別できないなら境界表現が同じ」については、
境界対象を一つ指定する試験環境を原始操作から作れる入力族を特定する。
その実現補題があれば、本質的像の差を検出する接続先を作れる。
全groupoidの回復には、対象の実現可能性に加えて射を検査する環境も必要になる。

全変更範囲を保つ置換では、候補辺の名前の対応、基準操作、候補座標の零条件、
共有部分への制限、再同定による補正を保持する比較を、元の内部変更から生成する。
各 $`S`$ の修復groupoidの対応を $`S\subseteq T`$ と整合させ、§3.1の厳密な
貼り合わせと交換することを証明する。境界上の抽象的なgroupoid同値だけを与えても、
候補辺の零条件や、厳密な一致を作る際の許容補正は決まらない。
全 $`S`$ の非空性を保存すれば包含極小の成功集合を、復元まで保てばその範囲の全修復を
引き継げる。どの原始的な内部変更からこの比較を生成できるかも、構成対象として定める。
その最初の具体的な操作として、常時補正可能な内部辺の分割を§3.6で扱う。

存在判定の逆向きは、外部が実際に指定できる座標に合わせて述べる。
外部が共有座標と候補の解禁集合 $`S`$ を指定し、内部候補の補正値自体は指定しない場合、
比較すべき境界関係は

```math
C_U(S)=\operatorname{pr}_{\partial}
\bigl(R_U\cap\{y_e=0:e\notin S\}\bigr)
```

である。$`\operatorname{pr}_{\partial}`$ は外部との共有座標への射影であり、
内部候補の座標を消去する。共有候補の座標は残す。
**命題（有限アフィン族における一点試験と文脈同値）。** §5.1の有限アフィン変換族で、
$`U,U'`$ は共有部分表示 $`W`$ の対象、基準実操作、core、指定比較、
$`P\cap W`$ と候補辺の名前を共有するとする。環境は $`W`$ に沿って厳密に貼り合わせ、
共有辺の補正値を一致させる。候補名は衝突なく共通に与え、共有候補には同じ許可条件を課す。
許容する外部環境の族は、以下の有限な平行辺と面の追加に閉じているとする。

境界の修復値 $`t=(t_e)_{e\in W_1}`$ に対し、環境 $`E_t`$ を次のように作る。
$`W`$ のセルを全て保ち、各共有辺 $`e:s\to v`$ について新しい候補辺
$`f_e:s\to v`$ と、比較が恒等の面 $`e=f_e`$ を加える。
新しい辺の原始操作は旧辺と同じ写像を用い、基準実操作とcore再選択を

```math
\widetilde L_{f_e}=\tau_{t_e}\widetilde L_e,
\qquad \operatorname{core}(f_e)=\operatorname{core}(e)
```

とし、$`f_e`$ は全ての試験で解禁集合から外す。$`P`$ は増やさず、新しい3-cellも加えない。
両側を比較するときは同じ辺名 $`f_e`$、同じ基準と面を用いる。
$`W`$ の各Law・3-cellは既存のものを保持するため、$`t`$ が $`W`$ の修復であれば、
この追加は同じ有限表示の入力条件を満たす。新しい面では両辺のcoreと核輸送が等しく、
恒等比較は核と可換である。固定辺に対する $`t_e`$ は零とする。

補正禁止により $`h_{f_e}=0`$ なので、新しい面の実等式は

```math
\tau_{h_e}\widetilde L_e
=\tau_{t_e}\widetilde L_e
\quad\Longleftrightarrow\quad h_e=t_e.
```

最後の同値は実操作の全単射性と平行移動の忠実性による。
したがって環境の共有補正関係は一点 $`\{t\}`$ である。
共有頂点の再同定を固定する必要はなく、この関係に残る自己同型は存在判定に影響しない。

この環境族に対して、§3.2の $`C_U(S)`$ は次を満たす。

```math
\forall S\subseteq\mathsf E,\ C_U(S)=C_{U'}(S)
\quad\Longleftrightarrow\quad
\text{全ての許容外部環境と整合する候補許可条件で、修復の存在が一致する}.
\tag{Ctx}
```

**証明。** 順方向では、任意の外部環境についてその内部補正を存在量化し、
共有部分上の実現可能集合を $`C_V(S_V)`$ とする。厳密な貼り合わせの存在は
$`C_U(S)\cap C_V(S_V)\ne\varnothing`$ と同値であり、$`U'`$ への置換で変わらない。
逆方向で $`t\in C_U(S)\setminus C_{U'}(S)`$ があれば上の $`E_t`$ を取る。
これは $`U`$ とだけ修復可能に貼り合わせられ、全外部環境での一致に反する。
逆側の差も同様である。追加候補 $`f_e`$ は常に禁止し、元の内部候補値を直接試験する
操作は使っていない。∎

(Ctx)は原始的な実操作から作った試験環境による、存在判定の文脈同値を特徴づける。
対象の個数、内部自由度、修復間の射を回復する主張は含まない。
全修復groupoidの置換には、§3.2・§3.6の再同定と復元を保つ対応を用いる。

例えば $`\mathbb F_3`$ で共有座標 $`z`$ と内部候補 $`y`$ を持つ
$`R_1=\{z=y\}`$、$`R_2=\{z=2y\}`$ は異なる。
しかし候補を禁止すると両者の境界は $`\{0\}`$、許すと両者とも全 $`\mathbb F_3`$ となる。
全ての境界環境で可否が一致しても、内部補正値まで同一とは限らない。
候補値も直接指定する試験を使う場合は、その操作と実現条件を別に定める。

### 3.3 保持する関係の形

内部の消去では、複数の境界座標を同時に結ぶ関係が生じる。
Hansen–Ghristのcellular sheafのKron reductionの検討には、内部の二座標から
三つの境界へ $`x,y,x+y`$ を送り、二項関係だけでは同じ制約を保持できない例がある
（[§4.2、Figure 4.1](https://jakobhansen.org/publications/spectralsheaves.pdf)）。
そのため、$`\mathcal I_i`$ の表示には多項の線形関係と再同定の作用を保持する。
表現の大きさは入力に依存する。主要な要求は、局所から生成でき、実修復の情報を保つことである。

### 3.4 修復可能な変更範囲と、不能証拠の完全分類

同じ表示 $`K`$ の補正微分を、常時許容する辺補正 $`x`$ と候補辺補正 $`y_e`$ に分ける。
大域での式は、元の同じ $`d^1`$ とdefectから

```math
Dx+\sum_{e\in\mathsf E}E_e y_e=-\delta
```

と生成する。ここで $`D`$ は $`E_0`$ の全補正を含む。局所では§3.1のように共有座標を
残し、局所表現を合成してからそれらを消去する方法との対応を示す。
次の商・類・写像を構成する。

```math
q:C^2(K,P)\longrightarrow\mathsf O=\operatorname{coker}D,\qquad
o=q(-\delta),\qquad B_e=qE_e,\qquad
\mathsf R_S=\sum_{e\in S}\operatorname{im}B_e.
```

$`\mathsf O`$ は常時許容補正で吸収できる方向を除いた要求の空間である。
全候補も許した商は $`\mathsf O/\mathsf R_{\mathsf E}\cong C^2/\operatorname{im}d^1`$ であり、
$`H^2(K,P)`$ は、この商から $`C^3`$ への誘導微分 $`\overline d^2`$ の核となる。
$`d^2\delta=0`$ により、$`o`$ の商への像はこの核に入り、相対障害 $`[-\delta]`$ に対応する。
商写像の $`\ker q=\operatorname{im}D`$ と同じ実修復方程式から、全範囲について次が従う。

```math
\mathscr R_{P,S}(K)\ne\varnothing
\quad\Longleftrightarrow\quad o\in\mathsf R_S
\qquad(S\subseteq\mathsf E).
\tag{F}
```

商の式を満たす候補補正から、$`D`$ の像上のsection $`s`$ を用いて

```math
x=s\!\left(-\delta-\sum_e E_e y_e\right)+k,\qquad k\in\ker D
```

と全解を戻す。各補正は元の名前付き辺の実射へ戻し、射については§2.5の再同定条件を保つ。

$`\lambda\in\mathsf O^*`$ で $`\lambda(o)\ne0`$ を満たすものに対して

```math
E_\lambda=\{e\in\mathsf E:\lambda\circ B_e\ne0\},\qquad
\mathcal H_o=\{E_\lambda:\lambda(o)\ne0\}
```

を定める。$`E_\lambda`$ は、その非零評価を変え得る名前付き補正の集合である。
有限次元の双対分離から

```math
o\in\mathsf R_S
\quad\Longleftrightarrow\quad
\forall\lambda\in\mathsf O^*,\quad
\lambda(o)\ne0\ \Longrightarrow\ S\cap E_\lambda\ne\varnothing
\tag{T}
```

を得る。逆向きは、$`o\notin\mathsf R_S`$ なら $`\mathsf R_S`$ 上で零、$`o`$ で非零の
$`\lambda`$ を選べることによる。この証拠は $`S`$ の全補正を排除する。

したがって、**包含極小の修復可能範囲は、$`\mathcal H_o`$ の極小横断集合に一致する**。
ここで横断集合とは全ての $`E_\lambda`$ と交わる集合であり、包含極小性は要素数最小とは
区別する。$`o=0`$ なら証拠族は空で、極小成功集合は空集合となる。
全候補を許しても修復不能なら証拠族に空集合が現れ、横断集合も存在しない。

(F)の線形可解性、(T)の双対分離、極小横断集合への移行は標準的な数学である。
主定理は $`D,E_e,o,B_e`$ を同じ実操作と輸送から生成し、局所表現の合成・
元の操作への復元・許容範囲の包含を通じて、全ての $`S`$ の分類を保存する。

### 3.5 記号的生成と、入力値の更新に対する再利用

表示、core、核輸送、補正の基底を既知とし、実操作の未知成分を $`v\in\mathsf V`$ とする。
実現可能な入力族について、同じ原始操作から

```math
D_i x_i+F_i z_i=r_{i,0}+B_i v
```

を生成する。行列と定数項は既知であり、$`v`$ の値は許された原始問い合わせから得る。
有限アフィン変換族では、既知の線形成分と未知の平行移動成分をこの形で扱える。
入力族全体で3-cell条件などが成立することと、全てのパラメータの実現を別途示す。

値の取得前に、$`q_iF_i z_i=q_i(r_{i,0}+B_i v)`$ という記号的関係、kernel、section、
再同定作用と復元式を生成する。§6ではこの表現から、判定や数値補正の出力に必要な
原始観測を決定する。値を代入した具体的インターフェースを受領した場合は、そこから
得られる情報を既知情報へ含める。

構造行列と核輸送が変わらずdefectだけが更新されるときには、消去結果・kernel・section・
再同定作用を再利用し、公開する右辺と復元のアフィン項を更新する。
(C)の復元に新しい右辺を代入すると同じ(B)・(M_S)を得るので、
この更新則は全 $`S`$ の判定・復元と交換する。
更新されなかった入力値が既知なら、追加観測は残る未知方向に制限する。
構造自体の置換は§3.2の比較で扱い、取得値の更新とは条件を分ける。

### 3.6 常時補正可能な内部辺の分割不変性

§2.1の入力で、固定部分 $`P`$ と外部との共有部分表示 $`W`$ を持つ領域を $`K`$ とする。
分割する辺 $`e:s\to t`$ は $`E_0`$ に属し、$`W`$ には属さない。
新しい内部頂点 $`w`$ は $`P,W`$ に含めず、同じ圏の塔の中で基準実操作の分解

```math
\widetilde L_e=L_2L_1,\qquad
e_1:s\to w,\quad e_2:w\to t
```

を与える。新しい対象・coreの因子・持ち上げは整合し、両因子は§2.1の強いopcartesian条件と
同型な核輸送の条件を満たすものとする。係数 $`A_w`$ は新対象の実射影の全核である。
因子の核輸送を $`\rho_1:A_s\to A_w`$、$`\rho_2:A_w\to A_t`$ とすると、
実射の輸送平方の合成と一意性から $`\rho_e=\rho_2\rho_1`$ を得る。
$`A_w`$ は $`A_s`$ と同型なので可換である。

新表示 $`K'`$ は、旧辺 $`e`$ の全ての出現を経路 $`e_2e_1`$ に置き換えて作る。
面の両経路、3-cellの型付き書き換え列とその前後の文脈経路にも同じ置換を行う。
面・3-cellの名前、指定比較、その終点は保ち、新しいLawは追加しない。
旧経路の実合成が一致するため、指定比較の整合・可換性と3-cell条件を引き継ぐ。
変更許可は

```math
E'_0=(E_0\setminus\{e\})\cup\{e_1,e_2\},\qquad
\mathsf E'=\mathsf E
```

とし、候補名と各 $`S\subseteq\mathsf E`$ をそのまま用いる。
これは与えられた実分解を採用する操作であり、分解の選択そのものは入力に含める。
例えば新しい頂点名に $`X_s`$ を置き、$`L_1=\mathrm{id}`$、$`L_2=\widetilde L_e`$ とする
分割もできる。アフィン変換族では、指定した可逆な因子 $`L_1`$ に対し
$`L_2=\widetilde L_eL_1^{-1}`$ として具体的な分解を作れる。

**命題（内部辺分割と全変更範囲の修復）。** 上の入力について、実修復の縮約から
全 $`S`$ に同じ式で定まる同値

```math
F_S:\mathscr R_{P,S}(K')\simeq\mathscr R_{P,S}(K)
\tag{Sub}
```

が得られる。この同値は $`S\subseteq T`$ と整合し、$`W`$ 上の対象・射を厳密に保つ。
全ての旧候補に対する残存障害と包含極小の修復可能範囲も保存し、
§3.4の有限体・有限次元の場合には双対の不能証拠も保存する。
有限体・有限次元の制限は、この同値自体には必要なく、§3.1の有限な表現生成で用いる。

**実操作と関手の構成。** 分割後の補正を $`h_1\in A_w`$、$`h_2\in A_t`$ とすると、
核輸送の定義と可換性から

```math
\iota_t(h_2)L_2\,\iota_w(h_1)L_1
=\iota_t(h_2+\rho_2h_1)\widetilde L_e
```

である。そこで $`F_S(h')_e=h_2+\rho_2h_1`$、他の旧辺はそのままとし、
頂点再同定は旧頂点への制限とする。全ての置換済み経路で実合成が一致するので、
指定面の修復条件を保存・反映する。
逆方向の関手 $`G_S`$ は対象と射について

```math
(G_Sh)_{e_1}=0,\qquad (G_Sh)_{e_2}=h_e,\qquad
(G_Sb)_w=\rho_1b_s
```

とし、他の成分は変えない。規約 $`(d^0b)_e=b_t-\rho_eb_s`$ により、
第1辺の補正は零のまま、第2辺の補正変化は $`b_t-\rho_e b_s`$ となるので、射も保つ。
$`F_SG_S=\mathrm{Id}`$ は厳密に成立する。

自然同型 $`\eta:G_SF_S\Rightarrow\mathrm{Id}`$ は、旧頂点で零、$`w`$ で
$`\eta_{h'}(w)=h_1`$ となる再同定である。その補正は二辺に
$`(h_1,-\rho_2h_1)`$ を加え、$`(0,h_2+\rho_2h_1)`$ を $`(h_1,h_2)`$ に戻す。
射 $`b':h'\to k'`$ についての自然性は、
$`k_1-h_1=b'_w-\rho_1b'_s`$ から従う。
実際、旧射 $`b:F_Sh'\to F_Sk'`$ の持ち上げは

```math
b'_w=k_1-h_1+\rho_1b_s
```

に一意に決まり、第2辺の射条件も満たす。これが全忠実性を直接与える。
候補辺には一切補正を加えないので、全ての $`S`$ で同じ $`F,G,\eta`$ を使える。

**追加自由度の可縮性。** 0-cochainと1-cochainに、それぞれ

```math
b'\longmapsto\bigl(b'|_{K_0},\ b'_w-\rho_1b'_s\bigr),\qquad
h'\longmapsto\bigl(F^1h',\ h_1\bigr)
```

という座標を取る。2次・3次は同じセル名で同定する。このとき

```math
C^\bullet(K',P)\cong C^\bullet(K,P)\oplus
\bigl[A_w\xrightarrow{\mathrm{id}}A_w\bigr]_{0,1},\qquad
d'^0(b,a)=(d^0b,a),\qquad d'^1(h,t)=d^1h.
\tag{Split}
```

旧経路の輸送が等しいので $`d'^2=d^2`$、基準実操作の合成が等しいので
$`\delta'=\delta`$ である。$`H:C'^1\to C'^0`$ を $`(Hh')_w=h_1`$、旧頂点で零とすると、
$`\mathrm{id}-GF=dH+Hd`$ も直接確認できる。
したがって相対 $`H^0,H^1,H^2`$ と障害類は同じ写像で対応する。

$`\operatorname{Pair}(A_w)`$ を、対象が $`A_w`$ で任意の二対象間に射が一つあるgroupoidとする。
対象の座標 $`(F_Sh',h_1)`$ と上の射の一意な持ち上げにより、補正座標のgroupoidには

```math
\mathscr R_{P,S}(K')\cong
\mathscr R_{P,S}(K)\times\operatorname{Pair}(A_w)
```

という表示が得られる。各旧修復の上には $`A_w`$ で添字づけられる実際の分割補正があり、
それらは新頂点の再同定で一意に結ばれる。同型類と自己同型は保たれるが、
実修復の対象集合を全単射にする主張ではない。

**不能証拠と公開関係。** 常時許容補正の部分への縮約を $`F_{E_0}`$ とすると、
$`D'=DF_{E_0}`$ であり、$`F_{E_0}`$ は $`G_{E_0}`$ を右逆に持つ全射である。従って

```math
\operatorname{im}D'=\operatorname{im}D,\qquad
\mathsf O'=\mathsf O,\qquad o'=o,\qquad B'_c=B_c\quad(c\in\mathsf E).
```

ここでは同じ面座標を通じて商を同定している。全 $`S`$ の残存障害と極小修復範囲が一致し、
§3.4の条件下では証拠支持族 $`\mathcal H_o`$ も一致する。
局所の内部変数消去でも、分割した二辺はともに非共有の常時許容辺であるため、
§3.1の公開関係 $`R_U`$ は同じ境界・候補座標上で等しい。
部品側の復元は、旧補正 $`h_e`$ に対して任意の $`a\in A_w`$ を選び、
$`h_1=a`$、$`h_2=h_e-\rho_2a`$ とすることで全て得られる。

**外部との合成。** $`F,G`$ は $`W`$ 上恒等で、$`\eta|_W=0`$ である。
従って、$`W`$ で接続する外部表示 $`V`$ を固定したまま、これらを $`V`$ 上恒等に延長できる。
共有辺・共有頂点の厳密一致を保つため、§3.1の $`\operatorname{Glue}_S`$ と交換し、
接続後の全実修復groupoidにも同値を与える。
同じ旧端点を持つ経路の実合成・核輸送は一致し、旧頂点を基点とする閉路holonomyも保つ。

新頂点の再同定を許すことと、両因子を常時許容辺にすることが、この操作の条件である。
新頂点まで固定すると追加された実修復を同定できない例が§5.7に現れる。
候補辺自体を分割する場合には、解禁条件と零条件の輸送を別に定める必要がある。
観測最適値を比較する場合も、旧一辺の評価と新二辺の評価の対応・費用を指定する。
(Sub)だけから問い合わせ数の不変性は結論しない。

## 4. 既存研究との具体的な比較

### 4.1 最も近い理論への具体的な写像

比較では、同じ有限線形方程式を各理論の入力へ写す。領域の補正解を
$`H={h:d^1h=-\delta}`$、再同定を $`G=C^0(U,P_U)`$、作用を
$`h\mapsto h+d^0b`$ とする。$`z:H\to Z`$ は共有辺と全候補辺の補正値を取り出す写像である。
これらから、次の二つの忘却表示を作る。

```math
\mathcal I
\longmapsto (0\longleftarrow H\xrightarrow{z}Z)
\longmapsto R=z(H)\subseteq Z.
\tag{Fgt}
```

最初の表示は解の空間と境界・候補への射影を保持し、再同定作用と元の実射への復元を忘れる。
二番目は各 $`z`$ を実現する内部解も忘れる。ここで $`0`$ は一元の零次元空間である。
空の場合を許すアフィンspanとして読めば一般の右辺を扱え、斉次の場合は線形spanになる。
線形核・基底・演算はそのまま既存の有限次元線形代数へ写る。

[Interacting Hopf Algebras](https://arxiv.org/pdf/1403.7048) の Theorem 5.5 は
行列のspanの等式理論を与える。§6.1の写像 $`\Phi`$ はspanの中間変数を存在量化して
線形関係へ送り、Lemma 6.6は合成保存を示す。$`k`$ 自身を係数PIDに取った場合、
(Fgt)の斉次部分はこの写像そのものである。したがって、全内部解をspanで保持すること、
およびその像を取って合成的な実現可能性判定を行うことは、既存の構成に含まれる。

**公開関係による判定の十分性。** $`Z_S=\{z:y_e=0\ (e\notin S)\}`$ とすると、
任意の外部アフィン条件 $`C\subseteq Z`$ に対し

```math
\exists h\in H:\ z(h)\in C\cap Z_S
\quad\Longleftrightarrow\quad R\cap C\cap Z_S\ne\varnothing.
\tag{Rel}
```

証明は $`R=z(H)`$ の定義による。複数領域の共有値の一致もアフィン条件なので、
§3.1の(B)はこの関係合成で判定できる。**全候補座標を残したアフィン関係は、全 $`S`$ の
存在判定を保持する。** この部分を既存の関係理論との相違とはしない。

また、二つの公開関係 $`R,R'\subseteq Z`$ が全てのアフィン条件 $`C`$ に対して
同じ非空判定を返すことと、$`R=R'`$ は同値である。異なる点 $`z`$ があれば
$`C=\{z\}`$ が区別するためである。これは本ノートの静的な有限関係についての観察であり、
信号流回路の実行意味論に関する定理とは区別する。

[Contextual Equivalence for Signal Flow Graphs](https://arxiv.org/pdf/2002.08874) は、
$`k(x)`$ 上のアフィン関係を表示意味論とし、Proposition 2の一点試験回路を用いて、
Theorem 2・§4.2で文脈同値と表示的等価の一致を証明する。本ノートの方程式は
定数係数のアフィン関係としてその表示領域にも写せる。スカラー拡大は有限体上の
修復の個数や原始問い合わせを保つ操作ではなく、この翻訳は関係の合成と等式の比較に用いる。
存在判定に関する完全抽象性を、修復groupoid全体の完全抽象性と読み替えない。

### 4.2 忘却表示から復元できないもの

以下は各理論の表現力全体についての不可能性ではなく、(Fgt)や $`\pi_0`$ という
明示した忘却の後に何を一意に復元できるかについての比較命題である。

**比較命題。** 有限体上の本ノートの実アフィン操作族には、次の例が存在する。

1. 候補座標を忘れた公開関係が等しいが、修復可能な候補集合が異なる。
2. 全候補座標と全内部解を保持する解spanが等しいが、修復groupoidが同値でない。
3. 局所groupoidを先に $`\pi_0`$ へ送ると、大域修復の同型類も復元できない。
4. 変更範囲を制限した局所groupoidを、同型までの一致だけで貼ると、禁止された補正を
   使って初めて実現できる貼り合わせを含んでしまう。

**証明。** 第1点は§5.5を同じ座標 $`(u,v)`$ で比較する。
$`k=\mathbb F_3`$、$`c=1`$ に対して $`T=-I`$ なら $`v=1`$、$`T=I`$ なら
$`2u+v=1`$ である。候補座標 $`u,v`$ をともに消すと、どちらも一元の非空関係を返す。
しかし $`S=\{a\}`$、すなわち $`v=0`$ で、前者は不能、後者は $`u=2`$ で修復できる。
全候補座標を残せば二つのアフィン関係は異なり、(Rel)がその差を正しく検出する。

第2点では§5.6の二辺閉路を、$`A=\mathbb F_3^2`$、面なし、両辺候補とし、
$`T=I`$ と $`T(x,y)=(x+y,y)`$ で比較する。いずれも解空間は
$`H=A\oplus A`$、候補射影は $`z=\mathrm{id}`$ であり、全 $`S`$ の生の解空間
$`H\cap Z_S`$ も一致する。一方、再同定作用は

```math
d^0_T(b_s,b_t)=(b_t-b_s,\ b_s-Tb_t)
```

であり、これを(Fgt)の最初の写像が忘れる。全候補を許す場合のgroupoidは

```math
\begin{array}{c|c|c}
T&\#\pi_0&\operatorname{Aut}(h)\\\hline
I&9&A\quad(9\text{要素})\\
\begin{psmallmatrix}1&1\\0&1\end{psmallmatrix}&3&\mathbb F_3\quad(3\text{要素})
\end{array}
```

となる。実際、$`e`$ の補正を零にする再同定で
$`H//G\simeq A//A`$、作用 $`w\mapsto w+(I-T)b`$ へ移り、同型類は
$`\operatorname{coker}(I-T)`$、自己同型は $`\ker(I-T)`$ である。

### 5.1 アフィン変換言語の実射・全核・輸送への実現

と同定される。$`\pi:E\to H=\operatorname{GL}_k(A)`$ は同じ写像の線形成分を読む


### 5.3 同一表示の候補解禁、原始観測、修復出力

§5.2で、表示、係数、core、固定する場所 $`P`$ は既知とし、固定辺の実操作表
$`\tau_{b_1},\tau_{b_2}`$ を未知入力とする。各入力の修復中は、その二つの実操作を保持する。

このように「修復中に固定する」と「問い合わせ前に値を知っている」を区別する。

入力値の空間を $`\mathsf V=A^2`$、共有補正が実現できる要求を
$`\mathsf R=\operatorname{diag}A`$ と置く。この商は上の相対障害と符号を介して対応する。
$`b_i`$ の観測は、固定辺 $`a`$ または $`b`$ を状態0で評価することで実現する。
各問い合わせは一つの座標を正確に返す。

全 $`S`$ を比較する例では、初めから内部辺 $`c:t\to t`$ を持つ表示 $`K^+`$ を用い、
第二の面を $`ce\Rightarrow b`$ とする。$`c=\tau_z`$ の基準実操作は恒等とし、
$`E_0=\{e\}`$、$`\mathsf E=\{c\}`$ と置く。$`a,b`$ と両頂点は固定する。

```math

u=b_1,\quad z=b_2-b_1
```

となる。$`S=\varnothing`$ では $`z=0`$ を課すので、要求の許容方向は
$`\operatorname{diag}A`$ であり、§5.2と同じ存在判定になる。
$`S=\{c\}`$ では要求の全 $`A^2`$ を吸収できる。
両者は同じ $`K^+`$ と原始入力を使う(M_S)の二つの範囲である。

問い合わせを $`a(0)=b_1`$、$`b(0)=b_2`$ の二つに限定する。
数値出力は、許容範囲の補正値を明示するか、修復不能を返すものとする。

| 既知情報 | $`S=\varnothing`$：判定／数値出力 | $`S=\{c\}`$：判定／数値出力 |
| --- | --- | --- |
| 値なし | 2／2 | 0／2 |
| $`b_1`$ が既知 | 1／1 | 0／1 |
| 両値、または両具体的インターフェースが既知 | 0／0 | 0／0 |

$`S=\{c\}`$ で既存操作の参照・逆・合成を出力言語に許せば、
$`e:=a`$、$`c:=b\circ a^{-1}`$ という式は値を問い合わせずに生成できる。
表の数値出力には、未知操作を後で呼び出す式は含めない。

旧入力の両値が既知で「$`b_2`$ だけが更新された」という情報を受け取った場合は、
構造と $`b_1`$ を再利用する。追加判定は候補禁止時に一回、解禁時に零回となる。
更新値自体も通知に含まれる場合は、それを既知情報に加える。

### 5.4 非自明な輸送と、全修復を保持する例

相対障害の例に加え、核輸送を落とすと存在判定が変わる例を用意する。
$`A=\mathbb F_3`$ とし、三頂点 $`s,m,t`$、辺 $`e,b:s\to m`$、$`f:m\to t`$、
$`a:s\to t`$、面 $`fe\Rightarrow a`$ と $`e\Rightarrow b`$ を取る。
$`e,b`$ のcoreは恒等、$`f,a`$ のcoreは $`-1`$、指定比較は恒等とする。
実操作は $`e(x)=x+u`$、$`f(x)=-x+1`$、$`a(x)=-x`$、$`b(x)=x+1`$ とし、
頂点と辺 $`f,a,b`$ を固定する。面の一致条件は $`-u+1=0`$ と $`u=1`$ なので、
実修復 $`u=1`$ がある。核輸送を恒等として計算すると第一の式が $`u+1=0`$ へ変わり、
第二の式と両立しなくなる。非自明な輸送を保持することが、修復の存在判定に必要な例となる。
この例の閉路holonomyは自明である。$`t`$ の座標を反転し、固定操作の表も同時に
変換すれば全辺の線形成分は恒等になる。これは $`P`$ 上で恒等な許容再同定とは異なる
座標表示の変更であり、固定した操作表で輸送を正確に扱う必要性を示している。

全修復の保持は§5.6で、同じ閉路作用から生じる修復の同型類・自己同型・貼り合わせを
具体的に比較する。三領域以上の例では、二重交差ごとの再同定に加え、
三重交差の整合を検証する。
輸送が同型で各連結成分が $`P`$ の頂点に触れる場合は、$`d^0b=0`$ と固定頂点での零から
辺に沿って $`b=0`$ が伝播し、$`H^0(K,P)=0`$ となる。自己同型を残す例はその条件と
区別する。全体の自己同型が自明でも、§2.5の重なりの $`BA`$ は貼り合わせに影響する。

### 5.5 閉路holonomyが極小修復範囲を変える例

$`A=\mathbb F_3`$、一頂点と二本の名前付きloop $`a,b`$ を取る。
頂点を $`P`$ として固定し、$`E_0=\varnothing`$、$`\mathsf E=\{a,b\}`$ とする。
coreはそれぞれ $`T=-1`$ と恒等、基準実操作は $`a_0(x)=-x`$、$`b_0(x)=x`$ とする。
全核補正を加えた実操作は

```math
a_u(x)=-x+u,\qquad b_v(x)=x+v.
```

非零の $`c\in A`$ を固定し、面の左経路を $`baa`$、右経路を空経路、
指定比較を $`\tau_{-c}`$ とする。3-cell集合は空とする。
指定比較は平行移動の全核と可換であり、coreでは両経路の輸送が恒等で一致する。
実際の面の条件は

```math
b_v\circ a_u\circ a_u=\tau_c,\qquad
(I+T)u+v=c.
```

である。$`T=-1`$ では $`a_u^2=\mathrm{id}`$ であり、$`(I+T)u=0`$。
したがって§3.4の空間と写像は

```math
\mathsf O=A,\qquad o=c,\qquad B_a=0,\qquad B_b=I
```

となる。恒等評価 $`\lambda:A\to\mathbb F_3`$ は $`\lambda(o)\ne0`$ を満たし、
その証拠支持は $`E_\lambda=\{b\}`$ である。

| 追加補正を許す集合 $`S`$ | 補正の制約・解 | 存在 |
| --- | --- | --- |
| $`\varnothing`$ | $`u=v=0`$ | なし |
| $`\{a\}`$ | $`v=0`$、$`u`$ は任意 | なし |
| $`\{b\}`$ | $`u=0`$、$`v=c`$ | あり |
| $`\{a,b\}`$ | $`u`$ は任意、$`v=c`$ | あり |

包含極小の修復可能範囲は $`\{b\}`$ だけである。
同じ表示でcoreを $`T=I`$ とする別の入力では、$`a_u(x)=x+u`$ となり、
面の条件は $`2u+v=c`$ に変わる。$`2`$ は $`\mathbb F_3`$ で可逆なので、
極小修復範囲は $`\{a\}`$ と $`\{b\}`$ の二つとなる。

loop $`a`$ の輸送 $`-1`$ は、頂点の基底変更による共役でも恒等にはならない。
この例は、閉路holonomyが名前付き補正の有効性と極小修復範囲を変えることを示す。
計算対象は上の指定比較を持つ有限表示の修復であり、3-cellを追加する際には
その比較の整合条件を改めて満たす必要がある。

### 5.6 閉路作用が修復の同型類と自己同型を同時に決める例

$`A=\mathbb F_3^2`$、$`T(x,y)=(x+y,y)`$ とし、§5.1のアフィン群の射影を使う。
全核は平行移動 $`A`$ であり、二頂点 $`s,t`$ を往復する辺の実操作を

```math
e_u:s\to t,\quad e_u(x)=x+u,\qquad
f_v:t\to s,\quad f_v(x)=Tx+v
```

とする。$`P=\varnothing`$、面・3-cellなしとし、まず両辺の補正を許す。
再同定 $`(b_s,b_t)\in A^2`$ は

```math
(u,v)\longmapsto(u+b_t-b_s,\ v+b_s-Tb_t)
```

と作用する。一周する実操作は $`f_ve_u(x)=Tx+w`$、$`w=v+Tu`$ であり、
再同定によって $`w\mapsto w+(I-T)b_s`$ となる。
$`e`$ の補正を零にする再同定を用いると、修復groupoidは次の作用groupoidと同値になる。

```math
\mathscr R(K)\simeq A//A,\qquad b\cdot w=w+(I-T)b,
\qquad
\pi_0\mathscr R(K)\cong\operatorname{coker}(I-T)\cong\mathbb F_3,
\qquad
\operatorname{Aut}(h)\cong\ker(I-T)\cong\mathbb F_3.
```

ここで $`A//A`$ は作用する元 $`b\in A`$ を射として保持する。
作用の像だけで割ると、核に属する自己同型を失う。
実操作の組は81個、再同定の軌道は各27個の三つであり、各安定化群は3要素となる。

領域 $`U`$ は辺 $`e`$ と両端点、$`V`$ は辺 $`f`$ と両端点、
重なり $`W`$ は二頂点からなる。$`BA`$ を一対象で自己同型群が $`A`$ のgroupoidとすると、
基準操作 $`e_0,f_0`$ を使った局所の表示は

```math
\mathscr R(U)\simeq BA,\qquad
\mathscr R(V)\simeq BA,\qquad
\mathscr R(W)\simeq B(A\oplus A).
```

境界への写像は、$`(s,t)`$ の順に $`b\mapsto(b,b)`$ と $`b\mapsto(Tb,b)`$ である。
そのhomotopy pullbackは、三つの同型類と各 $`\mathbb F_3`$ の自己同型群を回復する。
一方、先に各groupoidの $`\pi_0`$ を取ると $`*\times_* *=*`$ になり、
大域の選択肢と自己同型を保持できない。

同じ例で $`E_0=\varnothing`$、$`\mathsf E=\{e,f\}`$、基準を $`u=v=0`$ とし、
$`S=\varnothing`$ を取る。大域の対象は一つで、その自己同型は
$`b_t=b_s=Tb_t`$ を満たすので、$`\mathscr R_{\varnothing,\varnothing}(K)\simeq B\mathbb F_3`$ となる。
しかし制限した局所groupoidは依然として上の $`BA`$ と同じ境界写像を持つため、
通常のhomotopy pullbackは三つの $`B\mathbb F_3`$ を返す。
§3.1の厳密な一致条件を使う合成は、一つの対象とその許された自己同型を回復する。

$`\ker(I-T)=\operatorname{im}(I-T)=\langle(1,0)\rangle`$ であり、
$`T`$ は不変な補空間を持たない非分裂のJordan blockである。
同じ閉路作用が、再同定で動かせる方向、残る修復の違い、自己同型を支配している。
頂点 $`s`$ を固定する変形では、大域自己同型は消え、全補正時の同型類は $`A`$ の九つとなる。
この場合も局所は一点、重なりは $`BA`$ で、重なりの射が九つの貼り合わせを区別する。

この例は全修復の分類と合成を検査する。§5.5は修復要求と極小範囲に対するholonomyの
効果を検査し、両例で主定理の異なる結論を具体化する。

### 5.7 非自明な閉路作用を保つ分割と、実修復の復元

§5.5と同じ $`A=\mathbb F_3`$、固定頂点 $`p`$、loop $`a,b`$、面 $`baa`$ と
指定比較 $`\tau_{-c}`$ を使い、$`c\ne0`$ とする。
ここでは $`E_0=\{a\}`$、$`\mathsf E=\{b\}`$ とし、$`a`$ を常時補正可能な内部辺とする。
実操作は $`a_h(x)=-x+h`$、$`b_z(x)=x+z`$、面の条件は $`z=c`$ である。
この表示では $`P=W=\{p\}`$ としてよい。

$`a`$ を新頂点 $`w`$ を通る二辺 $`a_1:p\to w`$、$`a_2:w\to p`$ に分割する。
基準実操作とその全核補正を

```math
L_1(x)=x+1,\qquad L_2(x)=-x+1,\qquad L_2L_1(x)=-x,
\qquad
a_{1,u}(x)=x+1+u,\qquad a_{2,v}(x)=-x+1+v
```

とする。$`\rho_1=I`$、$`\rho_2=-I`$ であり、実際に合成すると

```math
a_{2,v}a_{1,u}(x)=-x+(v-u),\qquad h=v-u.
```

面を $`b(a_2a_1)(a_2a_1)`$ に置換すると、条件は引き続き $`z=c`$ となる。
旧閉路 $`a`$ と新閉路 $`a_2a_1`$ の核輸送はともに $`-I`$ である。
新頂点の再同定 $`t\in\mathbb F_3`$ は
$`(u,v,z)\mapsto(u+t,v+t,z)`$ と作用し、合成補正 $`h=v-u`$ を保つ。

| 候補の解禁集合 $`S`$ | 分割前の実修復数 | 分割後の実修復数 | 分割前後の同型類数 |
| --- | --- | --- | --- |
| $`\varnothing`$ | 0 | 0 | 0 |
| $`\{b\}`$ | 3 | 9 | ともに3 |

分割前は $`h\in\mathbb F_3`$ の三つで、固定頂点のため再同定は恒等だけである。
分割後は各 $`h`$ に対し $`(u,v)=(r,h+r)`$ の三つがあり、新頂点の再同定が
それらを自由推移的に結ぶ。両側の各修復の自己同型群は自明である。
標準の復元は $`(u,v)=(0,h)`$、全ての復元は $`r`$ を動かして得られる。

候補 $`b`$ の補正値 $`z`$ は変わらず、公開関係は両側とも $`z=c`$ である。
従って、極小修復範囲 $`\{b\}`$ と、それを要求する不能証拠も同じになる。
一方、分割後に新頂点 $`w`$ まで固定すると九つの実修復が全て別の同型類となり、
三つの同型類を持つ旧groupoidとの同値は失われる。
新しい頂点の固定は、§3.6の分割とは異なる保存条件を課す操作である。

### 5.8 同じ有限変換網での生成・修復・観測・再利用

処理系の可逆データ変換網を表す有限な設計例を固定する。
対象値は $`A=\mathbb F_3`$ とし、全操作は一変数のアフィン全単射とする。
線形成分への射影の全核は平行移動であり、以下の補正はこの全核を用いる。
頂点 $`p`$ と二つの入力操作 $`r_x=\tau_x,r_y=\tau_y`$ を固定部分 $`P`$ に置く。
パラメータ $`(x,y)\in\mathbb F_3^2`$ の各組が実操作として実現し、修復中はその組を保つ。
問い合わせ前には両値が未知であり、構造・線形成分・操作名・固定する場所を既知とする。

常時補正可能な操作と候補操作を

```math
e_u(t)=t+u,\qquad a_h(t)=-t+h,\qquad
b_z(t)=t+z,\qquad c_v(t)=t+v,
\qquad E_0=\{e,a\},\quad\mathsf E=\{b,c\}
```

とする。四つとも $`p`$ のloopであり、基準の補正は零とする。
指定する二つのLawは

```math
e_u b_z=r_x,\qquad e_u a_h b_z a_h c_v=r_y.
\tag{X1}
```

合成は右から適用する。両経路のcoreは恒等、指定比較も恒等とし、3-cellは置かない。
したがって任意の $`x,y`$ が同じ入力条件を満たす。
実際の関数を合成すると

```math
u+z=x,\qquad u-z+v=y.
\tag{X2}
```

を得る。$`a_h`$ を二度通る効果により $`h`$ は相殺されるが、間の操作 $`b_z`$ の補正は
$`z\mapsto-z`$ と輸送される。閉路 $`a`$ のholonomyは $`-1`$ であり、頂点の座標変更でも
恒等にはならない。

**局所からの生成と、全修復の復元。** 領域 $`U`$ に $`e,b,r_x`$ と第一の面、
領域 $`V`$ に $`e,a,b,c,r_y`$ と第二の面を置く。重なり $`W`$ は $`p,e,b`$ である。
公開する記号的関係は、それぞれ $`u+z=x`$ と $`u-z+v=y`$ となる。
$`V`$ は、内部の全補正を復元するため、自由パラメータ $`h\in\mathbb F_3`$ も局所に保持する。
旧頂点は固定されているので、異なる $`h`$ は異なる修復の同型類であり、このパラメータを
公開関係だけで置き換えて捨てることはできない。

共有する $`u,z`$ を一致させ、常時補正 $`u`$ を消去すると

```math
d:=y-x=z+v,\qquad
(u,h,z,v)=(x-z,h,z,d-z),\qquad h,z\in\mathbb F_3.
\tag{X3}
```

を得る。これが全候補許容時の全修復であり、候補禁止は $`b\notin S`$ なら $`z=0`$、
$`c\notin S`$ なら $`v=0`$ として同じ式へ課す。
行列は値を取得する前に、元の合成から

```math
D=\begin{pmatrix}1&0\\1&0\end{pmatrix},\qquad
E_b=\binom{1}{-1},\qquad E_c=\binom{0}{1},\qquad
-\delta=\binom{x}{y}
```

と生成できる。$`D`$ の列は $`u,h`$ の順である。
$`q(r_1,r_2)=r_2-r_1`$ によって $`\mathsf O\cong\mathbb F_3`$、
$`o=d`$、$`B_b=B_c=1`$ を得る。共有座標の一致と局所の消去から得た(X3)は、この大域の商と一致する。

| 解禁範囲 $`S`$ | 実修復の全体 | 実修復数・同型類数 |
| --- | --- | --- |
| $`\varnothing`$ | $`d=0`$ のとき $`(x,h,0,0)`$ | $`d=0`$ なら3、それ以外は0 |
| $`\{b\}`$ | $`(x-d,h,d,0)`$ | 3 |
| $`\{c\}`$ | $`(x,h,0,d)`$ | 3 |
| $`\{b,c\}`$ | $`(x-z,h,z,d-z)`$ | 9 |

各行で $`h`$、最終行ではさらに $`z`$ が自由に動く。旧表示の自己同型は全て恒等である。
$`d\ne0`$ なら $`\lambda:\mathsf O\to\mathbb F_3`$ を恒等評価とすると、
$`\lambda(o)=d\ne0`$ が候補禁止時の修復不能証拠となる。
全ての非零証拠の支持は $`\{b,c\}`$ なので、包含極小の修復可能範囲は
$`\{b\}`$ と $`\{c\}`$ である。$`d=0`$ なら空集合が唯一の極小範囲となる。

ここで同じ表示・固定部分・許容範囲を保ち、$`a_h(t)=Tt+h`$ の線形成分を $`T=1`$ へ変えると、
実合成から得る差の式は

```math
d=(1+T)h+(T-1)z+v=2h+v
```

に変わる。常時許容する $`h`$ だけで全ての入力を修復でき、極小範囲は常に空集合となる。
$`T=-1`$ のholonomyは常時補正のこの方向を相殺し、候補 $`b`$ に有効な補正方向を生む。
この比較でも補正 $`h`$ は許容したままであり、輸送を変えた後にその自由度を落とさない。

**未知入力の取得と、判定・数値出力の差。** 原始問い合わせを
$`r_x(0)=x`$ と $`r_y(0)=y`$ の二つに限定する。数値出力は
$`(u,h,z,v)`$ の具体値または修復不能とする。未知操作を後で呼ぶ式は含めない。
全ての入力に常に正答する決定的な手続きの、最適な最悪時追加問い合わせ回数は次となる。

| 既知情報 | $`S=\varnothing`$：判定／数値出力 | $`S\ne\varnothing`$：判定／数値出力 |
| --- | --- | --- |
| 値なし | 2／2 | 0／2 |
| $`x`$ の値のみ | 1／1 | 0／1 |
| $`x,y`$ の両値 | 0／0 | 0／0 |

候補禁止時の判定には $`x=y`$ を決める必要があり、一方の座標だけでは同じ答えの中に
成功入力と失敗入力がある。候補を一つ以上解禁すれば全入力が成功するので、判定には値を要さない。
数値補正を一つ出すと、(X2)から $`x=u+z,y=u-z+v`$ の両値が定まる。
したがって成功入力を含む同一観測fiberの異なる右辺へ、一つの数値補正を共用できない。
表の下限は、この事実と二つの原始座標問い合わせから得られる。上限は取得後に(X3)を使う。
具体的な局所関係 $`u+z=x`$、$`u-z+v=y`$ を既に両方受領している場合、両値は既知であり、
表の最終行が適用される。記号的な生成を値の取得と混同しない。

**同じ構造での値更新。** 旧入力 $`(x,y)=(0,0)`$ と旧補正 $`(0,0,0,0)`$ が既知で、
$`y`$ だけが更新されたとする。更新値を受領していなければ追加問い合わせ $`r_y(0)`$ は一回、
更新値が通知されれば零回である。更新値が $`y=1`$ のとき $`d=1`$ となり、候補禁止では
$`\lambda(o)=1`$ が修復不能を証明する。二つの極小の選択肢は、$`h=0`$ を選ぶと

```math
S=\{b\}:\quad (u,h,z,v)=(2,0,1,0),\qquad
S=\{c\}:\quad (u,h,z,v)=(0,0,0,1).
```

となる。前者は $`e,b`$ の実操作を変更し、後者は $`c`$ だけを変更する。
同じ候補数でも、復元される実操作の変更箇所は異なる。
局所関係・消去行列・不能証拠の評価式・復元式は同じであり、右辺だけを更新する。
$`S\ne\varnothing`$ で可否だけを返す場合は、更新後も観測零回で成功と判定できる。

**内部辺分割後の再利用と、全ての分割補正。** $`a`$ は $`V`$ の内部辺であり、
$`W,P`$ に属さない。新頂点 $`m`$ を固定せず、

```math
a_{1,\alpha}:p\to m,\quad a_{1,\alpha}(t)=t+1+\alpha,
\qquad
a_{2,\beta}:m\to p,\quad a_{2,\beta}(t)=-t+1+\beta
```

へ分割する。基準の合成は $`-t`$ であり、全補正後の合成は
$`a_{2,\beta}a_{1,\alpha}(t)=-t+\beta-\alpha`$ となる。
第二のLawに現れる二箇所の $`a`$ をともに $`a_2a_1`$ へ置換すると、
公開関係(X3)、$`D`$ の像、障害 $`d`$、候補列 $`B_b,B_c`$、全 $`S`$ の判定と極小範囲が保たれる。
旧補正 $`h`$ の全ての復元は

```math
(\alpha,\beta)=(r,h+r),\qquad r\in\mathbb F_3
```

である。新頂点の再同定 $`t\in\mathbb F_3`$ は
$`(\alpha,\beta)\mapsto(\alpha+t,\beta+t)`$ と作用し、同じ旧補正に戻る三つの組を
自由推移的に結ぶ。そのため実修復数は上表の三倍になるが、同型類数と自己同型群は変わらない。
旧入力の更新例では、$`\{b\}`$・$`\{c\}`$ のどちらを選んでも $`h=0`$ の全復元は
$`(\alpha,\beta)=(0,0),(1,1),(2,2)`$ であり、二つのLawの実写像の等号が成立する。
$`V`$ は復元部分だけを更新し、$`U`$ へ公開する関係を再生成する必要はない。
原始問い合わせ $`r_x(0),r_y(0)`$ 自体が変更されないこの例では、上の観測最適値も同じとなる。

この例では、同じ原始入力から、局所表現、全変更範囲の判定、不能証拠、極小解禁、元の実操作への
補正、出力別の観測、値更新、内部分割後の再利用が得られる。閉路輸送・内部の修復パラメータ・
再同定のいずれかを捨てると、それぞれ極小範囲・全修復・分割後の同型類の対応を失う。

### 5.9 週次ジョブの移行と、既存通知を保つ互換処理

週次ジョブのワーカーを入れ替え、受け取る曜日番号を日曜始まりから月曜始まりへ変える
設計例を考える。同じ共有処理を使う既存通知は、従来どおり「当日を含む次の日曜までの日数」
を返す。問題は、**共有処理だけで新ワーカーへ合わせられるか、どちらの利用側まで変更を
許す必要があるか**である。

曜日番号には実在する二つの規約を使う。ECMAScriptの曜日値は日曜0・月曜1・…・土曜6、
Pythonの `date.weekday()` は月曜0・…・日曜6である。
[ECMAScript仕様](https://tc39.es/ecma262/2025/multipage/numbers-and-dates.html#sec-week-day)、
[Python仕様](https://docs.python.org/3/library/datetime.html#datetime.date.weekday)。
入力は、日付から既に取り出されたECMAScript式の曜日コード $`d\in\{0,\ldots,6\}`$ とする。
対象となる操作は、この7値を変換する純粋関数であり、演算を $`\mathbb F_7`$ 上で行う。

**実装と固定する振る舞い。** 共有処理 $`e`$ の後で、新ワーカー用の互換処理 $`a`$ と
既存通知用の処理 $`b`$ に分岐する。$`e`$ の出力は公開されない7値の中間コードであり、
その番号の意味は二つの利用側と一緒に変更できる。外部の入出力形式は固定する。
補正する定数 $`u,z,v`$ の基準値を全て0とすると、処理は次のように書ける。

```python
def route_weekday(day, u=0, z=0, v=0):
    internal_day = (day + u) % 7
    return {
        "worker_day": (internal_day + z) % 7,
        "days_until_sunday": (-internal_day + v) % 7,
    }
```

新ワーカーへ渡す値は $`r_W(d)=d-1`$、既存通知の値は $`r_N(d)=-d`$ とする。
後者は日曜に0、月曜に6、土曜に1を返す。たとえば月曜入力 $`d=1`$ では、
移行後の正しい出力は `worker_day=0, days_until_sunday=6` である。
基準の処理は `(1,6)` を返す。共有処理だけを $`u=6`$ に変えると `(0,0)` となり、
新ワーカーに合わせる変更が既存通知を壊す。

有限表示の頂点を入力 $`s`$、内部 $`m`$、ワーカー出力 $`w`$、通知出力 $`n`$ とし、

```math
e_u:s\to m,\quad e_u(d)=d+u,\qquad
a_z:m\to w,\quad a_z(t)=t+z,\qquad
b_v:m\to n,\quad b_v(t)=-t+v
```

を名前付きの実操作にする。固定部分 $`P`$ は外部頂点 $`s,w,n`$ と、
基準となる辺 $`r_W:s\to w`$、$`r_N:s\to n`$ からなる。
二つの面を $`a_ze_u\Rightarrow r_W`$、$`b_ve_u\Rightarrow r_N`$ とし、
指定比較は恒等、3-cellは置かない。常時補正できるのは共有処理 $`E_0=\{e\}`$、
解禁候補は利用側の $`\mathsf E=\{a,b\}`$ である。

**実コードから核と方程式を得る。** 保持する線形成分は $`e,a`$ で $`1`$、
$`b`$ で $`-1`$ である。これは、入力の曜日を翌日へ進めると、曜日コードは1進み、
日曜までの日数は1減るという循環的な対応を表す。7値上の写像に

```math
f(d+1)=f(d)+M\quad(\forall d\in\mathbb F_7),\qquad M\in\{1,-1\}
```

を課すと、逐次代入から $`f(d)=Md+f(0)`$ が従う。逆も成立し、これらは全て全単射である。
したがって、この条件を満たす全操作は§5.1でcoreを $`M`$ に固定したfiberに一致し、
補正は射影の全核である平行移動7個を尽くす。上のコードでは式から条件を確認でき、
既存の変換表から入力を作る場合には7値全てについて同じ等式を検査できる。

二つのLawを実関数の合成として展開すると

```math
a_ze_u=r_W\ \Longleftrightarrow\ u+z=6,\qquad
b_ve_u=r_N\ \Longleftrightarrow\ -u+v=0.
\tag{W1}
```

となる。通知経路で共有補正の符号が反転するのは、実操作 $`b`$ の核輸送が
$`\rho_b=-1`$ だからである。係数を手で割り当てず、同じ関数の合成からこの符号を得る。

**局所検証から統合と全修復へ。** ワーカー側の領域 $`U`$ は $`e,a,r_W`$ と第一の面を、
通知側の領域 $`V`$ は $`e,b,r_N`$ と第二の面を持つ。重なりは共有辺 $`e`$ とその両端点である。
両領域は(W1)の一方ずつを公開する。候補を禁止したままでも、ワーカー側は $`u=6`$、
通知側は $`u=0`$ でそれぞれ局所検証を通せる。しかし、統合時には同じ共有処理を
二つの異なる値に設定できない。

二つの公開関係で共有値 $`u`$ を一致させ、消去すると

```math
z+v=6,\qquad (u,z,v)=(u,6-u,u),\quad u\in\mathbb F_7.
\tag{W2}
```

を得る。候補を禁止する条件を $`z=0`$ または $`v=0`$ として同じ関係へ課せば、
全ての許容範囲の可否と、元のコードへ戻す補正定数が得られる。

| 解禁候補 $`S`$ | 全修復 $`(u,z,v)`$ | 実装で行う変更 |
| --- | --- | --- |
| $`\varnothing`$ | なし | 共有処理だけでは両方の出力仕様を保てない |
| $`\{a\}`$ | $`(0,6,0)`$ | 共有処理と通知を維持し、ワーカー直前で月曜始まりへ変換する |
| $`\{b\}`$ | $`(6,0,6)`$ | 共有処理を月曜始まりへ変え、通知側でその影響を補正する |
| $`\{a,b\}`$ | $`(u,6-u,u)`$、$`u\in\mathbb F_7`$ | 7通りの内部表現と、それぞれに対応する利用側の補正 |

包含極小の解禁範囲は $`\{a\}`$ と $`\{b\}`$ である。解禁候補数は同じでも、
前者は $`a`$、後者は $`e,b`$ の実操作を変える。これは変更許可の極小性であり、
変更する関数数やパッチ行数の最小化とは区別する。担当範囲やリリース順に応じて、
この二つの案から選べる。

同じ合成から $`D=(1,-1)^{\mathsf T}`$、$`E_a=(1,0)^{\mathsf T}`$、
$`E_b=(0,1)^{\mathsf T}`$、$`-\delta=(6,0)^{\mathsf T}`$ を得る。
$`q(r_1,r_2)=r_1+r_2`$ により $`\mathsf O=\mathbb F_7`$、$`o=6`$、
$`B_a=B_b=1`$ となる。双対評価 $`\lambda=\mathrm{id}_{\mathbb F_7}`$ は、
共有処理の変更だけでは変わらない非零値6を返し、候補支持は $`\{a,b\}`$ である。
従って、少なくとも一方の利用側を変更する必要があり、どちらの単独解禁でも修復できる。
この不能証拠と上表は、同じ実操作・同じ許可範囲から得られる。

**内部表現の再命名と観測。** 非固定頂点 $`m`$ の再同定 $`t\mapsto t+\beta`$ は

```math
(u,z,v)\longmapsto(u+\beta,\ z-\beta,\ v+\beta)
```

として作用する。両候補を許せば七つの実修復を自由推移的に結ぶので、同型類は一つ、
各修復の自己同型は恒等だけになる。片方を禁止した場合、その実操作を保つ条件が
$`\beta=0`$ を強制する。内部コードは公開形式として固定していないため、この同型は
中間表現の変更に対応する。外部出力が同じでも、上表の異なるパッチを一つの実操作へ
潰してはいない。

この具体例では出力仕様の定数6と0を既に知っているため、修復判断・補正出力のための
追加観測は0回である。既存の関数表を調べて定理の入力条件を確認する作業と、
条件確認後の未知パラメータを取得する問い合わせを区別する。

開発者へ返せるのは「テストが失敗した」という情報に加え、**共有処理だけでは直せない理由、
追加変更を許す二つの極小範囲、その各範囲でコードへ書き戻せる全ての定数**である。
この例では直接連立しても同じ解を得る。主定理は、各担当領域で生成した関係を合成して
同じ判定と全修復を回復できることを保証する。非自明な閉路holonomyの役割は§5.5〜5.8の例が示す。

## 6. 接続定理：修復・観測双対性

§3.5の記号的表現から、未知の実操作について何を取得すれば判定・数値補正出力が
可能になるかを導く。具体的インターフェースの生成に既に使った観測は、取得済み情報に含める。

### 6.1 原始入力から修復方向への接続

表示・core・核輸送・候補名を共有する原始入力族 $`\mathcal F`$ を取る。
未知値を読む座標 $`\nu:\mathcal F\to\mathsf V`$ と、全 $`v\in\mathsf V`$ の
実現 $`X_v\in\mathcal F`$ を与え、$`\nu(X_v)=v`$ を元の実操作で確認する。
$`\mathsf V`$ は同じ有限体上の有限次元空間である。これは入力族の条件であり、
修復可能性や障害の零性を入力として与えるものではない。
原始問い合わせ $`j`$ の実評価が $`\lambda_j(\nu(X))`$ に一致することも確認する。

§3.5のように、既知の線形成分とパラメータにアフィンに依存する実平行移動から
各経路を合成する。経路補正の式により、面の実defectの負号付き座標は
$`r(v)=b_0+Bv`$ となる。行列 $`B`$ と定数項 $`b_0`$ は、この実合成から計算する。
各 $`S`$ に対し、主定理の同じ辺行列から許容列を取ったものを $`D_S`$ とし、
$`q_S:C^2\to\operatorname{coker}D_S`$ と置く。

**接続命題。** 全ての $`S`$ と $`X\in\mathcal F`$ について

```math
\mathscr R_{P,S}(X)\ne\varnothing
\quad\Longleftrightarrow\quad
q_S\bigl(b_0+B\nu(X)\bigr)=0.
\tag{Obs}
```

**証明。** 主定理の復元は、独立に定義した実修復と
$`D_Sh=b_0+B\nu(X)`$ の解を対応させる。この線形方程式に解があることは
右辺が $`\operatorname{im}D_S`$ に属することと同値であり、(Obs)を得る。
局所の記号的関係を合成しても、同じ主定理から同じ判定になる。
$`\operatorname{im}D_S=\operatorname{im}D+\sum_{e\in S}\operatorname{im}E_e`$ なので、
$`\operatorname{coker}D_S\cong\mathsf O/\mathsf R_S`$ も同じ面座標から得られる。∎

修復可能な基準入力 $`v_*`$ がある場合、$`v=v_*+n`$ と移して
$`\mathsf R^{\mathrm{in}}_S=\ker(q_SB)`$ とする。このとき入力側の商は

```math
\mathsf V/\mathsf R^{\mathrm{in}}_S\cong\operatorname{im}(q_SB)
\subseteq\mathsf O/\mathsf R_S
```

となる。問い合わせの下限には、この実現された入力族と像だけを用いる。
修復可能な入力が一つもない場合は全入力で不能を返せる。
§6.2では線形化した入力を $`\mathsf V`$、修復可能部分空間を $`\mathsf R`$ と略記する。

§5.1の実現を用いる§5.8では、$`\mathsf V=\mathbb F_3^2`$、
$`X_{(x,y)}`$ は固定入力操作 $`\tau_x,\tau_y`$ を持つ同じ網であり、
その0での評価が $`\nu(X_{(x,y)})=(x,y)`$ になる。全入力でcoreと指定比較が整合し、
実合成から $`b_0=0,B=I`$ を得る。この一族で、全実現・原始評価・同じ障害・全 $`S`$ の
対応が同時に成立する。§5.3も同じ構成の小さい例である。

全補正を許し局所修復がある場合には、§2.4の接続写像が局所差を同じ実defectへ送る。
一般の $`S`$ は上の $`\mathsf O/\mathsf R_S`$ で扱う。
同じ物理的な基準操作の別表示には、§2.5の固定条件も同時に輸送する。
既知情報が入力を制限するときは、その残るfiberを§6.4・§6.5で扱う。

### 6.2 障害の双対、観測十分性、最悪時最適値

有限な問い合わせ集合 $`J_0`$ と線形評価 $`\lambda_j\in\mathsf V^*`$ を固定する。
$`J\subseteq J_0`$ の観測を $`O_J(v)=(\lambda_j(v))_{j\in J}`$ とする。
**定理（観測十分性と最悪時最適値）。** 上の入力に対して

```math
\begin{aligned}
(\mathsf V/\mathsf R)^*&\cong\mathsf R^\perp,\\
\exists f\ \forall v,\quad f(O_J(v))=\mathbf 1_{\mathsf R}(v)
&\Longleftrightarrow \ker O_J\subseteq\mathsf R\\
&\Longleftrightarrow\mathsf R^\perp\subseteq
\operatorname{span}\{\lambda_j:j\in J\}.
\end{aligned}
\tag{D}
```

$`\mathbf 1_{\mathsf R}`$ は所属の真偽を返す関数、
$`\mathsf R^\perp=\{\lambda:\lambda|_{\mathsf R}=0\}`$ は修復で変わらない評価の空間である。
十分性は、同じ観測の二入力の差が $`\ker O_J`$ に入ることから従う。
必要性は、零入力と $`\ker O_J\setminus\mathsf R`$ の入力が区別できないことから従う。
有限次元の双対を取り、核包含を評価のspanの条件へ移す。

G-128への接続には、加法群 $`G=(\mathsf V,+)`$、部分群 $`\Gamma=\mathsf R`$ と、
観測点 $`X_{\mathrm{obs}}=\coprod_{j\in J_0}k`$ への作用

```math
v\cdot(j,a)=(j,a+\lambda_j(v))
```

を構成する。点 $`(j,0)`$ の評価は問い合わせ $`j`$ と同じ情報であり、点安定化群は
評価の核になる。同じ $`j`$ の異なる $`a`$ を読むことは新しい情報を増やさない。
作用、観測表、修復可能性の述語をこの対応で一致させ、G-128の結論から

```math
D_{\mathrm{repair}}
=\min\{|J|:J\subseteq J_0,\ \ker O_J\subseteq\mathsf R\}
\tag{Q}
```

を得る。十分な集合がない場合は右辺を無限大とする。
ここで $`D_{\mathrm{repair}}`$ は、正確な問い合わせのみで全入力に常に正答する
決定的手続きの、最適な最悪時問い合わせ回数である。
下限は零入力でたどる質問列を再現する入力から、上限は最小の固定集合から得る。

このモデルでは、入力について既知の情報と、問い合わせでのみ得られる値を分ける。
問い合わせ以外の計算回数は(Q)に含めない。集約値を一回で返す問い合わせを追加すれば
最適値は変わる。§5.3では座標評価に二回を要する一方、$`b_1+b_2`$ を正確に返す
問い合わせを許せば一回で存在を判定できる。

### 6.3 修復不能の証拠と、必要な変更方向

有限次元では、修復不能な $`v\notin\mathsf R`$ に対し

```math
\lambda|_{\mathsf R}=0,\qquad\lambda(v)\ne0
```

を満たす $`\lambda`$ を商空間の双対から構成できる。
許容補正が吸収できる方向ではこの値を変えられないので、同じ証拠が全ての許容修復を排除する。
同じ入力座標を保ったまま修復方向を $`\mathsf R'\supseteq\mathsf R`$ へ広げても、
$`\lambda|_{\mathsf R'}=0`$ なら修復不能である。
したがって成功する範囲拡張には、この評価を変える操作方向の追加が必要になる。
一つの証拠を変えられることは必要条件であり、成功の判定は拡張後の全障害で行う。

§5.3では $`\lambda(b_1,b_2)=b_1+b_2`$ がこの役割を果たす。
共有補正の方向 $`(1,1)`$ は値を変えず、候補辺の解禁による $`(0,1)`$ は値を変える。
障害、必要な観測、追加すべき修復方向を同じ入力から説明できる。
同じ表示の候補辺を解禁する場合には、§3.4の(F)・(T)によって全双対証拠を用い、
追加範囲が十分かどうかと、包含極小の成功範囲まで分類する。
その $`\lambda`$ の値を問い合わせから得るには、許された評価のspanで表せることを
別に確認する。代数的な証拠の存在だけで、原始観測による取得可能性を仮定しない。

### 6.4 既知の局所情報を条件とする追加観測

統合者が既に受け取った局所情報を $`\eta(X)`$ とする。これには、局所可解性の真偽、
具体的修復、生成したインターフェースなど、実際に利用可能な内容を含める。
$`\eta(X)=s`$ の下で残る入力族上の、各追加観測fiberで修復可否が一定となることが
観測十分性の条件である。

線形座標で既知情報が $`Lv=s`$ と表され、その全fiber $`F_s`$ が実現される場合を取る。
$`N=\ker L`$ とする。$`F_s\cap\mathsf R^{\mathrm{in}}_S=\varnothing`$ なら、存在判定は常に偽で
追加問い合わせは零回である。交わる場合は修復可能な $`w\in F_s\cap\mathsf R^{\mathrm{in}}_S`$ を選び、
$`v=w+n`$ と移すと、未知入力は $`n\in N`$、修復可能部分空間は
$`N\cap\mathsf R^{\mathrm{in}}_S`$ となる。これに(D)・(Q)を適用して

```math
D_{\mathrm{repair}}(S\mid Lv=s)
=\min\{|J|:N\cap\ker O_J\subseteq\mathsf R^{\mathrm{in}}_S\}
\qquad(F_s\cap\mathsf R^{\mathrm{in}}_S\ne\varnothing)
```

を得る。十分な $`J`$ がないときは無限大とする。既知情報が一般の非線形な内容なら、
fiber上の可否一定条件を用い、上の線形公式の適用条件を別に示す。

§5.2では、具体的な局所修復は $`h_U=b_1`$、$`h_V=b_2`$ である。
その両方、または $`u=b_i`$ という二つの生成済みインターフェースを受領すると、
両座標は既知になる。追加座標問い合わせの最悪時最適値は次のように変わる。

| 既知の局所情報 | 追加問い合わせ |
| --- | --- |
| 両側で修復可能という真偽だけ | 2回 |
| 一方の具体的修復 | 1回 |
| 両側の具体的修復、または両インターフェース | 0回 |

主定理の出力を受け取った後の観測問題は、この既知情報を含めて定める。
存在判定と具体的修復の出力に必要な情報は、§5.3と同様に区別する。

### 6.5 記号的表現からの観測計画と、判定・数値出力の最適値

§3.5の適用族で、表示・core・核輸送・補正の基底と構造行列を既知とする。
未知入力 $`v\in\mathsf V`$ を含む大域の実補正方程式を

```math
D_S h=b_0+Bv,\qquad q_S:C^2\longrightarrow\operatorname{coker}D_S
```

と生成する。$`D_S`$ の定義域は常時許容辺と $`S`$ の候補辺の補正値の空間であり、
禁止辺には零を補う。右辺は同じ実defectの負号付き座標である。
修復可能な入力は $`q_S(b_0+Bv)=0`$ を満たすものとなる。
(Obs)と主定理により、この写像と局所の記号的関係の合成は同じ実修復の存在判定を与える。

既知情報 $`Lv=s`$ の非空fiber $`F_s`$ の全入力が実操作として実現されるものとし、
$`N=\ker L`$ と置く。許された問い合わせは既知の有限集合 $`J_0`$ に属する
正確な線形評価 $`\lambda_j(v)`$ であり、元の操作に対する評価との一致を示す。
決定的な手続きが全入力に常に正答する際の、最悪時追加問い合わせ回数を数える。
問い合わせ以外の計算はこの回数に含めない。

二つの出力を区別する。判定は修復可否を返す。数値出力は、固定した核の基底で
具体的な補正値 $`h`$ を返すか、修復不能を返す。数値出力には、未知操作を後で評価する
プログラム式や追加問い合わせを含めない。
**定理（判定と数値補正の観測最適値）。** fiberに修復可能な入力があるとき、

```math
\begin{aligned}
D_{\mathrm{dec}}(S\mid Lv=s)
&=\min\{|J|:J\subseteq J_0,\ N\cap\ker O_J\subseteq\ker(q_SB)\},\\
D_{\mathrm{num}}(S\mid Lv=s)
&=\min\{|J|:J\subseteq J_0,\ N\cap\ker O_J\subseteq\ker B\}.
\end{aligned}
\tag{Q_{\mathrm{out}}}
```

十分な $`J`$ がない場合は無限大とする。fiberの全入力が修復不能なら、両出力とも
問い合わせ零回で修復不能を返せる。
一般の既知情報について、判定には§6.4の可否一定条件を使う。
数値出力の観測fiberには、全入力が不能、または全入力が可解で右辺 $`b_0+Bv`$ が一定という
条件を課す。(Q_out)の最適値は、ここで指定したアフィンfiberに適用する。

下限には修復可能な基準入力 $`v_*\in F_s`$ を取り、その入力で手続きが読む集合を $`J`$ とする。
$`n\in N\cap\ker O_J`$ に対する $`v_*+n`$ は、適応的な手続きでも同じ質問と答えの列をたどる。
判定が同じなら $`q_SB n=0`$ が必要である。
同じ数値補正 $`h`$ を返すなら、両入力の右辺が同じでなければならず、$`Bn=0`$ が必要となる。
後者は、もう一方の入力が不能になる場合も、同じ数値解を返せないことから従う。
上限には核包含を満たす固定集合を使う。判定用なら残存障害を、数値出力用なら右辺全体を
既知情報と観測値から決定でき、線形求解と実操作への復元で出力する。

したがってこのモデルでは、修復可能性の判断に必要な情報と、具体的な核補正値を指定する
ための情報を、同じ実方程式から比較できる。§5.3の0回と2回の差が後者の必要性を示す。
操作を参照する式の生成は別の出力言語であり、同節の $`e:=a`$、$`c:=b\circ a^{-1}`$ を
数値出力の下限と区別する。

実行の順序は、記号的表現の生成、既知情報と出力に応じた問い合わせ集合の選択、
必要値の取得、判定・復元とする。入力更新時にも、§3.5で再利用する構造と
既知のままの値を明示し、残る未知方向 $`N`$ に対して同じ最適値を適用する。

### 7.2 同じ対象を使うことの確認

主要な証明では、次の対応を各段階で追う。

- **固定部分**：cochainの零と、元の辺・頂点再同定が変化しないことを双方向に結ぶ。
- **変更範囲と基準**：候補辺の名前、基準実操作との一致、全 $`S`$ の零条件を消去後も保持する。
- **再同定**：共有部分で一致させる操作が、禁止辺で非零の補正を生まない条件を保持する。
- **全核**：選んだ可換部分群ではなく、明示した射影の全核が係数になることを示す。
- **輸送と3-cell**：実際の経路の順序と係数輸送から微分とcocycle条件を導く。
- **全修復**：生成した表現からの復元と、任意の実修復からの座標化を相互逆にする。
- **公開関係と局所保持**：(B)で内部自由度を求めずに済むことと、射の復元には元の再同定作用を使うことを示す。
- **同じ障害**：全核許容時には局所差の接続像と相対defectを、一般の $`S`$ では
  $`\mathsf O/\mathsf R_S`$ における残存障害と観測側の商を、同じ写像で対応させる。
- **全範囲の分類**：大域微分からの $`o,B_e`$ と局所表現の消去を比較し、全 $`S`$ の可否を反映する。
- **未知入力の実現**：問い合わせ下限に用いる識別不能な二入力を、元の操作表へ戻す。
- **既知情報**：局所修復やインターフェースが既に明らかにした入力値を、追加観測のモデルへ含める。
- **出力**：可否、具体的な核補正値、既存操作を参照する式を区別し、最適値の出力条件を保持する。
- **再利用**：構造とdefectの変化を分け、記号的生成・値の更新・全範囲の判定が交換することを示す。

既存構成の参照先は§9に集める。相対複体とdescentは§2、生成と復元は§3.1、
アフィン入力族は§5.1、観測との対応は§6の証明を用いる。

### 7.3 表示変更の適用条件と発展問題

具体的な表示変更として、§3.6は常時補正可能な内部辺の分割を扱う。
実分解から縮約・復元・自然同型を生成し、全 $`S`$ の修復、残存障害、候補名、
外部との合成を対応させる。§5.7はその実操作と再同定を具体化する。
他の表示変更についても、何を変更し、どの固定条件と候補を輸送するかを指定して比較する。

表示変更で、実入力・固定部分・核輸送・許容修復を比較できる場合、障害写像
$`\Phi:\Omega_{\mathrm{fine}}\to\Omega_{\mathrm{view}}`$ を構成する。
実入力から生じる障害類の集合を $`\mathcal O_{\mathrm{real}}`$ とすると、

```math
\ker\Phi\cap\mathcal O_{\mathrm{real}}\subseteq\{0\}
```

がその族での零性反映の条件になる。
障害の零性の反映に加えて、指定修復や全修復を戻すには、解のfiberと再同定の比較も構成する。
観測を比較する場合は、評価を $`\Phi`$ または生成元のcochain比較に沿って引き戻す。
変更範囲の分類を移す場合には候補辺の対応と各 $`S`$ の修復関手を比較し、
単一の障害類の零性反映から全範囲の保存を結論しない。

独立した意味論への接続は、有限変換・プロトコルを第一の適用族とし、
条件を満たす双方向モデル同期を第二の候補とする。
[n1015](n1015_aat_reconstruction_cs_correspondence_design.md)とG-124の
局所再構成を用いる際にも、固定部分、核補正、制限、頂点再同定との交換を追加で証明する。
各意味論からAAT入力を独立に作り、同じ主定理から元の修復へ戻すことを目標にする。

## 8. CS・ソフトウェア工学での意義

主定理は、分担した改修に対し、保持する実操作を明示したうえで、
各部分の内部修復を求めずに全ての許容変更範囲の統合可否を判断し、
選んだ統合案から各部分の実修復と選択肢を回復する方法を与える。
具体的な開発例を§5.9の週次ジョブ移行に置く。新ワーカーの曜日形式と既存通知の出力を
同時に保持するため、共有処理と利用側のどこを変更すればよいかを、全代替案とともに決める。
§5.1の有限アフィン変換族では、保持する可視条件が線形成分、全核が平行移動であり、
名前付き辺の解禁と実行可能な補正を直接対応させられる。

| 定理から得るもの | 開発上の判断 |
| --- | --- |
| 各 $`S`$ の残存障害 $`[o]\in\mathsf O/\mathsf R_S`$ | 公開部分を保持したまま、その範囲の補正で整合化できるか。全核許容時には相対 $`H^2`$ の零性とも対応する |
| 公開関係だけの(B)と、局所での全修復復元 | 内部解を統合者に渡さずに各範囲の可否を決め、選んだ境界解から各部分の補正と代替案を構成する |
| 極小修復範囲と双対証拠の対応 | 修復に十分な包含極小の辺集合を分類し、許可範囲では直せない理由を返す |
| 候補辺・基準・再同定を保つ置換 | 内部実装の変更後も、各変更範囲の統合判断と修復を引き継ぐ |
| 常時補正可能な内部辺の分割不変性 | 操作を二段へ分けた後も公開関係と不能証拠を再利用し、旧修復から全ての分割補正を復元する |
| 記号的生成と条件付きの判定・数値出力の最適値 | 受領済み情報と求める出力を明示し、元の操作の何を読む必要があるかを取得前に決める |
| defect更新に対する構造の再利用 | 行列の消去結果と復元手順を保持し、更新された値に必要な観測と右辺の更新を行う |
| holonomyから得る補正方向 | 同じ一箇所の変更でも、障害に効くものと打ち消されるものを区別する |
| groupoidを保つ合成 | 局所では同型な修復から生じる大域の選択肢と、許された自己同型を保持する |

AIによる改修へ接続する場合も、返す情報を具体化できる。
成功時には固定部分を保つ辺の補正と残る選択肢、失敗時には許容補正で不変な非零評価を返す。
全ての証拠支持を通じて、十分な追加変更範囲とその極小の選択肢を示せる。
候補生成はその範囲ごとの実修復へ戻し、禁止辺を変更する再同定を混入させない。

比較実験を行う場合は、同じ入力・固定部分・許容補正を用いた大域直接求解、内部変数消去、
増分求解を比較対象とする。比較する内容は、全変更範囲の可否と極小成功集合、
実修復の復元、局所結果の再利用、既知情報ごとの追加問い合わせ、不能証拠を操作へ戻せることとする。
入力値だけが変わる場合、内部構造が変わる場合、候補辺を解禁する場合を分け、
再利用する行列・section・核と、更新する右辺・比較写像を具体化する。
速度差を研究する場合に限り、入力取得と表現生成も含めた
費用モデルを別に定める。主定理の実効性は、有限データからの停止と出力の正確性で述べる。

AATとしての成果は、同じ操作と保存条件から、修復の存在、全選択肢、合成、観測、
全変更範囲の可否と包含極小の成功範囲を導き、異なる意味論にも同じ対応を使えることである。
主定理と接続定理は、修復側と観測側で同じ対象と写像を使い、
得られた解と不能証拠を元の実操作まで戻す。§5.8はこの対応を一つの有限変換網で与え、
§5.9は実在する曜日規約を使った設計例で、変更箇所と具体的な補正定数へ読み戻す。
