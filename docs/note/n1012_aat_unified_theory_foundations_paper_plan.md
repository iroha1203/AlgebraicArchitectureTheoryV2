# n1012: AAT統一理論の基礎論文構想 — Rising Seaとしての体系化

**Foundations of Algebraic Architecture Theory**

*A Rising Sea of Readings, Transport, and Comparison*

## 1. 目的と位置づけ

本ノートは、[研究の全体目標](../research_goal.md)が掲げるRising Seaを、AATの基礎論文の
構成へ移す。G-101〜G-119を起点に、[n1010の研究計画](n1010_aat_post_annapurna_conjectures_research_plan.md)の
S5（独立な実現と有限表示からの再構成）までを本論の収録目標とし、S6以降を展望に置く。
これは拘束力を持たない構想メモであり、研究の進展に応じて構成と収録範囲を見直す。

**新規性の中心は、ソフトウェアアーキテクチャの統一理論としてのAATにある。**
AtomとLawから対象・射・操作を構成し、診断、輸送、正規化、比較を共通の数学として展開する。
既存の圏論やコホモロジーには帰属を示し、AAT固有の構成と、それらを接続する定理を明らかにする。

Rising Seaは、異なるCSの問題をひとつの枠組みで扱えるところまで理論を育てる方法である。
同じ定義と定理が複数の問題に働き、問題間の関係も説明できることを本文で示す。
「AATにとってのTohoku」は、対象と基本構成の存在・普遍性・合成則を確立し、
後続の研究が依拠できる基礎を与えるという役割を表す。
読者が自身の問題を定式化して研究を進められることを、論文の到達像とする。

形式は200ページ級を想定した、定理と証明を中心とする長編の理論論文。
基本的な代数と圏論を知るCS・ソフトウェア工学の研究者が、AATの研究履歴を知らずに読めるようにする。
主要な定義と証明は本文で辿れ、標準数学の補足は原典へ案内する。長さは必要な内容から決める。

## 2. 研究問いと主結果

> 読み取りの変更は、AtomとLawから構成されるアーキテクチャの診断と構造にどう作用するか。
> 診断の保存、実現の比較、比較を保つ変更はどの条件で接続され、
> 表示からそれらを回復するには何が必要か。

問いは、保存（第1〜4章）、比較と変更（第5〜7章）、表示と再構成（第8章）に分ける。
主結果候補の骨格を以下に置く。正確な量化・仮定・証明は収録時に一次資料と照合する。

| 結果群 | 入力と条件 | 結論の形と後続での使用 |
| --- | --- | --- |
| 診断不変性 | Law評価、解像度変更、被覆とLaw由来係数に関する条件 | 障害類の比較が同型となる。第2章の診断を第3章で比較し、第7章の情報損失と対照する |
| 輸送 | 対象と正確な読み取り変更、幾何・診断を運ぶ条件 | 普遍性を満たす輸送が存在し、単位・合成と整合する。第4章から第5章の二経路を構成する |
| 生成比較と正規化 | 指定された生成比較とcoreの正規化 | 比較を可逆な対応と冪等因子へ分解する。第5〜6章で像と固定点を記述する |
| 比較を保つ変更 | 比較射と、底を固定する許容された端点の可逆変更 | 可換式を満たす変更を分類し、表示変更との整合と観測による識別の差を示す。第7章でCSの問題へ適用する |
| AATの再構成 | 独立に定めた表示圏・実現圏と表示関手 | 充満忠実性・冪等完備性・retract生成をAATの構成から証明し、実現と比較の圏を再構成する。第8章の到達目標とする |

章の展開は定義・補題・主定理・証明・系の依存関係に沿って組む。
一般命題の仮定をAATのどの構成から得るかを示し、存在や整合性を定義の入力へ埋め込まない。
診断不変性と輸送は共通の基礎から分かれる結果群であり、全体を一列の工程として扱わない。

## 3. CSとの対応と具体例

各セクションで、扱うCSの問いと数学的内容の関係を示す。適用には、
**既存の問題 → AATへの入力の構成 → 対応命題 → 共通定理の適用 → 元の問題への帰結**
を揃える。これは論証の要件であり、各節で同じ導入を繰り返す指定ではない。
対応命題は同値・含意・保存の向きを明示する。有限モデル内の対応と既存のCS意味論への対応を区別し、
後者では意味論の定義・出典と、それを結ぶ写像を与える。
CS側の整合性・互換性などの条件は、AATへの翻訳に先立って独立に定める。
例えば互換性を可換式として定義して終えるのでなく、元の互換性条件と可換式の対応を証明する。
その対応が主要な数学的仕事を担う場合は、主定理として本文で扱う。

例は三つの役割に分ける。

- **説明用の主例**：注文・請求・決済・台帳を持つ小さなシステム。入力データ、Law、許容変更、
  各章で追加する構造を先に揃え、整合性・解像度・輸送・変更を通して使う。
- **有限例・反例**：仮定を欠くと何が成立しないか、自然性や観測による識別がどこで失われるかを示す。
- **共通定理の再利用**：異なる入力構造を持つCSの問題へ同じ定理を適用し、共通性を示す。

再利用の最初の候補は、第7章の端点変更の分類である。二つの設計モデル間の対応と、
サービス・クライアント間の対応をそれぞれ比較射に取り、許容変更が底を固定する可逆変更として
表される条件を確認する。両者に同じ可換式と分類定理を使い、適用条件を満たす例では、
観測値の一致と比較の保存を分離する結果へ接続する。
共通化の成果として、再利用できた証明、共通に導かれた成立条件、または一方の問題から
他方へ移せる帰結を特定する。二つの例を同じ記号で書けることに加え、何が新たに分かるかを示す。
これらの入力と対応補題は主定理の照合と並行して構成し、成立を確かめて収録する。
計算可能性や実用上の効果を主張する場合は、対応するアルゴリズム・計算量解析・実験を用意する。

### 導入と前提

Introductionでは、モデル間の対応と変更を扱う具体的な問題から研究問いを導く。
貢献の各項目に主定理とCSとの対応命題への参照を付け、対象・主要な仮定・結論・証明の着想を予告する。
前提節では集合と圏の大きさ、合成順序、係数の規約、標準概念の参照先と記号一覧を置く。
個別の仮定は各定理の近くに、AAT固有の定義は第1章に、層やKaroubi完備化は必要になる章に置く。

導入の章間図では定義への依存と証明への依存を区別する。主な読書経路は、
診断不変性が前提節と第1〜3章、輸送と生成比較が第1・4〜6章、比較を保つ変更が第1・6〜7章。
幾何・診断を使う箇所は第2〜3章、生成比較を使う箇所は第4〜5章へ戻る。
第8章は第1・6・7章の構成を受け取る。必須箇所は主定理の依存を照合して確定する。

### 理論本体の接続

**第I部（第1〜2章）**では、`E_geom → E_core → B` の対象・射と保持するデータを定義し、
局所文脈、被覆、係数から診断へ進む。主例の金額整合性と局所補正を定式化し、
構造相・意味相、SAGAとの接点を示す。この対象と診断が後続の比較の入力になる。

**第II部（第3〜4章）**では、Law評価を保つ標準解像度からAtlasの診断不変性へ進み、
仮定の役割を反例で示す。輸送では基本構造・幾何・診断の整合を証明し、
名称や語彙の変更を合成する。第3章の表示可能性は第8章へ、第4章の輸送は第5章の二経路へつなぐ。

**第III部（第5〜6章）**では、モデル移送と部分モデルの取り出しを二経路として定式化し、
比較の存在・可逆性・診断保存を区別して調べる。生成比較を冪等正規化によって分析し、
固定点と像、片側吸収と自然性の関係を扱う。coreの正規化結果は `E_core` 上で述べる。
さらにS4の完全幾何への持ち上げと変更の反映・持ち上げの判定を本論で扱う。
端点、可逆比較、冪等因子の対応を入力と生成経路から構成し、成立条件または固定入力での反証を示す。

**第IV部（第7〜8章）**では、一般構成 `Arr(Kar(E))` にcoreの冪等像と完全幾何の比較を
それぞれ配置する。両段を結ぶ命題では投影と保持データを指定する。
端点変更の分類を§3の二つの問題へ適用し、診断を保存する情報と比較を保つ情報の関係を調べる。
S2の観測・正規化による比較情報の変化と、S3の対象・射の表示可能性を展開する。
第8章では、n1010 §6.1の一般再構成原理を証明した上で、S5の独立な表示圏・実現圏・表示関手を構成し、
その仮定を個別に放電する。対象だけでなく比較と変更、観測との整合まで接続することを目指す。
実現圏は表示関手の像や表示圏のKaroubi完備化と定義して済ませず、Atom・Law・operationの
データ条件から対象範囲を定める。底を固定する版では、底への投影との整合も別に証明する。

### 関連研究と結び

近接研究の選定は主定理の選定と並行して行う。Introductionで差分を予告し、
Related Workで対象・仮定・許容変更・保存する構造・結論を比較する。
候補分野は、多視点モデリング、アーキテクチャ不整合、抽象解釈、変換の意味保存、データ移送、
双方向変換、インターフェース理論、モデル駆動開発、圏論的仕様、層によるシステムの記述。
主結果ごとに最も近い結果を原典で確認し、既存の道具とAAT固有の構成・証明を区別する。
帰属は各章の初出にも記す。

結論では、保存、比較と変更、表示と再構成という研究問いに対し、本文が何を明らかにしたかを
主要な仮定とともに簡潔に述べる。共通の構成から得た数学的結果と、CSの問題への帰結を結びつけ、
本論の貢献をまとめる。その後にFurther Directionsとして、S6のdescent、局所的な変更の持ち上げと
既存の障害類に関する二種類のH¹への接続、Morita形を後続問題として提示する。
その先に、SHIGUREの幾何学的表現可能性を位置づける。
SFTやArchSigへの展開は、本文の構成から具体的な問いを述べられるものを選ぶ。

### 付録の分担

付録Aの対応表には、論文中の番号と命題、Lean宣言と公開ソース、形式化された対象・仮定・結論、
本文との対応、付録Cの検証資料への参照を載せる。複数宣言で支える命題はその組み合わせを示し、
未形式化の命題も明記する。G番号は役割を説明した補助列に置く。

主要定理の仮定・証明の筋道・CSとの対応補題は本文に残し、付録Bに補助的な証明と計算を置く。
付録Cでは固定版の証明ソース、Leanと依存ライブラリの版、対象ごとの手順と結果を記録する。
型検査と、本文の命題・仮定・証明依存関係との照合は別に示す。大きな資料は公開固定版へ参照を付ける。

### CS論文としての補強ポイント

収録案は、次の批判に対する具体的な証拠から評価する。

| 批判 | 本文で示すもの |
| --- | --- |
| CSの結論を定式化へ先に入れただけではないか | 独立したCS側の問題定義と、§3の対応命題の証明 |
| 共通の記号を使っただけではないか | 異なる二つの問題への同一定理の適用と、共通化によって得た証明・条件・帰結 |
| 一般数学の仮定を入力として要求しただけではないか | 各主結果で借りる一般命題と、Atom・Law・操作からその仮定を導くAAT固有の証明 |
| 再構成が定義だけで成立していないか | 表示とは独立した実現側の意味、射・操作の選択理由、表示関手の充満忠実性などの証明 |
| 理論に都合のよい例だけを選んでいないか | 操作・状態・非可逆な変更など、保存条件が自明でない問題と、その条件の実質を示す例・反例 |

最後の観点では、対象とする変更の種類に対応する定理を選ぶ。端点の可逆変更の分類と、
非可逆な比較・変更に関する結果の適用範囲を区別する。
執筆の初期に、独立した二つのCSの問題を同じ定理へ接続し、共通化の成果を一つ具体化する。
対応が成立しない場合は欠ける条件や写像を記録し、問題の改名で済ませず、必要な構成または適用先を見直す。
これを、本文にない問題へも進める基礎ができているかを判断する最初の材料とする。

執筆・文献確認・公開の手順は[論文作成ガイドライン](../paper/guideline.md)に従う。

## 6. 文体

SAGA論文と同様に、読みやすく、言い切れるところをしっかり言い切る文体を採る。
各段落は中心となる主張から始め、必要な定義・理由・帰結へつなぐ。
平明な言葉と一貫した記号を使い、専門用語は初出で説明する。

証明した内容は「構成する」「存在する」「保存する」と明確に述べる。
必要な仮定は命題の近くに置き、その条件の下で得られる結論を断定する。
予想や未解決の構成は、その状態を具体的に記す。

説明は、対象が何であり、何を構成し、何が分かるかを肯定形で進める。
「〜ではない」「〜を保証するものではない」といった防御的な否定は最小限にする。
否定は、反例・不可能性・不成立そのものが数学的内容である場合や、具体的な誤読を防ぐ必要が
ある箇所に絞り、根拠とともに述べる。

理論の意義は、定理間の接続とCSへの帰結から伝える。
読者への呼びかけや価値の反復説明を抑え、論証を読み進めることで可能性が見える文章にする。
