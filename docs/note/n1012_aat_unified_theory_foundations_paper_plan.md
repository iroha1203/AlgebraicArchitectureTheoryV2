# n1012: AAT統一理論の基礎論文構想 — Rising Seaとしての体系化

**Foundations of Algebraic Architecture Theory**

*A Rising Sea of Readings, Transport, and Comparison*

## 1. 目的と位置づけ

本ノートは、[研究の全体目標](../research_goal.md)が掲げるRising Seaを、AATの基礎論文の
構成へ移す。G-101〜G-119を起点に、[n1010の研究計画](n1010_aat_post_annapurna_conjectures_research_plan.md)の
S5（独立な実現と有限表示からの再構成）までを本論の収録目標とし、S6以降を展望に置く。
これは拘束力を持たない構想メモであり、研究の進展に応じて構成と収録範囲を見直す。

**貢献の中心に置くのは、AAT固有の構成から導かれる存在・不可能性・分類である。**
AtomとLawから対象・射・操作を構成し、診断、輸送、正規化、比較を共通の数学として展開する。
その構成によって、比較を保つ変更をどの情報で識別でき、どう持ち上げられ、どの自由度が残るかを
決定する。既存の圏論・群論・コホモロジーには帰属を示し、一般定理に必要な対象・写像・証拠を
AATの入力から作る部分と、異なるCSの問題へ結論を戻す部分を明らかにする。
新規性は、その具体的な構成と適用を含む定理単位で先行研究と比較して確定する。

Rising Seaは、異なるCSの問題に共通する構造から、その成立条件や解の分類を導けるまで
理論を育てる方法である。同じ定義と定理が複数の問題に働き、何が新しく分かったかを本文で示す。
「AATにとってのTohoku」は、対象と基本構成の存在・普遍性・合成則を確立し、
そこから個別の問題への新しい帰結を導くための基礎を与えるという役割を表す。
読者が自身の問題を定式化して研究を進められることを、論文の到達像とする。

形式は200ページ級を想定した、定理と証明を中心とする長編の理論論文。
基本的な代数と圏論を知るCS・ソフトウェア工学の研究者が、AATの研究履歴を知らずに読めるようにする。
主要な定義と証明は本文で辿れ、標準数学の補足は原典へ案内する。長さは必要な内容から決める。

## 2. 研究問いと主結果

> 同じ診断が得られることと、構造の比較や比較を保つ変更が成立することは、どう違うのか。
> 適合する変更をどう構成でき、その選択にはどの自由度があるのか。
> 何を保持すれば、その違いと分類まで含めて表示から回復できるのか。

この問いを、AtomとLawから構成される対象と読み取りの変更について定式化する。
前半の診断不変性から、読み取りや正規化によって失われる比較・変更の情報へ進む。
後半では、識別の限界、適合する変更の構成、その全選択肢の分類を同じ入力について示し、
最後にその区別と分類を保持する表示の条件を問う。

問いは、保存（第1〜4章）、比較と変更（第5〜7章）、表示と再構成（第8章）に分ける。
主結果候補の骨格を以下に置く。正確な量化・仮定・証明は収録時に一次資料と照合する。

| 結果群 | 入力と条件 | 結論の形と後続での使用 |
| --- | --- | --- |
| 診断不変性 | Law評価、解像度変更、被覆とLaw由来係数に関する条件 | 障害類の比較が同型となる。第2章の診断を第3章で比較し、第7章の情報損失と対照する |
| 輸送 | 対象と正確な読み取り変更、幾何・診断を運ぶ条件 | 普遍性を満たす輸送が存在し、単位・合成と整合する。第4章から第5章の二経路を構成する |
| 生成比較と正規化 | 指定された生成比較とcoreの正規化 | 比較を可逆な対応と冪等因子へ分解する。第5〜6章で像と固定点を記述する |
| 比較を保つ変更と情報損失 | 実生成比較、canonical正規化、元coreのadmissibility。全端点自己同型群と底を固定する部分群 | 正規化後の比較を保つ各変更に、適合・不適合な持ち上げが共存する。適合する持ち上げ全体を核の作用で分類し、第7章で§2.1の系へまとめ、対応を証明したCS入力へ適用する |
| AATの再構成 | 独立に定めた表示圏・実現圏と表示関手 | 充満忠実性・冪等完備性・retract生成をAATの構成から証明し、実現と比較の圏を再構成する。第7章の変更の区別・持ち上げ・分類を表示側で回復して第8章を閉じる |

章の展開は定義・補題・主定理・証明・系の依存関係に沿って組む。
一般命題の仮定をAATのどの構成から得るかを示し、存在や整合性を定義の入力へ埋め込まない。
診断不変性と輸送は共通の基礎から分かれる結果群であり、全体を一列の工程として扱わない。

### 2.1 第7章で取り出す系：同じ正規化結果を持つ適合・不適合な変更

以下は、G-122の既存成果を組み合わせて収録する系の候補と、その導出である。
系をまとめた新しいLean宣言は未形式化であり、収録時に§5の一次証拠との対応を揃える。

[G-122の共通入力とDのcanonical版](../../research/goals/G-122-aat-full-geometry-normalization.md)に従い、
`U,A,z,k,g_z` と元coreのcanonical admissibilityを固定する。
そこから生成される可逆比較 `c=barAlpha_z:X≅Y` とcanonical正規化関手 `N` を使う。
この系はcochainに依存しないcanonical版から導く。
元の端点自己同型対の群を `G=Aut(X)×Aut(Y)`、正規化後を `G'=Aut(NX)×Aut(NY)` とし、
関手による準同型を `r:G→G'` とする。`Γ≤G` と `Γ'≤G'` は、それぞれ `c` と `N(c)` を
保つ部分群である。G-122から、制限準同型 `r̄:Γ→Γ'` のsectionとambientな核の元

\[
 s:\Gamma'\longrightarrow\Gamma,\qquad \bar r\,s=1,
 \qquad t\in\ker r,\quad t\notin\Gamma
\]

を同じ入力から得る。`t` は元の比較を壊す端点変更対 `(τ,1)` で、底・係数への作用は両端で恒等である。

任意の `b∈Γ'` に対し、`h_good=s(b)`、`h_bad=t s(b)` と置くと、

\[
 r(h_{\mathrm{good}})=r(h_{\mathrm{bad}})=b,\qquad
 h_{\mathrm{good}}\in\Gamma,\quad h_{\mathrm{bad}}\notin\Gamma.
\]

最初の等式はsectionと `r(t)=1` による。もし `t s(b)∈Γ` なら、部分群の閉性から
`t=(t s(b))s(b)^{-1}∈Γ` となるので、最後の不所属も従う。
二つの持ち上げは底と係数への作用も一致する。底を固定する版は、`b` を底固定部分群に取り、
sectionの底保存と `t` の底恒等性から同じ構成を得る。

従って、正規化後の情報 `r(h)` だけから、全変更 `h∈G` について元の比較を保つかを
正確に判定することはできない。形式的には、`h∈Γ ⇔ P(r(h))` をすべての `h` で満たす
述語 `P:G'→Prop` は存在しない。別の診断 `d` へこの結論を移す際は、同じ変更の集合上で
`d=d'∘r` という因子化を証明し、その範囲で適用する。

一方、適合する持ち上げは `s(b)` から構成できる。`K=ker r̄` とすれば、

\[
 \{h\in\Gamma\mid r(h)=b\}=s(b)K
\]

であり、`K` の右作用は自由かつ推移的である。実際、任意の適合する持ち上げ `h` に対し
`s(b)^{-1}h∈K` がその一意な差を与える。
ここで作用する `K` と、`t` が属するambientな核 `ker r` を区別する。

この短い導出は一般群論を使う。AATの貢献として前面に出すのは、その入力となる
`r,s,t` を原始データ・輸送・完全幾何の構成から得て、**識別の限界、適合する変更の構成、
全選択肢の分類を同じ実生成比較について決定すること**である。

### 2.2 第8章で回復する情報

G-123が固定targetを満たすとき、第7章で得た変更の区別と分類を、パラメータ相対の
有限表示へ運ぶ。原始データから独立に定めた実現と表示の間で、対象・射・比較を回復し、
元の比較を保つ条件、section、二種類の核、各持ち上げのfiberを同じ対応で保存・反映する。
ここで再構成の入力は、必要な対象・operation・Law・幾何を保持した表示である。
正規化結果だけを入力として失われた区別を復元する主張とは、入力が異なる。

## 3. CSとの対応と具体例

各セクションで、扱うCSの問いと数学的内容の関係を示す。適用には、
**既存の問題 → AATへの入力の構成 → 対応命題 → 共通定理の適用 → 元の問題への帰結**
を揃える。これは論証の要件であり、各節で同じ導入を繰り返す指定ではない。
対応命題は同値・含意・保存の向きを明示する。有限モデル内の対応と既存のCS意味論への対応を区別し、
後者では意味論の定義・出典と、それを結ぶ写像を与える。
CS側の整合性・互換性などの条件は、AATへの翻訳に先立って独立に定める。
例えば互換性を可換式として定義して終えるのでなく、元の互換性条件と可換式の対応を証明する。
その対応が主要な数学的仕事を担う場合は、主定理として本文で扱う。

例は三つの役割に分ける。

- **説明用の主例**：注文・請求・決済・台帳を持つ小さなシステム。第I部で局所から全体への整合性、
  第II部で読み取りや粒度を変えた後の診断、第III部で移送と部分の取り出しの順序、
  第IV部で比較を保つ追随変更とその表示を問う。入力データ、Law、許容変更、追加構造を先に揃え、
  各段で残った問いが次の構成を必要とするように展開する。
- **有限例・反例**：仮定を欠くと何が成立しないか、自然性や観測による識別がどこで失われるかを示す。
- **共通定理の再利用**：異なる入力構造を持つCSの問題へ同じ定理を適用し、共通性を示す。

再利用の最初の候補は、第7章の端点変更の分類である。二つの設計モデル間の対応と、
サービス・クライアント間の対応をそれぞれ比較射に取り、許容変更が底を固定する可逆変更として
表される条件を確認する。両者に同じ可換式と分類定理を使い、適用条件を満たす例では、
観測値の一致と比較の保存を分離する結果へ接続する。
共通化の成果として、各問題でどの情報では変更の適合性を識別できないか、どの構造を保持すれば
適合する変更を構成・分類できるか、その結論のどの部分がAATの共通定理から得られたかを示す。
再利用できた証明、共通に導かれた成立条件、問題間で移せる帰結を、その具体的な証拠にする。
これらの入力と対応補題は主定理の照合と並行して構成し、成立を確かめて収録する。
§2.1の系は、CS側の独立した意味から該当するAAT入力・正規化・許容変更を構成し、
比較の保存との対応を証明できた入力族へ適用する。この接続と元の問題への帰結を、論文の数学的内容に含める。
計算可能性や実用上の効果を主張する場合は、対応するアルゴリズム・計算量解析・実験を用意する。

具体的な設計は、[n1015のモデル同期とプロトコルの対応](n1015_aat_reconstruction_cs_correspondence_design.md)
に置く。モデル同期ではgetとputの両方を保つ変更、プロトコルでは既存adapterと操作の実行を
保つ変更を扱う。操作を通じて結ばれる状態の間で補完データの変更が一致する条件を共用し、
追随変更の自由度を同じ核とfiberの分類から導く。有限補完を持つlensの再構成と、
操作tableから全実行経路への再構成を、その独立な意味と表示の具体案とする。
完全幾何とG-122の生成比較への接続は、[n1014の設計](n1014_aat_realization_reconstruction_design.md)で
別途具体化する。これらのCSの圏を完全幾何の実現圏と同一視せず、接続の証明を揃えて収録する。
S5の研究目標・要求命題・完了条件は
[G-123のGOALカード](../../research/goals/G-123-aat-realization-reconstruction.md) にまとめる。

### 導入と前提

Introductionでは、モデル間の対応と変更を扱う具体的な問題から研究問いを導く。
§2.1の適合・不適合な持ち上げとその分類を通じ、AATの構成によって決定できる問いを提示する。
貢献の各項目に主定理とCSとの対応命題への参照を付け、対象・主要な仮定・結論・証明の着想を予告する。
前提節では集合と圏の大きさ、合成順序、係数の規約、標準概念の参照先と記号一覧を置く。
個別の仮定は各定理の近くに、AAT固有の定義は第1章に、層やKaroubi完備化は必要になる章に置く。

導入の章間図では定義への依存と証明への依存を区別する。主な読書経路は、
診断不変性が前提節と第1〜3章、輸送と生成比較が第1・4〜6章、比較を保つ変更が第1・6〜7章。
幾何・診断を使う箇所は第2〜3章、生成比較を使う箇所は第4〜5章へ戻る。
第8章は第1・6・7章の構成を受け取る。必須箇所は主定理の依存を照合して確定する。

### 理論本体の接続

**第I部（第1〜2章）**では、`E_geom → E_core → B` の対象・射と保持するデータを定義し、
局所文脈、被覆、係数から診断へ進む。主例の金額整合性と局所補正を定式化し、
構造相・意味相、SAGAとの接点を示す。この対象と診断が後続の比較の入力になる。

**第II部（第3〜4章）**では、Law評価を保つ標準解像度からAtlasの診断不変性へ進み、
仮定の役割を反例で示す。輸送では基本構造・幾何・診断の整合を証明し、
名称や語彙の変更を合成する。第3章の表示可能性は第8章へ、第4章の輸送は第5章の二経路へつなぐ。

**第III部（第5〜6章）**では、モデル移送と部分モデルの取り出しを二経路として定式化し、
比較の存在・可逆性・診断保存を区別して調べる。生成比較を冪等正規化によって分析し、
固定点と像、片側吸収と自然性の関係を扱う。coreの正規化結果は `E_core` 上で述べる。
さらにS4の完全幾何への持ち上げと変更の反映・持ち上げの判定を本論で扱う。
端点、可逆比較、冪等因子の対応を入力と生成経路から構成し、成立条件または固定入力での反証を示す。

**第IV部（第7〜8章）**では、一般構成 `Arr(Kar(E))` にcoreの冪等像と完全幾何の比較を
それぞれ配置する。両段を結ぶ命題では投影と保持データを指定する。
端点変更の分類を§3の二つの問題へ適用し、診断を保存する情報と比較を保つ情報の関係を調べる。
S2の観測・正規化による比較情報の変化と、S3の対象・射の表示可能性を展開する。
第7章では、G-122の実生成比較に§2.1の系を適用し、同じ正規化後の変更の上にある
適合・不適合な持ち上げと、適合する持ち上げ全体の分類を一つの結果群にまとめる。
第8章では、n1010 §6.1の一般再構成原理を証明した上で、S5の独立な表示圏・実現圏・表示関手を構成し、
その仮定を個別に放電する。最後の主要な系として、第7章の比較を保つ変更の分類を
表示側から回復することを目指す。底を固定する条件、許容変更、観測との整合を証明し、
実現側と表示側で同じ分類に到達して章を閉じる。
実現圏は表示関手の像や表示圏のKaroubi完備化と定義して済ませず、Atom・Law・operationの
データ条件から対象範囲を定める。底を固定する版では、底への投影との整合も別に証明する。

### 関連研究と結び

近接研究の選定は主定理の選定と並行して行う。Introductionで差分を予告し、
Related Workで対象・仮定・許容変更・保存する構造・結論を比較する。
候補分野は、多視点モデリング、アーキテクチャ不整合、抽象解釈、変換の意味保存、データ移送、
双方向変換、インターフェース理論、モデル駆動開発、圏論的仕様、層によるシステムの記述。
主結果ごとに最も近い結果を原典で確認し、既存の道具とAAT固有の構成・証明を区別する。
帰属は各章の初出にも記す。

## 6. 文体

SAGA論文と同様に、読みやすく、言い切れるところをしっかり言い切る文体を採る。
各段落は中心となる主張から始め、必要な定義・理由・帰結へつなぐ。
平明な言葉と一貫した記号を使い、専門用語は初出で説明する。

証明した内容は「構成する」「存在する」「保存する」と明確に述べる。
必要な仮定は命題の近くに置き、その条件の下で得られる結論を断定する。
予想や未解決の構成は、その状態を具体的に記す。

説明は、対象が何であり、何を構成し、何が分かるかを肯定形で進める。
「〜ではない」「〜を保証するものではない」といった防御的な否定は最小限にする。
否定は、反例・不可能性・不成立そのものが数学的内容である場合や、具体的な誤読を防ぐ必要が
ある箇所に絞り、根拠とともに述べる。

理論の意義は、定理間の接続とCSへの帰結から伝える。
読者への呼びかけや価値の反復説明を抑え、論証を読み進めることで可能性が見える文章にする。
