# n1016: Rising Sea v2 構想 — 変更と修復の構造

[振り返り](../../outreach/paper/rising-sea/furikaeri.md)を起点に、Rising Sea v2の
中心となる問い、主定理の候補、章間の接続を整理する。
[n1012](n1012_aat_unified_theory_foundations_paper_plan.md)の基礎論文としての広がりを受け継ぎ、
変更と修復の構造から、診断・比較・再構成へ進む構想を置く。
以下の「第n章」はv1本文、「§n」はこのノートの節を指す。

## 1. 中心となる問いと、三つの研究軸

v1は、Atom・Lawから幾何を作り、貼り合わせ、診断、輸送、比較、再構成へ進む。
そこには、診断が同じでも変更の適合性は異なること、元の比較が非可逆でも
正規化の像の間には同型が残ること、全有限片から回復できても一つの有限片では
決まらないことが現れる。v2では、これらの違いを生む構造を詳しく調べる。

> 保つべきLaw・操作・観測を指定したとき、許される変更と修復の全体は、
> どのような構造をなすか。その構造から、存在・分類・不可能性・構成方法と、
> 判定・構成に必要な情報を、どこまで導けるか。

「何を保ちながら、どこまで変えられるか」を、変更と修復の全体を記述する問題として問う。
保存条件に加え、変更の種類、満たしたい関係、修復したい不一致を入力として指定する。
その入力から群・合同関係・複体などを構成し、存在条件、解全体の分類、障害を導く。
有限入力で判定・構成を行う場合には、入力の表示方法と計算の停止条件も定める。

この問いを、次の三つの研究軸に沿って具体化する。

| 研究軸 | 得たい結果 | 主な候補 |
| --- | --- | --- |
| 変更と修復の全体を記述する | いつ可能か、どのような選択肢があり、何が妨げるかを同じ構造から導く | 修復商の分類、holonomyと持ち上げ、Lawの微小変形（§2） |
| 比較に沿って選択肢と障害を追う | 表示・解像度・readingの変更が、分類と診断をどう保ち、何を失わせるかを記述する | 再構成と比較の整合、Atlasの欠損と合成、係数変更（§3〜4） |
| 判定と構成に必要な情報を定める | 適合性の判定、変更の区別、局所データの延長に必要な読取りを特徴づける | 有限決定性、最小観測数、障害を検出する閉路（§5） |

三つの軸を結ぶのは、同じ入力に対して構成した写像と、その保存・反映の性質である。
修復の存在を診断で判定するには、実際の障害類を比較写像で追う。
分類を局所表示から回復するには、対象・射に加え、群作用や持ち上げのfiberも対応させる。
これらの接続によって、別々の問題に同じ定理を適用できる形を目指す。

以下の追加結果は研究候補である。出発点の定理はv1本文に対応させ、候補ごとに
入力・仮定・新しい結論・例と反例を定める。持ち上げの存在、解全体の分類、
与えられた変更の適合性は区別し、再構成では非可逆な構造保存射も保持する。

## 2. 変更と修復の全体を記述する

主定理の候補を、合同関係、群作用、変形複体という三つの構造から具体化する。
それぞれについて、存在と選択肢の記述に、障害と構成方法を結びつける。

### 2.1 修復商を、操作合同関係の区間として分類する

出発点は[第3章](../../outreach/paper/rising-sea/ja/06-resolution-invariance.md)の
定理3.4である。Law評価を保つ標準解像度に、名前付き操作と同一視の要求を加える。

有限状態集合 $`S`$、有限個の全域操作 $`T_e:S\to S`$、保存すべき観測
$`o:S\to O`$、同一視したい状態対 $`R\subseteq S\times S`$ を固定する。
Lawの評価値も保存する場合は $`o`$ に含める。操作と観測は有限表で与え、
観測値の等号を判定できるものとする。二つの操作経路 $`p,q`$ を一致させる要求は、
$`R=\{(T_p(x),T_q(x))\mid x\in S\}`$ として表す。

操作合同関係とは、各 $`T_e`$ が保つ同値関係である。その全体を $`\operatorname{Con}_T(S)`$
とし、包含で順序づける。$`R`$ を含む最小の操作合同関係を $`\equiv_R`$ とする。
一方、空語を含むすべての操作語 $`w`$ について

```math
x\approx_o y
\quad\Longleftrightarrow\quad
\forall w,\quad o(T_w(x))=o(T_w(y))
```

と置く。目標は、$`\approx_o`$ を $`\ker o`$ に含まれる最大の操作合同関係と特徴づけ、
修復のために必要な同一視と、観測を保ったまま許される同一視を同じ順序で比べることである。

修復商は、操作と観測を降下させ、$`R`$ の各対を同一視する全射 $`q:S\to Q`$ とする。
主定理候補は、元の $`S`$ からの商写像と可換な同型までの修復商を、次の区間で分類する。

```math
\{\theta\in\operatorname{Con}_T(S)
  \mid \equiv_R\ \subseteq\theta\subseteq\ \approx_o\}.
```

対応は $`q\mapsto\ker q`$ と $`\theta\mapsto(S\to S/\theta)`$ から構成する。
商の間の因子化を合同関係の包含へ対応させ、次を一組の帰結として導くことを狙う。

- **存在**：修復商が存在することと、$`\equiv_R\subseteq\approx_o`$、
  $`\equiv_R\subseteq\ker o`$、$`R\subseteq\approx_o`$ が同値になる。
- **分類と普遍性**：存在する場合、$`S/{\equiv_R}`$ は必要な同一視だけを行う最も細かい修復商、
  $`S/{\approx_o}`$ は観測と操作を保つ最も粗い商となり、すべての修復商がその間に並ぶ。
  $`S/{\equiv_R}`$ は、$`R`$ を同一視する任意の操作・観測保存射を一意に因子化する。
- **不可能性**：存在しない場合、$`(x,y)\in R`$ と
  $`o(T_w(x))\ne o(T_w(y))`$ となる操作語 $`w`$ を具体的な証拠として返す。
- **有限構成**：合同関係の生成と観測による分割の細分化から両端を求め、
  積状態集合 $`S\times S`$ の到達可能性から失敗を示す操作列を求める。

同じ $`S,T,o`$ に対する複数の修復要求は、合同関係のjoinで合成する。
要求 $`R_i`$ が生成する合同関係を $`\theta_i`$ とすると、

```math
\equiv_{R_1\cup R_2}=\theta_1\vee\theta_2,\qquad
\theta_1,\theta_2\subseteq\approx_o
\ \Longrightarrow\ \theta_1\vee\theta_2\subseteq\approx_o.
```

したがって、個別に可能な要求を合わせても修復商を作れる。$`\bar R_2`$ を
$`S/\theta_1`$ における $`R_2`$ の像とすると、逐次修復
$`(S/\theta_1)/{\equiv_{\bar R_2}}`$ と一括修復 $`S/(\theta_1\vee\theta_2)`$
の間に、元の $`S`$ からの写像と可換な一意の同型を構成する。
有限個の要求について、順序と括弧づけを変える同型の整合まで求める。
代表の選択を伴う正規化については、§2.2で別に合成の可否を問う。

観測を有限Law族の評価に取ると、$`\approx_o`$ は、操作を繰り返してもLawを読める
最も粗い解像度の候補になる。現在のLaw値による分割から、各操作後の所属先が
異なる状態を分ける操作を反復し、安定した分割との一致と停止を証明する。

最初の例は $`S=\{a,b,c\}`$、$`o(a)=o(b)=0,\ o(c)=1`$、
$`T(a)=a,\ T(b)=T(c)=c`$ とする。現在の観測では同じ $`a,b`$ が一回の操作で
区別される。$`R=\{(a,b)\}`$ の修復要求と、将来の観測を保つ要求が両立しないことを示したい。
定値観測や、$`R\subseteq\approx_o`$ となる別の要求も置き、成立する場合と比較する。

この分類が最小化するのは、修復のために同一視する状態対である。
AATへの接続では、面のdefectから $`R`$ を作る方法、商とLaw・幾何の対応、
操作・観測を保つ写像に対する自然性を示す。第1章のAtom対応は全単射なので、
意味論内の商をAATへ運ぶ射の種類も明示する。

### 2.2 商の代表を選び、正規化へ戻す

構成5.40と[第6章](../../outreach/paper/rising-sea/ja/09-idempotent-normalization.md)の
定理6.16・命題6.31を出発点に、§2.1の商から元の状態上の正規化を作る条件を問う。

型付きの有限プロトコル $`X`$ へ広げる。defect族 $`\Delta`$ が自然な自己同型として
与えられる場合、$`(x,\delta(x))`$ を生成対に取る。商写像を $`q`$ とし、自然なsection $`s`$ を
選べれば、$`N=sq`$ が冪等で $`N\delta=N`$ を満たすことを示す。

最初の反例候補は、二状態を交換する一ループ、定値の観測、同じ交換をdefectとする
プロトコルである。一点への商は作れても、自然なsectionには交換の固定点が必要になる。
商を作ることと、その商の代表を操作に整合して元の状態から選ぶことの違いを示したい。

修復要求の合成に対しては、個別の自然な正規化が存在しても、一括した要求には
自然な正規化が存在しない例を置く。$`S=\{0,1,2,3\}`$、$`T=(01)(23)`$、
定値観測、$`R_1=\{(0,2)\}`$、$`R_2=\{(0,3)\}`$ とする。
次の表の $`N_1,N_2`$ は、それぞれの要求が生成する合同関係を核に持ち、
$`T`$ と可換な冪等写像になる。

| 状態 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| $`N_1`$ | 0 | 1 | 0 | 1 |
| $`N_2`$ | 0 | 1 | 1 | 0 |

二つの合同関係のjoinは全状態を同一視するため、一括修復商は一点になる。
その自然なsectionには $`T`$ の固定点が必要だが、この操作には固定点がない。
商の合成の普遍性と、元の状態から代表を選ぶ条件の違いを同じ入力で示す。

もう一つの問いは、すべてのdefectで固定される状態の部分プロトコル
$`X^\Delta`$ を残すretraction $`r:X\to X^\Delta`$ の存在である。
包含を $`i`$ とすると、$`ri=1`$ と操作・観測の保存を同時に要求する。
各頂点に固定状態があっても、生成辺の自然性を満たすretractionがあるかは別に調べる。
観測を定値とする例として、$`A=\{0,1,2\}`$ から $`B=\{b_0,b_1\}`$ へ
$`T(0)=b_0,\ T(1)=T(2)=b_1`$ と写し、$`A`$ で1と2を交換、$`B`$ で恒等とする。
固定状態をすべて残す要求と辺の自然性が衝突する反例候補になる。

商による同一視と、固定状態へのretractionは別の構成として比較する。
$`N=ir`$ に $`N\delta=\delta N=N`$ まで求める場合には $`r\delta=r`$ も課す。
第4章の面defectをこの意味論へ対応させ、表示変更に整合する選択、第7章の変更群、
第8章の有限表からの構成へ接続する。商をAAT側の射・Law・幾何へ運ぶ条件も定める。
完全幾何の全圏での普遍性を述べる場合は、その圏における因子化を別に構成する。

### 2.3 操作のholonomyから、変更群と持ち上げを分類する

出発点は[第7章](../../outreach/paper/rising-sea/ja/10-comparison-and-information.md)の
定理7.24・7.25と命題7.29である。各辺が隠れ状態を恒等に運ぶという仮定を、
有限fiber間の全単射へ広げる。有限有向グラフ $`Q`$ と経路関係 $`\Pi`$、
それを満たす有限集合値の実現 $`F`$ を固定する。追加の観測は定値とする。
各連結成分で根と全域木を選び、辺とその逆輸送からなる閉路の置換が生成する群を
$`\operatorname{Hol}_j(F)`$ とする。これは操作のholonomyである。

最初の定理候補は、底を固定する変更群を、閉路の作用と可換な置換から求める式である。

```math
\operatorname{Aut}_Q(F)\cong
\prod_j C_{\operatorname{Sym}(K_j)}(\operatorname{Hol}_j(F)).
```

ここで $`K_j`$ は根のfiber、$`C`$ は中心化群を表す。木の辺から他の頂点の変更を
決定し、残る辺の条件を中心化条件へ移す。根や木を変えたときの共役も対応させる。
次に、$`\Pi`$ が生成する経路同値を保つ群 $`H\le\operatorname{Aut}(Q)`$ を指定する。
底の変更で再添字づけた実現と、各閉路の作用を同時に共役で結べる条件から、
持ち上がる部分群 $`H_{\mathrm{lift}}\le H`$ を特定する。
底の変更とその持ち上げの対の群 $`A_F`$ について

```math
1\longrightarrow\operatorname{Aut}_Q(F)
\longrightarrow A_F\longrightarrow H_{\mathrm{lift}}\longrightarrow1
```

を構成する。持ち上げの存在、各fiberのtorsor、群準同型のsectionの存在を別々に問う。

最初の例には、二頂点の有向サイクルで、各fiberを二元集合、二辺の作用を恒等と交換に
するものを選ぶ。頂点と辺を同時に交換する底の変更を許すと、全状態は四状態のサイクルに
なる。経路関係は空とし、狙う例の結論は $`1\to C_2\to C_4\to C_2\to1`$ である。
可視の交換の持ち上げはいずれも位数4となるため、群準同型のsectionを選べない。
ここで各可視変更は持ち上がる。失敗するのは、可視側の二回で戻る関係を保つ
持ち上げの選択であり、同じ持ち上げを繰り返すと四回で戻る。

第4章には合成と整合する持ち上げの問題、第8章には有限操作表から群拡大まで回復する
問題として接続する。非可逆な辺には木に沿う逆輸送が使えないため、別の拡張として扱う。

### 2.4 持ち上げの整合を、可換核の二次障害で記述する

[第4章](../../outreach/paper/rising-sea/ja/07-transport-coherence.md)の定理4.23と
定理4.33・4.34を出発点に、再選択の存在をcochainで計算する条件を調べる。
最初はcore側の整合する選択を固定し、各辺の整列した幾何への持ち上げが存在し、
その核が可換で、exactな輸送が核を同型に運ぶ場合を扱う。

頂点・辺・面と、面の間の指定された関係を持つ有限複体を $`K`$ とする。
coreの選択と共役作用から核の局所係数 $`A_\rho`$ を構成し、面のdefectが
$`\delta\in Z^2(K;A_\rho)`$ を定めることを狙う。辺の核補正 $`a`$ による変化を
$`\delta+d_\rho a`$ と書ければ、同じcoreの選択が整合的に持ち上がる条件を
$`[\delta]=0\in H^2(K;A_\rho)`$ で表せる。

持ち上げがある場合には、補正の解全体を $`Z^1(K;A_\rho)`$ のtorsorとして記述し、
頂点での再同定も同一視した解を $`H^1(K;A_\rho)`$ のtorsorとして分類する。
ここでは核の局所係数、cocycle条件、採用した3-cellの関係を同じ入力から導くことが
主要な証明になる。全経路の整合へ進む場合には、指定した関係の十分性も示す。

最初の例には§2.3の $`C_4\to C_2`$ と関係 $`e^2=1`$ を使う。
coreで非自明な $`C_2`$ の元を選ぶと、どちらの持ち上げも二乗に非零の核成分を残す。
核の辺補正でこのdefectを消せないことを、二次障害の計算として表したい。
第2章の一次の貼り合わせ障害、第7章の群拡大、第8章の有限な関係の読取りが接続する。

中心列を持つ核では、その列に沿う段階的な持ち上げを検討する。その際、後段の障害は前段で
選んだ解に依存するものとして構成し、各段の存在条件と選択肢を保持する。

### 2.5 Lawの微小変形から、修復係数と障害を導く

[第2章](../../outreach/paper/rising-sea/ja/05-law-geometry.md)の構成2.6・定理2.9は
Lawの代数幾何的な実現を扱い、定理2.22は修復係数によるtorsorと層条件から
貼り合わせの障害を作る。この間を、方程式から修復係数を導く構成で結びたい。

体 $`k`$ を固定し、有限被覆上に多項式座標と有限Law、および一つのlawfulな状態を取る。
核 $`M`$ が $`M^2=0`$ を満たす全射の $`k`$-代数準同型 $`A'\to A`$ に沿う持ち上げを問う。
方程式を課す前の状態空間は局所的に滑らかで、Lawイデアルは局所的に正則列で生成され、
座標と方程式の制限が整合する場合から始める。

LawのJacobianから、$`M`$ に値を持つ微小補正と微小残差の層の写像
$`J:T^0\to T^1`$ を構成する。局所的な座標の持ち上げから、重なりでのずれ
$`g`$ とLaw残差 $`r`$ を取り出す。狙う命題は、$`(g,r)`$ が指定被覆のČech複体と
$`T^0\to T^1`$ の総複体に次数1の類を定め、その零性がlawfulな大域的持ち上げの
存在と同値になることである。存在する場合の持ち上げ全体を、総複体の
$`H^0`$ のtorsorとして記述することも問う。局所的なlawful liftがある場合には、差の係数を
$`\ker J`$ として定理2.22型の障害へ戻す。

最初の例は、一つのchartで $`x^2=0`$ を課し、$`k[\epsilon]/(\epsilon^2)`$ の
状態 $`x=\epsilon`$ を $`k[\epsilon]/(\epsilon^3)`$ へ持ち上げる問題とする。
候補 $`x'=\epsilon+a\epsilon^2`$ には二乗の残差 $`\epsilon^2`$ が残る。
閉路による貼り合わせの障害がなくても、局所のLaw残差が持ち上げを妨げる例を狙う。
証明は平方零Taylor展開と重なりでの適合式から始め、方程式の表示変更との整合へ進む。
一般のイデアルでは、方程式の間の関係も保持する必要がある。

二つの変更の干渉を調べる例には、原点でLaw $`xy=0`$ を課す。
$`k[\epsilon]/(\epsilon^2)`$ 上では任意の $`a,b\in k`$ に対して
$`(x,y)=(a\epsilon,b\epsilon)`$ がLawを満たす。
$`k[\epsilon]/(\epsilon^3)`$ 上の持ち上げを
$`x'=a\epsilon+u\epsilon^2`$、$`y'=b\epsilon+v\epsilon^2`$ と置くと、
残差は $`ab\epsilon^2`$ であり、持ち上げの条件は $`ab=0`$ になる。
各軸に沿う変更は延長できても、その和は延長できない場合がある。
$`x^2=0`$ の例に加え、被約なLaw空間でも二つの変更が二次で干渉することを示す。
まず方程式からこの二次残差を計算し、一般の変形類どうしの積として表す際には、
積を誘導する追加構造と表示独立性を構成する。

診断との接続では、定理3.37にならい、同じ変更から作る診断と変形のデータを追う。
修復係数からLawの微小補正への対応を構成し、診断のcochainと変形複体の間で
どの向きに比較写像を作れるか、その係数と次数を定める。指定した変更の障害類が
対応し、零性を保存・反映する部分クラスを求めることが目標である。
一次変形を分類する次数と高次への持ち上げを妨げる次数を、それぞれ比較する。

### 2.6 線形プロトコルの実現を、係数代数にわたる族として扱う

具体的な実現の族として、有限グラフ、有限個の経路関係、各頂点の階数を固定する。
可換 $`k`$-代数上の有限自由加群を状態、行列を辺作用とする線形プロトコルを、
有限集合値のプロトコルとは独立に定める。経路関係と観測保存の多項式から、
基底を固定した実現関手を表すアフィン概形を構成する。さらに、頂点の基底変更、辺の
行列変化、関係式の微分から変形複体を作る。ループに $`A^2=0`$ を課す例で、
$`A=\epsilon B`$ の二次への延長に $`B^2=0`$ が必要となる現象を調べる。
高次の持ち上げには関係式の間の関係も含め、変形複体の表示独立性を問う。
同型と自己同型を保った実現のgroupoidとAAT入力への対応を構成し、
第1・2・7・8章とSHIGUREの実現の族へ接続する。

辺が可逆な連結プロトコルでは、経路関係と逆輸送から得る基本群の表現として、
有限集合値の実現と線形実現を比較できる。辺の可逆性を課さない線形実現は、
経路圏とその関係式の表現として扱う。どちらの場合も、実現の同型類と自己同型群を分けて保つ。

さらに、頂点の基底変換群が作用する実現空間から、実現の族と自己同型を保つ
商stackを構成する候補がある。その族では、局所自由加群と基底の貼り合わせを許す
範囲を定める。非可逆な構造保存射を含む圏は別に保持する。
一つの有限次元モデルを固定し、実現空間、微小自己同型、一次変形、高次への持ち上げ
障害まで同じ入力から計算することを、最初のまとまった成果としたい。

## 3. 局所表示から、変更の分類と比較を回復する

§2の意味論をAAT入力へ対応させた上で、変更と修復を局所表示でも扱う。
そのために、対象・射の再構成に、分類を支える群作用・正規化・比較の整合を加える。

### 3.1 主同値に、保持する構造を対応させる

v1の定理8.18は、Atomの集合と射の方式を固定した入力 $`\Theta`$ に対し、
完全幾何の圏と、原始データから独立に定めた局所モデルの圏の同値を与える。

```math
N_\Theta:\mathcal R_\Theta\simeq\mathcal M_\Theta.
```

この同値を、表示の変更をまたいで構造を対応させる中心候補に置く。
底・観測・係数への射影、正規化、比較を局所モデル側にも構成し、読取り・組立てと
交換することを証明したい。局所側の構成は、その原始データから定義する。
同値で運んだものと、この独立な構成との一致が接続定理の内容になる。

調べる対応は、次の二段である。

1. 圏同値に沿って対象・射・同型・比較群を運ぶ一般的な構成。
2. AATの射影、生成比較、正規化、指定されたsectionについて、その構成が
   原始データから作ったものと一致すること。

二段目によって、第6〜7章の具体的な分類を第8章の再構成へ接続する。
第2〜3章の障害と診断については、係数・複体・比較写像との整合を別に構成する。
章ごとに必要な構造を明示することで、主同値から何が導かれるかを精密にする。

### 3.2 比較を保つ変更の分類を回復する

比較 $`c:X\to Y`$ を保つ端点自己同型対の群を $`\Gamma_c`$ と書く。
回復したいものは、$`\Gamma_c`$ と $`\Gamma_{N_\Theta(c)}`$ の同型に加え、
次の構造の整合である。

- 端点自己同型への評価と、底を固定する部分群、指定された許容部分群。
- 正規化前後の制限準同型と、その指定されたsection。
- 制限準同型の核、変更全体の観測準同型の核、各持ち上げのfiber。
- 冪等完備化と射の圏への延長、および比較平方。

たとえば、正規化後には同じ変更となる二つの持ち上げについて、片方だけが元の
比較を保つという第7章の区別を、局所表示からも判定したい。
適合する持ち上げ全体に作用する核と、比較を壊す変更も含む観測の核を区別したまま運ぶ。

この問いは、[G-124のC](../../research/goals/G-124-aat-local-semantic-reconstruction.md)
とv1結論の「再構成と比較群の整合」に対応する。既存の固定された証明対象を用い、
変更の判定と分類を局所表示から回復する問題として扱う。

### 3.3 診断・輸送まで接続を広げる

Atlasの比較を構成するには、局所モデルから解像度、被覆、係数、cochain写像を
取り出す必要がある。これらを揃え、完全幾何側で作った診断比較との可換図式を狙う。
比較写像の核・余核、その零性まで対応すれば、再構成と診断不変性がつながる。

さらに、一つの解像度変更と一つのreading変更を固定し、二経路で作る複体と
比較写像を調べる。第4〜5章の輸送・基底変換の仮定に、診断側のどの仮定を
加えると経路が整合するかを問う。この接続は独立した研究候補とし、最初に
一つの平方について構成と反例候補を確定する。

## 4. 診断を保つ比較と、失われる情報を記述する

変更や修復の障害を診断で読むとき、解像度と係数の選択が判定にどう影響するかを問う。
Atlasの発展候補は、[n1006](n1006_aat_atlas_reinforcement_plan.md)の
R14・R8・R10・R15・R3を中心に選ぶ。
出発点はv1第3章の有理係数の比較であり、対象・射・係数を広げる場合は、
どの構成と結論が変わるかを候補ごとに定める。

### 4.1 数値の背後にある対象と合成

値の部分集合 $`A`$ に対応する一次コホモロジーの比較を $`T_A`$ とすると、
v1の欠損は

```math
J_A=(\dim\ker T_A,\ \dim\operatorname{coker}T_A)
```

である。R14では、cochain水準の比較 $`u_A`$ の写像錐 $`D_A=\operatorname{Cone}(u_A)`$
を用い、Lawごとの比較と領域ごとの比較を同じ構成で記述する案を検討する。
錐の長完全列には他次数も現れるため、$`J_A`$ と錐のコホモロジーの次元との
対応を明示する。

$`T_A`$ を粗い側から細かい側への診断比較とすると、核は細かい側で消える
粗い側の類、余核は粗い側から届かない細かい側の診断方向を表す。
細かい側を参照とし、診断類と実際の修復障害の対応を固定した場合に、これらを
過剰な検出と見逃しの構造として読む。次元は診断空間の自由度であり、実践側での
偽陽性・偽陰性の件数や率との対応には、入力事例と正解判定を別に定める。

最初に狙う結果は、三段の解像度の比較で、後段の核から前段の余核への写像を
特定し、合成後の欠損を説明することである。中間段で現れた類が最終比較では
消える例を、各段の写像と同じ入力から構成したい。

台から作る有限半束 $`\Sigma_M`$ についても、Lawによる多数の比較をまとめる
添字として検討する。何を同一視する商かを明示し、比較に使うセル構造を保存する
普遍性と、診断の零性だけを判定するための情報の十分性をそれぞれ問う。

### 4.2 欠損の発生源と局所分解

R8では、比較を、粗い側の係数と細かい側の順像係数を結ぶ写像、およびfiberの
コホモロジーに関わる写像へ分解する案を調べる。
得たいのは、核・余核への寄与を係数の差とfiberの構造から説明し、
診断不変性に必要な条件を取り出す定理である。

先に確かめる問いは、許容する部分写像・退化したセルの下で、その順像と比較複体を
構成できるか、想定する完全列が成立するかである。その上で、transgressionが
消える条件と非零になる例を調べる。fiberの非輪状性に関する必要条件C3′も、
その条件とともに固定する。

標準的な写像錐や完全列を使い、Atlas固有の比較データから各項を構成し、
どの診断の変化に対応するかを示すことが、この候補の数学的な内容になる。

### 4.3 診断を保つ解像度の選び方

R10では、細かい解像度と許容する粗化の規則を固定し、すべての対象Law族に対する
診断不変性を保つ粗化の集合を調べる。問いを次の三つに分ける。

1. 診断を保つ最粗の解像度は存在するか。これ以上粗くできない解像度は、互いに比較できないものとしてどれだけあるか。
2. 共通粗化・共通精細化に沿って診断不変性は保たれるか。
3. 自己同型に対して自然に、一つの極大の粗化を選べるか。

n1006の環状の有限例を候補にし、診断を保つ二つの粗化から作る共通粗化で欠損が生じるか、
自己同型の作用が選択を妨げるかを確認する。非一意性、閉性の不成立、自然な
選択の不可能性は、それぞれの結論に必要な例と証明を用意する。

§2.1では、同じ操作と観測の下で修復合同関係がjoinについて閉じ、最も粗い商もある。
これと診断保存を比較するには、状態の同一視からnerve・台・係数・比較写像を作る規則を
固定する。合同関係のjoinが操作を保つことから、その規則で得る診断の保存は直ちには従わない。
共通粗化で閉路や面の関係が変わる例を調べ、最粗元の不存在を述べる場合には、
候補となるすべての共通上界を同じ粗化規則の下で排除する。

この結果が得られれば、「どこまでまとめて読めるか」に対して、許される選択肢の
構造を答えられる。実践側では、その選択肢と読取り費用を組み合わせることになる。

### 4.4 領域の貼り合わせと有限な視野

R15では、二つの領域での比較を、それらの合併での比較へつなぐ
Mayer–Vietoris型の図式を狙う。各領域では欠損が零でも、合併では非零になる
候補例を使い、交差部分のどの写像がその違いを生むかを特定したい。

R3では、読取りの半径と、一度に扱う対象の幅を独立の制約として固定する。
指定された有限の視野では一致しながら、一様不変性が異なる入力族を探す。
領域の貼り合わせによる正の計算方法と、制約された視野では決まらない例を
組にすることで、十分な読取りの条件を具体化する。

### 4.5 辺の持ち上げの一意性から、局所的な面の関係へ

定理3.17の条件CにあるC5は、coarse辺へ写るfine辺が高々一つであることを要求する。
例3.25には、平行な持ち上げを面の関係で結ぶことで、C5を満たさなくても一様不変性が
成立する例がある。この現象を、局所的な細分化に使える構成定理へ進める。

最初の候補は、同じcoarse辺へ写る二辺 $`e_1,e_2`$ の始点を、縮約されるfiber内の
辺 $`c`$ でそろえ、三角形 $`f`$ に $`\partial f=c+e_2-e_1`$ を課す比較である。
fiber内の補正で $`z(c)=0`$ にしたcocycleは、この面の関係から二つの持ち上げに
同じ値を持つ。どのラベルについても必要な台と面が存在する条件を揃え、持ち上げの
選択に依存せずcoarse側へ読み戻せることを狙う。

この比較では、fine面はcoarse辺へ退化する。定義3.13の、縮約する面の全辺を
縮約する規則を広げる。セル写像をchainへ線形に延長し、$`r_2(f)=0`$ でも
$`r_1(\partial f)=0`$ となるchain写像を構成する必要がある。
セルの写像と台・係数の写像を対応させ、診断のcochain写像を作る。

得たい結果は、指定された基本細分化ごとにchain写像、逆向きの写像、鎖ホモトピーを
構成し、その合成で診断不変性を保証する定理である。鎖ホモトピー同値まで成り立つ
変形と、一次診断だけを保つ変形は区別する。試験例には非零の閉路を残したまま
上の三角形を加える比較と、その面を除く比較を取り、追加の一次自由度を面が消す
仕組みを調べる。R8の局所分解とR14の合成則へ接続する。

### 4.6 有限位数の修復障害を検出する

[第2章](../../outreach/paper/rising-sea/ja/05-law-geometry.md)の定義2.35・補題2.36の
係数 $`M_R`$ は自由アーベル群だが、意味的修復を扱う例2.51には
$`\mathbb Z/2`$ の非零障害がある。有理化で失われる障害を、整数と有限環の診断へ接続する。

有限被覆上の有限表示アーベル群の係数を取り、その生成子・関係・制限写像と、
意味的修復との比較から複体 $`C`$ を作る。
狙うのは、有理数と適切な有限環の診断を組み合わせ、$`[o]\in H^1(C)`$ の零性を
反映する構成である。$`H^1(C)`$ のねじれ部分を消す整数 $`m`$ を持つ場合の
有理化と $`m`$ による剰余を出発点とし、cochainから自然な比較写像を作る。
次数ごとの係数にねじれがあれば自由分解を用い、係数変更に伴う他次数の項も調べる。
最初の例には例2.51と、円周を一周する輸送が $`-1`$ の整数局所係数を選ぶ。
後者では $`\mathbb Z\xrightarrow{-2}\mathbb Z`$ への比較を構成し、
各fiberが自由でも一次コホモロジーにねじれが生じるかを確かめる。

有限自由整数複体については、有理化で消える一次の類をねじれ部分として特定し、
零性の反映を $`\operatorname{im}d^0`$ が $`\ker d^1`$ の中で飽和する条件に結ぶ。
ここで飽和とは、$`z\in\ker d^1`$ と正整数 $`n`$ について
$`nz\in\operatorname{im}d^0`$ なら $`z\in\operatorname{im}d^0`$ となることである。
Smith標準形から、零の場合には整数の補正、非零の場合には残る障害の有限表示を
返す構成を問う。ラベルの欠落など、係数比較自体による情報損失は別に判定する。

### 4.7 すべての定数係数で診断を保つ条件を求める

次に、与えられた解像度比較が、すべての定数アーベル係数で一次診断を保つ条件を問う。
[第3章](../../outreach/paper/rising-sea/ja/06-resolution-invariance.md)の
有限2-nerveと許容するcell比較から、各Law値の部分集合に対応する整数chain写像を作る。
通常のcellのincidenceを持つ範囲で、任意のアーベル群 $`M`$ に対する
$`H^1(-;M)`$ の比較の同型性を、整数 $`H_1`$ 上の比較写像の同型性で特徴づけたい。
証明では $`H_0`$ の自由性を使い、Law族への一様性を定理3.22に接続する。

試験例には、二辺のサイクルを一つのループへ次数2で写す比較を選ぶ。有理係数では
同型、整数係数では非全射、$`\mathbb Z/2`$ 係数では零写像になる挙動を、許容される
cell比較から示す。群の抽象的な同型型に加え、与えられた写像の核・余核を計算する。
§4.6で作る修復係数の診断と、この定数係数による判定の対応も構成する。

### 4.8 指定された補正を比較の前へ持ち上げる

定理3.40は、有理診断が零なら元の整数補正を構成できることを示す。
その構成を土台に、診断側で選んだ補正そのものを元の側へ戻す条件と、戻し方の全体を問う。
非負次数のアーベル群のcochain複体 $`C,D`$、比較 $`\phi:C\to D`$、
障害cocycle $`z\in Z^1(C)`$、$`d_Db=\phi^1z`$ を満たす指定補正 $`b\in D^0`$ を取る。
求める集合は

```math
\operatorname{Lift}_\phi(z,b)
=\{a\in C^0\mid d_Ca=z,\ \phi^0a=b\}.
```

写像錐の規約を $`\operatorname{Cone}(\phi)^n=D^n\oplus C^{n+1}`$、
$`d(b,c)=(d_Db+\phi c,-d_Cc)`$ とする。$`(b,-z)`$ は次数0のcocycleであり、
その類の零性と $`\operatorname{Lift}_\phi(z,b)`$ の非空性を同値にする。
この判定には $`\operatorname{Cone}(\phi)^{-1}=C^0`$ を保持する。
$`d(0,a)=(\phi^0a,-d_Ca)`$ が、指定補正との一致と修復条件を同時に表す。

元の側の補正 $`a_0`$ が一つある場合、
$`k_\phi:Z^0(C)\to Z^0(D)`$ を誘導写像とし、
$`[b-\phi^0a_0]\in\operatorname{coker}k_\phi`$ を持ち上げ障害とする。
この類は $`a_0`$ によらず、零なら持ち上げ全体は $`\ker k_\phi`$ のtorsorになる。
すべての診断側補正が持ち上がる条件は $`k_\phi`$ の全射性、
存在する持ち上げが一意となる条件は単射性として記述する。

最初の例は、一辺に対する差分複体
$`C=(\mathbb{Z}^2\xrightarrow{(u,v)\mapsto v-u}\mathbb{Z})`$ の有理化とする。
$`z=1`$、$`b=(1/2,3/2)`$ に対し、補題3.39は整数補正 $`a_0=(0,1)`$ を与える。
指定された $`b`$ の持ち上げ障害は $`[1/2]\in\mathbb{Q}/\mathbb{Z}`$ であり非零になる。
同じ差を修復できることと、指定された補正をそのまま実現できることを区別する例である。
G-125の実比較、候補07の写像錐、候補16・17の比較へ、この解集合の構成を接続する。

### 4.9 係数の族に沿う診断の跳躍

後続の候補として、係数や辺作用を動かしたときに診断の自由度が変わる場所を求める。
有限表示の可換 $`k`$-代数 $`R`$ 上で、同じLaw・制限式から有限自由複体
$`C_R^0\xrightarrow{d^0}C_R^1\xrightarrow{d^1}C_R^2`$ を作る。
点 $`s\in\operatorname{Spec}R`$ における剰余体を $`\kappa(s)`$ とすると、

```math
\beta_1(s)=\dim_{\kappa(s)}H^1(C_R\otimes_R\kappa(s))
=\operatorname{rank}_R C_R^1
 -\operatorname{rank}d^0_s-\operatorname{rank}d^1_s.
```

狙うのは、$`\beta_1(s)\ge r`$ となる閉集合を、行列
$`\operatorname{diag}(d^0,d^1)`$ の小行列式で構成することである。
これは有限自由複体のfiberのコホモロジーを扱う標準結果
（[Stacks Project, Lemma 36.31.1](https://stacks.math.columbia.edu/tag/0BDH)）を、
実際の診断入力から生成した複体へ適用する課題となる。
複体を特殊化してからコホモロジーを取り、$`H^1(C_R)`$ 自体の特殊化との一致には
必要な係数変更条件を別に示す。

例には $`R=k[t,t^{-1}]`$、$`C_R=(R\xrightarrow{t-1}R)`$ を取り、
可逆な一ループの辺作用を $`t`$ 倍とする。一次診断は $`t=1`$ でのみ一次元になる。
候補15の線形実現の族から、この型の診断複体を作ることを最初の接続とする。
比較の核・余核へ広げる場合は、誘導写像が族として構成できる階数一定の部分ごとに扱う。

## 5. 判定と構成に必要な情報を定める

### 5.1 読取りの十分性、区別、延長

読取りの十分性は、何を決めたいかによって異なる。v1の三つの出発点を対応させる。

| 読み取るもの | 問うこと | 主な出発点 |
| --- | --- | --- |
| Law値の部分集合に対応する比較 | 全対象Law族に対する診断不変性が決まるか | 定理3.22・命題3.23 |
| 変更の観測値 | 比較を保つ変更かどうかが決まるか | 定理7.9 |
| 局所的な射の表 | 全体の射・変更が区別され、整合する表が延長できるか | 命題8.26・8.28・8.33 |

共通化したいのは、指定した読取りが、指定した問いに答えるために十分かという
定式化である。対象の全情報が回復される場合と、一つの判定だけが回復される場合を
分けて扱う。たとえば定理7.9の核の包含は適合性の判定条件であり、観測の単射性を
要求していない。

対象とする射・変更の有限決定には、[G-124のD・E](../../research/goals/G-124-aat-local-semantic-reconstruction.md)
にある、区別・延長・実効性の定義を用いる。

- **区別**：選んだ局所読取りで、対象とする射・変更を区別できる。
- **延長**：局所整合条件を満たすデータを、全体の射・変更へ延長できる。
- **実効性**：列挙と等号判定を持つ有限入力から、整合判定と延長を計算できる。

計算費用は、これらに加えて入力サイズと処理を定めて評価する。
有限個の成分を読むことと、各成分を有限のデータで記述することも分ける。

最初の共通例には、各辺が隠れ状態を恒等に運ぶ操作系を用いる。
そこで連結成分と読取り頂点の配置から区別・延長を判定し、lensの基準fiber、
プロトコルの生成表、独立なタグ変更へ接続する。
隠れ状態を非自明に運ぶ操作系への拡張では、経路に沿う輸送とその整合を改めて問う。

第3章との接続では、比較データのどの部分を読めば欠損の零性を判断できるかを
同様に定式化する。ここでは、診断の対象を選ぶ集合、局所表示の添字集合、
解像度の粗化という三つの選択を区別し、それらを結ぶ写像を構成する。

### 5.2 適合性を判定する最小観測数

変更の群 $`G`$、適合する変更の部分群 $`\Gamma\le G`$、観測可能なテスト点の
集合 $`X`$ と $`G`$ の作用を固定する。有限集合 $`B\subseteq X`$ に対して

```math
O_B(g)=(g\cdot x)_{x\in B},\qquad
G_{(B)}=\{g\in G\mid \forall x\in B,\ g\cdot x=x\}
```

と置く。最初の命題候補は、$`O_B(g)`$ だけで $`g\in\Gamma`$ を判定できることと
$`G_{(B)}\subseteq\Gamma`$ の同値である。観測の一致を
$`h^{-1}g\in G_{(B)}`$ に帰着させて示す。$`O_B`$ は群準同型を仮定しないため、
定理7.9の原理を、点上で読む観測へ具体化する問題になる。

この条件を満たす最小の点数を

```math
b_\Gamma(G\curvearrowright X)
=\min\{|B|\mid B\subseteq X\text{ は有限},\ G_{(B)}\subseteq\Gamma\}
```

と定め、該当する有限集合がない場合は $`\infty`$ とする。
$`\Gamma=\{1\}`$ なら変更そのものの識別、一般の $`\Gamma`$ なら適合性の判定に
必要な観測点数を表す。最初の例は、$`C_2\times C_2`$ が二つの二元集合を独立に
交換する作用とし、第一成分が恒等であることを適合条件とする。適合性には第一の
二元集合の一点、変更の識別には両集合の一点ずつが必要となる違いを示したい。

さらに、過去の答えに応じて次の点を選ぶ適応的な読取りにも、同じ値が下限になることを狙う。
既知の有限群作用と $`\Gamma`$ を固定し、未知の $`g\in G`$ への問い合わせを
正確な点評価 $`x\mapsto g\cdot x`$ に限る。常に正答する決定的アルゴリズムを扱い、
問い合わせ以外の計算費用を数えない。このモデルで、最適な最悪時問い合わせ数を
$`b_\Gamma`$ と同値にする。下限は、恒等元を入力したときの質問点集合 $`B`$ から導く。
$`G_{(B)}`$ に不適合な変更があれば、その変更もすべて同じ答えを返し、判定に失敗する。
上限は最小の $`B`$ を固定して読む方法が与える。

有限表による構成では、不適合な変更の集合 $`U=G\setminus\Gamma`$ と
$`S_x=\{g\in U\mid g\cdot x\ne x\}`$ を作る。
$`B`$ が十分であることは $`\bigcup_{x\in B}S_x=U`$ と同値なので、最小観測集合は
この集合被覆問題へ対応する。被覆可能で $`U\ne\varnothing`$ なら、greedy法による
$`H_{|U|}`$ 倍以下の近似を得る候補になる。ここで $`H_m=\sum_{i=1}^m1/i`$ とする。
被覆不能なら、作用の核に属する不適合な変更を返し、$`b_\Gamma=\infty`$ を示す。
$`U=\varnothing`$ なら問い合わせは不要である。

生成元で置換群を与える場合は別の入力表現になる。
$`\Gamma=\{1\}`$ に対する最小baseのNP困難性
（[Blaha, 1992](https://www.sciencedirect.com/science/article/pii/019667749290020D)）と比較し、
有限表の全列挙費用、群の生成元表示での計算費用、未知変更への問い合わせ数を分けて評価する。

AATでの追加目標は、§2.3の操作とholonomyからこの値と実際の観測点を求め、
独立な系の合成や操作の追加でどう変わるかを記述することである。群作用の入力に加え、
許すテスト点と適合部分群を固定する。観測表から変更が存在するかは§5.1の延長問題と
して扱い、最小観測数の定理と生成元・関係式による延長定理を組にする。

### 5.3 修復障害を検出するために必要な閉路を特定する

[第3章](../../outreach/paper/rising-sea/ja/06-resolution-invariance.md)の定理3.40は、
関係成分を識別する条件 $`R_q`$ と、各ラベルについて全chartに共通する代表を使い、
有理数値の診断から整数係数の障害の零性を戻す。ここでは共通代表の条件を詳しく調べる。

構成3.36の、有限被覆、連結なchartと二重交差、三重交差なしという範囲を保つ。
$`R_q`$ によって修復係数を $`\mathbb Z^\Lambda`$ と識別し、被覆のグラフを
$`N`$、ラベル $`\lambda`$ が実際に診断座標として現れる部分グラフを
$`N_\lambda`$ とする。辺の可視性は交差の台から定める。

候補は、構成3.36で実現されるすべての局所データについて、診断が障害の零性を
反映するための必要十分条件を、各ラベルに対する次の全射性で与えることである。

```math
H_1(N_\lambda;\mathbb Q)\longrightarrow H_1(N;\mathbb Q).
```

定数係数のグラフでは、部分グラフからのこの写像は単射である。その全射性を、
$`N`$ の橋でない辺がすべて $`N_\lambda`$ に含まれる条件へ言い換える。
橋とは、その辺を除くと連結成分数が増える辺である。辺の向きはchainの符号に使い、
橋の判定では無向グラフとして扱う。ループと平行辺も保持する。
したがって、与えられた可視部分が十分かは、橋の列挙と辺の包含から線形時間で判定する
構成を目指す。chart等を選ぶことで可視部分を得るときの最小費用は、別の選択問題として定める。

最初の正例には、閉路に樹木を付け、ラベルが閉路では見えるが樹木の先では見えない
入力を選ぶ。反例候補には、8の字の片方の閉路しか見えないラベルを置く。
閉路上のperiodと制限写像から条件を導き、反例も構成3.36の実際の局所状態へ戻す。

この結果は、第2章の修復と第7章の情報の十分性を、必要な観測の具体的な選択で結ぶ。
係数方向の衝突、非定数係数、2-cellを含む場合には、それぞれ追加の比較条件を問う。

## 7. CSへの帰結

### 7.1 数学的な構造から、変更の判断へ戻す

CSで得たいのは、保存すべき条件から変更の選択肢を求め、その構成方法や
実現を妨げる理由を説明できることである。修復商なら状態をどこまでまとめられるか、
holonomyと二次障害なら局所の変更を合成して整合させられるか、有限決定性なら
判断に何を読む必要があるかが、具体的な帰結になる。

AIが生成した変更案に対しても、保存するLaw・操作・観測と、変更前後の対応を
入力として与える接続を考える。得たい出力は、成立条件、許される選択肢、または
失敗を示す状態・操作列・関係式である。保存対象は利用者が指定し、
その入力に対して定理が与える判定と構成を使う。

共通定理の再利用には、[n1015](n1015_aat_reconstruction_cs_correspondence_design.md)の
lensとプロトコルを用いる。それぞれの意味論からAAT入力を独立に構成し、
対応命題を介して同じ定理を適用する。CS側へ帰結を戻し、どの証明と条件を
再利用できるかを調べる。

### 7.2 具体的な変更・修復の問題

注文・支払・在庫を持つシステムでは、同じ「受付済み」と表示される二状態でも、在庫引当の有無によって
次の注文確定の結果が変わるなら、その結果を保つ商では二状態を区別する必要がある。

CS側の問題として、次を具体化する。

- 各部分でLawを満たす状態を、全体へ貼り合わせられるか。
- 不一致を解消するために状態をまとめても、その後の操作と観測を保てるか。
- 個別に実現できる修復を合わせたとき、商と自然な正規化はそれぞれ存在するか。
- サービスをまとめた解像度でも、同じ不整合を診断できるか。
- 診断側で選んだ補正を元の状態へ戻せるか。戻せる場合、どの自由度が残るか。
- サービスを分ける変更と、共通処理を抽出する変更の二経路が整合するか。
- 表示や観測が同じ変更のうち、既存の対応を保つものはどれか。
- 二つの微小変更が個別にはLawを保って延長できても、同時に延長すると干渉するか。
- 読取り点を適応的に選んでも、判定に必要な情報量の下限は残るか。
- 分担した局所記述から、その変更と選択肢を回復できるか。

## 9. GOALカード候補と依存関係

### 9.1 一枚のカードで何を定めるか

一枚のGOALは、入力から一つの構造を構成し、そこから存在・分類・不可能性・計算に
関する一組の帰結を得る単位にする。以下では、研究目標を候補01〜19へ分ける。
候補番号はこのノート内の参照用とし、GOALの通し番号は正式なカード化の際に割り当てる。

各候補の「target案」は、その入力に対する一般的な結論を表す。「例・反例」は、
同じ一般定理への適用と、条件の必要性を確かめるための固有の証明対象である。
「固定前の課題」がある候補は、そこで挙げた対象・写像・仮定を定めてからtargetを固定する。
構成済みの比較や分類を入力として受け取る場合と、それらを原始入力から作る場合を区別する。

合同関係や群作用の一般論と、AATの原始入力からそれらを構成する対応を分ける。
計算を帰結に含める候補では、入力の表現とサイズを定め、停止・正確性・計算費用の上界を揃える。

正式なカードは[GOALカードの型](../../research/goals/README.md#goal-カードの型)に従い、
研究目的、固定target、前提・構成台帳、完了条件を揃える。各候補に固有の完了条件は、
targetの全条項と指定した例・反例の成立、および参照する既存構成との対応とする。
証明途中で反証された場合は、その固定targetに対する反例を成果として残す。

### 9.2 既存の定理・固定targetと新規候補の差分

定理3.37・3.40・3.43・3.44に対応する既存の接続定理として再利用する。
新規候補では、そこから広げる対象・仮定・比較を特定する。

| 出発点 | 再利用する構成・結論 | 新規候補で広げる部分 |

### 9.3 変更・修復・情報に関する候補

#### 候補01：操作と観測を保つ修復商の分類と有限構成

- **目的・出発点**：§2.1の修復可能性と全選択肢を、同じ合同関係の区間から求める。
- **入力**：任意の有限集合 $`S`$、有限個の全域操作 $`T_e`$、有限表で与える観測
  $`o`$、同一視要求 $`R\subseteq S^2`$。観測値の等号判定を入力に含める。
- **target案**：$`\equiv_R`$ と $`\approx_o`$ を入力から構成し、元の状態集合からの商写像と可換な
  同型までの修復商と
  $`\equiv_R\subseteq\theta\subseteq\approx_o`$ を満たす操作合同関係を、因子化の順序も
  含めて対応させる。§2.1の存在条件、両端の普遍性、有限構成の停止・正確性を示す。
  不可能な入力には、$`R`$ の状態対と観測を分離する操作語を返す。
  要求の和と生成合同関係のjoinを対応させ、同じ操作・観測での修復可能性の閉性を示す。
  逐次修復と一括修復の一意の同型を元の商写像と可換に構成し、有限個の要求について
  順序・括弧づけを変える同型の整合を証明する。
- **例・反例**：四状態で $`T=(01)(23)`$、観測の分割を $`\{0,1\}\mid\{2,3\}`$、
  $`R=\{(0,1)\}`$ とし、最も細かい修復商と最も粗い修復商が異なることを示す。
  不可能な例には§2.1の三状態を使う。
- **依存**：新規候補への依存はない。有限操作の意味論を固定する最初のカードに向く。

#### 候補05：適合性を決定する最小観測集合

- **目的・出発点**：§5.2。変更全体の識別に加え、適合性だけを判定する観測を最小化する。
- **入力**：任意の群作用 $`G\curvearrowright X`$、適合部分群 $`\Gamma`$、有限な観測集合
  $`B\subseteq X`$。計算部分では $`G,X,\Gamma`$ と作用を有限表で与える。
- **target案**：$`O_B`$ からの適合性判定と $`G_{(B)}\subseteq\Gamma`$ の同値を示す。
  §5.2の正確な点評価だけを使う決定的・常時正答の問い合わせモデルで、
  最適な適応的アルゴリズムの最悪時問い合わせ数が $`b_\Gamma`$ と一致することを示す。
  有限入力では $`b_\Gamma`$ と最小集合を計算し、十分な集合がなければ、全点で同じ観測を
  持ちながら適合性が異なる変更を返す。集合被覆への対応とgreedy法の近似保証を構成する。
  独立な二系の直積群が観測点の非交和に作用し、
  適合部分群も直積である場合の加法性を示す。同じ作用で適合部分群を狭めると、必要点数が
  減らないことも対応させる。観測表の延長は、指定表を実現する変更の存在として別に判定する。
- **例・反例**：二つの二元集合に作用する $`C_2\times C_2`$ で、適合性の判定に一点、
  全変更の識別に二点が必要なことを示す。非忠実な作用で $`b_\Gamma=\infty`$ となる例も置く。
- **依存**：一般判定は独立に扱える。操作系への適用では、候補03から適合群を構成し、
  観測対象とその作用を指定する。G-124 D・Eの区別・延長との対応を保つ。
  未知の変更の判定では、変更が適合群に属することを前提にせず、周囲の $`G`$ 全体を量化する。
  計算量は有限表と生成元表示で分け、問い合わせ数とは別に定める。

- **例・反例**：各段には欠損があり、合成では欠損が消える一組を、抽象的な線形写像に加え
  実際のLaw・台・セル比較から構成する。同じ入力で $`\chi`$ の非零性を示す。
- **固定前の課題・依存**：許容比較の合成と、$`\Sigma_M`$ の普遍性が量化する対象・射を

#### 候補09：整数・有限環による修復障害の検出と補正の構成

#### 候補13：診断欠損の貼り合わせと、有限な観測幅の限界

- **目的・出発点**：§4.4、n1006のR15・R3。部分ごとの診断と全体の診断の差を説明する。
- **入力案**：有限概念集合上の二領域の和・交差、台と係数の制限、それらの解像度比較。
- **target案**：元のcochainから短完全列と写像錐の長完全列を作り、
  $`J_A=J_B=0`$ でも $`J_{A\cup B}\ne0`$ となる原因を交差上の写像から特定する。
  幅については、任意の有限 $`k`$ に対し、$`|A|\le k`$ の全診断が一致しながら
  一様不変性が異なる、同じ概念集合上の有限入力対を構成する。
- **例・反例**：$`k+1`$ 個の概念をまたぐ交互多角形を候補にし、低い幅では見えない
  閉路を実際の台・Lawから構成する。
- **固定前の課題・依存**：領域の和・交差に対するセルと係数の制限を固定する。
  候補07の写像錐を再利用する。半径方向のR3-rは、読む局所型と観測写像を定めた上で、
  幅方向とは独立の後続カードへ分ける。

### 9.5 Lawの幾何と、章間の接続に関する候補

#### 候補14：Lawから導く微小修復の障害と選択肢

- **目的・出発点**：§2.5。修復係数をLawの方程式から導き、局所残差と貼り合わせを同時に扱う。
- **入力案**：体 $`k`$、有限被覆上の滑らかな状態空間、正則列で局所生成されるLaw、
  制限写像、一つのlawfulな $`A`$ 値状態、核 $`M`$ が平方零の可換 $`k`$-代数の全射 $`A'\to A`$。
- **target案**：Jacobianから $`T^0\to T^1`$ を作り、局所liftのずれとLaw残差を
  総複体の一次の類へ送る。選択によらないその類の零性を大域的lawful liftの存在と
  同値にし、存在する場合の解を $`H^0`$ のtorsorとして記述する。
  局所lawful liftがある場合は、$`\ker J`$ による第2章のtorsor障害へ対応させる。
- **例・反例**：$`x^2=0`$ の状態 $`x=\epsilon`$ を $`k[\epsilon]/(\epsilon^2)`$ から
  $`k[\epsilon]/(\epsilon^3)`$ へ持ち上げられないことと、liftが存在する線形Lawの例で、
  残差・補正・選択肢を計算する。
  $`xy=0`$ の原点では、一次方向 $`(a,b)`$ の二次への延長条件 $`ab=0`$ を導き、
  個別に延長できる二方向の和が延長できない例を同じ障害構成で説明する。
- **固定前の課題・依存**：座標・方程式・制限が作る層と、表示変更に沿う比較を固定する。
  任意イデアルへの拡張は、方程式間の関係を保持する後続問題として分ける。

#### 候補15：線形プロトコルの実現の族と一次変形

- **目的・出発点**：§2.6。有限集合値とは独立に定めた実現を、係数代数に自然な族として扱う。
- **入力**：体 $`k`$、有限グラフ、有限個の経路関係、各頂点の階数、行列で与える観測保存条件。
  任意の可換 $`k`$-代数に対する、基底を固定した線形実現を量化する。
- **target案**：独立に定義した実現関手をアフィン概形で表し、係数変更との自然性を示す。
  一つの実現で、許容する頂点の基底変更・辺行列・関係式の線形化から複体を作り、
  微小自己同型と一次変形の分類に対応させる。
  同型を保つgroupoidと、非可逆な構造保存射を含む圏の双方をAAT入力へ対応させる。
- **例・反例**：$`A^2=0`$ を満たす行列の族で、$`A=\epsilon B`$ が二次へ延長する
  条件を計算する。自己同型を持つ実現を含め、同型類だけでは失われるデータを特定する。
- **固定前の課題・依存**：観測データと許容射を独立に定義する。商stackによる族の表現と
  一般の高次持ち上げは、descentと方程式間の関係を固定する後続カードへ分ける。
  候補14の局所変形を具体化する入力族として接続する。

#### 候補16：診断障害とLawの微小持ち上げ障害を結ぶ比較

- **目的・出発点**：§2.5の診断との接続。同じ修復問題に対する二つの障害を対応させる。
- **入力案**：候補14、または候補15の一つの有限次元モデルと、その同じ原始入力から
  生成する第2〜3章の修復係数・診断複体。
- **target案**：係数と次数を特定したcochain比較を構成し、指定された変更の障害類を
  対応させる。零性を保存・反映する条件を原始入力で記述し、その条件下で
  診断の零性と同じ持ち上げ問題の可解性を同値にする。
- **例・反例**：同じ入力族に可解・不可解の両例を置き、両側で同じ類を追う。
  反映条件を外した例も、その比較写像の情報損失として記述する。
- **固定前の課題・依存**：候補14・15から一つのモデルを選び、写像の向き・係数・次数を
  先に固定する。G-125の実比較を出発点にする。両側が一次のコホモロジーを使うことだけで
  比較を済ませず、元の局所データからの生成式を対応させる。

#### 候補17：局所再構成と診断比較・輸送の整合

- **目的・出発点**：§3.3。G-124 Cの構造保存を、診断と実際の障害の判定へ広げる。
- **入力案**：G-124の実現と局所モデル、そこから独立に構成する被覆・台・係数・診断複体。
  一つの許容する解像度変更とreading変更の平方を固定する。
- **target案**：局所モデル側で作る複体・比較写像と、完全幾何側の構成を再構成同値で
  運んだものを対応させる。指定障害類、比較の核・余核、零性判定を追い、
  二経路の診断比較の可換性を証明する。
- **例・反例**：非単射の解像度変更と非零の診断を含む有限入力で両経路を計算する。
  必要な局所条件を外した場合に、どの写像の構成・整合が失敗するかを特定する。
- **固定前の課題・依存**：局所モデルからAtlas入力を取り出せる対象族と、平方に必要な
  exactness・係数・被覆の条件を定める。G-125のreading変更の可換性を再利用し、
  G-124 Cの再構成と候補07の比較との整合を加える。候補16とは別の、表示と輸送に関する比較を扱う。

#### 候補18：指定補正の持ち上げ障害と解全体の分類

- **目的・出発点**：§4.8。G-125による整数補正の構成から、診断側で指定した補正との
  一致条件と、すべての持ち上げの分類へ進む。
- **入力**：非負次数のアーベル群の複体 $`C,D`$、cochain写像 $`\phi:C\to D`$、
  $`z\in Z^1(C)`$、$`d_Db=\phi^1z`$ を満たす $`b\in D^0`$。
  AATへの接続では、これらを同じ修復入力から構成する。
- **target案**：$`[(b,-z)]\in H^0(\operatorname{Cone}(\phi))`$ の零性を、
  $`d_Ca=z`$ かつ $`\phi^0a=b`$ となる補正の存在と同値にする。
  元の補正がある場合には $`k_\phi:Z^0(C)\to Z^0(D)`$ の余核による障害へ対応させ、
  非空な持ち上げ集合をその核のtorsorとして分類する。全補正の持ち上げ・一意性の条件を導く。
  有限表示の整数複体では、指定補正の持ち上げ判定と解の表示を整数線形代数から構成する。
- **例・反例**：§4.8の一辺の整数・有理差分複体で、整数補正は存在するが
  $`b=(1/2,3/2)`$ 自体は持ち上がらないことを示す。複数の持ち上げの例は、
  $`C^0=\mathbb{Z}^3`$、$`D^0=\mathbb{Z}^2`$、$`C^1=D^1=\mathbb{Z}`$、
  $`d_C(u,v,w)=d_D(u,v)=v-u`$、$`\phi^0(u,v,w)=(u,v)`$、$`\phi^1=1`$ とする。
  $`z=1`$、$`b=(0,1)`$ の持ち上げは $`(0,1,w)`$ 全体で、$`\mathbb{Z}`$ のtorsorになる。
- **固定前の課題・依存**：一般の複体での分類は独立に扱い、G-125の実比較に適用する。
  錐の次数 $`-1`$ と補正の符号を固定し、cochain上の一致とcohomology上の一致を区別する。
  候補07と錐の構成を共有し、候補16・17の比較が解集合にも誘導する写像を追う。

#### 候補19：線形実現の族における診断の跳躍集合

- **目的・出発点**：§4.9。後続課題として、単一の係数・実現での診断を、係数と辺作用の
  族に沿って比較し、診断の自由度が変わる場所を記述する。
- **入力案**：体 $`k`$、有限表示可換 $`k`$-代数 $`R`$、候補15の線形実現の族、
  有限被覆・台・Law・制限式。その入力から有限自由な診断複体 $`C_R`$ を作る。
- **target案**：fiberごとの一次診断の次元を行列の階数で表し、指定次元以上になる集合を
  小行列式の消滅で構成する。複体の構成と係数変更の自然性を示し、各fiberで元の診断に戻す。
  比較の核・余核については、階数一定の部分ごとに誘導写像と診断欠損を計算する。
- **例・反例**：$`k[t,t^{-1}]`$ 上の一ループから $`R\xrightarrow{t-1}R`$ を生成し、
  $`t=1`$ での跳躍を示す。同じ複体の次数0では、コホモロジーを先に取ると零だが、
  $`t=1`$ への特殊化を先に行うと $`k`$ になり、二つの操作の順序による差が現れる。
- **固定前の課題・依存**：候補15と、同じ入力から診断を作る対応を先に固定する。
  台と複体の階数が変わる場合には、有限自由複体を作れる部分へ分ける条件を定める。
  SHIGURE全体の表現可能性を前提とせず、この有限な族の構成を対象にする。

### 9.6 最初に具体化する組と、その後の接続

最初の組は、候補01・03・05とする。いずれも入力と一般的な結論を具体的に記述でき、
有限例を含むtarget案を作りやすい。候補01が修復の全体、候補03が変更と持ち上げの全体、
候補05がその判定に必要な観測を担う。候補05の一般論は独立に進め、操作系への適用で
候補03の出力を使う。

| 接続 | 渡す構造・帰結 |
| --- | --- |
| 候補01 → 候補02 | 合成できる修復商から、型付きの商・section・正規化の合成条件へ |
| 候補03 → 候補04・05 | 群拡大を整合障害へ、変更群と作用を最小観測へ |
| 候補07 → 候補08・11・13 | 実際の比較と写像錐を、局所変形・欠損分解・貼り合わせへ |
| 候補14・15 → 候補16 | 方程式から作った複体と指定障害を、診断との比較へ |
| G-124 C・G-125の既存定理・候補07 → 候補17 | 既存の障害診断比較を再利用し、再構成・合成との整合を加える |
| G-125の実比較・候補07 → 候補18 → 候補16・17 | 障害の対応から指定補正の持ち上げへ進み、解集合の比較を加える |
| 候補15 → 候補19 | 線形実現の族から診断複体を生成し、特殊化と跳躍を計算する |

候補06・09・10は診断が検出する情報を広げる。候補12は診断を保つ解像度の選択を扱う。
候補14から16への接続は、Law自体から修復係数を導くために優先して具体化する。
$`x^2=0`$ と $`xy=0`$ を同じ構成に通し、候補18で、存在判定を越えて指定補正と
解全体を比較する。候補19はその後に族としての変化を調べる位置に置く。
これらを他の候補へ接続するときは、同じ入力に対する写像と量化範囲を照合する。
各カードの前提・構成台帳には、保持する入力、そこから作る構造、既存定理を使う箇所を
記す。一枚ごとの研究目標と、他のカードから受け取る構造を、上の依存に沿って固定する。
