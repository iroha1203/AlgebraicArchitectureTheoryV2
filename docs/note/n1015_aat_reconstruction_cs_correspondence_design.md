# n1015: 再構成定理のCSへの対応 — モデル同期とプロトコルの追随変更

[G-123のdraftカード](../../research/goals/G-123-aat-realization-reconstruction.md) E・Fの
独立なCS意味論、decoder、変更分類の構成案を本ノートで定める。

[n1012](n1012_aat_unified_theory_foundations_paper_plan.md) の二つのCS適用と、
[n1014](n1014_aat_realization_reconstruction_design.md) のG-123設計を具体化する。
本ノートの新しい命題は設計段階の命題候補と証明案であり、Leanでの証明とAATへの接続は未実装である。

## 1. CSで答える問いと共通の帰結

二つの問題を扱う。

1. **モデル同期**: 具体データとそのviewをそれぞれ変更したとき、読み出しと更新の両方の意味が保たれるか。
2. **プロトコルの追随変更**: 既存のadapterと操作の実行規則に対し、両端の可逆変更後も同じ対応が保たれるか。

共通の帰結は、観測結果を保つ変更のうち、操作も保つものを特徴づけ、指定した可視変更に対する
追随変更の存在と選択の自由度を分類することである。CS側で操作の意味を先に定義し、
その意味を保つ条件から比較群との対応を証明する。

## 2. モデル同期: 有限の補完データを持つlens

### 2.1 独立した意味と対象範囲

固定した集合 `V` と点 `v₀ : V` を、利用者に見えるモデルとその基準値とする。
`V` は無限でもよい。実現 `L` は集合 `C` と全域関数

\[
 g:C\to V,\qquad p:C\times V\to C
\]

であり、次の三法則を満たすものとする。`p(c,v)` の引数順を本ノートの規約とする。

\[
 p(c,g(c))=c,\qquad g(p(c,v))=v,\qquad
 p(p(c,v),w)=p(c,w).
 \tag{L1}
\]

さらに `K_L={c∈C | g(c)=v₀}` が有限であることを対象の条件にする。
この条件はdecoderや表示の存在を使わず、viewの一つのfiberから定める。
`C=∅` も許す。稼働例では `K_L` を非空とする。

三法則はtotalなvery well-behaved lensの条件である。lensのget/putの意味と法則は
[Fosterらの著者公開稿 §3](https://www.cis.upenn.edu/~bcpierce/papers/lenses-full.pdf) を参照する。
三つ目のPutPutは、更新の履歴を補完データに累積するモデルを対象から外す実質的な条件である。
この対象範囲を、二法則だけを満たすlens全体へ広げない。

### 2.2 実現圏・表示圏・decoder

`R_lens(V)` の対象を§2.1のlens、射 `h:L→L'` を

\[
 g'h=g,\qquad h(p(c,v))=p'(h(c),v)
 \tag{L2}
\]

を満たす関数とする。恒等・合成は関数の恒等・合成である。

`P_lens` の対象は自然数 `n`、射 `n→m` は `Fin n→Fin m` の有限tableとする。
decoder `F_lens` は

\[
 n\mapsto\bigl(V\times\operatorname{Fin}(n),\ g(v,k)=v,\
 p((v,k),w)=(w,k)\bigr),\qquad
 t\mapsto((v,k)\mapsto(v,t(k)))
 \tag{L3}
\]

と定める。`V` の要素や`C`全体を有限とする条件は置かない。

**再構成命題候補**。`F_lens` は圏同値を与える。特に充満忠実であり、
`R_lens(V)` は冪等完備、すべての実現は表示のretractである。

証明案では、まず次を構成する。

\[
 \theta_L:C\longrightarrow V\times K_L,\quad
 c\longmapsto(g(c),p(c,v_0)),\qquad
 \theta_L^{-1}(v,k)=p(k,v).
 \tag{L4}
\]

(L1)から互いに逆で、getとputを保つことが分かる。(L2)の射は基準fiberへの制限
`K_L→K_L'` で一意に決まり、任意のそのような関数が射を与える。
有限fiberの列挙から同じ端点のtableを構成する。冪等射は`K_L`上の冪等関数の像で分裂する。
全域性・PutPut・有限fiberの使用先がこの証明で明らかになる。

n1014 §4.1の制限・延長は、この族では具体的に
`res(h)=h|K_L`、`ext(t)(c)=p'(t(p(c,v₀)),g(c))` である。
生成部の写像は有限集合間の関数 `t:K_L→K_L'` で、全域の射を入力に取らずに延長できる。
表示された積lens間では `K_L ≃ Fin n`、`K_L' ≃ Fin m` の対応を通じて、
構文のtableと生成部の写像の全単射 `J` を得る。選択値を保つ版では `t(k₀)=k₀'` を課す。

この定理の定数補完による表示は、lens・データベースの既存理論に帰属する。
[同稿 §10](https://www.cis.upenn.edu/~bcpierce/papers/lenses-full.pdf) が述べる定数補完との関係を
参照し、AATへの入力構成、観測と比較群の整合を本計画で追加する仕事として扱う。

### 2.3 可視変更に追随する変更

`H≤Sym(V)` を許容する可視変更の群として固定する。各 `u∈H` について、
`h:C≃C'` が読み出しと更新の意味を運ぶ条件を

\[
 g'h=u g,\qquad h(p(c,v))=p'(h(c),u(v))
 \tag{L5}
\]

とする。これは、次の二つの図式で同じ `h,u` を使う条件である。

\[
 \begin{array}{ccc}
 C&\xrightarrow{g}&V\\
 {\scriptstyle h}\downarrow&&\downarrow{\scriptstyle u}\\
 C'&\xrightarrow{g'}&V
 \end{array}
 \qquad
 \begin{array}{ccc}
 C\times V&\xrightarrow{p}&C\\
 {\scriptstyle h\times u}\downarrow&&\downarrow{\scriptstyle h}\\
 C'\times V&\xrightarrow{p'}&C'
 \end{array}
\]

読み出しと更新を別々の変更で保つことでは足りず、両図式の `C` に同じ変更を作用させる。
§5の一射へのまとめ方は、この同時保存をAATの比較群へ渡すために用いる。
点`v₀`を固定しない`u`も許す。(L4)を使うと(L5)は、ある唯一の
全単射 `φ:K_L≃K_L'` によって

\[
 \theta_{L'}h\theta_L^{-1}(v,k)=(u(v),\varphi(k))
 \tag{L6}
\]

と書けることと同値になる。`φ(k)=p'(h(k),v₀)` で構成する。
`u`は利用者が指定する可視変更であり、decoderが追加で読むデータは有限fiber間のtableである。
完成した`h`を構文の定数として受け取らない。

一つのlensについて、(L5)を満たす組`(u,h)`を可逆変更の群の元とする。
その群から`H`への射は、(L6)で`φ=id`としたsectionを持つ。
核は`Sym(K_L)`、各`u`上のfiberはその核のtorsorである。
射の種類を全単射から一般の関数へ広げる場合も、(L2)の圏の再構成が先にある。

**対象形成の基準値を保つ版**。さらにsection `s:V→C`を持ち、
`g(s(v))=v`、`p(s(v),w)=s(w)`を要求する。射には`s'u=hs`を課す。
(L4)では`s(v)`は`(v,k₀)`、`k₀=s(v₀)`に対応する。この実現圏の表示は、
基準要素を持つ有限集合と基準要素を保つtableである。可逆変更の核は`Sym(K_L)`の
`k₀`の固定部分群となる。AATの`object_formation_eq`への接続では、この追加データの対応を調べる。

### 2.4 読み出しだけでは選べない変更の固定例

`V=K=Bool`、`C=V×K`、getとputを(L3)と同じものとする。
可視変更を恒等として、`h(v,k)=(v,k⊕v)` を取る。これはgetを保つ全単射である。
しかし`c=(false,false)`、更新値`true`について

\[
 h(p(c,true))=(true,true),\qquad
 p(h(c),true)=(true,false).
 \tag{L7}
\]

従って更新操作を保たない。getだけを保つ変更は、viewの値ごとに補完の置換を選べるため4個ある。
putも保つ変更は、両viewで同じ置換を使う2個である。可視変更をBoolの反転にした場合も4個と2個になる。
この差は、更新規則を残すことの具体的な意味を示す。

基準値を保つ版の固定例は`V=Bool`、`K={0,1,2}`、`s(v)=(v,0)`とする。
`v=false`では補完を固定し、`v=true`では`1`と`2`を交換する変更はgetとsectionを保つが、
`c=(false,1)`を`true`へ更新する操作を保たない。sectionを保つという同じ資格の下で、
getを保つ変更は4個、getとputを保つ変更は2個であり、双方の群に非恒等元がある。

## 3. プロトコル: 操作と実行経路を保持する表示

### 3.1 独立した実現と有限表示

有限な型付き有向多重グラフ `Q=(V,E,s,t)` と、有限個の並行経路間の等式`L`を固定する。
`C_Q`を自由圏の経路合同による商とし、`O:C_Q→Set`を観測のパラメータとする。
`R_proto(Q,L,O)`の対象は、各`X(v)`が有限な関手`X:C_Q→Set`と
自然変換`o:X→O`である。射`a:X→Y`は`o_Y a=o_X`を満たす自然変換とする。
実行は生成辺の列であり、その作用は関手による経路の評価で定める。

`P_proto`の対象は、頂点ごとの個数`n_v`、生成辺ごとのtable
`Fin n_s→Fin n_t`、各状態の観測値`o_v(i)∈O(v)`である。
`L`の各式と、生成辺についての観測の可換式を満たすものを取る。
射は頂点ごとのtableで、生成辺との可換式と観測保存を満たすものとする。
decoderは生成tableを経路に沿って合成し、商圏上の関手へ延長する。

**再構成命題候補**。このdecoderは圏同値を与える。経路帰納法により、生成辺の可換式から
全実行経路の可換式を導く。有限carrierの列挙が本質的全射性を与え、
冪等射の像は各`X(v)`の固定点集合と、そこへの操作の制限から構成する。
観測値の所属先`O(v)`は無限でもよい。

この族の生成部上の整合写像は、頂点ごとの有限table `a_v` で、各生成辺 `e:v→w` に対して
`Y(e)a_v=a_wX(e)`、各頂点で `o_Y(v)a_v=o_X(v)` を満たすものである。
`res` は自然変換からこのtable族を取り出す。`ext` は同じ成分を使い、経路帰納法で
すべての経路について自然性を証明する。構文の等号はtableの外延的等号であり、
`J`はこのtable族との対応である。
これがn1014 §4.1–§4.2を具体化する二つ目の例になる。

生成辺はoperationの名前として残す。二辺が同じ状態遷移を実現しても、同じ辺とするには
`L`に由来する経路の等号が必要である。操作名の変更を扱う版では、`Q`の自己同型で`L`と
観測を保つものを別の入力とし、頂点・辺の両方の写像を運ぶ。

経路等式を持つschemaと集合値の実現は
[Spivak, Functorial Data Migration §3.2](https://arxiv.org/pdf/1009.1166) の既存の数学を使用する。
本案は、指定した有限carrierの作用と観測を保持する再構成・追随変更へ、その構成を接続する。

### 3.2 adapterを保つことの意味

具体側の実現`X`、抽象側の実現`Y`、既存のadapter`q:X→Y`を入力とする。
`q`は各制御点の対応と、すべての操作の実行を対応させる。
可逆な変更`a:X≃X'`、`b:Y≃Y'`後のadapterを`q':X'→Y'`とする。

CS側の要求は、各状態について、先にadapterで対応づけてから変更した結果と、
先に変更してから新しいadapterで対応づけた結果が一致することである。
加えて、各変更が操作の実行を運ぶことを要求する。この条件から

\[
 bq=q'a
 \tag{P1}
\]

との同値を証明し、経路帰納法で任意の有限実行に拡張する。
`q'=q`と同じ端点を固定すると、比較を保つ変更の群を得る。

扱うCSの問いは、既存adapterを維持する可逆変更である。
[de Alfaro–HenzingerのInterface Automata](https://research-explorer.ista.ac.at/record/4622) が扱う
環境の存在による互換性やalternating refinementとの関係は、各定義への別の対応を要する。
本案の(P1)にその名称や結論をそのまま付けない。

## 4. 二つの問題で共用する変更の分類

### 4.1 操作が補完データを運ぶモデル

有向多重グラフ`Q=(V,E,s,t)`と集合`K`を固定する。状態は`V×K`、観測は`q(v,k)=v`、
各辺`e:v→w`の操作は`(v,k)→(w,k)`とする。操作の同一性は`e`で保持する。
`H≤Aut(Q)`を許容する可視変更群とし、`u∈H`に追随する可逆変更`h`を考える。

**共通分類命題候補**。`qh=u_V q`を満たす`h`は、唯一の族`φ_v∈Sym(K)`により

\[
 h(v,k)=(u_V(v),\varphi_v(k))
\]

と書ける。さらに操作の実行を運ぶことは

\[
 \varphi_{s(e)}=\varphi_{t(e)}\quad(e\in E)
 \tag{C1}
\]

と同値である。operationの写像は`(e,k)↦(u_E(e),φ_{s(e)}(k))`とする。
変更の群`A_Q`は、この操作保存条件を満たす組`(u,h)`の群とする。
従って`φ`は向きを忘れた連結成分ごとに一定であり、`A_Q`について

\[
 1\longrightarrow\prod_{j\in\pi_0(Q)}\operatorname{Sym}(K)
 \longrightarrow A_Q\longrightarrow H\longrightarrow1
 \tag{C2}
\]

は分裂する。sectionは`(v,k)↦(u_V(v),k)`である。任意の`u`上の追随変更の集合は
同じ核のtorsorとなる。`V`と`K`が有限なら、その個数は`(|K|!)^{|π₀(Q)|}`である。
この入力ではsectionがすべての可視変更への追随変更を与える。
共通分類が明らかにするのは、その全選択肢と、操作の連結成分ごとに残る自由度である。

証明案では、`h`と`u_V`の全単射性から各fiberの全単射`φ_v`を取り出す。
一辺の実行の両順序を計算すると(C1)になる。等号を経路に沿ってつなぐことで
連結成分上の一定性を得る。逆にその族から`h`を構成する。
核の作用・完全性・torsorへの整理にはG-120の`GroupHomRestriction.lean`を使う。
合成における`H`の作用は連結成分の置換であり、一般には直積ではなく半直積になる。

各状態に基準補完`k₀`を指定し、その値を保つ変更を扱う版では、各`Sym(K)`を
`k₀`の固定部分群に置き換える。同じ(C1)とsectionが成立する。

### 4.2 同じ命題による二つの帰結

| 入力 | 操作グラフ | (C1)から分かること |
| --- | --- | --- |
| 積表示されたlens | すべてのview値の間にput操作がある | 補完の変更はview値に依存しない。§2.3の`Sym(K)`を回復する |
| 独立したセッション群のプロトコル | セッション内の遷移を辺とする | 補完の変更は各セッションの連結成分で一貫している必要がある |

固定するプロトコル例は、`V={0,1,2,3}`、辺`0→1`と`2→3`、`K=Bool`とする。
可視変更が恒等のとき、状態ごとに補完を反転するかどうかを選べる観測保存変更は16個あり、
操作も保つものは4個である。二つの辺を交換する可視変更についても追随変更は4個である。
セッション内で補完の対応が一貫していることが、その差を決める。

共有するのは(C1)の導出と(C2)の分類である。具体入力から操作を構成する証明は各問題で行い、
得られる核の違いを、操作によって結ばれる状態の違いとして説明する。
後続の候補には、各辺が補完を全単射 `T_e:K≃K` で運ぶモデルを置く。
その場合の操作保存式は `φ_t(e) T_e=T_{u_E(e)} φ_s(e)` となり、閉路に沿う合成との
整合や追随変更の存在を調べる問題へ進む。この候補はS6以降の展望に置き、
G-123のFは(C1)・(C2)の入力と結論で閉じる。

## 5. AATとG-122へ接続する要求

§2・§3の独立な実現とdecoderを、次の型付きデータからAATへ接続する。
この節は入力配置と翻訳の構成案を与える。GOALカードEではCSの法則・射の全範囲と
往復の結論を固定し、完全なAAT入力・射の構成を研究義務にする。

### 5.1 lensから渡すデータと写像

状態`C`、view`V`、読取りの実行`Read=C`、更新の実行`Write=C×V`を別の型として持つ。
型を区別した上で、次の写像を保持する。

| 成分 | source・target・値の読取り | 変更`(h,u)`の作用 |
| --- | --- | --- |
| 状態とview | `C,V` | `h,u` |
| `Read` | sourceは`c`、targetは`g(c)` | `Read(c)↦Read(h(c))` |
| `Write` | sourceは`c`、要求値は`v`、targetは`p(c,v)` | `Write(c,v)↦Write(h(c),u(v))` |
| 選択値を持つ版 | `s:V→C` | `hs=s'u` |

`Read`のtargetを保つ式は`g'h=ug`、`Write`のtargetを保つ式は
`hp=p'(h×u)`である。sourceと要求値を保つ写像は実行の写像を一意に決めるので、
この型付きデータの射と(L5)の写像の対応には余分な操作変更を含まない。
`u=id`、一般の関数`h`に対して同じ式を使うと(L2)になる。
法則は(L1)の三式をそのまま対象条件にし、`Write`を実現された状態写像の等号で商にしない。

有限表示へは、(L4)による`C≃V×K_L`を使い、有限な`K_L`のtableを渡す。
`g,p`は積の式へ移り、一般の射は§2.2の`ext(t)`、可視変更に相対的な射は(L6)から戻す。
ここでは`h`のtable化を要求せず、パラメータ`V,u`と有限補完上のtableを区別する。

### 5.2 プロトコルから渡すデータと写像

制御点`v`ごとの状態`X(v)`、操作名`e:v→w`、実行の型
`Step_e=X(v)`を区別する。`Step_e(x)`のsourceは`(v,x)`、targetは`(w,X(e)x)`、
操作名は`e`である。観測値は`o_v(x)∈O(v)`として保持する。

固定した`Q,L,O`上で、状態写像`a_v:X(v)→Y(v)`から実行の写像を
`Step_e(x)↦Step_e(a_v(x))`と定める。target保存と観測保存は、それぞれ
`a_w X(e)=Y(e)a_v`、`o_Y(v)a_v=o_X(v)`である。
sourceと操作名から実行の写像が決まり、生成辺でこの式を確認すれば、§3.1の経路帰納へ進める。
観測値はパラメータの値、状態と生成辺の作用は有限tableで記述する。

adapter`q`も同じ型の射であり、二つの変更`a,b`について、各頂点で
`b_v q_v=q'_v a_v`を要求する。この成分式から(P1)へ進み、全実行との整合を運ぶ。
操作名を変更する版では、§3.1で指定したグラフ自己同型と経路等式・観測の輸送を入力に加える。
その場合も、状態の写像とは別に操作名の写像を保持する。

### 5.3 AATの成分への配置と完全な射の回復

Atomには型・役割・操作名を与え、状態carrierとその作用はSource・対象・局所実現の
データとして扱う構成を選ぶ。各状態を一つずつAtomとして符号化すると、
`SignedExactCoreReadingHom.atomEquiv`の条件が非単射なCS射を排除してしまう。
例えば`Fin 2→Fin 1`の補完tableが与えるlens射も、Eの回復対象である。

pointを持つ底への入力案は、互いに区別した和

\[
 S_L=1+C+V+(C\times V),\qquad
 S_X=1+\sum_{v\in V}X(v)+\sum_{e\in E}X(s(e))
 \tag{A1}
\]

をSourceとし、先頭の`*`を選択値、normalizeを恒等にするものである。
lensのSource写像は`id+h+u+(h×u)`、固定schemaのプロトコルでは
`*↦*`、`(v,x)↦(v,a_v(x))`、`(e,x)↦(e,a_{s(e)}(x))`とする。
固定schemaの操作名への作用は恒等、可視変更を扱う版では許された自己同型を用いる。
この配置は`C=∅`も許し、選択値付きlensのsectionとは独立に底のpointを保持する。
CSのsectionを保存する義務は別に残る。

Source表だけからAAT入力が完成するわけではない。
§5.1・§5.2の読取り・実行を抽出、対象、operation、Lawの各成分に実現し、
型付きデータの保存が完全なAAT射の保存条件と対応することを構成・証明する。
どの許容射についても読み戻しが定まり、元の全域の対象写像・operation写像・幾何写像まで
戻ることを求める。CSの記録上で一致するだけの射を等しいことにしない。

| 接続 | 構成・証明するもの |
| --- | --- |
| CS入力からAtom・Source・対象 | 上の型・役割・操作名とSource配置から構成する。一般のCS射の非可逆性を保持し、operation名を同じ状態写像で商にしない |
| CS条件からLaw | lensの三法則、プロトコルの経路等式と観測保存を、Law評価とその保存条件へ移す。両方向の対応を示す |
| CS射からAAT射 | (L2)・(L5)・(P1)を満たす写像からAATの射を構成し、対象・operation・Lawへの作用を計算する |
| AAT射からCS射 | 許容するAAT射の各成分を読み戻す。構成と読み戻しが互いに逆となる射の範囲を、独立したデータ条件で固定する |
| 複数操作の同時保存 | getとputのように同じcarrierを複数回使う図式では、コピー間の同じ変更と積上の誘導写像を揃える |
| 完全幾何 | context、coverage、overlap、係数、raw restriction、Support・Axis・Observableを構成して、射の保存則を証明する |
| G-122の比較 | 実生成`barAlpha`・`barBeta`、冪等射、底を固定する資格、section、二種類の核を、n1014 §5の同じ入力で対応させる |

§2.3の二つの図式が共有する変更を、比較群への接続で保持する。
getだけの一射へlensを写すと(L7)を識別できない。getとputを一つの比較にまとめる場合は
`c_L:C⊔(C×V)→V⊔C`を使い、二つの成分をそれぞれgetとputで定める。
その端点変更を`h⊔(h×u)`と`u⊔h`に限定した比較群は(L5)に一致する。
このコピー間の連動条件を、単なる底固定と同一視せず、許容変更の部分群として構成する。

ここでのCSの許容射は、型、source/target、操作名、Law、観測、必要な選択値の保存から
独立に定める。この保存条件を完成したdecoderの像で置き換えない。
G-122の固定入力について全比較群を運ぶ要求はカードDが担い、CSの許容部分群だけへ
その要求を縮めない。完全幾何への構成は、両者を同じAの宣言へ収録する仕事として残る。

### 5.4 共通分類への二つの代入

積lensでは、制御点を`V`、辺を全ての組`(v,w)`とし、辺の作用を
`(v,k)↦(w,k)`にする。可視変更`u`は辺に`(v,w)↦(u(v),u(w))`として作用する。
このグラフは`v₀`を持ち連結なので、(C2)の核は`Sym(K)`となる。
sectionを保つ版では`k₀`の固定部分群に置き換える。

プロトコルでは、各制御点の状態を同じ`K`、各生成辺の状態作用を`id_K`とする
セッションモデルを使う。観測先を各頂点で一元集合とし、状態全体から制御点への
投影を可視なadapterと読む。頂点ごとの補完置換が辺に沿って一致することが操作保存になり、
(C2)の連結成分ごとの核を得る。操作名を動かす変更はグラフ自己同型を通して運ぶ。
Eの一般プロトコル族のうち、このセッションモデルへFを適用する。

## 6. 論文への配置と帰属

二つのCSのdecoderは、設計上、Karoubi化前から圏同値を与える。
CSの節では独立した意味と生成データの対応を説明し、Karoubiの一般原理は
AATの正規化された実現・比較へ同じ再構成を広げるところで用いる。

| 配置 | 読者が得るもの |
| --- | --- |
| 導入 | 読み出し結果は保たれるのに更新との整合が壊れる(L7)を、モデル同期の問いとして提示 |
| 第1・4章 | CSの入力と射からAtom・Law・operationへの対応、および変更の合成 |
| 第6・7章 | 操作を保持すると追随変更の自由度がどう決まるかを(C1)・(C2)で説明 |
| 第8章 | 独立な意味から表示を構成し、同じ分類を表示側で回復することを証明 |
| 付録 | 具体例の計算、Lean宣言、固定版の出典、検証記録 |

新規性の検討では、lensの法則・定数補完、schemaの関手意味論、一般の核とtorsorの結果を
既存研究に帰属させる。AATで追加する候補は、Atom・Law・完全幾何からの独立な構成、
観測が忘れる変更の識別、生成比較と有限表示を通じた同じ変更分類への接続である。
この接続の証明と、先行研究との定理単位の比較を揃えて、論文の貢献を確定する。
