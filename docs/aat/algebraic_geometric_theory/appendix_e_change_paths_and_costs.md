# 付録E 変更経路と費用の問題

本付録では、第8章で構成した許された一段変更の経路に対して費用を割り当て、最適経路およびその下限を局所合成や再構成の下で回復するための問題を定式化する。

[第8章](part_3/chapter_8_constrained_changes_and_completions.md#84-許された一段階の変更と経路)の許された一段変更とその接続同型から、有限長の経路を構成する。
一段変更の費用を、比較同型に関して不変な関数 $`c:\mathop{\mathrm{Ob}}\nolimits\mathcal E\to[0,\infty]`$ によって指定する。
有限長の経路 $`\gamma=(e_1,\ldots,e_n)`$ の費用を $`c(\gamma)=\sum_{i=1}^n c(e_i)`$ と定め、長さ $`0`$ の経路の費用は $`0`$ とする。

固定された端点、固定図式、および途中と終端の評価条件を満たすすべての経路にわたって、最小費用の下限を

```math
d(a,b)=\inf\{c(\gamma):\gamma\text{ は指定条件を満たす }a\text{ から }b\text{ への経路}\}
```

と定める（条件を満たす経路が存在しない空集合の下限は $`\infty`$ とする）。
途中の評価条件が経路の接続を許す場合には、経路の連結に対して費用が加法的に振る舞う。
一方、下限 $`d(a,b)`$ を実際に達成する最小費用の経路が存在するためには、その経路族に関する追加条件が必要である。
たとえば、1点から別の1点へ費用 $`1/n`$（$`n=1,2,\ldots`$）の辺が無限本ある場合には、下限は $`0`$ であるが費用 $`0`$ を達成する経路は存在しない。

**問題E.1（局所合成と最適経路の回復）.**
原始的な許容規則、固定条件、および一段変更の費用を入力として与えたとき、次の三つを特徴づけよ。

1. 局所の経路と接続同定から大域経路を組み立てるとき、共有部分の重複を含めて費用を正確に計算し、すべての経路とその費用を回復するための条件。
2. 表示変更および係数変更の下で、すべての経路の比較が費用を保存し、下限値 $`d(a,b)`$ とそれを実現するすべての経路およびすべての比較を回復するための条件。
3. 候補の有限性・非負費用・到達可能性の下で有限時間に停止する最適化手順、および無限の経路族において下限が実際に達成されるための条件。

第19章におけるすべての解からなる族の比較に費用評価を組み込み、両方向の経路比較が費用を保つならば、対応する経路の費用集合が一致するため下限値 $`d(a,b)`$ も等しくなる。
さらに、両方向の比較が費用を保つ経路 groupoid の圏同値を与えるならば、最小値を実現する対象とその間のすべての比較射がなす部分 groupoid も、同じ費用値を持つファイバーへの制限として圏同値に対応する。
この一般的な観察を実際の構成へ適用するための原始費用と局所合成条件を整備することが、問題E.1の主眼である。
なお、第18章で扱った問い合わせ数は、指定された評価行為の個数を費用とする別種の出力問題であり、同章でその最適値を証明している。
