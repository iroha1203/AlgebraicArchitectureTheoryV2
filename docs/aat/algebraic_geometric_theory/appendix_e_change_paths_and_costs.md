# 付録E 変更経路・移行幅・費用

許された一段変更の規則から、経路の費用、同時変更の幅、一時的な接続資源を構成する。有限移行での資源の下限と達成、有限状態グラフでの最適語、時間を含む局所データからの最適経路groupoidの回復を扱う。

## E.1 許容経路と一般の再構成問題

[第8章](part_3/chapter_8_constrained_changes_and_completions.md#84-許された一段階の変更と経路)の一段変更と接続同型から有限長の経路を構成する。一段変更の費用を、比較同型で不変な関数 $`c:\operatorname{Ob}\mathcal E\to[0,\infty]`$ によって指定し、経路 $`\gamma=(e_1,\ldots,e_n)`$ の費用を $`c(\gamma)=\sum_i c(e_i)`$ とする。長さ零の経路の費用は零である。途中と終端の評価条件を満たす経路について

```math
d(a,b)=\inf\{c(\gamma):\gamma:a\rightsquigarrow b\}
```

と置き、空集合の下限は $`\infty`$ とする。有限費用の最適化は $`d(a,b)<\infty`$ となる端点対を対象とする。無限本の平行辺の費用が $`1/n`$ である例では下限は零だが達成されない。

**問題E.1（局所合成と最適経路の回復）.**
原始的な許容規則・固定条件・費用から、局所経路の合成、費用の正確な加算、表示変更・係数変更との比較、最適経路の達成、およびすべての最適経路と比較射の回復を特徴づけよ。有限の状態グラフでの最適化は定理E.5、時間を含む有限の局所データからの回復は定理E.6で扱う。一般の無限候補、局所データだけから長さを制限せず行う再構成、および任意の理論間の普遍的な最小拡張については、これらの有限の構成を越える問題が残る。

## E.2 Law・同時変更数・一時資源

Lawを満たすかどうかは、指定された残差または障害類によって判定する。一方、同時に何個の部品を変えられるかと、その途中で必要な一時資源は許容する一段変更に属するデータである。

**例E.2（コホモロジーの次元はLaw違反量ではない）.**
一頂点・一ループ・面なしの表示で係数を体 $`k`$、輸送を恒等とすると
$`C^0=k,\ C^1=k,\ C^2=0,\ d^0=0`$
なので $`H^1=k`$ である。しかしループの実際の操作を恒等とした実現には、課したすべてのLawを満たす定数経路が存在する。従って $`\dim H^1>0`$ はLaw違反を意味しない。第11章の可否判定も、群の次元ではなく指定類 $`[\delta]`$ の零性を用いている。

**設定E.3（名前付き接続を使う有限移行）.**
有限単純無向グラフ $`G=(V,E)`$ の頂点を部品とし、各頂点の相を $`s_v\in\{0,1\}`$ とする。各辺 $`e=\{u,v\}`$ には、必要なときだけ有効にできる名前付きの接続 $`a_e\in\{0,1\}`$ を置く。原始Lawは

```math
a_e=0\ \Longrightarrow\ s_u=s_v.
```

この有限のLawは $`\mathbb F_2`$ 上では $`(1-a_e)(s_u-s_v)=0`$ と書ける。以下ではこの有限集合上の実現を扱う。

状態を、移行済み頂点 $`M=\{v:s_v=1\}`$ と有効な接続 $`A=\{e:a_e=1\}`$ の対 $`(M,A)`$ で表す。始状態は $`(\varnothing,\varnothing)`$、終状態は $`(V,\varnothing)`$ とする。一段変更は、未移行の非空集合 $`B\subseteq V\setminus M`$ を一度に移行し、同じ一段の中で接続集合を $`A'`$ へ更新する操作

```math
(M,A)\longrightarrow(M\cup B,A').
```

両端でLawを満たすことを要求し、幅は $`|B|`$、資源量は状態ごとの $`|A|`$ と定める。接続の更新はこの一段変更に含まれる原始操作であり、頂点の幅には数えない。接続を別の時間にしか更新できない規則を課す場合は、別の経路問題となる。

**定理E.4（移行幅と接続資源の厳密な最小値）.**
$`w\ge1`$ を固定する。頂点集合の順序付き分割 $`V=B_1\sqcup\cdots\sqcup B_\ell`$、$`1\le|B_i|\le w`$ に対して
$`M_i=B_1\cup\cdots\cup B_i`$ と置く。また
$`\partial_GM=\{\{u,v\}\in E:|\{u,v\}\cap M|=1\}`$
を両相を結ぶ辺の集合とする。幅が高々 $`w`$ の移行経路で必要な一時資源の最小ピークは

```math
b_w(G)=
 \min_{(B_1,\ldots,B_\ell)}
       \max_{0\le i\le\ell}|\partial_GM_i|.
```

$`V=\varnothing`$ では値を零とする。$`w=1`$ の値は、頂点順序の各前半集合を横切る辺数の最大値を最小化する量、すなわちグラフのcutwidthである。

**証明.**
原始Lawを辺ごとに読むと、状態 $`(M,A)`$ がLawを満たすことと $`\partial_GM\subseteq A`$ とは同値である。任意の移行経路の各頂点は一度だけ相を変えるので、各段の移行集合は上の順序付き分割をなす。その各状態で
$`|A_i|\ge|\partial_GM_i|`$
となるから、どの経路のピークも右辺以上である。

逆に任意の順序付き分割に対し、各段で接続を
$`A_i=\partial_GM_i`$
へ更新する。これは設定E.3の許容操作であり、全状態でLawを満たす。始点と終点の接続は空で、ピークはちょうどその分割の値となる。分割は有限個なので最小値は達成される。□

接続を一切使わない場合、非空な連結グラフのLawを満たす状態は全頂点が相零または相一の二つだけである。したがって $`|V|>w`$ なら移行不能である。これは道グラフでも成り立つ。局所的に単純な依存関係でも、許容幅が小さく接続を使えなければ移行は妨げられる。一方、$`V\ne\varnothing`$ と接続予算 $`b\ge0`$ を与えたときの必要幅は、有限個の $`w=1,\ldots,|V|`$ のうち $`b_w(G)\le b`$ となる最小値として正確に求まる。

## E.3 有限状態グラフの最適化

**定理E.5（有限グラフの資源・費用・すべての最適語）.**
Lawと評価条件を満たす状態を有限集合 $`S`$、許された原始的一段変更を有限有向多重グラフの辺とする。各辺に非負有理数費用 $`c(e)`$ と非負整数幅 $`w(e)`$、各状態に非負整数資源 $`r(s)`$ を与える。始点 $`a`$、終点 $`b`$ と最大幅を指定し、その幅を越える辺を除く。

到達可能なら、経路上の最大資源の最小値 $`\rho_*`$ は達成される。さらに資源が $`\rho_*`$ 以下の経路の中で費用の最小値 $`d_*`$ も達成される。両値と一つの達成経路は有限時間で計算できる。加えて、資源制限後のグラフから、費用最小の経路語をすべて生成する有限有向グラフを構成できる。

**証明.**
資源の候補値は有限集合 $`\{r(s):s\in S\}`$ である。各閾値 $`\rho`$ について、$`r(s)\le\rho`$ の状態が誘導する部分グラフで $`a`$ から $`b`$ への到達可能性を有限探索する。最初に到達できる閾値が $`\rho_*`$ であり、その探索が達成経路を与える。

以後この部分グラフに固定する。経路が同じ頂点を二度通るなら、その間の閉路を削除しても両端と許容性は保たれ、非負費用により費用は増えない。従って到達可能な両端について、辺数が高々 $`|S|-1`$ の単純経路（$`a=b`$ なら長さ零）が最小値を達成する。これらは有限個なので列挙でも $`d_*`$ を計算できる。

すべての最適語のためには、閉路を一律に削除してはならない。零費用の閉路を何度でも通る最適経路があり得るからである。各頂点について最小費用 $`d_a(s)`$ と $`d_b(s)`$ を、それぞれ $`a`$ から、または $`b`$ へ向かう距離として計算する。有限距離を持つ辺のうち

```math
d_a(s)+c(e)+d_b(t)=d_*,\qquad e:s\to t
```

を満たすものだけを残す。

最適経路の各接頭・接尾経路は最短でなければ、より短いものへの交換で全体費用を下げられる。従ってその全辺は残る。逆に残した辺では、距離の三角不等式
$`d_a(t)\le d_a(s)+c(e)`$ と
$`d_*\le d_a(t)+d_b(t)`$
から $`d_a(t)=d_a(s)+c(e)`$ が従う。残したグラフ上の任意の $`a`$-$`b`$ 経路でこの等式を足すと、費用は $`d_a(b)-d_a(a)=d_*`$ となる。よってこの有限グラフは、零費用閉路も含めてすべての最適語を正確に生成する。□

## E.4 時間を含む局所合成と全最小解

空間の局所経路だけを連結すると、共有部分での時刻や接続同型が食い違うことがある。そこで有限の時間列 $`0,\ldots,H`$ を含めて、状態、各時刻間の一段変更、接続同型、端点同定、および固定条件を原始変数として保持する。

具体的には、選んだ有限実現族の各担体・操作・比較射を有限表で与え、第8章の許容記録と第19章の原始式を評価する。各変数 $`v`$ の値集合を有限集合 $`X_v`$ とし、各Lawと自然性式を、その式が読む変数集合上の有限関係とする。一段変更の費用も、その原始記録を読む非負有理数値の局所関数 $`c_\alpha`$ とする。各費用関数はその局所記録の比較同型に関して不変とする。

変数の有限集合を覆う袋 $`B_t`$ を有限木の頂点 $`t`$ に置き、次を要求する。各関係と各費用関数の支持は一つの袋に含まれ、各変数を含む袋の集合は連結である。後者をrunning-intersection条件と呼ぶ。各関係と費用関数を、それを含む袋のうち一つだけに割り当てる。すべての変数を含む一つの袋は常にこの条件を満たすが、小さな袋への分解が計算量を減らす。

**定理E.6（局所費用の合成と最適経路groupoid）.**
上の有限の原始入力から、長さ $`H`$ の許容経路の最小費用と、その値を達成するすべての対象を、局所表の最小化と加算によって回復できる。さらに、原始比較射の有限表とその自然性式から、最適対象間のすべての比較射・恒等射・合成を回復できる。従って最適経路groupoid全体を回復できる。空の経路族の値は $`\infty`$ とする。

**構成と証明.**
木に根を選び、非根頂点 $`t`$ の親を $`p(t)`$、共有変数を
$`S_t=B_t\cap B_{p(t)}`$
とする。根の $`S_t`$ は空とする。袋の代入 $`x\in\prod_{v\in B_t}X_v`$ について、そこに割り当てた関係を一つでも破れば $`C_t(x)=\infty`$、すべて満たせば $`C_t(x)`$ をそこに割り当てた費用関数の和とする。共有変数の代入 $`\sigma`$ に対して、葉から順に

```math
D_t(\sigma)=
 \min_{\substack{x\in\prod_{v\in B_t}X_v\\x|_{S_t}=\sigma}}
 \left(C_t(x)+\sum_{u:\,p(u)=t}D_u(x|_{S_u})\right)
```

を計算する。$`\min`$ と $`+`$ は $`[0,\infty]`$ のmin-plus演算であり、空の最小値は $`\infty`$ である。

$`t`$ の部分木と残りの木の両方に現れる変数は、running-intersection条件により $`S_t`$ に属する。また異なる子の部分木に共通の変数は $`B_t`$ に属する。従って子の代入どうしを貼り合わせる条件は、式中の共有値の一致だけで尽くされる。各関係は支持を含む一つの袋で検査され、各費用も一度だけ加算される。葉からの帰納法により $`D_t(\sigma)`$ は、その共有値を持つ部分木全体の許容代入の最小費用となる。根の値が全体の最小費用である。

各有限の最小値を達成する袋の代入を一つに絞らず、すべて保存する。$`D_t(\sigma)=\infty`$ の項目には許容代入がないので何も保存しない。根が $`\infty`$ なら経路groupoidは空である。根の値が有限なら、共有値を伝えて保存した代入を組み合わせると、すべての最適な全体代入を得る。逆に全体最適代入のある部分木が、その共有値で最小でなければ、より小さい代入への置換で全体費用を減らせる。従ってすべての全体最適代入はこの手順に現れる。

ここで代入を経路へ戻す操作を明示する。各時刻の操作表から状態を復元し、一段変更の記録から操作・翻訳・固定同定を取り出す。すべての原始Lawと保存式を検査したので、これらは第8章の一段変更となる。共有時刻の一致と接続同型の自然性式から順に合成でき、端点条件も保持される。逆に実際の経路をこれらの有限表へ読み出せば同じ代入に戻る。これは定理19.2・19.5の原始再構成を時間列へ適用した対応であり、完成した経路の集合を入力として仮定してはいない。

最後に、二つの最適対象を固定する。比較射の各原始成分を、その始域・終域を持つ可逆射の有限表から選ぶ変数とし、操作との自然性、接続同型との可換性、および端点・固定部分の条件を有限関係として課す。この変数と関係にも支持を含む木の袋を作る（一つの袋でもよい）。費用をすべて零とする上の組み立ては、条件を満たすすべての比較の成分を列挙する。成分の読み出しが同じ射を分離し、自然性式があるので組み立てた成分は実際の経路比較を与える。恒等、逆元、合成は原始射の表の成分ごとの演算であり、各自然性式を保つ。従って対象の同型類だけでなく全groupoidが戻る。費用の比較不変性により、最適対象の全体は同型で閉じている。□

長さが高々 $`H`$ の場合は、各長さ $`0,\ldots,H`$ の有限表を作って最小値を比較すればよい。許容されていない待機操作を勝手に追加する必要はない。定理E.5は有限の全体グラフについて長さを制限せず扱い、定理E.6は時間を明示した局所入力について全比較まで扱う。両者の対象は異なり、問題E.1の一般の無限経路族を解決したことにはならない。

## E.5 理論間の接続と最小性の種類

理論解釈 $`u:\mathbb T\to\widetilde{\mathbb T}`$ は、定理2.4により反対向きのモデル関手 $`u^*:\mathcal A_{\widetilde{\mathbb T}}\to\mathcal A_{\mathbb T}`$ を誘導する。従って共通の拡張理論を使う比較は

```math
\mathbb T\xrightarrow{u}\widetilde{\mathbb T}
       \xleftarrow{v}\mathbb T',
 \qquad
 \mathcal A_{\mathbb T}\xleftarrow{u^*}
       \mathcal A_{\widetilde{\mathbb T}}
       \xrightarrow{v^*}\mathcal A_{\mathbb T'}
```

という向きを持つ。この図式だけで、端点の持ち上げ、許容経路、費用の保存、または最小性が得られるわけではない。

**命題E.7（接続の具体的な最小性と費用比較）.**
設定E.3で相集合 $`M`$ を固定し、Lawを満たす接続集合を包含で順序づける。この順序集合の最小元は一意に $`\partial_GM`$ である。したがって、固定した頂点の移行順序に対しては、各段の接続をこの最小元にすることで成分ごとに最小の接続列を得る。全順序にわたる資源ピークの最小化は、これとは別に定理E.4の値を与える。

また、二つの経路groupoidの間に、端点と固定条件に整合し費用を保つ圏同値が構成されていれば、費用の値集合と下限は等しく、最小値を達成する対象の全充満部分groupoidも同値である。この条件は、原始状態・一段変更・接続同型・比較射の名前を全単射で変え、Law・合成・端点と各費用関数を保つ表示同型から構成できる。

**証明.**
第一の主張は、各辺の原始Lawが $`\partial_GM\subseteq A`$ と同値であることから従う。包含の順序圏では、$`\partial_GM`$ から各許容 $`A`$ への射がちょうど一つ存在するので、これはこの指定された接続族における始対象でもある。移行順序を固定すれば各段で同じ議論が適用できる。

第二の主張では、圏同値 $`F`$ が対象の費用を保ち、費用が同型で不変なので、任意の対象 $`y`$ と $`Fx\cong y`$ を与える本質的全射性から逆向きにも同じ費用値が得られる。したがって値集合と下限が等しい。最小値を持つ場合、$`F`$ と準逆はその値の対象へ制限され、充満忠実性と単位・余単位もそのまま制限されるので最適部分groupoidが同値になる。

原始表示同型の場合、各有限経路の全成分へ名前の全単射を適用し、比較射の成分にも同じ操作を行う。Lawと合成の保存により経路と射が得られ、逆の全単射が逆関手を与える。費用は各一段の対応で一致するため総和も一致する。これで上の費用比較条件を原始入力から構成できる。□

ここでの最小元は、名前付き接続を持つ指定された有限族における最小性である。任意の理論 $`\mathbb T,\mathbb T'`$ に対する共通拡張の普遍的な最小性には、拡張間の射、保持する観測、端点の解釈、および比較の同一視を別に定義する必要がある。その一般問題は問題E.1に含める。
