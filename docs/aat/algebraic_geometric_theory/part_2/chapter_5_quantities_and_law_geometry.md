# 第5章 量とLawから生じる相対幾何

状態の構造を固定したままでも、その上で観測・評価する量は独立に動かすことができる。この章では、まず量を関数として直接定義し、その関数が等式 Law を満たす条件から座標代数、普遍量、および普遍残差を構成する。次に、その量モデル関手がアフィンスキームで表現されることと、通常の可換代数や冪零方向がこの枠組みから回復されることを示す。最後に、構造射に沿う量の引き戻しと、関数として与えられた元の残差をすべての係数環へ正則に拡張する分類問題を扱う。

## 5.1 固定構造上の量モデル

まず、基礎環 $`k`$ と状態側の構造 $`S`$ を固定する。なお、この章の $`S`$ は構造を表す記号であり、第1章で用いた sort 集合の記号とは区別する。構造 $`S`$ には状態担体、操作、関係、および必要な部分操作の定義域を含めるが、量の値はこれらとは独立に選ぶ。

**定義5.1（固定定義域の量と等式 Law）.**
量の小さい添字集合 $`J`$ と、各量 $`j\in J`$ に対する小さい定義域 $`D_j(S)`$ を与える。

- $`k`$-代数 $`R`$ における **量モデル候補** とは、関数の族

  ```math
  q_j:D_j(S)\longrightarrow R\qquad(j\in J)
  ```

  をいう。
- 各等式 Law $`\ell`$ には、小さい入力集合 $`E_\ell(S)`$ と、各入力で評価される二つの有限式 $`t_\ell,t'_\ell`$ を指定する。これらの式は、$`k`$ の係数、環演算、および量の適用 $`q_j(u)`$ から組み立てる。ここで $`u`$ は固定構造 $`S`$ の操作から作られる項（term）であって、指定された Law 入力上で定義され、$`D_j(S)`$ の元を返すものとする。入力集合 $`E_\ell(S)`$ と状態項 $`u`$ の値は、量の選択には依存しない。
- Law $`\ell`$ は、すべての入力 $`e\in E_\ell(S)`$ に対して等式 $`t_\ell(q,e)=t'_\ell(q,e)`$ が成り立つことを要求する。

この定義は、第1章で導入した等式 Law のうち、入力集合と必要な定義可能性の条件が固定構造 $`S`$ だけから決まる場合に相当する。したがって、入力は $`E_\ell(S)=I_\ell^{(S,q)}=J_\ell^{(S,q)}`$ となるように指定している。量を動かすと真偽が変わる条件を前件に置く場合や、量の値に応じて部分操作の定義域が変わる場合には、その条件を表す別の表示が必要となる。

すべての必須 Law を満たす量モデル候補の族の集合を $`\mathrm{QMod}_S(R)`$ と書く。環射 $`\alpha:R\to R'`$ は合成によって写像 $`q_j\mapsto\alpha\circ q_j`$ を誘導する。有限式の構造帰納法により、残差も $`\alpha`$ でそのまま移るため、これはモデルをモデルへ送る。恒等射と合成の法則は関数合成の結合律から従い、$`\mathrm{QMod}_S`$ は $`k`$-代数の圏から集合の圏への関手となる。この段階の定義には、座標環やスキームを一切用いていない。

## 5.2 普遍量・残差・生成イデアル

次に、量モデルの関手 $`\mathrm{QMod}_S`$ を代数的に表示するため、各量と各入力に形式変数を割り当てた周囲環、普遍量、および普遍残差を構成する。

**構成5.2（量の座標と元の式の評価）.**
量の添字と定義域をまとめたタグ付き索引集合 $`L_S=\coprod_{j\in J}D_j(S)`$ を取り、自由加群 $`Q_S`$ と多項式環 $`A_S`$ を次のように構成する。

**式(5.1)**

```math
Q_S=\bigoplus_{(j,x)\in L_S}k e_{j,x},\qquad
A_S=\mathrm{Sym}_k Q_S=k[t_{j,x}\mid(j,x)\in L_S]
```

量の宣言名 $`j`$ を索引に含めているため、同じ定義域を持つ異なる量も座標上で区別される。**普遍量** を $`q_j^{\mathrm{univ}}(x)=t_{j,x}`$ と定める。元の式に現れる状態項を固定構造 $`S`$ で評価し、量の適用を対応する変数 $`t_{j,x}`$ に置き換えて環演算を行うことにより、**普遍残差** と **残差イデアル** を

**式(5.2)**

```math
\rho_\ell(e)=t_\ell(q^{\mathrm{univ}},e)-t'_\ell(q^{\mathrm{univ}},e)\in A_S,
\qquad I_S=(\rho_\ell(e)\mid\ell\text{ は必須},\ e\in E_\ell(S))
```

と定める。各多項式 $`\rho_\ell(e)`$ に現れる変数と項の個数は有限であるが、イデアル $`I_S`$ の生成元の総数が有限であることは仮定しない。同じ入力を何度も使う式では、同じ変数を繰り返して用いる。なお、残差を線形写像として記録するときには、$`C_k(E_\ell(S))\to A_S,\ e_\gamma\mapsto\rho_\ell(\gamma)`$ と表す。

これらから、周囲空間 $`X_S`$、Law を課した空間 $`M_S`$、および閉埋込み $`i_S`$ を

```math
X_S=\mathrm{Spec}\,A_S,\qquad M_S=\mathrm{Spec}(A_S/I_S),
\qquad i_S:M_S\hookrightarrow X_S
```

と定める。以後の幾何的解析に備えて、周囲環 $`A_S`$、名前付き残差族 $`(\rho_\ell(e))`$、イデアル $`I_S`$、および包含 $`i_S`$ を一体として保持する。追加の Law を課す場合には、その残差が生成するイデアルを $`I_S`$ に加える。

普遍残差 $`\rho_\ell(e)`$ が、任意の具体的な量モデル候補 $`q`$ における元の式の差を正確に再現することを、次の補題で確認する。

**補題5.3（元の式と普遍残差の評価）.**
任意の量モデル候補 $`q=(q_j)`$ に対し、$`t_{j,x}\mapsto q_j(x)`$ によって一意な $`k`$-代数射 $`\mathrm{ev}_q:A_S\to R`$ が定まり、すべての Law $`\ell`$ と入力 $`e\in E_\ell(S)`$ に対して

**式(5.3)**

```math
\mathrm{ev}_q(\rho_\ell(e))
 =t_\ell(q,e)-t'_\ell(q,e)
```

が成り立つ。さらに、この等号は係数変更および定義可能な状態項の代入に関して自然である。

**証明.**
多項式環 $`A_S`$ の構成と普遍性は[補題B.2](../appendix_b_coefficients_and_descent.md#b1-係数とアフィン構成)により与えられ、各変数の像 $`t_{j,x}\mapsto q_j(x)`$ から一意な $`k`$-代数射 $`\mathrm{ev}_q`$ が定まる。状態項の値は固定構造 $`S`$ 上であらかじめ一意に決まり、式の葉である量の適用 $`q_j(u)`$ と係数の葉では $`\mathrm{ev}_q`$ の評価と直接の評価が定義により一致する。加法・逆元・積についても環射 $`\mathrm{ev}_q`$ が環演算を保つため、式の構造に関する帰納法によって式(5.3)が従う。

状態項への代入については、[定理1.8](../part_1/chapter_1_atoms_laws_theories.md#14-表示代入理論の射)により同じ入力値が返されるため評価が一致する。係数変更 $`\alpha:R\to R'`$ についても、すべての葉において $`\alpha\circ\mathrm{ev}_q`$ と $`\mathrm{ev}_{\alpha\circ q}`$ が同じ値を返すので、式全体でも一致する。□

この結果により、点 $`A_S\to R`$ は宣言 $`j`$ と入力 $`x`$ を備えた具体的な量 Atom $`(j,x,q_j(x))`$ を復元する。Law の式における各出現も同じ構造帰納法で評価できる。座標変数 $`t_{j,x}`$ が宣言名と入力を保持しているため、値が偶然等しい異なる量 Atom を混同することはない。

## 5.3 表現と通常のアフィン幾何の回復

補題5.3を用いれば、量モデル関手 $`\mathrm{QMod}_S`$ がアフィンスキーム $`M_S=\mathrm{Spec}(A_S/I_S)`$ によって表現されることが直ちに示せる。さらに、周囲空間 $`X_S`$ への射が Lawful locus $`M_S`$ を経由するための必要十分条件を与え、通常の可換代数や冪零方向がこの構成から自然に現れることを具体例で確認する。

**定理5.4（量・Law モデルの相対表現）.**
定義5.1の任意の小さい定義域族および Law 族に対し、すべての $`k`$-代数 $`R`$ において自然な全単射

**式(5.4)**

```math
\mathrm{QMod}_S(R)
\ \cong\ \mathrm{Hom}_{k\text{-}\mathrm{Alg}}(A_S/I_S,R)
\ \cong\ \mathrm{Hom}_k(\mathrm{Spec}\,R,M_S)
```

が成り立つ。特に、$`A_S/I_S`$ における変数の剰余類 $`\overline t_{j,x}`$ からなる量は普遍モデルを与える。

**構成と証明.**
まず第一の全単射を示す。量モデル $`q\in\mathrm{QMod}_S(R)`$ に対し、補題5.3の評価射 $`\mathrm{ev}_q:A_S\to R`$ を構成する。すべての必須 Law の成立は、式(5.3)によりすべての生成元 $`\rho_\ell(e)`$ の像が 0 であることと同値であり、イデアルの定義から $`I_S`$ 全体が 0 へ送られることと同値である。したがって $`\mathrm{ev}_q`$ は一意な商環の射 $`A_S/I_S\to R`$ を経由する。

逆に、商環の射 $`v:A_S/I_S\to R`$ が与えられたとき、$`q_j(x)=v(\overline t_{j,x})`$ と定める。補題5.3と残差の剰余類が 0 であることから、この $`q`$ はすべての必須 Law を満たす。二つの構成はすべての変数の像を保つため互いに逆である。環射 $`R\to R'`$ との合成もすべての変数上で一致し、自然性が従う。第二の全単射と一般のスキーム上での貼り合わせは[補題B.2](../appendix_b_coefficients_and_descent.md#b1-係数とアフィン構成)による。最後に恒等環射 $`\mathrm{id}_{A_S/I_S}`$ を読むことで普遍モデルが得られる。□

一般の試験 $`k`$-スキーム $`T`$ に対しては、量を大域切断への写像 $`q_j:D_j(S)\to\Gamma(T,\mathcal O_T)`$ として定義し、同じ Law を課すことができる。これは各アフィン開集合上の量モデルが重なり上で一致することと同値であり、各変数ごとに切断を貼り合わせれば一意なスキーム射 $`T\to M_S`$ を得る。無限個の量が存在する場合であっても、切断の貼り合わせは変数ごとに独立して行える。

**定理5.5（Lawful locus への一意な因子分解）.**
任意の試験スキーム $`T`$ と周囲空間への射 $`p:T\to X_S`$ に対して、次の三つの条件は同値である。

1. $`p`$ から読み出される量のすべての必須残差が、$`\mathcal O_T`$ の切断として 0 である。
2. 引き戻し写像 $`p^{-1}\widetilde I_S\to\mathcal O_T`$ の像が生成するイデアル層が 0 である。
3. $`p=i_S\circ\bar p`$ となるスキーム射 $`\bar p:T\to M_S`$ が一意に存在する。

**証明.**
まず各アフィン開集合 $`W\subseteq T`$ 上で補題5.3を適用すると、$`p|_W`$ から読み出される具体的な残差は $`p^*\rho_\ell(e)`$ に一致する。生成元 $`p^*\rho_\ell(e)`$ がすべて 0 であることは、それらの生成するイデアルが 0 であることと同値なので、1 と 2 は同値である。また、アフィン開集合上で対応する環射が商環 $`A_S/I_S`$ を経由することもこれと同値であり、因子分解はアフィン開集合上で一意に定まる。アフィン開集合の重なり上では一意性により局所的な因子分解が一致して貼り合うため、2 から 3 が従う。逆に 3 が成り立てば、$`i_S`$ に対応する環射が $`I_S`$ のすべての生成元を 0 へ送るため 1 が従う。□

条件 2 で用いているのはイデアル層の写像の **像** である点に注意する。加群の引き戻し $`p^*\widetilde I_S`$ そのものが零加群になることは要求していない。

次に、この枠組みが通常のアフィン幾何のすべての対象をそのまま回復することを確認する。

**例5.6（可換代数と対称代数の回復）.**
任意の可換 $`k`$-代数 $`B`$ の台集合を定義域とする一つの量 $`q:B\to R`$ を考え、すべての $`b,c\in B`$ と $`a\in k`$ に対して

```math
q(b+c)=q(b)+q(c),\quad q(bc)=q(b)q(c),\quad
q(1)=1,\quad q(a1_B)=a
```

という等式 Law を課す。$`t_b\mapsto b`$ は $`k`$-代数射 $`A_B/I_B\to B`$ を定め、逆に $`b\mapsto\overline t_b`$ は上の関係式によって $`k`$-代数射 $`B\to A_B/I_B`$ を定める。両合成はすべての $`b\in B`$ およびすべての生成元 $`\overline t_b`$ で恒等となるため、$`A_B/I_B\cong B`$ である。こうして任意の可換代数のアフィンスキームとすべての環射がこの構成から回復される。

同様に、任意の $`k`$-加群 $`N`$ について、量 $`q:N\to R`$ に加法性とスカラー倍の保存 $`q(m+n)=q(m)+q(n)`$、$`q(am)=a\,q(m)`$ を課すと、自由加群 $`k^{(N)}`$ をこの線形関係で割った加群が $`N`$ となる。多項式環を同じ線形関係で割った環は対称代数 $`\mathrm{Sym}_k N`$ であり、普遍線形写像 $`N\to\mathrm{Sym}_k N`$ と変数 $`t_m`$ の対応から互いに逆な代数射を構成して確かめられる。

**例5.7（逆元と冪零方向）.**
一点定義域を持つ二つの量 $`x,y`$ に Law $`xy=1`$ を課すと、座標環は $`k[x,y]/(xy-1)\cong k[x,x^{-1}]`$ となる（同型は $`y\mapsto x^{-1}`$ と $`x^{-1}\mapsto y`$ で与えられる）。また、一点定義域の量 $`t`$ に Law $`t^2=0`$ を課すと、座標環は $`k[t]/(t^2)`$ となる。体上の点 $`t=0`$ の上には、双対数環 $`k[\varepsilon]/(\varepsilon^2)`$ において $`t\mapsto a\varepsilon`$ とするすべての持ち上げが存在する。このように、状態構造が固定された離散構造であっても、量の側に微小方向が生じる。

この例では、周囲環 $`k[t]`$ の中のイデアル $`I=(t^2)\subset k[t]`$ をあらかじめ保持している点が重要である。Law を満たす点上で残差を評価すると値は 0 になるが、普遍余法加群 $`I/I^2=(t^2)/(t^4)`$ を $`k[t]/(t^2)`$-加群として構成しておけば、$`t^2`$ が生成元として残る。これを $`t=0`$ の点へテンソルすると $`k`$ を得る。評価後の零イデアルから $`I/I^2`$ を作り直すとこの一次の法線情報は失われてしまう。第12章へ引き渡すのは、評価後の零値ではなく、周囲環、普遍残差、およびこの普遍イデアルである。

なお、状態の定数族 $`\underline D_k`$、量のパラメータ空間 $`\mathrm{Spec}\,k[t_x\mid x\in D]`$、および状態上の関数加群 $`k^D=\mathrm{Hom}_k(k^{(D)},k)`$ は、それぞれ役割の異なる別の対象である。量モデルの構成には任意関数を表す直和の双対を用いており、量自体に有限の台（サポート）は課していない。

## 5.4 構造射と量の引き戻し

この節では、構造射 $`h:S\to S'`$ に沿った量モデルの反変な引き戻しを構成し、続いて Law 入力の保存を課さない場合の対応空間を調べる。

**定理5.8（構造射による反変な量の比較）.**
$`S,S'`$ を、同じ量添字集合、Law 添字集合、元の式、および $`k`$ の係数を持つ二つの構造とする。第2章の意味での構造射 $`h:S\to S'`$ が各量の定義域の写像 $`h_j:D_j(S)\to D_j(S')`$ を誘導し、さらに各 Law の変数への代入を成分ごとに $`h`$ で送る写像が指定された入力集合に制限されて $`h_\ell:E_\ell(S)\to E_\ell(S')`$ を与えるとする。このとき、$`k`$-代数射 $`\phi_h`$ が

**式(5.5)**

```math
\phi_h:A_S\longrightarrow A_{S'},\quad t_{j,x}\longmapsto t_{j,h_j(x)},
\qquad
\phi_h(I_S)\subseteq I_{S'}
```

を満たして定まり、商環の Spec としてスキーム射 $`M(h):M_{S'}\to M_S`$ を誘導する。任意の係数 $`R`$ 上では、この射は量の引き戻し $`q'_j\mapsto q'_j\circ h_j`$ に一致し、恒等射・合成・係数変更と可換する。

**証明.**
多項式環の普遍性により、各変数の像 $`t_{j,x}\mapsto t_{j,h_j(x)}`$ から $`k`$-代数射 $`\phi_h:A_S\to A_{S'}`$ が一意に定まる。状態項の定義可能性とその値の保存は、構造射に関する[定理1.8](../part_1/chapter_1_atoms_laws_theories.md#14-表示代入理論の射)(2)から従う。これと量の葉の像を与える式(5.5)を組み合わせ、元の式の構造に関する帰納法を行うと、すべての $`\ell`$ と $`e\in E_\ell(S)`$ に対して $`\phi_h(\rho_\ell(e))=\rho'_\ell(h_\ell(e))`$ を得る。したがって $`I_S`$ のすべての生成元の $`\phi_h`$ による像が $`I_{S'}`$ に含まれるため、商環の射 $`A_S/I_S\to A_{S'}/I_{S'}`$ とその Spec としてのスキーム射 $`M(h):M_{S'}\to M_S`$ が定まる。任意の $`R`$-点で読むと、すべての変数の像が $`q'_j(h_j(x))`$ となり、定理5.4の対応に一致する。恒等射・合成・係数変更との可換性も各変数上で直接確認できる。□

構造射が Law 入力を保存せず、量定義域の写像 $`h_j:D_j(S)\to D_j(S')`$ だけを持つ場合でも、$`\phi_h:A_S\to A_{S'}`$ は同様に定まり、周囲空間の射 $`X_{S'}\to X_S`$ を与える。この状況では、引き戻しによって両側の Law がともに成り立つ対を集めた対応空間を次のように構成できる。

**命題5.9（量の一致を課す対応空間）.**
量定義域の写像 $`h_j:D_j(S)\to D_j(S')`$ だけを運ぶ $`h`$ に対し、アフィンスキーム

```math
Z_h=\mathrm{Spec}\left(
 (A_S/I_S)\otimes_k(A_{S'}/I_{S'})\,\big/
 (\overline t_{j,x}\otimes1-1\otimes\overline t_{j,h_j(x)})
 \right)
```

は、すべての試験スキーム上で $`q=h^*q'`$ を満たす量モデルの対 $`(q,q')`$ を表現する。第二射影 $`Z_h\to M_{S'}`$ は閉埋込みであり、

```math
Z_h\cong\mathrm{Spec}\bigl(A_{S'}/(I_{S'}+A_{S'}\phi_h(I_S))\bigr)
```

が成り立つ。したがって、$`Z_h`$ が $`M_{S'}`$ 全体からの射のグラフになることは、包含 $`\phi_h(I_S)\subseteq I_{S'}`$ と同値である。

**証明.**
テンソル積 $`(A_S/I_S)\otimes_k(A_{S'}/I_{S'})`$ からの環射は二つの量モデル $`(q,q')`$ の対を表し、追加の関係式 $`\overline t_{j,x}\otimes 1-1\otimes\overline t_{j,h_j(x)}=0`$ はまさに一致条件 $`q_j(x)=q'_j(h_j(x))`$ を表す。この関係式を用いて左側のすべての変数を右側の変数で消去すると、$`A_{S'}`$ 上に残る関係式は $`I_{S'}`$ と $`\phi_h(I_S)`$ が生成するイデアルに一致する。第二射影に対応する環射は商射 $`A_{S'}/I_{S'}\twoheadrightarrow A_{S'}/(I_{S'}+A_{S'}\phi_h(I_S))`$ であり、したがって第二射影は閉埋込みとなる。これが同型となるための必要十分条件が $`\phi_h(I_S)\subseteq I_{S'}`$ である。□

**例5.10（Law 入力の保存が必要になる場合）.**
量定義域を $`D(S)=\{a\}`$、$`D(S')=\{b\}`$、写像を $`h(a)=b`$ とする。一方、Law 入力を独立の指定部分集合として $`E(S)=\{a\}`$、$`E(S')=\varnothing`$ と取り、入力上で $`q(x)=0`$ を課す。このとき $`h`$ は量定義域を運ぶが、Law 入力 $`a`$ の像 $`b`$ は $`E(S')`$ に属さないため Law 入力を運ばない。結果として $`M_S=\mathrm{Spec}\,k`$、$`M_{S'}=\mathrm{Spec}\,k[t]`$ となり、閉埋込み $`Z_h\to M_{S'}`$ は $`t=0`$ の閉部分スキームを選び出す。基礎環 $`k`$ が非零ならば、$`M_{S'}`$ の点 $`q'(b)=1`$ を引き戻しても始域側の構造 $`S`$ の Law を満たさない。

なお、第3章の宣言を忘れる制限射では、残した量変数と Law 入力だけを読むことになる。対応する環射は変数の少ない環から変数の多い環へ向かい、Spec を取ると逆向きのスキーム射になる。他方、係数空間側の開制限は環の局所化である。同じ元の式を保持する宣言制限について、係数変更との比較射は

```math
A_{S|U}\otimes_k R\longrightarrow A_S\otimes_k R,\qquad t_{j,x}\otimes r\longmapsto t_{j,x}\otimes r
```

で与えられる。宣言を先に制限してから係数を変更しても、係数を先に変更してから宣言を制限しても、この像は完全に一致し、Law の残差も同じ多項式になる。よって商代数上でも両者は可換する。係数空間の開制限については、$`R`$ として局所化環を取ればそのまま従う。

## 5.5 残差の係数拡張

これまでは残差が最初から多項式として与えられていた。最後に、元の（native な）残差が単に集合上の関数 $`\varepsilon:D\to k`$ として与えられたときに、選んだ量 $`q:D\to k^X`$ からすべての係数環へ正則（regular）に延長できるかどうかを分類する。ここでは、すべての係数環に自然なスカラー操作が普遍入力における多項式によって一意に決まることを利用する。

**定理5.11（正則な拡張の分類）.**
任意の小さい集合 $`D,X`$、量の値の組を与える写像 $`q:D\to k^X`$、および元の残差 $`\varepsilon:D\to k`$ を固定する。$`X`$ の変数による単項式は、有限の台（サポート）を持つ指数関数 $`m:X\to\mathbb N`$ で索引づける。有限な単項式集合 $`F`$ ごとにアフィンスキーム

**式(5.6)**

```math
E_F=\mathrm{Spec}\,
k[b_m\mid m\in F]/
\left(\sum_{m\in F}b_m m(q(d))-\varepsilon(d)\ \middle|\ d\in D\right)
```

を構成する。$`F\subseteq F'`$ のときには追加された係数を 0 に置く閉埋込み $`E_F\to E_{F'}`$ を用い、アフィン試験環上の関手 $`E=\mathop{\mathrm{colim}}_F E_F`$ を定める。このとき、任意の $`k`$-代数 $`C`$ に対して、$`E(C)`$ は次の族の全体と自然な全単射を持つ。

- すべての $`C`$-代数 $`R`$ に関して自然な写像の族 $`f_R:R^X\to R`$ であって、すべての $`d\in D`$ について $`f_C(q(d)_C)=\varepsilon(d)_C`$ を満たすもの。

特に $`E(k)`$ は、元の残差 $`\varepsilon`$ のすべての正則なスカラー拡張を分類する。

**証明.**
まず任意の $`k`$-代数 $`C`$ を固定し、すべての $`C`$-代数 $`R`$ に自然な写像の族 $`(f_R:R^X\to R)`$ を考える。多項式環 $`C[t_x\mid x\in X]`$ における普遍的な組 $`(t_x)_{x\in X}`$ で $`f`$ を評価し、多項式

```math
P=f_{C[t_x]}((t_x)_x)\in C[t_x\mid x\in X]
```

を得る。任意の $`C`$-代数 $`R`$ と任意の組 $`r\in R^X`$ に対し、$`t_x\mapsto r_x`$ で定まる一意な評価環射 $`C[t_x]\to R`$ があるから、自然性により $`f_R(r)=P(r)`$ が成り立つ。逆に、任意の多項式 $`P\in C[t_x]`$ の評価は自然な族を与え、普遍的な組で評価すると元の多項式 $`P`$ に戻る。ゆえに、すべての自然なスカラー操作は一意な有限多項式に対応する。

次に、この多項式を $`P=\sum_{m\in F}b_m m`$ と表す。元の入力 $`q(d)_C`$ における値の一致条件 $`P(q(d)_C)=\varepsilon(d)_C`$ は、ちょうど式(5.6)の各関係式が 0 になることと同値である。同じ多項式の二つの表示は、それぞれの台の和集合へ移して不足係数を 0 で補えば一致する。したがって余極限 $`E(C)=\mathop{\mathrm{colim}}_F E_F(C)`$ が、条件を満たす多項式の全体を重複なく分類する。環射 $`C\to C'`$ は係数 $`b_m`$ をそのまま送るだけなので、この全単射は $`C`$ についても自然である。□

ここでいう「正則（regular）」とは、量空間全体 $`\mathrm{Spec}\,k[t_x]`$ の上の正則関数（すなわち多項式）を意味する。量の取りうる値にあらかじめ別の Law を課して閉部分スキームに制限する場合には、その座標環上の関数について同様の分類問題を立てる。定理5.11は、指定した量空間全体への拡張の分類を与えるものである。

**例5.12（非一意性と不存在）.**
正則な拡張は、基礎環やデータの性質によって非一意になったり存在しなかったりする。代表的な振る舞いを四つ挙げる。

- **有限体上の非一意性**: $`k=\mathbb F_p`$、$`D=k`$、$`X=\{x\}`$、$`q(d)=d`$、$`\varepsilon(d)=d`$ とする。多項式 $`P=t`$ と $`P=t^p`$ はともに $`E(k)`$ の点を与えるが、双対数環 $`k[\eta]/(\eta^2)`$ の入力 $`t=\eta`$ での値はそれぞれ $`\eta`$ と 0 であり、係数拡張としては異なる。
- **無限体上の不存在**: $`k=\mathbb Q`$、同じ $`D,q,X`$ に対して、残差を $`\varepsilon(0)=1`$、$`d\ne0`$ で $`\varepsilon(d)=0`$ と定める。拡張多項式が存在すれば無限個の根を持つことになるため零多項式でなければならず、$`0`$ での値 1 と矛盾する（根の個数の主張は、根 $`a`$ を持つ多項式を $`t-a`$ で割り次数に関する帰納法で従う）。したがって $`E(\mathbb Q)=\varnothing`$ である。
- **すべての入力を読む場合の一意性と消滅イデアル**: $`D=k^X,\ q=\mathrm{id}`$ のようにすべての入力を読む場合、$`k`$ が無限体ならば拡張は存在すれば一意である。実際、二つの拡張の差は有限個の変数しか含まないため、各変数について上の一変数の根の個数の議論を帰納すれば零多項式となる。一方、位数 $`N`$ の有限体 $`k=\mathbb F_N`$ では、すべての入力で消える多項式のイデアルは $`(t_x^N-t_x\mid x\in X)`$ である。実際、現れる有限個の変数について順にモニック多項式 $`t_x^N-t_x`$ で割ると、余りの各変数の次数は $`N`$ 未満となり、すべての入力で消えることから一変数の根の個数と帰納法により余りは 0 となる。
- **一般の基礎環における $`k`$-点の不存在とスキームの非空性**: 拡張の存在は $`E(k)\ne\varnothing`$、一意性は $`|E(k)|=1`$ として判定するが、一般の基礎環では $`k`$-点の不存在からスキームの空性は従わない。たとえば $`k=\mathbb Z`$、$`D=\mathbb Z`$、$`X=\{x\}`$、$`q(n)=2n`$、$`\varepsilon(n)=n`$、$`F=\{t\}`$ とすると、すべての一致方程式は $`2b-1=0`$ と同値であり、$`E_F=\mathrm{Spec}\,\mathbb Z[1/2]`$ はスキームとしては非空であるが $`\mathbb Z`$-点を持たない。

定理5.11の分類は、選んだ量の組による情報の不足も直接検出する。もし $`q(d)=q(d')`$ かつ $`\varepsilon(d)\ne\varepsilon(d')`$ となる点があれば、同じ入力に対して二つの異なる値を返す多項式は存在しないため $`E(k)`$ は空になる。また、複数の文脈にまたがって拡張を比較する際には、定理5.8による元の式の引き戻しと拡張多項式が一致する条件を、普遍的な組における係数等式として課すことができる。
