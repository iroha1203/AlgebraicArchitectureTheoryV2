# 付録D 有限root schemeとstalk

第16章の診断は、実現の係数環と診断係数を分けた層である。
この付録では、有限個のregular readoutから作る層が、幾何点で相異なる値の集合を読むことを証明する。

## D.1 有限root schemeの切断

scheme $`B`$ の小étale siteは、$`B`$ 上のétale schemeとその射を対象・射とし、
像が全体を覆うétale族を被覆とする。
集合または環 $`\Lambda`$ に対する定数層 $`\underline\Lambda`$ は、定数前層を層化したものである。
その切断はétale局所的に一定な値を持ち、連結成分上では一つの値となる。
幾何点 $`\bar b:\mathrm{Spec}\,\Omega\to B`$ のstalkは、その点を持つétale近傍上の切断のcolimitである。
ここでは $`\Omega`$ を代数閉体とする。

**補題D.1（有限rootのstalkと基底変更）.**
affine $`B=\mathrm{Spec}\,A`$ と有限族 $`f_1,\ldots,f_m\in A`$ について

```math
Z=\mathrm{Spec}\,A[z]/\prod_{i=1}^m(z-f_i),\qquad p:Z\to B
```

と置く。$`m=0`$ では $`Z=\varnothing`$ とする。
任意の診断係数環 $`\Lambda`$ と幾何点について

```math
(p_*\underline\Lambda)_{\bar b}
 \cong\Lambda^{\{f_1(\bar b),\ldots,f_m(\bar b)\}}
```

が自然に成立する。任意の $`g:B'\to B`$ と引戻した有限射 $`p':Z'\to B'`$ に対し
$`g^{-1}p_*\underline\Lambda\cong p'_*\underline\Lambda`$ である。
族の部分集合に対応するroot schemeの閉埋込みについても、この同型は値集合への制限と可換する。

**証明.**
まず幾何点を持つすべてのaffine étale近傍の環のcolimitを $`A^{\mathrm{sh}}`$ とする。
これは指定した幾何点の厳密局所環であり、局所環で剰余体が分離閉である。
各近傍を指定した点でさらに局所化することと、有限分離拡大をétale近傍へ含めることから、この二性質を得る。
以下ではrootがすべて指定関数から来ることを使い、その有限代数を直接分解する。

rootの剰余値ごとに多項式の因子をまとめる。
剰余値の異なる根 $`f_i,f_j`$ の差 $`f_i-f_j`$ は $`A^{\mathrm{sh}}`$ の単元なので、
異なるblockの因子は互いに素であり、
中国剰余によって有限代数がそのblockごとの直積に分かれる。
各blockの剰余代数は $`\kappa[z]/(z-a)^r`$ で、ただ一つの素点を持つ。
有限代数の極大イデアルは基底の極大イデアル上にあるので、各blockは局所環である。
したがってblockは連結であり、一つの相異なる根につき一つの連結成分を得る。

定数層のこの有限和上の切断は、各連結成分に一つの $`\Lambda`$ 値を置くことに等しい。
これがstalkの計算にもなることを確認する。
有限個の成分分割は有限代数の有限個の冪等元で表され、その係数と有限個の等式は
あるétale近傍ですべて定義される。従って成分ごとの有限個の値の指定はその近傍へ降りる。
逆に二切断がこの環上で等しければ、有限個の成分と値についての一致が
共通のétale近傍で成立する。これでstalkのcolimitとの両方向の同定を得る。
空のroot族の切断は零加群であり、同じ式に入る。

基底変更については、局所定数関数を引き戻す写像から標準比較
$`g^{-1}p_*\underline\Lambda\to p'_*\underline\Lambda`$ を作る。
$`B'`$ の任意の幾何点を取り、それを含むaffine開近傍へ制限して前半を適用する。
両側の根は同じ $`f_i`$ の像であり、上の計算により比較は各根で恒等になる。
stalkが同型の層射は同型である。単射性は等しいstalkを持つ二切断が局所的に等しくなること、
全射性は各点の原像を近傍へ延ばしてその一意性で貼り合わせることから従う。
支持の包含では、閉埋込みは同じ根を同じ値の点へ送るため、切断は値集合への制限になる。□

この証明はrootの重複度を取り除いた点集合を読んでいる。
例えば $`A=k[\epsilon]/(\epsilon^2)`$ の二つのreadout $`0,\epsilon`$ は異なる環の元だが、
どの幾何点でも同じ値0になる。対応するstalkは $`\Lambda`$ である。
実現の $`A`$ 値の状態と操作は、第4–8章の意味圏と実現族で引き続き保持される。

## D.2 chartの比較

同じreadoutを持つ二つのaffine chartの重なりでは、root多項式を引き戻した係数が一致する。
補題D.1の比較は同じ根に恒等として作用するため、三重の重なりでもcocycle条件を満たす。
従ってroot層と、その支持制限から作った複体を貼り合わせられる。
readoutが基底に依存する場合は、基底変更後の式も一緒に比較する。
商上に降下させるには、その作用に対するreadoutの不変性、または指定した値域同型との可換性を使う。
単にchartごとに層が存在することから、その条件は従わない。
