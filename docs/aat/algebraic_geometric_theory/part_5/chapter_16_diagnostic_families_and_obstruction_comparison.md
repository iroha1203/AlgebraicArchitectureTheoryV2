# 第16章 診断の族と障害の比較

診断は、指定された Law の値と支持から複体を構成し、そのコホモロジー類を読み取る操作である。
一方で、実際の修復に伴う障害は、具体的な操作と局所状態の不一致から独立に構成される。
両者を結ぶ比較写像を明示的に構成してはじめて、診断類の零性が実際の修復の可否に何を意味するのかを厳密に問うことができる。
本章では、比較における欠損の合成、順像係数と局所ファイバーへの分解、実現族上での値の合流、指定障害の零性反映、および双対評価・Hodge 分解による読み取りを一貫した生成規則のもとで扱う。
さらに、指定補正の持ち上げ、支持と整合する表示変更、実セル交差からの大域比較を構成し、整数のねじれを含む有限判定と、実現族上の診断次元・スペクトル根の降下へ進む。
基礎環 $`k`$ と実現の係数環 $`R`$ に加え、診断用の係数環 $`\Lambda`$ を別に指定する。

## 16.1 指定修復問題と Law 評価からの診断複体

まず、有限の Source 集合と Law 値の読み出し、および有限セル系上の支持データから Law 値診断複体を定義し、粗細の reading の比較からコチェイン写像を生成する。

**定義16.1（有限支持と Law 値複体）.**
有限集合 $`S`$（Source の集合）と有限の添字集合 $`L`$ を取る。
各 $`\ell\in L`$ に対して、原始操作・量・Law の式から評価される写像 $`\lambda_\ell:S\to W_\ell`$ を指定する。
これには、必須 Law の残差を読み出す場合も、指定された Law 入力に付随する操作値を読み出す場合も含まれ、どの式の値であるかは各 $`\lambda_\ell`$ の指定に含める。
全射 reading $`q:S\twoheadrightarrow T`$ がこの評価に**十分**であるとは、すべての $`\ell\in L`$ とすべての $`s,s'\in S`$ について

```math
q(s)=q(s')\Longrightarrow\lambda_\ell(s)=\lambda_\ell(s')
```

が成り立つことをいう。このとき、$`\bar\lambda_\ell\circ q=\lambda_\ell`$ を満たす写像 $`\bar\lambda_\ell:T\to W_\ell`$ が一意に定まる。

次に、有限セル系 $`K`$ を、頂点の集合 $`K_0`$、向き付き辺の集合 $`K_1`$、および三角形の面の集合 $`K_2`$ からなるデータとして与える。
各辺 $`e\in K_1`$ には始点 $`s(e)`$ と終点 $`t(e)`$ を、各面 $`f\in K_2`$ には三辺 $`e_{01}(f),e_{02}(f),e_{12}(f)`$ を指定し、対応する三頂点が一致する条件を課す（ループ、名前の異なる平行辺、および同じ辺の異なる出現も許す）。
各セルに属する下位次元のセル（辺に対する両端点、面に対する三辺および三頂点）を**下位セル（face）**と呼ぶ。
自由チェイン加群の微分を

```math
\partial_1[e]=[t(e)]-[s(e)],\qquad
\partial_2[f]=[e_{01}(f)]-[e_{02}(f)]+[e_{12}(f)]
```

と定めると、三頂点の相殺によって $`\partial_1\partial_2=0`$ が成り立つ。

各頂点 $`v\in K_0`$ に支持 $`T_v\subseteq T`$ を指定し、辺と面の支持は端点や三辺の支持の交差によって定める。
より一般に、各セル $`\sigma`$ の支持 $`T_\sigma\subseteq T`$ がその各 face の支持に含まれるという包含条件だけを満たす一般的な支持指定のもとでも、以下の複体は同様に構成でき、以下の比較もこの一般的な支持指定を扱う。

実際に生じる対 $`a=(\ell,w)`$（$`w\in\lambda_\ell(S)`$）を**ラベル**と呼ぶ（同じ値 $`w`$ であっても添字 $`\ell`$ が異なれば別のラベルとみなす）。
各ラベル $`a=(\ell,w)`$ に対する可視部分セル系 $`K_a`$ と、診断係数環 $`\Lambda`$ を持つ複体 $`D_q^\bullet`$ を

```math
K_a=\{\sigma\in K\mid
\exists t\in T_\sigma,\ \bar\lambda_\ell(t)=w\},\qquad
D_q^n=\bigoplus_a\Lambda^{(K_a)_n},\quad n=0,1,2
```

と定め、その他の次数は $`0`$ とする。ここで $`\Lambda^E`$ は有限集合 $`E`$ 上の $`\Lambda`$ 値関数加群を表す。
支持の包含条件から $`K_a`$ は face を取る操作について閉じており、微分 $`d=\partial^\vee`$ は端点差および三辺の交代和として well-defined に定まる。
なお、同じラベルを与える支持の証人 $`t\in T_\sigma`$ が複数存在しても、セル $`\sigma`$ の座標はラベル $`a`$ に対して一つだけである。
この複体 $`D_q^\bullet`$ を **Law 値診断複体**と呼び、そのコホモロジーを $`H^n(D_q)=\ker d^n/\mathop{\mathrm{im}}d^{n-1}`$ と書く。

宣言文脈の側との接続は、[第3章](../part_1/chapter_3_contexts_and_local_models.md)の有限被覆 $`(U_i)`$ とその交差に名前を付けることで与えられる。
頂点を被覆元、辺を選んだ二重交差の出現、面を三重交差の出現とし、同じ交差であっても出現位置を区別して保持する。
各 Source の Law 入力・読み出し・証人が交差上で読めることを支持条件と定め、すべての参照を含む宣言へ制限すれば、両端や三辺の制限写像が一致する。
この対応のもとで端点・face・支持の条件を確認して診断複体を構成する。任意の具体的な被覆を扱う場合も、その交差成分と制限に対応するセルを指定して同じ構成を用いる。

**命題16.2（原始比較からのコチェイン写像）.**
同じ $`S,L,\lambda`$ に対して十分な二つの reading $`q_f,q_c`$ を取り、粗視化写像 $`\rho`$ により $`q_c=\rho q_f`$ が成り立つとする。
細側のセル系から粗側のセル系へのセル対応 $`m`$ は、頂点写像 $`m_0`$、および各辺・各面に対する像または退化記号 $`\bot`$ の割り当てからなるものとし、次の条件を課す。

1. **辺の整合性**: 非退化な（像を持つ）辺は両端の頂点を保ち、退化辺（像が $`\bot`$）の両端は同じ粗頂点へ移る。
2. **面の整合性**: 非退化な面は三辺を保ち、退化面については粗側の自由整数加群において
   ```math
   [m_1e_{01}]-[m_1e_{02}]+[m_1e_{12}]=0,
   \qquad[\bot]=0
   ```
   が成り立つ。
3. **支持の整合性**: 各頂点および像を持つ各辺・各面 $`\sigma`$ について
   ```math
   \rho(T_\sigma^f)\subseteq T_{m(\sigma)}^c
   ```
   が成り立つ（なお、両側の支持を頂点支持の交差によって生成する場合には、すべてのセルに対するこの条件は頂点の条件 $`\rho(T_v^f)\subseteq T_{m_0v}^c`$ から自動的に従う）。

このとき、上のデータからすべてのラベルについて自然なコチェイン写像 $`F_m:D_{q_c}\to D_{q_f}`$ を生成できる。
この構成は恒等比較と二つの比較の合成を保ち、共通のラベルや支持部分集合への制限とも可換する。

**証明.**
まず、交差生成の場合に頂点の支持条件から辺・面の支持条件が従うことを確かめる。
細辺の支持に属する元は両端の頂点支持に属するため、その $`\rho`$ による像は対応する粗辺の両端の頂点支持に属し、したがって粗辺の支持にも属する。面についても三辺の交差に対してまったく同じ議論が成り立つ。一般の支持指定では仮定 3 を直接用いる。

次にコチェイン写像 $`F_m`$ を構成する。
ラベル $`a=(\ell,w)`$ に対して可視な細セル $`\sigma`$ の証人 $`t\in T_\sigma^f`$ を $`\rho(t)`$ へ送る。
条件 $`\bar\lambda^c_\ell\rho=\bar\lambda^f_\ell`$ と支持包含条件 3 により、非退化な細セル $`\sigma`$ の粗像 $`m(\sigma)`$ も同じラベル $`a`$ に対して可視である。
そこでチェイン上で、非退化なセルの基底をその像の基底へ、退化セルを $`0`$ へ送る線形写像 $`m`$ を定める。
辺については条件 1、面については条件 2（非退化面の三辺保存または退化面の零和条件）により、チェイン写像の条件 $`m\partial=\partial m`$ が成り立つ。
双対を取ることで、非退化なセルでは元の粗側コチェインを像のセルで評価し、退化セルでは $`0`$ を与えるコチェイン写像 $`F_m:D_{q_c}\to D_{q_f}`$ が得られる。

合成および制限との整合性を確かめる。
2段階の比較 $`m:K_1\to K_0`$ と $`n:K_2\to K_1`$ について、最終的に像を持つセルは両段階で像を持ち、支持包含が合成される。途中で退化するセルは合成でも退化させる。基底の像を合成すれば微分との可換性も保たれ、$`F_{mn}=F_nF_m`$ が成り立つ。恒等比較の支持条件は各支持の恒等包含である。
また、粗側の支持部分集合 $`A\subseteq T_c`$ へ制限する場合は細側を $`\rho^{-1}A`$ とする。非退化なセルでは $`\rho(T_\sigma^f\cap\rho^{-1}A)\subseteq T_{m(\sigma)}^c\cap A`$ となるため、同じ証人の輸送によって制限後も同じ式が成り立ち、比較と可換する。□

次の構成は、宣言文脈の被覆とその細分から、命題16.2の仮定をすべて満たす具体的なセル比較を明示的に組み立てるものである。

**構成16.2a（宣言被覆と reading からの具体的なセル比較）.**
宣言文脈 $`U`$ の有限被覆 $`(U_i)_{i\in I}`$ とその細分 $`(V_j)_{j\in J}`$ を取り、$`V_j\subseteq U_{a(j)}`$ を満たす添字写像 $`a:J\to I`$ を選ぶ。
両添字集合 $`I,J`$ に全順序を入れ、写像 $`a`$ が弱単調となるように $`J`$ を像ごとに並べておく。
セル系は、被覆元の添字（頂点）、相異なる昇順の 2添字（辺）、相異なる昇順の 3添字（面）から構成し、各セルには対応する宣言文脈の交差を割り当てる。

[第14章](chapter_14_transport_along_readings_and_coefficients.md)の指定された入力・値グラフ・関係の証人から有限個の Source を取り、その集合を $`S`$ とする。
各 $`s\in S`$ に対して、その事実を読み取るための依存関係と Law 入力を含む宣言支持 $`J_s`$ を記録し、$`S_i^c=\{s\mid J_s\subseteq U_i\}`$、$`S_j^f=\{s\mid J_s\subseteq V_j\}`$ と置く。
原始観測をまとめた値 $`r_f(s)`$ とその一部を読み取る $`r_c(s)=p(r_f(s))`$ を選び、共通の Law 値 $`(\lambda_\ell(s))_\ell`$ および支持への所属指示関数を加えて、二つの reading を

```math
q_c(s)=\bigl(r_c(s),(\lambda_\ell(s))_\ell,
                 (\mathbf1_{s\in S_i^c})_i\bigr),\qquad
q_f(s)=\bigl(r_f(s),(\lambda_\ell(s))_\ell,
                 (\mathbf1_{s\in S_i^c})_i,(\mathbf1_{s\in S_j^f})_j\bigr)
```

と定める。値域はそれぞれ実際の像とし、射影と $`p`$ から $`q_c=\rho q_f`$ を得る。
Law 値を成分に含んでいるため、両 reading はともに十分である。
頂点の支持を $`T_i^c=q_c(S_i^c)`$、$`T_j^f=q_f(S_j^f)`$ と定め、辺と面の支持は交差によって生成する。所属情報を reading の成分に保持しているため、各支持の逆像は元の $`S_i^c,S_j^f`$ に厳密に一致する。したがってこの支持は、同じ Source の事実が該当する宣言交差で読み取れることを正確に表す。

セル対応 $`m`$ は、頂点写像を $`m_0=a`$ とし、辺は両端の像が異なればその昇順辺へ、同じであれば $`\bot`$ へ送り、面は三頂点の像がすべて相異なればその昇順面へ、それ以外は退化記号 $`\bot`$ へ送る。
添字写像 $`a`$ の弱単調性により、退化面の三辺の像は $`(\bot,e,e)`$、$`(e,e,\bot)`$、または $`(\bot,\bot,\bot)`$ のいずれかとなり、命題16.2の符号付き零和条件を満たす。
また $`S_j^f\subseteq S_{a(j)}^c`$ から頂点支持の包含が成り立ち、交差生成によりすべてのセルの支持も保たれる。
こうして原始宣言・入力の組・読み出しからコチェイン写像 $`F_m`$ が構成された。

3段階の細分では所属情報をすべての段階分保持すれば、射影とセル像の合成が厳密に一致する。
また完全な名前替えにおいては、宣言支持と Source のすべての組を同時に運び、その全単射で $`S`$ を同定して同じ構成を適用できる。
したがって第14章の制限・観測の射や、第15章の同じ原始成分を持つ 2本の経路の比較は、この構成を通じて診断複体の比較へと接続する。
一方、値域の変更によって異なるラベルが一つに合流する場合は、ここでの固定ラベルの比較とは区別して 16.4 節で扱う。

なお、必須残差は[第5章](../part_2/chapter_5_quantities_and_law_geometry.md)の Lawful locus を定めるが、診断複体は選んだ読み出しと支持に基づいて構成されるため、すべての必須残差が零であっても $`H^1(D_q)`$ は非零になり得る。
たとえば面を持たない三角形のすべての辺を一つのラベルが支えるとき、$`d^0`$ の階数は $`2`$、$`D^1=\Lambda^3`$ となり、体係数では $`H^1(D_q)\cong\Lambda`$ となる。
診断コホモロジー空間そのものが非零であることと、ある具体的な修復問題がそこに指定する障害類が非零であることは別の情報である。

## 16.2 核・余核・写像錐と合成

粗細の reading を比較するコチェイン写像が誘導するコホモロジーの差は、写像錐（mapping cone）と 6項完全列によって定量的に制御できる。

コチェイン写像 $`F:D\to D'`$ の**写像錐** $`\mathrm{Cone}(F)`$ を

```math
\mathrm{Cone}(F)^n=D'^n\oplus D^{n+1},\qquad
d(y,x)=(d'y+Fx,-dx)
```

によって定義する。$`F`$ の微分との可換性 $`d'F=Fd`$ から $`d^2=0`$ が確かめられる。
包含 $`y\mapsto(y,0)`$ と射影 $`(y,x)\mapsto x`$ により短完全列 $`0\to D'\to\mathrm{Cone}(F)\to D[1]\to0`$ が得られる。
閉元を持ち上げてその微分を核へ戻す標準的な連結操作によりコホモロジーの長完全列が導かれる（持ち上げを変えても微分の像だけしか変わらないため類として一意であり、各箇所の核は持ち上げを閉元へ補正できる条件と一致する）。
特に低次数では次の二つの短完全列が得られる。

```math
0\to\mathop{\mathrm{coker}}H^0(F)\to H^0(\mathrm{Cone}(F))
 \to\ker H^1(F)\to0,
\qquad
0\to\mathop{\mathrm{coker}}H^1(F)\to H^1(\mathrm{Cone}(F))
 \to\ker H^2(F)\to0.
```

写像錐は比較の差を全次数にわたって捉え、次数 $`1`$ の核と余核はその特定の帰結にあたる。
以下では有限次元の体係数を考え、線形写像 $`f`$ の欠損の次元対を $`J(f)=(\dim\ker f,\dim\mathop{\mathrm{coker}}f)`$ と記す。

**定理16.3（欠損の合成）.**
有限 Source、有限 Law 値族、十分な三つの reading、および命題16.2の二つの具体的な比較から、有理係数の写像 $`f:H^1(D_0)\to H^1(D_1)`$ および $`g:H^1(D_1)\to H^1(D_2)`$ を生成する。
このとき、直接の比較写像は合成 $`gf`$ に一致し、自然な 6項完全列

```math
0\to\ker f\to\ker(gf)\xrightarrow{f}\ker g
 \xrightarrow{\delta}\mathop{\mathrm{coker}}f
 \xrightarrow{g}\mathop{\mathrm{coker}}(gf)
 \longrightarrow\mathop{\mathrm{coker}}g\to0
```

が存在する。ここで $`\delta(v)=[v]`$ を**相殺写像**と呼ぶ。
$`r=\mathop{\mathrm{rank}}\delta`$ と置くと、次元等式

```math
\dim\ker(gf)+r=\dim\ker f+\dim\ker g,\qquad
\dim\mathop{\mathrm{coker}}(gf)+r
 =\dim\mathop{\mathrm{coker}}f+\dim\mathop{\mathrm{coker}}g
```

が成り立つ。同じ完全列と次元等式は、Law 別の各ラベル成分および粗支持部分集合の標準逆像族に対しても成立する。

**証明.**
6項列の各写像を明示する。最初の矢印は包含 $`\ker f\hookrightarrow\ker(gf)`$、次は制限 $`x\mapsto f(x)`$、相殺写像は $`\delta(v)=[v]\in\mathop{\mathrm{coker}}f`$、余核の間の二つの矢印はそれぞれ $`[v]\mapsto[g(v)]`$ と $`[w]_{\mathrm{im}(gf)}\mapsto[w]_{\mathrm{im}g}`$ である。代表元を取り替えた差はいずれも対応する像に入るため、すべての写像が well-defined に定まる。

各箇所での完全性を確認する。
- $`\ker(gf)`$ において $`f(x)=0`$ であることは $`x\in\ker f`$ に他ならない。
- $`v\in\ker g`$ に対して $`\delta(v)=0`$ であることは $`v=f(x)`$ となる $`x`$ の存在と同値であり、このとき $`gf(x)=g(v)=0`$ なので $`x\in\ker(gf)`$ である。
- $`[v]\in\mathop{\mathrm{coker}}f`$ が $`[g(v)]=0\in\mathop{\mathrm{coker}}(gf)`$ を満たすなら、$`g(v)=gf(x)`$ となる $`x`$ が存在し、$`v-f(x)\in\ker g`$ が $`[v]`$ の $`\delta`$ による原像を与える。
- 最後の射 $`\mathop{\mathrm{coker}}(gf)\to\mathop{\mathrm{coker}}g`$ は明らかに全射であり、その核は $`w\in\mathop{\mathrm{im}}g`$、すなわち $`[g(v)]`$ の形の類からなる。

これにより 6項列のすべての箇所で完全性が示された。次元等式は、この完全列を像と核の短完全列へ分解して交互和を取ることで直ちに従う。
また、具体的な比較の合成と支持制限の整合性は命題16.2の基底計算により同じ写像を与え、ラベルの有限直和は核および余核の計算と可換するため、各ブロック成分ごとにも同じ結果が成り立つ。□

コサイクル $`z\in D_1^1`$ に対して $`g[z]=0`$ であることは、$`Gz=d_2c`$ を満たす実際の 0-コチェイン $`c`$ が存在することを意味する。
さらにその類 $`[z]`$ が $`\mathop{\mathrm{im}}f`$ に属することは、$`z-Fx=d_1b`$ を満たす粗側コサイクル $`x`$ と中間の 0-コチェイン $`b`$ の存在を意味する。
したがって相殺写像 $`\delta`$ は、後段の比較で消えるコホモロジー類のうち、前段の比較からすでに持ち込まれていた成分を取り除く役割を担っている。

**例16.4（相殺と 2段階の比較）.**
$`0\xrightarrow{f}\mathbb Q\xrightarrow{g}0`$ を考えると、$`J(f)=(0,1)`$、$`J(g)=(1,0)`$、一方合成では $`J(gf)=(0,0)`$ である。
相殺写像 $`\delta:\mathbb Q\to\mathbb Q`$ は恒等写像となり、前段の余核と後段の核という二つの差が完全に相殺する。
一般に、二つの比較がともに同型ならば合成も同型であり、前段と合成（または後段と合成）が同型ならば残る一射も同型となる。
しかし、合成の欠損が零であることだけから両段階の欠損が零であると結論することはできないことが、この例から分かる。

## 16.3 係数・ファイバー・局所貼り合わせによる分解

前節では 2段階の比較の合成を扱った。本節では単一の粗細セル比較 $`m:K_f\to K_c`$ を詳細に分解し、コホモロジーの差が「粗側での順像係数の変化」と「各粗セル上の局所ファイバーの位相・貼り合わせ」の二要素からどのように組み立てられるかを完全に記述する。

この節では一つのラベルまたは支持部分集合を固定し、命題16.2の粗・細セル系をそれぞれ $`K_c,K_f`$ と書く。係数は $`\mathbb Q`$ とし、各次数のすべての細セルを原始添字として用いる。
細セルを $`m`$ による像の退化状況に応じて次のように分類する。

- 辺の分割: 退化辺の集合を $`E_v`$、非退化な（写る）辺の集合を $`E_h`$ とする。
- 面の分割: すべての辺が退化する面の集合を $`F_v`$、一部の辺だけが写る退化面（混在面）の集合を $`F_m`$、非退化な（写る）面の集合を $`F_h`$ とする。

命題16.2の退化面の零和条件を自由基底の係数で比較すると、退化面の三辺の像は $`(\bot,\bot,\bot)`$、$`(\bot,e,e)`$、$`(e,e,\bot)`$ のいずれかのみとなる。

**構成16.5（順像係数と局所ファイバー）.**
粗セルごとのファイバーと、その連結成分から定まる順像係数系を次のように構成する。

1. **各粗セル上のファイバー**:
   - 粗頂点 $`c`$ 上のセル系 $`\Phi_c`$ を、$`m_0(v)=c`$ を満たす細頂点、その上の退化辺、およびその上のすべての辺が退化する面からなるセル系として定義する。
   - 粗辺 $`e`$ 上のグラフ $`\Gamma_e`$ を、$`m_1(a)=e`$ を満たす細辺を頂点とし、粗辺 $`e`$ に属する混在面を辺とするグラフとして定義する。混在面に対応する辺は、その三辺のうちの $`e_{02}`$ と、残る非退化辺 $`e_{01}`$ または $`e_{12}`$ とを結ぶ。
   - 粗面 $`F`$ 上の離散集合を $`\Psi_F=\{f\in F_h\mid m_2(f)=F\}`$ と定める。
2. **順像係数系**:
   粗セル上のベクトル空間を
   ```math
   G(c)=\mathbb Q^{\pi_0\Phi_c},\qquad
   G(e)=\mathbb Q^{\pi_0\Gamma_e},\qquad
   G(F)=\mathbb Q^{\Psi_F}
   ```
   と定める。細辺の持ち上げの両端点を取ることで写像 $`\pi_0\Gamma_e\to\pi_0\Phi_{s(e)},\pi_0\Phi_{t(e)}`$ が得られる（混在面の対応する端点は同じ頂点か退化辺で結ばれるため、連結成分のレベルで well-defined に定まる）。同様に、面の持ち上げの三辺は対応する $`\Gamma`$ の連結成分を定める。関数の引き戻しを係数射とすれば、面の三頂点を経由する二通りの係数射は一致する。これは接続（incidence）の出現位置を保ったセル係数系であり、各係数射の可逆性は要求しない。
3. **順像係数複体と比較分解**:
   順像係数複体 $`P^\bullet`$ を
   ```math
   P^0=\prod_cG(c),\quad P^1=\prod_eG(e),\quad P^2=\prod_FG(F)
   ```
   とし、係数射による端点差および三辺の交代和を微分とする（三頂点の相殺により複体となる）。
   粗側複体 $`C=C^\bullet(K_c;\mathbb Q)`$ からのコチェイン写像 $`\eta:C\to P`$ は、各粗セルの値をその持ち上げ成分上の定数関数へ送る写像とする。
   一方、細側複体 $`C'=C^\bullet(K_f;\mathbb Q)`$ への写像 $`\varepsilon:P\to C'`$ は、細頂点・写る辺・写る面では対応する連結成分上で評価し、退化辺・退化面では $`0`$ とする。混在面の二つの非退化辺の値は同じ $`\Gamma_e`$ 成分上で一致して相殺するため、$`\varepsilon`$ もコチェイン写像となる。さらにすべての成分には評価を行う細セルが少なくとも一つ存在するため、$`\varepsilon`$ は各次数で単射である。
   原始比較 $`u:C\to C'`$ は、各セルごとに $`u=\varepsilon\eta`$ と分解される。

この順像係数は、各粗セルの持ち上げを接続関係によって貼り合わせた局所定数関数から組み立てられている（たとえば粗辺上では、混在面が辺の持ち上げの値を同一視する）。
文脈の被覆から構成したセル系では、これらはそれぞれ被覆元、二重交差、三重交差の持ち上げの整合条件に対応する。
また、宣言の制限が同じセル・支持・退化対応を保つならば、これらの係数射も成分を制限する式によって運ばれる。

次の定理は、分解 $`u=\varepsilon\eta`$ をコホモロジーへ移し、原始比較 $`T=H^1(u)`$ の核と余核を、順像係数による変化 $`a=H^1(\eta)`$ と、局所ファイバーの適合空間 $`\mathscr R`$ 上の連結射 $`\tau`$ の核とに厳密に分離する。

**定理16.6（係数差と局所ファイバーの分解）.**
構成16.5のデータから、原始行列によって計算できるベクトル空間 $`\mathscr R`$ と線形写像 $`\tau:\mathscr R\to H^2(P)`$ を構成でき、次の 5項完全列が成り立つ。

```math
0\to H^1(P)\xrightarrow{b}H^1(C')\to\mathscr R
 \xrightarrow{\tau}H^2(P)\to H^2(C').
```

さらに $`a=H^1(\eta)`$、$`b=H^1(\varepsilon)`$、$`T=H^1(u)=ba`$ と置くと、核の等号と余核の短完全列

```math
\ker T=\ker a,\qquad
0\to\mathop{\mathrm{coker}}a\to\mathop{\mathrm{coker}}T
 \to\ker\tau\to0
```

が得られる。したがって、$`T`$ が同型であることと、「$`a`$ が同型かつ $`\tau`$ が単射である」ことは同値である。

**構成と証明.**
証明は、退化部分複体 $`L_\bullet`$ の構成、行列ブロック表示による $`H^1(Q)\cong\mathscr R`$ の同定、連結射 $`\tau`$ の明示式、および 5項列からの帰結の四段階で行う。

**1. 退化部分複体と短完全列.**
細チェイン複体の中に、次の部分複体 $`L_\bullet`$ を定義する。

```math
L_0=\partial\mathbb Q[E_v],\quad
L_1=\mathbb Q[E_v]+\partial\mathbb Q[F_m],\quad
L_2=\mathbb Q[F_v]\oplus\mathbb Q[F_m].
```

退化面の分類から $`\partial L_2\subseteq L_1`$、$`\partial L_1=L_0`$ が成り立つため $`L_\bullet`$ は部分複体であり、しかも $`H_0(L)=0`$ である。
その双対複体を $`Q=L^\vee`$ と置き、細コチェインの制限 $`C'\to Q`$ を考える。体上の部分空間の基底を全体の基底へ延長できるため、この制限写像は各次数で全射である。
制限写像の核を次数ごとに計算すると、次のようになる。

- 次数 $`0`$ では、退化辺の両端で値が等しく、したがって値は $`\Phi_c`$ の連結成分へ降りる。
- 次数 $`1`$ では、退化辺の値が $`0`$ であり、かつ混在面の二つの非退化辺の値が等しい。したがって値は $`\Gamma_e`$ の連結成分へ降りる。
- 次数 $`2`$ では、退化面の値が $`0`$ であり、残る値は $`\Psi_F`$ 上の関数となる。

これはちょうど $`\mathop{\mathrm{im}}\varepsilon`$ に一致する。したがってコチェイン複体の短完全列 $`0\to P\xrightarrow{\varepsilon} C'\to Q\to0`$ を得る。
ここで $`H^0(Q)=\mathrm{Hom}(L_0/\partial L_1,\mathbb Q)=0`$ であるため、誘導される長完全列の次数 $`1`$ の先頭に $`0`$ を置くことができる。

**2. ブロック行列表示による $`H^1(Q)\cong\mathscr R`$ の同定.**
残る $`H^1(Q)`$ を各粗セル上の局所ファイバーから明示的に計算する。細チェインの原始微分を、行を $`(E_v,E_h)`$、列を $`(F_v,F_m,F_h)`$ でブロック分割して

```math
\partial_1=(A\ B_0),\qquad
\partial_2=\begin{pmatrix}V&D&0\\0&B&H\end{pmatrix},\qquad
AV=0,\quad AD+B_0B=0,\quad B_0H=0
```

と表す。垂直チェイン複体は各粗頂点上の $`\Phi_c`$ のチェイン複体の直和であるため、$`\ker A/\mathop{\mathrm{im}}V=\bigoplus_cH_1(\Phi_c)`$ が成り立つ。
混在面の線形結合 $`y\in\ker B`$ に対しては $`ADy=-B_0By=0`$ となるため、線形写像

```math
\kappa:\ker B\longrightarrow\bigoplus_cH_1(\Phi_c),\qquad
y\longmapsto[Dy]
```

が定まる。$`L_1`$ の任意の閉元から混在面の微分を引けば垂直な閉元が残り、垂直な閉元 $`v`$ が $`L`$ 内で微分の像になる条件は $`v=Vx+Dy`$ かつ $`By=0`$ となる $`x,y`$ の存在である。
したがって $`H_1(L)=\mathop{\mathrm{coker}}\kappa`$ を得る。有限次元ベクトル空間の双対を取れば（双対とコホモロジーの同定は 16.6 節の線形代数の証明でも確認できる）、同じ閉元への評価によって自然同型

```math
H^1(Q)\cong\mathscr R:=
\ker\left(\kappa^\vee:\bigoplus_cH^1(\Phi_c)\to(\ker B)^\vee\right)
```

が得られる。こうして空間 $`\mathscr R`$ と、短完全列の連結射を通じた写像 $`\tau:\mathscr R\to H^2(P)`$ が構成された。

**3. 連結射 $`\tau`$ の明示式.**
元 $`r\in\mathscr R`$ を、$`zV=0`$ を満たす垂直コチェイン $`z`$ で代表する。
$`\mathscr R`$ の適合条件は $`zD|_{\ker B}=0`$ を意味するため、$`\mathop{\mathrm{im}}B`$ 上の線形汎関数を延長して $`\lambda B=-zD`$ を満たす水平コチェイン $`\lambda`$ を選ぶことができる。
このとき細コチェイン $`(z,\lambda)`$ の微分は、退化面上で $`0`$、非退化面上で $`\lambda H`$ となるため、連結射は

```math
\tau(r)=[\lambda H]\in H^2(P)
```

によって明示的に与えられる。
$`\lambda`$ の選択の差は $`B`$ を消すため $`P^1`$ の元となり、$`H`$ へ作用させた差は $`P`$ の微分の像に入る。また代表 $`z`$ を $`z+\gamma A`$ に取り替えたときは $`\lambda+\gamma B_0`$ を選べばよく、$`B_0H=0`$ から同じコホモロジー類を与える。よってこの式は代表の選び方によらず、短完全列の持ち上げと微分による連結射の定義そのものに一致する。したがって主張の 5項列は完全である（たとえば $`\tau(r)=0`$ であれば、持ち上げたコチェインの微分を $`P^1`$ の元で打ち消して細側のコサイクルを実際に構成できる）。

**4. 核と余核の分解.**
上の 5項完全列から、$`b=H^1(\varepsilon)`$ は単射であり、$`\mathop{\mathrm{coker}}b\cong\ker\tau`$ が成り立つ。
そこで定理16.3を合成 $`T=ba`$ に適用すると、相殺写像の始域 $`\ker b`$ が $`0`$ となるため、直ちに $`\ker T=\ker a`$ と短完全列 $`0\to\mathop{\mathrm{coker}}a\to\mathop{\mathrm{coker}}T\to\ker\tau\to0`$ が得られる。
次元を取れば

```math
\dim\ker T=\dim\ker a,\qquad
\dim\mathop{\mathrm{coker}}T
 =\dim\mathop{\mathrm{coker}}a+\dim\ker\tau
```

となり、非負整数の和が $`0`$ となる条件から最後の必要十分条件が従う。□

この分解は自然な短完全列として与えられており、直和分解の任意な選択を含まない。
定理16.3の 6項列における相殺写像と、本定理における局所ファイバーの連結射 $`\tau`$ とは役割の異なる別の写像である。
なお、十分条件として、すべての $`\Phi_c,\Gamma_e`$ が非空かつ連結であり、すべての $`\Psi_F`$ が 1点集合であるならば $`\eta`$ は複体同型となり、さらにすべての $`H^1(\Phi_c)=0`$ であれば $`\mathscr R=0`$ となるため $`T`$ は同型になる。一般の場合には、$`\tau`$ を含めた上の必要十分条件によって判定する。

**例16.7（局所ファイバーだけが増える場合）.**
粗側を 1点、細側を面のない三角形とし、すべての辺を退化させる。
すべてのセルに同じ一つの Source を支持させ、Law 値を $`0`$ とする。
このとき $`\Phi_c`$ は三角形そのもの、順像係数複体は $`P=(\mathbb Q\to0\to0)`$ であり、$`\mathscr R=\mathbb Q`$、$`\tau=0`$ となる。
粗側の $`H^1=0`$ から細側の $`H^1=\mathbb Q`$ への比較の余核は、ちょうどこの局所ファイバー項 $`\ker\tau=\mathbb Q`$ に一致する。
Law 別・支持別の診断に対しては、構成16.5を各ラベルの可視セルへ適用して有限直和を取ればよい。すべてのブロックで同じ原始対応を用いるため、直接比較との同一性も保たれる。

## 16.4 実現族と値の合流

固定したラベル集合のもとでの診断係数の変更 $`\Lambda\to\Lambda'`$ は、有限自由複体のテンソル積にすぎない。特に $`\Lambda'`$ が $`\Lambda`$ 上平坦であれば、サイクルと微分像の短完全列をテンソルすることで $`H^n(D)\otimes_\Lambda\Lambda'\cong H^n(D\otimes_\Lambda\Lambda')`$ が得られる。
これとは本質的に異なる現象として、実現そのものをパラメータ族の上で動かすと、読み出し値のあいだの等号関係が変化し、ラベルの再分類（値の合流）が生じる。本節では、この族としての診断を有限根スキーム上の étale 層複体として構成する。

**構成16.8（原始的な正則読み出しと根スキーム）.**
[第6章](../part_2/chapter_6_families_and_moduli.md)の実現族 $`\mathcal M`$ のアフィンチャート $`B=\mathrm{Spec}\,A`$ を取り、有限 Source 集合 $`S`$、有限の読み出し添字集合 $`L`$、および face $`\tau\subset\sigma`$ について包含 $`S_\sigma\subseteq S_\tau`$ を満たす固定した有限支持 $`S_\sigma\subseteq S`$ を与える。
各 $`f_{\ell,s}\in A`$ は、原始操作の有限式から生成される正則（regular）スカラー読み出しとする（具体例としては、多項式チャートの係数、固定した名前付き基底での成分、あるいは有限局所自由な自己準同型のトレースがある。トレースは基底変更 $`\mathrm{tr}(P^{-1}MP)=\mathrm{tr}(M)`$ のもとで不変であり、成分を読み取る場合はそのチャートを保持する）。

各セル $`\sigma`$ と各読み出し $`\ell\in L`$ に対し、有限根スキーム

```math
Z_{\sigma,\ell}
 =\mathrm{Spec}\,A[z]\Big/\left(\prod_{s\in S_\sigma}(z-f_{\ell,s})\right),
\qquad p_{\sigma,\ell}:Z_{\sigma,\ell}\to B
```

を定義する（空支持では積を $`1`$ とみなし、空スキームを得る）。
モニック（最高次係数が $`1`$ の）多項式による商であるため、$`p_{\sigma,\ell}`$ は有限射である。
face の包含 $`\tau\subset\sigma`$ に伴う支持の包含 $`S_\sigma\subseteq S_\tau`$ では多項式が割り切れるため、閉埋込み $`Z_{\sigma,\ell}\hookrightarrow Z_{\tau,\ell}`$ が誘導される。
診断係数環 $`\Lambda`$ の定数 étale 層（すなわち étale 試験スキーム上で局所定数な $`\Lambda`$ 値関数を読む層）の制限を順像し、

```math
\mathscr D_B^n=\bigoplus_{\dim\sigma=n,\ell}(p_{\sigma,\ell})_*\underline\Lambda
```

と置き、余次元 $`1`$ の face（辺に対する両端点、面に対する三辺）への制限の交代和を微分として複体 $`\mathscr D_B^\bullet`$ を定める。微分の二乗では同じ 2段階の制限が逆符号で現れて打ち消し合うため、$`\mathscr D_B^\bullet`$ は層の複体となる。

**定理16.9（実現族上の診断と茎）.**
構成16.8の任意の幾何点 $`\bar b:\mathrm{Spec}\,\Omega\to B`$ において、複体の茎（stalk）$`(\mathscr D_B)_{\bar b}`$ は、評価値 $`f_{\ell,s}(\bar b)`$ と同じ支持から定義16.1によって再生成される Law 値診断複体と自然に同型である。
さらに、任意の射 $`g:B'\to B`$ に対して自然同型 $`g^{-1}\mathscr D_B\cong\mathscr D_{B'}`$ が成り立ち、微分および比較写像と整合する。
ここで用いる $`g^{-1}`$ は étale 層の逆像であり、$`\mathcal O_B`$-加群としてのテンソル引き戻しとは別の操作である。

**証明.**
[補題D.1](../appendix_d_finite_roots_and_stalks.md#d1-有限根スキームの切断)を各有限射 $`p_{\sigma,\ell}`$ に適用すると、幾何点 $`\bar b`$ における茎は

```math
((p_{\sigma,\ell})_*\underline\Lambda)_{\bar b}
 \cong\Lambda^{\{f_{\ell,s}(\bar b)\mid s\in S_\sigma\}}
```

となる。重複した根や冪零厚みは幾何ファイバーの点の個数を増やさないため、右辺は相異なる値をちょうど一回ずつ読み取る。
支持の包含に対応する閉埋込みの制限写像は、値集合の包含に沿う関数の制限に一致する。
有限直和の項をラベル $`(\ell,w)`$ ごとに並べ替えると、次数 $`n`$ の座標は「値 $`w`$ を支持に持つ $`n`$-セル」とちょうど一対一に対応し、微分も定義16.1と同じ端点差および三辺の交代和となる。よって複体の自然同型が得られる。

基底変更 $`g:B'\to B`$ については、多項式のすべての係数を引き戻した同じ形の有限根スキームが得られ、補題D.1の基底変更同型が各成分およびすべての制限写像を保つ。したがって複体全体と生成比較の双方に対して主張の同型が成立する。□

有限個の読み出し変数 $`x_{\ell,s}`$ を持つアフィン空間上で先にこの複体を構成し、$`x_{\ell,s}\mapsto f_{\ell,s}`$ で引き戻しても同じ複体が得られる。
読み出し値の同値分割を固定し、同じブロックに属する値の差を $`0`$、異なるブロックに属する値の差を単元とした局所閉部分スキーム上では、根の多項式は相異なる根ごとの互いに素な因子へ分解する。
各因子は基底の一つの切断の冪零厚みであり、複体は同じ整数接続行列を $`\Lambda`$ 係数で読んだものとなるため、有限次元の体係数では各同値分割上でコホモロジー次元が一定となる。

次に、パラメータを動かして二つの読み出し値が合流するときに、診断コホモロジーがどのように変化するかを Mayer–Vietoris 型の完全列で記述する。

**命題16.10（値の合流による完全列）.**
二つの値に対応する可視部分セル系のブロックを $`K_a,K_b`$ とし、パラメータの変化によってそれら二つの値だけが合流するとする。
合流後の可視ブロックは和集合 $`U=K_a\cup K_b`$ であり、交差を $`I=K_a\cap K_b`$ と置く。
原始セルへの制限から、コチェイン複体の短完全列

```math
0\to C^\bullet(U;\Lambda)\xrightarrow{r}
C^\bullet(K_a;\Lambda)\oplus C^\bullet(K_b;\Lambda)
\xrightarrow{\rho}C^\bullet(I;\Lambda)\to0
```

が得られる。ここで $`r(x)=(x|_{K_a},x|_{K_b})`$、$`\rho(y,z)=y|_I-z|_I`$ である。
このとき、$`H^1(r)`$ が同型であるための必要十分条件は、$`H^0(\rho)`$ が全射かつ $`H^1(\rho)=0`$ であることである。

**証明.**
各次数において、交差 $`I`$ 上で一致する二つの関数は和集合 $`U`$ 上の一つの関数へ一意に貼り合わされるため、$`r`$ は単射かつ $`\ker\rho=\mathop{\mathrm{im}}r`$ である。
また、交差 $`I`$ 上の任意の関数は、$`K_a\setminus I`$ 上で $`0`$ を補って延長すれば $`\rho`$ の原像を持つため、$`\rho`$ は全射である。
制限写像は微分と可換するため、上の短完全列が成り立つ。
誘導される長完全列の該当部分は

```math
H^0(K_a)\oplus H^0(K_b)\xrightarrow{H^0\rho}H^0(I)
\to H^1(U)\xrightarrow{H^1r}H^1(K_a)\oplus H^1(K_b)
\xrightarrow{H^1\rho}H^1(I)
```

である。完全性により、$`H^1(r)`$ が単射であることは $`H^0(\rho)`$ が全射であることと同値であり、$`H^1(r)`$ が全射であることは $`H^1(\rho)=0`$ と同値である。□

これは合流後のブロックから合流前の二つのブロックへ向かう制限写像による比較であり、任意の二つの実現の間に自動的に特殊化射が存在すると仮定するのではなく、固定された支持の和集合と交差から得られる比較である。
三つ以上の値が同時に合流する場合には、各セルごとにそれを含むブロックの有限集合を取り、それらのすべての交差からなる交代複体を構成する。添字集合の一頂点を選ぶ縮約によって、増大した複体は各セル上で完全となるため、すべての交差を用いる有限 Mayer–Vietoris 複体が得られる。また、異なる合流順序を経て和集合へ戻る写像はいずれも同じセルへの制限であるため、比較は可換する。

**例16.11（台帳の意味保存族と診断の跳躍）.**
基底を $`B=\mathrm{Spec}\,k[t]`$ とし、分割台帳 $`R^2`$ の公開量を $`q(x,y)=x`$、操作を $`\mathrm{apply}_t(u)(x,y)=(x+u,y+tu)`$ と定める。
写像 $`h_t(x,y)=(x,y+tx)`$ は逆写像 $`h_t^{-1}(x,y)=(x,y-tx)`$ を持ち、$`h_t\mathrm{apply}_0=\mathrm{apply}_t h_t`$ かつ $`qh_t=q`$ を満たす。
したがってこの族は、すべてのパラメータ $`t`$ にわたって公開量を保つ意味的な同型を持つ。

ここで、面のない三角形の各辺に一つずつ Source を置き、各 Source をその辺の両端で支持する。
二つの読み出し値を原始定数 $`0`$ とし、第三の読み出し値を apply の第二成分の係数 $`t`$ とする。
- $`t\ne0`$ の幾何点では、値 $`0`$ のブロックは 2辺の道、値 $`t`$ のブロックは残る 1辺であり、両者の $`H^1`$ はともに $`0`$ である。
- $`t=0`$ の幾何点では、二つの値が合流して一つの三角形ブロックとなり、$`H^1\cong\Lambda`$ へ跳躍する。

交差ブロック $`I`$ は 2辺の道の両端の 2点からなるため、命題16.10の写像 $`H^0(\rho)`$ の余核（$`H^0(I)/\mathop{\mathrm{im}}(H^0\rho)`$）から新しい一つのコホモロジー類が生じる。
この読み出しは名前付き座標の係数を読むものであり、公開量だけを固定する同型のもとでは不変でないため、チャートに付随する診断として扱う。

逆向きに次元が減る跳躍も計算できる。三角形の各辺に値 $`0`$ の Source と値 $`t`$ の Source をそれぞれ置くと、$`t\ne0`$ では三角形ブロックが二つ、$`t=0`$ では一つになる。
このとき次元は $`2`$ から $`1`$ へ減少し、$`H^1(r):\Lambda\to\Lambda^2`$ は対角写像となる。非零の差を取り出す $`H^1(\rho)`$ が、合流前に二つの類を区別していた情報を表している。

## 16.5 実際の障害の比較と零性反映

ここまでは診断複体そのものの構造と比較を調べた。本節では、実際の局所状態と遷移の不一致から定まる障害類と Law 値診断複体のコホモロジー類とを比較し、診断類の零性が実際の障害類の零性を反映する条件を求める。

この節では、面を持たない有限単純グラフ $`G`$ を用いる。
具体的な被覆として、各被覆元が非空連結であり、非空な二重交差がすべて連結であり、三重交差が空であって、その交差グラフが $`G`$ となるものを取る。
係数の局所同定はすべての交差上で以下で構成する同一の可換群を読むものとする。この条件により、局所定数係数の Čech 0-コチェインおよび 1-コチェインは、グラフ $`G`$ の頂点・辺上の座標によって一意に表現される。
また、有限集合 $`S,L`$、評価 $`\lambda_\ell`$ に十分な reading $`q:S\twoheadrightarrow T`$、および face 包含を満たす支持を定義16.1のものとして固定し、診断係数を $`\Lambda=\mathbb Q`$ とする。

**構成16.12（実際の操作、関係、不一致）.**
原始生成元の集合を $`P=L\times S`$ とし、実際の再同定において同じ移動を表すと宣言された関係 $`\mathcal R\subseteq P\times P`$ を与える。
係数群を商加群

```math
M=\mathbb Z^{(P)}/\langle[p]-[p']\mid p\mathcal R p'\rangle
```

と定義する。これは関係 $`\mathcal R`$ の連結成分ごとに一つずつ自由生成元を持つ自由可換群である（実際、各生成元をその連結成分の基底へ送る写像と、各連結成分の基底を選んだ代表の剰余類へ送る写像とが、関係 $`\mathcal R`$ の経路に沿う差の和が商で $`0`$ になることによって代表の選び方に依存せず、互いに逆になる）。

各被覆元上の局所状態空間を $`M`$ の torsor とし、生成元はその同値類の加算として実際に作用するものとする。
各有向交差辺 $`e`$ にアフィン遷移 $`x\mapsto x+\xi_e`$ を指定し、逆向きの辺にはその逆遷移を割り当てる。
被覆元上の定数 torsor の層をこの遷移で貼り合わせる（三重交差が空であるため追加の三重整合式は不要であり、遷移とその逆の合成が恒等であることから層が定まる）。

各被覆元 $`v`$ で局所状態 $`p_v`$ を選び、固定した原点表示における**不一致（mismatch）**を

```math
g_e=\xi_e+p_{s(e)}-p_{t(e)}\in M
```

と計算する。この不一致 $`g`$ は実際の遷移と局所状態のみから決まり、診断複体は用いない。
三重交差が空であるため $`g`$ は 1-コサイクルであり、そのコホモロジー類 $`[g]\in H^1(G;M)`$ が**指定された実際の障害**である。
頂点補正 $`n_v\in M`$ によって局所状態を $`p_v+n_v`$ へ変更すると、不一致は $`g-dn`$ へ移る。
したがって $`[g]=0`$ であることと、頂点補正によってすべての実際の遷移を満たす局所状態を得られることとは同値であり、補正後の整合した局所状態は torsor の層の貼り合わせによって大域状態を与える。
なお、[定理12.5](../part_4/chapter_12_deformations_and_obstructions.md#124-局所的な持ち上げの貼り合わせと意味比較)の符号規約 $`r_{ij}=p_j-p_i`$ では共通の表示へ運ぶと $`r=-g`$ となるが、複体の符号反転同型が両指定類を対応させるため、同じ実際の状態の貼り合わせを判定している。

一方、Law 値評価 $`\lambda:P\to\mathscr L`$、$`(\ell,s)\mapsto(\ell,\lambda_\ell(s))`$ と同じ被覆・支持から、診断複体 $`D_q`$ を独立に生成する。
原始関係 $`\mathcal R`$ はラベルを保つと仮定する。
各原始生成元をそのラベルの基底元へ送ることで群準同型 $`M\to\mathbb Z^{\mathscr L}`$ を構成し、可視頂点・可視辺へ制限して有理化すると、微分と可換するコチェイン写像 $`F:C^\bullet(G;M)\to D_q^\bullet`$ が得られる。
**診断類**は、実際の不一致の生成式にこの読み取り写像 $`F`$ を適用したコサイクルの類として定義する。したがってその生成をたどると

```math
\mathrm{diag}(g)=H^1(F)[g]\in H^1(D_q)
```

となる。原点や局所状態を取り替えても差は $`dF(n)`$ となるため、同じ指定類が定まる。

次の定理は、関係 $`\mathcal R`$ が同じラベルを持つ生成元をすべて結ぶ（関係完全性）かつすべての非橋辺が可視であるときに、診断類の消滅が実際の整数補正の存在を正確に反映することを保証する。

**定理16.13（可視閉路による実際の障害の零性反映）.**
構成16.12において、同じラベルを持つ任意の二つの生成元が関係 $`\mathcal R`$ の有限ジグザグ列で結ばれると仮定する（関係完全性）。
各ラベル $`a`$ の可視部分グラフ $`G_a`$ が $`G`$ のすべての非橋辺を含むならば、次が同値である。

```math
\mathrm{diag}(g)=0\quad\Longleftrightarrow\quad[g]=0
\quad\Longleftrightarrow\quad
\exists n\in C^0(G;M),\ dn=g.
```

ここで**橋**とは、その辺を取り除くとグラフの連結成分数が増える辺のことをいう。
さらに、得られる補正 $`n`$ から各局所 torsor への実際の整数生成操作を復元できる。

**証明.**
まず係数群とラベル空間を同定する。関係 $`\mathcal R`$ はラベルを保ち、かつ同じラベルを持つすべての生成元をジグザグ列で結ぶため、関係の連結成分から発生ラベルの集合 $`\mathscr L`$ への写像は全単射となる。
構成16.12の自由基底の記述から同型 $`M\cong\mathbb Z^{\mathscr L}`$ が得られ、この同型は各原始生成元をその評価ラベルへ送るため、実際の遷移の読み取りとも可換する。

次に $`\mathrm{diag}(g)=0`$ を仮定して整数補正 $`n`$ を構成する。
上の同型により、各ラベル $`a`$ ごとに整数成分 $`g_{e,a}\in\mathbb Z`$ を読み取る。
診断類が $`0`$ であることは、可視部分グラフ $`G_a`$ 上で $`g_{e,a}=b_{t,a}-b_{s,a}`$ を満たす有理数のポテンシャル $`b`$ が存在することを意味する。
グラフ $`G`$ の任意の単純閉路に属する辺はすべて非橋辺であるため、仮定により $`G_a`$ において可視である。したがって、任意の単純閉路に沿った向き付き和 $`\sum g_{e,a}`$ はポテンシャルの差の相殺によって $`0`$ になる。

そこで $`G`$ の各連結成分について全域木と根を一つ選び、根で $`n_{v,a}=0`$ と置いたうえで、全域木の道に沿った整数 $`g_{e,a}`$ の和として各頂点の値 $`n_{v,a}\in\mathbb Z`$ を定める。
全域木に属する辺では定義により $`(dn)_{e,a}=g_{e,a}`$ が成り立つ。
全域木に属さない任意の辺は、全域木内の道と合わせて一つの単純閉路を作るが、その閉路に沿った $`g_{e,a}`$ の向き付き和が $`0`$ であるため、この辺でも等式 $`(dn)_{e,a}=g_{e,a}`$ が成立する。
こうしてすべての辺で整数補正 $`n_{v,a}`$ が得られた。ラベル集合が有限であるため、これを同型 $`M\cong\mathbb Z^{\mathscr L}`$ によって $`M`$ 値の頂点補正 $`n\in C^0(G;M)`$ へ戻せる。各係数は原始生成元の整数回の作用として実現でき、$`dn=g`$ が実際の局所状態の不一致を完全に消去する。

逆向きは直接的である。実際の補正 $`n\in C^0(G;M)`$ が $`dn=g`$ を満たすならば、$`F(n)`$ が診断複体における 0-コチェイン原像（原始元）となり、$`dF(n)=F(dn)=F(g)`$ から $`\mathrm{diag}(g)=0`$ が従う。□

この証明はコホモロジー空間 $`H^1(D_q)`$ 全体の消滅を要求しておらず、与えられた一つの指定類 $`[g]`$ のみを追跡している点に注意する。
また、すべての非橋辺が可視であるという条件は、すべての整数不一致について零性反映が成り立つための必要条件でもある。
実際、非橋辺 $`e`$ がラベル $`a`$ において可視でないならば、その辺の $`a`$ 座標だけを $`1`$ とした不一致は診断類として $`0`$ になるが、$`e`$ を含む単純閉路の和は $`\pm1`$ となるため実際の障害類 $`[g]`$ は非零である（この不一致は $`p_v=0`$ および指定された遷移 $`\xi_e`$ によって実際に生成できる）。

**例16.14（反映条件を原始データで調べる）.**
三角形の三辺すべてで一つのラベルが見え、$`M=\mathbb Z`$、局所状態をすべて $`0`$ とする。
- 遷移値を $`(1,0,0)`$ とすると、閉路に沿った和は $`1`$ であり、実際の障害類も診断類も非零となる。
- 遷移値を $`(1,1,-2)`$ とすると、閉路和は $`0`$ となり、頂点補正 $`(0,1,2)`$ を取れば実際の不一致が消える。
- 三辺のうち一つを見えなくすると、最初の不一致 $`(1,0,0)`$ をその見えない辺に配置できるため、診断類は零性反映を失う。

関係完全性も同様に必要である。二つの生成元 $`p,p'`$ が同じラベルを持つにもかかわらず関係 $`\mathcal R`$ が空である場合、$`M=\mathbb Z^2`$ となる。
三角形の一辺の不一致を $`[p]-[p']`$、残る 2辺の不一致を $`0`$ とすると、この非橋辺を通る実際の閉路類は $`M`$ において非零だが、ラベル空間への読み取り写像 $`F`$ による像は $`0`$ になる。この例は、ラベルの等号を係数群における関係と安易に同一視できないことを明確に示している。

なお、定理16.13ではすべての頂点における $`M`$ 値の補正を許している。
固定部分や許可範囲を課す修復問題では、許容される補正の像を用いる相対的な指定障害へ移行する必要がある（たとえば 1本の辺の両端を厳密に固定すると、$`H^1`$ が $`0`$ であってもその辺の非零不一致は修復できない）。
そのような問題ですべての解と再同定を回復するには、[第11章](../part_4/chapter_11_ariadne_relative_repairs.md)の範囲付き複体・実際の補正作用・すべての比較射の対応を併せて用いる。
また、第12章の平方零持ち上げ障害は、指定された変形問題の係数と次数から作られる類であり、本節の貼り合わせの 1類へ移す際にも、その局所持ち上げと係数比較を保持する。

## 16.6 双対評価と有限 Hilbert 複体による読取り

最後に、診断複体のコホモロジー類が零であるかどうかを具体的な数値や最小残差として読み取るための二つの線形代数的方法――双対サイクルによる完全ペアリング（周期）と、内積を入れた有限 Hilbert 複体上の Hodge 分解――を与え、前節の零性反映定理と統合する。

**定理16.15（完全ペアリングと比較）.**
体 $`\Lambda`$ 上のコチェイン複体 $`D`$ であって各次数が有限次元であるものを取る。
その双対チェイン複体を $`D^\vee_n=\mathrm{Hom}_\Lambda(D^n,\Lambda)`$、微分を $`\partial_n=(d^{n-1})^\vee`$ によって定める。
このとき、自然な評価写像は完全ペアリング

```math
H^n(D)\times H_n(D^\vee)\longrightarrow\Lambda,
\qquad\langle[x],[z]\rangle=z(x)
```

に降りる。さらに、任意のコチェイン写像 $`f:D\to D'`$ に対して随伴関係

```math
\langle H^n(f)x,z'\rangle=\langle x,H_n(f^\vee)z'\rangle
```

が成り立つ。したがって、指定されたコホモロジー類 $`x\in H^n(D)`$ が $`0`$ であることと、すべての双対サイクル $`z`$ に対する評価が $`0`$ であることは同値である。

**証明.**
まずペアリングが商に降りることを確かめる。双対サイクル $`z`$ は $`\partial_n z=z\circ d^{n-1}=0`$、すなわち $`\mathop{\mathrm{im}}d^{n-1}`$ を消す線形汎関数であるから、コサイクル $`x`$ の代表を変えても評価 $`z(x)`$ は変わらない。逆に双対の微分像の元は $`\lambda\circ d^n`$ の形であり、コサイクル $`x\in\ker d^n`$ を消すため双対側の代表にもよらない。

次に完全性（同型 $`H_n(D^\vee)\cong\mathrm{Hom}_\Lambda(H^n(D),\Lambda)`$）を示す。$`Z^n=\ker d^n`$、$`B^n=\mathop{\mathrm{im}}d^{n-1}`$ と置く。
商空間 $`Z^n/B^n`$ 上の任意の線形汎関数を $`Z^n`$ へ引き戻し、$`Z^n`$ の基底を $`D^n`$ の基底へ延長して $`D^n`$ 全体上の線形汎関数へ延ばす。この延長は $`B^n`$ を消すため双対サイクルとなる。
二つの延長の差は $`Z^n`$ を消すため、同型 $`D^n/Z^n\cong\mathop{\mathrm{im}}d^n`$ を経由する。その像 $`\mathop{\mathrm{im}}d^n\subseteq D^{n+1}`$ 上の線形汎関数を $`D^{n+1}`$ 全体へ延ばせば、差は $`\lambda\circ d^n=\partial_{n+1}\lambda`$ と書ける。
よって自然な写像 $`H_n(D^\vee)\to\mathrm{Hom}_\Lambda(H^n(D),\Lambda)`$ は全単射であり、有限次元性からペアリングは両側で非退化（完全）である。

比較の式は恒等式 $`z'(f(x))=(z'\circ f)(x)`$ そのものであり、商に降りてもそのまま保たれる。非零類に対してはそれを含む基底を選び、その座標汎関数を取れば非零評価が得られる。□

同じ診断複体に対するこの双対評価を**周期（period）**と呼ぶことができる。
少数の選んだサイクルだけでコホモロジー類の零性を判定するには、それらのホモロジー類が双対空間 $`H_n(D^\vee)`$ を張ることが必要十分である。
たとえば $`H^1(D)=\Lambda^2`$ で第一座標だけを読み取ると、非零類 $`(0,1)`$ を検出できない。一般の評価写像が存在することだけから非零類の分離は従わない。

次に、実数体または複素数体上の内積を導入して、各コホモロジー類に一意な最小ノルム代表（調和代表）を対応させる。

**定理16.16（Hodge 分解・調和代表・最小残差）.**
$`\Lambda=\mathbb R`$ または $`\mathbb C`$ とし、各次数が有限次元の $`\Lambda`$ 上のコチェイン複体 $`(D,d)`$（$`d^nd^{n-1}=0`$）を取る。
各 $`D^n`$ に正定値内積（$`\Lambda=\mathbb C`$ のときはエルミート（Hermitian）内積）を選ぶ。微分の随伴作用素と Laplacian を

```math
\Delta_n=d^{n-1}(d^{n-1})^*+(d^n)^*d^n,\qquad
\mathcal H^n=\ker\Delta_n
```

と定めると、直交分解

```math
D^n=\mathop{\mathrm{im}}d^{n-1}\ \mathbin{\perp}\
\mathcal H^n\ \mathbin{\perp}\ \mathop{\mathrm{im}}(d^n)^*
```

が成り立ち、各コホモロジー類は一意な調和代表（$`\mathcal H^n`$ の元）を持つ。
さらに、コサイクル $`g\in\ker d^n`$ の調和空間 $`\mathcal H^n`$ への直交射影を $`h(g)`$ とすると、最小残差等式

```math
\min_{c\in D^{n-1}}\|g-dc\|=\|h(g)\|
```

が成り立つ。

**証明.**
随伴作用素の定義から $`\langle\Delta_nx,x\rangle=\|(d^{n-1})^*x\|^2+\|d^nx\|^2`$ が成り立つため、内積の正定値性により $`\mathcal H^n=\ker d^n\cap\ker(d^{n-1})^*`$ を得る。
複体条件 $`d^nd^{n-1}=0`$ から二つの像 $`\mathop{\mathrm{im}}d^{n-1}`$ と $`\mathop{\mathrm{im}}(d^n)^*`$ は互いに直交し、それらの和の直交補空間はちょうど $`\ker(d^{n-1})^*\cap\ker d^n=\mathcal H^n`$ に一致する。有限次元性から、直交補空間を取ることで主張の直交直和分解が全空間を覆う。

任意のコサイクル $`g\in\ker d^n`$ をこの分解に従って書き、第三成分を $`(d^n)^*w`$ とする。前の二つの成分は $`d^n`$ で $`0`$ になるため $`d^n(d^n)^*w=d^ng=0`$ を得る。これと $`w`$ との内積を取れば $`\|(d^n)^*w\|^2=0`$ となり、第三成分は $`0`$ である。
したがって $`g=dc_0+h(g)`$ と分解でき、微分の像の成分 $`dc_0`$ と調和成分 $`h(g)`$ は一意に決まる。完全な（微分の像に属する）調和元は自分自身にも直交するため $`0`$ であり、よって自然な写像 $`\mathcal H^n\to H^n(D)`$ は同型となる。
最後に、任意の $`c\in D^{n-1}`$ について直交性から

```math
\|g-dc\|^2=\|h(g)\|^2+\|d(c_0-c)\|^2
```

が成り立つため、最小値 $`\|h(g)\|`$ は $`c=c_0`$ において達成される。□

以上の定理16.13・16.15・16.16を、生成された診断複体と実際の補正問題へ適用してまとめる。

**系16.16a（生成診断・実際の比較・実際の補正への適用）.**
定義16.1の有限データから作られる体 $`\Lambda`$ 上の診断複体 $`D_{q,\Lambda}`$ と、命題16.2から作られるコチェイン写像 $`F_m:D_{q_c,\Lambda}\to D_{q_f,\Lambda}`$ には、定理16.15の完全ペアリングと比較式がそのまま適用できる。
さらに $`\Lambda=\mathbb R,\mathbb C`$ のときは、各セル座標に内積を選んで定理16.16も適用できる。

以下では $`\Lambda=\mathbb R`$ または $`\mathbb C`$ とする。構成16.12の実際の不一致 $`g\in C^1(G;M)`$ とコチェイン写像 $`F:C^\bullet(G;M)\to D_{q,\mathbb Q}`$ を取り、$`F_\Lambda`$ を $`F`$ の値を $`D_{q,\Lambda}=D_{q,\mathbb Q}\otimes_{\mathbb Q}\Lambda`$ へ送る写像とする。
このとき、すべての整数補正 $`n\in C^0(G;M)`$ に対して

```math
F_\Lambda(dn)=d^0F_\Lambda(n),\qquad
\|h(F_\Lambda g)\|\leq\|F_\Lambda(g-dn)\|
```

が成り立つ。さらに、定理16.13の関係完全性と非橋辺可視性の仮定のもとでは、次の五条件はすべて同値である。

```math
\begin{aligned}
\|h(F_\Lambda g)\|=0
&\quad\Longleftrightarrow\quad
 \langle\mathrm{diag}_\Lambda(g),z\rangle=0
 \quad\text{for all }z\in Z_1(D_{q,\Lambda}^\vee)\\
&\quad\Longleftrightarrow\quad\mathrm{diag}_{\mathbb Q}(g)=0
 \quad\Longleftrightarrow\quad[g]=0
 \quad\Longleftrightarrow\quad
 \exists n\in C^0(G;M),\ dn=g.
\end{aligned}
```

**証明.**
有限 Source と有限セル系から構成されるため、複体 $`D_{q,\Lambda}`$ の各次数は有限個のラベル付きセルを基底とする有限次元ベクトル空間である。
微分は同じ整数接続行列、$`F_m`$ は写るセルの評価と退化セルの $`0`$ からなる行列である。
したがって命題16.2の整数等式を $`\Lambda`$ へ送れば $`dF_m=F_md`$ となり、定理16.15の双対写像はこの具体的な行列の転置として与えられる。これにより生成比較とペアリングの比較式が同定される。また内積を選んだときの随伴は同じ行列の内積に関する随伴であり、微分との可換式の随伴も成り立つ。

係数群 $`M`$ をラベルへ送る準同型と可視辺への制限は端点差と可換するため、構成16.12の $`F(dn)=dF(n)`$ を係数拡張することで等式 $`F_\Lambda(dn)=d^0F_\Lambda(n)`$ を得る。
$`F_\Lambda g`$ はコサイクルであるため、定理16.16の最小残差等式で $`c=F_\Lambda(n)`$ を代入すれば下界 $`\|h(F_\Lambda g)\|\leq\|F_\Lambda(g-dn)\|`$ が従う（なお、この下界は診断側のすべての 0-コチェインにわたる最小値であり、最小値を達成する 0-コチェインが実際の整数補正の像に入ることは最小性だけからは結論しない）。

最後に五条件の同値性を確かめる。体の拡大 $`\mathbb Q\hookrightarrow\Lambda`$ は平坦であるため、有限行列の核と像は係数拡張と交換し、$`H^1(D_{q,\Lambda})\cong H^1(D_{q,\mathbb Q})\otimes_{\mathbb Q}\Lambda`$ が成り立つ。
基底を取れば標準写像 $`x\mapsto x\otimes1`$ は単射であるため、$`\mathrm{diag}_\Lambda(g)=0`$ は指定有理類 $`\mathrm{diag}_{\mathbb Q}(g)=0`$ を反映する。
調和代表の零性とコホモロジー類の零性の同値は定理16.16から、すべての周期の零性との同値は定理16.15からそれぞれ従う。
残る二つの同値は定理16.13そのものであり、その全域木による構成から整数補正 $`n`$ を具体的に構成し、原始生成操作の作用へ戻すことができる。こうして同じ実際の不一致に対する五条件すべての同値性が示された。□

**同じ三角形の読み取り.**
例16.14の向き付き三辺と標準内積においては、$`d(c_0,c_1,c_2)=(c_1-c_0,c_2-c_1,c_0-c_2)`$ である。
双対サイクル $`z=(1,1,1)`$ に対する周期は $`g_1+g_2+g_3`$ であり、調和射影とそのノルムは

```math
h(g)=\frac{g_1+g_2+g_3}{3}(1,1,1),\qquad
\|h(g)\|=\frac{|g_1+g_2+g_3|}{\sqrt3}
```

と計算される。
$`g=(1,0,0)`$ では周期が $`1`$、最小残差は $`1/\sqrt3`$ である。
一方 $`g=(1,1,-2)`$ では両者が $`0`$ となり、同じ実際の整数補正が復元される。
ここで実数・複素数の最小化自体はそれらの係数の補正全体に対する主張であり、本例で整数補正まで復元できるのは、定理16.13の全域木による整数復元を併せて用いているためである。

なお、比較写像が各次数でユニタリ（unitary）な複体同型であれば、微分の可換式の随伴を取ることで Laplacian および調和射影とも可換する。
しかし一般のコチェイン同型ではこの結論は成り立たない。たとえば $`D^0=\mathbb R`$、$`D^1=\mathbb R^2`$、$`d(c)=(c,0)`$ に標準内積を入れ、$`F^0=1`$、$`F^1(x,y)=(x+y,y)`$ と置くと、$`F`$ は複体同型であるが、調和元 $`(0,1)`$ を非調和元 $`(1,1)`$ へ送ってしまう。
このように、コホモロジー類の輸送は定理16.15によって内積によらず成り立つが、調和代表そのものの輸送には内積との整合条件を含めて扱う必要がある。

本章から第17章へは、診断写像とその核、および指定類を分離する双対評価を受け渡す。
第18章の修復方程式へは、同じ原始的な不一致、許容補正の微分像、および指定障害とその読み取りを受け渡す。Hodge 表示は、選んだ実・複素内積のもとでこの指定類を読み取る一つの方法を与えるものである。

**問題16.17.**
面と非自明な係数輸送を持つ被覆について、原始関係から作られる係数、実際の不一致、および可視セルへの比較を保持する零性反映条件を求める。有限自由整数係数と指定整数比較に対しては、16.12節の構成16.28・定理16.29がねじれを含めた有限判定を与える。一般の関係係数や無限セル系へこの判定を拡張する条件を求めよ。

**問題16.18（診断の比較から修復全体を回復する条件）.**
固定部分と許可範囲を持つ第11章の修復 groupoid について、診断の比較からすべての対象とすべての再同定を回復する条件を求めよ。指定障害類の零性反映に加え、どの核と射の条件が必要か。構成11.20が原始操作から生成するのは修復複体間の写像 $`F_S:C_S\to C'_S`$ であり、定理11.21–11.22は、この比較について指定修復上のファイバーと、全欠陥に対する回復の必要十分条件を与える。残る問題は、Law 値診断複体 $`D_q`$ への比較を、再同定・補正・欠陥と許可範囲を保つ形で原始データから構成し、この判定へ接続する条件である。16.5節の比較は補正を次数 $`0`$ に置くため、この再同定の次数を含む比較とは別に扱う。

**問題16.19（実現商上の診断）.**
有限根スキームによる診断を、チャート間の比較と生成元を忘れる商スタック上で構成する条件を求めよ。16.13節の定理16.32は、不変なスカラー読み出しと同変な原始自己準同型のスペクトル診断について降下を構成する。基底に依存する成分は、フレームまたは指定ベクトルと共変ベクトルを保持して読める。一般に値域も輸送する読み出しについて、値域の同型とその合成条件から根の比較・face 制限・診断の降下を構成する条件を求めよ。

## 16.7 指定した補正をそのまま持ち上げる

比較先で一つの補正を指定すると、元の障害が消えることに加えて、その補正値自体を実現できるかが問題になる。16.2節の写像錐はこの追加条件も保持する。

**定理16.20（指定補正、全解、残差）.**
任意の非負次数のアーベル群複体 $`C,D`$ とコチェイン写像 $`F:C\to D`$ を取る。$`z\in Z^1(C)`$ と $`b\in D^0`$ が $`d_Db=F^1z`$ を満たすとする。負次数には零を置き、16.2節と同じ符号で写像錐を作る。このとき

```math
\{a\in C^0:d_Ca=z,\ F^0a=b\}\ne\varnothing
\iff [(b,-z)]=0\in H^0(\mathrm{Cone}(F)).
```

非空ならこの解集合は $`\ker H^0(F)`$ の torsor である。さらに、指定値を課さない解 $`a_0`$、すなわち $`d_Ca_0=z`$ が一つ得られたとき、

```math
r(b,z)=[b-F^0a_0]\in\mathop{\mathrm{coker}}H^0(F)
```

は $`a_0`$ の選択によらず、この残差の零性が指定補正の持ち上げと同値になる。16.2節の単射 $`\mathop{\mathrm{coker}}H^0(F)\hookrightarrow H^0(\mathrm{Cone}(F))`$ は $`r(b,z)`$ を $`[(b,-z)]`$ へ送る。

**証明.**
$`d(b,-z)=(d_Db-Fz,d_Cz)=0`$ である。負次数が零なので $`\mathrm{Cone}(F)^{-1}=C^0`$ であり、その元 $`a`$ の微分は $`(F^0a,-d_Ca)`$ である。したがって指定類の零性は、表示した二つの等式そのものである。二解の差は $`\ker d_C^0\cap\ker F^0`$ に属し、逆にその任意の元を加えても解である。非負複体では $`H^0=\ker d^0`$ だから、この群は $`\ker H^0(F)`$ に等しく、作用は自由かつ推移的である。

$`d_D(b-Fa_0)=Fz-Fz=0`$ なので残差は $`H^0(D)`$ の元を表す。別の解 $`a_1`$ を用いると差は $`F(a_1-a_0)`$、$`a_1-a_0\in H^0(C)`$ であるから余核の類は変わらない。残差が零なら $`b-Fa_0=Fc`$ となる $`c\in H^0(C)`$ を取り、$`a_0+c`$ が指定解になる。逆は同じ式から従う。最後に $`(b,-z)-d(0,a_0)=(b-Fa_0,0)`$ である。□

**例16.21（半整数の指定値とねじれ）.**
一本の辺 $`0\to1`$ に対して $`C^0=\mathbb Z^2,C^1=\mathbb Z`$、$`d(a_0,a_1)=a_1-a_0`$ とし、$`D`$ は同じ式の有理数係数版、$`F`$ は包含とする。$`z=0`$、$`b=(1/2,1/2)`$ は適合するが、整数値の指定解はない。通常の解 $`a_0=(0,0)`$ から得る残差は、$`\mathop{\mathrm{coker}}H^0(F)=\mathbb Q/\mathbb Z`$ の $`[1/2]`$ である。

同じ辺で両側の係数を $`\mathbb Z/4`$、比較を $`F(x)=2x`$ に変え、$`z=0,b=(2,2)`$ とすると、指定解は $`(1,1),(3,3)`$ の二つであり、$`\ker H^0(F)\simeq\mathbb Z/2`$ が単純推移的に作用する。一方、同じ比較で $`b=(1,1)`$ を指定すると、残差は余核 $`\mathbb Z/2`$ の非零類となり、指定解は存在しない。自由性やねじれの不存在を定理の仮定に加える必要はない。

構成16.12に適用するときは、実際の不一致を $`z=g`$ と置き、この定理の解 $`a`$ によって局所状態を $`p_v+a_v`$ へ更新する。辺上では $`g'_e=\xi_e+(p_{s(e)}+a_{s(e)})-(p_{t(e)}+a_{t(e)})=g_e-(d_Ca)_e=0`$ となり、同じ補正が $`F^0a=b`$ によって指定された診断補正を厳密に実現する。零性反映によって通常の解 $`a_0`$ を得た場合にも、指定値との差は上の残差で改めて判定する。

第11章の修復では、再同定・補正・欠陥がそれぞれ次数 $`0,1,2`$ にある。その設定における指定修復上のファイバーと、すべての修復・すべての再同定の比較は、[定理11.21–11.22](../part_4/chapter_11_ariadne_relative_repairs.md#1110-原始操作の比較と指定修復のファイバー)で与えられる。そこでは同じ写像錐の $`H^1,H^0,H^{-1}`$ が、順に指定先への持ち上げの存在・同型類・自己同型を記述する。

## 16.8 支持と整合する表示変更

定義16.1のセル系について、任意の $`A\subseteq T`$ が選ぶ部分セル系を

```math
K[A]=\{\sigma\in K\mid T_\sigma\cap A\ne\varnothing\},\qquad
C_n(K[A];\Lambda)=\Lambda^{(K[A]_n)}
```

と書く。支持の face 包含により $`\partial`$ はこの加群を保つ。ラベル $`a=(\ell,w)`$ の値集合を $`A_a=\bar\lambda_\ell^{-1}(w)`$ とすれば、Law 値複体の $`a`$ 成分は $`C_\bullet(K[A_a];\Lambda)^\vee`$ であり、さらに支持 $`A`$ へ制限した成分は $`K[A\cap A_a]`$ から作られる。このため、任意の支持部分集合に対して同じ式で定義できる鎖写像と鎖ホモトピーを構成すれば、すべての Law 成分へ同時に適用できる。

以下では、定義16.1の一般の face 単調支持、すなわち $`T_\sigma\subseteq T_\tau`$（$`\tau`$ は $`\sigma`$ の face）を持つセル系を使う。追加セルの支持は次の等式で直接指定し、旧セルの incidence と支持は明記した箇所以外では保持する。面の三辺を $`e_0=e_{01},e_1=e_{02},e_2=e_{12}`$、その符号を $`\epsilon_0=1,\epsilon_1=-1,\epsilon_2=1`$ と書く。新セルには既存セルと異なる名前を付け、異なる出現にも異なる名前を付ける。以下で $`v=w`$ は許す。

**三角形追加の定義.** 辺 $`e:v\to w`$ に対し、新頂点 $`v'`$、辺 $`c:v\to v'`$、$`b:v'\to w`$、面 $`f=(c,e,b)`$ を追加し、旧セルはすべて残す。支持は

```math
T_{v'}=T_c=T_v,\qquad T_b=T_f=T_e
```

とする。$`T_e\subseteq T_v\cap T_w`$ により、これらは face 単調支持である。

**辺分割と再三角形化の定義.** 辺 $`e:v\to w`$ を除き、新頂点 $`v'`$ と辺 $`c:v\to v',b:v'\to w`$ を置く。出現集合を

```math
O_e=\{(F,i)\in K_2\times\{0,1,2\}\mid e_i(F)=e\}
```

とする。各 $`o=(F,i)\in O_e`$ に辺 $`d_o:v\to w`$ と面 $`t_o=(c,d_o,b)`$ を追加する。旧面 $`F`$ の名前を保持し、三辺のうち $`e`$ の各出現だけを対応する $`d_{F,i}`$ に置き換えた面を、中心面 $`F^\circ`$ と書く。$`e`$ が現れない旧面は変更せず $`F^\circ=F`$ と記す。支持は

```math
T_{v'}=T_c=T_v,\qquad T_b=T_{d_o}=T_{t_o}=T_e,\qquad
T_{F^\circ}=T_F
```

とする。中心面の支持は各出現で $`T_F\subseteq T_e=T_{d_o}`$ を満たし、他の face 包含も元の包含と表示した等式から従う。同じ面に同じ辺が複数回現れる場合も、位置ごとの $`d_{F,i},t_{F,i}`$ を保持する。

**三角形追加の逆パターンと復元.** 入力セル系を $`N`$ とし、頂点 $`v,v',w`$、互いに異なる辺 $`e,c,b`$、面 $`f`$ を指定する。$`v'\notin\{v,w\}`$、向き $`e:v\to w,c:v\to v',b:v'\to w`$、三辺 $`f=(c,e,b)`$、および支持等式

```math
T_{v'}=T_c=T_v,\qquad T_b=T_f=T_e
```

を要求する。さらに、すべての辺 $`a`$、面 $`F`$、位置 $`i\in\{0,1,2\}`$ について、全接続を次の必要十分条件で指定する。

```math
\begin{aligned}
s(a)=v'\ \text{または}\ t(a)=v'
 &\iff a=c\ \text{または}\ a=b,\\
e_i(F)=c&\iff F=f\ \text{かつ}\ i=0,\\
e_i(F)=b&\iff F=f\ \text{かつ}\ i=2.
\end{aligned}
```

この表から、頂点 $`v'`$、辺 $`c,b`$、面 $`f`$ を削除し、残るセルの支持・端点・三辺をそのまま使って $`K`$ を復元する。全接続条件により、残る辺の端点と残る面の三辺は削除されない。保持された辺 $`e`$ への三角形追加は、各追加名を $`v',c,b,f`$ とすることで元の $`N`$ を復元する。

**辺分割の逆パターンと復元.** 入力 $`N`$ に、頂点 $`v,v',w`$、辺 $`c,b`$、有限の添字集合 $`O`$、および各 $`o\in O`$ の辺 $`d_o`$、面 $`t_o`$、中心面と位置 $`(F_o,i_o)\in N_2\times\{0,1,2\}`$ を指定する。$`v'\notin\{v,w\}`$ とし、$`c,b,(d_o)_{o\in O}`$ は互いに異なり、$`t_o`$ も異なる $`o`$ では異なるとする。向きと三辺は

```math
c:v\to v',\qquad b:v'\to w,\qquad d_o:v\to w,
\qquad t_o=(c,d_o,b)
```

であり、支持について

```math
T_{v'}=T_c=T_v,\qquad T_{d_o}=T_{t_o}=T_b
```

を要求する。また、すべての $`o,o'\in O`$ について $`F_o\ne t_{o'}`$ とする。すべての辺 $`a`$、面 $`F`$、位置 $`i`$、添字 $`o`$ に対し、全接続を

```math
\begin{aligned}
s(a)=v'\ \text{または}\ t(a)=v'
 &\iff a=c\ \text{または}\ a=b,\\
e_i(F)=c&\iff \exists o'\in O:\ F=t_{o'}\ \text{かつ}\ i=0,\\
e_i(F)=b&\iff \exists o'\in O:\ F=t_{o'}\ \text{かつ}\ i=2,\\
e_i(F)=d_o&\iff
 (F=t_o\ \text{かつ}\ i=1)\ \text{または}\ (F=F_o\ \text{かつ}\ i=i_o).
\end{aligned}
```

で指定する。中心面 $`F_o`$ は異なる $`o`$ で同じでもよいが、最後の同値と $`d_o`$ の相異性から位置の組 $`(F_o,i_o)`$ は互いに異なる。

旧入力 $`K`$ は次の操作で構成する。$`v'`$ と辺 $`c,b,d_o`$、面 $`t_o`$ を削除し、残る辺と異なる新しい一辺 $`e:v\to w`$ を支持 $`T_e=T_b`$ で置く。残る各面の三辺では、$`d_o`$ の出現を $`e`$ へ置き換え、他の辺は保持する。残る頂点・辺・面の支持は $`N`$ のものをそのまま使う。従って、再展開時の中心面について $`T_{F^\circ}=T_F`$ となる。端点と全接続の条件により incidence は定まり、$`T_b\subseteq T_{v'}\cap T_w=T_v\cap T_w`$ と、各中心面での $`T_{F_o}\subseteq T_{d_o}=T_e`$ により支持も face 単調である。

復元した $`e`$ の全出現は $`o\mapsto(F_o,i_o)`$ でちょうど列挙される。実際、最後の同値の右辺の第一項は削除済みの面であり、残った $`d_o`$ の出現は第二項だけである。逆に、復元時に $`e`$ を入れた位置には相異なる $`d_o`$ のうち一つがあった。よって再分割の出現集合は $`O`$ と全単射になり、追加セルを $`d_o,t_o`$ と名付ければ、支持を含む元の全セル表 $`N`$ が復元される。$`O=\varnothing`$ の場合は面に接しない辺の分割の逆となる。いずれの逆パターンも、元の $`K`$ や表示同型を入力として受け取らず、指定セルと全接続条件からそれらを構成している。

**定理16.22（支持を保つ基本変形）.**
直前に定義した三角形追加、辺分割と再三角形化、およびそれぞれの逆パターンによる復元を基本変形とする。各基本変形で結ばれるセル系 $`K,K'`$ は、任意の可換係数環 $`\Lambda`$、任意の $`A\subseteq T`$ に対して、明示的な鎖ホモトピー同値 $`C_\bullet(K[A];\Lambda)\simeq C_\bullet(K'[A];\Lambda)`$ を持つ。この同値は支持部分集合 $`A`$ の包含に関して自然であり、各 Law 値成分のコホモロジーをすべての次数で保つ。

**証明.**
鎖写像 $`r:C_\bullet(K')\to C_\bullet(K)`$、$`s:C_\bullet(K)\to C_\bullet(K')`$ と次数 $`+1`$ の写像 $`h`$ を構成し、

```math
rs=1,\qquad 1-sr=\partial h+h\partial
\qquad\text{(16.22a)}
```

を基底で確かめる。支持付きの基底式がすべての $`K[A]`$ に制限できるための十分条件は、非零係数で現れる各像セルの支持が元セルの支持を含むことである。

**三角形追加.**
$`s`$ は旧セルの包含とし、$`r`$ は旧セルで恒等、$`r(v')=v`$、$`r(c)=0`$、$`r(b)=e`$、$`r(f)=0`$ とする。$`h_0(v')=c`$、$`h_1(b)=f`$ とし、残る基底で $`h=0`$ とする。$`r\partial f=0-e+e=0`$ と端点の式により $`r,s`$ は鎖写像である。新セルについて式(16.22a)は

```math
\begin{aligned}
v'-v&=\partial c,\\
c&=h_0(v'-v),\\
b-e&=\partial f+h_0(w-v'),\\
f&=h_1(c-e+b)
\end{aligned}
```

となり、旧セルでは両辺が零である。$`T_{v'}=T_c`$、$`T_b=T_f`$ および $`T_e\subseteq T_v`$ が各写像の支持条件を与える。$`T_e\cap A=\varnothing`$ であっても、選ばれる新セルは $`v',c`$ の対だけ、またはいずれも無しとなり、同じ式が成立する。

**辺分割と再三角形化.** 写像を

```math
\begin{aligned}
&r(v')=v,\quad r(c)=0,\quad r(b)=r(d_o)=e,\quad
  r(t_o)=0,\quad r(F^\circ)=F,\\
&s(e)=c+b,\qquad
  s(F)=F^\circ+\sum_{i:e_i(F)=e}\epsilon_i t_{F,i},\\
&h_0(v')=c,\qquad h_1(d_o)=-t_o
\end{aligned}
```

と定める。$`r,s`$ は他の旧頂点・旧辺で恒等、$`h`$ は表示した以外の基底で零である。特に $`h_1(b)=0`$ である。$`\partial t_o=c-d_o+b`$ を代入すると、$`\partial s(F)`$ では各 $`d_o`$ が相殺され、$`e`$ の各出現が $`c+b`$ に置き換わる。よって $`\partial s=s\partial`$ である。$`r`$ の鎖写像条件も $`r\partial t_o=0-e+e=0`$ と中心面の三辺から従う。さらに

```math
\begin{aligned}
(1-sr)b&=-c=h_0(w-v'),\\
(1-sr)d_o&=d_o-c-b=-\partial t_o,\\
(1-sr)F^\circ&=-\sum_{i:e_i(F)=e}\epsilon_i t_{F,i}
              =h_1\partial F^\circ,\\
(1-sr)t_o&=t_o=h_1(c-d_o+b)
\end{aligned}
```

であり、$`v',c`$ では三角形追加と同じ計算を使う。これですべての基底について式(16.22a)が確かめられた。$`s(F)`$ の追加面には $`T_F\subseteq T_e=T_{t_o}`$、$`h_1(d_o)`$ には $`T_{d_o}=T_{t_o}`$ があり、残る支持条件も表示した等式から従う。ループや反復出現を含む場合も計算は同じであり、$`O_e=\varnothing`$ は面に接しない辺の通常の分割となる。

**逆縮約.** 定理前の復元で得た $`K`$ を展開すると、入力 $`N`$ と、名前・incidence・支持を保つ同型が得られる。この構成した同型を介して、上の $`r,s,h`$ を使う。

以上の基底式は支持の包含を保つので、任意の $`A`$ と各 Law 成分へ制限できる。双対を取ると、原始収縮のコチェイン比較 $`r^*`$ と $`s^*`$ は互いにホモトピー逆となる。二つの収縮を合成するときは $`r=r_1r_2`$、$`s=s_2s_1`$、$`h=h_2+s_2h_1r_2`$ とすれば式(16.22a)が成り立つため、有限列でも結論が保たれる。

さらに十分 reading の細分 $`\rho:T_f\twoheadrightarrow T_c`$ について、同じセル名と incidence を使い、$`T_\sigma^f=\rho^{-1}T_\sigma^c`$ とした場合、$`T_\sigma^c\cap A\ne\varnothing`$ と $`T_\sigma^f\cap\rho^{-1}A\ne\varnothing`$ は同値である。したがってセル名の恒等対応が各支持複体の同型を与え、Law 値の降下式によって各ラベルとも整合する。この reading 変更と基本変形との任意の有限合成にも、同じ結論が成立する。□

**例16.23（面の複製は二次コホモロジーを増やす）.**
面 $`F`$ と同じ三辺・支持を持つ別名の面 $`\widehat F`$ を追加する。収縮 $`r`$ は $`r(\widehat F)=F`$、旧セルで恒等である。$`F`$ が選ばれる支持成分では、新たな基底 $`\widehat F-F`$ の微分が零となるため、

```math
C_\bullet(K')\cong C_\bullet(K)\oplus\Lambda[2],\qquad
r=(1,0).
```

従って $`r^*`$ は $`H^0,H^1`$ で同型、$`H^2`$ で単射となり、その余核は $`\Lambda`$ である。この余核を読む写像は、二次コチェイン $`z`$ の $`z(\widehat F)-z(F)`$ である。$`F`$ が選ばれなければ新成分は現れない。具体的には、全支持の三頂点・三辺・一面からなる三角形では $`H^1=H^2=0`$ であり、面を一枚複製すると $`H^1=0,H^2=\Lambda`$ となる。これにより、一次比較の同型性から全次数のホモトピー同値を結論することはできない。

## 16.9 実セル交差による二領域の貼り合わせ

体 $`\Lambda`$ 上で、命題16.2の比較を $`u:C_c\to C_f`$ と書く。粗支持の部分集合 $`A,B\subseteq T_c`$ に対し、粗側では $`A,B`$、細側ではその $`\rho`$ による逆像でセルを選ぶ。$`s=c,f`$ それぞれで、$`K_{s,U}=K_{s,A}\cup K_{s,B}`$、$`K_{s,I}=K_{s,A}\cap K_{s,B}`$ とする。ここで $`I`$ は選ばれたセルの実際の交差である。あるセルの支持が $`A`$ と $`B`$ に別々の点で出会う場合も $`I`$ に入るので、$`A\cap B`$ に出会うセルだけを取った部分セル系とは異なり得る。

$`C_{s,X}=C_\bullet(K_{s,X};\Lambda)^\vee`$ と書く。制限写像と差制限により

```math
0\longrightarrow C_{s,U}
 \xrightarrow{i_s} C_{s,A}\oplus C_{s,B}
 \xrightarrow{r_s}C_{s,I}\longrightarrow0,
\qquad
r_s(x,y)=x|_I-y|_I
\qquad\text{(16.24a)}
```

は複体の短完全列となる。実際、$`U`$ 上の関数は交差で一致する二つの関数に一意に貼り合い、$`I`$ 上の関数を次数ごとに $`A`$ へ零延長し、$`B`$ 側を零とすれば $`r_s`$ の全射性を得る。この零延長は次数ごとの線形切断である。複体の射である制限写像の可換性は、選んだセル系が face で閉じることから従う。

原始比較は $`U,A,B,I`$ のすべてに制限できる。特に $`I`$ の細セルの二つの支持証人を別々に $`\rho`$ で運べば、その非退化な粗像は両粗領域に入る。非退化セルでの評価と退化セルでの零を照合すると、これらの比較と式(16.24a)は可換する。

**定理16.24（Mayer–Vietoris 列と比較）.**
原始セルから構成した式(16.24a)には、比較 $`u`$ と可換する長完全列

```math
\cdots\to H^n(C_{s,A})\oplus H^n(C_{s,B})
 \xrightarrow{r_s^n}H^n(C_{s,I})
 \xrightarrow{\delta_s}H^{n+1}(C_{s,U})
 \to H^{n+1}(C_{s,A})\oplus H^{n+1}(C_{s,B})\to\cdots
\qquad\text{(16.24b)}
```

がある。$`r_s^n`$ は差制限が誘導する写像である。また、同じ領域の比較錐 $`\mathop{\mathrm{Cone}}\nolimits (u_X)`$ に対しても、式(16.24a)の各写像を二座標へ適用して短完全列と長完全列が得られる。

**証明.** 交差上の閉元 $`z`$ を差制限によって組 $`(x,y)`$ に持ち上げると、$`(dx,dy)`$ は差制限の核に入る。従って $`U`$ 上の一意な閉元 $`w`$ へ貼り合い、$`\delta_s[z]=[w]`$ と定められる。持ち上げを変えた差は $`i_s(a)`$ の形なので $`w`$ は $`da`$ だけ変わり、$`z`$ の代表を $`dz'`$ だけ変える場合は $`z'`$ を持ち上げてその微分を加えればよい。よって類は選択によらない。

$`\delta_s[z]=0`$ なら $`w=da`$ として持ち上げから $`i_s(a)`$ を引くと閉元となるため、$`[z]`$ は差制限の像に入る。$`U`$ 上の閉元 $`w`$ が両領域で微分の像なら、その原始元を $`x,y`$ と取ると $`x|_I-y|_I`$ は閉元で、その連結像が $`[w]`$ となる。最後に閉元の組 $`(x,y)`$ の差制限が微分の像 $`dz'`$ なら、$`z'`$ の持ち上げの微分を引いて差制限を厳密に零にでき、その組は $`U`$ へ貼り合う。これが列の三種類の箇所の完全性を示す。同じ持ち上げを比較で運べば連結射も可換する。

錐の次数 $`n`$ は $`C_f^n\oplus C_c^{n+1}`$、微分は $`(y,x)\mapsto(d_fy+u(x),-d_cx)`$ である。両座標の短完全性と比較正方形から錐の短完全列が得られ、同じ持ち上げの議論を適用できる。□

局所一次比較が同型でも、大域比較には交差の零次と一次がともに寄与する。これを次の形で分離する。

**定理16.25（大域一次比較の必要十分条件）.**
$`T_X=H^1(u_X)`$ と書き、$`T_A,T_B`$ が同型であると仮定する。式(16.24b)から

```math
Q_s=\mathop{\mathrm{coker}}\nolimits r_s^0,\qquad
P_s=\ker r_s^1,\qquad
q:Q_c\longrightarrow Q_f,\quad q[z]=[H^0(u_I)z],
```

を定め、

```math
Z=\mathop{\mathrm{im}}\nolimits r_c^1\cap\ker H^1(u_I)
```

と置く。ここで $`Q_s,q,Z`$ はこの定理内の記号であり、$`q`$ は零次差制限の余核間の写像、$`Z`$ は交差上の一次コホモロジーの部分空間を表す。命題16.2の reading は引き続き $`q_c,q_f`$ と書く。このとき自然な同型と短完全列

```math
\ker T_U\cong\ker q,\qquad
0\longrightarrow\mathop{\mathrm{coker}}\nolimits q
 \longrightarrow\mathop{\mathrm{coker}}\nolimits T_U
 \longrightarrow Z\longrightarrow0
\qquad\text{(16.25a)}
```

がある。従って $`T_U`$ が同型であることは、$`q`$ が同型かつ $`Z=0`$ であることと同値である。特に有限次元の欠損は

```math
J(T_U)=\bigl(\dim\ker q,
             \dim\mathop{\mathrm{coker}}\nolimits q+\dim Z\bigr)
```

である。

**証明.** 長完全列から、各側の自然な短完全列

```math
0\to Q_s\xrightarrow{j_s}H^1(C_{s,U})
 \xrightarrow{t_s}P_s\to0,\qquad j_s[z]=\delta_s[z]
```

を得る。局所比較の直和 $`L=T_A\oplus T_B`$ は $`p:P_c\to P_f`$ を誘導し、$`q,T_U,p`$ が二行の短完全列の比較をなす。この比較の蛇の列は

```math
0\to\ker q\to\ker T_U\to\ker p
 \xrightarrow{\partial_{\mathrm{sn}}}\mathop{\mathrm{coker}}\nolimits q
 \to\mathop{\mathrm{coker}}\nolimits T_U\to\mathop{\mathrm{coker}}\nolimits p\to0.
```

その連結射は次の具体式で得られる。$`a\in\ker p`$ を $`b\in H^1(C_{c,U})`$ に持ち上げると、$`T_Ub=j_f(z)`$ となる一意な $`z\in Q_f`$ があり、$`\partial_{\mathrm{sn}}(a)=[z]`$ とする。別の持ち上げとの差は $`j_c(Q_c)`$ なので、$`z`$ の差は $`q(Q_c)`$ に入る。各箇所の完全性もこの式で確認できる。例えば $`[z]`$ が次の射の核に入れば $`j_f(z)=T_Ub`$ と書け、$`t_cb\in\ker p`$ の連結像が $`[z]`$ である。また $`[b_f]`$ が $`\mathop{\mathrm{coker}}\nolimits p`$ で消えるなら、$`t_fb_f=p(a_c)`$ を満たす $`a_c`$ の持ち上げ $`b_c`$ を取り、$`b_f-T_Ub_c\in j_f(Q_f)`$ として一つ前の像へ戻せる。他の箇所は同じ短完全列の核・像の同定から従う。

$`L`$ は同型だから $`p`$ は単射である。また

```math
P_f\longrightarrow Z,\qquad y\longmapsto r_c^1(L^{-1}y)
```

は全射で、核は $`p(P_c)`$ に等しい。像が $`Z`$ に入ることは $`H^1(u_I)r_c^1=r_f^1L`$ による。逆に $`z=r_c^1(x)\in\ker H^1(u_I)`$ なら $`Lx\in P_f`$ が $`z`$ へ移る。よって $`\mathop{\mathrm{coker}}\nolimits p\cong Z`$ であり、蛇の列から式(16.25a)が従う。

余核の包含は $`[z]\mapsto[\delta_fz]`$、射影は
$`[b_f]\mapsto r_c^1(L^{-1}t_fb_f)`$ である。従ってこの列は元の大域比較の実際の余核を中項に持つ。各 Law 値成分について $`A,B`$ をその値集合との交差へ替え、実セル交差を取れば同じ構成ができ、有限直和で Law 族全体の列になる。□

## 16.10 全順序組を生成する Source 別複体

**補題16.26（Source を保持した全組生成の消滅）.**
各 Source $`s`$ に、その Source が支える有限頂点集合 $`V_s`$ を与える。座標は Source の名前を保持し、同じ $`s`$ に属するすべての順序付き二つ組を辺、すべての順序付き三つ組を面として生成する。反復頂点も許す。任意の可換環 $`\Lambda`$ に対し、この生成規則で得る複体

```math
B^0=\bigoplus_s\Lambda^{V_s},\qquad
B^1=\bigoplus_s\Lambda^{V_s\times V_s},\qquad
B^2=\bigoplus_s\Lambda^{V_s^3}
```

の $`H^1`$ は零である。微分は

```math
(da)_s(u,v)=a_s(v)-a_s(u),\qquad
(dz)_s(u,v,w)=z_s(u,v)-z_s(u,w)+z_s(v,w)
```

とする。

**証明.** $`V_s\ne\varnothing`$ ごとに根 $`r_s\in V_s`$ を選び、閉元 $`z`$ に対し $`a_s(v)=z_s(r_s,v)`$ と置く。生成された面 $`(r_s,u,v)`$ の閉元条件は
$`z_s(r_s,u)-z_s(r_s,v)+z_s(u,v)=0`$ なので、$`da=z`$ である。空の $`V_s`$ は零成分を与える。□

この仮定は、各 Source を別座標に保ち、その支持上の全二つ組・全三つ組を生成する規則である。定義16.1では同じ Law 値を持つ複数 Source の証人を一つのセル座標へまとめるため、適用時にはこの Source 別の座標条件も照合する。生成した一次コホモロジーの零性は、この明示的な根からの原始元によって説明される。

## 16.11 診断次元を実現する幾何

実現を動かしたときの値の一致は、診断次元に幅広い変化を生じさせる。その変化を同じ原始表示から構成する。

**定理16.27（構成可能な診断次元の実現）.**
可換環 $`k`$ 上の有限表示アフィンスキーム $`B`$ を取り、有限個の正則関数の零・非零条件による分割上で一定な有限値関数 $`\beta:|B|\to\mathbb N`$ を与える。
有限の原始操作・Law・名前付き生成元から $`B`$ を実現スキームとして構成し、その上の正則読み出しと有限支持セル系から、任意の診断係数体 $`\Lambda`$ について

```math
\dim_\Lambda H^1((\mathscr D_B)_{\bar b})=\beta(b)
```

となる構成16.8の複体を生成できる。
一方、$`B=\mathrm{Spec}\,\mathbb Q[\lambda,\mu]`$ と $`\beta=\mathbf1_{V(\lambda)\cap D(\mu)}`$ に対して、すべての点で同じ導来ファイバーの一次 Betti 数を持つ pseudo-coherent $`\mathcal O_B`$-複体は存在しない。

**証明.**
[補題D.2・定理D.3](../appendix_d_finite_roots_and_stalks.md#d3-診断次元の原始的な実現)で、一つの局所閉集合の指示関数を閉路辺の読み出しと全支持 Source から作り、有限直和で $`\beta`$ を得た。同じ証明では階数一の原始単項操作の係数を座標とし、多項式 Law から $`B`$ 自体を構成している。
後半では、$`V(\lambda)`$ の生成点から原点への特殊化により次元が $`1`$ から $`0`$ へ下がる。[補題D.4・命題D.5](../appendix_d_finite_roots_and_stalks.md#d4-導来ファイバーの次元との相違)の三項自由複体の階数計算は、pseudo-coherent 複体の導来ファイバーの一次 Betti 数が上半連続であることを示すので、矛盾する。□

定理は、実現スキームの幾何と診断用の étale 層の幾何を同じ原始入力で結びつける。前者の剰余体と診断係数体 $`\Lambda`$ は別に指定され、両者の次元は整数値として比較される。

## 16.12 整数障害・有限素数冪・指定比較

整数コサイクルの調和射影は実数上の微分像への所属を判定する。整数修復まで回復するには、同じ複体のねじれを保持する必要がある。[付録CのC.5–C.7節](../appendix_c_homological_constructions.md#c5-整数複体の調和射影と有限算術判定)では、整数基底を指定した有限自由複体について、整数多項式から有限の検査集合と修復を構成している。ここでは、この判定を原始操作と元の比較写像へ接続する。

**構成16.28（原始操作からの整数修復行列）.**
第11章の有限セル表示、固定閉部分表示 $`P`$、候補名と許可範囲 $`S`$ を取り、各頂点の核を整数基底付き有限自由群 $`A_v`$ とする。式(11.1)から生成される核輸送 $`\rho_e`$ は整数可逆行列である。経路和 $`T_w`$、微分 $`d^0,d^1,d^2`$ は式(11.3)の加算と整数行列積から作られる。固定セルの座標を除き、禁止辺の補正座標を零にすると $`C_S^1,C_S^2,C_S^3`$ が得られる。$`C_S^0`$ は禁止辺における $`d^0b=0`$ の整数核であり、整数行・列基本変形で基底を取れる。この基底で $`C_S^\bullet`$ は有限自由整数複体となる。

実際の面の不一致から得た $`\delta`$ は $`d^2\delta=0`$ を満たす。$`z=-\delta`$ と置くと、修復は $`d^1h=z`$ であり、解から元の操作を $`L_e^h=\iota(h_e)\widetilde L_e`$ によって復元する。従って補題C.4の $`g_2=\det'((d^1)^\top d^1)`$ に対する定理C.5が、指定した実際の修復の存在と同値な有限算術判定を与える。合同解からの整数解の復元も同じ $`d^1`$ と同じ操作作用を使う。次数 $`1`$ に適用すれば、二つの修復の差に対して、それらを結ぶ整数再同定の存在を判定できる。

定義16.1の整数診断複体も、ラベル付き可視セルを基底とする有限自由整数複体である。命題16.2の比較はセルの評価と退化セルの零からなる整数行列なので、同じ判定を適用できる。構成16.12の係数は関係成分を基底とする自由群であり、各生成元をラベルの基底へ送る写像は整数上で定まる。この整数比較を有理数へ拡張したものが、16.5節の比較である。

**定理16.29（元の比較を保持する零性反映の有限条件）.**
有限自由整数複体の指定された比較 $`F:C^\bullet\to D^\bullet`$ を取る。整数行列

```math
M_F^n=
\begin{pmatrix}d_C^n&0\\F^n&-d_D^{n-1}\end{pmatrix}
:C^n\oplus D^{n-1}\longrightarrow C^{n+1}\oplus D^n
```

の整数核の基底を $`(z_j,b_j)`$ とする。次の三条件は同値である。

1. すべての整数コサイクル $`z`$ について、$`[Fz]=0`$ なら $`[z]=0`$ である。
2. すべての $`j`$ について $`z_j\in\mathop{\mathrm{im}}d_C^{n-1}`$ である。
3. すべての $`j`$ について実調和射影 $`h_C(z_j)=0`$ であり、$`p^\alpha\parallel g_n(C)`$ となる有限個の素数冪すべてに対して $`[z_j\bmod p^\alpha]=0`$ である。

**証明.**
核の元は正確に $`d_Cz=0,Fz=d_Db`$ を満たす対である。従って $`z`$ をそのコホモロジー類へ送る写像の像は $`\ker H^n(F)`$ である。この写像は群準同型であり、核の整数基底の像 $`[z_j]`$ がその像を生成するので、1と2が同値になる。2と3の同値は、同じ整数複体 $`C`$ に対する定理C.5である。

16.2節の錐の符号では、同じ対はコサイクル $`(b,-z)\in\mathrm{Cone}(F)^{n-1}`$ に対応する。このため上の条件は、長完全列の射影 $`H^{n-1}(\mathrm{Cone}(F))\to H^n(C)`$ の像が零である条件を、原始比較 $`F`$ の行列から有限に検査している。比較写像を他の都合のよい写像へ取り替える操作は含まれない。□

原始操作の比較からこの定理の $`F`$ を生成するには、同じ型付きセルの上で各核の整数写像 $`\phi_v:A_v\to A'_v`$ が輸送を保つこと、すなわち $`\phi_t\rho_e=\rho'_e\phi_s`$ を用いる。各セルの終点に $`\phi`$ を適用すると、経路長の帰納法で $`\phi T_w=T'_w\phi`$ となり、面と3-セルの差を取れば $`Fd=d'F`$ を得る。固定セルと禁止辺の零も保たれるので、$`F_S:C_S\to C'_S`$ が生成される。原始比較が基準操作と指定面比較を運ぶときは、式(11.2)から $`F_S\delta=\delta'`$ であり、式(11.1)から修正作用と全再同定も運ばれる。定理16.29の $`n=2`$ は、この同じ $`F_S`$ を介して指定欠陥の零性反映を判定する。

一つの指定欠陥だけを扱う場合は、構成16.28の算術判定をその欠陥へ適用すればよい。定理16.29は、すべての整数コサイクルにわたる零性反映を検査する条件であり、この量化を一つの成功例から結論しない。

**例16.30（面と非自明輸送が残すねじれ）.**
整数アフィン群 $`\mathbb Z\rtimes\{1,-1\}`$ を線形成分 $`\{1,-1\}`$ へ射影し、その先を一点へ射影する圏の塔を取る。群の射はすべて可逆なので設定11.1の強い opcartesian 性を満たし、射影の核は平行移動の群 $`\mathbb Z`$ である。

頂点を一つとし、その頂点とループ $`a(x)=-x`$、$`r(x)=x+1`$ を固定する。変更を許すループの基準を $`e(x)=x`$ とし、面の Law を、通常の写像合成記法で

```math
a\circ e\circ a=r\circ e
```

と指定する。指定面比較は恒等、3-セルはない。$`a`$ による輸送は $`-1`$、$`r,e`$ による輸送は $`1`$ であり、両経路の輸送は一致する。補正 $`e_h(x)=x+h`$ を代入すると左辺は $`x-h`$、右辺は $`x+h+1`$ となる。従って

```math
C_S^0=0,\quad C_S^1=\mathbb Z,\quad C_S^2=\mathbb Z,
\qquad d^1=-2,\quad\delta=-1,
\qquad -2h=1.
```

実修復 $`h=-1/2`$ は存在し、実調和射影は零である。しかし整数修復はなく、$`H^2(C_S)=\mathbb Z/2\mathbb Z`$ に指定された $`[-\delta]=[1]`$ は非零である。$`g_2=4`$ が指定する検査は $`\mathbb Z/4\mathbb Z`$ 上の $`-2h=1`$ であり、これは解を持たない。

さらに整数アフィン群の準同型 $`(v,\varepsilon)\mapsto(2v,\varepsilon)`$ で操作を運ぶ。これは $`a`$ を保ち、固定操作 $`r`$ を $`r'(x)=x+2`$ へ送る。生成比較は $`F^1=F^2=2`$、目標の欠陥は $`\delta'=-2`$ である。目標修復 $`-2h'=2`$ には整数解 $`h'=-1`$ がある。元の比較は $`\mathbb Z/2\mathbb Z`$ 上の零写像を誘導し、零性を反映しない。定理16.29では $`(z,b)=(1,-1)`$ が $`F^2z=d^1b`$ を満たし、その整数類が素数冪検査で検出される。これにより、面・非自明輸送・固定操作・元の比較をすべて保持したまま、実係数の零性と整数修復の存在を区別できる。

整数周期の下界は命題C.9を同じ生成複体へ適用する。例えば面のない三角形の整数周期は $`z_1+z_2+z_3`$ であり、非零調和ノルムは $`1/\sqrt3`$ 以上である。ねじれ類の実調和射影は零なので、この下界と有限素数冪条件は互いに異なる情報を与える。

## 16.13 固有値の根診断と商上の選択

**構成16.31（原始操作からのスペクトル根診断）.**
第6章の有限局所自由実現の族上で、構成D.7の原始単項線形演算と多重線形演算への指定切断の代入を用いる。型の合う合成、和、スカラー倍から有限個の自己準同型 $`A_{\ell,s}:E_{r(\ell,s)}\to E_{r(\ell,s)}`$ を作る。フレームを変更すると、これらは式(6.4)の右作用による共役で輸送される。
構成16.8と同じ支持 $`S_\sigma`$ について

```math
P_{\sigma,\ell}(z)=\prod_{s\in S_\sigma}\det(z1-A_{\ell,s}),
\qquad
Z_{\sigma,\ell}=\mathrm{Spec}_B\mathcal O_B[z]/(P_{\sigma,\ell})
```

と置く。face $`\tau\subset\sigma`$ に対して $`P_{\sigma,\ell}\mid P_{\tau,\ell}`$ なので、根スキームの閉埋込みから関数の制限を得る。これを構成16.8の微分と同じ接続数で足して $`\mathscr D_{\mathrm{sp}}`$ を定める。

**定理16.32（茎・基底変更・商スタックへの降下）.**
構成16.31の複体は、各幾何点で、支持内の原始自己準同型の相異なる固有値集合上の関数複体を復元する。係数スキームの任意の変更 $`g:B'\to B`$ に対して自然同型

```math
g^{-1}\mathscr D_{\mathrm{sp},B}\cong\mathscr D_{\mathrm{sp},B'}
```

があり、face の制限と微分を保つ。この複体は第6章の実現商スタック $`[X_{\boldsymbol n}/G_{\boldsymbol n}]`$ 上に降りる。
さらに、各根スキーム $`Z=Z_{\sigma,\ell}`$ について、幾何基点を持つ連結な基底 $`U\to B`$ 上で有限 étale $`U`$-スキーム $`R`$ と、冪零な定義イデアルを持つ閉埋込み $`R\hookrightarrow Z_U`$ が指定されるとする。$`Z_U`$ 自体が有限 étale なら $`R=Z_U`$ とする。このとき、$`R`$ の切断 $`U\to R`$ として一つの根を大域的に選択できることは、幾何基点の根集合に対するモノドロミー作用が固定点を持つことと同値である。

**証明.**
多項式の根を事前に列挙せずに茎を計算する[補題D.6](../appendix_d_finite_roots_and_stalks.md#d5-一般のモニック多項式とスペクトル根)を各セルに適用する。face 間の整除による包含は根集合の包含に一致するので、同型は微分と可換する。
原始自己準同型の共役は特性多項式を変えない。そのためフレーム torsor 上の根座標を同じ $`z`$ とする同型がコサイクル条件を満たし、[定理D.8](../appendix_d_finite_roots_and_stalks.md#d5-一般のモニック多項式とスペクトル根)の試験スキームごとの構成によって商上の層複体を得る。
最後の仮定のもとで $`R`$ と $`Z_U`$ の幾何点の根集合は一致する。有限 étale な $`R`$ に[命題D.9](../appendix_d_finite_roots_and_stalks.md#d6-相異なる根のモノドロミーと選択)を適用し、番号付け torsor 上の選択を重なりで貼り合わせれば、$`R`$ の切断とモノドロミーの固定点が対応する。その切断を閉埋込みと合成すると実際の根 $`U\to Z_U`$ を得る。ここでは根の個数の一定性に加えて、$`R`$ とその閉埋込みを指定している。□

標数 $`2`$ 以外の体上では、$`z(z-t)`$ と $`z^2-t`$ は $`t\ne0`$ でともに二つの根を持つが、前者には大域的な二本の根があり、後者では二根が交換されるため一根を大域的には選べない。例D.10はこの相違と、診断係数で $`2`$ が可逆なときに限る不変・反対称部分への分解を計算している。根の個数だけを読む観測と、一つの固有値を選ぶ観測の差は、[第17章](../part_6/chapter_17_observation_sufficiency_and_selection.md)のファイバーごとの選択条件へ接続する。

原始式のスカラー値が基底変更で不変な場合も、構成16.8は同じ手続きで商上へ降りる。$`A_{11}`$ のような非不変成分を読む場合は、フレームまたはそれに相当するベクトル・共変ベクトルの指定を残す。値域を同時に変更する表示では、その値域同型と合成条件を指定してから制限を比較する。この条件と具体例は付録DのD.5節で与えた。
