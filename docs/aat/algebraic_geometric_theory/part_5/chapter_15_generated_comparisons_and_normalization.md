# 第15章 生成比較と正規化

輸送してから制限する経路と、制限してから輸送する経路は、始域と終域が一致していても自動的に等しくなるわけではなく、両者を結ぶ比較射の構成を必要とする。
さらに商や冪等射による正規化を組み合わせると、比較が本質的に保つのは冪等射の像の部分となる。
本章では、生成比較と冪等正規化という 2段階をはっきりと区別したうえで、変更の保存・反映・すべての持ち上げの構造を解析する。
意味圏のすべての射（可逆とは限らない射を含む）を保持したまま議論を進め、群による分類はその可逆な自己同型部分に適用する。

## 15.1 2本の経路と標準比較

まず、第14章で用意した随伴を持つ輸送・制限の関手から、可換平方に沿う 2本の経路を結ぶ標準比較（Beck–Chevalley の mate）を構成する。

**設定15.1（随伴を持つ可換平方）.**
[第14章](chapter_14_transport_along_readings_and_coefficients.md)で構成した完全な reading の底の圏、または多重線形等式理論と係数の底の圏 $`(\mathbb T,R)`$ において、可換平方

```math
\begin{array}{ccc}
b_{12}&\xrightarrow{p_2}&b_2\\
{\scriptstyle p_1}\downarrow&&\downarrow{\scriptstyle s_2}\\
b_1&\xrightarrow{s_1}&b_0
\end{array}
\qquad s_1p_1=s_2p_2
```

を取る。各辺 $`u`$ に対して順方向の関手を $`L_u`$、逆方向の関手を $`R_u`$ と記す。
ここで用いる随伴 $`L_u\dashv R_u`$ は、次のいずれかから構成される。

- 定理14.5の名前を戻す Hom 対応（完全な reading の場合）。
- 補題14.6aの平衡写像の Hom 対応（係数変更の場合）。
- 構成14.6bの生成元と関係から得られる Hom 対応（等式理論の解釈の場合）。
- 命題14.6cの混合した合成（解釈と係数変更を組み合わせた場合）。

なお、係数辺を含む後者の底の圏では、すべての sort が可変加群 sort であることを含め、補題14.6aで定めた理論の範囲を用いる（一般の正の存在式を含む理論には構成14.6bの末尾で挙げた反例があり、同じ方法で随伴を供給できない）。

各辺 $`u`$ の随伴の単位を $`\eta^u:1\to R_uL_u`$、余単位を $`\varepsilon^u:L_uR_u\to1`$ と書く。
輸送の合成比較から、自然同型 $`\Sigma`$ と 2本の経路を表す関手 $`D,V`$ を

```math
\Sigma:L_{s_2}L_{p_2}\xrightarrow{\sim}L_{s_1}L_{p_1},\qquad
D=L_{p_2}R_{p_1},\quad V=R_{s_2}L_{s_1}:
\mathcal A_{b_1}\longrightarrow\mathcal A_{b_2}
```

によって定める。ここで $`\Sigma=c_{s_1,p_1}^{-1}c_{s_2,p_2}`$ であり、平方の可換性 $`s_1p_1=s_2p_2`$ により直接輸送の終域を同定している。合成比較 $`c`$ には、完全な reading では命題14.6の比較を、解釈と係数の混合では命題14.6cの比較を用いる。

**定理15.2（生成された Beck–Chevalley 比較）.**
設定15.1のもとで、次の合成は自然変換 $`\alpha:D\Rightarrow V`$ を定める。

```math
DX\xrightarrow{\eta^{s_2}_{DX}}R_{s_2}L_{s_2}DX
\xrightarrow{R_{s_2}\Sigma_{R_{p_1}X}}
R_{s_2}L_{s_1}L_{p_1}R_{p_1}X
\xrightarrow{R_{s_2}L_{s_1}\varepsilon^{p_1}_X}VX.
```

この mate $`\alpha`$ は、自然同型 $`\Sigma`$ と二つの随伴から一意に決まり、随伴と輸送の選択をそれらの標準同型で取り替えても整合的に対応する。
特に、すべての辺が完全な輸送である場合には、$`\alpha`$ は自然同型となる。

**証明.**
合成を構成する各矢印は自然変換またはその関手による像であるため、合成 $`\alpha`$ も自然変換である。

一意性を確かめるため、$`L_{s_2}\dashv R_{s_2}`$ と $`L_{p_1}\dashv R_{p_1}`$ の Hom 全単射を順に適用する。
自然変換 $`L_{s_2}L_{p_2}\to L_{s_1}L_{p_1}`$ の成分を、右側の $`L_{p_1}R_{p_1}X`$ において余単位 $`\varepsilon^{p_1}_X`$ と合成し、左側の随伴の単位 $`\eta^{s_2}`$ を用いて戻すと、ちょうど上の合成式が得られる。
逆の操作は、単位 $`\eta^{p_1}`$ を挿入して左側の余単位 $`\varepsilon^{s_2}`$ を適用することである。両方向の往復は随伴の三角恒等式により恒等となる。
したがって自然変換どうしのこの対応は全単射であり、mate $`\alpha`$ の一意性が従う。Hom 対応と整合する自然同型で各随伴を取り替えても、この全単射のもとで同じ元に対応する。

最後に、各辺が完全な輸送である場合は、定理14.5の単位・余単位および $`\Sigma`$ がすべて可逆であるため、上の三つの矢印の逆を逆順に合成することで逆自然変換 $`\alpha^{-1}`$ が得られる。□

**合成する平方.**
二つの可換平方を貼り合わせた大きな平方から直接作られる mate は、それぞれの平方の mate を合成した比較と一致する。
実際、双方を上の Hom 全単射によって順方向の自然変換へ戻すと、途中に現れる単位と余単位が三角恒等式によって消え、命題14.6または命題14.6cの同じ合成比較に帰着する。この計算は恒等平方に対しても成り立つ。
こうして対象だけでなく、任意の意味射 $`h:X\to X'`$ に対しても可換式 $`V(h)\alpha_X=\alpha_{X'}D(h)`$ を伴う 2本の経路の比較が得られる。

なお、順方向の比較 $`\Sigma`$ が可逆であっても、そこから生成される mate $`\alpha`$ が同型になるとは限らない。次の例はその典型である。

**例15.2a（非可逆な解釈と係数を混ぜた平方）.**
操作を持たない加群の理論 $`\mathbb T_{\mathrm{mod}}`$ から、単位付き結合的代数の理論 $`\mathbb T_{\mathrm{alg}}`$ への解釈 $`u`$ を取る。
このとき、構成14.6bの左随伴はテンソル代数

```math
L_u^R(M)=T_R(M)=\bigoplus_{n\ge0}M^{\otimes_Rn}
```

である。実際、任意の線形写像 $`M\to A`$ は、純テンソルをその像の積へ送る唯一の単位的代数準同型へ延長される。
底の可換平方として、上辺と下辺を $`u`$、左右の辺を環射 $`b:R\to R'`$ とする。すなわち四隅の対象は $`b_{12}=(\mathbb T_{\mathrm{mod}},R)`$、$`b_2=(\mathbb T_{\mathrm{alg}},R)`$、$`b_1=(\mathbb T_{\mathrm{mod}},R')`$、$`b_0=(\mathbb T_{\mathrm{alg}},R')`$ である。
このとき $`\Sigma`$ は、テンソルの係数を掛け合わせる命題14.6cの自然同型である。

任意の $`R'`$-加群 $`X`$ に対する mate $`\alpha_X`$ は、

```math
\alpha_X:T_R(U_bX)\longrightarrow U_bT_{R'}(X),\qquad
x_1\otimes_R\cdots\otimes_Rx_n\longmapsto
x_1\otimes_{R'}\cdots\otimes_{R'}x_n
```

で与えられ、次数 $`0`$ では環射 $`b:R\to R'`$ となる。
実際、定理15.2の単位は $`z\mapsto z\otimes1`$、余単位はスカラー作用であるため、生成元に適用するとこの式に一致し、純テンソルの連接と単位を保つことから構成した代数準同型そのものであることが分かる。
ここで $`R=\mathbb Z`$、$`R'=\mathbb Q`$、$`X=0`$ と取ると、mate $`\alpha_0`$ は包含 $`\mathbb Z\to\mathbb Q`$ となり、同型ではない。
したがって、混合比較 $`\Sigma`$ の可逆性から mate の可逆性は従わず、mate の可逆性は別の条件として判定する必要がある。

## 15.2 冪等正規化と像

次に、同型な比較射 $`\alpha:X\xrightarrow{\sim}Y`$ の後に冪等射 $`d:Y\to Y`$ による正規化を施した合成 $`d\alpha`$ が、元の圏と Karoubi 圏のそれぞれでどのように振る舞うかを定式化する。

**定義15.3（冪等射と Karoubi 圏）.**
任意の圏 $`\mathcal E`$ において、$`d^2=d`$ を満たす自己射 $`d:Y\to Y`$ を**冪等射**と呼ぶ。
冪等射 $`d`$ の**分裂**とは、$`qs=1_Q`$ かつ $`sq=d`$ を満たす射の組 $`Y\xrightarrow{q}Q\xrightarrow{s}Y`$ のことをいう。

圏 $`\mathcal E`$ の **Karoubi 圏**（冪等完備化）$`\mathrm{Kar}(\mathcal E)`$ を次で定める。

- **対象**は、対象と冪等射の組 $`(Y,d)`$ とする。
- **射** $`h:(X,e)\to(Y,d)`$ は、$`h=dhe`$ を満たす元の圏 $`\mathcal E`$ の射 $`h:X\to Y`$ とする。
- **合成と恒等**: 合成は元の圏 $`\mathcal E`$ での合成とし、対象 $`(Y,d)`$ の恒等射は $`1_{(Y,d)}=d`$ とする。

条件 $`h=dhe`$ は $`dh=h=he`$ と同値であり、これらの等式から $`\mathrm{Kar}(\mathcal E)`$ が圏の公理を満たすことが直ちに従う。

元の圏で $`d`$ の分裂 $`Y\xrightarrow{q}Q\xrightarrow{s}Y`$ が存在するならば、$`q:(Y,d)\to(Q,1_Q)`$ と $`s:(Q,1_Q)\to(Y,d)`$ は $`\mathrm{Kar}(\mathcal E)`$ において互いに逆射となる。
さらに、Karoubi 圏内の任意の冪等射 $`a:(Y,d)\to(Y,d)`$ は、対象 $`(Y,a)`$ と両方向の射 $`a:(Y,d)\to(Y,a)`$、$`a:(Y,a)\to(Y,d)`$ によって分裂する。
したがって Karoubi 圏においては、元の圏に商や像が存在しない場合でも、冪等射の像を常に対象として扱うことができる。

**定理15.4（正規化分解と像の同型）.**
圏 $`\mathcal E`$ の同型射 $`\alpha:X\xrightarrow{\sim}Y`$ と冪等射 $`d:Y\to Y`$ に対し、

```math
\beta=d\alpha,\qquad e=\alpha^{-1}d\alpha,\qquad
\gamma=\alpha^{-1}d
```

と置く。このとき次が成り立つ。

1. $`e`$ は $`X`$ の冪等射（$`e^2=e`$）である。
2. $`\beta`$ が元の圏 $`\mathcal E`$ で可逆であることと、$`d=1_Y`$ であることは同値である。
3. 同じ射 $`\beta`$ は Karoubi 圏 $`\mathrm{Kar}(\mathcal E)`$ において同型 $`\beta:(X,e)\xrightarrow{\sim}(Y,d)`$ を与え、その逆射は $`\gamma:(Y,d)\to(X,e)`$ である。

**証明.**
まず共役の式から $`e^2=\alpha^{-1}d\alpha\alpha^{-1}d\alpha=\alpha^{-1}d^2\alpha=e`$ となり、1 が従う。

次に 2 を示す。$`\beta`$ が元の圏で可逆であるならば、$`d=\beta\alpha^{-1}`$ も可逆であり、冪等性 $`d^2=d`$ の両辺に $`d^{-1}`$ を掛けて $`d=1_Y`$ を得る。逆は $`d=1_Y`$ のとき $`\beta=\alpha`$ が同型であることから明らかである。

最後に 3 を示す。$`d\beta e=d(d\alpha)(\alpha^{-1}d\alpha)=d^3\alpha=d\alpha=\beta`$、および $`e\gamma d=(\alpha^{-1}d\alpha)(\alpha^{-1}d)d=\alpha^{-1}d^3=\gamma`$ であるから、$`\beta`$ と $`\gamma`$ はそれぞれ $`\mathrm{Kar}(\mathcal E)`$ の射である。さらに両方向の合成を計算すると、

```math
\gamma\beta=e=1_{(X,e)},\qquad \beta\gamma=d=1_{(Y,d)}
```

となる。したがって $`\beta`$ と $`\gamma`$ は Karoubi 圏において互いに逆射である。□

AAT における冪等射の具体的な供給源は[定理9.8](../part_3/chapter_9_quotients_symmetry_and_lifts.md#93-保存切断冪等射分裂)である。
同章の操作系において、商 $`q:Y\to Q`$ と操作・観測を保存する切断 $`s:Q\to Y`$ があるとき、合成 $`d=sq`$ は意味圏の冪等射となる。
その像はすべての操作で閉じており、量と観測はその像へ制限される。Law はこの分裂の対象 $`Q`$ に課されたものを用いる。
一般の理論で像に新しい構造を与える場合には、定義域・関係・Law がその構造へ降りることを別途確認する。
一方で、元の圏に分裂を明示的に構成していない場合であっても、定理15.4の Karoubi 圏における同型という結論は常に成立する。

**例15.5（四点と二点）.**
操作を恒等操作のみ、観測を定数写像とし、次の四点の集合の間の同型 $`\alpha`$ と冪等写像 $`d`$（$`d(0)=d(1)=0`$、$`d(2)=d(3)=2`$）を取る。

| $`x`$ | $`\alpha(x)`$ | $`d\alpha(x)`$ | $`e(x)`$ |
| --- | --- | --- | --- |
| $`x_0`$ | $`1`$ | $`0`$ | $`x_2`$ |
| $`x_1`$ | $`3`$ | $`2`$ | $`x_3`$ |
| $`x_2`$ | $`0`$ | $`0`$ | $`x_2`$ |
| $`x_3`$ | $`2`$ | $`2`$ | $`x_3`$ |

表から直ちに $`e^2=e`$ および $`e=\alpha^{-1}d\alpha`$ が確かめられる。
$`\beta=d\alpha`$ は四点集合の全体では非単射だが、冪等射の像の間の制限 $`\{x_2,x_3\}\to\{0,2\}`$ としては全単射となる。

**台帳への適用.**
例14.8の分割台帳において、商 $`q(x,y)=x+y`$ と切断 $`s(z)=(z,0)`$ は $`qs=1`$ を満たす。
read と apply を持つ操作系では両者とも構造保存射であり、冪等射 $`d(x,y)=(x+y,0)`$ の像は単一台帳と同型である。
一方、同じ名前の compact も保存する切断を要求すると、$`s(z)=(z,0)`$ に対して compact を施した像 $`(z-t,t)`$ は $`d`$ の像から出てしまう。
そのような場合には、compact を空語へ翻訳した変更問題として定式化する必要がある。

## 15.3 変更との自然性

個別の対象に対する正規化だけでなく、比較を保つ変更のあいだの関係を圏として整理することで、自然な冪等射や固定図式と整合する正規化関手が得られる。

**構成15.6（比較を保つ変更の圏）.**
まず、**比較の圏**を次のように定める。

- **対象**は三つ組 $`(X,Y,c:X\to Y)`$ とする。
- **射** $`(X,Y,c)\to(X',Y',c')`$ は、可換式 $`bc=c'a`$ を満たす射の対 $`(a:X\to X',b:Y\to Y')`$ とする。
- **合成**は成分ごとの合成 $`(a'a,b'b)`$ とする。可換式を貼り合わせれば再び射となる。

さらに、各対象に冪等射 $`e:X\to X`$、$`d:Y\to Y`$ を添え、整合条件 $`dc=ce`$ を課した対象 $`(X,Y,c,e,d)`$ を考える。
このときの射 $`(a,b)`$ には、比較の可換性 $`bc=c'a`$ に加えて冪等射との可換性 $`ae=e'a`$ および $`bd=d'b`$ を課す。
正規化された比較を $`\bar c=dce=dc=ce`$ と置くと、対応

```math
\mathcal N:(X,Y,c,e,d)\longmapsto
\bigl((X,e),(Y,d),\bar c\bigr),\qquad
(a,b)\longmapsto(e'ae,d'bd)
```

は Karoubi 圏上の比較の圏への関手を定める。
実際、$`(d'bd)\bar c=d'bce=d'c'ae=\bar c'(e'ae)`$ により比較との可換性が保たれる。また、合成においては中間の冪等射を可換性によって交換させて消去でき、恒等対 $`(1_X,1_Y)`$ は Karoubi 圏の恒等対 $`(e,d)`$ へ移る。

これを自然変換の族へ適用しよう。自然同型 $`\alpha:D\Rightarrow V`$ と自然な冪等射 $`d:V\Rightarrow V`$ に対しては、$`e=\alpha^{-1}d\alpha`$ が $`D`$ の自然な冪等射となり、合成 $`d\alpha`$ は Karoubi 圏値の関手の間の自然同型を与える。
ここで自然性は、二つの可換式 $`V(h)d_X=d_{X'}V(h)`$ と $`V(h)\alpha_X=\alpha_{X'}D(h)`$ を合成することで従う。
なお、各対象で個別に選んだ切断を自然な切断として扱うには、前者の可換式 $`V(h)d_X=d_{X'}V(h)`$ を別途確かめる必要がある。

第8章の固定図式の各辺にこの比較を配置すれば、可換な変更の対と固定自明化（trivialization）を同時に保持できる。
さらに評価条件を輸送する場合には定理14.10を用いる。正規化後の条件だけから元の許容条件を復元できるかという問題は、次節で扱う「反映」の問題に帰着する。

## 15.4 保存・反映・持ち上げ

正規化関手 $`\mathcal N`$ は、元の圏で比較を保つ変更を像の圏で比較を保つ変更へ送る（保存）。
逆に、像の側で比較を保つ変更が元の側でも比較を保つかどうか（反映）、また像の側で与えられた変更が元の側から持ち上がるかどうか（持ち上げ）を、可逆な自己同型の群の枠組みで精密に特徴づける。

**定義15.7（具体的な比較から作る群）.**
構成15.6の一対象 $`(X,Y,c,e,d)`$ を固定し、冪等射と交換する自己同型の群 $`G`$ と、比較 $`c`$ を保つ部分群 $`\Gamma`$ を

```math
G=C_{\mathrm{Aut}(X)}(e)\times C_{\mathrm{Aut}(Y)}(d),\qquad
\Gamma=\{(a,b)\in G\mid bc=ca\}
```

によって定義する。ここで中心化群の条件とは $`ae=ea`$ および $`bd=db`$ を意味する。
$`\Gamma`$ は可換式の合成と逆元をとる操作で閉じるため、$`G`$ の部分群である。

像の側（Karoubi 圏）の端点自己同型群を $`Q=\mathrm{Aut}_{\mathrm{Kar}}(X,e)\times\mathrm{Aut}_{\mathrm{Kar}}(Y,d)`$ と置き、その中で正規化比較 $`\bar c`$ を保つ部分群を $`\Delta`$ とする。
このとき、写像

```math
r:G\longrightarrow Q,\qquad r(a,b)=(eae,dbd)
```

は群準同型である（実際、$`a^{-1},b^{-1}`$ もそれぞれ冪等射 $`e,d`$ と交換し、像の側での逆射を与える）。
構成15.6の関手性から $`r(\Gamma)\subseteq\Delta`$ が従う。
このように、群と適合部分群の組は、端点の実際の変更と比較式から直接構成される。

次の定理は、適合性の反映条件と、像の側の変更のすべての持ち上げの空間構造を与える。

**定理15.8（反映とすべての持ち上げ）.**
任意の群準同型 $`r:G\to Q`$ と、$`r(\Gamma)\subseteq\Delta`$ を満たす部分群 $`\Gamma\le G`$、$`\Delta\le Q`$ に対して、次が同値である。

```math
r^{-1}(\Delta)=\Gamma
\quad\Longleftrightarrow\quad
\ker r\subseteq\Gamma\quad\text{かつ}\quad
r(\Gamma)=\Delta\cap\mathop{\mathrm{im}}r.
```

さらに、指定された $`\delta\in\Delta`$ の適合する持ち上げが存在する必要十分条件は $`\delta\in r(\Gamma)`$ である。
一つの持ち上げ $`\gamma_0\in\Gamma`$ を固定し、制限準同型の核を $`L=\ker(r|_\Gamma)`$ と置くと、$`\delta`$ の適合するすべての持ち上げからなる集合は右 $`L`$-torsor

```math
(r|_\Gamma)^{-1}(\delta)=\gamma_0L
```

となる。

**証明.**
まず前半の同値性を示す。左辺 $`r^{-1}(\Delta)=\Gamma`$ を仮定すると、単位元の原像 $`\ker r`$ は当然 $`\Gamma`$ に含まれる。また任意の $`\delta\in\Delta\cap\mathop{\mathrm{im}}r`$ に対し $`r(g)=\delta`$ となる $`g\in G`$ を取ると、仮定により $`g\in\Gamma`$ となるため $`\delta\in r(\Gamma)`$ を得て像の等号が成り立つ。
逆に右辺を仮定し、$`g\in G`$ が $`r(g)\in\Delta`$ を満たすとする。像の等号から $`r(\gamma)=r(g)`$ となる $`\gamma\in\Gamma`$ が存在する。このとき $`\gamma^{-1}g\in\ker r\subseteq\Gamma`$ であるから、$`g=\gamma(\gamma^{-1}g)\in\Gamma`$ となり、$`r^{-1}(\Delta)=\Gamma`$ が従う。

次に後半を示す。持ち上げの存在条件 $`\delta\in r(\Gamma)`$ は像の定義そのものである。
二つの適合する持ち上げ $`\gamma_0,\gamma\in(r|_\Gamma)^{-1}(\delta)`$ の差 $`\gamma_0^{-1}\gamma`$ は $`L=\ker(r|_\Gamma)`$ に属し、逆に $`\gamma_0`$ に右から $`L`$ の元を掛けても $`r`$ の像は $`\delta`$ のままである。この差は $`\gamma`$ に対して一意に決まるため、$`L`$ の右作用は自由かつ推移的であり、右 $`L`$-torsor となる。□

次の二つの有限例は、反映の失敗（核条件の破れ）と持ち上げ不能（像の欠損）が互いに独立な現象であることをはっきり区別する。

**例15.9（観測では見えない不適合変更）.**
まず、反映が失敗する例を見る。$`X=Y=\{0,1,2\}`$、$`c=1`$ とし、冪等射 $`e=d`$ をすべて $`0`$ へ送る定値写像とする（操作は恒等、観測は定数とする）。
置換 $`\tau=(12)`$ は $`d`$ と交換するため、対 $`(\tau,1)`$ は $`G`$ に属し、しかも $`r(\tau,1)=(d,d)`$ なので $`\ker r`$ に入る。
しかし $`1\circ c\ne c\circ\tau`$ であるから $`(\tau,1)\notin\Gamma`$ である。
像は 1点であって自明に比較を保つため、反映条件 $`r^{-1}(\Delta)=\Gamma`$ が失敗する。
一方、像の側の一つの恒等変更には、$`(1,1)`$ と $`(\tau,\tau)`$ という二つの適合する持ち上げが存在する。

次に、同じ 3点集合上で $`e(0)=0`$、$`e(1)=e(2)=1`$ と置く（$`c=1`$、$`d=e`$）。
像の集合 $`\{0,1\}`$ 上の恒等比較は、$`0`$ と $`1`$ を同時に交換する自己同型を許容する。
しかし $`e`$ と交換する全単射は、各ファイバーを対応するファイバーへ全単射に送らなければならない。
$`0`$ のファイバーの大きさは $`1`$、$`1`$ のファイバーの大きさは $`2`$ であるため、この交換は元の集合へ持ち上がらない。
この第二例では中心化群が自明であり $`G=\Gamma=1`$、一方 $`\Delta\cong\mathbb Z/2`$ である。
したがって、反映の核条件 $`\ker r\subseteq\Gamma`$ と等号 $`r(\Gamma)=\Delta\cap\mathop{\mathrm{im}}r`$ はともに成り立つが、$`r|_\Gamma`$ は全射ではない。
このように、第一例の適合性の反映失敗と、第二例の指定変更の持ち上げ不能とは明確に異なる現象である。

## 15.5 持ち上げの全体と残る自由

最後に、持ち上げが各元ごとに存在するときに群切断（合成を保つ持ち上げ）が存在するかを測る拡大の障害を確認し、さらに可逆でない一般の変更も含めた持ち上げ全体を 2-ファイバーとして定式化する。

準同型 $`r|_\Gamma:\Gamma\to\Delta`$ が全射であるとき、短完全列

```math
1\longrightarrow L\longrightarrow\Gamma\longrightarrow\Delta\longrightarrow1
```

が得られる。
ここで、各 $`\delta\in\Delta`$ に対して持ち上げを個別に一つずつ選ぶことと、合成を保つ群切断（準同型 $`s:\Delta\to\Gamma`$）を選ぶことは一般には異なる。
$`s(1)=1`$ を満たす任意の持ち上げの選択 $`s:\Delta\to\Gamma`$ に対し、

```math
a(\delta_2,\delta_1)=s(\delta_2)s(\delta_1)s(\delta_2\delta_1)^{-1}\in L
```

がその合成とのずれを測る。すべての対 $`(\delta_2,\delta_1)`$ について $`a(\delta_2,\delta_1)=1`$ であることと、選択 $`s`$ が群準同型であることは同値である。
たとえば自然な全射 $`\mathbb Z/4\to\mathbb Z/2`$ において、非零元の持ち上げは奇数であるため位数が $`4`$ となり、位数 $`2`$ の元を持つ群切断は存在しない。

次に、可逆でない変更も対象としてそのまま保持するため、構成15.6の正規化関手を $`\mathcal N:\mathcal K\to\mathcal K'`$ と記し、その矢印圏 $`\mathrm{Ar}(\mathcal K)`$ を構成する。

- $`\mathrm{Ar}(\mathcal K)`$ の**対象**は、$`\mathcal K`$ の任意の射 $`h:X\to Y`$（可逆性は問わない）とする。
- **射** $`h\to h'`$ は、可換式 $`b h=h'a`$ を満たす対 $`(a,b)`$ とする。

この矢印圏から可逆な比較射だけを残した core $`\mathrm{Ar}(\mathcal K)^\simeq`$ を取っても、対象である変更 $`h`$ 自身の可逆性は要求されない。
正規化関手 $`\mathcal N`$ は、対象に $`h\mapsto\mathcal N(h)`$、射に $`(a,b)\mapsto(\mathcal N(a),\mathcal N(b))`$ を割り当てることで、core の間の関手

```math
\mathcal N^\to:\mathrm{Ar}(\mathcal K)^\simeq\longrightarrow\mathrm{Ar}(\mathcal K')^\simeq
```

を定める。可換平方とその合成を関手で送るため、この式は対象・すべての比較射・恒等射・合成を保つ。

観測側（像の側）で指定された射 $`\delta`$ の**すべての持ち上げ**は、この関手 $`\mathcal N^\to`$ の 2-ファイバーとして定義される。

- **対象**は、対 $`(h,\theta:\mathcal N^\to(h)\cong\delta)`$ である。ここで $`\theta`$ は端点の二つの同型からなる可換平方である。
- **比較射**は、$`\theta'\mathcal N^\to(\zeta)=\theta`$ を満たす同型 $`\zeta:h\cong h'`$ である（この等式は両端点成分ごとの等号を表す）。

これは、第7章の変更全体の groupoid と同じ「矢印圏の core」の構成を、比較と正規化の圏へそのまま適用したものである。
さらに第8章の $`\mathcal F^{\partial}_{a,H,V}`$ と同じ 2-ファイバーと部分関手の構成により、固定条件や評価条件を追加することもできる。対象の集合だけへ潰す前に比較射を保持している点が重要である。
たとえば 2点集合の一方への冪等写像には逆射がなく群 $`G`$ の元にはならないが、この変更全体のファイバーの対象として問題なく扱える。

**問題15.10.**
指定された意味圏と許容規則 $`H`$ について、構成15.6の非可逆変更のファイバーを原始操作の式から表示せよ。
像側の変更の存在と、その間のすべての比較射の持ち上げをそれぞれ判定すること。

**問題15.11.**
構成14.6bの完全でない等式理論解釈に対し、定理15.2で構成した mate の可逆性を Law 表示と操作の翻訳から判定せよ。
部分操作の定義域を含める拡張では、まず該当する圏で左随伴を構成すること。
さらに、条件付き解族に制限した mate の可逆性と、意味圏全体での可逆性の関係を求めよ。

## 15.6 同型比較の情報損失と端点観測核

同型な比較については、観測で見えなくなる変更のうち比較を壊すものを、終点だけの観測核によって分類できる。
ここでは、同じ観測結果を持つ変更を、観測で見えない適合変更の合成まで同一視した集合を求める。

**定理15.12（端点観測核による分類）.**
圏の間の観測関手 $`O:\mathcal E\to\mathcal B`$ と同型 $`c:X\xrightarrow{\sim}Y`$ を固定する。
本節では

```math
\begin{gathered}
G_X=\mathop{\mathrm{Aut}}\nolimits _{\mathcal E}(X),\qquad
G_Y=\mathop{\mathrm{Aut}}\nolimits _{\mathcal E}(Y),\qquad
T:G_X\xrightarrow{\sim}G_Y,\quad T(a)=cac^{-1},\\
r_X(a)=O(a),\qquad r_Y(b)=O(b),\qquad
K_X=\ker r_X,\quad K_Y=\ker r_Y,\\
G=G_X\times G_Y,\qquad r=r_X\times r_Y,\qquad
\Gamma=\{(a,b):bc=ca\},\qquad K=\ker r,\quad L=K\cap\Gamma
\end{gathered}
```

と置く。$`L`$ は $`K`$ の部分群として読む。このとき $`T`$ は $`K_X\xrightarrow{\sim}K_Y`$ に制限され、

```math
K=K_X\times K_Y,\qquad
L=\{(a,T(a)):a\in K_X\}
```

である。$`K/L`$ を左剰余類 $`kL`$ の集合、基点を $`L`$ とすると、次は基点を保つ全単射である。

```math
\Psi:K/L\xrightarrow{\sim}K_Y,\qquad
\Psi([(a,b)])=bT(a)^{-1},\qquad
\Psi^{-1}(y)=[(1,y)].
```

したがって、観測で見えない変更の情報損失集合 $`K/L`$ が1点であることと、$`K_Y=1`$ は同値である。

**証明.**
関手性から
$`r_Y(T(a))=O(c)r_X(a)O(c)^{-1}`$ であり、$`c^{-1}`$ にも同じ式を適用すれば $`T(K_X)=K_Y`$ が従う。
積の観測の核は両成分の核の積であり、適合式 $`bc=ca`$ は $`b=T(a)`$ と同値なので、$`K,L`$ の表示を得る。

代表元を $`(a,b)(u,T(u))=(au,bT(u))`$ に取り替えると、

```math
bT(u)T(au)^{-1}
=bT(u)T(u)^{-1}T(a)^{-1}
=bT(a)^{-1}.
```

従って $`\Psi`$ は剰余類上で定まる。逆に
$`(a,b)(a^{-1},T(a^{-1}))=(1,bT(a)^{-1})`$ であり、右因子は $`L`$ に属する。
この式と $`\Psi([(1,y)])=y`$ から二つの写像が互いに逆と分かる。基点は単位元へ移る。□

ここで用いた剰余類集合には、$`L`$ の正規性は必要ない。
たとえば、操作を恒等だけ、観測を定数とした3点モデルを $`X=Y`$ とし、$`c=1`$、$`O`$ を1点モデルへの関手とする。
この場合 $`K=S_3\times S_3`$、$`L=\{(a,a):a\in S_3\}`$ である。
$`u=(123),v=(12)`$ とすると
$`(u,1)(v,v)(u^{-1},1)=(uvu^{-1},v)\notin L`$ であり、$`L`$ は正規でない。
定理はそれでも $`K/L`$ を6点の基点付き集合として $`S_3`$ と同定する。

定義15.7への適用では、まず対象を冪等射の組 $`(X,e)`$、射を $`ae=e'a`$ を満たす射とする圏を取る。
その観測関手を $`(X,e)\mapsto(X,e)\in\mathop{\mathrm{Kar}}\nolimits (\mathcal E)`$、$`a\mapsto e'ae`$ とする。
恒等射は $`e`$ へ移り、合成の保存は冪等射との可換式によって従う。
同型比較 $`c`$ は $`dc=ce`$ を満たすため、この圏の同型である。
端点の自己同型群はちょうど定義15.7の中心化群となり、定理15.12は正規化の実際の核 $`K`$ と適合核 $`L`$ に適用される。
観測だけから適合性を判定する条件は、[第17章](../part_6/chapter_17_observation_sufficiency_and_selection.md#172-既知情報観測ファイバーと出力十分性)の因子化に接続する。

## 15.7 指定正規化の成分と自然性

構成15.6で自然性に課した可換式は、各対象に冪等射を持つことだけからは従わない。
次の例では、原始宣言から許される射を作り、指定された成分との二つの合成を直接計算する。

**例15.13（端点に依存するタグ交換）.**
二つの sort $`V,A`$ と単項操作 $`s,t:A\to V`$ を宣言し、追加の Law は課さない。
状態観測は両 sort で1点集合への定数写像とする。モデル $`X`$ を

```math
V_X=\{0,1\},\qquad A_X=\{0,1\}^2\times\mathbb F_2,\qquad
s(x,y,\epsilon)=x,\quad t(x,y,\epsilon)=y
```

で定める。第1・2成分は操作の端点、第3成分は観測に現れないタグである。
指定する正規化 $`d:X\to X`$ と可逆な変更 $`h:X\to X`$ を

```math
\begin{array}{ll}
d_V(x)=0,&d_A(x,y,\epsilon)=(0,0,\epsilon),\\
h_V(x)=x,&h_A(x,y,\epsilon)=(x,y,\epsilon+x)
\end{array}
```

とする。$`x\in\{0,1\}`$ は右辺で $`\mathbb F_2`$ の元として読む。
両射について $`s f_A=f_Vs`$ および $`t f_A=f_Vt`$ が成り立ち、定数観測も保存される。
従って両者は実際の意味射である。さらに $`d^2=d`$、$`h^2=1`$ である。
しかし $`a=(1,1,0)\in A_X`$ において、

```math
(h_A d_A)(a)=(0,0,0),\qquad
(d_A h_A)(a)=(0,0,1)
```

となる。

一対象で射が $`1,h`$ の圏から意味圏への関手 $`F`$ を、このモデルと可逆変更で定める。
指定成分 $`d_X`$ は冪等な成分族であるが、$`F(h)d_X=d_XF(h)`$ が上の元で破れるため、自然変換 $`F\Rightarrow F`$ にはならない。
定理15.4の像の同型は各成分で成立する一方、この成分族から構成15.6の自然な正規化を得るには、許された各射について別途可換性が必要である。

第9章の holonomy から作られるすべての持ち上げについても、定理15.8をその実際の群準同型へ適用できる。
本章はこの分類を一般の比較と正規化の枠組みへ拡張した。続く第16章ではこれを線形な複体比較の核・余核へ接続し、第17章の観測十分性には例15.9のような観測で区別されない変更を受け渡す。また、第19章の再構成には、元の圏での比較、Karoubi 圏での像の比較、および変更全体のファイバーの三者を明確に区別して受け渡す。
