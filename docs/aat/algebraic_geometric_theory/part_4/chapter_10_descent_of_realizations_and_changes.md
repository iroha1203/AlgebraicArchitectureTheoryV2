# 第10章 実現と変更のdescent

局所候補が存在すること、候補どうしが整合すること、整合した候補から元の意味を持つ対象を
復元できることは、順に異なる条件である。本章では宣言を分ける方向と係数を局所化する方向で
この三段階を構成する。対象だけでなく、非可逆な意味保存射と図式の指定同定も保持する。

## 10.1 文脈・係数それぞれのdescent

**設定10.1（原始実現と被覆）.**
宣言被覆は[定義3.3](../part_1/chapter_3_contexts_and_local_models.md#33-被覆と局所整合データ)のものとする。
各Law、その入力sort、操作domain、量、指定witnessの全参照を、一つの被覆元に含める。
理論解釈を含む変更では[構成7.5](../part_3/chapter_7_semantic_changes_and_composition.md#73-全変更の関手と比較表示)の
翻訳・導出の支持も保持する。係数方向では次の実現と位相を用いる。

1. 第4章のtensor実現：準連接加群、有限arityの多重線形演算、指定元、tensor式の等号。
   係数被覆はZariskiまたはfppfとする。関係・部分操作を加える場合は、準連接部分加群の
   包含とそのdomain上の線形写像を原始データとし、平坦な引戻しを使う。
2. 第7章の多項式実現：指定階数の有限局所自由担体、有限次数の全域多項式操作、
   全代数上で読む多項式Law、線形状態射。係数被覆はZariskiまたはfppfとする。
   基底付きchartを降下するときは、基底を忘れた有限局所自由実現へ戻す。
3. 層実現：係数scheme上の集合の層を担体とし、層の射、関係の部分層、
   domainの部分層とその上の操作を取る。第4章と同じく、正の式の連言を交差、
   選言を部分層の和、存在量化を像の部分層で読む。係数被覆はZariskiとする。
   これは担体ごとの局所定数性を要求しない実現方式である。

第3の場合、各原始写像の引戻しは層の逆像であり、有限極限・和・像を保つため
正の式とLawを保つ。第1の場合の関係保存は部分加群を経由すること、
第3の場合は部分層を経由することである。部分操作の射は指定domainを送り、その上で可換する。
指定witnessを持つ問題ではwitnessの宣言も残す。
集合のnativeモデルについては係数を固定し、第3章と同じ全担体を持つ宣言制限を使う。

**定義10.2（descent圏）.**
文脈被覆 $`(U_i)`$ 上の対象は、局所実現 $`A_i`$ と
$`\theta_{ij}:A_j|_{U_i\cap U_j}\cong A_i|_{U_i\cap U_j}`$ である。
$`\theta_{ii}=1`$、$`\theta_{ij}\theta_{jk}=\theta_{ik}`$ を三重交差で課す。
射 $`h:(A_i,\theta^A)\to(B_i,\theta^B)`$ は構造保存射 $`h_i`$ の族で
$`h_i\theta^A_{ij}=\theta^B_{ij}h_j`$ を満たすものとする。
係数被覆 $`(T_a\to T)`$ では交差をfiber積に替え、同じ定義を用いる。
この圏を $`\mathrm{Desc}`$ と書く。射 $`h_i`$ 自身には可逆性を課さない。

**定理10.3（対象と全Homのdescent）.**
設定10.1の三方式では、各方向の制限関手
$`\mathcal A(U,T)\to\mathrm{Desc}(\mathcal A)`$ は圏同値である。
nativeモデルについても宣言方向で同じ結論が成り立つ。
復元は原始宣言の解釈を保ち、全Lawを保存・反映し、全Homを回復する。

**証明：宣言方向.**
各sort $`s`$ を含む添字 $`i_s`$ を選び、その担体を $`X_s`$ とする。
他の $`i`$ からの同定は $`\phi_{i,s}=\theta_{i_s i,s}`$ である。
これは同じsortを含む三重交差上のcocycleにより
$`\phi_{i,s}\theta_{ij,s}=\phi_{j,s}`$ を満たす。
操作 $`f:(s_1,\ldots,s_m)\to t`$ を含む $`U_i`$ で

```math
f=\phi_{i,t}\,f_i\,(\phi_{i,s_1}^{-1},\ldots,\phi_{i,s_m}^{-1})
```

と定める。共有操作を保つ $`\theta_{ij}`$ と上の式から添字に依存しない。
関係とdomainは同じ同型による部分対象の像、部分操作と量は同じ共役で定める。
指定元・witnessにも同じ操作を施す。
各Lawの全支持はある $`U_i`$ に入るので、その式の評価は $`\phi_i`$ によって一致する。
存在式のwitnessも同型で運ばれ、層の場合の局所witnessも同じ開集合上で運ばれる。
従って全Lawの充足を保存・反映する。
許す担体、線形性、多項式次数は同型で運んでも変わらない。

局所射は $`h_s=\phi^B_{i,s}(h_i)_s(\phi^A_{i,s})^{-1}`$ と運ぶ。
整合条件により添字によらず、各保存式はそれを含む文脈で確認できる。
この構成と制限は互いに逆の全Hom対応を与える。
対象の往復の同型は $`\phi_i`$ であり、恒等と合成の保存は成分の式から従う。

**証明：係数方向.**
tensor方式では[補題B.4](../appendix_b_coefficients_and_descent.md#b2-忠実平坦な係数descent)の
等化子から各担体と全線形写像を作る。有限tensor積のdatumを先に作れば、
演算はそのtensor積から出力への写像として降下する。
部分加群の包含は包含自身を降下し、忠実平坦性による単射性の反映を使う。
domain上の操作も全線形写像のdescentで降下する。
保存式とLawの両辺は、忠実平坦な係数変更の後で一致するため元でも一致する。
有限局所自由性・階数・指定元は補題B.5で降下する。

多項式方式では、入力の直和を $`E`$、出力を $`F`$ とすると、次数 $`d`$ 以下の操作を
$`F\otimes\bigoplus_{j=0}^d\mathrm{Sym}^j(E^\vee)`$ の切断として復元する。
自由化上の単項式係数を読む操作と評価が逆であり、基底変更は線形代入になる。
この有限局所自由な係数加群と整合切断を降下すれば原始操作が得られる。
Law・射の保存式は普遍入力での全残差係数の零性なので、同じ忠実性で反映される。
これが[命題7.9](../part_3/chapter_7_semantic_changes_and_composition.md#75-幾何的表現の条件と元の変更への回復)の
構成を各宣言へ適用したものである。

層方式では開集合 $`O\subseteq T`$ 上の切断を
$`x_a\in X_a(O\cap T_a)`$ で $`\theta_{ab}(x_b)=x_a`$ を満たす族として作る。
開被覆での一致と貼り合わせは成分ごとに成立するので層を得る。
関係・domainもその整合切断、操作・量・射も成分ごとの作用で構成する。
原始式からの帰納法により、その解釈は各 $`T_a`$ で元の解釈に一致する。
部分層の包含は局所で検査できるため全Lawを反映する。
以上の三方式で局所射の復元は一意であり、逆を持つ局所射は逆も降下する。□

第4章のZariski局所splitなcopying実現も、係数方向のdescentを満たす。
上の層構成を各 $`T_a`$ のsplit被覆へ制限すると元のnative構造になるからである。
宣言方向にcopyingの対象クラスへ戻すには、組み立てた全構造が同時にsplitとなる
被覆を確認する。有限な宣言と有限担体の場合は、各写像・関係・domainの有限表の
値が局所定数となる開集合を有限回共通細分すればこの確認ができる。
無限表示については末尾の問題10.11でこの追加条件を扱う。

## 10.2 二方向のdescent data

**定義10.4（二重descent datum）.**
文脈被覆 $`(U_i)`$ と係数被覆 $`(T_a\to T)`$ に対し、対象 $`A_{ia}`$、
文脈方向の $`\theta^a_{ij}`$、係数方向の $`\eta^i_{ab}`$ を与える。
各方向のcocycleに加えて、$`(U_i\cap U_j,T_a\times_TT_b)`$ 上で

```math
\theta^a_{ij}\eta^j_{ab}=\eta^i_{ab}\theta^b_{ij}
\tag{10.1}
```

を課す。引戻しの標準比較はこの式に挿入する。
射は両方向の同型と可換する全局所構造保存射である。
固定trivializationにも両方向の同じ可換式を課す。

**例10.5（混合正方形）.**
二つの文脈が共有するsortに二点集合を置き、係数空間の二つの開集合が非空に交わるとする。
各場所の担体を定数二点層とし、係数方向の同型を恒等とする。
第一の開集合での文脈同型を恒等、第二での文脈同型を交換とする。
各方向では逆同型を指定してcocycleを満たせるが、交差上の式(10.1)は
$`1=\mathrm{swap}`$ を要求して失敗する。
指定された四つの同定を同時に誘導する大域対象は存在しない。

## 10.3 大域化順序の交換

**定理10.6（二方向descentと交換）.**
定理10.3の方式と同じ二重datumから、文脈を先に降下した対象 $`A^{UC}`$ と
係数を先に降下した対象 $`A^{CU}`$ を構成できる。
両対象の局所datumへの同定を保つ一意の同型
$`\Xi:A^{UC}\cong A^{CU}`$ があり、全局所射および固定trivializationについて自然である。
三方向以上を順次組み立てたときも、同じdatumを固定する比較の合成は一致する。

**構成と証明.**
係数を先に扱う場合、式(10.1)は $`\theta_{ij}`$ が係数datumの射であることをいう。
従って等化子への制限、または整合切断への作用として $`\bar\theta_{ij}`$ を作れる。
そのcocycleは係数被覆上で元のcocycleとなるので、全Homの忠実性から成立する。
これを文脈方向の担体選択・共役構成へ入力する。
文脈を先に扱う場合は $`\eta_{ab}`$ を同じ成分共役で運び、式(10.1)で添字から独立にする。
そのcocycleも成分で確認し、係数方向の等化子または層構成を施す。

どちらの結果も $`(i,a)`$ への同定 $`\lambda^{UC}_{ia},\lambda^{CU}_{ia}`$ を持つ。
局所同型 $`(\lambda^{CU}_{ia})^{-1}\lambda^{UC}_{ia}`$ は両方向に整合する。
定理10.3の全Hom復元を二回使って $`\Xi`$ を作る。
原始操作・domain・関係・量を保存することはこの局所式で検査できる。
逆の局所式を復元すると $`\Xi^{-1}`$ になり、両合成は忠実性により恒等である。
射とtrivializationに関する自然性、比較の合成則も、局所では恒等同士の比較となるため従う。
ここでは等化子と任意の関手が一般に交換することを仮定していない。
使ったのは各原始宣言の復元式と、その全Homの一意性である。□

## 10.4 図式補完と条件付きfiber

**定義10.7（条件の局所性）.**
許容条件 $`H`$ と評価条件 $`V`$ がこの被覆に関して局所的であるとは、
制限によって条件を保ち、整合datumの復元が条件を満たすことと各局所対象が
条件を満たすことが同値になることをいう。witnessを条件のデータに含む場合は、
witness自身の整合と復元も要求する。

次の原始規則では、この局所性を直接確認できる。
固定操作・固定domainの等式、有限個の多項式保存式は、それを含む文脈と忠実平坦性で検査する。
線形写像の単射・全射・同型はkernel・余核と忠実平坦性で検査する。
多項式評価の零性と単元性は、前者を忠実性、後者を余核 $`R/(g)`$ の零性で検査する。
存在する逆写像は一意なので貼り合う。選択された移送や因子分解を持つ規則では、その写像と
可換式を宣言として降下する。任意の存在条件について、局所witnessの存在だけから
大域witnessを得るとは限らない。

**定理10.8（全補完・条件付き変更のdescent）.**
定理10.3の実現方式を用いる。小圏 $`J`$、固定部分圏、固定図式 $`d`$、
端点 $`a`$ とその制限を指定し、評価写像が制限と整合するとする。
上記の原始規則からなる $`H,V`$、または別途その局所性を証明した $`H,V`$ について、
第8章の全補完 $`\mathcal D_{J,K_{\mathrm{fix}},d}`$ と
$`\mathcal F^{\partial}_{a,H,V}`$ は対象・全比較射のdescentを満たす。
この復元と定理10.6の交換同型は、固定trivializationを保つ。

**証明.**
局所図式の各頂点を対象descent、各辺を全Homのdescentで復元する。
恒等・合成の式は全Homの忠実性から復元後にも成立するので、実際の関手 $`D:J\to\mathcal A`$ を得る。
固定部の同型 $`\alpha`$ と逆を降下すると、自然性と両逆の式が降下し
$`\alpha:D|_{K_{\mathrm{fix}}}\cong d`$ を得る。
射 $`\beta`$ は同じ方法で復元され、$`\alpha'\beta|_{K_{\mathrm{fix}}}=\alpha`$ は局所で検査する。
端点の同定と評価についても $`\alpha:\partial c\cong a`$ を先に降下し、
評価の自然性で局所評価がその制限であることを示す。
局所性により $`H,V`$ を満たすので式(8.1)の対象になる。
比較射とその固定条件も同じ可換式として復元する。
全構成が原始宣言の復元なので定理10.6と交換する。□

## 10.5 matchingと大域化

**例10.9（観測の参照を保持する）.**
加法群 $`A`$ の二変数 $`X,Y`$ と観測 $`T=X+Y`$ を固定する。
観測を保つ補正は $`(a,-a)`$ である。
観測式を保持せず $`\{X\},\{Y\}`$ の二つへ分け、各側で単独の変数を観測として固定すると、
各局所補正は0に限られる。この制限は元の固定観測の制限ではない。
観測宣言を含む文脈には $`X,Y`$ と加法も含めると、保存条件 $`h_X+h_Y=0`$ を
同じ式として制限・復元できる。

**命題10.10（厳密matching）.**
宣言・操作の実体と比較の成分を固定し、重なりで対象も射も厳密に等しいdatumを取る。
局所の固定条件が各宣言で検査できるとき、その合併は一意な大域対象・射を与える。

**証明.**
各宣言と射の成分を、それを含む文脈からそのまま取る。
等号による整合が選択からの独立性を与え、Law・固定条件は全支持を含む文脈で検査する。
全宣言が覆われるため一意である。□

指定操作を厳密に固定する第11章では、この命題を候補の零条件にも適用する。
重なりの任意の同型による同定へ置き換えられるかは、その同型を固定条件を保って
延長できるかで決まる。[例11.15](chapter_11_ariadne_relative_repairs.md#119-実アフィン操作への実現と例)で
両者の相違を計算する。

**問題10.11（実現クラスと一般規則の局所性）.**
任意の実現方式 $`\sigma`$ について、その担体、domain、Lawの解釈からdescentの有効性を決定せよ。
特に無限表示の局所split copyingでは、宣言方向に組み立てた全構造を一つの開被覆上で
同時にsplitにする条件を求めよ。一般の $`H,V`$ については、選択witnessのdescentと
局所存在条件を分け、定理10.8の局所性を原始規則から証明せよ。
二方向比較を任意のreadingへ輸送し、readingの合成と整合させる問題は第14章へ送る。
