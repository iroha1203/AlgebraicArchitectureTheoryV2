# 付録C 関係・解消・逆極限

第IV部で使う低次数の障害群と、比較を構成するための代数をまとめる。
複体はコホモロジー次数を使い、通常の自由解消の第 $`j`$ 項を次数 $`-j`$ に置く。
quasi-isomorphismは全コホモロジーで同型を与える複体写像をいう。

## C.1 関係加群と余接複体

$`P=k[x_1,\ldots,x_n]\twoheadrightarrow A`$ のkernelを $`I`$ とする。
導分を表す加群 $`\Omega_{P/k}`$ は $`dx_i`$ を基底とする自由 $`P`$-加群であり、
$`df=\sum(\partial f/\partial x_i)dx_i`$ と定める。
$`d(I^2)\subseteq I\Omega_{P/k}`$ なので

```math
N_{A/k}=[I/I^2\xrightarrow d\Omega_{P/k}\otimes_PA]
\qquad\text{(C.1)}
```

を次数 $`-1,0`$ に作れる。
この複体は余接複体 $`L_{A/k}`$ の次数 $`-1,0`$ の切断を表す。
全余接複体は、$`A`$ の自由simplicial多項式代数解消 $`P_\bullet\to A`$ を取り、
$`\Omega_{P_\bullet/k}\otimes_{P_\bullet}A`$ を正規化して構成する。
一つの解消は、忘却した集合上の自由多項式代数を反復して作る。
faceは隣接する自由代数の評価、degeneracyは自由生成元への挿入である。
増大した集合のsimplicial対象には、各元をその名前の自由生成元へ送る余分なdegeneracyがあり、
これが解消の縮約を与える。
次数1の関係は $`I/I^2`$、その微分は上の $`d`$ になり、
さらに高い次数は関係間の関係を保持する。

**補題C.1（liftに必要な二次数と表示比較）.**
任意の $`A`$-加群 $`M`$ に対して

```math
\mathop{\mathrm{Ext}}\nolimits^0_A(L_{A/k},M)=\mathop{\mathrm{Der}}\nolimits_k(A,M),\qquad
\mathop{\mathrm{Ext}}\nolimits^1_A(L_{A/k},M)=
\mathop{\mathrm{coker}}\nolimits\bigl(\mathop{\mathrm{Hom}}\nolimits_A(\Omega_{P/k}\otimes A,M)
 \to\mathop{\mathrm{Hom}}\nolimits_A(I/I^2,M)\bigr).
```

**証明.**
$`I/I^2`$ の自由解消 $`\cdots\to F_1\to F_0\to I/I^2\to0`$ を取り、
その末尾を式(C.1)の次数0の自由加群へ接続する。
Hom複体の次数1のcocycleは $`F_0\to M`$ で $`F_1`$ を消すもの、
すなわち $`I/I^2\to M`$ であり、0からの微分は表示した写像である。
次数0のkernelは $`I`$ を消す $`k`$-導分なので $`\mathop{\mathrm{Der}}\nolimits_k(A,M)`$ になる。
全余接複体と式(C.1)の差は次数 $`-2`$ 以下にあり、加群 $`M[0]`$ への導来Homでは
次数2以上にしか寄与しない。従ってこの計算で次数0,1を得る。

表示比較を直接確認するには、追加変数 $`y`$ に定義式 $`y-g(x)`$ を課す場合を考える。
conormalと微分加群に各一つの自由成分が増え、微分は $`(-dg,1)`$ である。
基底を変えるとこれは $`[A\xrightarrow1A]`$ の可縮な直和になる。
二つの多項式表示は、その変数の和集合の表示を介してこの操作で比較できる。
原始残差の評価も $`y=g(x)`$ を代入する同じ写像で運ばれる。
従って上の二群とliftの指定類は表示によらない。
全simplicial解消の比較は自由生成元の持上げで作り、二つの持上げの差を次の次数へ持ち上げると
homotopyを得る。これが全余接複体の導来同型型の独立性も与える。□

## C.2 正則列とsmoothness

正則列 $`f_1,\ldots,f_r`$ とは、各 $`f_i`$ が
$`B/(f_1,\ldots,f_{i-1})`$ 上の非零因子で、最後の商が零環でない列をいう。
局所的な主張では点を含む局所環でこの条件を課す。

**補題C.2（有理点での局所判定）.**
完全体 $`k`$ 上の有限型schemeの有理点 $`x`$ では、smoothnessは
局所環の正則性、すなわち
$`\dim_k\mathfrak m/\mathfrak m^2=\dim\mathcal O_{X,x}`$ と同値である。
多項式環の局所環を長さ $`r`$ の正則列で割ると、その次元は $`n-r`$ である。

**証明の代数的内容.**
多項式環の有理点の局所環は、$`x_i-x_i(x)`$ を正則parameterとする次元 $`n`$ の正則局所環である。
正則局所環はCohen–Macaulayであり、正則列の元を一つ割るたびに深さと次元が一つ減る。
これは非零因子による短完全列と局所環の次元定理から帰納でき、商の次元は $`n-r`$ となる。
有限型 $`k`$-代数の有理点では、微分の普遍性が
$`\Omega_{A/k}\otimes_Ak\cong\mathfrak m/\mathfrak m^2`$ を与える。
完全体上では有限型代数の正則局所環は幾何学的にも正則であり、これがsmoothnessの局所判定になる。
ここでは、体上の有限型代数についての「幾何学的正則性とsmoothnessの同値」という
通常の可換環論の定理を用いている。

第12章の完全交差の十分性は直接にも分かる。
階数 $`r`$ のJacobian minorが点で可逆なら、その近傍の任意の平方零残差を
その $`r`$ 変数の補正で消せる。
これは有限表示のstandard smoothな表示を与え、残る $`n-r`$ 個の変数を自由parameterにできる。
逆にsmoothな点では局所parameterの一次変形はその次元だけ独立なので、
接空間と局所次元が一致し、Jacobianの階数は $`r`$ になる。□

## C.3 導来テンソルとTor

加群 $`N`$ の自由解消は、その全元を生成元とする自由加群から全射し、
そのkernelに同じ操作を反復して作れる。
二つの解消の間の比較は、各自由生成元の像を全射に沿って持ち上げて順に構成する。
二比較の差は各段で次の微分像に入るので、同じ持上げで鎖homotopyを作れる。
従って解消 $`F_\bullet\to N`$ から作る $`F_\bullet\otimes_BM`$ の
導来同型型とhomologyは選択に依存しない。後者を $`\mathop{\mathrm{Tor}}\nolimits^B_j(N,M)`$ と定義する。
短完全列を自由解消で持ち上げてconeを取ると、対応するTorの長完全列を得る。
flatな加群でtensorする場合には元の完全性が保たれるので正次数は消える。

商代数の導来tensorを代数として保持する場合は、自由simplicial $`B`$-代数解消を使い、
各段を他方の商とtensorする。これにより乗法と単位も保持される。
各段の多項式代数は $`B`$-自由、正規化した加群はその直和因子なので、
その基礎複体のhomologyは上のTorの計算と一致する。
従って第12章の自由加群解消による計算は、この代数的交差のコホモロジーを計算している。

**補題C.3（正則列とKoszul複体）.**
$`f_1,\ldots,f_r`$ が加群 $`M`$ 上で順に非零因子なら、
$`K_\bullet(f_1,\ldots,f_r)\otimes M`$ の正次数homologyは0、
次数0は $`M/(f_1,\ldots,f_r)M`$ である。

**証明.**
一元では $`[M\xrightarrow{f_1}M]`$ なので単射性から従う。
長さ $`r`$ のKoszul複体は長さ $`r-1`$ の複体上の $`f_r`$ 倍のconeである。
帰納法でそのhomologyは次数0の商だけなので、coneの長完全列と
その商上の $`f_r`$ の単射性が結論を与える。□

## C.4 可算塔と導来逆極限

可算加群塔 $`(M_n,r_n)`$ の逆極限は
$`\Phi:\prod M_n\to\prod M_n`$、$`\Phi(x)_n=x_n-r_nx_{n+1}`$ のkernelである。
その余核を $`\lim^1M_n`$ とする。この二項複体は可算塔の導来逆極限を計算する。
この計算を導来関手と同定するには、$`J_n=\prod_{i=0}^nM_i`$、遷移を末尾射影とし、
$`M_n\to J_n`$ を $`x\mapsto(r_{0,n}x,\ldots,r_{n-1,n}x,x)`$ とする。
これは塔の単射で、$`J`$ は全射塔だから $`\Phi_J`$ も全射である。
積が完全なのでkernel・余核によるこの計算は短完全な塔の列から長完全列を与え、
今の埋込みで次数1を消せる。従って導来関手の普遍性により $`H^0=\lim,H^1=\lim^1`$ と同定される。
複体が二項なので可算塔にはこの計算を越える高次の項がない。
複体の塔には同じ操作を次数ごとに施して総複体を取り、式(13.3)を得る。

Mittag–Leffler塔について、各 $`n`$ で安定した後段の像を $`I_n\subseteq M_n`$ とする。
十分後の共通段を使えば $`r_nI_{n+1}=I_n`$ である。
$`I_n`$ の塔では再帰的持上げで $`\Phi`$ は全射となる。
$`Q_n=M_n/I_n`$ の塔では、各固定 $`n`$ への遷移 $`r_{n,m}`$ が十分大きい $`m`$ で0となる。
この場合、$`z=(z_n)`$ に対し

```math
x_n=\sum_{m\ge n}r_{n,m}z_m
```

は各 $`n`$ で有限和であり、$`x_n-r_nx_{n+1}=z_n`$ である。
元の塔の $`z`$ を商へ送りこの式を解き、その $`x_n`$ を $`M_n`$ へ持ち上げると、
残る誤差は $`I_n`$ の積に入る。その誤差を全射塔の解で補正できるので
元の $`\Phi`$ も全射、すなわち $`\lim^1M_n=0`$ となる。

この議論は塔のコホモロジーの安定像についてのものである。
個々の対象がある有限段で完全に決まることは、逆極限からその段への射の単射性など、
別の条件を要する。
