# 付録C 関係・解消・逆極限

この付録では、第IV部で用いる低次数の障害群と、それらの間の比較を構成するためのホモロジー代数の基礎をまとめる。複体にはコホモロジー次数を採用し、通常の自由解消の第 $`j`$ 項は次数 $`-j`$ に置く。また、すべてのコホモロジー群で同型を誘導する複体写像を**擬同型（quasi-isomorphism）**と呼ぶ。

## C.1 関係加群と余接複体

任意の可換環 $`k`$ と小さい添字集合 $`\Lambda`$ に対し、多項式環からの全射 $`P=k[x_\lambda\mid\lambda\in\Lambda]\twoheadrightarrow A`$ の核を $`I`$ とする。導分を表現する微分加群 $`\Omega_{P/k}`$ は $`dx_\lambda`$ を基底とする自由 $`P`$-加群であり、微分は $`df=\sum_\lambda(\partial f/\partial x_\lambda)dx_\lambda`$ で定められる（各多項式は有限個の変数しか含まないため、この和は有限和である）。ライプニッツ則より $`d(I^2)\subseteq I\Omega_{P/k}`$ が成り立つため、次数 $`-1,0`$ に置かれた二項複体

```math
N_{A/k}=[I/I^2\xrightarrow d\Omega_{P/k}\otimes_PA]
\qquad\text{(C.1)}
```

が定まる。

全余接複体 $`L_{A/k}`$ は、台集合上の自由多項式代数を反復する標準的な単体的（simplicial）解消 $`P_0=k[A],\ P_1=k[k[A]],\ \ldots`$ に対して、$`\Omega_{P_\bullet/k}\otimes_{P_\bullet}A`$ を正規化した複体として定義する。単体次数 $`j`$ はコホモロジー次数 $`-j`$ に置く。ここで面写像（face）は隣接する自由代数の評価写像であり、退化写像（degeneracy）は自由生成元への挿入である。増大された集合の単体的対象には、各元をその名前の自由生成元へ送る余分な退化写像が存在し、これが解消の縮約を与える。

本文では、全余接複体に関する次の三つの標準的な比較結果を用いる：

1. 任意の小さい多項式表示に対して、自然な導来同型 $`N_{A/k}\simeq\tau_{\ge-1}L_{A/k}`$ が存在する。ここで標準切断 $`\tau_{\ge-1}`$ は、次数 $`-1`$ の項を次数 $`-2`$ からの微分像で割り、より低い次数の項を消す操作である（正規化複体の次数 $`-1`$ の項そのものを $`I/I^2`$ と同一視しているわけではない）。
2. 多項式 $`k`$-代数 $`B`$ については、変数の個数によらず $`L_{B/k}\simeq\Omega_{B/k}[0]`$ が成り立つ。
3. 任意の環準同型の合成 $`k\to B\to A`$ について、推移三角

```math
L_{B/k}\otimes_B^{\mathbf L}A\longrightarrow L_{A/k}\longrightarrow L_{A/B}
 \longrightarrow (L_{B/k}\otimes_B^{\mathbf L}A)[1]
```

が成り立つ。

第12章で用いる低次数の導来 $`\mathrm{Hom}`$ 計算および表示間の比較は、以下の通り加群の計算によって直接証明できる。

**補題C.1（持ち上げに必要な2次数と表示比較）.**
任意の $`A`$-加群 $`M`$ に対して次が成り立つ：

```math
\mathop{\mathrm{Ext}}\nolimits^0_A(L_{A/k},M)=\mathop{\mathrm{Der}}\nolimits_k(A,M),\qquad
\mathop{\mathrm{Ext}}\nolimits^1_A(L_{A/k},M)=
\mathop{\mathrm{coker}}\nolimits\bigl(\mathop{\mathrm{Hom}}\nolimits_A(\Omega_{P/k}\otimes_PA,M)
 \to\mathop{\mathrm{Hom}}\nolimits_A(I/I^2,M)\bigr).
```

**証明.**
まず、$`I/I^2`$ の自由 $`A`$-加群解消 $`\cdots\to F_1\to F_0\to I/I^2\to0`$ を取り、その末尾を式(C.1)の次数 $`0`$ の自由加群 $`\Omega_{P/k}\otimes_PA`$ へ接続する。この自由複体から $`M`$ への $`\mathrm{Hom}`$ 複体において、次数 $`1`$ のコサイクルとは $`F_0\to M`$ であって $`F_1`$ を消すもの、すなわち $`A`$-線形写像 $`I/I^2\to M`$ に他ならず、次数 $`0`$ からの微分像は $`\mathop{\mathrm{Hom}}\nolimits_A(\Omega_{P/k}\otimes_PA,M)\to\mathop{\mathrm{Hom}}\nolimits_A(I/I^2,M)`$ の像である。また、次数 $`0`$ の核は $`I`$ を消す $`k`$-導分、すなわち $`\mathop{\mathrm{Der}}\nolimits_k(A,M)`$ に一致する。全余接複体 $`L_{A/k}`$ と切断 $`N_{A/k}\simeq\tau_{\ge-1}L_{A/k}`$ の差は次数 $`-2`$ 以下に集中しているため、次数 $`0`$ に置かれた加群 $`M[0]`$ への導来 $`\mathrm{Hom}`$ には次数 $`2`$ 以上にしか寄与しない。よってこの計算から次数 $`0,1`$ の公式が得られる。

次に、二つの多項式表示 $`P\twoheadrightarrow A`$ と $`Q\twoheadrightarrow A`$ の間の比較を直接構成する。$`P`$ の生成元を $`Q`$ へ持ち上げて $`A`$ 上の $`k`$-代数射 $`\varphi:P\to Q`$ を取ると、これは余法加群（conormal 加群）$`I/I^2\to J/J^2`$（ただし $`J=\ker(Q\to A)`$）および微分加群の写像を誘導し、したがって二項複体 $`N_{A/k}`$ の写像を与える。別の持ち上げ $`\psi:P\to Q`$ に対して
$`D(p)=[\varphi(p)-\psi(p)]\in J/J^2`$
と置くと、積の余分な項 $`(\varphi(p)-\psi(p))(\varphi(q)-\psi(q))`$ は $`J^2`$ に入るため、$`D:P\to J/J^2`$ は $`k`$-導分となり、$`A`$-線形写像 $`h:\Omega_{P/k}\otimes_PA\to J/J^2`$ を誘導する。二つの誘導写像の差は次数 $`-1`$ で $`hd_P`$、次数 $`0`$ で $`d_Qh`$ となるため、両者は加群複体の鎖ホモトピーで結ばれる。逆向きの表示射も同様に選べば、両合成が恒等写像と鎖ホモトピックになり、表示間のホモトピー同値を得る。

さらに、平方零拡大 $`R'\to R`$ に対する周囲での持ち上げ $`Q\to R'`$ を $`\varphi`$ と合成して $`P\to R'`$ の持ち上げに選べば、残差も $`r_P=r_Q\bar\varphi`$ と運ばれる。周囲での持ち上げの選択の差は微分の像に吸収されるため、定理12.2の指定障害類も表示比較の下で正確に対応する。なお、この議論では代数射の差を再び代数射として扱うのではなく、差を余法加群 $`J/J^2`$（商環 $`Q/J^2`$ 内の平方零イデアル）への導分へ変換してから加群複体の鎖ホモトピーに用いている点に注意する。□

## C.2 正則列と滑らかさ

環 $`B`$ の元の列 $`f_1,\ldots,f_r`$ が**正則列**であるとは、各 $`f_i`$ が商環 $`B/(f_1,\ldots,f_{i-1})`$ 上の非零因子であり、かつ最後の商環 $`B/(f_1,\ldots,f_r)`$ が零環でないことをいう。局所的な主張では、注目する点における局所環上でこの条件を課す。

**補題C.2（有理点での局所判定）.**
完全体 $`k`$ 上の有限型スキーム $`X`$ の有理点 $`x`$ において、点 $`x`$ での滑らかさ（smoothness）は局所環 $`\mathcal O_{X,x}`$ の正則性、すなわち
$`\dim_k\mathfrak m/\mathfrak m^2=\dim\mathcal O_{X,x}`$
と同値である。さらに、$`n`$ 変数多項式環の有理点における局所環を長さ $`r`$ の正則列で割った商環の次元は $`n-r`$ である。

**証明の代数的内容.**
多項式環 $`k[x_1,\ldots,x_n]`$ の有理点 $`x`$ における局所環は、$`x_i-x_i(x)`$ を正則パラメータ系とする次元 $`n`$ の正則局所環である。正則局所環は Cohen–Macaulay であり、正則列の元で一つ割るたびに深さとクルル次元がそれぞれ $`1`$ ずつ減少する。これは非零因子による短完全列と局所環の次元定理から帰納的に確かめられ、長さ $`r`$ の正則列による商環の次元は $`n-r`$ となる。

有限型 $`k`$-代数 $`A`$ の有理点では、微分加群の普遍性により同型 $`\Omega_{A/k}\otimes_Ak\cong\mathfrak m/\mathfrak m^2`$ が成り立つ。完全体上では有限型代数の正則局所環は幾何学的にも正則であり、これが滑らかさの局所判定を与える（ここでは、体上の有限型代数についての「幾何学的正則性と滑らかさの同値」という可換環論の標準定理を用いている）。

第12章における完全交差の場合の十分性は直接にも確認できる。階数 $`r`$ のヤコビ小行列式（Jacobian minor）が点 $`x`$ で可逆であれば、その近傍における任意の平方零残差を、対応する $`r`$ 個の変数の補正によって消去できる。これは有限表示の標準的に滑らかな（standard smooth）表示を与え、残る $`n-r`$ 個の変数を自由パラメータに取れる。逆に滑らかな点では局所パラメータの1次変形はその次元だけ一次独立であるため、接空間の次元と局所環の次元が一致し、ヤコビ行列の階数はちょうど $`r`$ になる。□

## C.3 導来テンソルとTor

$`B`$-加群 $`N`$ の自由解消は、$`N`$ のすべての元を生成元とする自由 $`B`$-加群からの全射を取り、その核に対して同じ操作を反復することで構成できる。二つの自由解消の間の比較写像は、各自由生成元の像を全射に沿って持ち上げることにより順次構成でき、二つの比較写像の差は各段で次の微分像に入るため、同じ持ち上げによって鎖ホモトピーを構成できる。したがって、自由解消 $`F_\bullet\to N`$ から作る複体 $`F_\bullet\otimes_BM`$ の導来同型型およびホモロジー群は解消の選択に依存しない。この第 $`j`$ ホモロジー群を $`\mathop{\mathrm{Tor}}\nolimits^B_j(N,M)`$ と定義する。短完全列を自由解消で持ち上げて写像錐を取れば対応する Tor の長完全列が得られ、平坦な加群 $`M`$ でテンソルする場合には元の解消の完全性が保たれるためすべての正の次数の Tor は消える。

二つの商代数の導来テンソル積を代数構造ごと保持したい場合には、自由な単体的 $`B`$-代数解消を用い、各段を他方の商代数とテンソルする。これにより乗法と単位元も保持される。各段の多項式代数は $`B`$-自由であり、正規化複体の各加群はその直和因子であるため、その基礎複体のホモロジーは上の自由加群解消による Tor の計算と完全に一致する。したがって、第12章で自由加群解消を用いて行う計算は、この代数的交差のコホモロジーをそのまま計算している。

**補題C.3（正則列とKoszul複体）.**
環 $`B`$ の元の列 $`f_1,\ldots,f_r`$ が $`B`$-加群 $`M`$ 上で順に非零因子であるならば、Koszul 複体 $`K_\bullet(f_1,\ldots,f_r)\otimes_BM`$ の正の次数のホモロジーはすべて $`0`$ であり、次数 $`0`$ のホモロジーは $`M/(f_1,\ldots,f_r)M`$ である。

**証明.**
長さ $`r=1`$ の場合は二項複体 $`[M\xrightarrow{f_1}M]`$ であり、$`f_1`$ 倍写像の単射性から直ちに従う。一般の長さ $`r`$ の Koszul 複体 $`K_\bullet(f_1,\ldots,f_r)\otimes_BM`$ は、長さ $`r-1`$ の複体 $`K_\bullet(f_1,\ldots,f_{r-1})\otimes_BM`$ 上の $`f_r`$ 倍写像の写像錐として表される。帰納法の仮定により長さ $`r-1`$ の複体のホモロジーは次数 $`0`$ の商加群 $`M/(f_1,\ldots,f_{r-1})M`$ だけに集中しているため、写像錐に伴うホモロジー長完全列と、その商加群上での $`f_r`$ 倍写像の単射性から結論が従う。□

## C.4 可算塔と導来逆極限

可算の加群の塔 $`(M_n,r_n)`$（ただし遷移写像を $`r_n:M_{n+1}\to M_n`$ とする）の逆極限 $`\lim M_n`$ は、シフト差写像
$`\Phi:\prod_{n\ge0}M_n\to\prod_{n\ge0}M_n,\quad \Phi(x)_n=x_n-r_nx_{n+1}`$
の核であり、その余核を $`\lim^1 M_n`$ と定義する。この二項複体 $`[\prod M_n\xrightarrow{\Phi}\prod M_n]`$ が可算塔の導来逆極限を計算することを確認しよう。

各段に $`J_n=\prod_{i=0}^n M_i`$、遷移写像に末尾成分の射影を置いた塔 $`J`$ を考え、塔の射 $`M_n\to J_n`$ を $`x\mapsto(r_{0,n}x,\ldots,r_{n-1,n}x,x)`$ で定める。これは塔の単射であり、$`J`$ は遷移がすべて全射な塔であるため $`\Phi_J`$ も全射（すなわち $`\lim^1 J_n=0`$）である。直積が完全関手であることから、核と余核によるこの二項複体は短完全な塔の列から長完全列を誘導し、上の埋め込み $`M\hookrightarrow J`$ によって次数 $`1`$ を消すことができる。したがって導来関手の普遍性により、$`H^0=\lim`$ および $`H^1=\lim^1`$ と同定される。また、複体が二項であるため、可算塔には次数 $`2`$ 以上の高次の導来逆極限は現れない。複体の可算塔に対しては、この操作を各次数に施して総複体を取ることで、第13章の式(13.3)が得られる。

次に、Mittag–Leffler 条件による $`\lim^1`$ の消滅を示す。Mittag–Leffler 塔 $`(M_n,r_n)`$ に対し、各 $`n`$ で安定した後段からの像を $`I_n\subseteq M_n`$ と置く。十分大きい共通の後段を取れば $`r_n(I_{n+1})=I_n`$ が成り立つため、部分塔 $`(I_n)`$ は遷移がすべて全射であり、再帰的な持ち上げによって $`\Phi_I`$ は全射（$`\lim^1 I_n=0`$）となる。一方、商の塔 $`Q_n=M_n/I_n`$ では、各固定された段 $`n`$ への合成遷移写像 $`r_{n,m}:Q_m\to Q_n`$ が十分大きい $`m`$ に対してすべて $`0`$ になる。したがって、任意の列 $`z=(z_n)\in\prod Q_n`$ に対し、

```math
x_n=\sum_{m\ge n}r_{n,m}z_m
```

は各 $`n`$ について有限和として定まり、$`x_n-r_nx_{n+1}=z_n`$ を満たす。

そこで、元の塔の任意の元 $`z\in\prod M_n`$ を商の塔 $`(Q_n)`$ へ送って上の有限和で解き、得られた $`x_n\in Q_n`$ を $`M_n`$ へ任意に持ち上げると、残る誤差 $`z-\Phi(x)`$ は部分塔の直積 $`\prod I_n`$ に入る。この誤差は全射塔 $`(I_n)`$ の解で補正できるため、元の写像 $`\Phi`$ も全射となり、$`\lim^1 M_n=0`$ が証明される。

最後に、以上の議論はあくまで塔のコホモロジー群の安定像と $`\lim^1`$ の消滅に関するものである点に注意する。個々の大域対象がある有限段だけで完全に一意に決まるためには、例13.8および命題13.9で見たように、逆極限からその有限段への制限射の単射性といった別の条件が必要になる。
