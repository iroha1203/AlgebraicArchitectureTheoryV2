# 第17章 出現の同定と観測語彙

一つの個体が複数の場所に現れることも、同じ名前が異なる個体に使われることもある。操作を通じて受け渡された出現をどこまで同一視するかによって、その後に読める量と評価できる Law が変わる。本章では、出現の記録から同一視を生成し、使用する評価を保つ商と、それを実現する補助属性を構成する。

第9章の操作合同関係を、複数の sort、部分的な操作記録、明示された不在、および部分評価へ拡張する。記録の同定と、未記録部分を埋めた構造の選択は別の段階であり、後者は第18章で扱う。

## 17.1 原始出現と機能的な同一視

**定義17.1（原始出現系）.**
第1章の署名 $`\Sigma`$ を固定する。**原始出現系** $`\mathcal E`$ は、各 sort の小さい出現集合 $`E_s`$、同一視要求 $`\mathscr R_s\subseteq E_s^2`$、および次の型付き記録からなる。

- 操作・部分操作・量の出力記録 $`G_e^+\subseteq E_{s_1}\times\cdots\times E_{s_n}\times E_t`$。
- 関係の成立・不在記録 $`r^+,r^-`$、部分操作の定義域の成立・不在記録 $`D_p^+,D_p^-`$、および出力組の不在記録 $`G_e^-`$。
- 固定値 sort $`v`$ の値集合 $`E_v=V_v`$。異なる固定値は同一視しない。

出力記録の入力は定義域成立の記録にも含める。未記録の入力には出力の存在も不在も課さない。全域操作として宣言された名前についても、この段階で全入力の出力が記録されているとは要求しない。関係や定義域について、成立・不在のどちらも記録されていない組があってよい。

同値関係族 $`\theta=(\theta_s)_s`$ が**機能的**であるとは、同じ操作名の二つの出力記録について

**式(17.1)**

```math
(\boldsymbol x,y),(\boldsymbol x',y')\in G_e^+,
\quad x_i\mathrel{\theta_{s_i}}x_i'\ (1\le i\le n)
\quad\Longrightarrow\quad y\mathrel{\theta_t}y'
```

が成り立つことをいう。固定値の区別と不在記録との整合は、この機能性とは別に検査する。

**定理17.2（最小機能閉包と記録の衝突）.**
$`\mathscr R`$ を含む最小の機能的同値関係族 $`\theta^{\min}(\mathcal E)`$ が存在する。商出現集合上に正の記録の像を取ると、各操作の記録は一価になる。

この商記録が固定値を区別し、成立記録と不在記録を混同しないための必要十分条件は、次の二条件である。

1. 固定値 sort 上の $`\theta^{\min}_v`$ が等号である。
2. 各関係・定義域・操作グラフについて、正の記録と負の記録の組が成分ごとに $`\theta^{\min}`$ で同値にならない。

これらのいずれかが失敗すると、要求を含むどの機能的同一視でも、その衝突を解消できない。

**証明.**
機能的同値関係族の交差は、式(17.1)を保つ。全関係族は機能的なので、要求を含むすべての族の交差を取れる。これが最小の族である。商の同じ入力に二つの正の出力記録があれば、式(17.1)が両出力を同じ商類にする。

商記録の固定値と正負の衝突は、まさに二条件で検出される。任意の機能的同一視は最小族を含むため、既に同じ類になった対を再び分離できない。逆に二条件が成立すれば最小族自身の商記録がそれらを満たす。□

この定理は記録の一価性と無矛盾性を構成する。たとえば非空な入力担体から空な出力担体への全域操作を宣言した場合、出力記録がなくても二条件は成立しうるが、全構造への延長は存在しない。全域性を含む延長の存在は18.1節の補完条件で判定する。

**命題17.3（有限閉包と破綻の導出列）.**
sort・操作名・記録が有限で、固定値 sort を含む各出現集合が有限かつ等号を判定できるとする。このとき最小機能閉包と定理17.2の二条件を有限計算で判定できる。衝突があれば、要求からその衝突へ至る有限の導出列を返せる。

**証明.**
要求から同値閉包を取り、入力が同値となった二つの記録の出力対を追加し、再び同値閉包を取る。新しい対が加わるたびに有限集合 $`\coprod_s E_s^2`$ の部分集合が真に増えるので停止する。各段階の対は任意の機能的上界に含まれ、停止時は機能的なので、最小族に一致する。追加する対ごとに、要求、反射律、対称律、推移律、または用いた出力記録と入力対を保存する。衝突した正負の組または異なる固定値からこの記録を逆にたどれば、有限導出列を得る。□

## 17.2 使用文脈と健全な商

**定義17.4（使用文脈同値と健全な同定）.**
sort $`s`$ の出現を一つ受け取る許容評価文脈の族 $`\mathcal V_s`$ を指定する。各文脈 $`c`$ は、指定された定義域 $`D_c\subseteq E_s`$ と固定値集合への評価 $`c:D_c\to Z_c`$ を持つ。未定義を表す新しい値 $`\bot_c`$ を加えた全写像を $`\widehat c:E_s\to Z_c\amalg\{\bot_c\}`$ とし、

**式(17.2)**

```math
x\approx_{\mathcal V,s}y
\quad\Longleftrightarrow\quad
\forall c\in\mathcal V_s,\quad \widehat c(x)=\widehat c(y)
```

と定める。従って同値な出現では評価の値だけでなく定義可能性も一致する。

同値関係族 $`\theta`$ による**健全な同定**には、次を要求する。

1. 同一視要求を含み、式(17.1)、固定値の区別、正負の記録の無矛盾性を満たす。
2. 保存・反映する操作の定義域と関係を、型付き積集合の部分集合族としてあらかじめ指定する。その各部分集合 $`Q`$ は商上の部分集合 $`\bar Q`$ へ降り、積の商写像 $`q`$ に対して $`Q=q^{-1}(\bar Q)`$ を満たす。
3. 各使用文脈を商記録で評価でき、商写像 $`q_s`$ に沿って定義可能性と値を保存・反映する。すなわち $`D_c=q_s^{-1}(D_{\bar c})`$ かつ $`c=\bar c q_s`$ が定義域上で成り立つ。

未記録の項目をすべて偽と扱うことはしない。第2項で要求する定義域の全体が与えられている場合と、成立・不在の記録だけが与えられている場合を区別する。また、文脈が項や式で指定されるとき、第3項は商上でその構文を評価した結果についての条件である。

健全な同定は必ず

**式(17.3)**

```math
\theta^{\min}(\mathcal E)\subseteq\theta
\subseteq\approx_{\mathcal V}
```

を満たす。ただし一般の記録では、この包含だけから定義域の整合や構文評価の一致までは従わない。次に、それらを原始操作から導けるクラスを与える。

**設定17.5（定義域を含む文脈閉性）.**
出現集合上に各記録操作の実際の部分写像 $`e:D_e\to E_t`$ があり、その定義域・関係の真偽が全入力で指定されているとする。定義域・関係の正負記録はこれらの表と一致し、定義17.4の第2項ではその全体を保存・反映する。操作の正の出力記録は $`e`$ のグラフ全体とし、出力組の明示不在は課さず $`G_e^-=\varnothing`$ とする。全域操作では $`D_e=\prod_iE_{s_i}`$ である。量の固定値集合も指定する。

基本の使用文脈には、次を含める。

- 各定義域・関係の真偽について、一座標だけを動かし他の座標を任意の出現に固定した読取り。
- 他の引数を固定した量の読取り、および固定値 sort の恒等読取り。
- 問題で保ちたい評価の読取り。

これらから、型の合う操作を一つ代入し、残る引数を任意の出現に固定する操作を有限回反復して $`\mathcal V`$ を作る。合成文脈は代入操作が未定義なら未定義とする。評価対象の項・量化なしの式は、これらの原始読取りから構成する。量化を用いる場合は、別途指定した量化範囲の全体を商写像で覆い、同じ保存・反映の帰納法が適用できることを要求する。

**定理17.6（文脈閉性からの最大商）.**
設定17.5で得た $`\approx_{\mathcal V}`$ は、操作の出力、定義域、関係、固定値を保つ合同関係族であり、指定された文脈評価を商へ保存・反映する。このクラスで健全な同定が存在するための必要十分条件は

**式(17.4)**

```math
\theta^{\min}(\mathcal E)\subseteq\approx_{\mathcal V}
```

である。成立するとき $`\approx_{\mathcal V}`$ は最粗の健全な同定である。健全な同定の全体は、式(17.3)を満たす操作合同関係族として与えられる。

**証明.**
同値な入力組の一座標だけを置き換える。他の引数を固定した定義域読取りが基本文脈にあるので、操作の定義可能性は変わらない。両出力が定義されるとき、任意の出力文脈 $`c`$ にその操作を代入した文脈が $`\mathcal V`$ にあるため、両出力で $`\widehat c`$ が一致する。従って出力も文脈同値である。有限個の座標を順に置き換えれば操作の合同性を得る。同じ議論を関係の真偽読取りへ適用すると関係の保存・反映を得る。固定値の恒等読取りは異なる値の同一視を防ぐ。

商の操作 $`\bar e`$ と関係を代表元で定める。上の結果により代表によらず定まり、商の操作グラフは $`\bar e`$ のグラフとする。正の出力記録はこのグラフへ写り、$`G_e^-=\varnothing`$ なので負のグラフ記録との衝突もない。項の構成に関する帰納法で定義域と出力が対応する。等式は固定値を比較する評価、関係原子式は指定された真偽読取りとして扱い、論理演算についても帰納する。出現そのものの等号や操作グラフの所属真偽を評価として保つ場合には、その各座標の読取りも基本文脈に含める。これを含めずに、商写像がそれらを反映するとは結論しない。量化では、指定された範囲の全射性により商上の具体例を元へ戻して反映を示す。

任意の健全な同定は式(17.3)を満たす。逆に式(17.4)が成立すれば、今構成した文脈同値自身が要求を含み、すべての構造条件を満たす。最後に、文脈同値より細かい操作合同関係では定義域・関係の一致も保たれ、同じ構文帰納法が使える。よって分類と最大性が従う。□

一つの sort、全域単項操作 $`T`$、観測 $`o`$ に特殊化すると、定義域読取りは定数であり、使用文脈は $`o\circ T^n`$ で生成される。従って定理9.5の操作合同関係の分類を得る。たとえば $`E=\{a,b\}`$、$`T(a)=T(b)=a`$、$`o\equiv0`$ では、文脈同値は全関係であり、一点への商が得られる。

出力組の明示不在を課す場合には、式(17.4)だけでは足りない。$`E=\{a,b\}`$、$`T=\operatorname{id}_E`$ とし、正のグラフ記録を $`\{(a,a),(b,b)\}`$、負の記録を $`\{(a,b),(b,a)\}`$、要求を $`\mathscr R=\{(a,b)\}`$ とする。定義域と定数評価だけを読み取れば $`\theta^{\min}=\approx_{\mathcal V}=E^2`$ だが、商では正負のグラフ記録が衝突する。この系は $`G_T^-\ne\varnothing`$ なので設定17.5には属さない。

さらに、正のグラフの全補集合を負の記録とすると、操作の像に属する各出現は単独の同値類でなければならない。実際、$`y=e(\boldsymbol x)`$ と異なる $`y'`$ を同一視すれば、正の記録 $`(\boldsymbol x,y)`$ と負の記録 $`(\boldsymbol x,y')`$ が衝突する。この条件は、操作の出力同士を同一視できる通常の操作商より強い制約である。

**例17.7（最粗商がない部分記録）.**
$`E=\{a,b,c\}`$ に部分操作の記録 $`p(a)=a`$ と、$`p`$ が $`b`$ では未定義であるという記録を与える。$`c`$ での定義可能性は未記録とし、使用文脈は定数読取りだけとする。要求は空とする。

$`\{a,c\}\mid\{b\}`$ と $`\{a\}\mid\{b,c\}`$ は、それぞれ記録と定数評価を保つ商である。しかし両方を含む同値関係は全関係であり、定義域成立と明示不在を混同する。従って最粗の健全な同定は存在しない。この例では、設定17.5の全入力で指定された定義域と、その定義域読取りを含む文脈閉性が与えられていない。

全域操作でも、部分的なグラフ不在を課すと同じ現象が起こる。$`E=\{a,b,c\}`$、$`T=\operatorname{id}_E`$ とし、正の記録をその全グラフ、負の記録を $`G_T^-=\{(a,b)\}`$ とする。要求は空、評価は定数とする。上の二つの分割はともに操作と正負記録を保つが、両方を含む全関係では正の記録 $`(a,a)`$ と負の記録 $`(a,b)`$ が衝突する。従って、この場合にも最粗の健全な同定は存在しない。

**命題17.8（有限文脈の判定と分離文脈）.**
命題17.3と同じ有限性・等号判定の条件を課し、候補同値関係に対する構造条件と文脈評価の保存・反映を判定できるとする。健全な同定の全体、存在の有無、および最粗のものの存在を有限計算で求められる。設定17.5で有限個の基本読取りから文脈族を生成し、各読取りを評価でき、その値域 $`Z_c`$ の等号を判定できる場合は、反復細分で文脈同値と分離文脈を構成できる。

**証明.**
一般の場合には各 sort の有限集合上の同値関係をすべて列挙し、定義17.4の条件を検査する。残った有限族の中で全要素を含むものがあれば、それが最粗である。候補を除いた各検査に、未充足の同一視要求、固定値衝突、正負の記録、機能性違反、指定した部分集合の保存・反映の違反、または評価が異なる文脈と入力対を記録する。全候補が除かれた場合には、この有限な検査結果が不存在を示す。評価の判定は有限個の文脈を入力に含めるか、次のような有限生成手順によって与える。

設定17.5では、基本読取りの定義可能性と値で初期分割を作る。各操作の一座標以外を固定した部分写像について、未定義を独立な値として、現在の出力分割の逆像で入力分割を細分する。真の細分の回数は出現数で抑えられる。各段階の区別は基本文脈またはそれへの操作代入で説明できる。一方、文脈同値な対はどの段階でも分離されない。停止時の関係は基本読取りを保つ操作合同関係なので、文脈の構成に関する帰納法によりすべての文脈を保つ。従って停止時の分割が正確に文脈同値であり、細分の記録から分離文脈も取り出せる。□

たとえば $`E=\{a,b,c\}`$、$`T(a)=a,T(b)=c,T(c)=c`$、$`o(a)=o(b)=0,o(c)=1`$ とする。基本観測 $`o`$ の分割は $`\{a,b\}\mid\{c\}`$ だが、一回の細分で $`a,b`$ が分離される。分離文脈は $`o\circ T`$ であり、その後は分割が変わらない。

## 17.3 補助属性の最小値域

**設定17.9（初期読み出しと二つの補完問題）.**
初期読み出し $`p_s:E_s\to W_s`$ に、補助属性 $`a_s:E_s\to U_s`$ を加える。

評価分離だけの問題では、積読取りが同一視する出現を文脈同値に限り、要求は同じ積読取りを持つことを求める。健全な個体同定の問題では、それに加えて定義17.4のすべての構造条件を課す。どちらも初期読み出し $`p_s`$ 自体は保持する。

**定理17.10（評価分離の最小属性値域）.**
$`\mathscr R_s\subseteq\ker p_s\cap\approx_{\mathcal V,s}`$ とする。評価分離だけを満たす補助属性の最小値域濃度は

**式(17.5)**

```math
\kappa_s=\sup_{w\in\operatorname{im}p_s}
  \left|p_s^{-1}(w)/\!\approx_{\mathcal V,s}\right|
```

である。空像に対しては $`\sup\varnothing=0`$ とし、空集合から空集合への属性を許す。無限集合の濃度比較と各ファイバーでの選択には選択公理を用いる。

**証明.**
同じ $`p_s`$ 値を持つ異なる文脈同値類の代表には異なる属性値が必要なので、各ファイバーの商の濃度が下限になる。濃度 $`\kappa_s`$ の集合 $`U_s`$ を取り、各ファイバーの商から $`U_s`$ への単射を選ぶ。出現の属性をその同値類の像と定めると、
$`\ker(p_s,a_s)=\ker p_s\cap\approx_{\mathcal V,s}`$
となる。要求を含み、評価を分離し、下限を達成する。空像の場合も同じ主張が成り立つ。□

**定理17.11（健全な同定の実現と同時最適化）.**
健全な同値関係族 $`\theta`$ を固定し、

**式(17.6)**

```math
\theta^{\min}(\mathcal E)\subseteq\theta
\subseteq\ker p\cap\approx_{\mathcal V}
```

とする。$`\ker(p_s,a_s)=\theta_s`$ を実現する属性の最小値域濃度は

```math
\kappa_s(\theta)=\sup_{w\in\operatorname{im}p_s}
  |p_s^{-1}(w)/\theta_s|
```

である。すべての健全な積読取りはこの形から得られる。命題17.8の有限判定の条件に加えて $`p_s`$ を評価でき、$`W_s`$ の等号を判定できるなら、存在する場合には最適な濃度の組とそれを実現する属性を有限計算で返せる。不存在の場合には、命題17.8の検査結果に初期読み出しの不一致も含めて返せる。

**証明.**
固定した $`\theta`$ に対し、定理17.10と同じく各ファイバーの $`\theta_s`$ 類を区別することが必要であり、各商を同じ値域へ単射で送れば十分である。得られる核は正確に $`\theta`$ なので、その健全性を保持する。逆に健全な積読取りの核は式(17.6)と定義17.4を満たす。

有限系では健全な族を列挙し、$`\theta_s\subseteq\ker p_s`$ を満たすものだけを残す。この検査で除く族には、$`x\mathrel{\theta_s}y`$ かつ $`p_s(x)\ne p_s(y)`$ となる対を記録する。残った各族から得た組 $`(\kappa_s(\theta))_s`$ を比較する。成分ごとの順序で極小な組をすべて残せるし、指定した比較可能な費用で最小化してもよい。異なる sort の最小値を別々の同値関係族から取り出して、一つの族で同時達成できると結論することはしない。有限個の族と有限個の濃度の比較なので停止する。すべての族が除かれたときには、健全性または初期読み出しとの衝突を示す有限検査結果が揃う。□

**例17.12（評価には二値、操作保存には三値）.**
一つの sort で $`E=\{a,b,c,d\}`$ とし、全域操作 $`T`$、初期読み出し $`p`$、観測 $`o`$ を次の表で与える。操作の出力を正の記録として与え、明示不在は課さない。評価文脈は $`o\circ T^n`$（$`n\ge0`$）の全体とする。

| 出現 | $`T`$ | $`p`$ | $`o`$ |
| --- | --- | --- | --- |
| $`a`$ | $`a`$ | 0 | 0 |
| $`b`$ | $`c`$ | 0 | 0 |
| $`c`$ | $`c`$ | 1 | 0 |
| $`d`$ | $`d`$ | 0 | 1 |

文脈同値類は $`\{a,b,c\}`$ と $`\{d\}`$ である。$`p=0`$ のファイバーにはこの二類が現れるため、評価分離だけなら式(17.5)の値は2である。

一方、操作を保ち初期読み出しを保持する商で $`a\sim b`$ とすると、$`T(a)=a\sim c=T(b)`$ となり、$`p(a)\ne p(c)`$ に反する。$`d`$ は観測で $`a,b`$ と分離される。従って $`p=0`$ では三つの属性値が必要である。属性を $`a\mapsto0,b\mapsto1,c\mapsto0,d\mapsto2`$ とすると、積読取りは単射となり、三値で健全性を達成する。

さらに要求 $`\mathscr R=\{(a,b)\}`$ を加えると、$`\mathscr R\subseteq\ker p\cap\approx_{\mathcal V}`$ は成立するが、最小機能閉包が $`a\sim c`$ を強制する。そのため、初期読み出しを保持する健全な同定は存在しない。同一視要求の対だけを検査する手続きと、評価分離の式を操作保存の最小値へ流用する手続きは、いずれもこの例で失敗する。

## 17.4 別名・変換・解釈の区別

**例17.13（受渡しの別名と変換後の値）.**
出現 $`x,x'`$ が同じ量0を読み、操作記録も $`T(x)=y,T(x')=y'`$ と対応しているとする。$`x\sim x'`$ を要求すれば機能閉包は $`y\sim y'`$ を生成する。これは入力の別名を出力へ伝える同定である。反対に、変換前の出現 $`u`$ が量0、変換後の出現 $`T(u)`$ が量1を持つなら、量読取りを保つ同定では両者を分離しなければならない。「変換でつながる」という事実だけは同一視要求にならない。

同じ記号 $`x`$ が二つの解釈で異なる評価を持つ場合には、解釈を表すタグ $`i=0,1`$ を付けた出現 $`(i,x)`$ を取る。たとえば一方の量が0、他方が1なら、記号名だけの読取りは両者を区別できないが、タグを補助属性として加えれば分離できる。このタグの必要性は名前の形からではなく、固定した評価文脈の不一致から従う。

健全な商で個体と値の型が定まった後にも、操作の未記録入力や未確認の関係は残りうる。次章ではそれらを名前付きスロットとして保持し、すべての補完に共通して確定する評価を調べる。完成した候補族上での観測十分性と最小公開補完は、第20章へ接続する。
