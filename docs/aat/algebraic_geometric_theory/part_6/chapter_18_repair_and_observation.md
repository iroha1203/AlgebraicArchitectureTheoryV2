# 第18章 修復と観測

変更を許す範囲を広げると、補正によって吸収できる欠陥（defect）の範囲も広がる。
しかし、修復が可能であると分かるだけの情報から、具体的にどの補正値を返すべきかまで一意に決まるとは限らない。
本章では、第11章のアリアドネと同じ実際の入力・固定部分・許可範囲から一つの線形な補正方程式を構成し、修復の可否判定に必要な情報と具体的な数値補正に必要な情報とを比較する。
一般の体上の線形代数による特徴づけ、適応的な手続きを含めた最適問い合わせ数、および有限座標での実効的な計算と実際の修復への復元を順に扱う。
さらに、構造パラメータに伴う十分集合の構成可能な層別化、範囲拡大による必要情報の変化、非線形な族における適応的問い合わせの利得、および凍結範囲の三項保存則を示す。問い合わせごとの費用を与えた場合には、有限候補の分離集合と適応木の再帰、アフィン族の重み付き核条件から最適費用を求める。

## 18.1 実際の操作からの補正方程式

まず、第11章の相対修復の設定において、基準となる実際の操作をパラメータで動かした入力の族から線形な補正方程式を導き、その解の groupoid が実際の修復の全体と一致することを確かめる。

**構成18.1（実際の入力族と線形な補正問題）.**
[第11章](../part_4/chapter_11_ariadne_relative_repairs.md#111-原始的な操作射影の核固定部分)の型付きセル表示 $`K`$、固定部分 $`P=K_{\mathrm{fix}}`$、常時許容辺 $`E_0`$、候補辺 $`\mathsf E`$、および許可範囲 $`S\subseteq\mathsf E`$ を固定する。
各頂点のファイバー自己同型の射影の核（以下、射影の核）$`A_v`$ は体 $`k`$ 上の線形空間であり、各辺の核輸送 $`\rho_e`$ は線形同型であると仮定する。

基準となる実際の操作をパラメータ $`v\in P_{\mathrm{in}}`$ で動かすが、射影の核 $`A_v`$、核輸送 $`\rho_e`$、および固定辺・禁止辺の位置はすべての入力で共通に保つ。
このとき、実際の欠陥が

```math
\delta(v)=\delta_0+C_{\mathrm{in}}v
```

というアフィン依存性を持つ入力族を用いる。
ここで $`P_{\mathrm{in}}`$ は $`k`$ 上の線形空間、$`C_{\mathrm{in}}`$ は線形写像であり、各 $`v\in P_{\mathrm{in}}`$ が設定11.1の同じ原始仕様を満たす実際の入力を与えるものとする（固定部分で $`\delta(v)|_P=0`$ となることも条件に含める）。
一般の圏の塔ではこのアフィン依存性を入力条件として仮定する。
一方、以下に述べる具体的なアフィン網では、原始操作の合成からこのアフィン形とすべての係数を直接導出する。

補正空間と右辺を次のように置く。

```math
P_S=C_S^1,\quad Y=C_{\mathrm{fix}}^2,\quad
D_S=d^1|_{P_S}:P_S\to Y,\quad
b_0=-\delta_0,\quad B_{\mathrm{in}}=-C_{\mathrm{in}}
```

すると、原始修復がすべての Law を満たす条件は線形方程式

**式(18.1)**

```math
D_Sh=b_0+B_{\mathrm{in}}v,\qquad
\pi_S:Y\longrightarrow Y/\mathop{\mathrm{im}}\nolimits D_S
```

で表される。ここで、禁止された候補辺 $`e\in\mathsf E\setminus S`$ の補正は $`h_e=0`$ であり、再同定の全体からなる空間は
$`C_S^0=\{b\in C_{\mathrm{fix}}^0:d^0b\in P_S\}`$ のまま保持する。
なお、禁止辺の両端で $`b`$ を個別に零にするような過剰な条件は課さない。

**具体的なアフィン網での生成.**
有限表示 $`K`$ と線形空間 $`A`$ を取り、各辺の可逆な線形成分 $`M_e`$ を固定した上で、基準となる辺と面の比較を

**式(18.2)**

```math
\widetilde L_e(v)(x)=M_ex+t_e^0+T_ev,\qquad
u_f(v)=\tau_{c_f^0+C_fv}
```

によって指定する。ここで $`T_e,C_f`$ は線形写像である。
経路 $`w`$ に沿う平行移動成分は再帰式 $`t_{we}(v)=M_et_w(v)+t_e(v)`$ で計算されるため、$`v`$ のアフィン式になる。
面の両辺の線形成分を一致させると、実際の合成から各面 $`f`$ の欠陥は

```math
\delta_f(v)=c_f(v)+t_{\ell_f}(v)-t_{r_f}(v)
```

として得られる。微分 $`d^1`$ の各項も同じ経路の $`M_e`$ の積から構成される。

さらにパラメータ $`v`$ に対して、固定部分ですべての Law が成立する条件と、3-セルの指定された実際の比較の等式を課す。
固定部分の値そのものは入力 $`v`$ とともに動いてよいが、各入力 $`v`$ に対する修復はその入力での値をそのまま保持する。
これらの条件がすべてのパラメータで成立するように定数部を選び、線形部の共通の核を $`P_{\mathrm{in}}`$ と置けば、$`P_{\mathrm{in}}`$ のすべての点が実際の入力となる。
さらに、既知情報 $`Lv=s`$ で制限した非空なファイバーについても、そのすべての点がこの同じ式で実現される。
なお、候補を都合のよい有限個の入力だけに制限して核の条件を判定するようなことはしない。

問い合わせには、原始操作を指定された状態で評価し、既知の定数部を差し引いた値を用いる。
たとえば任意の線形汎関数 $`\ell\in A^*`$ に対し、原点 $`0`$ での評価から

```math
\ell\bigl(\widetilde L_e(v)(0)-t_e^0\bigr)=\ell T_ev
```

が得られる。面の比較や名前付きパラメータも同様に読み出し、それらの許された線形結合を $`\lambda_j(v)`$ とする。
これにより、実際の問い合わせの結果と線形評価 $`\lambda_j(v)`$ との一致が、式(18.2)への代入によって証明される。
有限座標が指定されている場合には、線形成分 $`M_ex`$ も基底上の値から生成できる。
任意次元の場合にも同じ代数式がそのまま定まるが、後述する有限行列算法は有限座標を指定した場合にのみ用いる。

構成18.1で得た線形方程式(18.1)は、単に修復の存在を記述するだけでなく、再同定まで含めた実際の修復の groupoid 全体を回復する。

**命題18.2（方程式とすべての実際の修復との比較）.**
構成18.1の下で、各入力 $`v\in P_{\mathrm{in}}`$ について、式(18.1)の解の集合に再同定 $`b\in C_S^0`$ が $`b:h\to h+d^0b`$ として作用して得られる作用 groupoid は、同じ入力 $`v`$ に対するすべての実際の修復からなる groupoid $`\mathscr R_S(K;v)`$ と圏同値である。
さらにこの比較は、許可範囲のすべての包含関係と、宣言の閉部分表示への制限を保つ。

**証明.**
まず、式(18.1)の解 $`h\in P_S`$ を実際の辺 $`L_e^{v,h}=\iota(h_e)\widetilde L_e(v)`$ の族へ送る対応を考える。
実際の経路への代入（補題11.3）により、補正後の欠陥は $`\delta(v)+d^1h`$ となるから、すべての Law が成立することと式(18.1)が成り立つこととは同値である。

逆に、実際の修復の補正成分 $`c_e`$ が与えられたとき、$`\iota(h_e)=c_e\widetilde c_e(v)^{-1}`$ によって $`h_e`$ を取り出す。
この $`h_e`$ は、射影の核への所属と強い opcartesian 因子分解の一意性によって一意に定まる。
また、固定辺および禁止辺における実際の等式はそのまま $`h_e=0`$ に戻る。

次に射（再同定）を比較する。
実際の再同定の条件 $`L'_e=b_tL_eb_s^{-1}`$ は、式(11.1)の核輸送によって $`h'=h+d^0b`$ と同値であり、逆向きも同じ式から従う。
恒等射と合成は射影の核における零元と加法にそれぞれ対応するため、この比較は対象・すべての射（$`\mathrm{Hom}`$ の全体）・合成のすべてを回復する。
最後に、閉部分表示への制限と許可範囲の包含関係は、いずれも同じ成分 $`h,b`$ の制限および包含として働くため、すべての比較式と可換する。□

この構成を[命題11.5a](../part_4/chapter_11_ariadne_relative_repairs.md#第8章の補完と条件付き変更族への接続)へ送ると、空の能動（active）始域、固定された外部群、許容規則 $`H_S`$、および自明な評価条件 $`V=E=\mathbf 1`$ を持つ第8章の条件付き変更族が得られる。
具体的には、辺の同変写像を零点で評価して $`h_e`$ を抽出し、逆に $`x\mapsto\rho_ex+h_e`$ によって戻す操作がその比較を与える。
一般の固定同定を持つ表示であっても、記録 $`t`$ を保持して $`h=h^B-d^0t`$、$`b=\gamma-t'+t`$ と戻すため、すべての再同定が失われることはない。

## 18.2 残存障害と双対観測

本節以降で述べる線形代数の定理では、任意の体 $`k`$ 上の任意次元の線形空間と、任意の線形写像 $`D_S:P_S\to Y`$、$`B_{\mathrm{in}}:P_{\mathrm{in}}\to Y`$、および定数ベクトル $`b_0\in Y`$ を扱う。
構成18.1は、この一般的な枠組みを実際の修復問題へ適用した具体例である。

まず、式(18.1)の可解性、入力方向に対する残存障害の振る舞い、および不能の双対証拠をまとめる。

**定理18.3（可解性・入力方向・不能証拠）.**
右辺を $`r(v)=b_0+B_{\mathrm{in}}v`$、残存障害を $`o_S(v)=\pi_Sr(v)`$、入力方向の障害写像を $`A_S=\pi_SB_{\mathrm{in}}`$ と置く。
このとき、式(18.1)が可解であることは $`o_S(v)=0`$ と同値である。
また、可解な入力 $`v_*`$ を一つ取ると、任意の入力変位 $`n\in P_{\mathrm{in}}`$ に対して

**式(18.3)**

```math
o_S(v_*+n)=A_Sn,\qquad
P_{\mathrm{in}}/\ker A_S\xrightarrow{\sim}\mathop{\mathrm{im}}\nolimits A_S,\quad
[n]\longmapsto A_Sn
```

が成り立つ。さらに、式(18.1)が不能であることは、ある双対元 $`\psi\in Y^*`$ が $`\psi D_S=0`$ かつ $`\psi(r(v))\ne0`$ を満たすことと同値である。

**証明.**
商写像 $`\pi_S:Y\to Y/\mathop{\mathrm{im}}\nolimits D_S`$ の定義から、$`\pi_Sr(v)=0`$ は $`r(v)\in\mathop{\mathrm{im}}\nolimits D_S`$ と同値であり、これが式(18.1)の可解性にほかならない。
可解な基準点 $`v_*`$ では $`o_S(v_*)=0`$ であるから、線形性より $`o_S(v_*+n)=o_S(v_*)+A_Sn=A_Sn`$ が得られる。
商空間 $`P_{\mathrm{in}}/\ker A_S`$ から像 $`\mathop{\mathrm{im}}\nolimits A_S`$ への誘導写像は、核で割っているため単射であり、像の定義から全射である。

不能証拠の同値性を示す。
式(18.1)が不能ならば、商空間 $`Y/\mathop{\mathrm{im}}\nolimits D_S`$ において類 $`[r(v)]`$ は非零元である。
この非零元を含む商空間の基底を選び、$`[r(v)]`$ で値 $`1`$、他のすべての基底元で値 $`0`$ を取る線形汎関数を構成して $`\pi_S`$ と合成すれば、$`\psi D_S=0`$ かつ $`\psi(r(v))=1\ne0`$ を満たす $`\psi\in Y^*`$ が得られる。
逆に、そのような $`\psi\in Y^*`$ が存在するとき、もし式(18.1)に解 $`h`$ があれば $`\psi(r(v))=\psi(D_Sh)=0`$ となって矛盾する。□

この双対証拠の存在定理は有限次元性を必要とせず、基底の選択を含む純粋に代数的な存在証明である。
一方、有限座標と実効的な体演算が与えられていれば、左核（$`\psi D_S=0`$ の解空間）の行を求める掃き出し法によって不能証拠を具体的に計算できる。
ここで第11章との役割の違いを確認しておく。第11章における許可範囲の選択では写像 $`D_S`$ そのものを動かしたのに対し、本章における観測の選択ではその同じ $`D_S`$ を固定した上で、入力方向 $`n`$ をどれだけ区別できるかを問う。

有限次元の場合には、第16章および第17章の双対評価との直接的な対応も見える。
二項複体 $`P_S\xrightarrow{D_S}Y`$ を次数 $`0,1`$ に置くと、その1次コホモロジー $`H^1`$ は余核 $`Y/\mathop{\mathrm{im}}\nolimits D_S`$ である。
定理16.15の双対サイクルは $`\psi D_S=0`$ を満たす $`\psi\in Y^*`$ に一致し、指定類 $`o_S(v)`$ の周期（period）は
$`\langle o_S(v),[\psi]\rangle=\psi b_0+\psi B_{\mathrm{in}}v`$ となる。
したがって、許された問い合わせの中に線形評価 $`\lambda_\psi=\psi B_{\mathrm{in}}`$ が含まれていれば、既知の定数 $`\psi b_0`$ を加えることで第17章の周期観測が得られる。
余核の双対空間を張るような $`\psi`$ をすべて読み出せば、それらの値の全体から $`o_S(v)`$ が完全に決まり、すべての値が零であることと可解性とが同値になる。
二つの入力の差 $`n`$ についてすべての周期が消える条件は $`B_{\mathrm{in}}n\in\mathop{\mathrm{im}}\nolimits D_S`$、すなわち $`A_Sn=0`$ である。
これは次節で示す可否判定用の核条件に一致し、数値補正用の核条件 $`B_{\mathrm{in}}n=0`$ とは明確に区別される。

## 18.3 既知情報を条件とする十分性

あらかじめ線形な既知情報が与えられている状況の下で、追加の線形問い合わせの集合 $`J`$ が、可否判定に十分であるための条件と、具体的な数値補正を返すのに十分であるための条件をそれぞれ核の包含関係として特徴づける。

線形な既知情報 $`L:P_{\mathrm{in}}\to I_{\mathrm{known}}`$ とその観測値 $`s\in I_{\mathrm{known}}`$ を固定し、非空なファイバー $`F_s=L^{-1}(s)`$ と核 $`N=\ker L`$ を取る。
許された問い合わせの添字集合を $`J_0`$、各 $`j\in J_0`$ に対する正確な線形評価を $`\lambda_j:P_{\mathrm{in}}\to k`$ とし、任意の部分集合 $`J\subseteq J_0`$ に対して観測写像を $`O_Jv=(\lambda_j(v))_{j\in J}`$ と書く。

数値補正の出力は、すべての成分を具体的な値として評価した一つの補正ベクトル $`h\in P_S`$、または不能を表す記号 $`\bot`$ とする。
入力 $`v\in F_s`$ に対する出力の有効性を

**式(18.4)**

```math
\mathop{\mathrm{Valid}}\nolimits(v,h)\iff D_Sh=r(v),\qquad
\mathop{\mathrm{Valid}}\nolimits(v,\bot)\iff r(v)\notin\mathop{\mathrm{im}}\nolimits D_S
```

で定める。
ここで、$`O_J`$ が「判定に十分である」とは、可解性の真偽が観測像 $`O_J(F_s)`$ 上の関数へ因子化することをいい、「数値補正に十分である」とは、同じ観測像 $`O_J(F_s)`$ 上に、各入力 $`v\in F_s`$ に対して式(18.4)を満たす出力を返す関数が存在することをいう。
なお、この数値出力の定義では、未知入力に対して後から評価する自由変数を出力の中に残すことは許さない。

**定理18.4（判定と数値補正の二つの核条件）.**
非空なファイバー $`F_s`$ の中に可解な入力 $`v_*`$ が少なくとも一つ存在すると仮定する。
このとき、任意の部分集合 $`J\subseteq J_0`$ について、次の二つの同値が成り立つ。

**式(18.5)**

```math
\begin{aligned}
O_J\text{ が判定に十分}
&\iff N\cap\ker O_J\subseteq\ker(\pi_SB_{\mathrm{in}}),\\
O_J\text{ が数値補正に十分}
&\iff N\cap\ker O_J\subseteq\ker B_{\mathrm{in}}.
\end{aligned}
```

**証明.**
まず、判定の十分性についての必要性を示す。
$`n\in N\cap\ker O_J`$ を取ると、$`v_*+n\in F_s`$ であり、かつ $`O_J(v_*+n)=O_J(v_*)`$ となるため、$`v_*+n`$ は $`v_*`$ と同じ観測値を持つ。
判定の十分性と $`v_*`$ の可解性から $`v_*+n`$ も可解でなければならず、式(18.3)により $`\pi_SB_{\mathrm{in}}n=o_S(v_*+n)=0`$ が従う。
逆に $`N\cap\ker O_J\subseteq\ker(\pi_SB_{\mathrm{in}})`$ を仮定する。
二つの入力 $`v,w\in F_s`$ の観測値が等しければ $`v-w\in N\cap\ker O_J`$ であるから、仮定の包含関係より $`o_S(v)-o_S(w)=\pi_SB_{\mathrm{in}}(v-w)=0`$、すなわち $`o_S(v)=o_S(w)`$ となる。
したがって各観測ファイバー上で可解性の真偽が一定となり、定理17.4によって判定の十分性が従う。

次に、数値補正の十分性についての必要性を示す。
$`O_J`$ が数値補正に十分であれば、同じ観測値を持つ $`v_*`$ と $`v_*+n`$（$`n\in N\cap\ker O_J`$）に対して同じ出力が返される。
$`v_*`$ は可解であるからその共通の出力は一つの補正ベクトル $`h\in P_S`$ であり、式(18.4)より $`D_Sh=r(v_*)=r(v_*+n)`$ となる。
両辺の差を取れば $`B_{\mathrm{in}}n=0`$ が得られる。
逆に $`N\cap\ker O_J\subseteq\ker B_{\mathrm{in}}`$ を仮定すると、同じ観測ファイバーに属するすべての入力 $`v`$ は共通の右辺 $`r(v)`$ を持つ。
その共通の右辺が像 $`\mathop{\mathrm{im}}\nolimits D_S`$ に入らなければ $`\bot`$ を返し、像に入るならば逆像 $`h\in P_S`$ を一つ選んで返せば、同じ $`h`$ がその観測ファイバーのすべての点で式(18.4)を満たす。
（なお、$`\mathop{\mathrm{im}}\nolimits D_S`$ への線形な切断を基底の選択からあらかじめ一度構成しておけば、この逆像の選択をすべての観測ファイバーで一様に行える。）□

定理18.4において、可解な基準点 $`v_*`$ の存在は両方の必要性の証明で本質的に用いている。
実際、もし $`F_s`$ のすべての入力が不能であるならば、判定も数値補正も定数出力「不能」（数値出力では $`\bot`$）で十分であり、追加の問い合わせは $`0`$ 回でよい。
この場合には、式(18.5)の包含関係は必要条件として課さない。
また、空のファイバー $`F_s=\varnothing`$ に対しても $`0`$ 回の手続きを置くことはできるが、それは実現可能な入力についての判断を返す場合ではない。

観測集合 $`J`$ が有限であるとき、定理18.4の核条件は双対空間（有限次元では行空間）の包含条件へ書き換えられる。

**系18.5（有限観測の双対表示）.**
$`J\subseteq J_0`$ が有限集合であるとき、任意の線形写像 $`C:P_{\mathrm{in}}\to W`$ について

**式(18.6)**

```math
N\cap\ker O_J\subseteq\ker C
\iff
\{\phi C|_N:\phi\in W^*\}
 \subseteq\mathop{\mathrm{span}}\nolimits\{\lambda_j|_N:j\in J\}
```

が成り立つ。有限次元座標表示では、これは行空間の包含条件
$`\mathop{\mathrm{row}}\nolimits(C)\subseteq\mathop{\mathrm{row}}\nolimits(L)+\mathop{\mathrm{span}}\nolimits\{\lambda_j:j\in J\}`$ に等しい。
特に、定理18.4の仮定（非空ファイバー $`F_s`$ における可解な基準点 $`v_*`$ の存在）のもとで $`C=\pi_SB_{\mathrm{in}}`$ と $`C=B_{\mathrm{in}}`$ をそれぞれ代入すれば、可否判定と数値補正それぞれの必要十分条件（同値条件）が得られる。

**証明.**
左辺から右辺を示す。
$`N\cap\ker O_J=\ker(O_J|_N)`$ が $`\ker(C|_N)`$ に含まれるとき、任意の $`\phi\in W^*`$ に対して線形汎関数 $`\phi C|_N`$ は $`\ker(O_J|_N)`$ 上で消えるから、像 $`\mathop{\mathrm{im}}\nolimits(O_J|_N)\subseteq k^J`$ 上の線形汎関数へ因子化する。
この汎関数を有限次元空間 $`k^J`$ 全体へ延長すると座標汎関数の有限線形結合として表されるため、$`\phi C|_N\in\mathop{\mathrm{span}}\nolimits\{\lambda_j|_N:j\in J\}`$ を得る。

逆に右辺を仮定する。
$`\lambda_j|_N`$ の任意の線形結合は共通の核 $`N\cap\ker O_J`$ 上で消えるから、任意の $`n\in N\cap\ker O_J`$ と任意の $`\phi\in W^*`$ に対して $`\phi(C(n))=0`$ となる。
非零ベクトル $`C(n)\ne0`$ はある双対元 $`\phi\in W^*`$ によって検出できるため、すべての $`\phi\in W^*`$ で消えることは $`C(n)=0`$ と同値であり、$`N\cap\ker O_J\subseteq\ker C`$ が従う。
有限次元空間では直交補空間について $`(\ker L)^\perp=\mathop{\mathrm{row}}\nolimits(L)`$ であるから、行空間の包含表示が得られる。□

なお、無限集合 $`J`$ に対する核の包含条件自体は定理18.4の形のまま成立するが、式(18.6)のように有限線形結合の張る空間を用いる双対表示の証明は有限な観測集合に対して適用する。

## 18.4 判定・数値補正・修正式

定理18.4の核条件は静的な観測集合 $`J`$ に対するものであったが、実際には前の返答に応じて次の問い合わせを変える適応的な手続きも考えられる。
本節では、適応的な決定的手続きまで含めた最悪時の最適追加問い合わせ数を求め、具体例で判定・数値補正・操作参照式の違いを比較する。

**定理18.6（出力別の最適追加問い合わせ数）.**
18.3節の線形データと非空なファイバー $`F_s`$ を取り、そのすべての点を未知入力とする。
許された問い合わせは、各 $`j\in J_0`$ における正確な値 $`\lambda_j(v)`$ の取得である。
それまでの返答の有限列から次の問い合わせまたは最終出力を返す決定的手続きのうち、すべての入力 $`v\in F_s`$ で有限回で停止して正答するものを考える（内部の計算量は数えない）。

このとき、$`F_s`$ に可解な入力が存在する場合、可否判定と数値補正のそれぞれについて、最適な最悪時追加問い合わせ数は

**式(18.7)**

```math
m_C=\min\{|J|:J\subseteq J_0\text{ は有限},\
              N\cap\ker O_J\subseteq\ker C\},
\quad C=\pi_SB_{\mathrm{in}},\ B_{\mathrm{in}}
```

で与えられる。候補となる有限集合が空であれば $`m_C=\infty`$ と定め、その場合、対応する出力についてすべての入力で停止して正答する決定的手続きは存在しない。
一方、$`F_s`$ のすべての入力が不能である場合には式(18.7)を適用せず、両方の出力の最適問い合わせ数はともに $`0`$ となる。

**証明.**
まず、$`F_s`$ に可解な入力が存在する場合を考える。その一つを $`v_*`$ と置く。
下限を示すため、すべての入力で停止して正答する任意の決定的手続きを取り、入力 $`v_*`$ 上での有限な実行で問い合わせた添字の集合を $`J`$ と置く。
任意の $`n\in N\cap\ker O_J`$ に対して、入力 $`v_*+n\in F_s`$ は $`J`$ に属するすべての問い合わせで $`v_*`$ と同じ値を返す。
したがって、手続きの決定性に関する帰納法により、$`v_*+n`$ の実行は $`v_*`$ とまったく同じ問い合わせ列と同じ最終出力を再現する。
判定出力では両入力が可解であることから $`\pi_SB_{\mathrm{in}}n=0`$ が、数値出力では同じ補正ベクトル $`h`$ が両方の右辺を満たすことから $`B_{\mathrm{in}}n=0`$ がそれぞれ従う。
ゆえに $`J`$ は対応する $`C`$ に対する有限な十分集合であり、その濃度 $`|J|`$ は $`v_*`$ 上の実行長以下であるから、任意の手続きの最悪問い合わせ数は $`m_C`$ 以上である。
有限な十分集合が存在しない場合には、$`v_*`$ 上での有限停止自体が矛盾を導く。

次に上限を示す。
有限な十分集合が存在すれば、最小濃度を与える有限集合 $`J`$ を一つ選び、そのすべての元を固定した順序で問い合わせる手続きを作る。
定理18.4によって各観測ファイバーに共通の有効出力が存在するため、その出力を返せばすべての入力で正しく、最悪問い合わせ数は高々 $`|J|=m_C`$ である。
下限と合わせて最適値は $`m_C`$ に等しい。

最後に、$`F_s`$ のすべての入力が不能である場合には、問い合わせを一切行わずに定数出力「不能」（または $`\bot`$）を返す手続きがすべての入力で正しいため、最適問い合わせ数は $`0`$ である。□

一般の体上で定理18.6が与えるのは、返答の履歴から出力を選ぶ集合論的な手続きについての最適値である。
体の元の有限符号化、等号判定、および線形方程式の求解が実効的である場合に、実際に計算可能な手続きを構成する方法は次節で扱う。

**例18.7（同じ有限アフィン網で二つの情報量を計算する）.**
例11.14で導入した有限体 $`\mathbb F_3`$ 上の網を用い、未知の入力を $`v=(x,y)`$ とする。
固定ループは $`r_x(t)=t+x,\ r_y(t)=t+y`$、常時許容辺は $`e,a`$、候補辺は $`b,c`$ である。
補正方程式を再掲すると、

**式(18.8)**

```math
D(u,h,z,w)=(u+z,\ u-z+w),\qquad r(v)=(x,y)
```

である。問い合わせ $`x=r_x(0)`$、$`y=r_y(0)`$ は原始操作の正確な評価値である。
もし許された問い合わせの集合に差 $`d=y-x`$ を加えるならば、その線形結合も独立した一つの問い合わせとして明示的に宣言する（これは問い合わせごとの単位費用を指定した別の設定であり、二つの評価を暗黙に1回へ数え直すものではない）。

まず、候補辺をどちらも禁止した場合（$`S=\varnothing`$）を考える。
このとき $`D_\varnothing(u,h)=(u,u)`$ であり、商写像は $`\pi_\varnothing(r_1,r_2)=r_2-r_1`$、入力写像は $`B_{\mathrm{in}}=1_{k^2}`$ である。
既知情報がないとき、問い合わせ集合 $`\{x,y,d\}`$ に対する可否判定の最適値は $`1`$、数値補正の最適値は $`2`$ となる。
前者は $`d=0`$ か否かだけで判定できることによるが、後者では可解な直線 $`x=y`$ の上であっても補正値 $`u=x`$ が入力に応じて動くためである。
式(18.5)でも、$`\ker d`$ は $`\ker(\pi_\varnothing B_{\mathrm{in}})`$ に含まれるが $`\ker B_{\mathrm{in}}=0`$ には含まれない。
実際、任意の一つの問い合わせは非零の核を持ち、二つの独立な問い合わせを取って初めてすべての入力が決まる。

次に、許可範囲を $`S=\{c\}`$ へ広げると、$`D_S(u,h,w)=(u,u+w)`$ は全射となり、すべての入力で修復可能になる。
このとき判定の最適値は $`0`$ に下がるが、数値補正の最適値は依然として $`2`$ であり、たとえば $`(u,h,z,w)=(x,0,0,y-x)`$ を返せる。
ここに既知情報 $`x=s`$ を加えると、核は $`N=\{(0,y)\}`$ へ狭まり、数値補正の最適値は $`1`$ に下がる。
これは、未知入力に対する問い合わせ集合を変えず、既知情報の核だけを狭めた計算である。

また局所的な面ごとに見ても同様の区別が生じる。
第一面だけの局所方程式 $`u+z=x`$ はすべての入力で可解だが、具体的な数値対 $`(u,z)`$ を返すには $`x`$ の値が必要である。
第二面だけでも同様に、可否の真偽と局所修復の数値とは異なる出力である。
大域的には、共有する変数 $`u,z`$ と自由変数 $`h`$ を残したまま式(18.8)の両辺を同時に満たさなければならない。

**例18.8（台帳の数値補正と操作参照式）.**
第8章・第17章と同じ分割台帳において、読み出し $`p(B,C)=B+C`$ を保つ `compact` 操作の修復を求める。
基底・外部入力・読み出し $`p`$ を固定し、観測対象の候補操作を $`c_v(B,C)=(B+v,C)`$ とする。
許容される補正は第二座標へ定数 $`h`$ を加えることであるとすると、

```math
c_v^h(B,C)=(B+v,C+h),\qquad p c_v^h-p=v+h
```

となる。したがって $`D(h)=h`$、$`b_0=0`$、$`B_{\mathrm{in}}(v)=-v`$ であり、可否の障害は常に零である。
すべての入力が可解であるから、可否判定には問い合わせを一切必要としない。
一方、評価済みの数値補正は $`h=-v`$ であり、問い合わせとして $`c_v(0,0)`$ の第一座標を読み出す1回の評価が必要十分である。

これに対し、「$`c_v(0,0)`$ の第一座標の符号を反転した値を加える」という操作参照式であれば、問い合わせを行う前にも記述できる。
しかし、これは未知の操作を後から評価する式を返すという別種の出力であり、式(18.4)で定めた評価済みの数値補正とは異なる。
もちろん、原始操作の評価を完了した後では、両者は同じ実際の修復を与える。

## 18.5 最適観測から実際の修復への復元

ここまでの線形代数的な特徴づけを、有限座標と実効的な体演算の下での具体的な算法へ落とし込み、得られた数値補正を第11章の実際の修復へ復元する手順を完成させる。

**命題18.9（有限座標での求解と実際の修復への復元）.**
線形空間 $`P_{\mathrm{in}},P_S,Y,I_{\mathrm{known}}`$ はいずれも有限次元であり、許された問い合わせの添字集合 $`J_0`$ は有限集合であるとする。
さらに、体 $`k`$ の元には有限の表現があり、四則演算と零判定が有限時間で停止して正しい値を返すと仮定する。

このとき、行列 $`D_S,B_{\mathrm{in}},L`$、ベクトル $`b_0,s`$、および各問い合わせの行ベクトルを入力として与えれば、次のすべてを有限計算で実行できる。

1. 既知情報ファイバー $`F_s`$ の非空性、可解な基準点の有無、および各出力（可否判定・数値補正）に対する十分な問い合わせ集合の存在可否の判定。
2. 十分集合が存在する出力に対する、最小の十分集合と正しい手続きの生成。
3. 十分集合が存在しない出力に対する、正答手続きの不存在の証拠データの生成。

さらに、構成18.1における実際の操作の評価と射影の核の作用も実効的であれば、得られた数値補正から対応する実際の修復をそのまま復元できる。

**構成と証明.**
手順は四つの段階からなる。

第一に、既知情報ファイバーの非空性と可解な基準点の有無を調べる。
掃き出し法で線形方程式 $`Lv=s`$ の可解性を検査し、解がなければ「実現可能な入力なし」と判定して、両方の出力に0回の問い合わせ手続きを返す（その正答条件は空な入力集合上で成立する）。
$`Lv=s`$ が可解であれば、次に連立系
$`Lv=s,\ D_Sh-B_{\mathrm{in}}v=b_0`$
を同時に解く。この連立系が不能であれば、非空なファイバー $`F_s`$ はすべての点で不能であるから、両方の出力に0回の定数出力手続きを返す。
可解であれば、特解の $`v`$ 成分を可解な基準点 $`v_*`$ とし、あわせて掃き出し法で核 $`N=\ker L`$ の基底を求める。

第二に、最小の十分集合または不存在の証拠データを生成する。
掃き出し法で $`D_S`$ の像と余核の行列を構成した上で、すべての部分集合 $`J\subseteq J_0`$ を濃度の小さい順に列挙し、各 $`J`$ について式(18.5)または式(18.6)の包含条件を有限行列の掃き出し法で検査する。
最初に条件を満たした集合が最小の十分集合である。
すべての候補が失敗した場合には、有限な十分集合は存在しない。
このとき特に全体集合 $`J_0`$ に対する核包含も失敗するため、掃き出し法によって
$`n\in N\cap\ker O_{J_0}`$ かつ $`C(n)\ne0`$
を満たすベクトル $`n`$ を具体的に選べる（ここで $`C`$ は対象出力に応じて $`\pi_SB_{\mathrm{in}}`$ または $`B_{\mathrm{in}}`$ とする）。
すると、入力 $`v_*`$ と $`v_*+n`$ は許されたすべての問い合わせで同じ返答を返すが、判定出力では可否が異なり、数値出力では共通の数値補正を持たない。
したがってこの $`(v_*,n)`$ が正答手続きの不存在の証拠データとなる。（たとえば $`D_S=B_{\mathrm{in}}=1_k`$、$`b_0=0`$、既知情報なし、問い合わせなしの場合には、可否は常に真でも入力ごとに異なる補正 $`h=v`$ を共通には返せない。）

第三に、選んだ最小十分集合 $`J`$ を用いた手続きを実行する。
実際の問い合わせから得た返答ベクトルを $`y`$ とし、連立系 $`Lv=s,\ O_Jv=y`$ を解いて一つの代表入力 $`v_y`$ を求める（実際の入力からの返答であればこの系は必ず可解である）。
判定出力では $`\pi_Sr(v_y)=0`$ であるかを検査して真偽を返す。
数値出力では方程式 $`D_Sh=r(v_y)`$ を解き、可解なら特解 $`h`$ を、不能なら $`\bot`$ を返す。
核条件(18.5)により、代表 $`v_y`$ の取り方を変えても判定の真偽は変わらず、数値出力では右辺 $`r(v_y)`$ そのものが一致するため、返した補正 $`h`$ は未知の実際の入力に対しても有効である。

第四に、停止性と実際の修復への復元を確認する。
掃き出し法は有限個の行と列についてピボット（pivot）を一つずつ確定するため必ず停止し、可逆な行基本変形と自由変数の代入がすべての解との双方向対応を与える。
また、不整合行 $`0=c\ne0`$ が現れた場合には、元の行の線形結合を記録しておくことで不能の双対証拠 $`\psi`$ へ戻せる。
最後に、得られた数値補正 $`h`$ を原始辺へ
$`L_e^{v,h}=\iota(h_e)\widetilde L_e(v)`$
として適用すれば、命題18.2により同じ Law・固定部分・禁止辺を満たす実際の修復が得られる。
なお、復元された実際の辺を全座標の表として出力する場合には、基準となる実際の辺の座標も入力または追加の評価から得る必要がある。
補正値を原始操作へ作用させる段階と、その結果である実際の辺の全表を書き出す段階とは区別して扱う。□

基礎体 $`k`$ が有限体である場合には、体の演算表と有限座標からすべての入力とすべての補正を直接列挙する方法も取れる。
まず、ファイバー $`F_s`$ の各入力 $`v`$ について、$`P_S\cup\{\bot\}`$ をすべて列挙して式(18.4)を満たす有効な出力の集合を求める。
次に、有限個の部分集合 $`J\subseteq J_0`$ を濃度の小さい順に試し、すべての入力を返答の組によって観測ファイバーへ分類する。
判定出力では各ファイバーの可解性が一定であるかを、数値出力では各ファイバーに属するすべての入力の有効出力集合の共通部分が非空であるかを検査する。
検査を通過した最初の集合 $`J`$ に対して、各返答ごとにその判定値または共通出力の一つを返す手続きを作れば、定義からこの手続きは正しく、逆に正しい出力関数が存在すれば各共通部分が非空となるため検査を必ず通過する。
可解な入力が存在する場合には、定理18.4および定理18.6により、この列挙法で求めた最小値も適応的な手続きを含めた最適値に一致する（空入力および全不能入力はあらかじめ0回の問い合わせで処理しておく）。
体・座標数・問い合わせ集合がいずれも有限であるため、入力・出力・部分集合に関するすべての反復は必ず停止する。

以上の線形修復での結果を手がかりに、一般の解の族における必要情報の問題を次のように定式化しておく。

**問題18.10（一般の解の族における必要情報）.**
第17章の構成17.5で定めた解の族 $`p:\mathcal F\to\mathcal U`$ に対し、既知情報 $`\eta`$ と許された問い合わせを指定する。
同じ観測ファイバーに属するすべての候補・評価・出力関係を保つ比較を構成し、次の各出力について十分性と最適問い合わせ数を特徴づけよ。
対象とする出力は、非線形な族における具体的な解、解の同型類、すべての解からなる groupoid、指定位相での局所切断、および大域的な正則切断である。
線形な数値出力において式(18.5)を導いたのと同様に、原始的な許容規則からファイバー共通出力の条件を導くことを求める。
以下の18.6–18.8節では、正則な線形行列族における点ごとの判定・数値補正と、有限の非線形な判定族を扱う。
この問題のうち、一般の非線形な解・同型類・groupoid の出力と、局所および大域の正則切断の十分性は引き続き別に特徴づける必要がある。

## 18.6 構造パラメータと必要情報の層別化

未知の入力と、既知の構造パラメータを分けて考える。
構造を固定した各点では定理18.4–18.6を使えるが、その十分集合や最適値は構造に応じて変わる。
その変化は、有限個の小行列式の零・非零条件で記述できる。

**設定18.11（原始操作から生成される正則な行列族）.**
体 $`k`$ 上の有限型アフィンスキーム $`T=\mathop{\mathrm{Spec}}\nolimits A`$ と、固定した有限セル表示・固定部分・常時許容辺・候補辺集合 $`\mathsf E`$ を取る。
各射影の核には有限自由 $`A`$-加群の座標を指定し、式(18.2)の線形成分 $`M_e`$ とその逆、平行移動の定数部および入力係数を $`A`$ の行列で与える。
面の線形成分の一致と3-セルの比較等式は、この原始族の等式として課す。
未知入力 $`v`$ は固定した $`A^n`$ の座標を持つ。既知情報と入力条件は有限個の線形評価で与え、固定部分の Law も合わせた有限の連立式を $`Lv=s`$ と書く。したがって $`L`$ はある有限な $`m`$ に対する $`m\times n`$ 行列である。
名前付きの有限問い合わせ集合 $`J_0`$ を固定し、各問い合わせは原始操作の評価から定数部を除いた線形な値とする。

各 $`t\in |T|`$ では構造パラメータ $`t`$ を既知とし、剰余体 $`K_t=\kappa(t)`$ 上で

**式(18.9)**

```math
D_{S,t}h=b_{0,t}+B_tv,\qquad L_tv=s_t,\qquad
O_{J,t}v=(\lambda_{j,t}(v))_{j\in J},
\quad S\subseteq\mathsf E,\ J\subseteq J_0
```

を考える。$`D_S`$ は同じ $`d^1`$ の許可座標に属する列を取った行列であり、$`B`$ はこの節での $`B_{\mathrm{in}}`$ である。
すべての行列と右辺は原始データから生成される。
実際、経路に沿う $`M_e`$ の積と平行移動の再帰式により $`\delta_0,C_{\mathrm{in}},d^1`$ が得られ、$`b_0=-\delta_0`$、$`B=-C_{\mathrm{in}}`$ となる。
固定部分および3-セルに課した入力等式の定数部と線形部が $`L,s`$ の対応する行を与え、指定状態での評価が $`O_J`$ の行を与える。
これらは有限回の加法・乗法であるから、$`A`$ 上で正則であり、任意の係数変更とも可換する。
入力条件の連立後は、$`L_tv=s_t`$ のすべての解が構成18.1の実際の入力である。

**定理18.12（十分集合と最適問い合わせ数の構成可能分割）.**
設定18.11の下で、$`|T|`$ は有限個の構成可能集合に分割でき、その各部分上では、すべての $`S,J`$ について次のデータが一定である。

1. 既知情報ファイバー $`F_t=\{v:L_tv=s_t\}`$ が空か、非空ですべての入力が不能か、可解な入力を含むか。
2. $`J`$ が判定に十分か、および数値補正に十分か。
3. 両出力の最適な最悪時問い合わせ数 $`m_{\mathrm{dec}}(S,t),m_{\mathrm{num}}(S,t)\in\{0,\ldots,|J_0|\}\cup\{\infty\}`$。

空入力のときは十分性を空集合上の条件として真、最適値を $`0`$ とするが、第一のデータによって全不能の場合と区別する。
$`\infty`$ は可解な入力が存在し、全問い合わせを使っても十分でない場合を表す。

**証明.**
以下の行列をすべて $`A`$ 上で作る。各ブロックは表示された上下または左右の順に並置する。

**式(18.10)**

```math
Q_J=\binom{L}{O_J},\qquad
M_S=\begin{pmatrix}L&0\\-B&D_S\end{pmatrix},\qquad
c=\binom{s}{b_0},\qquad
K_{S,J}=\begin{pmatrix}D_S&B\\0&Q_J\end{pmatrix}.
```

まず $`F_t\ne\varnothing`$ は $`\mathop{\mathrm{rank}}\nolimits L_t=\mathop{\mathrm{rank}}\nolimits [L_t\ s_t]`$ と同値である。
可解な入力とその補正が同時に存在する条件は
$`\mathop{\mathrm{rank}}\nolimits M_{S,t}=\mathop{\mathrm{rank}}\nolimits [M_{S,t}\ c_t]`$
である。前者だけが成り立ち後者が成り立たなければ、非空な入力ファイバー全体が不能である。

可解な入力が存在するとき、定理18.4の核条件は次の階数等式に一致する。

**式(18.11)**

```math
\begin{aligned}
J\text{ が判定に十分}
&\iff \mathop{\mathrm{rank}}\nolimits K_{S,J,t}
       =\mathop{\mathrm{rank}}\nolimits D_{S,t}+\mathop{\mathrm{rank}}\nolimits Q_{J,t},\\
J\text{ が数値補正に十分}
&\iff \mathop{\mathrm{rank}}\nolimits \binom{Q_{J,t}}{B_t}
       =\mathop{\mathrm{rank}}\nolimits Q_{J,t}.
\end{aligned}
```

第二式は行空間の包含そのものである。
第一式では、$`K_{S,J,t}`$ の像から第二成分の $`\mathop{\mathrm{im}}\nolimits Q_{J,t}`$ へ射影すると全射となり、その核は
$`\mathop{\mathrm{im}}\nolimits D_{S,t}+B_t\ker Q_{J,t}`$
である。よってその階数は
$`\mathop{\mathrm{rank}}\nolimits Q_{J,t}+\dim(\mathop{\mathrm{im}}\nolimits D_{S,t}+B_t\ker Q_{J,t})`$
であり、等式は $`B_t\ker Q_{J,t}\subseteq\mathop{\mathrm{im}}\nolimits D_{S,t}`$ と同値になる。
これは $`\ker Q_{J,t}=\ker L_t\cap\ker O_{J,t}`$ を用いた判定の核条件である。

有限行列 $`H`$ の階数が $`r`$ となる点集合は、すべての $`(r+1)`$ 次小行列式が零、少なくとも一つの $`r`$ 次小行列式が非零という条件で定まる。
$`r=0`$ のときは零次小行列式を $`1`$ とする。
これは有限個の局所閉集合の和であり、構成可能である。
上に現れる行列をすべての $`S,J`$ について集めても有限個なので、全行列の階数を固定した共通細分は有限構成可能分割を与える。
その上で入力の状態と式(18.11)の真偽は一定となる。
可解な入力がある部分では、十分な $`J`$ の最小濃度が定理18.6により適応的な手続きを含めた最適値に等しい。
全不能の部分では定数出力 $`\bot`$ で十分であり、空入力の場合も上の規約を用いる。
これですべての主張を得る。□

この分割は、剰余体上の問題を一様に分類する。
さらに小行列式を選べば、各部分の求解を正則な式で表せる。

**命題18.13（小行列式のチャート上の求解と修復）.**
定理18.12の分割を、各行列について選んだ非零小行列式を記録する有限な局所閉チャートで覆う。
階数 $`r`$ のチャートに、すべての $`(r+1)`$ 次小行列式を零とする方程式と、選んだ $`r`$ 次小行列式を可逆とする条件を課した部分スキーム構造を入れる。
これらの共通部分上では、可解な基準入力、観測値に整合する代表入力、および可解な右辺に対する数値補正を、指定小行列式の逆数を用いた正則な式で構成できる。
可解な入力を含む部分で数値補正に十分な $`J`$ を選んだ場合、この補正を原始操作へ作用させると、同じ返答を持つ各入力の実際の修復を得る。

**証明.**
可換環上の行列 $`H`$ に可逆な $`r\times r`$ 部分行列 $`P`$ があるとする。
行・列の順を変えて $`H=\left(\begin{smallmatrix}P&Q\\R&S\end{smallmatrix}\right)`$ と書き、可逆な行・列変形をすると、

**式(18.12)**

```math
H\sim
\begin{pmatrix}I_r&0\\0&S-RP^{-1}Q\end{pmatrix}.
```

右下の各成分に $`\det P`$ を掛けた値は、対応する $`(r+1)`$ 次小行列式である。
したがってチャートの方程式の下で右下は厳密に零となる。
この変形は $`(\det P)^{-1}`$ を用いた正則な式で、核と像の基底、および像への切断を与える。
右辺 $`c`$ を含む拡大行列についても $`(r+1)`$ 次小行列式が零なら、変形後の右辺の下段が零となるため、自由変数を零とした特解が正則に得られる。
$`r=0`$ の場合は $`H=0,c=0`$ であり、零を特解とする。

これを $`L`$ と $`M_S`$ に適用すれば、非空入力と可解な基準入力を構成できる。
問い合わせの返答を $`y`$ とすると、代表入力は
$`Q_Jv=(s,y)`$
の特解である。この方程式が整合する返答の部分スキームは、行変形後の右辺の下段を零とする線形方程式で定まり、その上で特解 $`v_y`$ は $`y`$ にも正則に依存する。
次に $`D_Sh=b_0+Bv_y`$ を同じ方法で解く。
可解性は行変形後の下段が零となる条件であり、その零集合上で特解 $`h_y`$ は正則である。
各剰余体でその条件が失敗すれば不能を返す。

可解な入力を含む部分で数値補正に十分な場合には、式(18.11)の二つ目の階数条件を同じ行変形で展開すると、チャート上で $`B=U_JQ_J`$ となる行列 $`U_J`$ が得られる。
実際、$`Q_J`$ を $`(I_r\ 0)`$ の形にしたとき、縦に加えた $`B`$ の後半の列は上位小行列式の消滅によって零になる。
したがって $`Q_Jv=Q_Jv_y`$ なら $`Bv=Bv_y`$ であり、$`h_y`$ はその観測ファイバーの全入力に共通の補正となる。
最後に
$`L_e^{v,h_y}=\iota((h_y)_e)\widetilde L_e(v)`$
と置く。補題11.3によって欠陥は零、固定辺と禁止辺では補正座標が零である。
命題18.2の逆構成と再同定 $`b:h\to h+d^0b`$ も同じ原始式を用いるため、得た解と実際の修復の対応を保持する。□

この正則求解は、明示した決定式方程式を満たすチャート上の構成である。
剰余体上での可解性だけを非還元基底上の切断と読み替えると、たとえば
$`A=k[\varepsilon]/(\varepsilon^2)`$ 上の $`0h=\varepsilon`$ で失敗する。
唯一の点の剰余体では右辺は零だが、$`A`$ 上には解がない。
この場合、拡大行列の一次小行列式を零とするチャートの方程式は $`\varepsilon=0`$ であり、命題18.13が用いた条件を正確に示している。

**例18.14（構造の特殊化と無限値）.**
$`T=\mathop{\mathrm{Spec}}\nolimits k[t,(1-t)^{-1}]`$ とし、方程式を $`th=v`$、問い合わせ候補を一つ $`\lambda_t(v)=tv`$ とする。既知情報はない。
これは一頂点のアフィン網で実現できる。固定ループを $`a(x)=(1-t)x`$、修復対象のループの基準を $`\widetilde e(x)=x`$ とし、面の両経路を $`ea,ae`$、指定比較を $`u_v(x)=x+v`$ とする。
補正 $`e^h(x)=x+h`$ を代入すると
$`u_v a e^h-e^h a=v-th`$
となるので、面の Law は $`th=v`$ に一致する。
核の輸送は固定ループ上で可逆な乗法 $`1-t`$、修復対象上で恒等である。
問い合わせは面の比較の評価 $`u_v(0)=v`$ の既知係数 $`t`$ 倍を、一つの許された評価として指定する。
$`t\ne0`$ では全入力が可解なので $`m_{\mathrm{dec}}=0`$、問い合わせから $`v=t^{-1}\lambda_t(v)`$ を回復できるので $`m_{\mathrm{num}}=1`$ である。
$`t=0`$ では入力 $`v=0`$ は可解、$`v=1`$ は不能だが、問い合わせは両者で零となる。
したがってこの点では両最適値が $`\infty`$ となる。
ここで $`t`$ 自体は既知であり、$`t`$ を問い合わせる費用は数えていない。

## 18.7 範囲拡大と二つの必要情報

**定理18.15（範囲拡大と自由な線形問い合わせ）.**
体上の有限次元の設定で、既知情報・右辺・問い合わせ候補を固定する。
許可範囲 $`S\subseteq S'`$ に対して、$`F_s`$ 内に $`S`$ で可解な入力が存在すれば、判定に十分な集合の族は包含関係
$`\mathcal J_{\mathrm{dec}}(S)\subseteq\mathcal J_{\mathrm{dec}}(S')`$
を満たし、$`m_{\mathrm{dec}}(S')\le m_{\mathrm{dec}}(S)`$ となる。
数値補正に十分な集合の族は両範囲で等しく、最適値も等しい。

さらに、問い合わせ候補を全線形汎関数 $`P_{\mathrm{in}}^*`$、各評価の費用を1とすると、可解な基準入力のある範囲について

**式(18.13)**

```math
\begin{aligned}
m_{\mathrm{dec}}(S)
 &=\mathop{\mathrm{rank}}\nolimits (\pi_SB|_{\ker L})
  =\mathop{\mathrm{rank}}\nolimits \begin{pmatrix}D_S&B\\0&L\end{pmatrix}
     -\mathop{\mathrm{rank}}\nolimits D_S-\mathop{\mathrm{rank}}\nolimits L,\\
m_{\mathrm{num}}(S)
 &=\mathop{\mathrm{rank}}\nolimits (B|_{\ker L})
  =\mathop{\mathrm{rank}}\nolimits \binom{L}{B}-\mathop{\mathrm{rank}}\nolimits L.
\end{aligned}
```

**証明.**
列を加える範囲拡大では $`\mathop{\mathrm{im}}\nolimits D_S\subseteq\mathop{\mathrm{im}}\nolimits D_{S'}`$ である。
よって $`\ker(\pi_SB)\subseteq\ker(\pi_{S'}B)`$ となり、定理18.4の判定用核条件は $`S`$ から $`S'`$ へ保存される。
数値補正用の条件は両範囲で同じ $`\ker B`$ を使うため、十分集合の族が等しい。
定理18.6を適用すれば、$`\infty`$ を含めた最適値の関係を得る。

任意の線形写像 $`C`$ に対し、$`N=\ker L`$ 上で $`C`$ の行が張る双対部分空間の次元を $`r`$ とする。
核条件を満たす $`q`$ 個のスカラー問い合わせの行は、この $`r`$ 次元空間を張らねばならないので $`q\ge r`$ である。
逆に、この空間の基底である $`r`$ 個の線形汎関数を選び、$`N`$ から $`P_{\mathrm{in}}`$ へ延長して問い合わせに用いれば十分である。
したがって最適値は $`r=\mathop{\mathrm{rank}}\nolimits (C|_N)`$ となる。
$`C=\pi_SB,B`$ を代入し、定理18.12の像への射影と同じ次元計算を用いると式(18.13)を得る。□

固定された問い合わせ候補では、式(18.13)の階数は下界になっても、候補の最小濃度と一致するとは限らない。
たとえば $`k=\mathbb F_2`$、入力 $`v\in k^3`$、候補を3座標の評価だけとし、右辺を $`v_1+v_2+v_3`$ とする。
補正を許さないとき、可否 $`v_1+v_2+v_3=0`$ は3回を要する。零入力で未読の座標を一つ変えれば同じ返答で可否が変わるからである。
1次元の補正 $`h`$ を許して $`h=v_1+v_2+v_3`$ とすると、判定は0回になる。
数値補正はどちらの範囲でも3回を要する。
これに対し、全線形汎関数を許す設定では和を一度読み出せる。
したがって範囲拡大による判定費用の減少を、固定候補の設定で追加補正空間の次元だけから上に抑えることはできない。

可解な基準入力の仮定も必要である。
たとえば既知情報のない一変数入力で $`B=1`$、$`b_0=0`$ の場合、補正空間が零でも入力0は可解であり、上の定理が使える。
一方、右辺を $`(1,v)\in k^2`$ とし、補正空間が零の範囲から全空間を許す範囲へ移る場合、最初は全入力不能で数値出力は0回、拡大後は補正 $`(1,v)`$ のために1回の問い合わせを要する。

## 18.8 非線形な判定族と適応的問い合わせ

線形な入力ファイバーでは、一つの可解入力の実行列が全体の下界を与えた。
未知入力によって読むべき座標自体が変わる族では、適応的な問い合わせが少なくなる。

**命題18.16（選択されたビットの判定）.**
整数 $`m\ge2`$ に対し、未知入力を
$`s\in\{1,\ldots,m\}`$、$`b_1,\ldots,b_m\in\mathbb F_2`$ とする。
許された問い合わせは $`s,b_1,\ldots,b_m`$ の各値を1回で読む操作であり、判定対象を $`b_s=0`$ とする。
この判定は有限の原始操作と一つの Law から構成でき、最適な最悪時問い合わせ数は適応的には2、非適応的には $`m+1`$ である。

**原始構成と証明.**
sort として一点集合 $`\mathbf1`$、名前付き定数 $`c_i:\mathbf1\to I=\{1,\ldots,m\}`$ を持つ集合 $`I`$、零元を持つ $`B=\mathbb F_2`$ を固定する。
未知の原始単項操作を
$`\sigma:\mathbf1\to I`$、$`\beta:I\to B`$
とし、$`\sigma(*)=s`$、$`\beta(c_i(*))=b_i`$ と置く。
要求する Law は $`\beta\sigma=0:\mathbf1\to B`$ である。
許容修復を恒等だけにした解の族では、この Law が成り立つ入力に一つの修復があり、他の入力には修復がない。
問い合わせはそれぞれ $`\sigma(*)`$ と $`\beta(c_i(*))`$ の原始評価であり、全入力 $`I\times B^m`$ が実現される。

適応的な上界は、最初に $`s`$ を読み、その返答が $`i`$ なら次に $`b_i`$ を読む手続きで得られる。
0回では、同じ $`s=1`$ で $`b_1`$ だけ異なる二入力の可否を区別できない。1回だけでも足りない。唯一の問い合わせが $`s`$ なら、同じ $`s`$ を持ち $`b_s`$ だけ異なる二入力を区別できない。
唯一の問い合わせが $`b_i`$ なら、$`j\ne i`$ を選んで $`s=j`$ とし、$`b_j`$ だけを変えた二入力を区別できない。
よって適応的最適値は2である。

非適応的な十分集合は、すべての $`b_i`$ を含まねばならない。
$`b_i`$ が欠けると $`s=i`$ を固定して $`b_i`$ だけ変える二入力が同じ返答を持つからである。
さらに $`s`$ も必要である。$`b_1=0,b_2=1`$ という同じビット表で、$`s=1`$ と $`s=2`$ を区別する必要がある。
全部の $`m+1`$ 個を読めば十分なので、非適応的最適値は $`m+1`$ となる。□

この例の入力集合と出力条件は設定18.11のアフィン線形ファイバーとは異なる。
原始操作の合成で指定された Law を保持したまま、問い合わせ履歴が次の入力位置を選ぶことが、二つの最適値の差を生んでいる。

## 18.9 凍結範囲と必要情報の三項保存則

第11章の同じ範囲付き複体を使い、凍結した辺の座標を、再同定のパラメータ、修復の同型類、可否判定の必要情報の三つに分ける。

**定理18.17（三項保存則）.**
体上の有限次元の場合を考え、$`V=C_{\mathsf E}^1`$、$`U=C_S^1`$、$`G=\mathop{\mathrm{im}}d^0`$、$`Z=\ker d^1`$ と置く。未知の欠陥 $`\delta`$ は $`\mathop{\mathrm{im}}d_{\mathsf E}^1`$ 全体を動き、既知情報はこの所属条件と構造データだけとする。問い合わせは、この入力空間上のすべての線形汎関数の正確な評価を許し、一つの汎関数の評価を単位費用と数える。許可範囲 $`S`$ での修復可否に対する最適な最悪時問い合わせ数を $`m_{\mathrm{dec}}(S)`$ とすると、

```math
m_{\mathrm{dec}}(S)
=\dim\frac{\mathop{\mathrm{im}}d_{\mathsf E}^1}
                 {\mathop{\mathrm{im}}d_S^1},
```

```math
\dim(C_{\mathsf E}^0/C_S^0)
+\bigl(\dim H^1(C_{\mathsf E})-\dim H^1(C_S)\bigr)
+m_{\mathrm{dec}}(S)
=\sum_{e\in\mathsf E\setminus S}\dim A_{t(e)}.
```

共通の指数 $`m`$ を持つ有限アーベル群の場合には、同じ群と写像から

```math
|C_{\mathsf E}^0/C_S^0|\,
\frac{|H^1(C_{\mathsf E})|}{|H^1(C_S)|}\,
\left|\frac{\mathop{\mathrm{im}}d_{\mathsf E}^1}
                 {\mathop{\mathrm{im}}d_S^1}\right|
=\prod_{e\in\mathsf E\setminus S}|A_{t(e)}|
```

が成り立つ。第三因子は修復可否の剰余障害群の位数である。

**証明.**
$`G\subseteq Z`$ なので、凍結座標の空間 $`V/U`$ に三段の部分群列

```math
0\subseteq(G+U)/U\subseteq(Z+U)/U\subseteq V/U
```

がある。その三つの商を順に計算する。微分 $`d^0`$ の逆像による $`C_S^0`$ の定義から

```math
(G+U)/U\simeq G/(G\cap U)\simeq C_{\mathsf E}^0/C_S^0.
```

第11章の単射 $`H^1(C_S)\hookrightarrow H^1(C_{\mathsf E})`$ を用いると、第二の商は

```math
(Z+U)/(G+U)
\simeq Z/(G+(Z\cap U))
\simeq H^1(C_{\mathsf E})/H^1(C_S)
```

である。最後に $`d^1`$ は全射
$`V\to d^1V/d^1U`$
を誘導し、その核は $`Z+U`$ なので、第三の商は $`d^1V/d^1U`$ である。有限次元の場合は三つの次元を加え、有限群の場合は三つの位数を掛ければ $`V/U`$ の次元・位数になる。$`U`$ は許可辺の全座標を含むので
$`V/U=\bigoplus_{e\in\mathsf E\setminus S}A_{t(e)}`$
となり、表示した右辺を得る。

体上の問い合わせ数について、可否は商写像 $`q_S:d^1V\to d^1V/d^1U`$ の零性である。零入力は可解なので定理18.6を適用できる。十分な問い合わせの線形包は $`q_S^*`$ の像を含まなければならず、その次元 $`\dim(d^1V/d^1U)`$ 未満の個数では不可能である。逆に、その像の基底を問い合わせれば可否が定まる。これは適応的手続きにも同じ下限を与える。有限群では、問い合わせの値域と費用を別に指定しない限り位数を問い合わせ回数と同一視せず、上の積等式として述べる。□

第二項の双対は、定理11.23により凍結部分に台を持つ双対サイクルの商である。第一項は許容再同定パラメータの減少であり、自己同型群 $`H^0(C_S)`$ 自体の減少ではない。問い合わせを固定の候補集合に限定した場合には定理18.6の極小十分集合を使い、第三項を無条件にその最適値へ置き換えない。

**例18.18（有限変換網での保存量）.**
例11.14・18.7の $`\mathbb F_3`$ 上の網では、$`C^0_{\mathsf E}=0`$、$`V=\mathbb F_3^4`$、$`d^1(u,h,z,w)=(u+z,u-z+w)`$ である。$`\dim H^1(C_{\mathsf E})=2`$ であり、各範囲の保存量は次の通りとなる。

| 許可範囲 $`S`$ | 再同定パラメータの減少 | 同型類の次元差 | $`m_{\mathrm{dec}}(S)`$ | 凍結座標数 |
| --- | --- | --- | --- | --- |
| $`\varnothing`$ | 0 | 1 | 1 | 2 |
| $`\{b\}`$ | 0 | 1 | 0 | 1 |
| $`\{c\}`$ | 0 | 1 | 0 | 1 |
| $`\{b,c\}`$ | 0 | 0 | 0 | 0 |

空範囲では可否が $`y-x=0`$ なので、全線形汎関数を許す設定では問い合わせ $`y-x`$ 一つで足りる。座標問い合わせ $`x,y`$ だけを許す設定なら最適値は2であり、上の保存則の問い合わせ条件が実際に使われている。有限群として見た積等式は、空範囲で $`1\cdot3\cdot3=9`$、一辺を許す範囲で $`1\cdot3\cdot1=3`$、全範囲で $`1=1`$ となる。

例11.15の二辺経路では $`V=\mathbb F_3^2`$、$`d^0(t)=(t,-t)`$、$`d^1=0`$ である。全範囲の $`H^1`$ は1次元で、空範囲・一辺・全範囲の三項はそれぞれ $`(1,1,0)`$、$`(1,0,0)`$、$`(0,0,0)`$ となる。有限群の等式では $`3\cdot3\cdot1=9`$、$`3\cdot1\cdot1=3`$ を得る。可否の障害がなくても、凍結は再同定パラメータと同型類の両方に作用する。

さらに例11.16の剪断では、全範囲で $`\dim C^0=4`$、$`\dim\ker d^0=1`$、$`\dim H^1=1`$ である。空範囲の三項は $`(3,1,0)`$、一辺を許す範囲では $`(2,0,0)`$ となり、いずれの範囲でも $`H^0\simeq\mathbb F_3`$ は変わらない。

指定された目標修復を回復する問題では、可否だけでなく第11章の定理11.21のファイバーを出力として保持する。その存在の障害、同型類の torsor、すべての自己同型は同じ $`F_S`$ の写像錐で計算される。入力・問い合わせ・出力の比較も保つとき、定理11.22の圏同値は修復全体を返す手続きを運ぶ。特定の数値補正を厳密に返すには、目標との同型だけでなく第16章の指定補正の二等式を使う。

最後に、次章の再構成定理との関係を述べておく。
すべての解からなる族の圏同値が既知情報・問い合わせ・出力の対応を保つ場合には、一方の手続きにおける各問い合わせを同じ返答を与える問い合わせへ送り、最終出力をその比較で運ぶことができる。
実行列の長さと正当性は各段階の帰納法で保たれるため、逆向きの比較も持つならば最適問い合わせ数も一致する。
ただし、具体的な数値ベクトルをそのまま返す出力指定には、そのベクトルの対応まで保つ比較が必要であり、すべての解の同型類だけを保つ比較でこれを代用することはできない。
次章では、局所の原始的な読み取りから、このようなすべての解の族の比較そのものを構成する。

## 18.10 有限候補の重み付き観測

**設定18.19（候補・出力・問い合わせ費用）.**
既知情報と整合する候補集合 $`U`$ と問い合わせ集合 $`J_0`$ を有限とする。必要な出力を $`p:U\to P`$、正確な問い合わせを $`q_j:U\to Y_j`$、その費用を $`c_j\in[0,\infty)`$ とする。候補は原始Lawを満たす有限データから列挙し、$`q_j`$ と $`p`$ はそのデータを評価して得る。

静的な集合 $`J\subseteq J_0`$ が**出力に十分**であるとは、すべての $`u,v\in U`$ について、$`q_j(u)=q_j(v)`$（全 $`j\in J`$）なら $`p(u)=p(v)`$ となることをいう。適応的な手続きは、既知情報とそれまでの返答から次の問い合わせまたは最終出力を決める決定的なものとし、全入力で有限停止して正しい $`p`$ を返すことを要求する。費用は、同じ問い合わせの反復も含め、実行するたびに $`c_j`$ を加える。空の候補集合の最悪費用は零とする。以下の最適値の等式は実数費用に対して成り立ち、有限時間での計算の主張では入力費用を非負有理数とする。

**定理18.20（静的な横断集合と適応的な最適値）.**
$`p(u)\ne p(v)`$ となる候補対について

```math
E_{u,v}=\{j\in J_0:q_j(u)\ne q_j(v)\}
```

と置く。静的な問い合わせ集合 $`J`$ が出力に十分であることと、すべての $`E_{u,v}`$ に交わることとは同値である。従って静的な最小費用は

```math
\min_{J\subseteq J_0,\ \forall u,v:\ p(u)\ne p(v),\
                J\cap E_{u,v}\ne\varnothing}\ \sum_{j\in J}c_j
```

である。候補となる $`J`$ がなければ値を $`\infty`$ とする。

一方、候補部分集合 $`A\subseteq U`$ に対する適応的な最悪費用の最適値 $`V(A)`$ は、次の再帰式で与えられる。$`A`$ が空または $`p|_A`$ が定数なら $`V(A)=0`$。それ以外では

```math
V(A)=\min_{\substack{j\in J_0\\|q_j(A)|\ge2}}
       \left(c_j+\max_{y\in q_j(A)}V(A\cap q_j^{-1}(y))\right),
```

空の最小値は $`\infty`$ とする。この再帰は真の部分集合だけを参照するので停止し、有限値の場合にはそれを達成する決定木を構成する。入力表と非負有理数費用が与えられれば、静的値と適応値は有限時間で計算できる。

**証明.**
静的な $`J`$ が十分なら、出力の異なる二候補がすべての $`J`$ の返答で一致することはない。従って $`J`$ は各 $`E_{u,v}`$ と交わる。逆にこの交わり条件があれば、同じ返答ベクトルを持つ候補の出力はすべて一致するので、その値を返せる。有限個の $`J`$ を列挙すれば費用の最小値を得る。空の辺 $`E_{u,v}`$ は、全問い合わせを用いても区別できない候補対を表す。

適応的な手続きのある段階で候補が $`A`$ になったとする。$`q_j|_A`$ が定数である問い合わせは、返答を既に予測できるので省略でき、非負費用のため最悪費用を増やさない。全入力で有限停止する手続きは、有限個の入力の有限実行列の合併として有限の決定木を持つ。したがって定値でない出力を決める木の最初の有用な問い合わせは $`A`$ を真に分割し、返答 $`y`$ の後の費用は帰納法により少なくとも $`V(A\cap q_j^{-1}(y))`$ である。これが再帰式の下限を与える。

逆に再帰式の値が有限なら、最小値を与える $`j`$ を選び、各返答の真部分集合に帰納的に構成した最適木を接続する。これが式の費用を達成する。どの分割にも不能な子があれば最悪費用は $`\infty`$ であり、正答する有限木は存在しない。有限表と有理数では分割・比較・加算が実効的なので計算も停止する。□

**定理18.21（アフィン族の重み付き核条件）.**
定理18.6の非空なファイバー $`F_s`$ と有限の問い合わせ集合 $`J_0`$ を取り、費用 $`c_j\ge0`$ を付ける。可解な入力が存在する場合、決定的で全入力上停止する手続きの最適な最悪費用は

```math
\min_{\substack{J\subseteq J_0\\N\cap\ker O_J\subseteq\ker C}}
       \sum_{j\in J}c_j,\qquad
 C=\pi_SB_{\mathrm{in}}\ \text{または}\ B_{\mathrm{in}}
```

である。前者は可否判定、後者は数値補正を出力する場合である。十分集合がなければ値は $`\infty`$ で、すべて不能なら最適費用は $`0`$ である。

**証明.**
可解な入力 $`v_*`$ に対する任意の正しい手続きの実行を取り、そこで問い合わせた添字の集合を $`J`$ とする。定理18.6の同じ返答列を作る議論から、$`N\cap\ker O_J\subseteq\ker C`$ が必要である。この実行の費用は、重複を取り除いた $`\sum_{j\in J}c_j`$ 以上だから式の値が下限となる。逆に、有限個の部分集合のうち費用を最小にする十分集合を一度ずつ問い合わせ、定理18.4の出力を返せば上限を達成する。十分集合がない場合とすべて不能の場合も定理18.6の証明がそのまま適用できる。□

有限候補の一般の出力では適応性が費用を下げる。命題18.16の $`m\ge2`$ 個のビットの例で、選択添字の費用を $`c_s`$、各ビットの費用を $`c_i>0`$ とすると、静的には全問い合わせが必要なので費用は $`c_s+\sum_i c_i`$ であるが、添字を先に読み指定ビットだけを読む手続きの最悪費用は $`c_s+\max_i c_i`$ である。一方、定理18.21のアフィン族では、可解な入力を通る実行一本が全体で十分な静的集合を強制するため、この改善は生じない。


第VI部では、目的の出力に応じた観測の十分性を定め、同じ補正方程式から判定と数値補正に必要な情報を分離した。次の第VII部では、原始的な局所読み取りから対象・すべての射・修復の全体を回復し、有限情報でそれらを決定できる条件を調べる。
