# 付録F 普遍係数と有限停止

有限個の全域多項式操作について、すべての操作語による残差を有限個の語から生成する。係数を変数として扱うことで、停止する語長を係数環や初期値に依存させずに選ぶ。本付録の計算は整数係数の恒等式を生成するため、冪零元を持つ環への特殊化も保つ。

## F.1 多項式環の有限生成性

環は単位元を持つ可換環とする。環 $`R`$ が **Noether 環**であるとは、すべてのイデアルが有限生成であることをいう。

**補題F.1（有限生成性と上昇列）.**
次が成り立つ。

1. $`R`$ が Noether 環なら、有限自由 $`R`$-加群の任意の部分加群は有限生成である。
2. $`R`$ が Noether 環なら、$`R[t]`$ も Noether 環である。
3. $`\mathbb Z[z_1,\ldots,z_s]`$ のイデアルの任意の上昇列は有限段で停止する。

**証明.**
第一の主張は自由加群の階数 $`n`$ について帰納する。$`n=0`$ は明らかである。部分加群 $`M\subseteq R^n`$ の最後の座標への像はイデアルなので有限生成である。その生成元を $`M`$ へ有限個持ち上げる。最後の座標が零である核は $`R^{n-1}`$ の部分加群なので帰納法により有限生成であり、核の生成元と先ほどの持ち上げが $`M`$ を生成する。

第二の主張ではイデアル $`J\subseteq R[t]`$ を取る。$`J`$ の非零多項式の最高次係数と零を集めた集合 $`L`$ はイデアルである。実際、二つの多項式に適切な $`t`$ の冪を掛けて次数を揃えれば最高次係数を加えられ、スカラー倍も同様である。係数が相殺した場合には零が得られる。$`L=0`$ なら $`J=0`$ である。それ以外では $`L`$ の有限生成元を $`f_1,\ldots,f_r\in J`$ の最高次係数として選び、$`n=\max_i\deg f_i`$ と置く。

$`f\in J`$ の次数が $`d\ge n`$ なら、その最高次係数を上の生成元の線形結合に書き、対応する $`t^{d-\deg f_i}f_i`$ の線形結合を引くことで次数を真に下げられる。有限回の反復で次数 $`n`$ 未満の元になる。$`J\cap R[t]_{<n}`$ は有限自由加群 $`R[t]_{<n}\cong R^n`$ の部分加群なので、第一の主張により有限生成である。その生成元と $`f_i`$ が $`J`$ を生成する。$`n=0`$ のときは次数0未満の加群を零とする。

最後に、整数の非零イデアルは、その正の元の最小値 $`a`$ によって生成される。除法の余りもイデアルに入るため $`a`$ 未満の正の余りは存在しない。従って $`\mathbb Z`$ は Noether 環であり、第二の主張を反復すれば有限変数多項式環も Noether 環となる。上昇列 $`J_0\subseteq J_1\subseteq\cdots`$ の和集合はイデアルである。その有限生成元はある共通の $`J_b`$ に含まれるため、和集合が $`J_b`$ に一致する。□

## F.2 係数を固定しない操作語の恒等式

非負整数 $`N,m,d,d_0`$ を固定する。多重指数 $`\alpha\in\mathbb N^N`$ の総次数を $`|\alpha|`$ とし、$`|\alpha|\le d`$ および $`|\beta|\le d_0`$ を満たす添字を使う。有限個の係数変数と状態変数から環

```math
P=\mathbb Z[a_{j,r,\alpha},b_\beta,x_1,\ldots,x_N]
```

を作る。ただし $`1\le j\le m,\ 1\le r\le N`$ である。普遍操作と一つの普遍残差を

```math
F_{j,r}(x)=\sum_{|\alpha|\le d}a_{j,r,\alpha}x^\alpha,
\qquad
\mathcal R(x)=\sum_{|\beta|\le d_0}b_\beta x^\beta
```

と定める。$`\Phi_j:P\to P`$ はすべての係数変数を固定し、$`x_r`$ を $`F_{j,r}(x)`$ へ送る環準同型とする。

操作語の集合は $`\{1,\ldots,m\}^*`$ であり、空語の準同型は恒等とする。すべての長さ $`L`$ 以下の合成により得る多項式を $`G_L=\{\Phi_w(\mathcal R):|w|\le L\}`$、その生成イデアルを $`J_L=(G_L)`$ と書く。操作の順序を反転して語を添字づけても、このすべての語からなる集合は同じである。

**定理F.2（普遍的な有限生成語長）.**
上の整数だけから計算可能な整数 $`B(N,m,d,d_0)`$ を構成でき、次が成り立つ。

1. $`J_B=J_{B+1}=J_L`$（$`L\ge B`$）。
2. 任意の語 $`w`$ に対し、$`\Phi_w(\mathcal R)`$ は $`G_B`$ の整数係数多項式による線形結合である。
3. 任意の可換環 $`R`$、次数 $`d`$ 以下の $`m`$ 個の多項式操作 $`f_j`$、次数 $`d_0`$ 以下の任意の有限残差族 $`(\rho_i)_{i=1}^q`$ について、

```math
(\rho_i\circ f_w:1\le i\le q,\ w\in\{1,\ldots,m\}^*)
=
(\rho_i\circ f_w:1\le i\le q,\ |w|\le B)
```

が $`R[x_1,\ldots,x_N]`$ のイデアルの等号として成り立つ。右辺の上界は $`q`$ にも依存しない。

**証明.**
補題F.1により $`P`$ は Noether 環なので、列 $`J_L`$ はある段 $`b`$ で $`J_b=J_{b+1}`$ となる。各 $`j`$ に対して $`\Phi_j(G_L)\subseteq G_{L+1}`$ であり、環準同型は線形結合を線形結合へ送るから $`\Phi_j(J_L)\subseteq J_{L+1}`$ である。従って $`J_b`$ はすべての $`\Phi_j`$ で保たれる。語長に関する帰納法によりすべての $`\Phi_w(\mathcal R)`$ が $`J_b`$ に入り、一度停止した後のすべての等号を得る。

この段を有限算法で見つける。整数係数の有限変数多項式には、次数と係数の絶対値をともに上から制限した有限の列挙がある。段 $`h=0,1,\ldots`$ ごとに、すべての $`L\le h`$ と、各 $`j`$ および $`g\in G_L`$ に対する有限族

```math
\Phi_j(g)=\sum_{u\in G_L}p_{j,g,u}u
```

の候補を列挙する。各 $`p_{j,g,u}\in P`$ の次数と係数の絶対値を $`h`$ 以下に限る。すべての恒等式を展開して係数比較し、同時に成立する組を見つけたら、その $`L`$ を返す。同じ段内での候補には固定した辞書式順序を使う。各段の処理は有限である。

停止段 $`b`$ ではすべての $`\Phi_j(g)`$ が $`J_b`$ に属するので、この形の有限個の証明多項式が存在する。その次数・係数の絶対値・$`b`$ をすべて上回る $`h`$ で探索は成功する。従って算法は停止し、返した $`B`$ は $`\Phi_j(J_B)\subseteq J_B`$ を証明する有限個の恒等式を伴う。帰納法で任意の語に対する所属証明も生成できる。

最後に、普遍操作の係数 $`a_{j,r,\alpha}`$ を $`f_j`$ の係数へ送り、$`b_\beta`$ を一つの $`\rho_i`$ の係数へ送る。これは整数係数の環射なので、得られたすべての恒等式を任意の $`R`$ で保存する。各 $`\rho_i`$ について同じ恒等式を別々に特殊化すれば、第三の等号が従う。除算も根基も用いていない。$`q=0`$ の両辺は零イデアル、$`m=0`$ では空語だけなので同じ結論が成り立つ。□

この算法の上界は語長についてのものである。列挙に必要な時間、係数の桁数、長さ $`B`$ 以下の語の個数の小ささは、定理の結論に含まれない。

**例F.3（一次元アフィン操作の短い証明）.**
一操作 $`f(x)=ax+c`$ と残差 $`\rho(x)=bx+e`$ では、

```math
\rho(f(f(x)))=(a+1)\rho(f(x))-a\rho(x).
```

従って長さ1までの二つの残差が生成するイデアルは $`f`$ の引き戻しで保たれ、全語に十分である。この恒等式は $`a,b,c,e`$ を含む整数多項式環で成立するため、任意の係数環と試験代数で使える。
