# 第3章 文脈と局所モデル

局所的に取り出すものを指定すると、それに応じて制限の向きと組立ての条件が定まる。
この章では、まず宣言を部分的に取り出す。保持したsortの担体は全体を保持し、
操作やLawを、その入力と参照先とともに選ぶ。
この制限について対象と射を組み立てた後、有限の状態やqueryだけを読む制限、
および係数空間の開集合への制限を区別する。

## 3.1 依存に閉じた文脈とLawの支持

**定義3.1（宣言文脈）.**
原始表示\(\mathcal P\)の宣言の集合を\(\operatorname{Decl}(\mathcal P)\)とする。
sort、操作、関係、部分操作、量に加えて、Lawの名前付き宣言もこの集合に含める。
部分操作とそのdomain・graph記号は一つの宣言の組として扱う。
次の参照を宣言の依存とする。

- 操作・関係・量は、その全入力sortと出力sortに依存する。
- 部分操作は入力sort・出力sortに依存する。domainを別sortと包含で表す宣言は、
  そのsortと包含操作も保持する。
- Lawは、変数文脈の全sort、入力の式\(\iota_\ell\)、結論の式\(\chi_\ell\)に現れる
  全記号と、その記号の依存に依存する。
- 導出Lawの宣言は、添付された有限導出木の全sequent、型付き変数文脈、
  使用したgraphの構造公理に現れる宣言、および使用した必須Lawにも依存する。
  それらの宣言についても依存に閉じていることを要求する。

文脈\(U\)は、この依存について閉じた\(\operatorname{Decl}(\mathcal P)\)の部分集合である。
Lawの式と入力を読むのに必要な宣言の最小の依存閉包を\(\operatorname{Supp}(\ell)\)と呼ぶ。
Lawの宣言も保持した文脈が必要な場合は、
\(\{\ell\}\cup\operatorname{Supp}(\ell)\)の依存閉包を取る。
具体的な入力値は支持に含めず、その入力を走らせるsortと式を保持する。

包含\(V\subseteq U\)を一つの射\(V\to U\)とする文脈圏を
\(\operatorname{Ctx}(\mathcal P)\)と書く。
交差と任意の合併は依存に閉じており、それぞれ文脈になる。
制限表示\(\mathcal P|_U\)は、\(U\)に含まれる宣言とLawを保持する。
その必須Lawは、\(U\)内の必須Law宣言である。
導出Lawの導出木も保持する。木に現れる全宣言と使用する公理が\(U\)内にあるため、
同じ導出木が制限後の言語でも有効である。

たとえば定数\(c:S\)の全域性から
\(\top\vdash_{\varnothing}\exists x:S\,\top\)を導く場合、
結論の式には\(c\)が現れないが、その導出には\(c\)のgraph構造公理を使う。
この導出Lawを残す文脈は\(c\)も残す。これにより、非空性を導いたデータが
制限表示にも保持される。

sort \(s\)を残すことは、\(X_s(A)\)の一部の状態だけを残すことではない。
この宣言制限では担体\(X_s(A)\)をそのまま残す。
たとえば操作\(f\)を含む文脈では、\(f_A\)の全入力での値を持つ。

## 3.2 モデル・射・評価の制限

**命題3.2（制限と評価）.**
各文脈\(U\)に\(\mathcal A(U):=\mathcal A_{\mathbb T_{\mathcal P|_U}}\)を対応させる。
\(V\subseteq U\)に対して、忘却による関手

```math
\operatorname{res}_{U,V}:\mathcal A(U)\longrightarrow\mathcal A(V),
\qquad A\longmapsto A|_V
\tag{3.1}
```

がある。これらは恒等と合成に厳密に従う。
支持が\(V\)に入るterm \(t\)、正の式\(\varphi\)、Law \(\ell\)については、
\(A|_V\)での定義域・評価・充足は\(A\)でのそれと一致する。

**証明.**
残すsortの担体、操作、関係、domain、量を\(A\)からそのまま取る。
依存閉性により、残した操作の入出力とLawの全入力を読める。
必須Law \(\ell\in V\)については、その式の全記号が\(V\)にある。
termの構文木で帰納すれば、残した原始操作が同じ写像なので定義域と値が一致する。
式については原子式から連言・選言・存在量化へ帰納する。
量化sortも同じ全担体を持つので、witnessの範囲も一致する。
この一致を入力の式と結論に適用すれば、\(A|_V\)は\(\ell\)を満たす。

射は残したsortの成分写像を取る。
保存条件は残した宣言についての元の保存条件だから成立する。
恒等と合成は成分で一致する。
二段の制限と一段の制限は同じデータを残すため等しい。□

したがって\(\mathcal A\)は\(\operatorname{Ctx}(\mathcal P)^{\mathrm{op}}\)上の圏値の関手である。
式の支持を保つ宣言制限は、構文側の制限と評価側の制限を同時に与える。
Lawの結論だけを残して入力の式を忘れると、この証明の入力集合の一致が失われる。

## 3.3 被覆と局所整合データ

**定義3.3（宣言被覆と厳密な整合族）.**
\(U\)の宣言被覆は、文脈族\((U_i\subseteq U)_{i\in I}\)で
\(\bigcup_iU_i=U\)を満たすものとする。添字集合\(I\)は小さいものとする。
特に各Law宣言とその全支持は、少なくとも一つの\(U_i\)に入る。
恒等包含は被覆であり、\(V\subseteq U\)への引戻しは\((U_i\cap V)_i\)、
各\(U_i\)の被覆を合わせた族も被覆である。
これらは集合の合併・交差の法則から従い、宣言文脈上の被覆の規則を定める。

局所モデル\(A_i\in\mathcal A(U_i)\)の厳密な整合族とは、
全\(i,j\)について

```math
A_i|_{U_i\cap U_j}=A_j|_{U_i\cap U_j}
\tag{3.2}
```

が成り立つ族である。等号には共有sortの担体、操作、関係、domain、量の全データを含む。
二つの整合族\((A_i),(B_i)\)の間の整合局所射は、
\(h_i:A_i\to B_i\)で
\(h_i|_{U_i\cap U_j}=h_j|_{U_i\cap U_j}\)を満たす族である。
これらからなる圏を\(\operatorname{Match}((U_i),\mathcal A)\)と書く。

同型によって局所対象を同定するデータは、別に
\(\theta_{ij}:A_j|_{U_i\cap U_j}\xrightarrow{\sim}A_i|_{U_i\cap U_j}\)と
\(\theta_{ii}=\operatorname{id}\)、
\(\theta_{ij}\theta_{jk}=\theta_{ik}\)を三重交差上で指定する。
射の整合条件も
\(h_i\theta^A_{ij}=\theta^B_{ij}h_j\)となる。
以下の二定理は、\(\theta_{ij}\)が恒等で式(3.2)となる入力について述べる。

**定理3.4（宣言被覆上の厳密な組立て）.**
任意の小さい原始表示、宣言文脈\(U\)、宣言被覆\((U_i)\)、
厳密な整合局所モデル族\((A_i)\)に対し、
\(A|_{U_i}=A_i\)を全\(i\)について満たす\(A\in\mathcal A(U)\)が一意に存在する。

**構成と証明.**
各sort \(s\in U\)について、\(s\in U_i\)となる局所モデルの担体を\(X_s(A)\)とする。
二つの局所モデルが\(s\)を持つなら\(s\in U_i\cap U_j\)なので、
式(3.2)によりそれらの担体は等しい。
したがって値は選択によらず一意に定まる。

操作\(f\in U\)を含む\(U_i\)を取る。
依存閉性により全入出力sortも\(U_i\)にある。
その担体は既に定めた大域担体と等しいので、\(f_A=f_{A_i}\)と置ける。
他の\(U_j\)も\(f\)を含む場合、共有宣言の等号により同じ写像となる。
関係、部分操作のdomainと写像、量も同じ方法で定める。
これは宣言ごとに一意に決まる局所データの合併であり、
局所モデルを大域モデルの存在から逆に選んだものではない。

必須Law \(\ell\in U\)を取る。被覆条件から\(\ell\in U_i\)となる\(i\)があり、
その文脈には全入力sortと全支持がある。
任意の\(\gamma\in I_\ell^A\)について、命題3.2の評価の一致により
\(\gamma\in I_\ell^{A_i}\)である。
\(A_i\)は\(\ell\)を満たすので結論の式が成立し、同じ評価の一致で\(A\)でも成立する。
よって\(A\)は全必須Lawを満たす。
構成から\(A|_{U_i}=A_i\)である。

別の大域モデル\(A'\)が同じ制限を持つなら、各宣言を含む\(U_i\)でその解釈は\(A\)と等しい。
全宣言が覆われるため、全担体と全構造写像が等しく、\(A'=A\)である。□

**定理3.5（構造保存射の局所組立て）.**
同じ宣言被覆と二つの大域モデル\(A,B\)に対し、整合局所射
\(h_i:A|_{U_i}\to B|_{U_i}\)から、制限が全ての\(h_i\)となる一意の射\(h:A\to B\)が構成される。
この構成は制限・恒等・合成と可換する。したがって制限関手は圏の同型

```math
\mathcal A(U)\ \cong\ \operatorname{Match}((U_i),\mathcal A)
\tag{3.3}
```

を与える。

**証明.**
sort \(s\)を含む\(U_i\)で\(h_s=(h_i)_s\)と置く。
局所射の整合から、これは\(i\)によらない。
操作\(f\)の保存条件は\(f\)を含む一つの文脈で検査する。
そこには全入出力sortがあり、その写像は既に構成した\(h_s\)なので、
\(h_i\)の保存式がそのまま大域の保存式になる。
関係とdomainの保存、部分操作と量の可換性も同じである。
観測を宣言に含めて保持する場合は、その宣言で観測の可換性を検査する。

全sortが被覆されるので射は一意である。
局所恒等から得る成分は恒等、局所合成から得る成分は成分写像の合成となる。
別の文脈へ制限して組み立てても同じ成分を取るため、制限とも可換する。
定理3.4の対象の構成と合わせると、式(3.3)の逆関手が得られる。□

Lawも覆う条件は必要である。
たとえば同じ二点担体に二操作\(f,g\)とLaw \(g(f(x))=x\)を持つ表示を考える。
\(f\)だけを持つ文脈と\(g\)だけを持つ文脈に、それぞれ定数\(0\)の操作を置くと、
共有sortは一致する。しかし合成は定数\(0\)であり、\(x=1\)でLawに反する。
この二文脈は全操作を覆うが、Law宣言とその支持を含む要素がなく、宣言被覆ではない。

### 生成元付き加群への適用

**命題3.6（有限局所自由実現の宣言方向の組立て）.**
可換環\(R\)、各型\(s\)の有限な生成元数\(m_s\)と階数\(n_s\)を固定する。
局所実現のデータを

```math
K_s\subseteq R^{m_s},\qquad
Q_s=R^{m_s}/K_s,\qquad
\pi_s:R^{m_s}\twoheadrightarrow Q_s
\tag{3.4}
```

とし、\(K_s\)は部分加群、\(Q_s\)は階数\(n_s\)の有限局所自由加群とする。
さらに有限arityの\(R\)多重線形演算と、その有限式で書かれたLawを指定する。
文脈が型を含むときは\(m_s,n_s\)と全ての名前付き生成元を同時に含み、
演算とLawの依存にも閉じているとする。

全宣言を覆う局所実現族について、共有型の\(K_s\)と共有演算が交差上で等しければ、
その族は一意の生成元付き大域実現へ組み立つ。

**証明.**
\(R\)を固定sortとし、各\(Q_s\)の加法・零・逆元、\(R\)のスカラー作用、
\(m_s\)個の名前付き生成元を宣言する。
多重線形演算を集合上の多引数操作として読み、線形性を各変数のLawとして課す。
tensor積からの線形写像を用いる記述とも、その多重線形写像によって対応する。
各型に付随するこの宣言全体を文脈で同時に保持する。

共有\(K_s\)が等しければ、式(3.4)の標準の商集合・加群構造・生成元は厳密に等しい。
共有演算も仮定から等しいため、定理3.4の局所モデルの条件を満たす。
同定したデータを合わせると、各型の商は局所で選ばれた同じ\(R^{m_s}/K_s\)である。
従って全射\(\pi_s\)、有限局所自由性、指定階数も保たれる。
各演算の多重線形性と各Lawは、それを含む文脈で成立する。
一意性は各\(K_s\)と各演算がその制限で決まることから従う。□

この証明で覆ったのは宣言であり、係数環\(R\)は固定されている。
係数空間の開被覆から加群を降下する構成は、[第6章](../README.md#第ii部-実現の族とlawの幾何)へ接続する。

**例3.7（共有kernelが一致する場合と異なる場合）.**
\(R=\mathbb Q\)とし、型\(p,q,r\)に階数\(1\)、生成元数\(1,2,1\)を指定する。
型\(q\)の共有表示を

```math
K_q=\mathbb Q(3,-2),\qquad
Q_q=\mathbb Q^2/K_q,\qquad
\phi:Q_q\xrightarrow{\sim}\mathbb Q,\quad
[x,y]\longmapsto 2x+3y
\tag{3.5}
```

とする。kernelは表示した一次元部分空間であり、\(\phi([1/2,0])=1\)なので同型である。
\(e=[1/2,0]\)と置けば、名前付き生成元は\([1,0]=2e\)、\([0,1]=3e\)である。

左の文脈に\(p,q\)と二操作\(f:\mathbb Q\to Q_q\)、\(g:Q_q\to\mathbb Q\)を置き、
\(f(a)=2ae\)、\(g(z)=\phi(z)/2\)とする。
右の文脈に\(q,r\)と\(u:Q_q\to\mathbb Q\)、\(v:\mathbb Q\to Q_q\)を置き、
\(u(z)=3\phi(z)\)、\(v(a)=(a/3)e\)とする。
左右に往復が恒等となる二つずつのLawを置く。
\(gf(a)=a\)、\(fg(z)=\phi(z)e=z\)、\(uv(a)=a\)、\(vu(z)=z\)なので、全Lawが成立する。
共有\(q\)のkernelと生成元が同じであるため、命題3.6で一つの実現へ組み立つ。

右側だけ\(K'_q=\mathbb Q(0,1)\)、
\(Q'_q=\mathbb Q^2/K'_q\)、\(\phi'([x,y])=x\)へ変え、
\(u',v'\)を同じ係数\(3,1/3\)で定めても、右の往復Lawは成り立つ。
しかし共有生成元を保つ同型\(F:Q_q\to Q'_q\)は存在しない。
存在すれば\(F\pi_q=\pi'_q\)から、\(F\)の単射性により
\(\ker\pi_q=\ker\pi'_q\)となるはずだが、式(3.5)の\(K_q\)と\(K'_q\)は異なる。
したがってこの二つの局所実現は、同じ生成元を保持する全体には組み立たない。

## 3.4 有限fragment

**定義3.8（二種類の有限制限）.**
宣言の有限fragmentは、宣言文脈\(U\)の有限な依存閉部分集合\(F\)と、その制限表示である。
モデルを\(F\)へ制限しても、残したsortの担体と操作の全入力は保持される。

値の有限fragmentでは、各sortの有限個の標本名、その標本が指す状態、
有限個のqueryを指定する。queryには、操作の指定入力での値、graphへの所属、
関係やdomainへの所属、量の値などを用いる。
queryのスキーマには、値の型、問う原子事実、真偽の両方を読むか、
標本にない出力をどのように記録するかも含める。
この有限データを忘れる写像が、値のfragmentの制限である。

たとえば\(f:X\to X\)の宣言を保持した局所モデルは、
全\(x\in X\)に対する\(f(x)\)を持つ。
一方、有限集合\(Q\subseteq X\times X\)上で
「\(f(a)=b\)か」を読むfragmentは、その有限個の答えを持つ。
未照会の組については、そのfragmentに答えがない。

宣言の有限fragmentが\(U\)を覆う場合には、定理3.4–3.5が直ちに適用できる。
具体的には、有限依存閉部分集合の族が各宣言を含むなら、この族は有限合併で有向になる。
その上の厳密な整合族から、全担体・全操作を持つモデルと射を回復する。
基本署名と有限式のLawの表示では、各宣言の依存閉包が有限なので、この条件を満たす。
型ごとに無限個の宣言を同時に保持する指定を加えた場合には、
その指定について有限閉包の条件を改めて調べる。

**問題3.9（値の有限fragmentによる完全な記述）.**
小さい理論\(\mathbb T\)と、状態の標本・query・許容する有限の値・
それらの保存写像を原始データから定める有限制限方式を与える。
有限fragmentの添字を有向集合\(I\)とし、
局所データとその保存写像の圏\(\mathcal F_i\)、
\(i\le j\)に対する忘却関手\(r_{ji}:\mathcal F_j\to\mathcal F_i\)、
モデルからの制限\(r_i:\mathcal A_{\mathbb T}\to\mathcal F_i\)を構成する。
忘却の恒等・合成と\(r_{ji}r_j=r_i\)を要求する。
局所データはその有限スキーマの整合条件から定義し、
大域モデルから既に得られた像だけで置き換えない。

この入力について、次の二つが成り立つための条件を、
操作のarity、queryの被覆、出力witness、担体と指定supportの条件から求めよ。

1. 任意の整合族\((F_i)\)、すなわち\(r_{ji}F_j=F_i\)を満たす族に対し、
   全域として宣言した操作の全域性、部分操作の指定domain、全必須Law、
   および指定されたsupport条件を満たす大域モデルが回復される。
   そのfragment族は\((F_i)\)と整合的に同型である。
2. 任意の二つの大域モデル\(A,B\)について、整合する全局所射の族から
   一意の大域構造保存射\(A\to B\)が回復される。

すなわち、原始データから構成した比較関手

```math
\mathcal A_{\mathbb T}\longrightarrow
\varprojlim_{i\in I}\mathcal F_i
\tag{3.6}
```

の本質的全射性と充満忠実性を、具体的な条件から証明する問題である。
右辺の対象は厳密に整合する局所対象族、射は厳密に整合する局所射族とする。
担体を固定する方式では、左辺もその担体と指定写像を持つ圏に制限する。
全体が可算とは限らないので、一般には自然数列に限らず有向な有限部分の系を用いる。
逆極限による大域化と、どの有限段階で出力が決まるかは、
それぞれ[第13章](../README.md#第iv部-局所変更修復障害)と[第19章](../README.md#第vi部-観測必要情報再構成)へ渡す。

**例3.10（有限の答えから全域性が失われる）.**
担体を\(\mathbb N\)に固定し、全域操作\(f:\mathbb N\to\mathbb N\)を考える。
\(Q_n=\{0,\ldots,n\}^2\)上の全graph queryに、真偽の両方を答えるものとする。
有限表\(F_n\)では、\((i,j)\in Q_n\)への答えを
「\(i\ge1\)かつ\(j=i\)のときだけ真」とする。
これらは表を切り取る制限について厳密に整合する。
各\(F_n\)は、全域写像

```math
f_n(0)=n+1,\qquad f_n(i)=i\quad(i\ge1)
\tag{3.7}
```

の観測として実現できる。
しかし全ての\(F_n\)を同時に実現する全域写像\(f\)は存在しない。
もし存在すれば、\(j=f(0)\)を含む\(n\)において
query \((0,j)\)は真になるはずだが、\(F_n\)は偽と答えるからである。
各有限段階の出力witnessがその段階の外へ移ることを許したため、
全域性\(\forall x\,\exists y\,G_f(x,y)\)を回復できなかった。

supportにも同じ区別が現れる。
\(\mathbb N\)上の有限supportの\(0,1\)値列を各有限初期区間へ制限すると、
全ての有限\(0,1\)列が現れる。
各段で全て\(1\)の列は整合するが、その大域列は無限supportを持つ。
値の整合と全体に課すsupport条件を、有限制限方式の中でどう結ぶかが問題3.9の一部になる。

## 3.5 宣言の制限と幾何の局所化

**命題3.11（宣言忘却に対応する座標環の向き）.**
係数環\(k\)と、量の変数・多項式Lawからなる二表示\(V\subseteq W\)を取る。
\(V\)の変数を\(W\)の同名の変数へ送る多項式環準同型が、
\(V\)のLaw idealを\(W\)のLaw idealへ送るとする。
商環を\(B_V,B_W\)と書くと、環射\(B_V\to B_W\)があり、
任意の\(k\)代数\(R\)でのモデルの忘却は

```math
\operatorname{Hom}_{k\text{-alg}}(B_W,R)
\longrightarrow
\operatorname{Hom}_{k\text{-alg}}(B_V,R)
\tag{3.8}
```

という前合成で与えられる。

**証明.**
変数の写像は多項式環の普遍性から環準同型になる。
idealに関する仮定により商へ降りる。
\(B_W\to R\)は\(W\)の全変数の値と全Lawの成立を指定し、
前合成はそのうち\(V\)の変数の値を残す。
\(V\)のLawは商への因子化から成立する。これがモデルの忘却である。□

これに対し、一つの係数空間の開包含\(\Omega_V\subseteq\Omega_W\)では、
関数の制限は
\(\Gamma(\Omega_W,\mathcal O)\to\Gamma(\Omega_V,\mathcal O)\)である。
たとえば\(\operatorname{Spec}B\)の基本開集合\(D(s)\)では、
環\(B\)から局所化\(B_s\)への写像を用いる。
宣言を忘れる写像と、この局所化による制限は、別々の構成である。

**例3.12（共有変数を保つ逆向きの環射がない）.**
固定係数\(\mathbb Q\)上で\(V=\{x\}\)、\(W=\{x,y,xy=1\}\)と略記する。
共通の環演算と型の宣言は両方に含めている。
座標環と忘却に対応する環射は

```math
B_V=\mathbb Q[x]\longrightarrow
B_W=\mathbb Q[x,y]/(xy-1),\qquad x\longmapsto\bar x
\tag{3.9}
```

である。共有\(x\)を保つ逆向きの\(\mathbb Q\)代数射
\(\phi:B_W\to B_V\)が存在すると仮定する。
\(q(x)=\phi(\bar y)\)と置くと、関係\(\bar x\bar y=1\)から\(xq(x)=1\)となる。
\(x=0\)で評価すれば\(0=1\)となり矛盾する。よってそのような射は存在しない。

一方、\(B_W\)は\(\mathbb Q[x,x^{-1}]\)と同型である。
\(\bar y\)を\(x^{-1}\)へ送る写像と\(x^{-1}\)を\(\bar y\)へ送る写像が互いに逆になる。
したがってこの例では、式(3.9)は同時に基本開集合\(D(x)\)への局所化でもある。
二つの局所性を比較できることは、この具体的な環射と同型によって確かめられる。

第I部で構成したのは、言語、モデルと全構造保存射、理論解釈、
そして宣言の被覆上の対象・射の組立てである。
係数的実現と幾何的表示はこれらの対象を受け取り、
同型によるdescentと有限queryによる再構成は、それぞれの追加データから先へ進む。
