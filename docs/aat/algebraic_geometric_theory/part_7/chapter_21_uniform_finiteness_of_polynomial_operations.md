# 第21章 全域多項式操作の一様有限性

有限個の全域多項式操作と Law 残差を指定し、すべての操作語で残差が消える初期状態を求める。操作と残差の係数を変数として扱い、状態変数数・操作数・操作次数・残差次数だけに依存する計算可能な語長を構成する。
普遍係数環の Noether 性、所属恒等式の有限探索、任意の可換環への特殊化を順に証明し、この語長までの残差から最大の不変閉部分スキームを得る。整数係数の恒等式を使うため、冪零元を持つ環への特殊化も保たれる。最後に、ガード付き操作で初期値に独立な一様語長が存在しない例を調べる。

## 21.1 全域多項式操作と全語判定

**設定21.1（全域多項式操作と残差）.**
可換環 $`R`$、状態担体 $`\mathbb A_R^N`$、次数 $`d`$ 以下の名前付き全域多項式操作 $`f_1,\ldots,f_m`$、次数 $`d_0`$ 以下の原始 Law 残差 $`\rho_1,\ldots,\rho_q`$ を固定する。多項式は各 $`R`$-代数 $`S`$ 上の自然な操作を定める。語 $`w=j_1\cdots j_\ell`$ の作用を $`f_w=f_{j_1}\circ\cdots\circ f_{j_\ell}`$ とし、$`f_{vw}=f_v\circ f_w`$、空語の作用を恒等とする。この合成順は20.4節と同じである。操作どうしの可換性は要求しない。

長さ $`L`$ までの Law を課すイデアルと閉部分スキームを

```math
I_L=(\rho_i\circ f_w:1\le i\le q,\ |w|\le L),
\qquad
W_L=\operatorname{Spec}R[x]/I_L
```

とする。すべての $`W_L`$ は元の状態空間の閉部分スキームであり、その交わりは生成イデアルの和によるスキーム論的交わりとして取る。

## 21.2 多項式環の有限生成性

環は単位元を持つ可換環とする。環 $`R`$ が **Noether 環**であるとは、すべてのイデアルが有限生成であることをいう。

**補題21.2（有限生成性と上昇列）.**
次が成り立つ。

1. $`R`$ が Noether 環なら、有限自由 $`R`$-加群の任意の部分加群は有限生成である。
2. $`R`$ が Noether 環なら、$`R[t]`$ も Noether 環である。
3. $`\mathbb Z[z_1,\ldots,z_s]`$ のイデアルの任意の上昇列は有限段で停止する。

**証明.**
第一の主張は自由加群の階数 $`n`$ について帰納する。$`n=0`$ は明らかである。部分加群 $`M\subseteq R^n`$ の最後の座標への像はイデアルなので有限生成である。その生成元を $`M`$ へ有限個持ち上げる。最後の座標が零である核は $`R^{n-1}`$ の部分加群なので帰納法により有限生成であり、核の生成元と先ほどの持ち上げが $`M`$ を生成する。

第二の主張ではイデアル $`J\subseteq R[t]`$ を取る。$`J`$ の非零多項式の最高次係数と零を集めた集合 $`L`$ はイデアルである。実際、二つの多項式に適切な $`t`$ の冪を掛けて次数を揃えれば最高次係数を加えられ、スカラー倍も同様である。係数が相殺した場合には零が得られる。$`L=0`$ なら $`J=0`$ である。それ以外では $`L`$ の有限生成元を $`f_1,\ldots,f_r\in J`$ の最高次係数として選び、$`n=\max_i\deg f_i`$ と置く。

$`f\in J`$ の次数が $`d\ge n`$ なら、その最高次係数を上の生成元の線形結合に書き、対応する $`t^{d-\deg f_i}f_i`$ の線形結合を引くことで次数を真に下げられる。有限回の反復で次数 $`n`$ 未満の元になる。$`J\cap R[t]_{<n}`$ は有限自由加群 $`R[t]_{<n}\cong R^n`$ の部分加群なので、第一の主張により有限生成である。その生成元と $`f_i`$ が $`J`$ を生成する。$`n=0`$ のときは次数0未満の加群を零とする。

最後に、整数の非零イデアルは、その正の元の最小値 $`a`$ によって生成される。除法の余りもイデアルに入るため $`a`$ 未満の正の余りは存在しない。従って $`\mathbb Z`$ は Noether 環であり、第二の主張を反復すれば有限変数多項式環も Noether 環となる。上昇列 $`J_0\subseteq J_1\subseteq\cdots`$ の和集合はイデアルである。その有限生成元はある共通の $`J_b`$ に含まれるため、和集合が $`J_b`$ に一致する。□

## 21.3 普遍係数と計算可能な一様語長

非負整数 $`N,m,d,d_0`$ を固定する。多重指数 $`\alpha\in\mathbb N^N`$ の総次数を $`|\alpha|`$ とし、$`|\alpha|\le d`$ および $`|\beta|\le d_0`$ を満たす添字を使う。有限個の係数変数と状態変数から環

```math
P=\mathbb Z[a_{j,r,\alpha},b_\beta,x_1,\ldots,x_N]
```

を作る。ただし $`1\le j\le m,\ 1\le r\le N`$ である。普遍操作と一つの普遍残差を

```math
F_{j,r}(x)=\sum_{|\alpha|\le d}a_{j,r,\alpha}x^\alpha,
\qquad
\mathcal R(x)=\sum_{|\beta|\le d_0}b_\beta x^\beta
```

と定める。$`\Phi_j:P\to P`$ はすべての係数変数を固定し、$`x_r`$ を $`F_{j,r}(x)`$ へ送る環準同型とする。

操作語の集合は $`\{1,\ldots,m\}^*`$ であり、空語の準同型は恒等とする。語 $`w=j_1\cdots j_\ell`$ に対して $`\Phi_w=\Phi_{j_\ell}\circ\cdots\circ\Phi_{j_1}`$ と置く。これは21.1節の $`f_w=f_{j_1}\circ\cdots\circ f_{j_\ell}`$ の引き戻しの順序である。すべての長さ $`L`$ 以下の合成により得る多項式を $`G_L=\{\Phi_w(\mathcal R):|w|\le L\}`$、その生成イデアルを $`J_L=(G_L)`$ と書く。

**定理21.3（普遍的な有限生成語長）.**
上の整数だけから計算可能な整数 $`B(N,m,d,d_0)`$ を構成でき、次が成り立つ。

1. $`J_B=J_{B+1}=J_L`$（$`L\ge B`$）。
2. 任意の語 $`w`$ に対し、$`\Phi_w(\mathcal R)`$ は $`G_B`$ の $`P`$-線形結合、すなわち係数変数と状態変数の整数係数多項式を係数とする線形結合である。
3. 任意の可換環 $`R`$、次数 $`d`$ 以下の $`m`$ 個の多項式操作 $`f_j`$、次数 $`d_0`$ 以下の任意の有限残差族 $`(\rho_i)_{i=1}^q`$ について、

```math
(\rho_i\circ f_w:1\le i\le q,\ w\in\{1,\ldots,m\}^*)
=
(\rho_i\circ f_w:1\le i\le q,\ |w|\le B)
```

が $`R[x_1,\ldots,x_N]`$ のイデアルの等号として成り立つ。右辺の上界は $`q`$ にも依存しない。

**証明.**
補題21.2により $`P`$ は Noether 環なので、列 $`J_L`$ はある段 $`b`$ で $`J_b=J_{b+1}`$ となる。各 $`j`$ に対して $`\Phi_j(G_L)\subseteq G_{L+1}`$ であり、環準同型は線形結合を線形結合へ送るから $`\Phi_j(J_L)\subseteq J_{L+1}`$ である。従って $`J_b`$ はすべての $`\Phi_j`$ で保たれる。語長に関する帰納法によりすべての $`\Phi_w(\mathcal R)`$ が $`J_b`$ に入り、一度停止した後のすべての等号を得る。

この段を有限算法で見つける。整数係数の有限変数多項式には、次数と係数の絶対値をともに上から制限した有限の列挙がある。段 $`h=0,1,\ldots`$ ごとに、すべての $`L\le h`$ と、各 $`j`$ および $`g\in G_L`$ に対する有限族

```math
\Phi_j(g)=\sum_{u\in G_L}p_{j,g,u}u
```

の候補を列挙する。各 $`p_{j,g,u}\in P`$ の次数と係数の絶対値を $`h`$ 以下に限る。すべての恒等式を展開して係数比較し、同時に成立する組を見つけたら、その $`L`$ を返す。同じ段内での候補には固定した辞書式順序を使う。各段の処理は有限である。

停止段 $`b`$ ではすべての $`\Phi_j(g)`$ が $`J_b`$ に属するので、この形の有限個の証明多項式が存在する。その次数・係数の絶対値・$`b`$ をすべて上回る $`h`$ で探索は成功する。従って算法は停止し、返した $`B`$ は $`\Phi_j(J_B)\subseteq J_B`$ を証明する有限個の恒等式を伴う。帰納法で任意の語に対する所属証明も生成できる。

最後に、普遍操作の係数 $`a_{j,r,\alpha}`$ を $`f_j`$ の係数へ送り、$`b_\beta`$ を一つの $`\rho_i`$ の係数へ送る。これは整数係数の環射なので、得られたすべての恒等式を任意の $`R`$ で保存する。各 $`\rho_i`$ について同じ恒等式を別々に特殊化すれば、第三の等号が従う。除算も根基も用いていない。$`q=0`$ の両辺は零イデアル、$`m=0`$ では空語だけなので同じ結論が成り立つ。□

ここで $`B`$ は上の探索が最初に返した $`L`$ であり、最小の安定段であるとは限らない。この算法の上界は語長についてのものである。列挙に必要な時間、係数の桁数、長さ $`B`$ 以下の語の個数の小ささは、定理の結論に含まれない。

## 21.4 最大安全状態スキームと係数変更

**定理21.4（一様語長と最大安全状態スキーム）.**
定理21.3の計算可能整数 $`B=B(N,m,d,d_0)`$ について、次が成り立つ。

1. 任意の $`R`$-代数 $`S`$ と $`x\in S^N`$ に対し、長さ $`B`$ 以下の全語で残差が零であることと、すべての有限語で残差が零であることは同値である。
2. $`W_\infty:=W_B`$ は各 $`f_j`$ で保たれ、$`W_0`$ に含まれる最大の不変閉部分スキームである。
3. 任意の係数変更 $`R\to R'`$ に対し、この最大不変閉部分スキームの構成は基底変更と可換する。
4. 反復

```math
W_{L+1}=W_L\cap\bigcap_{j=1}^m f_j^{-1}(W_L)
```

は $`B`$ 段までに停止する。ここで逆像と交わりはスキーム論的に取る。

**証明.**
定理21.3を残差族へ適用すると $`I_B=I_\infty`$ であり、各長い語の残差は $`I_B`$ の生成元の多項式線形結合になる。任意の $`S`$-点にこの恒等式を評価すれば第一の同値を得る。

$`f_j^*(I_B)\subseteq I_B`$ なので $`f_j`$ は商環上の準同型を誘導し、$`W_B`$ を保つ。逆に閉部分スキーム $`Z=\operatorname{Spec}R[x]/K`$ が $`W_0`$ に含まれ各 $`f_j`$ で保たれるなら、$`I_0\subseteq K`$ かつ $`f_j^*K\subseteq K`$ である。語について帰納して $`I_\infty\subseteq K`$、すなわち $`Z\subseteq W_B`$ を得る。これは全試験代数上の点を保持する最大性である。

係数変更後の $`I_B`$ は、同じ有限個の多項式の像が生成するイデアルである。普遍的な所属恒等式は係数変更で保たれるため、変更後もそれが全語の残差イデアルとなる。従って最大性を持つ同じ構成が基底変更後にも成立する。最後に反復の右辺のイデアルは $`I_L+\sum_j(f_j^*I_L)`$ であり、ちょうど $`I_{L+1}`$ である。□

この結論は、短い語の残差から長い語の残差を生成する恒等式による。20.4節は最小線形実現そのものを回復し、本節は全域多項式操作と残差を入力として全語で安全な初期状態を構成する。

## 21.5 短い恒等式と冪零元の試験点

**例21.5（一次元アフィン操作の短い証明）.**
一操作 $`f(x)=ax+c`$ と残差 $`\rho(x)=bx+e`$ では、

```math
\rho(f(f(x)))=(a+1)\rho(f(x))-a\rho(x).
```

従って長さ1までの二つの残差が生成するイデアルは $`f`$ の引き戻しで保たれ、全語に十分である。この恒等式は $`a,b,c,e`$ を含む整数多項式環で成立するため、任意の係数環と試験代数で使える。

**例21.6（根基で失われる試験点）.**
恒等操作と Law $`x^2=0`$ を取る。安全スキームは $`\operatorname{Spec}k[x]/(x^2)`$ である。試験代数 $`k[\epsilon]/(\epsilon^2)`$ の点 $`x=\epsilon`$ も安全である。一方、根基 $`\sqrt{(x^2)}=(x)`$ に置き換えたスキームはこの点を持たない。幾何点の零点集合の一致は、定理21.4の全試験代数にわたる結論を代用しない。

## 21.6 ガード付き操作と一様性

**命題21.7（ガード付き操作では一様語長が存在しない）.**
整数状態 $`(x,y)\in\mathbb Z^2`$ 上で、一つの操作と残差を

```math
f(x,y)=
\begin{cases}
(x-1,y)&x>0,\\
(x,1)&x\le0,
\end{cases}
\qquad \rho(x,y)=y
```

と定める。変数数、操作数、各分岐の次数、残差次数、ガード、および係数を固定したまま、全語での残差消滅を初期値に独立な有限語長で判定することはできない。

**証明.**
任意の整数 $`n\ge0`$ について、初期値 $`(n,0)`$ から長さ $`r\le n`$ の状態は $`(n-r,0)`$ である。長さ $`n+1`$ では $`(0,1)`$ となる。もし一様上界 $`B`$ があれば $`n=B`$ として、その上界まで消滅するのに次の段で失敗する入力を得る。□

この不能性は初期値に独立な上界についてのものであり、この具体的操作の判定不能性を意味しない。

**問題21.8（数量評価とガードの符号化）.**
定理21.3の停止算法から得る語長を、変数数と次数による明示的な数量評価に改善せよ。有限制御を持つ部分操作族については、制御位置・分岐・違反状態を原始宣言に符号化し、全語判定の決定可能性を分類せよ。定理21.4の対象は全域多項式操作であり、命題21.7が示す一様上界の不存在と、一般の判定不能性の証明を区別する。
