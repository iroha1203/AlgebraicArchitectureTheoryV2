# 序論

同じ状態を読み取る二つの仕組みであっても、更新後の振る舞いは異なりうる。読み取りを保つ写像に「更新操作も保つ」という条件を加えると、許される変更の集合は大きく変わる。さらに、変更してはならない固定部分、局所的に変更できる範囲、そして満たすべき Law を指定すると、その集合の中から一つの具体的な変更問題が定まる。AAT は、このように条件から対象と射を構成し、それらの全体がもつ構造を調べる数学理論である。

理論の出発点は、共通の Atom 語彙、署名、および Law である。署名は型（sort）と名前付きの操作・関係・量を宣言し、Law はその入力と充足条件を定める。モデルは各型に担体となる集合を、各操作に具体的な写像を割り当てる。観測は、こうして与えられた構造から値を読む写像として表される。モデルの間の射には、操作を運ぶこと、関係と部分操作の定義域を保つこと、そして選ばれた観測と可換であることを課す。

この構成の順序には二つの側面がある。問いを立てる際には、まず保ちたい Law に基づいて必要な観測を選ぶ。一方、数学的な定義の段階では、その Law を評価するための型・操作・入力を先に定める。「Law に基づいて観測する」という選択の順序と、「構造を定義してから評価する」という論証の順序が、ここで一つに結びつく。

## 生成操作からすべての実行へ

本書で最初に得る保存定理は極めて具体的である。状態集合の間の写像 $`h:A\to B`$ が、各全域の名前付き操作と可換であり、観測についても $`o_B\circ h=o_A`$ を満たすとする。このとき、任意の有限操作語 $`w`$ に対して

```math
o_B\bigl(w_B(h(a))\bigr)=o_A\bigl(w_A(a)\bigr)
```

が成り立つ。[第2章の定理2.6](part_1/chapter_2_models_and_morphisms.md#24-すべての操作語への保存の延長)では、この等式を操作語に関する帰納法で証明し、さらに部分操作の定義域や操作語の翻訳を含む形へ拡張する。ここで写像 $`h`$ は単射である必要も全射である必要もない。したがって、複数の状態を一つにまとめる変更も、補助的な状態を追加する変更も、まったく同じ保存条件のもとで統一的に調べられる。

この基本定理は、変更の存在や構造を分類する後続の議論に確かな意味を与える。条件を満たす射を一つ構成できれば、その射がどの実行列を運び、観測上で何を保つかがただちに分かる。さらに、そのような射をすべて集めれば、同じ条件を満たす変更の全体を統一的に扱えるようになる。

## 三つの到達点

本書は、次の三つの到達点に向けて議論を積み上げる。

**1. 条件を満たす変更の全体の構成.**
[第II–III部](README.md#第ii部-実現の族とlawの幾何)では、意味の対象と射を係数環上に実現し、実現の族、意味を保つ変更の全体がなす族、および変更の合成を構成する。変更元、固定部分、許容規則、評価条件を指定したとき、それらを満たすすべての変更を求めることが目標である。幾何的な表示を与える際には、適切な係数や設定のもとでその点と射から元の意味の対象・射を回復する比較写像を併せて与える。座標環を構成できる場合の相対 $`\mathrm{Spec}`$、局所チャートによる表示、および同型射を含む族（groupoid やスタック）を、それぞれに必要な仮定のもとで使い分ける。

**2. 修復の全体と障害の構造.**
[第IV部](README.md#第iv部-局所変更修復障害)では、局所的な変更を大域的に組み立てるための整合条件と、Law を回復させる具体的な補正を扱う。固定部分と変更を許す範囲から許容される補正を定め、その作用を通じて、修復の存在条件、異なる修復どうしの再同定、および修復の後に残る自由度を明らかにする。また、局所解が存在するときに大域解へ進めるための条件と、その妨げとなる障害も、同じ原始データから導出する。

指定された目標修復を持ち上げる問題では、比較写像の錐から存在・同型類・自己同型を同時に読み取る。さらに、すべての欠陥に対して修復 groupoid 全体を回復する条件を、同じ比較の低次数コホモロジーで特徴づける。整数係数では、実調和代表と有限個の素数冪での検査を組み合わせ、ねじれを含む指定障害の零性を判定する。

**3. 必要情報の分離と変更問題の再構成.**
[第VI部](README.md#第vi部-観測必要情報再構成)では、同じ変更・修復問題に対して、(i) 可否を判定するために必要な情報、(ii) 具体的な補正値を選ぶために必要な情報、(iii) 解の全体を回復するために必要な情報、の三者を明確に区別する。[第18章の定理18.4](part_6/chapter_18_repair_and_observation.md#183-既知情報を条件とする十分性)は、一つの具体的な補正方程式に対して二つの核条件を与える。入力族・既知情報・要求する出力を固定したうえで、許容補正で吸収できる方向を除いた残存障害を決める情報と、具体的な補正値を指定するための右辺の情報を、それぞれの核条件として調べる。

さらに、解の全体を局所的な読み取りから回復するのが[第19章の定理19.5](part_6/chapter_19_local_reconstruction_and_finite_determination.md#193-条件付き変更と修復全体の相対再構成)である。ここでは、局所的な原始表から対象・可逆とは限らない一般の射・合成を復元し、許容規則、固定部分の同定、および評価条件を保存・反映することを示す。元の（native）モデルには定理19.2を用い、加群・層・局所的に分裂する複製余代数・自然多項式の係数族には、局所表と逆構成を与える定理19.2aを用いる。これらを通じて、第8章の条件付き変更の全体と、第11章の正則作用モデルを経由する修復の全体とを、すべての比較射に至るまで回復できる。加えて、内部輸送が恒等である protocol の有限決定には操作グラフの連結成分条件を、すべての解を実際に計算する算法には指定範囲の有限表または実効的な有限行列の条件を用いる。

有限個の単項線形操作を持つ総階数 $`N\ge1`$ の有限局所自由実現では、到達写像と双対観測写像の全射性のもとで、長さ $`2N-1`$ 以下の公開評価から一意な同型まで実現を復元する。この有限ハンケル表による再構成は、生成元からの商を使ったモジュライ表示とも整合する。また、構造パラメータを動かす修復方程式については、十分な問い合わせ集合と最適問い合わせ数が一定になる構成可能分割を与える。修復範囲の拡大が判定情報をどう変えるかは、凍結した部分の双対完全列と保存則によって同じ補正複体の上で調べられる。

これらの到達点を支える基盤として、[第I部](README.md#第i部-lawと意味の基礎)では全議論に共通する言語・モデル・射・制限を構成する。また、[第V部](README.md#第v部-輸送比較診断)の輸送・比較・診断は、同じ変更・修復問題を異なる reading や異なる係数環のもとで追跡し、診断複体と実際の障害を比較するために位置づけられる。

## 論証の順序

基礎を固める第I部は、次の 3 章からなる。

- [第1章](part_1/chapter_1_atoms_laws_theories.md)では、Atom の共通語彙と個々の評価事実を分離し、項と正の式の構文・評価・代入を定める。正の式の保存を構文木から直接証明し、理論の射を翻訳と Law の導出によって与える。
- [第2章](part_1/chapter_2_models_and_morphisms.md)では、理論を固定した意味圏と、理論変更を伴う全体圏を構成する。さらに lens と protocol を独立に定義し、その対象とすべての射を共通言語から回復できることを示す。
- [第3章](part_1/chapter_3_contexts_and_local_models.md)では、依存関係に閉じた宣言の文脈とその制限を定め、共有データが厳密に一致する局所モデルおよび局所射を組み立てる。

ここで重要な区別が二つある。第一に、宣言の文脈による局所性と、係数空間の開集合による局所性とは異なる制限写像をもつ。第二に、宣言を有限個に限ることと、状態や問い合わせの値を有限個だけ読むこととにも明確な相違がある。第3章ではこれらを具体例とともに定式化し、後続の descent（第10章）および有限情報による再構成（第13・19章）へ橋渡しする。

本書の各章は原則として、原始入力の指定、そこから構成される対象と写像、そしてそれらについて証明される性質、という順序で記述する。証明を与えた主張を定理・命題・補題・系と呼び、一般的な結論を将来の課題として残す箇所は「問題」として明記する。全体で用いる記号の一覧と使い分けは[共通記号](notation.md)にまとめている。

## 同じ対象と写像を結ぶ四つの接続

本書の各部は独立した話題の寄せ集めではなく、同じ原始的な対象と写像を四つの軸で結びつけている。

| 接続 | 構成と参照 |
| --- | --- |
| 意味と幾何 | 第4–7章では、独立に与えた状態・操作・すべての射を、係数上の実現とその幾何的表示へ送る。台帳モデルにおけるすべての線形比較は例8.7で、同じ係数とすべての比較射の読み戻しは例19.6で確かめる。 |
| 変更と障害 | 第11章では、実際の辺の比から補正と射影の核を構成し、同じ面の欠陥（defect）を消す修復の全体を分類する。第12章では、固定した周囲環における残差を持ち上げの障害へ送る。 |
| 修復と観測 | 第16章では、実際の障害と診断複体の類を比較し、第17章では状態観測と Law 評価から実現族上の観測を構成する。第18章では、同じ補正方程式の余核と右辺を用いて、判定に必要な情報と具体的な数値補正に必要な情報を分離する。 |
| 局所と大域 | 第3・10・13章では、対象とすべての射の局所からの組み立てを構成し、第19章でそれを固定条件をもつ解の全体族へ適用する。すべての有限断片の整合、有限決定、および有限次数試験を、それぞれ適切な条件のもとで調べる。 |

本書を通して繰り返し現れる代表例として、台帳モデルでは公開の読み取りと係数問い合わせを、有限アフィン網では許可範囲と未知入力を、無限 protocol ではすべての有限断片と整合する大域解を追跡する。これらの具体例について原始入力と写像を各章で保持し続けることにより、条件を満たす変更の存在、具体的な解の選択、および解の全体の回復を、同一の問題の上で直接比較できるようになっている。なお、変更経路に費用を加えた最適選択の問題は、[付録E](appendix_e_change_paths_and_costs.md)で扱う。
