# 序論

同じ状態を読み取る二つの仕組みであっても、更新後の振る舞いは異なりうる。読み取りを保つ写像に「更新操作も保つ」という条件を加えると、許される変更の集合は大きく変わる。さらに、変更してはならない固定部分、局所的に変更できる範囲、そして満たすべき Law を指定すると、その集合の中から一つの具体的な変更問題が定まる。AAT は、このように条件から対象と射を構成し、それらの全体がもつ構造を調べる数学理論である。

理論の出発点は、共通の Atom 語彙、署名、および Law である。署名は型（sort）と名前付きの操作・関係・量を宣言し、Law はその入力と充足条件を定める。モデルは各型に担体となる集合を、各操作に具体的な写像を割り当てる。観測は、こうして与えられた構造から値を読む写像として表される。モデルの間の射には、操作を運ぶこと、関係と部分操作の定義域を保つこと、そして選ばれた観測と可換であることを課す。

この構成の順序には二つの側面がある。問いを立てる際には、まず保ちたい Law に基づいて必要な観測を選ぶ。一方、数学的な定義の段階では、その Law を評価するための型・操作・入力を先に定める。「Law に基づいて観測する」という選択の順序と、「構造を定義してから評価する」という論証の順序が、ここで一つに結びつく。

## 生成操作からすべての実行へ

本書で最初に得る保存定理は極めて具体的である。状態集合の間の写像 $`h:A\to B`$ が、各全域の名前付き操作と可換であり、観測についても $`o_B\circ h=o_A`$ を満たすとする。このとき、任意の有限操作語 $`w`$ に対して

```math
o_B\bigl(w_B(h(a))\bigr)=o_A\bigl(w_A(a)\bigr)
```

が成り立つ。[第2章の定理2.6](part_1/chapter_2_models_and_morphisms.md#24-すべての操作語への保存の延長)では、この等式を操作語に関する帰納法で証明し、さらに部分操作の定義域や操作語の翻訳を含む形へ拡張する。ここで写像 $`h`$ は単射である必要も全射である必要もない。したがって、複数の状態を一つにまとめる変更も、補助的な状態を追加する変更も、まったく同じ保存条件のもとで統一的に調べられる。

この基本定理は、変更の存在や構造を分類する後続の議論に確かな意味を与える。条件を満たす射を一つ構成できれば、その射がどの実行列を運び、観測上で何を保つかがただちに分かる。さらに、そのような射をすべて集めれば、同じ条件を満たす変更の全体を統一的に扱えるようになる。

## 四つの到達点

本書は、次の四つの到達点に向けて議論を積み上げる。

**1. 条件を満たす変更の全体の構成.**
[第II–III部](README.md#第ii部-実現の族とlawの幾何)では、意味の対象と射を係数環上に実現し、実現の族、意味を保つ変更の全体がなす族、および変更の合成を構成する。変更元、固定部分、許容規則、評価条件を指定したとき、それらを満たすすべての変更を求めることが目標である。幾何的な表示を与える際には、適切な係数や設定のもとでその点と射から元の意味の対象・射を回復する比較写像を併せて与える。座標環を構成できる場合の相対 $`\mathrm{Spec}`$、局所チャートによる表示、および同型射を含む族（groupoid やスタック）を、それぞれに必要な仮定のもとで使い分ける。

**2. 修復の全体と障害の構造.**
[第IV部](README.md#第iv部-局所変更修復障害)では、局所的な変更を大域的に組み立てるための整合条件と、Law を回復させる具体的な補正を扱う。固定部分と変更を許す範囲から許容される補正を定め、その作用を通じて、修復の存在条件、異なる修復どうしの再同定、および修復の後に残る自由度を明らかにする。また、局所解が存在するときに大域解へ進めるための条件と、その妨げとなる障害も、同じ原始データから導出する。

指定された目標修復を持ち上げる問題では、比較写像の錐から存在・同型類・自己同型を同時に読み取る。さらに、すべての欠陥に対して修復 groupoid 全体を回復する条件を、同じ比較の低次数コホモロジーで特徴づける。整数係数では、実調和代表と有限個の素数冪での検査を組み合わせ、ねじれを含む指定障害の零性を判定する。

**3. 観測と必要情報.**
[第VI部](README.md#第vi部-観測と必要情報)では、同じ変更・修復問題について、目的の出力に十分な観測を選ぶ。第17章で、可否判定・量・個別の解・同型類・解の全体という出力を区別し、観測ファイバー上での十分性と共通解の選択を調べる。[第18章の定理18.4](part_6/chapter_18_repair_and_observation.md#183-既知情報を条件とする十分性)は、一つの具体的な補正方程式に対して二つの核条件を与える。入力族・既知情報・要求する出力を固定したうえで、許容補正で吸収できる方向を除いた残存障害を決める情報と、具体的な補正値を指定するための右辺の情報を、それぞれの核条件として調べる。

構造パラメータを動かす修復方程式については、十分な問い合わせ集合と最適問い合わせ数が一定になる構成可能分割を与える。修復範囲の拡大が判定情報をどう変えるかは、凍結した部分の双対完全列と保存則によって同じ補正複体の上で調べる。また、適応的な問い合わせと問い合わせごとの費用を扱い、得られた観測から実際の修復へ戻る手続きを構成する。

**4. 再構成と有限決定.**
[第VII部](README.md#第vii部-再構成と有限決定)では、原始的な局所表に全域性・Law・制限の整合条件を課し、対象と射を組み立てる。解の全体を局所的な読み取りから回復するのが[第19章の定理19.5](part_7/chapter_19_reconstruction_from_local_models.md#193-条件付き変更と修復全体の相対再構成)である。ここでは、対象・可逆とは限らない一般の射・合成を復元し、許容規則、固定部分の同定、および評価条件を保存・反映することを示す。元の（native）モデルには定理19.2を用い、加群・層・局所的に分裂する複製余代数・自然多項式の係数族には、局所表と逆構成を与える定理19.2aを用いる。これらを通じて、第8章の条件付き変更の全体と、第11章の正則作用モデルを経由する修復の全体とを、すべての比較射に至るまで回復できる。

[第20章](part_7/chapter_20_finite_determination_and_minimal_realizations.md)では、内部輸送が恒等である protocol の有限決定に操作グラフの連結成分条件を用い、すべての解を実際に計算する算法には指定範囲の有限表または実効的な有限行列の条件を用いる。有限個の単項線形操作を持つ総階数 $`N\ge1`$ の有限局所自由実現では、到達写像と双対観測写像の全射性のもとで、長さ $`2N-1`$ 以下の公開評価から一意な同型まで実現を復元する。この有限ハンケル表による再構成は、生成元からの商を使ったモジュライ表示とも整合する。[第21章](part_7/chapter_21_uniform_finiteness_of_polynomial_operations.md)では、与えられた全域多項式操作と残差について、全語での残差消滅を有限語で判定し、安全状態スキームを構成する。

これらの到達点を支える基盤として、[第I部](README.md#第i部-lawと意味の基礎)では全議論に共通する言語・モデル・射・制限を構成する。また、[第V部](README.md#第v部-輸送比較診断)の輸送・比較・診断は、同じ変更・修復問題を異なる reading や異なる係数環のもとで追跡し、診断複体と実際の障害を比較するために位置づけられる。

## 多変更・将来要求・有限計算への展開

二つずつの変更が可能でも、三つを同時に実現できるとは限らない。[定理12.16](part_4/chapter_12_deformations_and_obstructions.md#128-二変更の混合障害と三重持ち上げ)は、原始Lawの混合係数からペアの障害を作り、ペア補正を選び直す自由度を含む三重障害集合を構成する。その集合が零を含むことが、三つの平方零方向の持ち上げに必要十分となる。非可換な自己同型を持つ重なりでは、命題12.18が共役と補正式を保持した貼り合わせを与える。

同じ現在の公開挙動を持つ実現でも、将来要求への応答は異なる。[12.10節](part_4/chapter_12_deformations_and_obstructions.md#1210-指定要求の持ち上げと滑らかな開集合)では要求の係数と内部係数を分け、指定要求の残差を相対ヤコビ写像の余核で測る。標準的な滑らかなチャートでは補正を実際に構成し、Hensel局所環と完備局所環では指定した解を持ち上げる。Fittingイデアルの基底変更と単純根の議論は付録Cで証明する。

部分的な観測から得た不能証拠については、[定理11.24](part_4/chapter_11_ariadne_relative_repairs.md#1112-部分観測の不能証拠と任意の外部への置換)が微分・残差・許可補正の制限から全体での不能性を導く。系11.25の共有宣言と閉被覆を保つ内部置換、および[定理18.20・18.21](part_6/chapter_18_repair_and_observation.md#1810-有限候補の重み付き観測)の重み付き問い合わせは、どこまで確定し何を追加で読むべきかを同じ修復問題から導く。

全域多項式操作については、[定理21.3](part_7/chapter_21_uniform_finiteness_of_polynomial_operations.md#213-普遍係数と計算可能な一様語長)が、状態変数数・操作数・操作次数・残差次数だけに依存する計算可能な語長 $`B(N,m,d,d_0)`$ を、普遍係数環の Noether 性と恒等式の有限探索から構成する。[定理21.4](part_7/chapter_21_uniform_finiteness_of_polynomial_operations.md#214-最大安全状態スキームと係数変更)はこの上界を任意の可換環と試験代数に適用し、根基を取らない最大不変閉部分スキームを与える。ガード付きの操作には同じ一様性が成り立たないことも具体例で示す。

最後に、[付録E](appendix_e_change_paths_and_costs.md)では一段変更の規則から同時変更数と一時接続資源を分け、有限移行の資源下限とその達成を証明する。有限状態グラフでは零費用閉路を含むすべての最適語を回復し、時間を含む有限の局所表ではmin-plusの費用合成と原始比較射の組み立てにより最適経路groupoidを復元する。

これらの証明の依存は、付録Cから第12章へ、第11章の修復から第18章へ進む。第21章では普遍係数による一様語長を先に構成し、その後で安全状態スキームを導く。定理E.6は第8章の経路、第19章の再構成、および第20章の有限列挙を用いる。第6章と第17章が先行参照する第20章の線形最小実現の構成と証明は、その両章に依存しない。後の章への問題の案内は証明の前提にせず、同じ定理を相互に引用して証明する循環を作らない。


## 論証の順序

基礎を固める第I部は、次の 3 章からなる。

- [第1章](part_1/chapter_1_atoms_laws_theories.md)では、Atom の共通語彙と個々の評価事実を分離し、項と正の式の構文・評価・代入を定める。正の式の保存を構文木から直接証明し、理論の射を翻訳と Law の導出によって与える。
- [第2章](part_1/chapter_2_models_and_morphisms.md)では、理論を固定した意味圏と、理論変更を伴う全体圏を構成する。さらに lens と protocol を独立に定義し、その対象とすべての射を共通言語から回復できることを示す。
- [第3章](part_1/chapter_3_contexts_and_local_models.md)では、依存関係に閉じた宣言の文脈とその制限を定め、共有データが厳密に一致する局所モデルおよび局所射を組み立てる。

ここで重要な区別が二つある。第一に、宣言の文脈による局所性と、係数空間の開集合による局所性とは異なる制限写像をもつ。第二に、宣言を有限個に限ることと、状態や問い合わせの値を有限個だけ読むこととにも明確な相違がある。第3章ではこれらを具体例とともに定式化し、後続の descent（第10章）、有限断片の整合族からの再構成（第13・19章）、および有限決定（第20章）へ橋渡しする。

本書の各章は原則として、原始入力の指定、そこから構成される対象と写像、そしてそれらについて証明される性質、という順序で記述する。証明を与えた主張を定理・命題・補題・系と呼び、一般的な結論を将来の課題として残す箇所は「問題」として明記する。全体で用いる記号の一覧と使い分けは[共通記号](notation.md)にまとめている。

## 同じ対象と写像を結ぶ四つの接続

四つの到達点へ至る論証では、同じ原始的な対象と写像を次の四つの接続に沿って追跡する。それぞれの接続は複数の部にまたがり、構成した対象や比較を後続の問いへ引き渡す。

| 接続 | 構成と参照 |
| --- | --- |
| 意味と幾何 | 第4–7章では、独立に与えた状態・操作・すべての射を、係数上の実現とその幾何的表示へ送る。台帳モデルにおけるすべての線形比較は例8.7で、同じ係数とすべての比較射の読み戻しは例19.6で確かめる。 |
| 変更と障害 | 第11章では、実際の辺の比から補正と射影の核を構成し、同じ面の欠陥（defect）を消す修復の全体を分類する。第12章では、固定した周囲環における残差を持ち上げの障害へ送る。 |
| 修復と観測 | 第16章で実際の障害と診断複体の類を比較し、第VI部へ渡す。第17章では状態観測と Law 評価から実現族上の観測を構成し、第18章では同じ補正方程式の余核と右辺を用いて、判定に必要な情報と具体的な数値補正に必要な情報を分離する。 |
| 局所と大域 | 第3・10・13章で対象とすべての射の局所からの組み立てを構成し、第VII部へ渡す。第19章で固定条件をもつ解の全体族を再構成し、第20章で有限決定・有限次数試験・有限公開語からの復元を調べる。第21章では、普遍係数の恒等式から全語判定の一様有限性を導く。 |

本書を通して繰り返し現れる代表例として、台帳モデルでは公開の読み取りと係数問い合わせを、有限アフィン網では許可範囲と未知入力を、無限 protocol ではすべての有限断片と整合する大域解を追跡する。これらの具体例について原始入力と写像を各章で保持し続けることにより、条件を満たす変更の存在、具体的な解の選択、および解の全体の回復を、同一の問題の上で直接比較できるようになっている。なお、変更経路に費用を加えた最適選択の問題は、[付録E](appendix_e_change_paths_and_costs.md)で扱う。
