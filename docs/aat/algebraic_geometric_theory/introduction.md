# 序論

同じ状態を読み取る二つの仕組みでも、更新後の振る舞いは異なりうる。
読取りを保つ写像に、更新を保つ条件を加えると、許される変更の集合が変わる。
さらに、固定すべき部分、局所的に変更できる範囲、満たしたいLawを指定すると、
その集合の中から一つの変更問題が定まる。
AATは、このように条件から対象と射を構成し、それらの全体を調べる。

出発点は、共通のAtom語彙、署名、Lawである。署名は型と名前付きの操作・関係・量を宣言し、
Lawはその入力と充足条件を定める。モデルは各型に集合を、各操作に実際の写像を与える。
観測は、こうして与えられた構造から値を読む写像である。
モデルの間の射には、操作を運ぶこと、関係と定義域を保つこと、
選ばれた観測と可換することを課す。

この順序には二つの意味がある。問いを立てる際には、保ちたいLawから必要な観測を選ぶ。
数学的な定義では、そのLawを評価するための型・操作・入力を先に定める。
「Lawに基づいて観測する」という選択の順序と、
「構造を定義してから評価する」という論証の順序が、ここで結びつく。

## 生成操作から全実行へ

最初の保存定理は具体的である。状態間の写像 $h:A\to B$ が各全域の名前付き操作と可換し、
観測について $o_Bh=o_A$ を満たすとする。すると、任意の有限操作語 $w$ に対して

```math
o_B\bigl(w_B(h(a))\bigr)=o_A\bigl(w_A(a)\bigr)
```

が成り立つ。[第2章の定理2.6](part_1/chapter_2_models_and_morphisms.md#24-全操作語への保存の延長)では、
この式を語の帰納法で証明し、部分操作の定義域と操作語の翻訳を含む形に拡張する。
$h$ は非単射でも非全射でもよい。状態をまとめる変更も、補助状態を加える変更も、
同じ保存条件で調べられる。

この結果は、変更の存在を分類する後続の議論に具体的な意味を与える。
条件を満たす射を一つ構成できれば、その射がどの全実行を運び、何を観測上保つかが分かる。
射をすべて集めれば、同じ条件を満たす変更の全体を扱える。

## 三つの到達点

**条件を満たす全変更の構成。**
[第II–III部](README.md#第ii部-実現の族とlawの幾何)では、意味の対象と射を係数上に実現し、
実現の族、全変更の族、合成を構成する。変更元、固定部分、許容規則、評価条件を指定したとき、
それらを満たす全変更を求める。幾何による表示は、その点と射から元の意味の対象・射を
回復する比較とともに与える。座標環を構成できる場合の相対Spec、
局所表示、同型を含む族を、それぞれに必要な仮定の下で用いる。

**全修復と障害の構造。**
[第IV部](README.md#第iv部-局所変更修復障害)では、局所の変更を組み立てる際の整合条件と、
Lawを回復させる実際の補正を扱う。固定部分と変更範囲から許容補正を定め、
補正の作用から修復の存在、修復間の再同定、残る自由度を求める。
局所解があることから大域解へ進むための条件も、同じデータについて問う。

**必要情報と変更問題の再構成。**
[第VI部](README.md#第vi部-観測必要情報再構成)では、同じ変更・修復問題に対して、
可否を判断する情報、具体的な補正を選ぶ情報、全解を回復する情報を区別する。
第18章で中心になるのは、一つの実補正方程式に対する二つの核条件である。
許容補正で吸収できる方向を除いた残存障害を決める情報と、
具体的な補正値を指定するための右辺の情報を、それぞれ調べる。
入力族・既知情報・要求する出力を固定してから、この相違を述べる。

以上は後続の問いと結果の予告である。第I部では、それらの議論が共通に用いる
言語、モデル、射、制限を構成する。
[第V部](README.md#第v部-輸送比較診断)の輸送・比較・診断は、
同じ問題を異なるreadingや係数の下で追うために位置づける。

## 論証の順序

[第1章](part_1/chapter_1_atoms_laws_theories.md)では、
Atomの共通語彙と個々の事実を分け、式の構文・評価・代入を定める。
正の式の保存を構文から証明し、理論の射を翻訳とLaw導出で与える。
[第2章](part_1/chapter_2_models_and_morphisms.md)では、
固定理論の意味圏と、理論変更を伴う全体圏を構成する。
lensとprotocolを独立に定義し、その対象と全ての射を共通言語から回復する。
[第3章](part_1/chapter_3_contexts_and_local_models.md)では、
依存に閉じた宣言の文脈と制限を定め、共有データが厳密に一致する局所モデル・射を組み立てる。

この宣言の局所性と、係数空間の開集合による局所性には別の制限写像がある。
また、宣言を有限個にすることと、状態・queryの有限個の値だけを読むことにも相違がある。
第3章で両者を具体例とともに定め、後続のdescentと有限情報による再構成へ渡す。

各章では、原始入力、そこから構成する対象・写像、それらについて証明する性質を順に述べる。
証明を与えた主張を定理・命題と呼び、求める一般的な結論を残す箇所は問題として記す。
全体の記号は[共通記号](notation.md)にまとめる。
