# 付録B 係数・アフィン構成・descent

この付録では、第II部（第4章〜第6章）で用いる代数的構成と、局所データから大域対象を組み立てる descent の基礎事項をまとめる。環の Spec には素イデアルの Zariski 位相と局所化による構造層を用いる。準連接加群とは、各アフィン開集合 $`\mathrm{Spec}\,R`$ 上である $`R`$-加群 $`N`$ から作られる層 $`\widetilde N`$ と同型になる加群層をいい、基本開集合上では $`\widetilde N(D(f))=N_f`$ で与えられる。これらの局所化は、分母を揃える計算によって層の一致条件と貼り合わせ条件を満たす。

## B.1 係数とアフィン構成

まず、第4章の複製方式で用いる開閉分割と冪等元の対応、第5章の量モデルの表現に用いる多項式環・対称代数・Spec の普遍性、および第6章の相対幾何で用いる係数変更の可換性を示す。

**補題B.1（開閉分割と冪等元）.**
可換環 $`R`$ の冪等元 $`e`$ と $`\mathrm{Spec}\,R`$ の開閉集合は、対応 $`e\mapsto D(e)`$ によって一対一に対応する。さらに、有限個の互いに素な開閉集合による $`\mathrm{Spec}\,R`$ の分割は、和が 1 である互いに直交する冪等元の有限族と一対一に対応する。

**証明.**
$`e`$ が冪等元ならば $`e(1-e)=0`$ かつ $`e+(1-e)=1`$ であるから、各素イデアルは $`e`$ と $`1-e`$ のちょうど一方のみを含み、$`D(e)`$ の補集合は開集合 $`D(1-e)`$ となる。よって $`D(e)`$ は開閉集合である。

逆に、開閉集合 $`W\subseteq\mathrm{Spec}\,R`$ が与えられたとき、$`W`$ 上の定数切断 1 と補集合上の定数切断 0 を貼り合わせて大域切断 $`e\in R=\Gamma(\mathrm{Spec}\,R,\mathcal O)`$ を得る。$`e^2-e`$ は各局所環で 0 となるため $`e^2=e`$ であり、かつ $`D(e)=W`$ が成り立つ。同じ開閉集合 $`W`$ を与える二つの冪等元は各局所環で同じ値（0 または 1）を取るため等しい。互いに素な有限開閉分割についても、対応する冪等元どうしの積は局所的に 0、和は局所的に 1 となるため大域でも直交性と和 1 が従う。逆方向も各素イデアルで値を読むことで同様に確認できる。□

**補題B.2（任意集合の多項式・対称代数・Spec）.**
任意の小さい集合 $`L`$ に対し、多項式環 $`k[t_l\mid l\in L]`$ は有限の台（サポート）を持つ指数関数 $`\nu:L\to\mathbb N`$ による単項式を基底とする自由 $`k`$-加群として構成できる。積を指数の和で定めると、任意の $`k`$-代数 $`R`$ について自然な全単射

```math
\mathrm{Hom}_{k\text{-}\mathrm{Alg}}(k[t_l],R)\cong R^L
```

が成り立つ。また、任意の $`k`$-加群 $`Q`$ に対しても、可換テンソル代数（対称代数）$`\mathrm{Sym}_k Q`$ は自然な全単射

```math
\mathrm{Hom}_{k\text{-}\mathrm{Alg}}(\mathrm{Sym}_k Q,R)
 \cong\mathrm{Hom}_k(Q,R)
```

を満たす。さらに、任意の $`k`$-スキーム $`T`$ と可換 $`k`$-代数 $`B`$ に対し、自然な全単射

```math
\mathrm{Hom}_k(T,\mathrm{Spec}\,B)
 \cong\mathrm{Hom}_{k\text{-}\mathrm{Alg}}(B,\Gamma(T,\mathcal O_T))
```

が成り立つ。

**証明.**
多項式環については、各多項式の和と各単項式の積がいずれも有限和・有限積であるため、変数への値の割当て $`(r_l)_{l\in L}\in R^L`$ を代入することで $`k`$-代数射が定まる。任意の $`k`$-代数射は生成元 $`t_l`$ の像で一意に決まるため、第一の全単射を得る。

対称代数 $`\mathrm{Sym}_k Q`$ は、テンソル代数を $`u\otimes v-v\otimes u`$ の形の元が生成する両側イデアルで割って構成する。線形写像 $`Q\to R`$ は純テンソルを値の積へ送ることでテンソル代数からの環射を与え、$`R`$ の可換性により商 $`\mathrm{Sym}_k Q`$ を経由する。逆写像は次数 1 成分 $`Q\hookrightarrow\mathrm{Sym}_k Q`$ への制限で与えられる。

最後の主張では、環射 $`B\to\Gamma(T,\mathcal O_T)`$ を $`T`$ の各アフィン開集合 $`W=\mathrm{Spec}\,R`$ へ制限し、素イデアルの逆像と局所化の環射によってスキーム射 $`W\to\mathrm{Spec}\,B`$ を構成する。二つのアフィン開集合の重なりをアフィン開集合で覆えば、同じ大域切断の制限を用いているため局所射が一致して貼り合い、スキーム射 $`T\to\mathrm{Spec}\,B`$ を得る。逆にスキーム射は大域切断の引き戻し環射を与える。これらはアフィン開集合上で互いに逆なので、一般の $`T`$ 上でも互いに逆となる。□

**補題B.3（係数変更と方程式）.**
任意の環射 $`R\to R'`$ に対し、直和、テンソル積、余核、および対称代数は、それぞれの標準的な構成による自然な同型の下で係数変更 $`-\otimes_R R'`$ と可換する。特に、$`A`$ が $`R`$-代数で $`I=(f_i)\subseteq A`$ がイデアルならば、自然な同型

```math
(A/I)\otimes_R R'
 \cong (A\otimes_R R')/(f_i\otimes 1\mid i)
```

が成り立つ。

**証明.**
直和の元は有限和なのでテンソルの双線形関係とそのまま交換できる。テンソル積の結合同型は純テンソルの括弧を移す写像とその逆によって与えられる。余核は生成元を関係式で割る構成であり、テンソル積の右完全性によりテンソル後も同じ関係の像で割った商に同型となる。対称代数の可換性は、補題B.2の普遍性を任意の $`R'`$-代数を試験対象として両辺に適用するか、あるいはテンソル代数の生成元と可換性関係式を直接運ぶことで得られる。最後の式も、両辺からの $`R'`$-代数射がいずれも、すべての $`f_i`$ を 0 へ送る環射 $`A\to C`$ と $`R'\to C`$ の対（$`R`$ 上で整合するもの）を表すことから従う。以上の議論は任意の環射に対して成り立ち、平坦性は用いない。□

この補題の最後の式では、加群 $`I\otimes_R R'`$ の $`A\otimes_R R'`$ への **像**（これが定めるイデアル）を用いている点に注意する。写像 $`I\otimes_R R'\to A\otimes_R R'`$ が単射であるかどうかは別の条件である。原始的な残差の生成元 $`f_i`$ を保持しておけば、任意の係数変更の下でその像が生成するイデアルを直接構成できる。

## B.2 忠実平坦な係数descent

第6章で加群や演算の族が fppf スタックをなすことを証明するためには、忠実平坦な環射に沿う加群と射の有効 descent が不可欠である。まず基礎定義を置く。

環射 $`A\to B`$ が **忠実平坦** であるとは、関手 $`B\otimes_A-`$ が完全であり、かつ $`B\otimes_A M=0`$ から $`M=0`$ が従うことをいう。完全性と忠実性により、$`A`$-加群の写像が単射・全射・同型であることは、$`B`$ をテンソルした後に検査できる。

$`B`$-加群 $`N`$ の **descent データ（descent datum）** とは、$`B\otimes_A B`$-線形同型

**式(B.1)**

```math
\theta:N\otimes_A B\xrightarrow{\sim}B\otimes_A N
```

であって、三重テンソル上でコサイクル（cocycle）条件 $`\theta_{12}\theta_{01}=\theta_{02}`$ を満たすものをいう。ここで、左辺 $`N\otimes_A B`$ では第一因子の $`B`$ が $`N`$ に作用し、右辺 $`B\otimes_A N`$ では第二因子の $`B`$ が $`N`$ に作用するものとし、添字は三重テンソルにおいて $`N`$ を置く位置を示す。descent データの射とは、同型 $`\theta`$ と可換する $`B`$-線形写像をいう。

**補題B.4（加群とすべての写像の有効 descent）.**
忠実平坦な環射 $`A\to B`$ について、$`A`$-加群の圏と、$`B`$-加群の descent データの圏とは圏同値である。descent データ $`(N,\theta)`$ から降下して得られる $`A`$-加群 $`M`$ と比較同型は、

**式(B.2)**

```math
M=\{n\in N\mid\theta(n\otimes 1)=1\otimes n\},
\qquad B\otimes_A M\xrightarrow{\sim}N,\quad b\otimes m\longmapsto bm
```

によって与えられる。

**証明.**
まず $`\rho:N\to B\otimes_A N`$ を $`\rho(n)=\theta(n\otimes 1)`$ と置く。$`\theta`$ の $`B\otimes_A B`$-線形性から $`\rho(bn)=(b\otimes 1)\rho(n)`$ が成り立つ。コサイクル条件 $`\theta_{12}\theta_{01}=\theta_{02}`$ を、三つの係数を一致させる対角射 $`B\otimes_A B\otimes_A B\to B`$ へ引き戻すと、得られる自己同型 $`a:N\to N`$ は $`a^2=a`$ を満たすため恒等射でなければならない。これから二つの基本恒等式

**式(B.3)**

```math
\mu\rho=\mathrm{id}_N,\qquad
(1\otimes\rho)\rho(n)=\sum_i b_i\otimes 1\otimes n_i
\quad\left(\rho(n)=\sum_i b_i\otimes n_i\right)
```

を得る。ここで $`\mu(b\otimes n)=bn`$ であり、第二式は $`n\otimes 1\otimes 1`$ においてコサイクル条件を評価した式である。

次に、式(B.2)の写像 $`\mu:B\otimes_A M\to N`$ が同型であることを示す。定義により $`M`$ は二つの $`A`$-線形写像 $`\rho`$ と $`n\mapsto 1\otimes n`$ の等化子である。$`A\to B`$ の平坦性により、$`B\otimes_A M`$ は $`B\otimes_A N\rightrightarrows B\otimes_A B\otimes_A N`$ の等化子となる。式(B.3)の第二式より任意の $`n\in N`$ に対して $`\rho(n)`$ はこの等化子に属するため、$`B`$-線形写像 $`\beta:N\to B\otimes_A M`$ が定まる。式(B.3)の第一式から $`\mu\beta=\mathrm{id}_N`$ が成り立ち、また $`m\in M`$ に対して $`\rho(bm)=(b\otimes 1)(1\otimes m)=b\otimes m`$ であるから $`\beta\mu=\mathrm{id}_{B\otimes_A M}`$ が成り立つ。よって式(B.2)は同型であり、同じ式から descent データとも整合する。

逆に、元の $`A`$-加群 $`M_0`$ から出発して拡張加群 $`B\otimes_A M_0`$ に標準の descent データ（二つの引き戻しを係数因子の移動で同一視したもの）を付けたとき、その等化子が $`M_0`$ に一致することを確かめる。そのためには列

```math
0\longrightarrow M_0\longrightarrow B\otimes_A M_0
\rightrightarrows B\otimes_A B\otimes_A M_0
```

の完全性を示せばよい。この列に左からもう一度 $`B`$ をテンソルし、最初の写像を $`i'(b\otimes m)=b\otimes 1\otimes m`$、次の二つの射の差を $`d'(b_0\otimes b_1\otimes m)=b_0\otimes b_1\otimes 1\otimes m-b_0\otimes 1\otimes b_1\otimes m`$ と置く。次数ごとの写像

```math
s_0(b_0\otimes b_1\otimes m)=b_0 b_1\otimes m,\qquad
s_1(b_0\otimes b_1\otimes b_2\otimes m)=b_0 b_1\otimes b_2\otimes m
```

は $`s_0 i'=\mathrm{id}`$ および $`s_1 d'=i' s_0-\mathrm{id}`$ を満たす。したがって $`i'`$ は単射であり、$`d'(z)=0`$ ならば $`z=i's_0(z)`$ となるため、テンソル後の列は完全である。忠実平坦性はこの完全性を元の列へ反映するため、等化子は正確に $`M_0`$ に一致する。

最後に射の対応を確認する。descent データの射 $`f:(N,\theta)\to(N',\theta')`$ は式(B.2)の等化子 $`M`$ を $`M'`$ へ送るため、制限によって $`A`$-線形写像 $`M\to M'`$ を誘導し、そのテンソル拡張は式(B.2)の同型の下で元の射 $`f`$ に一致する。逆に、任意の $`A`$-線形射のテンソル拡張は標準の descent データと可換する。これら二つの構成も互いに逆であり、恒等射と合成を保つ。□

続いて、第6章で用いる有限局所自由性・階数・テンソル演算・構造保存射がすべて同じ descent で降下することを確認する。

**補題B.5（有限局所自由性、テンソルと演算）.**
補題B.4の状況において、$`N`$ が有限局所自由 $`B`$-加群ならば、降下した $`A`$-加群 $`M`$ も有限局所自由であり、一定階数 $`n`$ もそのまま降下する。さらに、テンソル積、線形・多重線形演算、指定元、同じ型のテンソル式の等号、およびそれらを保つすべての写像も同じ descent によって降下する。

**証明.**
第一に、アフィン上の有限局所自由 $`B`$-加群 $`N`$ が有限表示かつ平坦であることを分母払いで確認する。$`\mathrm{Spec}\,B`$ を覆う有限個の基本開集合 $`D(f_i)`$ 上で $`N_{f_i}`$ の有限基底を取り、分母を払って $`N`$ の元へ持ち上げたものを集めると、$`B`$-線形写像 $`B^r\to N`$ を得る。この写像の余核は各 $`f_i`$ で局所化すると 0 であり、各元を消す $`f_i`$ の冪は単位イデアルを生成するため余核自体が 0（すなわち全射）である。この全射の核を $`K`$ とすると、各 $`K_{f_i}`$ は有限自由加群への分裂全射の核なので有限生成である。その生成元の分母を払って集めれば同じ議論で $`K`$ も有限生成となり、$`N`$ は有限表示である。また、任意の単射を $`N`$ とテンソルしたときの核も各 $`f_i`$ で局所化すれば 0 になるため、$`N`$ は平坦である。

第二に、忠実平坦な環射 $`A\to B`$ に沿って有限生成性・有限表示性・平坦性を降下する。$`B\otimes_A M\cong N`$ の有限個の生成元をそれぞれ有限個の純テンソルの和で書き、そこに現れる $`M`$ の元の有限集合が生成する部分加群を $`M'\subseteq M`$ と置く。すると $`B\otimes_A(M/M')=0`$ なので忠実性から $`M=M'`$ となり、$`M`$ は有限生成である。次に全射 $`A^r\twoheadrightarrow M`$ の核を $`K`$ とする。平坦性により $`B\otimes_A K`$ は全射 $`B^r\twoheadrightarrow N`$ の核であり、$`N`$ の有限表示性から有限生成である。今の議論を $`K`$ に適用すれば $`K`$ も有限生成となり、$`M`$ は有限表示である。さらに、任意の単射 $`L\hookrightarrow L'`$ に $`M`$ をテンソルした写像は、さらに $`B`$ をテンソルすれば $`N`$ の平坦性によって単射となるため、忠実性から元の写像も単射であり、$`M`$ は平坦である。

第三に、有限表示かつ平坦な $`A`$-加群 $`M`$ が局所自由であり、一定階数 $`n`$ を引き継ぐことを確認する。各素イデアル $`\mathfrak p\in\mathrm{Spec}\,A`$ に対し、局所環 $`A_{\mathfrak p}`$ の残差体 $`\kappa(\mathfrak p)`$ 上の基底を $`M_{\mathfrak p}`$ の有限個の元へ持ち上げると、中山の補題（Nakayama の補題）によりこれらは $`M_{\mathfrak p}`$ を生成する。得られる全射の核は有限生成であり、$`M_{\mathfrak p}`$ の平坦性により残差体でテンソルしても短完全列のまま保たれる。残差体上では基底を選んだため核のテンソルは 0 となり、もう一度中山の補題を適用して核は 0 となる（ここで中山の補題は、有限生成元の関係行列 $`I-C`$ の行列式が局所環の単元になることから従う）。有限表示性により、この有限個の生成元と関係の等号はある $`f\notin\mathfrak p`$ に対する基本開集合 $`D(f)`$ 上で成立するため、$`M`$ はその近傍で有限自由である。また忠実平坦射 $`\mathrm{Spec}\,B\to\mathrm{Spec}\,A`$ は全射であり、残差体の拡大の下で有限次元ベクトル空間の次元は不変なので、$`N`$ の一定階数 $`n`$ がそのまま $`M`$ の階数になる。

なお、アフィン上の有限局所自由加群は有限射影加群でもある（第6章の核表示の係数変更で用いる）。実際、有限個の基本開集合上で基底と双対基底を選び分母を払うと、各被覆元の十分大きな冪を掛けた恒等写像が有限個の写像 $`m\mapsto\lambda(m)v`$ の和として表せる。これらの冪は単位イデアルを生成するため、適切な係数を掛けて足し合わせれば恒等写像自身がそのような有限和になり、この双対基底の式が有限自由加群からの全射に右逆を与えて射影性を示す。

最後に、テンソル積・演算・Law・射の降下を確認する。テンソル積の descent データは二つの同型 $`\theta_1,\theta_2`$ をテンソルして因子を並べ替えることで作られ、補題B.3と補題B.4の同型によりその降下は $`M_1\otimes_A M_2`$ に一致する。演算はそのテンソル積から出力加群への descent データの射であるため、補題B.4により一意に降下する。指定元も線形写像 $`A\to M`$ として同様に降下する。テンソル式の等号は、降下した二つの写像の差を $`B`$ でテンソルして 0 になることから忠実性により従う。すべての構造保存射についても同じ可換式を忠実性で検査でき、写像に全射性を課す場合もその余核がテンソル後に 0 になることで判定できる。□

## B.3 層、チャートと相対Spec

最後に、アフィン環上の descent を一般のスキーム上の fppf 被覆へ拡張し、開チャートの接着と相対 Spec の構成を確立する。

第II部で用いる係数方向の局所性は、Zariski 開被覆と fppf 位相である。アフィン底上の fppf 被覆は、平坦かつ有限表示のアフィン射（スキーム射）の共同全射族によって局所的に記述される。有限個の部分族で底が覆われるとき、対応する代数の有限直積を $`B`$ と置けば元の環から $`B`$ への射は忠実平坦である。ここでは「平坦かつ局所有限表示なスキーム射は、任意の基底変換（base change）の後も開写像である」というスキーム論の標準定理を用いる。一般の fppf 被覆をアフィンな底へ制限し、各被覆元を有限表示のアフィン射となる開集合で覆うと、それらの像は開集合として底を覆うため、底の準コンパクト性により有限個を選び出せる。この有限細分に対して補題B.4を適用できる。

この手順を底スキームの各アフィン開集合上で実行し、重なり上で同じ descent データから得られる同型を貼り合わせることで、準連接加群の fppf descent を得る。具体的には、選んだ有限細分から降下した加群を元の各被覆元へ引き戻し、さらに細分とのファイバー積上で元の加群と比較すると、その同型は補題B.4の全忠実性により一意に降下する。二つの異なる細分を選んだ場合も共通細分上の恒等射から一意な比較同型が得られ、これらの一意性が重なりでの一致と三重交差のコサイクル条件を保証する。なお Zariski 被覆については、加群層の切断を「局所切断の整合族」として直接定義する構成もでき、各アフィン開集合へ制限すれば補題B.4の等化子に一致する。さらに補題B.5を適用すれば、有限局所自由加群、原始演算、およびすべての構造保存射の descent が得られる。これが第6章における係数 descent の根拠である。

**補題B.6（開チャートの接着）.**
スキームの族 $`(U_i)`$、開部分スキーム $`U_{ij}\subseteq U_i`$、および同型 $`\varphi_{ij}:U_{ij}\xrightarrow{\sim}U_{ji}`$ が与えられ、恒等・両逆・三重交差のコサイクル条件を満たし、重なりの開集合 $`U_{ij}\cap U_{ik}`$ も $`\varphi_{ij}`$ によって $`U_{ji}\cap U_{jk}`$ へ正確に対応するとする。このとき、各 $`U_i`$ が開部分スキームとして埋め込まれるスキーム $`M`$ を構成できる。同じコサイクル条件を満たす加群層とその射の族も、$`M`$ 上の加群層とその射へ貼り合う。

**証明.**
直和 $`\coprod_i U_i`$ の点を $`x\sim\varphi_{ij}(x)`$ によって同一視する。コサイクル条件によりこれは整合する同値関係となり、同一の $`U_i`$ 内の異なる 2 点を新たに同一視することはない。商空間には各 $`U_i`$ の開集合が開集合となる位相を入れる。開集合 $`W`$ 上の構造層を、各 $`W\cap U_i`$ 上の関数の族であって重なり上で $`\varphi_{ij}`$ に関して一致するものと定めると、これは層をなし、各 $`U_i`$ への制限は元の構造層に一致する。したがって各点の局所環も元のチャートの局所環に同型であり、得られる局所環付き空間はスキームである。加群層も同様に整合切断の族として構成でき、射は各チャート上で成分ごとに作用させればよく、局所的な可換式は大域でも成り立つ。□

**補題B.7（準連接代数の相対 Spec）.**
スキーム $`T`$ 上の準連接 $`\mathcal O_T`$-代数 $`\mathcal C`$ に対し、アフィンな $`T`$-スキーム $`\mathrm{Spec}_T\mathcal C`$ を構成できる。任意のスキーム射 $`g:T'\to T`$ について自然な全単射

```math
\mathrm{Hom}_T(T',\mathrm{Spec}_T\mathcal C)
 \cong\mathrm{Hom}_{\mathcal O_{T'}\text{-}\mathrm{Alg}}(g^*\mathcal C,\mathcal O_{T'})
```

が成り立ち、この構成は任意の基底変換と可換する。

**証明.**
$`T`$ の各アフィン開集合 $`W=\mathrm{Spec}\,R`$ 上で $`\mathcal C|_W=\widetilde C`$ と表し、アフィン射 $`\mathrm{Spec}\,C\to\mathrm{Spec}\,R`$ を構成する。基本開集合 $`D(f)\subseteq W`$ への制限は局所化 $`C_f`$ に対応し、その Spec は元の Spec の対応する基本開集合である。二つのアフィン開集合の交差を基本開集合で覆えば、この局所化による同型は合成に関して整合するため、補題B.6により貼り合わせて所期の $`T`$-スキーム $`\mathrm{Spec}_T\mathcal C`$ を得る。局所的な環射の普遍性は補題B.2で与えられており、その一意性から上の全単射も貼り合わされる。基底変換はアフィン開集合上で $`C\mapsto C\otimes_R R'`$ として構成され、局所化と交換するため大域でも交換する。□

最後に、この相対 Spec の構成を fppf スタック $`\mathcal B`$ 上の準連接代数 $`\mathcal C`$ へ拡張しておく。各試験スキーム $`T\to\mathcal B`$ ごとに補題B.7の構成を施し、対象を「構造 $`b/T`$ と代数射 $`b^*\mathcal C\to\mathcal O_T`$ の対」、射を「代数射と可換する構造同型」と定めることで、相対 Spec の族を得る。底の構造 $`b`$ は $`\mathcal B`$ のスタック性によって降下し、補題B.4による加群と写像の descent、および補題B.5による乗法・単位とその保存式の descent から、代数射も一意に降下する。したがってこの族は fppf スタックをなし、構造 $`b`$ を固定したファイバーは補題B.7のアフィン $`T`$-スキームとなる。第6章の相対 Spec（定理6.10）はこの構成によって定まる。
