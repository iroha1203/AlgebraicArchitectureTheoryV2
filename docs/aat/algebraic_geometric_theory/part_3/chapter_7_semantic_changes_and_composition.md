# 第7章 意味保存変更と合成の幾何

一つの実現から別の実現へ移る変更を、状態の写像と操作の翻訳で記述する。
補助状態を忘れる写像も、操作をいくつかの段階へ分ける翻訳も、変更の対象になる。
この章では全ての意味保存射を集め、その比較、合成、係数と文脈に沿う変化を構成する。
その後に、状態射を座標で回復できる場合の幾何的表示を作る。

## 7.1 操作・観測を保つ射

**設定7.1（変更を取る意味圏）.**
文脈 $`U`$、係数環 $`R`$、理論 $`\mathbb T`$、実現方式 $`\sigma`$ を指定する。
本章の $`\mathcal A(U,R)`$ は、
[定義4.1](../part_2/chapter_4_coefficient_realizations.md#41-原始実現データと係数に沿う関手)から
構成した $`\mathcal A_{\mathbb T,\sigma}(U,R)`$、または理論変更を含む全体圏とする。
係数変更を使うときは、その方式について対象・全射・Lawの保存と
単位・合成の整合を証明済みであることを仮定する。
理論変更を含むときは、許す理論解釈の引戻しが実現方式の対象と射を保ち、
係数変更と可換するものを取る。
集合上では[構成2.5](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)をそのまま使う。
この条件を満たす方式ごとに以下の構成を行う。

固定理論の射 $`h:A\to B`$ は各sortの実写像であり、
全域操作と量の可換式、関係の保存、部分操作のdomainの保存とそこでの可換式を満たす。
固定した観測値sort $`O_s`$ については $`o_{B,s}h_s=o_{A,s}`$ を課す。
固定宣言上の射を恒等とする場合も、第2章の固定データ付き意味圏に含める。

理論変更を伴う射は

```math
(u,h):(\mathbb T,A)\longrightarrow(\mathbb T',B),
\qquad h:A\longrightarrow u^*B
```

である。$`u`$ はsort・操作term・関係・domainの翻訳とLawの導出を持つ。
関係とdomainには第1章の正の式を用いる。
これにより[定理2.4](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)が
対象だけでなく全構造保存射への $`u^*`$ の作用を与える。
合成は $`(v,k)(u,h)=(vu,u^*k\circ h)`$ である。
観測を固定する場合、翻訳でもその値sortを固定する。

例えば、状態 $`X\times Z`$ の操作を
$`(x,z)\mapsto(T_e(x),L_e(x,z))`$、観測を $`o(x,z)=o_X(x)`$ とする。
射影 $`h(x,z)=x`$ は全操作と観測を保つ。
$`X`$ が非空で $`Z`$ に異なる二元があれば、$`h`$ は非単射である。
この射も、以下で作る変更の族の一つの対象となる。

## 7.2 操作語の翻訳と部分操作

**定理7.2（翻訳された全操作語の保存）.**
型付きの名前付き単項操作と観測を持つ $`A,B`$ を取り、
sort対応 $`s\mapsto u(s)`$ と各操作 $`e:s\to t`$ の有限語翻訳
$`\tau(e):u(s)\rightsquigarrow u(t)`$ を与える。
空語も許す。状態写像 $`h_s:X_s(A)\to X_{u(s)}(B)`$ が

**式(7.1)**

```math
\begin{aligned}
h_s(D_e^A)&\subseteq\mathrm{Dom}_B(\tau(e)),\\
h_t(e_A(x))&=\tau(e)_B(h_s(x))\quad(x\in D_e^A),\\
o_{B,u(s)}h_s&=o_{A,s}
\end{aligned}
```

を満たすとする。全域操作では $`D_e^A=X_s(A)`$ と読む。
任意の型付き有限語 $`w:s\rightsquigarrow t`$ と
$`x\in\mathrm{Dom}_A(w)`$ について

```math
\begin{aligned}
h_s(x)&\in\mathrm{Dom}_B(\tau(w)),\\
h_t(w_A(x))&=\tau(w)_B(h_s(x)),\\
o_{B,u(t)}(\tau(w)_B(h_s(x)))&=o_{A,t}(w_A(x))
\end{aligned}
```

が成り立つ。さらに全生成操作で
$`D_e^A=h_s^{-1}\mathrm{Dom}_B(\tau(e))`$ なら、
$`\mathrm{Dom}_A(w)=h_s^{-1}\mathrm{Dom}_B(\tau(w))`$ である。

**証明.**
空語では両側が恒等写像なので、domainと値は一致し、最後の式は観測の可換性である。
$`w`$ の後に $`e`$ を実行できるとする。
帰納法により $`\tau(w)_B(h_s(x))=h(w_A(x))`$ であり、
式(7.1)の第一式によりその値で $`\tau(e)`$ を実行できる。
第二式をこの中間状態に適用すれば合成後の値も一致する。
終点の観測の可換性から第三式を得る。
domain反射がある場合、逆に翻訳された合成語の実行可能性から、
帰納法で $`w_A(x)`$ を回復し、生成操作の反射で $`w_A(x)\in D_e^A`$ を得る。
これで両方向を証明した。□

理論解釈 $`u`$ からの語翻訳には、定理2.4の評価の一致を適用できる。
多引数の操作とparameterを含むtermでは、
[定理1.8](../part_1/chapter_1_atoms_laws_theories.md#14-表示代入理論の射)の
構文木の帰納法を使う。外部parameterを固定する場合、そのsortの写像は恒等である。
domainの前向き保存と反射は、異なる仮定として保持する。

**例7.3（台帳、空語、途中のread）.**
任意の可換環 $`R`$ で、単一台帳を状態 $`D=R`$、
$`\mathrm{apply}_u(x)=x+u`$、$`\mathrm{read}(x)=x`$ とする。
分割台帳は状態 $`B\oplus C=R^2`$ とし、

```math
\begin{aligned}
p(B,C)&=B+C,\\
\mathrm{apply}_u(B,C)&=(B+\lambda u,C+(1-\lambda)u),\\
\mathrm{compact}_t(B,C)&=(B+\mu t,C-\mu t)
\end{aligned}
```

と定める。parameter $`u,t`$ のsortは固定する。
applyを単一台帳のapplyへ、compactを空語へ翻訳すると、
$`p\,\mathrm{apply}_u=p+u`$、$`p\,\mathrm{compact}_t=p`$ である。
readを $`p`$ とすれば、全有限語について定理7.2が使える。
操作の翻訳は分割台帳の理論から単一台帳の理論へ向く。
$`p`$ は、零環以外では $`(1,-1)`$ を核に持つ非単射の意味射である。

applyをwriteBとwriteCへ分け、その間にもreadする言語を考える。
$`R=\mathbb Q`$、$`\lambda=1/2`$、$`u=2`$ なら、途中の公開値は $`x+1`$ となる。
単一のatomicなapplyの前後の値は $`x,x+2`$ である。
したがって完了点の語翻訳に、途中readの対応は含まれていない。
細分した言語の意味射を求めるには、phaseとその観測を宣言して式(7.1)を再び課す。

## 7.3 全変更の関手と比較表示

**構成7.4（全変更とその比較）.**
設定7.1の圏から

```math
\mathcal M(U,R)=\mathcal A(U,R)^{\simeq},\qquad
\mathcal C(U,R)=\mathrm{Fun}([1],\mathcal A(U,R))^{\simeq}
```

を作る。$`\mathcal C`$ の対象は任意の意味保存射 $`h:A\to B`$、
射 $`h\to h'`$ は同型 $`a:A\xrightarrow{\sim}A'`$、
$`b:B\xrightarrow{\sim}B'`$ で $`bh=h'a`$ を満たす対である。
始域・終域を取る関手を $`s,t:\mathcal C\to\mathcal M`$ と書く。
係数変更・文脈制限は図式の各頂点・辺に作用する。
その単位・合成比較は各成分で意味圏の比較になるので、$`\mathcal C`$ も擬関手になる。

**構成7.5（原始宣言からの比較表示）.**
まず原始表示 $`\mathcal P_0,\mathcal P_1`$ と理論解釈 $`u`$ を固定する。
両表示のsort・操作・Lawを、添字0と1を付けて別々に置く。
各sort $`s`$ に新しい写像記号 $`H_s:s_0\to u(s)_1`$ を加える。
$`H_s`$ は実現方式で許す任意の写像として解釈する。
これに以下の式を課した表示を $`\mathcal P_{01,u}`$ とする。

```math
\begin{aligned}
H_t f_0(\boldsymbol x)&=\tau_f{}_1(H_{\boldsymbol s}\boldsymbol x),\\
r_0(\boldsymbol x)&\ \Longrightarrow\ u(r)_1(H_{\boldsymbol s}\boldsymbol x),\\
D_p^0(\boldsymbol x)&\ \Longrightarrow\ u(D_p)_1(H_{\boldsymbol s}\boldsymbol x),\\
D_p^0(\boldsymbol x)&\ \Longrightarrow\
 H_t p_0(\boldsymbol x)=\tau_p{}_1(H_{\boldsymbol s}\boldsymbol x),\\
o_{1,u(s)}H_s&=o_{0,s}.
\end{aligned}
```

部分termの等式は第1章の値graphで読む。翻訳domainとtermの定義可能性の一致は
理論解釈の導出に含まれるため、第四式の右辺はその入力で定義される。
観測値sortと外部parameterを固定する場合、その成分は恒等とする。
表示のモデルの比較は、両端の構造同型で新しい $`H_s`$ と可換するものとする。
新しい写像記号には、元の操作からtermとして生成できるという条件を課さない。

**定理7.6（全Homの表示と回復）.**
$`\mathcal P_{01,u}`$ のモデルのgroupoidは、
独立なモデル $`A,B`$ と全意味射 $`h:A\to u^*B`$ のgroupoidに同値である。
両端を固定し比較を恒等とすると、そのfiberは全Hom集合そのものになる。
対応は、許される文脈制限・係数変更と自然に可換する。

**証明.**
モデルから0側と1側の担体・操作・関係を読み、$`H_s`$ の解釈を $`h_s`$ とする。
両側のLawがそれぞれ $`A,B`$ をモデルにし、追加した各式が
操作、関係、domain、観測の保存を与えるので、$`h:A\to u^*B`$ を得る。
逆に独立な $`A,B,h`$ の担体と写像を、各宣言に代入する。
意味射の定義から全追加式が成立する。両方向は担体・各操作・各写像をそのまま戻す。

比較同型の $`H_s`$ に対する保存式は、ちょうど $`(u^*b)h=h'a`$ である。
したがって任意の比較対から表示の同型を一意に作れ、表示の全同型もその対へ戻る。
これで本質的全射性と忠実充満性を得た。恒等と合成は成分写像で一致する。
文脈制限では支持に閉じた宣言を残し、翻訳先に必要な宣言も残す。
係数変更では担体と原始写像を設定7.1の規則で運ぶ。
どちらも読戻し前後で同じ成分になり、方式の比較同型も同じ成分で作用する。□

理論自体を動かす全体圏では、翻訳の同値類 $`u`$ もデータに含める。
射 $`(u,h)`$ と $`(u',h')`$ の比較には、理論の同型 $`\alpha,\beta`$ と
モデルの同型 $`a:A\to\alpha^*A'`$、$`b:B\to\beta^*B'`$ を置き、

```math
\beta u=u'\alpha,\qquad
(u^*b)h=(\alpha^*h')a
```

を課す。右辺・左辺は同じ $`(\beta u)^*B'`$ を終域とする。
各 $`u`$ の比較表示とこれらの比較を合わせると、全体圏の $`\mathcal C`$ を回復する。
翻訳を導出で同一視する規則は第1章のものを用い、導出の選び方を追加の状態にしない。
異なる翻訳添字を結ぶ理論同型も、この比較式で保持する。

## 7.4 恒等・合成とnerve

**定理7.7（合成可能な全変更とnerve）.**
$`N_n=\mathrm{Fun}([n],\mathcal A)^{\simeq}`$ と置く。
$`N_0=\mathcal M`$、$`N_1=\mathcal C`$ であり、$`n\ge2`$ について自然な同値

**式(7.2)**

```math
N_n\simeq
\underbrace{\mathcal C\mathbin{\times^{(2)}_{t,\mathcal M,s}}\cdots
\mathbin{\times^{(2)}_{t,\mathcal M,s}}\mathcal C}_{n\text{ 個}}
```

がある。恒等を挿入する写像と隣り合う辺を合成する写像は単位律・結合律を満たす。
比較表示で構成した合成は、第2章の意味圏の合成に戻り、係数変更と文脈制限に自然である。

**証明.**
右辺の2-fiber積を具体的に書く。その対象は
$`f_i:A_{i-1}\to B_i`$ と同型 $`\theta_i:B_i\xrightarrow{\sim}A_i`$
（$`1\le i<n`$）である。
射は各 $`f_i`$ の可換な同型対で、隣接する対が $`\theta_i`$ とも可換するものとする。
そこから鎖

```math
A_0\xrightarrow{f_1}B_1
\xrightarrow{f_2\theta_1}B_2\longrightarrow\cdots
\xrightarrow{f_n\theta_{n-1}}B_n
```

を作る。逆に鎖から、つなぎの同型を全て恒等として右辺の対象を作る。
鎖から出発した往復は恒等である。
一般の対象からの往復には、各元の始域と直前の終域の間の $`\theta_i`$ が自然な同型を与える。
比較の可換式から、その同型は全ての辺と可換する。
二鎖間の射は頂点ごとの同型と辺の可換式で一意に定まり、右辺の比較も同じ条件へ戻る。
よって二関手は互いの準逆である。

鎖の内部頂点を除く面写像は隣接する射の合成、端を除く面写像は端の辺の忘却、
退化写像は恒等射の挿入である。
三つの辺で二通りに内部頂点を除いても結合律により同じ合成を得る。
恒等挿入後の合成は単位律で元へ戻り、互いに離れた頂点の操作は可換する。
これがsimplicialな関係式を全て与える。

表示側では恒等に $`H_s=\mathrm{id}`$、合成に $`H_s'=K_sH_s`$ を代入する。
操作の可換式は $`KHf=K\tau(f)H=\tau'(\tau(f))KH`$ となり、
関係・domainは二つの保存を順に使う。
理論を動かす場合の正確な式は $`u^*k\circ h`$ であり、定理2.4がterm代入との一致を与える。
定理7.6の読戻しもこの実写像を返す。
制限・係数変更は関手で、三つの射の比較は設定7.1の整合性を持つので、全構成と可換する。□

$`N_n`$ の辺 $`f_i`$ は非可逆でもよい。
可逆であることを要求するのは鎖どうしの比較である。
例えば例7.3の射影を辺とする鎖は $`N_1`$ に含まれる。
この区別により、対象の同型分類と全変更の合成を同時に保持する。

## 7.5 幾何的表現の条件と元の変更への回復

**定理7.8（線形状態射のaffine表示）.**
基礎環 $`R`$、有限sort、固定翻訳 $`u`$ を取り、両端の担体を
$`R^{m_s}`$、$`R^{n_t}`$ とする。
全域操作・観測は有限変数の多項式で与え、Lawと保存式は全 $`R`$-代数上の自然写像の等式として読む。
状態比較には各代数で線形な自然写像を許す。
関係・部分操作を含まないこの実現方式で、全意味射は次のaffine schemeで表される。

```math
\mathrm{Hom}_{u}(A,B)=\mathrm{Spec}\,R[z_{s,ij}]/I_{A,B,u}.
```

ここで $`Z_s=(z_{s,ij})`$ は $`n_{u(s)}\times m_s`$ 行列であり、
$`I_{A,B,u}`$ は

```math
Z_t f_A(\boldsymbol x)-\tau_f{}_B(Z_{\boldsymbol s}\boldsymbol x),
\qquad o_B(Z_sx)-o_A(x)
```

の全出力成分の全単項式係数が生成するイデアルである。
原始操作・観測と保存式が有限族なら有限表示のaffine schemeとなる。

**証明.**
$`R`$-代数 $`S`$ 上で、線形な自然写像 $`h_T:T^{m_s}\to T^{n_{u(s)}}`$
（$`T`$ は全 $`S`$-代数）は $`h_S`$ の標準基底の像から行列 $`H_s`$ を持つ。
自然性が全 $`T`$ でこの行列の係数拡張を与え、線形性が任意の入力の値を決める。
逆に任意の行列はそのような自然写像を与える。
保存式を普遍入力 $`\boldsymbol x`$ で $`S[\boldsymbol x]`$ 上に評価すると、
全代数上での保存は残差多項式の全係数が0であることを含意する。
逆に係数が0なら全ての代入で式が成立する。
[補題B.2](../appendix_b_coefficients_and_descent.md#b1-係数とaffine構成)により、
これは商環から $`S`$ への環射と全単射である。
行列を読むことと新しい写像記号を評価することが互いに逆なので、定理7.6の全Homを回復する。
係数を環射で送る操作と単項式展開は可換するため、対応は $`S`$ に自然である。□

両端の操作係数も動かす場合は、第6章のchart変数と上の行列変数を合わせ、
両端のLawと保存式の係数で割る。基底変更 $`G_s,F_t`$ は
$`H_s\mapsto F_{u(s)}H_sG_s^{-1}`$ と作用する。
両端の操作係数も同じ基底変更で運べば、保存残差は可逆な入力代入と出力変換で移る。
逆変換もあるので、零条件が同値になる。
この作用groupoidの射は、ちょうど定理7.6の両端の線形同型と可換する対である。
有限局所自由の担体は局所的に基底を選び、
[補題6.2](../part_2/chapter_6_families_and_moduli.md#61-係数実現の族と同型)の
全線形写像のdescentによって貼り合わせる。
こうしてchart、基底変更、descentから対象と全比較射を回復する。

翻訳添字 $`u`$ を複数許すときは、その添字も保持する。
固定した離散添字集合なら各表示の族を取り、添字間の同型も許す場合は7.3節の比較を加える。
schemeの直和は試験schemeの開閉部分ごとに添字を選ぶ点も持つため、
全域で一つの翻訳を指定する関手との比較には、その局所選択を許すかどうかを指定する。

**例7.9（座標化で保持する射のクラス）.**
裸の集合 $`\mathbb Z`$ の全自己写像には $`x\mapsto x^2`$ も含まれる。
加群構造を宣言し線形射を取ると、自己射は $`x\mapsto ax`$ である。
定理7.8の行列chartは後者の全Homを表す。
また $`\mathbb F_p`$ 上では $`x^p-x`$ は全ての基礎体の点で0だが、
$`\mathbb F_p[t]`$ の入力 $`t`$ では0でない。
全代数上の自然写像の等式を用いた係数の抽出は、この二つを区別する。

**例7.10（無限protocolの全射とtranslation）.**
整数 $`\mathbb Z`$ を状態とし、各 $`n\in\mathbb Z`$ に操作 $`T_n(x)=x+n`$ を置く。
Lawは $`T_0=\mathrm{id}`$、$`T_{n+m}=T_nT_m`$ とする。
任意の状態射 $`h:\mathbb Z\to\mathbb Z`$ がこれらの操作を保つなら、
$`h(x)=h(T_x(0))=T_x(h(0))=x+c`$、$`c=h(0)`$ である。
逆に全てのtranslation $`x\mapsto x+c`$ は操作を保ち、合成はparameterの加法になる。
観測を $`o(x)=x\bmod m`$（$`m\ge1`$）とすると、観測保存は $`c\in m\mathbb Z`$ と同値である。
従って無限の操作系の全Homをこのparameter集合から回復できる。
有限個の観測・操作から同じ全Homを回復する条件は、第13章の有限部分からの再構成へつながる。

**問題7.11（一般の実現方式の表現）.**
関係・部分操作のdomainや無限担体を持つ方式について、定理7.6の比較表示から、
全ての状態射と比較を回復する表示系を構成せよ。
