# 第7章 意味保存変更と合成の幾何

一つの実現から別の実現へ移る変更を、状態の写像と操作の翻訳で記述する。
補助状態を忘れる写像も、操作をいくつかの段階へ分ける翻訳も、変更の対象になる。
この章では全ての意味保存射を集め、その比較、合成、係数と文脈に沿う変化を構成する。
その後に、状態射を座標で回復できる場合の幾何的表示を作る。

## 7.1 操作・観測を保つ射

**設定7.1（変更を取る意味圏）.**
基礎可換環 $`k`$、$`k`$-代数 $`R`$、理論 $`\mathbb T`$、実現方式 $`\sigma`$ を指定する。
固定理論では[定義4.1](../part_2/chapter_4_coefficient_realizations.md#41-原始実現データと係数に沿う関手)の
$`\mathcal A_{\mathbb T,\sigma}(U,R)`$ を用いる。係数変更を使う場合は、
環射 $`b:R\to R'`$ の関手 $`B_b`$ が対象・全ての射・Lawを保ち、
$`B_{\mathrm{id}}\cong\mathrm{Id}`$、$`B_cB_b\cong B_{cb}`$ が単位・結合の整合を満たす方式を取る。

理論を動かす場合は、許す理論と解釈の小圏 $`\mathbf T_\sigma`$ を固定する。
各 $`u:\mathbb T\to\mathbb T'`$ の引戻しは全ての射に作用する関手
$`u^*:\mathcal A_{\mathbb T',\sigma}(R)\to\mathcal A_{\mathbb T,\sigma}(R)`$ であり、
相互導出で同一視した解釈に依存する。さらに自然同型

```math
\eta_{\mathbb T}:\mathrm{Id}\xrightarrow{\sim}\mathrm{id}_{\mathbb T}^*,\qquad
\kappa_{u,v}:u^*v^*\xrightarrow{\sim}(vu)^*,\qquad
\chi_{b,u}:B_bu^*\xrightarrow{\sim}u^*B_b
```

を指定する。$`\eta,\kappa`$ は三角形・五角形の整合を満たし、
$`\chi`$ は理論解釈と環射のそれぞれの単位・合成比較と可換する。
これらは方式に課す条件である。以下では比較同型で同定した式を使い、
必要な箇所では $`\kappa`$ を明示する。

全体圏での宣言文脈は、一つの表示の部分集合ではなく、各理論の表示に対する文脈族
$`\boldsymbol U=(U_{\mathbb T})`$ である。
各許可解釈の代表を選び、残すsort・操作・関係・domain・量の翻訳の支持と、
残すLawの翻訳の導出木を $`U_{\mathbb T'}`$ に含める。
代表の同一視、単位、合成に使う導出木も残す。
この条件で $`u`$ は制限理論間の解釈 $`u_{\boldsymbol U}`$ を定め、
同一視と合成も制限後に成立する。
こうした文脈族を成分ごとの包含で順序づけ、$`\mathrm{Ctx}(\mathbf T_\sigma)`$ と書く。
許可解釈の添字 $`u`$ は制限後も保持する。
固定した一つの解釈だけを扱うときは、同じ条件を満たす文脈対 $`(U_0,U_1)`$ を使う。

宣言制限は各sortの担体と残す原始写像をそのまま取り、
理論引戻し・係数変更と、上の比較同型に整合して可換するものとする。
全体圏を $`\mathcal A_{\mathrm{tot}}(\boldsymbol U,R)`$、固定理論の圏を
$`\mathcal A_{\mathbb T,\sigma}(U,R)`$ と書き、どちらかを指定したとき $`\mathcal A`$ と略す。

集合の方式では[定理2.4・構成2.5](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)が
これらを与える。copyingでは、局所split表示上のterm・正の式・導出をnativeで評価する。
同じ開被覆で引戻しが局所splitとなり、全ての層の射は正の式の保存によって引き戻せる。
係数変更と各式の解釈の交換は定理4.12の計算であり、成分での同じ代入が単位・合成を保つ。
tensorではtensor式の型を保つ解釈を許すと、構成4.8・命題4.10の純tensorの計算が
引戻しと係数変更の比較を与える。三段の変更はどの順序でも同じ純tensorへ作用する。
多項式方式の係数変更と整合は命題7.9で構成する。

固定理論の射 $`h:A\to B`$ は各sortの実写像であり、
全域操作と量の可換式、関係の保存、部分操作のdomainの保存とそこでの可換式を満たす。
固定した観測値sort $`O_s`$ については $`o_{B,s}h_s=o_{A,s}`$ を課す。
固定宣言上の射を恒等とする場合も、第2章の固定データ付き意味圏に含める。

理論変更を伴う射は

```math
(u,h):(\mathbb T,A)\longrightarrow(\mathbb T',B),
\qquad h:A\longrightarrow u^*B
```

である。$`u`$ はsort・操作term・関係・domainの翻訳とLawの導出を持つ。
関係とdomainには第1章の正の式を用いる。
これにより[定理2.4](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)が
対象だけでなく全構造保存射への $`u^*`$ の作用を与える。
次の射を $`(v,k):(\mathbb T',B)\to(\mathbb T'',C)`$ とすると、
恒等は $`(\mathrm{id},\eta_A)`$、合成は
$`(v,k)(u,h)=(vu,\kappa_{u,v,C}\circ u^*k\circ h)`$ である。
集合の厳密な引戻しでは $`\eta,\kappa`$ は恒等となり、構成2.5の式に戻る。
観測を固定する場合、翻訳でもその値sortを固定する。

例えば、状態 $`X\times Z`$ の操作を
$`(x,z)\mapsto(T_e(x),L_e(x,z))`$、観測を $`o(x,z)=o_X(x)`$ とする。
射影 $`h(x,z)=x`$ は全操作と観測を保つ。
$`X`$ が非空で $`Z`$ に異なる二元があれば、$`h`$ は非単射である。
この射も、以下で作る変更の族の一つの対象となる。

## 7.2 操作語の翻訳と部分操作

**定理7.2（翻訳された全操作語の保存）.**
型付きの名前付き単項操作と観測を持つ $`A,B`$ を取り、
sort対応 $`s\mapsto u(s)`$ と各操作 $`e:s\to t`$ の有限語翻訳
$`\tau(e):u(s)\rightsquigarrow u(t)`$ を与える。
空語も許し、$`\tau(\varnothing_s)=\varnothing_{u(s)}`$、
$`\tau(e_m\cdots e_1)=\tau(e_m)\cdots\tau(e_1)`$ によって全有限語へ延長する。
状態写像 $`h_s:X_s(A)\to X_{u(s)}(B)`$ が

**式(7.1)**

```math
\begin{aligned}
h_s(D_e^A)&\subseteq\mathrm{Dom}_B(\tau(e)),\\
h_t(e_A(x))&=\tau(e)_B(h_s(x))\quad(x\in D_e^A),\\
o_{B,u(s)}h_s&=o_{A,s}
\end{aligned}
```

を満たすとする。全域操作では $`D_e^A=X_s(A)`$ と読む。
任意の型付き有限語 $`w:s\rightsquigarrow t`$ と
$`x\in\mathrm{Dom}_A(w)`$ について

```math
\begin{aligned}
h_s(x)&\in\mathrm{Dom}_B(\tau(w)),\\
h_t(w_A(x))&=\tau(w)_B(h_s(x)),\\
o_{B,u(t)}(\tau(w)_B(h_s(x)))&=o_{A,t}(w_A(x))
\end{aligned}
```

が成り立つ。さらに全生成操作で
$`D_e^A=h_s^{-1}\mathrm{Dom}_B(\tau(e))`$ なら、
$`\mathrm{Dom}_A(w)=h_s^{-1}\mathrm{Dom}_B(\tau(w))`$ である。

**証明.**
空語では両側が恒等写像なので、domainと値は一致し、最後の式は観測の可換性である。
$`w`$ の後に $`e`$ を実行できるとする。
帰納法により $`\tau(w)_B(h_s(x))=h(w_A(x))`$ であり、
式(7.1)の第一式によりその値で $`\tau(e)`$ を実行できる。
第二式をこの中間状態に適用すれば合成後の値も一致する。
終点の観測の可換性から第三式を得る。
domain反射がある場合、逆に翻訳された合成語の実行可能性から、
帰納法で $`w_A(x)`$ を回復し、生成操作の反射で $`w_A(x)\in D_e^A`$ を得る。
これで両方向を証明した。□

理論解釈 $`u`$ からの語翻訳には、定理2.4の評価の一致を適用できる。
多引数の操作とparameterを含むtermでは、
[定理1.8](../part_1/chapter_1_atoms_laws_theories.md#14-表示代入理論の射)の
構文木の帰納法を使う。外部parameterを固定する場合、そのsortの写像は恒等である。
domainの前向き保存と反射は、異なる仮定として保持する。

**例7.3（台帳、空語、途中のread）.**
任意の可換環 $`R`$ で、単一台帳を状態 $`D=R`$、
$`\mathrm{apply}_u(x)=x+u`$、$`\mathrm{read}(x)=x`$ とする。
分割台帳は状態 $`B\oplus C=R^2`$ とし、

```math
\begin{aligned}
p(B,C)&=B+C,\\
\mathrm{apply}_u(B,C)&=(B+\lambda u,C+(1-\lambda)u),\\
\mathrm{compact}_t(B,C)&=(B+\mu t,C-\mu t)
\end{aligned}
```

と定める。parameter $`u,t`$ のsortは固定する。
applyを単一台帳のapplyへ、compactを空語へ翻訳すると、
$`p\,\mathrm{apply}_u=p+u`$、$`p\,\mathrm{compact}_t=p`$ である。
readを $`p`$ とすれば、全有限語について定理7.2が使える。
操作の翻訳は分割台帳の理論から単一台帳の理論へ向く。
$`p`$ は、零環以外では $`(1,-1)`$ を核に持つ非単射の意味射である。

applyをwriteBとwriteCへ分け、その間にもreadする言語を考える。
$`R=\mathbb Q`$、$`\lambda=1/2`$、$`u=2`$ なら、途中の公開値は $`x+1`$ となる。
単一のatomicなapplyの前後の値は $`x,x+2`$ である。
したがって完了点の語翻訳に、途中readの対応は含まれていない。
細分した言語の意味射を求めるには、phaseとその観測を宣言して式(7.1)を再び課す。

## 7.3 全変更の関手と比較表示

**構成7.4（全変更とその比較）.**
設定7.1の圏から

```math
\mathcal M(U,R)=\mathcal A(U,R)^{\simeq},\qquad
\mathcal C(U,R)=\mathrm{Fun}([1],\mathcal A(U,R))^{\simeq}
```

を作る。$`\mathcal C`$ の対象は任意の意味保存射 $`h:A\to B`$、
射 $`h\to h'`$ は同型 $`a:A\xrightarrow{\sim}A'`$、
$`b:B\xrightarrow{\sim}B'`$ で $`bh=h'a`$ を満たす対である。
始域・終域を取る関手を $`s,t:\mathcal C\to\mathcal M`$ と書く。
係数変更・文脈制限は図式の各頂点・辺に作用する。
その単位・合成比較は各成分で意味圏の比較になるので、$`\mathcal C`$ も擬関手になる。

**構成7.5（原始宣言からの比較表示）.**
設定7.1の方式、原始表示 $`\mathcal P_0,\mathcal P_1`$ と理論解釈 $`u`$ を固定する。
両表示の宣言を添字0と1で区別する。ただし固定観測値sort・外部parameter sortと
その固定構造は共有し、複製しない。各可変sortに写像記号 $`H_s:s_0\to u(s)_1`$ を加え、
固定sortの $`H_s`$ は恒等とする。次の式を課す。

```math
\begin{aligned}
H_t f_0(\boldsymbol x)&=\tau_f{}_1(H_{\boldsymbol s}\boldsymbol x),\\
r_0(\boldsymbol x)&\ \Longrightarrow\ u(r)_1(H_{\boldsymbol s}\boldsymbol x),\\
D_p^0(\boldsymbol x)&\ \Longrightarrow\ u(D_p)_1(H_{\boldsymbol s}\boldsymbol x),\\
D_p^0(\boldsymbol x)&\ \Longrightarrow\
 H_t p_0(\boldsymbol x)=\tau_p{}_1(H_{\boldsymbol s}\boldsymbol x),\\
H_q q_0(\boldsymbol x)&=u(q)_1(H_{\boldsymbol s}\boldsymbol x),\\
o_{1,u(s)}H_s&=o_{0,s}.
\end{aligned}
```

第五式は量の保存であり、量の値sortを固定する場合は $`H_q=\mathrm{id}`$ である。
部分的な量にはそのdomainの前向き保存も課し、第五式をdomain上で読む。
部分termの等式は第1章の値graphで読む。翻訳domainとtermの定義可能性の一致は
理論解釈の導出に含まれるため、第四式の右辺はその入力で定義される。

この比較表示を $`\mathcal P_{01,u}`$ と書き、その**混合解釈**を次で定義する。
0側と1側の各宣言群には、それぞれ $`\sigma`$ の対象条件とLawを課す。
$`H_s`$ には担体間で $`\sigma`$ が許す任意の写像を割り当て、上の保存式を課す。
集合では全入力の式、層では可換図式と関係・domainの部分層への因子化、
加群では指定された線形写像の可換式として解釈する。
比較は両端の構造同型で全 $`H_s`$ と可換する対である。
このgroupoidを $`\mathrm{Cmp}_\sigma(\mathcal P_0,\mathcal P_1;u)`$ と書く。
$`H_s`$ を既存のtermから生成する条件や、両端と同じ被覆で局所splitとなる条件は課さない。
通常の $`\sigma`$ を拡張署名全体へ適用するモデル概念とは区別する。

文脈対 $`(U_0,U_1)`$ による比較表示の制限は、設定7.1の翻訳支持・導出の条件に加え、
残す0側sortの $`H_s`$ と、残す原始宣言に対する上の保存式をすべて残すものとする。
共有sortとその固定条件も保持する。
単に $`\mathcal P_{01,u}`$ の任意の依存閉部分を取る操作ではない。

**定理7.6（全Homの表示と回復）.**
設定7.1と構成7.5の下で、$`\mathrm{Cmp}_\sigma(\mathcal P_0,\mathcal P_1;u)`$ は、
独立な $`\sigma`$-モデル $`A,B`$ と全意味射 $`h:A\to u^*B`$ のgroupoidに同値である。
両端を厳密固定し比較を恒等とすると、そのfiberは全Hom集合になる。
翻訳添字と後述の理論同型比較も含めた混合解釈は、全体圏の $`\mathcal C`$ に同値である。
これらの同値は、構成7.5の文脈制限と設定7.1の係数変更に擬自然である。

**証明.**
混合解釈から0側と1側の担体・原始構造を読み、$`H_s`$ の解釈を $`h_s`$ とする。
両側の対象条件とLawが $`A,B`$ をモデルにする。
追加した各式は、その方式における操作、関係、domain、量、観測の保存条件である。
従って $`h:A\to u^*B`$ を得る。
逆に独立な $`A,B,h`$ の担体と写像を各宣言へ代入すると、意味射の定義から全追加式が成り立つ。
両方向は担体・各操作・各写像をそのまま戻す。
比較同型の保存式は $`(u^*b)h=h'a`$ であるから、全比較対も一意に相互回復し、
恒等と合成は成分で一致する。厳密固定した両端の比較は恒等対だけなので、全Hom集合を得る。

全体圏では $`u:\mathbb T_0\to\mathbb T_1`$ も対象データに含める。
$`(u,h)`$ と $`(u',h')`$ の比較は理論同型
$`\alpha:\mathbb T_0\cong\mathbb T'_0`$、$`\beta:\mathbb T_1\cong\mathbb T'_1`$ と
状態同型 $`a:A\cong\alpha^*A'`$、$`b:B\cong\beta^*B'`$ で

```math
\beta u=u'\alpha,\qquad
\kappa_{u,\beta,B'}(u^*b)h
 =\kappa_{\alpha,u',B'}(\alpha^*h')a
```

を満たすものとする。両辺の終域は同じ $`(\beta u)^*B'`$ である。
これは全体圏における可換正方形の式そのものである。
全体圏の任意の正方形を二つの理論成分と二つの状態成分へ分解すれば上のデータに戻る。
比較の合成は全体圏の合成であり、$`\kappa`$ の整合により再び同じ可換式を満たす。
従って翻訳添字を含む全対象と全比較射を相互回復する。
導出は解釈の同一視に使い、その導出木の選択を対象の追加データにはしない。

文脈制限では残す担体と写像は変わらず、必要な翻訳・保存式も残るため、
評価後に制限する場合と制限後に評価する場合は同じモデル・同じ射を返す。
環射 $`\ell:R\to R'`$ では、状態射を
$`B_\ell A\xrightarrow{B_\ell h}B_\ell u^*B\xrightarrow{\chi_{\ell,u}}u^*B_\ell B`$ に送る。
混合解釈の各宣言を運んでも同じ式になる。比較射の両端も $`B_\ell a,B_\ell b`$ と
必要な $`\chi`$ で運ばれ、$`\chi`$ の自然性が可換正方形を保つ。
単位と二段の変更に対する二つの比較は、設定7.1の整合により各宣言で一致する。
文脈制限との交換も残した各成分で同じ比較である。
これが対象・全比較射についての擬自然性とその整合を与える。□

## 7.4 恒等・合成とnerve

**定理7.7（合成可能な全変更とnerve）.**
$`N_n=\mathrm{Fun}([n],\mathcal A)^{\simeq}`$ と置く。
$`N_0=\mathcal M`$、$`N_1=\mathcal C`$ であり、$`n\ge2`$ について自然な同値

**式(7.2)**

```math
N_n\simeq
\underbrace{\mathcal C\mathbin{\times^{(2)}_{t,\mathcal M,s}}\cdots
\mathbin{\times^{(2)}_{t,\mathcal M,s}}\mathcal C}_{n\text{ 個}}
```

がある。恒等を挿入する写像と隣り合う辺を合成する写像は単位律・結合律を満たす。
設定7.1の下で、混合解釈の合成は意味圏の合成に戻る。
この同値と全ての面・退化写像は、同設定の係数変更と文脈族の制限に擬自然である。

**証明.**
右辺の2-fiber積を具体的に書く。その対象は
$`f_i:A_{i-1}\to B_i`$ と同型 $`\theta_i:B_i\xrightarrow{\sim}A_i`$
（$`1\le i<n`$）である。
射は各 $`f_i`$ の可換な同型対で、隣接する対が $`\theta_i`$ とも可換するものとする。
そこから鎖

```math
A_0\xrightarrow{f_1}B_1
\xrightarrow{f_2\theta_1}B_2\longrightarrow\cdots
\xrightarrow{f_n\theta_{n-1}}B_n
```

を作る。逆に鎖から、つなぎの同型を全て恒等として右辺の対象を作る。
鎖から出発した往復は恒等である。
一般の対象からの往復には、各元の始域と直前の終域の間の $`\theta_i`$ が自然な同型を与える。
比較の可換式から、その同型は全ての辺と可換する。
二鎖間の射は頂点ごとの同型と辺の可換式で一意に定まり、右辺の比較も同じ条件へ戻る。
よって二関手は互いの準逆である。

鎖の内部頂点を除く面写像は隣接する射の合成、端を除く面写像は端の辺の忘却、
退化写像は恒等射の挿入である。
三つの辺で二通りに内部頂点を除いても結合律により同じ合成を得る。
恒等挿入後の合成は単位律で元へ戻り、互いに離れた頂点の操作は可換する。
これがsimplicialな関係式を全て与える。

表示側では恒等に $`H_s=\mathrm{id}`$、合成に $`H_s'=K_sH_s`$ を代入する。
操作の可換式は $`KHf=K\tau(f)H=\tau'(\tau(f))KH`$ となり、
関係・domainは二つの保存を順に使う。
理論を動かす場合の式は $`\kappa_{u,v}\circ u^*k\circ h`$ であり、
$`\kappa`$ の自然性と五角形の整合がterm代入と三射の合成の一致を与える。
定理7.6の読戻しもこの実写像を返す。
係数変更または宣言制限の関手を $`F`$ と書くと、
$`F(f_{i+1}\theta_i)=F(f_{i+1})F(\theta_i)`$、$`F(\mathrm{id})=\mathrm{id}`$ である。
従って鎖への復元、全比較、面・退化写像は $`F`$ と可換する。
二段の係数変更の比較は鎖の各頂点に方式の比較同型を置いた自然同型であり、
各辺との可換性はその自然性から従う。三段の比較は各頂点で設定7.1の五角形に一致する。
制限を混ぜた場合も残した成分で同じ図式となるので、要求された擬自然性を得る。□

$`N_n`$ の辺 $`f_i`$ は非可逆でもよい。
可逆であることを要求するのは鎖どうしの比較である。
例えば例7.3の射影を辺とする鎖は $`N_1`$ に含まれる。
この区別により、対象の同型分類と全変更の合成を同時に保持する。

## 7.5 幾何的表現の条件と元の変更への回復

**定理7.8（線形状態射のaffine表示）.**
可換環 $`R`$、有限sort、固定翻訳 $`u`$ を取り、両端の担体を
$`R^{m_s}`$、$`R^{n_t}`$ とする。
固定観測値sortの担体は $`R^{k_s}`$、固定外部parameter sortも指定された有限自由加群とし、
それらの状態比較は恒等とする。全域操作・量・観測は有限変数の多項式で与え、
Lawと保存式は全 $`R`$-代数上の自然写像の等式として読む。
状態比較には各代数で線形な自然写像を許す。
関係・部分操作を含まないこの実現方式で、全意味射は次のaffine schemeで表される。

```math
\mathrm{Hom}_{u}(A,B)=\mathrm{Spec}\,R[z_{s,ij}]/I_{A,B,u}.
```

ここで可変sortの $`Z_s=(z_{s,ij})`$ は $`n_{u(s)}\times m_s`$ 行列、
共有する固定sortの $`Z_s`$ は恒等行列であり、
$`I_{A,B,u}`$ は

```math
Z_t f_A(\boldsymbol x)-\tau_f{}_B(Z_{\boldsymbol s}\boldsymbol x),
\qquad o_B(Z_sx)-o_A(x)
```

の全出力成分の全単項式係数が生成するイデアルである。
原始操作・観測と保存式が有限族なら有限表示のaffine schemeとなる。

**証明.**
$`R`$-代数 $`S`$ 上で、線形な自然写像 $`h_T:T^{m_s}\to T^{n_{u(s)}}`$
（$`T`$ は全 $`S`$-代数）は $`h_S`$ の標準基底の像から行列 $`H_s`$ を持つ。
自然性が全 $`T`$ でこの行列の係数拡張を与え、線形性が任意の入力の値を決める。
逆に任意の行列はそのような自然写像を与える。
保存式を普遍入力 $`\boldsymbol x`$ で $`S[\boldsymbol x]`$ 上に評価すると、
全代数上での保存は残差多項式の全係数が0であることを含意する。
逆に係数が0なら全ての代入で式が成立する。
[補題B.2](../appendix_b_coefficients_and_descent.md#b1-係数とaffine構成)により、
これは商環から $`S`$ への環射と全単射である。
行列を読むことと新しい写像記号を評価することが互いに逆なので、定理7.6の全Homを回復する。
係数を環射で送る操作と単項式展開は可換するため、対応は $`S`$ に自然である。□

**命題7.9（多項式族のchart・基底変更・係数descent）.**
有限sort、有限個の全域操作・量・観測、有限個の多項式Lawと、型を保つ翻訳 $`u`$ を固定する。
各担体を指定階数の有限局所自由加群とし、各原始写像 $`f`$ に総次数上限 $`d_f`$ を与える。
共有する固定sortと固定データの比較は恒等とする。
操作は各自由化上で多項式として与え、状態射は線形とする。
この実現方式では次が成り立つ。

1. 両端に基底を選んだ全変更は、両端の単項式係数と状態行列を変数とする有限表示affine schemeで表される。
2. 両端の基底変更 $`G_s,F_t`$ は第6章と同じ右作用であり、状態行列は
   $`H_s\mapsto F_{u(s)}^{-1}H_sG_s`$ へ移る。この作用groupoidは基底を持つ両端間の全比較を保持する。
3. Zariski被覆とfppf被覆について対象と全ての線形状態射が降下する。
   これにより有限局所自由な両端を持つ全変更と全比較を回復する。
4. 係数変更、構成7.5の文脈制限、型を保つ多項式termの代入は整合する。
   次数上限を持つ部分族に制限するときは、その上限を保つ翻訳を用いる。

**証明.**
自由な担体の操作 $`f`$ を、入力変数 $`\boldsymbol x`$ に対して
$`\sum_{|\nu|\le d_f}c_{f,i,\nu}\boldsymbol x^\nu`$ と書く。
両端の全係数と状態行列を変数とする多項式環を作り、Lawと保存式を代入・展開した
全残差係数で割る。固定する原始写像はその指定係数への等式を課す。
全代数上で成り立つことと全残差係数の零性は、一般元への評価と代入で同値である。
点から全原始写像と状態射を戻し、元の係数を読むと元の点へ戻る。これが1を示す。

新しい基底を旧基底に $`G,F`$ を右から掛けて作る。
原始操作と状態射の新座標は

```math
f_A'(\boldsymbol x)=G_t^{-1}f_A(G_{\boldsymbol s}\boldsymbol x),\qquad
g_B'(\boldsymbol y)=F_w^{-1}g_B(F_{\boldsymbol r}\boldsymbol y),\qquad
H_s'=F_{u(s)}^{-1}H_sG_s.
```

$`g_B`$ は1側の任意の原始操作 $`\boldsymbol r\to w`$ であり、固定sortでは行列を恒等と読む。
termに関する帰納法で翻訳 $`\tau_f`$ の内部の基底変更が相殺され、
保存残差 $`r`$ は $`r'(\boldsymbol x)=F_{u(t)}^{-1}r(G_{\boldsymbol s}\boldsymbol x)`$ となる。
逆の基底変更も同じ式なので、全係数の零性は同値である。
二回の基底変更は行列積 $`(G,F)(G',F')`$ に対応し、右作用を得る。
作用の矢は両端に $`G^{-1},F^{-1}`$ を持つ構造同型であり、
逆に任意の両端の同型対は一意な可逆行列対を持つ。これが2の全比較の回復である。

一般の有限局所自由担体で、操作の入力の直和を $`E`$、出力を $`F`$ とする。
次数 $`d`$ 以下の係数を持つ多項式写像は、加群層

```math
F\otimes\bigoplus_{i=0}^{d}\mathrm{Sym}^i(E^\vee)
```

の切断と対応する。自由化上では右辺の基底が出力基底と入力単項式であり、
切断を多項式評価する写像と一般元から係数を読む写像が逆になる。
自由化の変更では上の線形代入が両側に同じ作用を与えるので、この対応は貼り合う。
これが多重線形演算から多項式演算へ移る際に用いる係数加群である。

[補題B.4・B.5](../appendix_b_coefficients_and_descent.md#b2-忠実平坦な係数descent)により、
被覆上の担体と全線形写像を降下する。
双対、有限直和、有限次対称冪は有限局所自由加群の基底上の構成と整合し、
その係数加群の整合切断も補題B.4で一意に降下する。
従って全原始多項式写像が降下する。
Lawと状態射の保存式は自由化上の残差係数に忠実平坦性を適用して降下する。
逆写像を持つ局所比較では逆写像も降下し、一意性から互いに逆となる。
以上が3である。基底を忘れた全体は、chartの作用groupoidにこのdescentを施して得る。

任意の環射で係数と行列を送ると、和・積・代入・逆行列の式が保存される。
局所自由な場合も、双対と対称冪のこの係数加群は引戻しと可換する。
恒等と二段の係数変更は各係数に同じ環射を適用し、三段の整合も同じ積になる。
文脈制限は残す係数を取るだけで、termの代入は同じ多項式の合成である。
よって4を得る。この構成を多項式実現方式と呼び、設定7.1の条件を満たす方式として用いる。□

翻訳添字 $`u`$ を複数許すときは、その添字も保持する。
固定した離散添字集合なら各表示の族を取り、添字間の同型も許す場合は7.3節の比較を加える。
schemeの直和は試験schemeの開閉部分ごとに添字を選ぶ点も持つため、
全域で一つの翻訳を指定する関手との比較には、その局所選択を許すかどうかを指定する。

**例7.10（射のクラスと局所表示）.**
裸の集合 $`\mathbb Z`$ の全自己写像には $`x\mapsto x^2`$ も含まれる。
加群構造を宣言し線形射を取ると、自己射は $`x\mapsto ax`$ である。
定理7.8の行列chartは後者の全Homを表す。
また $`\mathbb F_p`$ 上では $`x^p-x`$ は全ての基礎体の点で0だが、
$`\mathbb F_p[t]`$ の入力 $`t`$ では0でない。
全代数上の自然写像の等式を用いた係数の抽出は、この二つを区別する。

通常のcopyingを比較表示全体へ適用すると、混合解釈と異なることも具体的に分かる。
$`R=\prod_{n\in\mathbb N}\mathbb F_2`$、$`A=\underline{\mathbb N}_R`$、
$`B=\underline{\{0,1\}}_R`$ とし、両端に操作を置かない。
第 $`n`$ 成分だけが1の冪等元を $`e_n`$ とすると、
入力 $`n`$ に対する係数 $`a_{n,1}=e_n,a_{n,0}=1-e_n`$ は定理4.3の全Homの条件を満たす。
これにより層の射 $`h:A\to B`$ と、構成7.5の混合解釈を得る。
有限supportのイデアルを含む極大イデアル $`\mathfrak p`$ を取ると、
そのfiberで全 $`e_n`$ は0なので $`h`$ の像は一点である。
他方、$`\mathfrak p`$ の基本開近傍 $`D(f)`$ では $`f\notin\mathfrak p`$ だから、
ある $`m`$ で $`f_m=1`$ である。第 $`m`$ 座標での評価の核も $`D(f)`$ に入り、
そのfiberでは $`h(m)=1`$、$`n\ne m`$ なら $`h(n)=0`$ で、像は二点となる。
像の濃度は両端の同型で変わらないので、どの近傍でも三つ組 $`(A,B,h)`$ は
一つのnative構造の定数実現にならない。
両端を局所splitとすることと、追加写像も同じ被覆で局所splitとすることは別の条件である。

**例7.11（無限protocolの全Homと係数列）.**
可換環 $`R`$ と係数列 $`a=(a_n)_{n\ge0}`$ を取る。
各 $`n`$ に状態sort $`X_n=R`$、全体で共有する外部parameter sort $`R`$ を置き、

```math
T_{n,u}(x)=x+u,\qquad d_n^a:X_{n+1}\to X_n,\quad d_n^a(x)=2x+a_n
```

とする。観測は定数とし、parameter sortは固定する。
Law $`T_{n,0}=\mathrm{id}`$、$`T_{n,u+v}=T_{n,u}T_{n,v}`$ と
$`d_n^aT_{n+1,u}=T_{n,2u}d_n^a`$ は直接計算で成り立つ。
この実現を $`A^a`$ とする。
$`A^a\to A^b`$ の意味射は、平行移動の保存により
$`h_n(x)=h_n(T_{n,x}(0))=x+c_n`$、$`c_n=h_n(0)`$ でなければならない。
残る生成操作 $`d_n`$ の可換性は

```math
2x+a_n+c_n=2x+2c_{n+1}+b_n
\quad\Longleftrightarrow\quad c_n-2c_{n+1}=b_n-a_n
```

である。逆にこの全方程式を満たす列は全原始操作を保つ。
従って全Homはこの方程式の全解と全単射になり、恒等は零列、射の合成は列の加法である。
環射は全係数を送り、全代数上で自然な射についても一般元 $`0`$ の像が同じ列を回復する。
特に $`A^0\to A^a`$ の全変更は $`c_n-2c_{n+1}=a_n`$ と分類される。
状態sort $`X_0,\ldots,X_N`$ と操作 $`d_0,\ldots,d_{N-1}`$ のfragmentでは、
$`c_N`$ を任意に選び、後退代入で全解を得る。
第13章では、この有限解と、無限列として整合する全解を比較する。

**例7.12（lensの全変更と非可逆な忘却）.**
非空の固定view集合 $`V`$ に対し、状態 $`V\times C`$、
$`\mathrm{get}(v,c)=v`$、$`\mathrm{put}((v,c),w)=(w,c)`$ という積lensを取る。
同じviewを持つ $`V\times C'`$ への全意味射は

```math
h_r(v,c)=(v,r(c)),\qquad r:C\to C'
```

に一意に対応する。
実際、getの保存から $`h(v,c)=(v,r_v(c))`$ と書け、putの保存から
$`r_w(c)=r_v(c)`$ となる。基準viewを一つ選べば共通の $`r`$ を得る。
逆に任意の $`r`$ で二つの操作を保存する。合成は $`h_{r'}h_r=h_{r'r}`$ である。
$`C=\{0,1\}`$、$`C'=\{*\}`$ では射影が非単射の変更となる。
構成7.4ではこれも対象であり、$`r:C\to C'`$ と $`r':D\to D'`$ の比較は補助集合の全単射
$`a:C\cong D`$、$`b:C'\cong D'`$ で $`br=r'a`$ を満たす対である。
従って全Homだけでなく全比較と合成も同じデータで回復する。

**問題7.13（一般の実現方式の表現）.**
関係・部分操作のdomainや無限担体を持つ方式について、定理7.6の比較表示から、
全ての状態射と比較を回復する表示系を構成せよ。
状態射の座標化、原始評価の正則性、翻訳添字と係数descentをどの条件から導けるかを求めよ。
copying方式では[定理4.6](../part_2/chapter_4_coefficient_realizations.md#43-無限担体とtotality)の
入力ごとの有限supportを保持する表示が出発点になる。
一般の $`\mathcal C`$、$`s,t`$ とnerveは、これらの表現条件を用いずに既に構成されている。
