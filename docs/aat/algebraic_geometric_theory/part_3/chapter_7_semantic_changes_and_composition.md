# 第7章 意味保存変更と合成の幾何

一つの実現から別の実現へ移る変更は、状態の写像と操作の翻訳の組によって記述される。
補助状態を忘却する写像も、一つの操作を複数の段階へ分割する翻訳も、同じ意味保存変更の対象となる。
この章では、すべての意味保存射を集めてその比較、合成、係数変更および文脈制限に沿う変化を構成する。
さらに、状態射を座標によって回復できる実現方式において、変更の全体をアフィンスキームや作用 groupoid として幾何的に表示する。

## 7.1 操作・観測を保つ射

まず、第2章と第4章で導入した意味圏を土台として、理論を固定した変更と理論の解釈を伴う変更の両方を統一的に扱える枠組みを設定する。

**設定7.1（変更を取る意味圏）.**
基礎可換環 $`k`$、$`k`$-代数 $`R`$、理論 $`\mathbb T`$、実現方式 $`\sigma`$ を指定する。
変更を扱う意味圏と、その上で許す係数変更・理論解釈・宣言制限の条件を次のように定める。

- **固定理論と係数変更.**
  理論を固定する場合は、[定義4.1](../part_2/chapter_4_coefficient_realizations.md#41-原始実現データと係数に沿う関手)の圏 $`\mathcal A_{\mathbb T,\sigma}(U,R)`$ を用いる。
  係数変更を扱う場合は、任意の環射 $`b:R\to R'`$ に対する係数変更関手 $`B_b`$ が対象・すべての射・Law を保ち、さらに比較同型 $`B_{\mathrm{id}}\cong\mathrm{Id}`$ および $`B_cB_b\cong B_{cb}`$ が単位律と結合律の整合条件を満たす実現方式を取る。

- **理論の変更と引戻し.**
  理論を動かす場合は、許す理論と解釈からなる小圏 $`\mathbf T_\sigma`$ を固定する。
  各解釈 $`u:\mathbb T\to\mathbb T'`$ に対する引戻しは、対象だけでなくすべての射に作用する関手
  $`u^*:\mathcal A_{\mathbb T',\sigma}(R)\to\mathcal A_{\mathbb T,\sigma}(R)`$
  であり、相互導出によって同一視された解釈のみに依存するものとする。
  さらに自然同型

  ```math
  \eta_{\mathbb T}:\mathrm{Id}\xrightarrow{\sim}\mathrm{id}_{\mathbb T}^*,\qquad
  \kappa_{u,v}:u^*v^*\xrightarrow{\sim}(vu)^*,\qquad
  \chi_{b,u}:B_bu^*\xrightarrow{\sim}u^*B_b
  ```

  を指定する。ここで $`\eta,\kappa`$ は三角形および五角形の整合条件を満たし、$`\chi`$ は理論解釈と環射それぞれの単位比較・合成比較と可換するものとする。
  これらは実現方式に課す条件である。以下では比較同型によって同一視した式を用いるが、必要な箇所では $`\kappa`$ を明示する。

- **担体と原始構造の評価.**
  比較表示を扱う実現方式では、各対象の担体 $`X_s(A)`$ と許容担体写像を指定し、射を原始構造の保存条件を満たす写像族そのものとして与える。
  引戻しには $`X_s(u^*B)=X_{u(s)}(B)`$ という同一視を指定し、その原始操作・量を翻訳項の評価、関係・定義域を翻訳式の解釈によって定める。
  固定された観測・パラメータ sort は保ち、射の引戻しは $`X_s(u^*b)=b_{u(s)}`$ とする。
  この同一視の下で、$`A\to u^*B`$ の射の条件は、構成7.5の6種類の保存式と固定 sort 上の恒等条件にちょうど一致するものとする。
  さらに $`\eta`$ と $`\kappa`$ の担体成分はそれぞれ恒等写像であり、翻訳の単位・合成による原始構造の評価の一致を実現するものとする。
  したがって $`h:A\to u^*B`$、$`k:B\to v^*C`$ の担体写像を $`H_s,K_t`$ と書けば、$`\kappa_{u,v,C}\circ u^*k\circ h`$ の担体成分は $`K_{u(s)}H_s`$ となる。
  これらの評価と担体の同一視は宣言制限と可換し、係数変更では $`\chi_{b,u}`$ を介して一致するものとする。

- **宣言文脈族と制限.**
  全体圏における宣言文脈は、単一の表示の部分集合ではなく、各理論の表示に対する文脈族 $`\boldsymbol U=(U_{\mathbb T})`$ である。
  $`\mathbf T_\sigma`$ の各射について、定義1.9の翻訳データと導出を備えた代表をあらかじめ固定する。代表の同一視、単位、および合成に用いる導出木も、この代表族とともに固定する。
  各許可解釈 $`u:\mathbb T\to\mathbb T'`$ について、残す sort・操作・関係・定義域・量の翻訳の支持を $`U_{\mathbb T'}`$ に含める。
  あわせて、残す全域操作・量の全域性の導出 $`\top\vdash\mathrm{Def}_{\tau_f}`$、残す部分操作の定義域一致の両向きの導出 $`\delta_p\dashv\vdash\mathrm{Def}_{\tau_p}`$、および残す必須 Law の翻訳の導出に現れるすべての宣言と必須 Law を保持する。
  代表の同一視、単位、および合成に用いる導出についても、残す宣言に関係する導出木中のすべての宣言と必須 Law を保持する。
  この条件により、$`u`$ は制限理論の間の解釈 $`u_{\boldsymbol U}`$ を定め、解釈の同一視と合成も制限後にそのまま成立する。
  この固定した代表族と導出木に対して、条件を満たす文脈族を成分ごとの包含関係で順序づけ、$`\mathrm{Ctx}(\mathbf T_\sigma)`$ と書く。
  許可解釈の添字 $`u`$ は制限後も保持する。
  固定した一つの解釈だけを扱うときは、同じ条件を満たす文脈対 $`(U_0,U_1)`$ を用いる。

  宣言制限は各 sort の担体と残す原始写像をそのまま取り、理論引戻しおよび係数変更と、上記の比較同型に整合して可換するものとする。
  全体圏を $`\mathcal A_{\mathrm{tot}}(\boldsymbol U,R)`$、固定理論の圏を $`\mathcal A_{\mathbb T,\sigma}(U,R)`$ と書き、どちらかを指定したときには $`\mathcal A`$ と略記する。

- **主要な実現方式における確認.**
  集合の実現方式では、[定理2.4・構成2.5](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)が上記の条件をすべて与える。引戻しの担体は翻訳先 sort の集合そのものであり、構造保存写像の条件を書き下すと構成7.5の保存式となる。単位・合成の比較は同じ集合上の恒等写像である。
  複製（copying）方式では、局所分裂表示上の項・正の式・導出を元の（native）モデルで評価する。同じ開被覆の上で引戻しが再び局所的に分裂し、すべての層の射は正の式の保存によって引き戻すことができる。係数変更と各式の解釈の交換は定理4.12の計算によって与えられ、成分ごとの同じ代入が単位と合成を保つ。
  テンソル（tensor）方式では、テンソル式の型を保つ解釈を許すと、構成4.8・命題4.10の純テンソルの計算が引戻しと係数変更の比較を与える。3段階の変更はどの順序で施しても同じ純テンソルへ作用する。
  多項式方式における係数変更と整合条件は、後の命題7.9で構成する。
  複製方式では担体は翻訳先 sort の層、テンソル方式と多項式方式では翻訳先 sort の加群である。それぞれ構造を保つすべての層の射、すべての構造保存線形写像を許すため、6種類の保存式を満たす許容写像族が射の全体を与える。
  いずれも理論引戻しは担体を再添字づけして原始構造だけを翻訳するので、恒等翻訳と合成翻訳の比較は担体上で恒等となる。複製方式の局所評価、テンソル方式の型を保つ代入、多項式方式の普遍入力での代入が、それぞれこの比較による原始構造の一致を保証する。

- **固定理論および理論変更を伴う射.**
  固定理論の射 $`h:A\to B`$ は各 sort の担体間の写像の族であり、全域操作と量の可換式、関係の保存、部分操作の定義域の保存およびその定義域上での可換式を満たす。
  固定した観測値 sort $`O_s`$ については $`o_{B,s}h_s=o_{A,s}`$ を課す。
  固定宣言上の射を恒等写像とする場合も、第2章の固定データ付き意味圏に含める。

  理論変更を伴う射は、解釈 $`u`$ と状態射 $`h`$ の組

  ```math
  (u,h):(\mathbb T,A)\longrightarrow(\mathbb T',B),
  \qquad h:A\longrightarrow u^*B
  ```

  で与えられる。ここで $`u`$ は sort・操作の項・関係・定義域の翻訳と Law の導出を持つ。
  関係と定義域の翻訳には第1章の正の式を用いる。これにより[定理2.4](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)が、対象だけでなくすべての構造保存射に対する $`u^*`$ の作用を与える。
  続く射を $`(v,k):(\mathbb T',B)\to(\mathbb T'',C)`$ とするとき、恒等射は $`(\mathrm{id},\eta_A)`$、合成は
  $`(v,k)(u,h)=(vu,\kappa_{u,v,C}\circ u^*k\circ h)`$
  で定義される。集合の厳密な引戻しにおいては $`\eta,\kappa`$ は恒等となり、構成2.5の式に帰着する。
  観測を固定する場合は、翻訳においてもその観測値 sort を固定する。

具体例として、状態空間 $`X\times Z`$ 上に操作 $`(x,z)\mapsto(T_e(x),L_e(x,z))`$ と観測 $`o(x,z)=o_X(x)`$ を定めた実現を考える。
第1成分への射影 $`h(x,z)=x`$ は、すべての操作と観測を保つ意味保存射である。
$`X`$ が非空で $`Z`$ に相異なる二つの元があれば、$`h`$ は単射ではない。
このような非単射の射も、以下で構成する変更の族の一つの対象として対等に扱う。

## 7.2 操作語の翻訳と部分操作

個々の生成操作に関する保存条件と定義域の条件が成り立てば、それらを任意の有限回合成した操作語全体についても保存と観測の一致が従う。
また、部分操作を扱う際には、定義域の前向き保存と反射を明確に区別しておく必要がある。

**定理7.2（翻訳された操作語全体の保存）.**
型付きの名前付き単項操作と観測を持つ実現 $`A,B`$ を取り、sort 対応 $`s\mapsto u(s)`$ と、各生成操作 $`e:s\to t`$ に対する有限語翻訳 $`\tau(e):u(s)\rightsquigarrow u(t)`$ を与える。
空語への翻訳も許し、$`\tau(\varnothing_s)=\varnothing_{u(s)}`$ および $`\tau(e_m\cdots e_1)=\tau(e_m)\cdots\tau(e_1)`$ によって、$`\tau`$ をすべての有限語へ延長する。
状態写像の族 $`h_s:X_s(A)\to X_{u(s)}(B)`$ が、各生成操作 $`e:s\to t`$ および各 sort $`s`$ について

**式(7.1)**

```math
\begin{aligned}
h_s(D_e^A)&\subseteq\mathrm{Dom}_B(\tau(e)),\\
h_t(e_A(x))&=\tau(e)_B(h_s(x))\quad(x\in D_e^A),\\
o_{B,u(s)}h_s&=o_{A,s}
\end{aligned}
```

を満たすとする（全域操作については $`D_e^A=X_s(A)`$ と読む）。
このとき、任意の型付き有限語 $`w:s\rightsquigarrow t`$ と任意の $`x\in\mathrm{Dom}_A(w)`$ に対して

```math
\begin{aligned}
h_s(x)&\in\mathrm{Dom}_B(\tau(w)),\\
h_t(w_A(x))&=\tau(w)_B(h_s(x)),\\
o_{B,u(t)}(\tau(w)_B(h_s(x)))&=o_{A,t}(w_A(x))
\end{aligned}
```

が成り立つ。さらに、すべての生成操作で定義域の反射条件 $`D_e^A=h_s^{-1}\mathrm{Dom}_B(\tau(e))`$ が成り立つならば、任意の型付き有限語 $`w`$ についても $`\mathrm{Dom}_A(w)=h_s^{-1}\mathrm{Dom}_B(\tau(w))`$ が成立する。

**証明.**
操作語 $`w`$ の長さに関する帰納法で示す。

まず空語 $`w=\varnothing_s`$ の場合、$`w_A`$ と $`\tau(w)_B`$ はともに恒等写像である。
したがって定義域と像は自明に一致し、第三式は式(7.1)の第三式（観測の可換性）そのものである。

次に、語 $`w`$ について主張が成り立つと仮定し、$`w`$ の後に生成操作 $`e`$ を続けて実行できる状態 $`x\in\mathrm{Dom}_A(ew)`$ を取る。
帰納法の仮定より $`h_s(x)\in\mathrm{Dom}_B(\tau(w))`$ かつ $`\tau(w)_B(h_s(x))=h(w_A(x))`$ が成り立つ。
ここで $`w_A(x)\in D_e^A`$ なので、式(7.1)の第一式により中間状態 $`h(w_A(x))`$ において $`\tau(e)`$ が実行可能であり、ゆえに $`h_s(x)\in\mathrm{Dom}_B(\tau(ew))`$ を得る。
さらに式(7.1)の第二式をこの中間状態に適用すれば、合成後の値も $`h(e_A(w_A(x)))=\tau(e)_B(\tau(w)_B(h_s(x)))=\tau(ew)_B(h_s(x))`$ と一致する。
終点における観測の可換性 $`o_{B,u(t)}h_t=o_{A,t}`$ を適用すれば、第三式が従う。

最後に、すべての生成操作で定義域の反射が成り立つと仮定する。
前向き保存により $`\mathrm{Dom}_A(ew)\subseteq h_s^{-1}\mathrm{Dom}_B(\tau(ew))`$ はすでに得られている。
逆に $`h_s(x)\in\mathrm{Dom}_B(\tau(ew))`$ とすると、まず $`h_s(x)\in\mathrm{Dom}_B(\tau(w))`$ であるから、帰納法の仮定により $`x\in\mathrm{Dom}_A(w)`$ となり、中間状態 $`w_A(x)`$ が定義される。
このとき $`h(w_A(x))=\tau(w)_B(h_s(x))\in\mathrm{Dom}_B(\tau(e))`$ であるため、生成操作 $`e`$ に対する反射条件から $`w_A(x)\in D_e^A`$ が従い、ゆえに $`x\in\mathrm{Dom}_A(ew)`$ を得る。
これで両方向の包含が示された。□

理論解釈 $`u`$ から得られる語翻訳に対しては、定理2.4の評価の一致を適用できる。
多引数の操作とパラメータを含む一般の項に対しては、[定理1.8](../part_1/chapter_1_atoms_laws_theories.md#14-表示代入理論の射)の構文木に関する帰納法を用いればよい。
外部パラメータを固定する場合は、その sort の状態写像を恒等写像とする。
なお、定義域の前向き保存と反射は異なる仮定として区別して保持する。

**例7.3（台帳、空語、途中の read）.**
任意の可換環 $`R`$ 上で、単一台帳を状態 $`D=R`$、操作 $`\mathrm{apply}_u(x)=x+u`$、観測 $`\mathrm{read}(x)=x`$ で定める。
一方、分割台帳の状態を $`B\oplus C=R^2`$ とし、射影 $`p`$ および操作を

```math
\begin{aligned}
p(B,C)&=B+C,\\
\mathrm{apply}_u(B,C)&=(B+\lambda u,C+(1-\lambda)u),\\
\mathrm{compact}_t(B,C)&=(B+\mu t,C-\mu t)
\end{aligned}
```

と定める。パラメータ $`u,t`$ の sort は固定する。
ここで `apply` を単一台帳の `apply` へ、`compact` を空語へ翻訳すると、$`p\,\mathrm{apply}_u=p+u`$ および $`p\,\mathrm{compact}_t=p`$ が成り立つ。
分割台帳の `read` を $`p`$ とすれば式(7.1)が満たされるため、すべての有限語に対して定理7.2が適用できる。
操作の翻訳は分割台帳の理論から単一台帳の理論へ向かい、$`p`$ は零環以外の任意の環において $`(1,-1)`$ を核に持つ非単射の意味射となる。

次に、`apply` を `writeB` と `writeC` の2段階へ分割し、その途中にも `read` を行う言語を考える。
$`R=\mathbb Q`$、$`\lambda=1/2`$、$`u=2`$ とすると、途中の公開値は $`x+1`$ となるが、単一の不可分な（atomic な）`apply` の前後で観測される値は $`x`$ と $`x+2`$ のみである。
したがって、完了点における語翻訳の中には途中の `read` に対する対応は含まれていない。
細分した言語の意味射を求めるためには、途中のフェーズ（phase）とその観測を明示的に宣言し、式(7.1)を改めて課す必要がある。

## 7.3 すべての変更からなる関手と比較表示

ここでは、意味保存射そのものを対象とする変更の groupoid $`\mathcal C`$ を導入する。
続いて、元の二つの原始表示に状態射の記号と保存式を付け加えた比較表示を構成し、その混合解釈によって $`\mathcal C`$ の対象と比較射の全体を漏れなく復元できることを証明する。

**構成7.4（すべての変更とその比較）.**
設定7.1の意味圏 $`\mathcal A(U,R)`$ から、対象と同型からなる最大部分 groupoid と変更の groupoid をそれぞれ

```math
\mathcal M(U,R)=\mathcal A(U,R)^{\simeq},\qquad
\mathcal C(U,R)=\mathrm{Fun}([1],\mathcal A(U,R))^{\simeq}
```

と定める。$`\mathcal C`$ の対象は任意の意味保存射 $`h:A\to B`$ であり、$`h`$ から $`h'`$ への射（比較射）は、$`bh=h'a`$ を満たす同型の対 $`(a:A\xrightarrow{\sim}A',\ b:B\xrightarrow{\sim}B')`$ である。
始域および終域を取る関手を $`s,t:\mathcal C\to\mathcal M`$ と書く。
係数変更と文脈制限は図式の各頂点と辺へ成分ごとに作用する。
その単位比較・合成比較は各成分で意味圏 $`\mathcal A`$ の比較同型に一致するため、$`\mathcal C`$ も擬関手となる。

**構成7.5（原始宣言からの比較表示）.**
設定7.1の実現方式 $`\sigma`$、原始表示 $`\mathcal P_0,\mathcal P_1`$、および理論解釈 $`u`$ を固定する。
両表示の宣言は添字 $`0`$ と $`1`$ で区別するが、固定された観測値 sort や外部パラメータ sort とその固定構造は共有し、複製しない。
各可変 sort $`s`$ に写像記号 $`H_s:s_0\to u(s)_1`$ を追加し、固定 sort については $`H_s`$ を恒等とする。
さらに次の保存式を課す。

```math
\begin{aligned}
H_t f_0(\boldsymbol x)&=\tau_f{}_1(H_{\boldsymbol s}\boldsymbol x),\\
r_0(\boldsymbol x)&\ \Longrightarrow\ u(r)_1(H_{\boldsymbol s}\boldsymbol x),\\
D_p^0(\boldsymbol x)&\ \Longrightarrow\ u(D_p)_1(H_{\boldsymbol s}\boldsymbol x),\\
D_p^0(\boldsymbol x)&\ \Longrightarrow\
 H_t p_0(\boldsymbol x)=\tau_p{}_1(H_{\boldsymbol s}\boldsymbol x),\\
H_q q_0(\boldsymbol x)&=u(q)_1(H_{\boldsymbol s}\boldsymbol x),\\
o_{1,u(s)}H_s&=o_{0,s}.
\end{aligned}
```

ここで第五式は量の保存を表し、量の値 sort を固定する場合は $`H_q=\mathrm{id}`$ と読む。
部分的な量については、その定義域の前向き保存もあわせて課し、第五式を定義域上で読む。
また、部分項の等式は第1章の値グラフによって解釈する。
翻訳された定義域と項の定義可能性の一致は理論解釈 $`u`$ の導出に含まれるため、第四式の右辺はその入力において確実に定義される。

こうして得られる比較表示を $`\mathcal P_{01,u}`$ と書き、その**混合解釈**を次のように定義する。

- $`0`$ 側と $`1`$ 側の各宣言群には、それぞれ独立に方式 $`\sigma`$ の対象条件と Law を課す。
- 写像記号 $`H_s`$ には、担体の間で方式 $`\sigma`$ が許す任意の写像を割り当て、上記の保存式を課す。具体的には、集合ではすべての入力に対する式として、層では可換図式および関係・定義域の部分層への因子分解として、加群では指定された線形写像の可換式として解釈する。
- 混合解釈の間の比較射は、両端の構造同型の対であってすべての $`H_s`$ と可換するものとする。

この groupoid を $`\mathrm{Cmp}_\sigma(\mathcal P_0,\mathcal P_1;u)`$ と書く。
混合解釈では、$`H_s`$ が既存の項から生成されることや、両端と共通の被覆上で局所的に分裂することは要求しない。
その意味で、通常の方式 $`\sigma`$ を拡張署名全体へ一括適用するモデル概念とは明確に区別する。

文脈対 $`(U_0,U_1)`$ による比較表示の制限では、設定7.1における翻訳の支持と導出木の条件に加え、残す $`0`$ 側 sort の $`H_s`$ と、残す原始宣言に対応する上記の保存式をすべて残すものとする。
特に、全域操作・量の全域性と部分操作の定義域一致を証明する導出木中の宣言・必須 Law を $`U_1`$ に保持する。これにより制限後も定義1.9の全条件が成り立ち、保存式の右辺を同じ翻訳項によって評価できる。
共有 sort とその固定条件も保持する。
これは単に $`\mathcal P_{01,u}`$ の任意の依存閉部分を取る操作ではないことに注意する。

**定理7.6（射集合全体の表示と回復）.**
設定7.1と構成7.5の下で、groupoid $`\mathrm{Cmp}_\sigma(\mathcal P_0,\mathcal P_1;u)`$ は、独立な $`\sigma`$-モデル $`A,B`$ とすべての意味射 $`h:A\to u^*B`$ からなる groupoid に同値である。
特に、両端を厳密に固定して比較を恒等に限ったときのファイバーは、射集合全体 $`\mathrm{Hom}(A,u^*B)`$ と一致する。
さらに、翻訳添字と理論同型による比較も含めた混合解釈は、全体圏の変更 groupoid $`\mathcal C`$ に同値である。
これらの同値は、構成7.5の文脈制限および設定7.1の係数変更に対して擬自然である。

**証明.**
まず固定した解釈 $`u`$ について示す。
混合解釈から $`0`$ 側と $`1`$ 側の担体・原始構造を読み取り、$`H_s`$ の解釈を $`h_s`$ と置く。
両側の対象条件と Law から $`A,B`$ はそれぞれ $`\sigma`$-モデルとなり、追加された6種類の保存式は方式 $`\sigma`$ における操作、関係、定義域、量、観測の保存条件そのものである。
設定7.1の担体の同一視と原始構造の評価条件により、この写像族は意味射 $`h:A\to u^*B`$ を一意に定める。
逆に、独立に与えられた $`A,B`$ と意味射 $`h:A\to u^*B`$ の担体と写像を各宣言へ代入すると、意味射の定義からすべての保存式が成立する。
これら両方向の対応は担体・各操作・各写像をそのまま元に戻す。
比較同型の可換条件は $`(u^*b)h=h'a`$ であるから、すべての比較対も一意に相互回復され、恒等射と合成も成分ごとに一致する。
両端を厳密に固定した場合、比較は恒等対のみとなるため、ファイバーとして射集合全体を得る。

次に全体圏の場合を扱う。ここでは解釈 $`u:\mathbb T_0\to\mathbb T_1`$ 自体を対象データに含める。
$`(u,h)`$ と $`(u',h')`$ の間の比較射は、理論同型 $`\alpha:\mathbb T_0\cong\mathbb T'_0`$、$`\beta:\mathbb T_1\cong\mathbb T'_1`$ と状態同型 $`a:A\cong\alpha^*A'`$、$`b:B\cong\beta^*B'`$ の組であって、

```math
\beta u=u'\alpha,\qquad
\kappa_{u,\beta,B'}(u^*b)h
 =\kappa_{\alpha,u',B'}(\alpha^*h')a
```

を満たすものとする。両辺の終域はともに $`(\beta u)^*B'`$ である。
この等式は全体圏における可換正方形の条件そのものであり、逆に全体圏の任意の可換正方形を二つの理論成分と二つの状態成分へ分解すれば上のデータに戻る。
比較の合成は全体圏の合成に一致し、$`\kappa`$ の整合条件により再び同じ可換式を満たす。
したがって、翻訳添字を含むすべての対象と比較射が相互に回復される。
なお、導出木は解釈の同一視のために用いるものであり、特定の導出木の選択を対象の追加データには含めない。

最後に、文脈制限と係数変更に対する擬自然性を確かめる。
文脈制限においては、残す担体と写像は変わらず、必要な翻訳と保存式もすべて保持されるため、評価の後に制限する操作と制限の後に評価する操作はまったく同じモデルと同じ射を返す。
環射 $`\ell:R\to R'`$ による係数変更では、状態射 $`h`$ を合成
$`B_\ell A\xrightarrow{B_\ell h}B_\ell u^*B\xrightarrow{\chi_{\ell,u}}u^*B_\ell B`$
へ送るが、混合解釈の各宣言を運んだ場合も同じ式になる。
比較射の両端も $`B_\ell a,B_\ell b`$ と必要な $`\chi`$ によって運ばれ、$`\chi`$ の自然性から可換正方形が保たれる。
単位および2段階の係数変更に対する二つの比較同型は、設定7.1の整合条件により各宣言ごとに一致し、文脈制限との交換も残した各成分で同じ比較同型を与える。
以上により、対象およびすべての比較射についての擬自然性とその整合が得られた。□

## 7.4 恒等射・合成と nerve

単一の変更を扱う groupoid $`\mathcal C`$ を一般化し、合成可能な $`n`$ 本の変更の鎖全体を考える。
以下の定理は、この鎖の族が 2-ファイバー積によって記述され、恒等射の挿入や隣接射の合成が単体的（simplicial）な nerve 構造をなすことを保証する。

**定理7.7（合成可能な変更の全体と nerve）.**
各 $`n\ge0`$ に対して $`N_n=\mathrm{Fun}([n],\mathcal A)^{\simeq}`$ と置く。
このとき $`N_0=\mathcal M`$、$`N_1=\mathcal C`$ であり、任意の $`n\ge2`$ に対して自然な同値

**式(7.2)**

```math
N_n\simeq
\underbrace{\mathcal C\mathbin{\times^{(2)}_{t,\mathcal M,s}}\cdots
\mathbin{\times^{(2)}_{t,\mathcal M,s}}\mathcal C}_{n\text{ 個}}
```

が成り立つ。恒等射を挿入する写像と隣り合う辺を合成する写像は単位律・結合律を満たし、設定7.1の下で混合解釈の合成は意味圏の合成に一致する。
さらに、この同値とすべての面写像・退化写像は、設定7.1の係数変更および文脈族の制限に対して擬自然である。

**証明.**
まず式(7.2)の右辺の 2-ファイバー積を具体的に書き下す。
その対象は、射の列 $`f_i:A_{i-1}\to B_i`$（$`1\le i\le n`$）と、つなぎ目の同型 $`\theta_i:B_i\xrightarrow{\sim}A_i`$（$`1\le i<n`$）の組である。
射は各 $`f_i`$ に対する可換な同型対の列であって、隣接する対が $`\theta_i`$ とも可換するものとする。
この対象から、$`N_n`$ の対象である長さ $`n`$ の鎖

```math
A_0\xrightarrow{f_1}B_1
\xrightarrow{f_2\theta_1}B_2\longrightarrow\cdots
\xrightarrow{f_n\theta_{n-1}}B_n
```

を構成する。逆に、長さ $`n`$ の鎖から、すべてのつなぎ目の同型を恒等射として右辺の対象を作る。
鎖から出発する往復は厳密に恒等となる。
一方、右辺の一般の対象から出発する往復においては、各始域 $`A_i`$ と直前の終域 $`B_i`$ の間の同型 $`\theta_i`$ が自然な同型を与え、比較の可換式によってその同型はすべての辺と可換する。
二つの鎖の間の射は頂点ごとの同型と辺の可換式によって一意に定まり、右辺の比較射も同じ条件へ帰着する。
ゆえにこれら二つの関手は互いに準逆であり、式(7.2)の同値を得る。

次に単体的構造を確認する。
鎖の内部頂点を除く面写像は隣接する2射の合成、端を除く面写像は対応する端の辺の忘却、退化写像は恒等射の挿入として定義される。
三つの辺に対して二通りの順序で内部頂点を除いても、圏の結合律により同じ合成を得る。
恒等射の挿入の後に合成を行えば単位律によって元に戻り、互いに離れた頂点への操作は可換する。
これらにより単体的（simplicial）な関係式がすべて成り立つ。

続いて、比較表示側での合成との一致を見る。
表示側では恒等射に $`H_s=\mathrm{id}`$、合成に $`H_s'=K_{u(s)}H_s`$ を代入する。固定理論では $`u(s)=s`$ なので $`H_s'=K_sH_s`$ である。
操作の可換式は $`KHf=K\tau(f)H=\tau'(\tau(f))KH`$ となり、関係および定義域の保存は二つの保存条件を順に適用して従う。
理論を動かす場合の合成式は $`\kappa_{u,v}\circ u^*k\circ h`$ である。設定7.1の評価条件により、その担体成分はちょうど $`K_{u(s)}H_s`$ であり、恒等射 $`\eta_A`$ の担体成分は恒等写像となる。$`\kappa`$ の自然性と五角形の整合条件は、これらの同一視と三つの射の合成との整合を与える。
定理7.6の読戻しもこの具体的な合成写像を返す。

最後に擬自然性を確かめる。
係数変更または宣言制限の関手を $`F`$ と書くと、$`F(f_{i+1}\theta_i)=F(f_{i+1})F(\theta_i)`$ および $`F(\mathrm{id})=\mathrm{id}`$ が成り立つため、鎖への復元、すべての比較射、面写像および退化写像は $`F`$ と可換する。
2段階の係数変更に対する比較同型は、鎖の各頂点に実現方式の比較同型を配置した自然同型であり、各辺との可換性はその自然性から従う。
3段階の比較同型は各頂点で設定7.1の五角形整合に一致する。
宣言制限を混ぜた場合も残された成分上で同じ図式となるため、求める擬自然性が従う。□

なお、$`N_n`$ を構成する辺 $`f_i`$ は可逆である必要はない。
可逆性を要求するのは、あくまで鎖どうしを比較する射（同型）である。
例えば例7.3の射影を辺とする鎖は $`N_1`$ の対象に含まれる。
この区別によって、対象の同型分類とすべての変更（非可逆な変更を含む）の合成構造を同時に保持できる。

## 7.5 幾何的表現の条件と元の変更への回復

ここまで一般の意味圏の枠組みで構成してきた射集合と変更 groupoid に対し、多項式演算と線形状態射からなる有限実現方式では、具体的なアフィンスキームおよび作用 groupoid による表現が得られる。
以下では、まず両端を固定した線形状態射のアフィン表示を示し、次に基底変更と係数 descent を含む多項式族全体の表示を構成する。

**定理7.8（線形状態射のアフィン表示）.**
可換環 $`R`$、有限個の sort、および固定翻訳 $`u`$ を取り、両端のモデル $`A,B`$ の担体をそれぞれ有限自由加群 $`R^{m_s}`$、$`R^{n_t}`$ とする。
固定された観測値 sort の担体は $`R^{k_s}`$、固定された外部パラメータ sort も指定された有限自由加群とし、それらの sort 上での状態比較は恒等とする。
全域操作・量・観測は有限変数の多項式で与え、Law と保存式はすべての $`R`$-代数上の自然写像の等式として読む。
状態比較には各代数上で線形な自然写像を許すものとする。
関係と部分操作を含まないこの実現方式において、すべての意味射のなす関手は次のアフィンスキームで表される。

```math
\mathrm{Hom}_{u}(A,B)=\mathrm{Spec}\,R[z_{s,ij}]/I_{A,B,u}.
```

ここで、各可変 sort $`s`$ の行列 $`Z_s=(z_{s,ij})`$ は $`n_{u(s)}\times m_s`$ 行列、共有する固定 sort の $`Z_s`$ は恒等行列であり、$`I_{A,B,u}`$ は

```math
Z_t f_A(\boldsymbol x)-\tau_f{}_B(Z_{\boldsymbol s}\boldsymbol x),
\qquad o_B(Z_sx)-o_A(x)
```

のすべての出力成分におけるすべての単項式係数が生成するイデアルである。
原始操作・観測と保存式が有限族であるならば、これは有限表示のアフィンスキームとなる。

**証明.**
任意の $`R`$-代数 $`S`$ 上で、すべての $`S`$-代数 $`T`$ に対する線形な自然写像 $`h_T:T^{m_s}\to T^{n_{u(s)}}`$ を考える。
$`h_S`$ による標準基底の像を並べることで行列 $`H_s`$ が定まり、自然性からすべての $`T`$ において $`h_T`$ はこの行列の係数拡張となり、線形性から任意の入力での値が一意に決まる。
逆に、任意の行列 $`H_s`$ はこのような線形な自然写像を与える。

次に保存式を多項式環 $`S[\boldsymbol x]`$ 上の普遍入力 $`\boldsymbol x`$ で評価すると、すべての $`S`$-代数上で保存式が成り立つことは、残差多項式のすべての単項式係数が $`0`$ であることと同値である（逆向きは任意の代入で等式が成り立つことから直ちに従う）。
[補題B.2](../appendix_b_coefficients_and_descent.md#b1-係数とアフィン構成)により、この条件を満たす行列の組は商環 $`R[z_{s,ij}]/I_{A,B,u}`$ から $`S`$ への環射と全単射に対応する。
行列を読み出す操作と写像記号を評価する操作が互いに逆であるため、定理7.6の射集合全体が完全に回復される。
さらに、係数を環射で送る操作は単項式展開と可換であるため、この対応は $`S`$ について自然である。□

続いて、両端のモデル自体も多項式係数として動かし、基底変更と局所自由担体の descent を含めた変更族を構成する。

**命題7.9（多項式族のチャート・基底変更・係数 descent）.**
有限個の sort、有限個の全域操作・量・観測、有限個の多項式 Law、および型を保つ翻訳 $`u`$ を固定する。
各担体を指定階数の有限局所自由加群とし、各原始写像 $`f`$ に総次数上限 $`d_f`$ を与える。
共有する固定 sort と固定データの比較は恒等とする。
操作は各自由化の上で多項式として与え、状態射は線形とする。
この実現方式において、次の四つが成り立つ。

1. 両端に基底を選んだ変更の全体は、両端の単項式係数と状態行列を変数とする有限表示アフィンスキームで表される。
2. 両端の基底変更 $`G_s,F_t`$ は第6章と同じ右作用をなし、状態行列は $`H_s\mapsto F_{u(s)}^{-1}H_sG_s`$ へ移る。この作用 groupoid は、基底を持つ両端の間のすべての比較を保持する。
3. Zariski 被覆および fppf 被覆について、対象とすべての線形状態射が降下する。これにより、有限局所自由な担体を持つすべての変更とすべての比較が回復される。
4. 係数変更、構成7.5の文脈制限、および型を保つ多項式項の代入は整合する。ただし、次数上限を持つ部分族へ制限するときは、その次数上限を保つ翻訳を用いる。

**証明.**
四つの主張を順に証明する。

**1 の証明.**
自由な担体上の操作 $`f`$ を、入力変数 $`\boldsymbol x`$ に対して $`\sum_{|\nu|\le d_f}c_{f,i,\nu}\boldsymbol x^\nu`$ と展開する。
両端のすべての係数と状態行列の成分を変数とする多項式環を構成し、Law と保存式にこれらを代入・展開して得られるすべての残差係数で割る。
固定する原始写像については、対応する係数が指定値に等しいという等式を課す。
すべての代数上で等式が成り立つこととすべての残差係数が $`0`$ であることは、多項式環の一般元への評価および任意の元への代入によって同値である。
スキームの点からすべての原始写像と状態射を復元し、改めて係数を読み出せば元の点に戻るため、1 が示された。

**2 の証明.**
新しい基底を旧基底に可逆行列 $`G,F`$ を右から掛けて構成する。
このとき原始操作と状態射の新座標は

```math
f_A'(\boldsymbol x)=G_t^{-1}f_A(G_{\boldsymbol s}\boldsymbol x),\qquad
g_B'(\boldsymbol y)=F_w^{-1}g_B(F_{\boldsymbol r}\boldsymbol y),\qquad
H_s'=F_{u(s)}^{-1}H_sG_s
```

で与えられる。ここで $`g_B`$ は $`1`$ 側の任意の原始操作 $`\boldsymbol r\to w`$ であり、固定 sort に対しては行列を恒等行列と読む。
項の構造に関する帰納法により翻訳 $`\tau_f`$ の内部に現れる基底変更は互いに相殺されるため、保存残差 $`r`$ は $`r'(\boldsymbol x)=F_{u(t)}^{-1}r(G_{\boldsymbol s}\boldsymbol x)`$ と変換される。
逆の基底変更でも同じ形の変換となるため、すべての係数の零性は同値である。
2回の基底変更は行列積 $`(G,F)(G',F')`$ に対応し、右作用を定める。
作用の矢は両端に $`G^{-1},F^{-1}`$ を持つ構造同型を与え、逆に任意の両端の同型対は一意な可逆行列対を持つ。
これで 2 のすべての比較の回復が示された。

**3 の証明.**
一般の有限局所自由担体において、操作の入力担体の直和を $`E`$、出力担体を $`F`$ とする。
総次数 $`d`$ 以下の係数を持つ多項式写像は、加群層

```math
F\otimes\bigoplus_{i=0}^{d}\mathrm{Sym}^i(E^\vee)
```

の切断と一対一に対応する。実際、局所自由化の上では右辺の基底が出力基底と入力単項式の組になり、切断を多項式評価する写像と一般元から係数を読む写像が互いに逆となる。
自由化の変更において、上記の線形代入は両辺に同じ作用を与えるため、この対応は開被覆上で貼り合う。
これが多重線形演算から多項式演算へ移る際に用いる係数加群である。

ここで[補題B.4・B.5](../appendix_b_coefficients_and_descent.md#b2-忠実平坦な係数descent)を用いると、被覆上の担体とすべての線形写像が降下する。
双対、有限直和、有限次対称冪は有限局所自由加群の基底上の構成と整合するため、上記の係数加群の整合切断も補題B.4により一意に降下し、したがってすべての原始多項式写像が降下する。
Law と状態射の保存式は、自由化上の残差係数に忠実平坦性を適用することで降下する。
逆写像を持つ局所比較については逆写像も降下し、一意性により互いに逆となる。
以上が 3 である。基底を忘れた変更の全体は、チャートの作用 groupoid にこの descent を施して得られる。

**4 の証明.**
任意の環射で係数と行列の成分を送ると、和・積・代入・逆行列の式がすべて保存される。
局所自由な場合にも、双対と対称冪からなる上の係数加群は引戻しと可換する。
恒等および2段階の係数変更は各係数に同じ環射を適用する操作であり、3段階の整合も同じ合成積になる。
文脈制限は残す係数を抜き出すだけであり、項の代入は多項式の合成そのものである。
よって 4 を得る。この構成を**多項式実現方式**と呼び、設定7.1の条件を満たす方式として以下で用いる。□

翻訳添字 $`u`$ を複数許すときは、その添字も対象データとして保持する。
固定した離散添字集合を用いるなら各表示の族を取り、添字間の同型も許す場合には7.3節の比較を加える。
なお、スキームの直和は試験スキームの開閉部分ごとに異なる添字を選ぶ点も含むため、全域で一つの翻訳を指定する関手と比較する際には、そのような局所選択を許すか否かを明示的に指定する。

以下に、射のクラスの選び方、混合解釈と通常の複製方式との違い、無限 protocol における射集合、および lens の非可逆な忘却を示す三つの具体例を挙げる。

**例7.10（射のクラスと局所表示）.**
裸の集合 $`\mathbb Z`$ のすべての自己写像の中には $`x\mapsto x^2`$ のような非線形写像も含まれる。
これに対し加群構造を宣言して線形射のみを取ると、自己射は $`x\mapsto ax`$ に限られる。
定理7.8の行列チャートが表すのは後者の射集合全体である。
また、$`\mathbb F_p`$ 上では多項式 $`x^p-x`$ は基礎体のすべての点で $`0`$ を取るが、$`\mathbb F_p[t]`$ の入力 $`t`$ に対しては $`0`$ ではない。
すべての代数上の自然写像の等式を用いて係数を抽出する枠組みは、この二つを明確に区別する。

さらに、通常の複製方式を比較表示全体へ適用すると、構成7.5の混合解釈とは異なる結果になることも具体的に確かめられる。
$`R=\prod_{n\in\mathbb N}\mathbb F_2`$、$`A=\underline{\mathbb N}_R`$、$`B=\underline{\{0,1\}}_R`$ とし、両端に操作を置かない。
第 $`n`$ 成分だけが $`1`$ である冪等元を $`e_n`$ とすると、入力 $`n`$ に対する係数 $`a_{n,1}=e_n`$、$`a_{n,0}=1-e_n`$ は定理4.3の射集合全体の条件を満たす。
これにより層の射 $`h:A\to B`$ と構成7.5の混合解釈が得られる。
ここで有限な台（サポート）を持つ元のイデアルを含む極大イデアル $`\mathfrak p`$ を取ると、そのファイバーではすべての $`e_n`$ が $`0`$ になるため、$`h`$ の像は1点のみである。
他方、$`\mathfrak p`$ の任意の基本開近傍 $`D(f)`$ では $`f\notin\mathfrak p`$ なので、ある番号 $`m`$ で $`f_m=1`$ となる。
第 $`m`$ 座標での評価の核も $`D(f)`$ に属し、そのファイバーでは $`h(m)=1`$、$`n\ne m`$ に対して $`h(n)=0`$ となるため、像は2点になる。
像の濃度は両端の同型によって不変であるから、$`\mathfrak p`$ のどの開近傍上でも三つ組 $`(A,B,h)`$ は単一の元の構造の定数実現にはならない。
すなわち、両端を局所的に分裂させることと、追加の写像も同じ開被覆上で局所的に分裂させることとは異なる条件である。

**例7.11（無限 protocol の射集合全体と係数列）.**
可換環 $`R`$ と係数列 $`a=(a_n)_{n\ge0}`$ を取る。
各 $`n\ge0`$ に状態 sort $`X_n=R`$、全体で共有する外部パラメータ sort $`R`$ を置き、操作を

```math
T_{n,u}(x)=x+u,\qquad d_n^a:X_{n+1}\to X_n,\quad d_n^a(x)=2x+a_n
```

と定める。観測は定数とし、パラメータ sort は固定する。
Law $`T_{n,0}=\mathrm{id}`$、$`T_{n,u+v}=T_{n,u}T_{n,v}`$、および $`d_n^aT_{n+1,u}=T_{n,2u}d_n^a`$ は直接計算により成り立つ。
この実現を $`A^a`$ と書く。

$`A^a`$ から $`A^b`$ への意味射 $`h=(h_n)`$ を考える。
平行移動 $`T_{n,u}`$ の保存より、$`h_n(x)=h_n(T_{n,x}(0))=x+c_n`$（ただし $`c_n=h_n(0)`$）と表されなければならない。
残る生成操作 $`d_n`$ の可換性は

```math
2x+a_n+c_n=2x+2c_{n+1}+b_n
\quad\Longleftrightarrow\quad c_n-2c_{n+1}=b_n-a_n
```

と同値である。逆に、このすべての方程式を満たす係数列 $`(c_n)`$ はすべての原始操作を保つ。
したがって、射集合全体はこの方程式のすべての解と全単射に対応し、恒等射は零列、射の合成は列の成分ごとの加法になる。
環射はすべての係数をそのまま送り、すべての代数上で自然な射についても一般元 $`0`$ の像を取ることで同じ列が回復される。
特に $`A^0\to A^a`$ のすべての変更は方程式 $`c_n-2c_{n+1}=a_n`$ によって分類される。
状態 sort $`X_0,\ldots,X_N`$ と操作 $`d_0,\ldots,d_{N-1}`$ からなる有限断片では、$`c_N`$ を任意に選んで後退代入することで有限解の全体が得られる。
第13章では、こうした有限断片上の解と、無限列全体として整合する解の全体とを比較する。

**例7.12（lens のすべての変更と非可逆な忘却）.**
非空の固定されたビュー（view）集合 $`V`$ に対し、状態空間 $`V\times C`$ 上に操作 $`\mathrm{get}(v,c)=v`$ および $`\mathrm{put}((v,c),w)=(w,c)`$ を持つ積 lens を考える。
同じビューを持つ積 lens $`V\times C'`$ へのすべての意味射は、写像 $`r:C\to C'`$ によって

```math
h_r(v,c)=(v,r(c)),\qquad r:C\to C'
```

の形に一意に対応する。
実際、`get` の保存から $`h(v,c)=(v,r_v(c))`$ と書け、`put` の保存から任意の $`v,w\in V`$ に対して $`r_w(c)=r_v(c)`$ が従う。
基準となるビューを一つ選べば $`v`$ によらない共通の $`r`$ を得る。逆に、任意の写像 $`r:C\to C'`$ は二つの操作をともに保存し、合成は $`h_{r'}h_r=h_{r'r}`$ で与えられる。
$`C=\{0,1\}`$、$`C'=\{*\}`$ とすれば、射影は非単射な忘却の変更を与える。
構成7.4の枠組みではこれも対象であり、$`r:C\to C'`$ と $`r':D\to D'`$ の比較射は、$`br=r'a`$ を満たす補助集合の全単射対 $`(a:C\cong D,\ b:C'\cong D')`$ である。
したがって、射集合全体だけでなくすべての比較射と合成も同じデータによって完全に回復される。

**問題7.13（一般の実現方式の表現）.**
関係・部分操作の定義域や無限担体を持つ一般の実現方式について、定理7.6の比較表示からすべての状態射と比較を回復する表示系を構成せよ。
特に、状態射の座標化、原始評価の正則性、翻訳添字および係数 descent をどのような条件から導けるかを明らかにせよ。
複製方式においては、[定理4.6](../part_2/chapter_4_coefficient_realizations.md#43-無限担体と全域性)の入力ごとの有限な台（サポート）を保持する表示が出発点となる。
なお、一般の変更 groupoid $`\mathcal C`$、始域・終域関手 $`s,t`$、および nerve は、これらの幾何的表現条件を仮定せずにすでに構成されている。
