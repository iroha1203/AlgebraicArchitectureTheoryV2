# 第9章 商・対称性・持ち上げの分類

操作と観測を保つ変更には、状態を同一視する商、商の代表を選ぶ射、
可視な変更を内部状態へ持ち上げる射がある。
これらはそれぞれ異なる固定データを持つ変更問題である。
本章では実際の状態写像からその全体を構成し、
商を合同関係の区間、代表選択を冪等射の分裂、可逆な持ち上げをholonomyの方程式で分類する。

## 9.1 操作合同関係と観測同値

**定義9.1（操作系と合同関係）.**
小さい集合 $`S,E,O`$、各名前 $`e\in E`$ に対する全域操作
$`T_e:S\to S`$、観測 $`o:S\to O`$ を固定する。
状態集合と操作名の集合は空でもよい。
有限語 $`w=e_m\cdots e_1`$ の作用は
$`T_w=T_{e_m}\circ\cdots\circ T_{e_1}`$、空語の作用は恒等とする。

操作合同関係は、全ての $`e`$ について
$`x\mathrel\theta y\Rightarrow T_e(x)\mathrel\theta T_e(y)`$ となる同値関係
$`\theta\subseteq S\times S`$ である。
包含を順序とするその集合を $`\mathrm{Con}(S,T)`$ と書く。
任意の交差は再び操作合同関係であり、空交差は全関係である。
したがって下限は交差、上限は全ての上界の交差で与えられ、これは完備束になる。
最小元は等号、最大元は全関係である。

同一視要求 $`\mathscr R\subseteq S\times S`$ に対し、
それを含む全操作合同関係の交差を $`\equiv_{\mathscr R}`$ とする。
要求自体には対称性や推移性を仮定しない。
また、全操作語による観測同値を

**式(9.1)**

```math
x\approx_o y
\quad\Longleftrightarrow\quad
\forall w\in E^*,\quad o(T_w(x))=o(T_w(y))
```

と定める。

**命題9.2（生成合同関係と最大の観測保存合同関係）.**
任意の $`\theta\in\mathrm{Con}(S,T)`$ に対して

```math
\equiv_{\mathscr R}\subseteq\theta
\ \Longleftrightarrow\ \mathscr R\subseteq\theta,
\qquad
\theta\subseteq\approx_o
\ \Longleftrightarrow\ \theta\subseteq\ker o
```

が成り立つ。特に $`\approx_o`$ 自身が操作合同関係である。

**証明.**
第一の同値は交差の定義による。
式(9.1)は同値関係の交差なので同値関係である。
$`x\approx_o y`$ なら、任意の語 $`w`$ に対する語 $`we`$ を用いて
$`o(T_wT_e(x))=o(T_wT_e(y))`$ となるので操作にも安定である。
空語から $`\approx_o\subseteq\ker o`$ を得る。
逆に $`\theta\subseteq\ker o`$ なら、操作安定性の語長に関する帰納法により
$`x\mathrel\theta y`$ から $`T_w(x)\mathrel\theta T_w(y)`$ が従う。
そこで観測を取れば式(9.1)を得る。□

**例9.3（現在の観測と一操作後の観測）.**
$`S=\{0,1,2\}`$、$`O=\{0,1\}`$ とし、操作名を一つ $`e`$ とする。

| 状態 $`x`$ | $`o(x)`$ | $`T_e(x)`$ | $`o(T_e(x))`$ |
| --- | --- | --- | --- |
| $`0`$ | $`0`$ | $`0`$ | $`0`$ |
| $`1`$ | $`0`$ | $`2`$ | $`1`$ |
| $`2`$ | $`1`$ | $`2`$ | $`1`$ |

$`0,1`$ は現在の観測で一致するが、操作 $`e`$ の後には区別される。
従って $`\ker o`$ は操作合同関係ではなく、$`\approx_o`$ は等号である。
要求 $`\mathscr R=\{(0,1)\}`$ の生成合同関係は、操作安定性から $`0\equiv_{\mathscr R}2`$ も含み、
全関係となる。この要求を観測保存の下で実現できるかは、次節の区間の非空性で決まる。

## 9.2 商修復の区間と要求の合成

本節の意味圏は、名前付き全域操作と固定した観測値集合 $`O`$ を持つ状態集合の圏である。
射 $`f:(S,T,o)\to(S',T',o')`$ は
$`fT_e=T'_ef`$、$`o'f=o`$ を満たす写像である。
これは[第2章の意味圏](../part_1/chapter_2_models_and_morphisms.md#22-lawを満たすモデルと観測)で、
state sort、名前付き操作、固定観測sortと観測操作を指定した場合である。
操作語の等式をLawとして加えた場合も、以下の商へ同じ等式が降りる。

**定義9.4（商修復とその比較）.**
$`(S,T,o,\mathscr R)`$ の商修復は、状態集合 $`Q`$、全域操作 $`\overline T_e`$、
観測 $`\overline o:Q\to O`$ と、全射 $`q:S\twoheadrightarrow Q`$ で

**式(9.2)**

```math
qT_e=\overline T_eq,\qquad
\overline o q=o,\qquad
x\mathrel{\mathscr R}y\ \Longrightarrow\ q(x)=q(y)
```

を満たすものである。
二つの商修復の間の比較射は意味保存射 $`f:Q\to Q'`$ で $`fq=q'`$ を満たすものとする。
恒等と合成は写像の恒等と合成で与えられる。

**定理9.5（全商修復の分類）.**
任意の $`S,E,O,T,o,\mathscr R`$ に対し、商修復の圏は包含順序の圏

**式(9.3)**

```math
\left\{\theta\in\mathrm{Con}(S,T)\ \middle|\
  \equiv_{\mathscr R}\subseteq\theta\subseteq\approx_o\right\}
```

と同値である。対応は $`q\mapsto\ker q`$ であり、
逆方向は $`\theta\mapsto(S\twoheadrightarrow S/\theta)`$ から構成される。
従って商修復が存在することは $`\equiv_{\mathscr R}\subseteq\approx_o`$ と同値であり、
元の $`S`$ からの射と可換な同型までの分類も式(9.3)で与えられる。

**証明.**
商修復 $`q`$ に対し、$`q(x)=q(y)`$ なら

```math
q(T_e(x))=\overline T_e(q(x))
 =\overline T_e(q(y))=q(T_e(y))
```

なので $`\ker q`$ は操作合同関係である。
式(9.2)と命題9.2から
$`\equiv_{\mathscr R}\subseteq\ker q\subseteq\approx_o`$ を得る。

逆に式(9.3)の $`\theta`$ から、実際の商集合 $`Q_\theta=S/\theta`$ を取り、

```math
q_\theta(x)=[x]_\theta,\qquad
\overline T_e([x]_\theta)=[T_e(x)]_\theta,\qquad
\overline o([x]_\theta)=o(x)
```

と定める。操作安定性と $`\theta\subseteq\ker o`$ により、二つの写像は代表によらない。
商写像は全射であり、要求を含むことから最後の条件も成り立つ。
各操作語について $`T_w`$ が商へ降りるので、元の操作語の等式も保存される。

任意の商修復 $`q`$ には
$`[x]_{\ker q}\mapsto q(x)`$ という全単射 $`S/\ker q\to Q`$ がある。
同じ式で操作と観測を保ち、$`S`$ からの商写像と可換する。
逆写像もこれらの構造を保つので、意味圏の同型である。
また $`\ker q_\theta=\theta`$ である。

全ての比較射も回復する。
$`fq=q'`$ なら $`\ker q\subseteq\ker q'`$ である。
逆にこの包含があれば $`f(q(x))=q'(x)`$ と定められる。
包含から代表によらず、$`q`$ の全射性から一意である。
任意の $`z=q(x)`$ に対して

```math
f(\overline T_e(z))=f(q(T_e(x)))
 =q'(T_e(x))=\overline T'_e(f(z)),\qquad
\overline o'(f(z))=o(x)=\overline o(z)
```

となる。よって全Homが包含に対応する。
恒等包含は恒等射、二つの包含の合成は合成写像に対応する。
相互の包含はkernelの等号であり、対応する二射の合成は全射 $`q,q'`$ の上で恒等となる。
以上が圏同値と同型類の分類を与える。□

この証明では $`Q`$ の操作と観測も復元した。
同じ全射 $`q`$ の上で式(9.2)を満たす降下操作と観測は、
任意の $`z=q(x)`$ で値が決まるため一意である。
空の状態集合では全射の終域も空となり、同じ構成が成り立つ。

**命題9.6（要求族の合成）.**
任意の小さい添字集合 $`I`$ と要求族 $`(\mathscr R_i)_{i\in I}`$ に対して

**式(9.4)**

```math
\equiv_{\bigcup_{i\in I}\mathscr R_i}
 =\bigvee_{i\in I}\equiv_{\mathscr R_i},
\qquad
\equiv_{\bigcup_i\mathscr R_i}\subseteq\approx_o
\ \Longleftrightarrow\
\forall i,\ \equiv_{\mathscr R_i}\subseteq\approx_o
```

が成り立つ。空の要求族の生成合同関係は等号である。

**証明.**
合同関係 $`\theta`$ が左辺の生成元を含むことは、全ての $`\mathscr R_i`$ を含むことと同値である。
命題9.2によれば、これは全ての $`\equiv_{\mathscr R_i}`$ の上界であることと同値になる。
したがって最小のものはjoinである。
$`\approx_o`$ も合同関係なので、joinがその下にある条件は各項がその下にある条件に等しい。
空の要求は等号に含まれ、等号は全合同関係に含まれる。□

操作合同関係 $`\theta`$ による商 $`q_\theta:S\to S/\theta`$ の後で要求 $`\mathscr R'`$ を加える場合には、
新しい最小のkernelは $`\theta\vee\equiv_{\mathscr R'}`$ となる。
実際、商の上で $`([x]_\theta,[y]_\theta)`$ を $`x\mathrel{\mathscr R'}y`$ ごとに同一視して
操作合同関係を生成する。その逆像は $`\theta`$ と $`\mathscr R'`$ を含む。
逆に、それらを含む任意の合同関係は商上へ降りてこの要求を満たすため、
逆像はちょうどこのjoinである。
両方の商は同じkernelを持つため、$`[[x]_\theta]\mapsto[x]_{\theta\vee\equiv_{\mathscr R'}}`$ が
二段の操作商と一段の操作商の $`S`$ 上の同型を与える。
これらが観測を保つ商修復になる条件は
$`\theta\subseteq\approx_o`$ かつ $`\equiv_{\mathscr R'}\subseteq\approx_o`$ である。
命題9.6により、この二条件はjoinが $`\approx_o`$ に含まれることと同値であり、
その場合に定理9.5の観測保存因子射も適用できる。

**有限表からの判定。**
$`S,E`$ が有限で、観測値の等号を判定できる場合、生成合同関係は
$`\mathscr R`$ に同値関係の閉包と全操作による像を反復して求められる。
状態対は有限個なので、対が増えなくなると停止する。
全ての段階が任意の要求含有合同関係に含まれるため、停止時の関係は $`\equiv_{\mathscr R}`$ である。
$`\approx_o`$ は $`\theta_0=\ker o`$ から始め、
$`\theta_{n+1}=\ker o\cap\bigcap_{e\in E}(T_e\times T_e)^{-1}(\theta_n)`$
とする反復で求められる。
各段階は同値関係であり、$`\approx_o`$ を含む。
停止時は操作に安定で $`\ker o`$ に含まれるので命題9.2から $`\approx_o`$ に等しい。
最後に二つの表の包含を判定すればよい。

**条件付き変更との比較。**
構成8.8を集合の意味圏で用い、$`\mathcal C_H`$ は全射である全意味射のgroupoidとする。
始域を $`a=(S,T,o)`$ に固定したfiberの対象は
$`(q:A\twoheadrightarrow Q,\alpha:A\xrightarrow{\sim}S)`$ である。
要求 $`\mathscr R\subseteq S\times S`$ は固定状態上にあるので、評価はこのfiber上で

```math
\widetilde v(q,\alpha)=1
\quad\Longleftrightarrow\quad
\forall(x,y)\in\mathscr R,\quad
q\alpha^{-1}(x)=q\alpha^{-1}(y)
```

と定める。評価先を $`E=\{0,1\}`$、条件を $`V=\{1\}`$ とする。
fiberの比較 $`(a,b):(q,\alpha)\to(q',\alpha')`$ は
$`bq=q'a`$、$`\alpha'a=\alpha`$ を満たすので、
$`q'\alpha'^{-1}=bq\alpha^{-1}`$ となる。
$`b`$ は同型だから要求対の像の等号は同値であり、評価は比較不変である。

この許容族は全ての全射である意味射を取るため、$`q\alpha^{-1}`$ も同じ許容族に属する。
従って $`(q,\alpha)`$ を $`q\alpha^{-1}:S\twoheadrightarrow Q`$ へ送る厳密化により、
条件を満たす対象は定義9.4の商修復へ、全比較は $`fq=q'`$ を満たす同型へ戻る。
従ってこの変更groupoidは式(9.3)を離散groupoidとしたものと同値である。
離散性は、$`q`$ の全射性により自己同型が恒等になることから従う。
非可逆な因子射も扱うときには、定理9.5の圏全体を保持する。

## 9.3 保存section・冪等射・分裂

商の存在と、操作を保つ代表選択の存在は別の条件である。
ここでも9.2節の意味圏を使い、観測値集合と操作名を固定する。

**定義9.7（保存sectionと保存冪等射）.**
商 $`q:S\to Q`$ の保存sectionは、意味保存射 $`s:Q\to S`$ で
$`qs=\mathrm{id}_Q`$ となるものである。
保存冪等射は意味保存射 $`N:S\to S`$ で $`N^2=N`$ となるものである。

分裂の比較射 $`(f,g):(S,Q,q,s)\to(S',Q',q',s')`$ は意味保存射の対で

**式(9.5)**

```math
gq=q'f,\qquad fs=s'g
```

を満たすものとする。
冪等射の比較射 $`f:(S,N)\to(S',N')`$ には $`fN=N'f`$ を課す。
これらの条件は恒等と合成で保たれる。

**定理9.8（代表選択と冪等射の分裂）.**
上の意味圏における分裂の圏と保存冪等射の圏は同値である。
分裂から冪等射への関手は

**式(9.6)**

```math
(S,Q,q,s)\longmapsto(S,sq),\qquad(f,g)\longmapsto f
```

で与えられる。
逆方向は $`N`$ の像 $`Q_N=\mathrm{im}\,N\subseteq S`$ と、
終域を像へ制限した $`q_N=N:S\to Q_N`$、包含 $`s_N:Q_N\hookrightarrow S`$ から構成する。
また $`\ker(sq)=\ker q`$ である。
従って $`S`$ と要求 $`\mathscr R`$ を固定すれば、それを満たす商と保存sectionの全体は、
$`\mathscr R\subseteq\ker N`$ を満たす保存冪等射と同じ比較を持つ。

**証明.**
分裂から得る $`N=sq`$ は意味保存射の合成なので操作と観測を保ち、
$`N^2=s(qs)q=sq=N`$ である。
式(9.5)から $`fN=fsq=s'gq=s'q'f=N'f`$ となる。
$`s`$ は $`qs=\mathrm{id}`$ により単射なので、$`\ker N=\ker q`$ も従う。

逆に $`N`$ を与える。
任意の $`N(x)\in Q_N`$ に対し
$`T_e(N(x))=N(T_e(x))\in Q_N`$ なので、全操作が像へ制限できる。
観測は $`o|_{Q_N}`$ とする。
$`q_N`$ は全射であり、操作の可換性は $`NT_e=T_eN`$、観測保存は $`oN=o`$ である。
包含 $`s_N`$ も制限された構造を保つ。
$`N(N(x))=N(x)`$ から $`q_Ns_N=\mathrm{id}_{Q_N}`$ となる。
この二射を合成すると元の $`N`$ に戻る。

$`fN=N'f`$ を満たす比較射は $`f(N(x))=N'(f(x))\in Q_{N'}`$ を満たす。
従って像への制限 $`g=f|_{Q_N}`$ が定まり、
$`gq_N=q_{N'}f`$ と $`fs_N=s_{N'}g`$ を満たす。
制限写像も操作と観測を保つ。恒等と合成は制限前と一致する。

元の分裂へ戻る比較は
$`j:Q\to\mathrm{im}(sq)`$、$`j(y)=s(y)`$ である。
これは $`sq(s(y))=s(y)`$ により定義され、
逆写像は $`q`$ の像への制限である。
両写像は意味保存射で、$`jq=q_N`$、$`s_Nj=s`$ を満たす。
式(9.5)から $`j'g=(f|_{Q_N})j`$ となるので、この同型は全比較射に自然である。
以上が相互回復を与える。最後の要求に関する主張はkernelの等号による。□

**例9.9（商は存在するが保存sectionはない）.**
$`S=\{0,1\}`$、$`T(0)=1,T(1)=0`$、観測は定数とする。
一点系 $`Q=\{*\}`$ の操作を恒等とすれば、唯一の全射 $`q:S\to Q`$ は商修復である。
しかしsectionが操作を保つには $`T(s(*))=s(*)`$ が必要であり、交換操作に固定点はない。
従って保存sectionは存在しない。
定理9.8によれば、全関係をkernelに持つ保存冪等射もない。
実際、そのような写像は定数だが、二つの定数写像はいずれも交換操作と可換しない。

**固定図式による全代表選択。**
二頂点 $`0,1`$ と射 $`q:0\to1`$、$`s:1\to0`$、関係 $`qs=\mathrm{id}_1`$ を持つ
小圏を $`J_{\mathrm{split}}`$ とする。
[8.3節](chapter_8_constrained_changes_and_completions.md#83-固定図式とtrivializationを保つ全補完)で
頂点 $`0`$ のみを $`S`$ に固定した補完は、全分裂を与える。
頂点 $`0,1`$ と射 $`q`$ を固定した補完は、固定した商の全保存sectionを与える。
厳密固定の比較では、固定頂点の成分は恒等である。
前者では式(9.5)の $`f=\mathrm{id}_S`$、後者ではさらに $`g=\mathrm{id}_Q`$ となる。
固定部のtrivializationを許す場合も、
そのtrivializationで二射を運ぶと同じ厳密固定のデータに戻り、全比較射が対応する。
定理9.8はこのgroupoidにも制限される。
特に $`S`$ を厳密固定した分裂groupoidは、$`S`$ 上の保存冪等射の離散集合と同値になる。

**関手に沿う分裂の比較。**
任意の関手 $`F`$ は $`qs=\mathrm{id}`$ を
$`F(q)F(s)=\mathrm{id}`$ へ送り、比較の二式も保存する。
固定した $`q`$ について $`F`$ が充満忠実なら、
$`F(q)`$ のsectionは充満性である射 $`s`$ に戻り、
忠実性がその一意性と $`qs=\mathrm{id}`$ を与える。
したがって固定した商の全sectionを回復できる。
第15章でreadingを変える際には、この分裂データと、
読み方の比較関手が満たす条件とを合わせて用いる。

## 9.4 holonomyと中心化群

**定義9.10（可逆protocolと可視変更）.**
小さい有向グラフ $`G`$ の頂点集合を $`V_G`$、名前付き辺集合を $`E_G`$ とする。
各頂点に状態集合 $`X_v`$、辺 $`e:v\to w`$ に全単射
$`T_e:X_v\xrightarrow{\sim}X_w`$ を与える。
逆向きに辺を通る作用は $`T_e^{-1}`$ とし、有限の符号付き経路の作用を合成で定める。
指定した同始域・同終域の経路等式をLawとし、その作用の等号を仮定する。
経路等式と逆射の関係で割った経路groupoidを $`\mathcal E_G`$ とすれば、
これは関手 $`X:\mathcal E_G\to\mathbf{Set}`$ を与える。

全状態集合とその観測を

```math
S_X=\coprod_{v\in V_G}X_v,\qquad o(v,x)=v
```

とする。この観測は現在の頂点を読み、各辺の操作はその頂点のfiber上で定義される。
可視変更群 $`G_{\mathrm{vis}}`$ は、始域・終域と経路の合同関係を保つ
グラフ自己同型の指定部分群とする。
その元 $`g`$ は頂点と名前付き辺をともに置換し、経路を $`p\mapsto gp`$ へ送る。

$`g`$ のliftは、全単射族 $`a_v:X_v\xrightarrow{\sim}X_{gv}`$ で

**式(9.7)**

```math
a_wT_e=T_{ge}a_v\qquad(e:v\to w)
```

を満たすものである。その全体を $`\mathrm{Lift}(g)`$ と書く。
全状態の写像 $`A(v,x)=(gv,a_v(x))`$ は全単射で、$`oA=g\,o`$ を満たす。
逆にこの観測の式を満たす全単射はfiberへ制限でき、
辺の操作保存を課すと式(9.7)を得る。
従ってliftは実際の全状態射と一対一に対応する。
$`g=1`$ のとき観測は固定され、これを垂直変更と呼ぶ。

名前付きsortと操作を $`g`$ で読み替えると、式(9.7)は
[第2章の理論解釈を伴う射](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)の保存式である。
観測値sort上の成分は $`g`$ に指定される。
固定観測の意味圏に対応するのは $`g=1`$ の部分である。
この区別により、可視変更も内部状態の変更も、同じ可換式の中に保持される。

各連結成分 $`j`$ で根 $`r_j`$ と、根から各頂点 $`v`$ への符号付き経路
$`p_v:r_j\rightsquigarrow v`$ を選び、$`p_{r_j}`$ は空経路とする。
たとえば各成分の全域木の経路を使える。
定理ではこの選択をデータとし、頂点・辺・fiberの有限性を仮定しない。
$`P_v=T_{p_v}`$ と置く。
辺 $`e:v\to w`$ に対応する根のループとその作用は

**式(9.8)**

```math
\ell_e=p_w^{-1}ep_v,\qquad
L_e=P_w^{-1}T_eP_v\in\mathrm{Sym}(X_{r_j})
```

である。右端の経路から先に実行する。
根に始まり根に戻る全経路の作用からなる群を $`\mathrm{Hol}_j`$ と呼ぶ。

**補題9.11（名前付き辺によるholonomyの生成）.**
$`\mathrm{Hol}_j`$ は、成分内の全辺に対する $`L_e`$ で生成される。

**証明.**
各 $`L_e`$ は根のループの作用なので左辺に属する。
逆に符号付き経路の各通過の前後に $`P_vP_v^{-1}`$ を挿入する。
正向きの通過では $`P_w^{-1}T_eP_v=L_e`$、逆向きでは $`L_e^{-1}`$ となる。
隣り合う挿入は相殺し、根の $`P_{r_j}`$ は恒等なので、
根の全ループの作用はこれらの積になる。
経路等式を課した場合も、作用がその等式を満たすため同じ計算が商上で成り立つ。□

**定理9.12（全liftの根での復元）.**
任意の $`g\in G_{\mathrm{vis}}`$ について、$`\mathrm{Lift}(g)`$ は全単射族
$`b_j:X_{r_j}\xrightarrow{\sim}X_{g r_j}`$ で

**式(9.9)**

```math
b_jL_e=L_e^g b_j\quad(\text{成分 }j\text{ の全辺 }e),\qquad
L_e^g=T_{g p_w}^{-1}T_{ge}T_{g p_v}
```

を満たすもの全体と全単射になる。
順方向は $`b_j=a_{r_j}`$、逆方向は

**式(9.10)**

```math
a_v=T_{g p_v}\,b_j\,P_v^{-1}
```

である。

**証明.**
式(9.7)を逆射について解くと、逆向きの辺でも同じ可換式を得る。
経路の長さに関する帰納法により、任意の $`p:v\rightsquigarrow w`$ について
$`a_wT_p=T_{gp}a_v`$ となる。
根のループ $`\ell_e`$ へ適用すれば式(9.9)、
根からの経路 $`p_v`$ へ適用すれば式(9.10)を得る。
従って実際のliftは根の値から一意に決まる。

逆に式(9.9)を満たす $`b_j`$ から式(9.10)で全単射族を作る。
辺 $`e:v\to w`$ について

```math
\begin{aligned}
a_wT_e
 &=T_{g p_w}b_jP_w^{-1}T_e\\
 &=T_{g p_w}b_jL_eP_v^{-1}\\
 &=T_{g p_w}L_e^g b_jP_v^{-1}\\
 &=T_{ge}T_{g p_v}b_jP_v^{-1}
 =T_{ge}a_v.
\end{aligned}
```

よってこれはliftである。
根では $`P_{r_j}=T_{g p_{r_j}}=\mathrm{id}`$ なので、根への評価は元の $`b_j`$ に戻る。
実際のliftから再構成すると全経路の可換式により各 $`a_v`$ が元に戻る。
これが両方向の相互逆性を示す。□

**系9.13（垂直変更群）.**
垂直変更の点ごとの合成による群 $`K=\mathrm{Lift}(1)`$ には群同型

**式(9.11)**

```math
K\ \cong\ \prod_j
C_{\mathrm{Sym}(X_{r_j})}(\mathrm{Hol}_j)
```

がある。ここで $`C_L(M)=\{c\in L\mid cm=mc\ \forall m\in M\}`$ は中心化群である。

**証明.**
$`g=1`$ では式(9.9)は $`b_jL_e=L_eb_j`$ になる。
全生成元と可換することは、それらの逆元と有限積にも可換することと同値なので、
補題9.11により中心化群の条件に等しい。
根への評価と式(9.10)は恒等と合成を保つ。
後者では $`(P_vb_jP_v^{-1})(P_vc_jP_v^{-1})=P_vb_jc_jP_v^{-1}`$ と計算できる。□

**追加の観測を保持する場合。**
各頂点に $`\omega_v:X_v\to O_v`$、辺に全単射 $`U_e:O_v\to O_w`$ を与え、
$`\omega_wT_e=U_e\omega_v`$ と経路Lawを満たすとする。
可視変更に $`\eta_v:O_v\xrightarrow{\sim}O_{gv}`$ を含め、
$`\eta_wU_e=U_{ge}\eta_v`$ を課す。
追加の保存式 $`\omega_{gv}a_v=\eta_v\omega_v`$ は、定理9.12では
$`\omega_{g r_j}b_j=\eta_{r_j}\omega_{r_j}`$ に対応する。
実際、式(9.10)へ観測を合成し、$`\omega_vP_v=U_{p_v}\omega_{r_j}`$ と
$`\eta_vU_{p_v}=U_{g p_v}\eta_{r_j}`$ を代入すれば、全頂点の保存式を得る。
逆方向は根で評価すればよい。
従って $`g=1,\eta=\mathrm{id}`$ の垂直群では、式(9.11)の各因子に
$`\omega_{r_j}b_j=\omega_{r_j}`$ を課す。
中心化群の式には、選んだ観測をこのように保持する。

## 9.5 持ち上げのfiberと選択の整合

**命題9.14（全変更群とliftのtorsor）.**
対 $`(g,a)`$、$`g\in G_{\mathrm{vis}}`$、$`a\in\mathrm{Lift}(g)`$ 全体は群
$`G_{\mathrm{chg}}`$ をなす。積と逆は

**式(9.12)**

```math
(g,a)(h,b)=(gh,c),\qquad c_v=a_{hv}b_v,
\qquad
(g,a)^{-1}=(g^{-1},d),\quad d_v=a_{g^{-1}v}^{-1}
```

である。射影 $`\pi:G_{\mathrm{chg}}\to G_{\mathrm{vis}}`$ の核は $`K`$、
像 $`G_{\mathrm{lift}}`$ は持ち上げ可能な可視変更の部分群である。
各 $`g\in G_{\mathrm{lift}}`$ について、fiber $`\pi^{-1}(g)=\mathrm{Lift}(g)`$ は
右の合成作用による $`K`$-torsorとなる。

**証明.**
積の族について、辺 $`e:v\to w`$ の可換式を二度用いると

```math
c_wT_e=a_{hw}b_wT_e
 =a_{hw}T_{he}b_v
 =T_{ghe}a_{hv}b_v=T_{ghe}c_v
```

となる。逆族の可換性は元の式を逆射で解いて得る。
全状態上では通常の全単射の合成と逆射であり、可視成分も通常の合成なので群公理が成り立つ。
射影は群準同型で、核と像の記述は定義から従う。

同じfiberの二元 $`a,b`$ について $`a^{-1}b\in K`$ であり、
$`a(a^{-1}b)=b`$ である。
$`ak=ak'`$ なら逆元を左から掛けて $`k=k'`$ を得る。
よって作用は自由かつ推移的である。□

ここでfiberは、可視変更、protocol、両端の同定を固定した実際のlift全体である。
第8章の図式補完では、辺の可換正方形、状態の全単射とその逆、
指定した観測の比較を原始宣言に含めればこのfiberを得る。
比較時にも両端の固定trivializationを保つので、これは解集合を離散groupoidとして読む問題になる。
$`K`$ の作用は新しいliftを作る作用であり、
固定データを忘れて軌道を同一視する問題を選ぶ場合には、その商を別に取る。

**命題9.15（根と経路の選択への整合）.**
同じ成分で根を $`r_j`$ から $`r'_j`$ に替え、
経路 $`q_j:r_j\rightsquigarrow r'_j`$ を選ぶ。
定理9.12の根のデータの比較は

**式(9.13)**

```math
b'_j=T_{gq_j}\,b_j\,T_{q_j}^{-1}
```

である。新しい根からの経路をどの全域木から選んでも、
この比較の後に復元したliftは元のliftに一致する。
垂直変更群の比較は $`b_j\mapsto T_{q_j}b_jT_{q_j}^{-1}`$ という群同型になる。
全変更群の積、射影、各fiberの $`K`$ 作用も、この比較の下で一致する。

**証明.**
根の解から定理9.12で $`a`$ を復元する。
経路 $`q_j`$ の可換式により、新根での値は式(9.13)に等しい。
新根と新しい経路について同定理を適用すると、
同じ実際のliftを評価してから復元するため、全頂点で元の $`a`$ を得る。
これにより木の変更も同時に扱える。
根だけを替える垂直の場合、ループの作用も $`T_{q_j}`$ による共役で移るので、
中心化群の比較は表示した群同型となる。
二回の選択変更の比較は、間で実際のliftへの復元と評価が相殺するため合成に一致する。
群演算とtorsor作用も同じ実際の状態写像の合成から作ったので保たれる。□

**例9.16（各可視変更のliftと群section）.**
頂点は $`0,1`$、辺は $`e:0\to1`$ と $`f:1\to0`$ とし、追加の経路Lawは課さない。
両fiberを $`\{0,1\}`$、その交換を $`\kappa`$ として、
$`T_e=\mathrm{id}`$、$`T_f=\kappa`$ を与える。
二状態を $`\mathbb F_2`$ と読むと $`\kappa(x)=x+1`$ であり、これは有限アフィン変換網の例でもある。
可視群は頂点と辺を同時に交換する $`g`$ で生成され、$`g^2=1`$ である。

垂直変更 $`(b_0,b_1)`$ の辺 $`e`$ の式は $`b_1=b_0`$、
辺 $`f`$ の式は $`b_0\kappa=\kappa b_1`$ である。
二点集合の置換は $`\mathrm{id},\kappa`$ だけなので、
垂直群は恒等と $`k=(\kappa,\kappa)`$ の二元からなる。
根を $`0`$、木の辺を $`e`$ に取れば、$`fe`$ のholonomyは $`\kappa`$ であり、
中心化群もこの二元群になる。

$`g`$ のliftの式は

```math
a_1=\kappa a_0,\qquad a_0\kappa=a_1.
```

従ってliftは $`(a_0,a_1)=(\mathrm{id},\kappa)`$ と
$`(\kappa,\mathrm{id})`$ のちょうど二つである。
どちらについても式(9.12)により、二乗の両頂点成分は $`\kappa`$ になる。
つまり $`g`$ の両liftの二乗は $`k\ne1`$ であり、四乗は恒等である。
全変更群は四元巡回群、可視群は二元巡回群、射影はその剰余写像となる。

もし群section $`s:G_{\mathrm{vis}}\to G_{\mathrm{chg}}`$ があれば
$`s(g)^2=s(g^2)=1`$ でなければならないが、全liftの計算に反する。
したがって各可視変更は持ち上がっても、合成を保つ選択は存在しない。

**選択の合成条件。**
より一般に、射影 $`\pi:G_{\mathrm{chg}}\to G_{\mathrm{lift}}`$ の集合としてのsection
$`g\mapsto a_g`$ を $`a_1=1`$ と正規化して選ぶ。
無限群でその存在を用いるときは、各非空fiberからの選択に選択公理を用いる。
この段階では群準同型であることは課さない。
積から生じる差

```math
c(g,h)=a_ga_ha_{gh}^{-1}\in K,\qquad
\alpha_g(k)=a_gka_g^{-1}
```

は、結合律から

```math
c(g,h)c(gh,\ell)=\alpha_g(c(h,\ell))c(g,h\ell)
```

を満たす。実際、両辺へ右から $`a_{gh\ell}`$ を掛けると
$`(a_ga_h)a_\ell`$ と $`a_g(a_ha_\ell)`$ になる。
選択を $`a'_g=b_ga_g`$、$`b_g\in K`$、$`b_1=1`$ に替えると、直接の積の展開から

```math
c'(g,h)=b_g\alpha_g(b_h)c(g,h)b_{gh}^{-1}
```

となる。
したがって合成を保つ選択の問題は、全ての $`g,h`$ で右辺を恒等にする
$`(b_g)`$ の方程式となる。
個々のfiberの非空性と、この同時方程式の可解性を区別できる。

**問題9.17（部分操作を含む商と代表選択）.**
名前付き部分操作とそのdomainを持つ任意の状態集合について、
どの合同関係が、domainを保存・反射する商と全操作語の観測保存を同時に与えるか。
そのうち保存sectionを持つものを、原始domainと操作の条件から分類せよ。
全域操作での定理9.5・9.8に対応する区間と分裂を求めることが課題である。

**問題9.18（持ち上げの整合する選択）.**
名前付きグラフ、可逆な辺作用、経路Law、可視部分群を入力とし、
上の $`c'(g,h)=1`$ の全解を原始入力から構成せよ。
グラフと全fiberが有限で、可視部分群を有限表で与えた場合は全liftの列挙から判定できるが、
一般の入力で必要十分な構造条件と、表示の変更に自然な全選択の記述を求める。

本章で構成した商・分裂・持ち上げは、いずれも実際の操作と観測の保存式を持つ。
第11–12章では固定部分を持つ修正作用とその持ち上げをこの形で比較し、
第15章では分裂を読み方の変更に沿って運ぶ。
第17–18章では可視情報を固定したときに残る解の自由を、同じfiberの上で調べる。
