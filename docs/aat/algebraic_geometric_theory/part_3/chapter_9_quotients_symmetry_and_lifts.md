# 第9章 商・対称性・持ち上げの分類

操作と観測を保つ変更の中には、状態を同一視する商、商の代表元を整合的に選ぶ切断、および可視な変更を内部状態へ持ち上げる射といった基本的な問題が現れる。
これらはいずれも、異なる固定データを持つ変更問題として定式化できる。
本章では、具体的な状態写像の圏からこれらの変更の全体を構成し、商を合同関係の区間によって、代表選択を保存冪等射の分裂によって、そして可逆な持ち上げを holonomy の方程式と中心化群によって分類する。

## 9.1 操作合同関係と観測同値

状態を同一視して商を作るためには、同一視が操作の実行と整合し、かつ現在の観測だけでなく任意の操作列を実行した後の観測とも矛盾しないことが必要である。
本節では、その両側の条件をそれぞれ生成操作合同関係と観測同値関係として定式化する。

**定義9.1（操作系と合同関係）.**
小さい集合 $`S,E,O`$、各操作名 $`e\in E`$ に対する全域操作 $`T_e:S\to S`$、および観測 $`o:S\to O`$ を固定する（状態集合 $`S`$ と操作名集合 $`E`$ は空であってもよい）。
有限語 $`w=e_m\cdots e_1\in E^*`$ の作用を合成 $`T_w=T_{e_m}\circ\cdots\circ T_{e_1}`$ で定め、空語の作用は恒等写像とする。

**操作合同関係**とは、同値関係 $`\theta\subseteq S\times S`$ であって、すべての $`e\in E`$ に対して
$`x\mathrel\theta y\Rightarrow T_e(x)\mathrel\theta T_e(y)`$
（操作安定性）を満たすものをいう。
操作合同関係の全体を包含関係で順序づけた集合を $`\mathrm{Con}(S,T)`$ と書く。
任意の族の交差は再び操作合同関係であり、空交差は全関係 $`S\times S`$ である。
したがって、下限は交差、上限はすべての上界の交差で与えられ、$`\mathrm{Con}(S,T)`$ は最小元を等号、最大元を全関係 $`S\times S`$ とする完備束になる。

同一視の要求 $`\mathscr R\subseteq S\times S`$（$`\mathscr R`$ 自体には対称性や推移性を仮定しない）に対し、$`\mathscr R`$ を含むすべての操作合同関係の交差を $`\equiv_{\mathscr R}`$ と書き、$`\mathscr R`$ が生成する操作合同関係と呼ぶ。
また、すべての操作語による**観測同値**を

**式(9.1)**

```math
x\approx_o y
\quad\Longleftrightarrow\quad
\forall w\in E^*,\quad o(T_w(x))=o(T_w(y))
```

によって定める。

**命題9.2（生成合同関係と最大の観測保存合同関係）.**
任意の操作合同関係 $`\theta\in\mathrm{Con}(S,T)`$ に対して

```math
\equiv_{\mathscr R}\subseteq\theta
\ \Longleftrightarrow\ \mathscr R\subseteq\theta,
\qquad
\theta\subseteq\approx_o
\ \Longleftrightarrow\ \theta\subseteq\ker o
```

が成り立つ。特に、観測同値 $`\approx_o`$ 自身が操作合同関係であり、$`\ker o`$ に含まれる最大の操作合同関係である。

**証明.**
第一の同値は、$`\equiv_{\mathscr R}`$ が $`\mathscr R`$ を含むすべての操作合同関係の交差であるという定義から直ちに従う。

次に $`\approx_o`$ が操作合同関係であることを確かめる。式(9.1)は各語 $`w`$ に対する同値関係 $`\ker(o\circ T_w)`$ の交差であるため、同値関係である。
さらに $`x\approx_o y`$ ならば、任意の語 $`w\in E^*`$ と操作 $`e\in E`$ に対して語 $`we`$ に式(9.1)を適用することで $`o(T_w(T_e(x)))=o(T_w(T_e(y)))`$ を得るため、$`T_e(x)\approx_o T_e(y)`$ となり操作安定性が成り立つ。

最後に第二の同値を示す。空語に対する条件から $`\approx_o\subseteq\ker o`$ であるため、$`\theta\subseteq\approx_o`$ ならば $`\theta\subseteq\ker o`$ である。
逆に $`\theta\subseteq\ker o`$ とすると、操作安定性の語長に関する帰納法により、$`x\mathrel\theta y`$ から任意の語 $`w`$ について $`T_w(x)\mathrel\theta T_w(y)`$ が従う。
ここで $`\theta\subseteq\ker o`$ を適用すれば $`o(T_w(x))=o(T_w(y))`$ となり、式(9.1)より $`x\approx_o y`$ を得る。□

**例9.3（現在の観測と1操作後の観測）.**
$`S=\{0,1,2\}`$、$`O=\{0,1\}`$ とし、操作名を一つ $`e`$ のみとして次の表のように定める。

| 状態 $`x`$ | $`o(x)`$ | $`T_e(x)`$ | $`o(T_e(x))`$ |
| --- | --- | --- | --- |
| $`0`$ | $`0`$ | $`0`$ | $`0`$ |
| $`1`$ | $`0`$ | $`2`$ | $`1`$ |
| $`2`$ | $`1`$ | $`2`$ | $`1`$ |

状態 $`0`$ と $`1`$ は現在の観測値では一致するが、操作 $`e`$ を1回実行すると観測値が異なる状態へ移る。
したがって $`\ker o`$ は操作合同関係ではなく、観測同値 $`\approx_o`$ は等号のみとなる。
同一視要求 $`\mathscr R=\{(0,1)\}`$ が生成する操作合同関係は、操作安定性から $`0=T_e(0)\equiv_{\mathscr R}T_e(1)=2`$ も含むため、全関係 $`S\times S`$ になる。
この要求を観測保存の下で実現できるかどうかは、次節で導入する合同関係の区間が空でないかどうかによって完全に判定される。

## 9.2 商修復の区間と要求の合成

本節では、名前付き全域操作と固定された観測値集合 $`O`$ を持つ状態集合の圏を基礎の意味圏とする。
射 $`f:(S,T,o)\to(S',T',o')`$ は、すべての $`e\in E`$ に対して $`fT_e=T'_ef`$ および $`o'f=o`$ を満たす写像である。
これは[第2章の意味圏](../part_1/chapter_2_models_and_morphisms.md#22-lawを満たすモデルと観測)において、状態 sort、名前付き操作、固定された観測値 sort と観測操作を指定した場合に相当する。
操作語の等式を Law として追加した場合にも、以下で構成する商へ同じ等式が自然に降りる。

**定義9.4（商修復とその比較）.**
$`(S,T,o,\mathscr R)`$ に対する**商修復**とは、状態集合 $`Q`$、全域操作 $`\overline T_e:Q\to Q`$、観測 $`\overline o:Q\to O`$、および全射 $`q:S\twoheadrightarrow Q`$ の組であって、すべての $`e\in E`$ と $`x,y\in S`$ に対して

**式(9.2)**

```math
qT_e=\overline T_eq,\qquad
\overline o q=o,\qquad
x\mathrel{\mathscr R}y\ \Longrightarrow\ q(x)=q(y)
```

を満たすものである。
二つの商修復 $`(Q,\overline T,\overline o,q)`$ と $`(Q',\overline T',\overline o',q')`$ の間の比較射は、$`fq=q'`$ を満たす意味保存射 $`f:Q\to Q'`$ とする。
恒等射と合成は写像の恒等と合成によって与える。

**定理9.5（すべての商修復の分類）.**
任意の $`S,E,O,T,o,\mathscr R`$ に対し、商修復の圏は包含順序が定める圏

**式(9.3)**

```math
\left\{\theta\in\mathrm{Con}(S,T)\ \middle|\
  \equiv_{\mathscr R}\subseteq\theta\subseteq\approx_o\right\}
```

と同値である。対応は $`q\mapsto\ker q`$ で与えられ、逆方向の関手は $`\theta\mapsto(S\twoheadrightarrow S/\theta)`$ から構成される。
したがって、商修復が存在することの必要十分条件は $`\equiv_{\mathscr R}\subseteq\approx_o`$ であり、元の $`S`$ からの射と可換な同型までの分類も式(9.3)の区間によって完全に与えられる。

**証明.**
まず商修復から合同関係への対応を見る。
商修復 $`q`$ に対して $`q(x)=q(y)`$ ならば、式(9.2)の第一式より

```math
q(T_e(x))=\overline T_e(q(x))
 =\overline T_e(q(y))=q(T_e(y))
```

が成り立つため、核 $`\ker q`$ は操作合同関係である。
さらに式(9.2)の第二式・第三式と命題9.2により、$`\equiv_{\mathscr R}\subseteq\ker q\subseteq\approx_o`$ を得る。

逆に、式(9.3)の区間に属する操作合同関係 $`\theta`$ に対し、実際の商集合 $`Q_\theta=S/\theta`$ を取り、

```math
q_\theta(x)=[x]_\theta,\qquad
\overline T_e([x]_\theta)=[T_e(x)]_\theta,\qquad
\overline o([x]_\theta)=o(x)
```

と定める。$`\theta`$ の操作安定性と $`\theta\subseteq\approx_o\subseteq\ker o`$ により、$`\overline T_e`$ と $`\overline o`$ は代表元の選び方によらずに一意に定まる。
商写像 $`q_\theta`$ は全射であり、$`\mathscr R\subseteq\theta`$ から式(9.2)の第三式も成立する。
各操作語 $`w`$ の作用 $`T_w`$ も商へ降りるため、元の操作語の等式（Law）もすべて保存される。

次に、これら二つの構成が対象上で互いに準逆であることを確かめる。
任意の商修復 $`q:S\twoheadrightarrow Q`$ に対し、$`[x]_{\ker q}\mapsto q(x)`$ は全単射 $`S/\ker q\to Q`$ を定める。
この写像は同じ式によって操作と観測を保ち、$`S`$ からの商写像とも可換する。逆写像も操作と観測を保つため、これは商修復の圏における同型である。
一方、$`\ker q_\theta=\theta`$ であるから、もう一方の往復は厳密に恒等である。

最後に、すべての比較射が包含関係と一対一に対応することを確かめる。
比較射 $`f:Q\to Q'`$ が $`fq=q'`$ を満たすならば $`\ker q\subseteq\ker q'`$ である。
逆に $`\ker q\subseteq\ker q'`$ ならば、$`f(q(x))=q'(x)`$ という式が包含関係によって代表元によらず定まり、$`q`$ の全射性から $`f`$ は一意である。
任意の $`z=q(x)\in Q`$ に対して

```math
f(\overline T_e(z))=f(q(T_e(x)))
 =q'(T_e(x))=\overline T'_e(f(z)),\qquad
\overline o'(f(z))=o(x)=\overline o(z)
```

が成り立つため、$`f`$ は意味保存射であり、したがって射集合全体が包含関係と一対一に対応する。
恒等包含は恒等射に、二つの包含の合成は合成写像に対応する。
また、相互の包含は核の等号であり、対応する二つの射の合成は全射 $`q,q'`$ の上で恒等となるため同型を与える。
以上により圏同値と同型類の分類が得られた。□

なお、この証明では商集合 $`Q`$ の操作と観測の構造自体も復元した。
同じ全射 $`q`$ に対して式(9.2)を満たす降下操作と観測は、任意の $`z=q(x)`$ で値が定まるため一意である。
また、状態集合 $`S`$ が空の場合も全射の終域は空集合となり、同じ構成がそのまま成り立つ。

続いて、複数の同一視要求を同時に課す場合や段階的に加える場合の振舞いを、完備束 $`\mathrm{Con}(S,T)`$ の上限（join）によって記述する。

**命題9.6（要求族の合成）.**
任意の小さい添字集合 $`I`$ と同一視要求の族 $`(\mathscr R_i)_{i\in I}`$ に対して、

**式(9.4)**

```math
\equiv_{\bigcup_{i\in I}\mathscr R_i}
 =\bigvee_{i\in I}\equiv_{\mathscr R_i},
\qquad
\equiv_{\bigcup_i\mathscr R_i}\subseteq\approx_o
\ \Longleftrightarrow\
\forall i,\ \equiv_{\mathscr R_i}\subseteq\approx_o
```

が成り立つ。特に、空の要求族が生成する操作合同関係は等号である。

**証明.**
操作合同関係 $`\theta`$ が和集合 $`\bigcup_{i\in I}\mathscr R_i`$ を含むことは、すべての $`i\in I`$ について $`\mathscr R_i\subseteq\theta`$ が成り立つことと同値である。
命題9.2により、これはすべての $`i\in I`$ について $`\equiv_{\mathscr R_i}\subseteq\theta`$、すなわち $`\theta`$ が族 $`(\equiv_{\mathscr R_i})_{i\in I}`$ の上界であることと同値になる。
したがって、これらを含む最小の操作合同関係は束の上限（join）$`\bigvee_{i\in I}\equiv_{\mathscr R_i}`$ に一致する。
$`\approx_o`$ 自身も操作合同関係であるから、上限が $`\approx_o`$ に含まれる条件は各成分が $`\approx_o`$ に含まれる条件と同値である。
空の要求は等号に含まれ、等号はすべての操作合同関係に含まれるため、最後の主張も従う。□

操作合同関係 $`\theta`$ による商 $`q_\theta:S\twoheadrightarrow S/\theta`$ を取った後に追加の要求 $`\mathscr R'`$ を課す場合、得られる最小の核は上限 $`\theta\vee\equiv_{\mathscr R'}`$ となる。
実際、商 $`S/\theta`$ の上で $`x\mathrel{\mathscr R'}y`$ を満たす各対 $`([x]_\theta,[y]_\theta)`$ を同一視して操作合同関係を生成すると、その $`q_\theta`$ による逆像は $`\theta`$ と $`\mathscr R'`$ をともに含む操作合同関係になる。
逆に $`\theta`$ と $`\mathscr R'`$ を含む任意の操作合同関係は商 $`S/\theta`$ へ降りてこの要求を満たすため、逆像はちょうど上限 $`\theta\vee\equiv_{\mathscr R'}`$ に一致する。
2段階の操作商と1段階の操作商は同じ核を持つため、$`[[x]_\theta]\mapsto[x]_{\theta\vee\equiv_{\mathscr R'}}`$ が $`S`$ 上の同型を与える。
これらが観測を保つ商修復となる条件は $`\theta\subseteq\approx_o`$ かつ $`\equiv_{\mathscr R'}\subseteq\approx_o`$ であり、命題9.6によりこれは上限 $`\theta\vee\equiv_{\mathscr R'}\subseteq\approx_o`$ と同値になる。その場合には定理9.5の観測保存因子射もそのまま適用できる。

**有限表からの判定.**
状態集合 $`S`$ と操作名集合 $`E`$ が有限であり、観測値の等号を判定できる場合、商修復の存在判定は有限回の反復計算で完結する。
まず生成合同関係 $`\equiv_{\mathscr R}`$ は、$`\mathscr R`$ から出発して同値関係としての閉包とすべての操作 $`T_e`$ による像の追加を反復すればよい。状態対は有限個なので新たな対が増えなくなった時点で停止し、各段階の関係が $`\mathscr R`$ を含む任意の操作合同関係に含まれることから、停止時の関係は正確に $`\equiv_{\mathscr R}`$ に一致する。
一方、観測同値 $`\approx_o`$ は $`\theta_0=\ker o`$ から始め、
$`\theta_{n+1}=\ker o\cap\bigcap_{e\in E}(T_e\times T_e)^{-1}(\theta_n)`$
という降鎖の反復によって求められる。各段階は同値関係であり常に $`\approx_o`$ を含み、停止時には操作安定かつ $`\ker o`$ に含まれるため、命題9.2により $`\approx_o`$ に等しい。
最後に、得られた二つの有限表について包含 $`\equiv_{\mathscr R}\subseteq\approx_o`$ を判定すればよい。

**第8章の条件付き変更族との比較.**
集合の意味圏で構成8.8を適用し、許容変更の groupoid $`\mathcal C_H`$ を「全射であるすべての意味保存射」の groupoid とする。
始域を $`a=(S,T,o)`$ に固定したファイバーの対象は対 $`(q:A\twoheadrightarrow Q,\ \alpha:A\xrightarrow{\sim}S)`$ である。
要求 $`\mathscr R\subseteq S\times S`$ は固定された状態集合 $`S`$ 上で与えられているため、ファイバー上の評価 $`\widetilde v`$ を

```math
\widetilde v(q,\alpha)=1
\quad\Longleftrightarrow\quad
\forall(x,y)\in\mathscr R,\quad
q\alpha^{-1}(x)=q\alpha^{-1}(y)
```

によって定め、評価先を $`E=\{0,1\}`$、許容値の部分集合を $`V=\{1\}`$ とする。
ファイバーの比較射 $`(a,b):(q,\alpha)\to(q',\alpha')`$ は $`bq=q'a`$ および $`\alpha'a=\alpha`$ を満たすため、$`q'\alpha'^{-1}=bq\alpha^{-1}`$ が成り立つ。
$`b`$ は同型（全単射）なので要求対の像の等号は同値であり、評価 $`\widetilde v`$ は比較不変である。

この許容族はすべての全射意味保存射を含むため、$`q\alpha^{-1}`$ 自身も同じ許容族に属する。
したがって $`(q,\alpha)`$ を $`q\alpha^{-1}:S\twoheadrightarrow Q`$ へ送る厳密化によって、条件を満たす対象は定義9.4の商修復へ、すべての比較射は $`fq=q'`$ を満たす同型へと戻る。
ゆえにこの条件付き変更 groupoid は、式(9.3)の区間を離散 groupoid と見なしたものと同値である（離散性は、$`q`$ の全射性により自己同型が恒等射に限られることから従う）。
非可逆な因子射も含めて比較したい場合には、定理9.5の商修復の圏全体を保持する。

## 9.3 保存切断・冪等射・分裂

商が存在しても、各同値類から操作を保つ代表元を整合的に選べる（保存切断が存在する）とは限らない。
本節では、9.2節と同じ意味圏（観測値集合と操作名を固定した状態集合の圏）において、保存切断を持つ商の全体が保存冪等射の全体と同値であることを示す。

**定義9.7（保存切断と保存冪等射）.**
商 $`q:S\to Q`$ の**保存切断**とは、意味保存射 $`s:Q\to S`$ であって $`qs=\mathrm{id}_Q`$ を満たすものをいう。
**保存冪等射**とは、意味保存射 $`N:S\to S`$ であって $`N^2=N`$ を満たすものをいう。

分裂 $`(S,Q,q,s)`$（すなわち $`qs=\mathrm{id}_Q`$ を満たす意味保存射の組）の間の比較射 $`(f,g):(S,Q,q,s)\to(S',Q',q',s')`$ は、意味保存射の対であって

**式(9.5)**

```math
gq=q'f,\qquad fs=s'g
```

を満たすものとする。
保存冪等射の間の比較射 $`f:(S,N)\to(S',N')`$ は、$`fN=N'f`$ を満たす意味保存射とする。
これらの条件はいずれも恒等射と合成で保たれる。

**定理9.8（代表選択と冪等射の分裂）.**
上記の意味圏において、分裂の圏と保存冪等射の圏は同値である。
分裂から保存冪等射への関手は

**式(9.6)**

```math
(S,Q,q,s)\longmapsto(S,sq),\qquad(f,g)\longmapsto f
```

で与えられる。
逆方向の関手は、$`N`$ の像 $`Q_N=\mathrm{im}\,N\subseteq S`$ と、終域を像へ制限した全射 $`q_N=N:S\to Q_N`$、および包含写像 $`s_N:Q_N\hookrightarrow S`$ によって構成される。
さらに $`\ker(sq)=\ker q`$ が成り立つ。
したがって、$`S`$ と同一視要求 $`\mathscr R`$ を固定すれば、それを満たす商と保存切断の全体は、$`\mathscr R\subseteq\ker N`$ を満たす保存冪等射の全体と同じ比較構造を持つ。

**証明.**
まず順方向（式(9.6)）が関手を定めることを確認する。
分裂 $`(S,Q,q,s)`$ から得られる $`N=sq`$ は意味保存射の合成なので操作と観測を保ち、$`N^2=s(qs)q=sq=N`$ より保存冪等射である。
比較射 $`(f,g)`$ については、式(9.5)より $`fN=fsq=s'gq=s'q'f=N'f`$ が成り立つ。
また、$`qs=\mathrm{id}_Q`$ より $`s`$ は単射であるため、$`\ker N=\ker(sq)=\ker q`$ も従う。

次に逆方向の関手を構成する。保存冪等射 $`(S,N)`$ を与え、像を $`Q_N=\mathrm{im}\,N\subseteq S`$ と置く。
任意の $`N(x)\in Q_N`$ に対して $`T_e(N(x))=N(T_e(x))\in Q_N`$ が成り立つため、すべての操作 $`T_e`$ は $`Q_N`$ へ制限できる。
観測も制限 $`o|_{Q_N}`$ として定める。
このとき終域制限 $`q_N:S\to Q_N`$ は全射であり、操作の可換性は $`NT_e=T_eN`$、観測の保存は $`oN=o`$ から従う。
包含写像 $`s_N:Q_N\hookrightarrow S`$ も制限された構造を保ち、冪等性 $`N(N(x))=N(x)`$ から $`q_Ns_N=\mathrm{id}_{Q_N}`$ を得る。
さらに、合成 $`s_Nq_N`$ は元の $`N`$ に厳密に一致する。

射の対応を見る。$`fN=N'f`$ を満たす比較射 $`f:(S,N)\to(S',N')`$ は、任意の $`x\in S`$ に対して $`f(N(x))=N'(f(x))\in Q_{N'}`$ を満たす。
したがって像への制限 $`g=f|_{Q_N}:Q_N\to Q_{N'}`$ が一意に定まり、$`gq_N=q_{N'}f`$ と $`fs_N=s_{N'}g`$ を満たす。
制限写像 $`g`$ も操作と観測を保ち、恒等射と合成は制限前と一致する。

最後に、元の分裂から出発する往復の自然同型を構成する。
$`j:Q\to\mathrm{im}(sq)`$ を $`j(y)=s(y)`$ で定める（$`sq(s(y))=s(y)`$ より像に属する）。
その逆写像は $`q`$ の像 $`\mathrm{im}(sq)`$ への制限である。
両写像はともに意味保存射であり、$`jq=q_N`$ と $`s_Nj=s`$ を満たすため分裂の同型を与える。
式(9.5)より $`j'g=(f|_{Q_N})j`$ が成り立つので、この同型はすべての比較射に対して自然である。
以上により二つの圏の同値が示された。最後の要求 $`\mathscr R`$ に関する主張は、核の等号 $`\ker(sq)=\ker q`$ から直ちに従う。□

**例9.9（商は存在するが保存切断はない）.**
$`S=\{0,1\}`$、操作 $`T(0)=1,\ T(1)=0`$、観測を定数とする。
1点系 $`Q=\{*\}`$ の操作を恒等写像とすれば、唯一の全射 $`q:S\to Q`$ は商修復を与える。
しかし、切断 $`s:Q\to S`$ が操作を保つためには $`T(s(*))=s(*)`$、すなわち固定点が必要であるが、交換操作 $`T`$ には固定点が存在しない。
したがって保存切断は存在しない。
定理9.8によれば、全関係 $`S\times S`$ を核に持つ保存冪等射も存在しないことになる。実際、全関係を核に持つ写像は定数写像に限られるが、二つの定数写像はいずれも交換操作 $`T`$ と可換しない。

**固定図式によるすべての代表選択.**
二つの頂点 $`0,1`$ と射 $`q:0\to1`$、$`s:1\to0`$、および関係式 $`qs=\mathrm{id}_1`$ で生成される小圏を $`J_{\mathrm{split}}`$ とする。
[8.3節](chapter_8_constrained_changes_and_completions.md#83-固定図式と自明化を保つ補完の全体)の補完の枠組みにおいて、頂点 $`0`$ のみを $`S`$ に固定した補完の全体は $`S`$ のすべての分裂を与え、頂点 $`0,1`$ と射 $`q`$ を固定した補完の全体は固定された商 $`q`$ のすべての保存切断を与える。
厳密固定の比較射では固定頂点の成分が恒等射になるため、前者では式(9.5)において $`f=\mathrm{id}_S`$、後者ではさらに $`g=\mathrm{id}_Q`$ が課される。
固定部分の自明化を許す非厳密な表示においても、その自明化によって二つの射を運べば厳密固定のデータに戻り、すべての比較射が一対一に対応する。
定理9.8はこの groupoid にもそのまま制限され、特に $`S`$ を厳密に固定した分裂 groupoid は、$`S`$ 上の保存冪等射の離散集合と同値になる。

**関手に沿う分裂の比較.**
任意の関手 $`F`$ は等式 $`qs=\mathrm{id}`$ を $`F(q)F(s)=\mathrm{id}`$ へ送り、比較射の二つの式（式(9.5)）も保存する。
さらに、固定された商 $`q`$ について関手 $`F`$ が充満忠実であるならば、$`F(q)`$ の任意の切断は充満性によってある射 $`s`$ へ戻り、忠実性によってその一意性と等式 $`qs=\mathrm{id}`$ が保証される。
したがって、固定された商のすべての切断を完全に回復できる。
第15章で reading を変更する際には、この分裂データと、読み方の比較関手が満たす充満忠実性などの条件とを組み合わせて用いる。

## 9.4 holonomy と中心化群

ここからは対象を可逆な操作からなる protocol へ移し、可視的なグラフ構造の対称性（可視変更）を内部状態空間へ持ち上げる問題を分類する。
連結成分ごとに選んだ根と全域木などの経路を用いることで、すべての持ち上げが根における holonomy との共役方程式によって完全に復元されることを示す。

**定義9.10（可逆 protocol と可視変更）.**
小さい有向グラフ $`G`$ の頂点集合を $`V_G`$、名前付き辺の集合を $`E_G`$ とする。
各頂点 $`v\in V_G`$ に状態集合 $`X_v`$ を、各辺 $`e:v\to w`$ に全単射 $`T_e:X_v\xrightarrow{\sim}X_w`$ を割り当てる。
逆向きに辺を通る作用は逆写像 $`T_e^{-1}`$ とし、有限の符号付き経路の作用を合成で定める。
始域と終域が一致する経路どうしの指定された等式を Law とし、それらの作用が一致すると仮定する。
経路等式と逆射の関係で割った経路 groupoid を $`\mathcal E_G`$ とすれば、このデータは関手 $`X:\mathcal E_G\to\mathbf{Set}`$ を定める。

全体の状態集合とその観測を

```math
S_X=\coprod_{v\in V_G}X_v,\qquad o(v,x)=v
```

とする。この観測 $`o`$ は現在の頂点を読み出し、各辺の操作はその始点頂点のファイバー上で定義される。
**可視変更群** $`G_{\mathrm{vis}}`$ は、辺の始域・終域および経路の合同関係を保つグラフ自己同型の指定された部分群とする。
$`g\in G_{\mathrm{vis}}`$ は頂点と名前付き辺をともに置換し、符号付き経路を $`p\mapsto gp`$ へ送る。

$`g\in G_{\mathrm{vis}}`$ の**持ち上げ**とは、全単射の族 $`a=(a_v:X_v\xrightarrow{\sim}X_{gv})_{v\in V_G}`$ であって、すべての辺 $`e:v\to w`$ に対して

**式(9.7)**

```math
a_wT_e=T_{ge}a_v\qquad(e:v\to w)
```

を満たすものをいう。$`g`$ の持ち上げの全体を $`\mathrm{Lift}(g)`$ と書く。
状態集合全体の上の写像 $`A(v,x)=(gv,a_v(x))`$ は全単射であって $`oA=g\,o`$ を満たし、逆にこの観測の式を満たす全単射は各ファイバーへ制限できて、辺の操作保存を課せば式(9.7)を得る。
したがって、持ち上げは状態集合全体の上の実際の意味射と一対一に対応する。
特に $`g=1`$ のときは観測が固定され、このような持ち上げを**垂直変更**と呼ぶ。

名前付き sort と操作を $`g`$ によって読み替えると、式(9.7)は[第2章の理論解釈を伴う射](../part_1/chapter_2_models_and_morphisms.md#23-構造保存射と理論の解釈)の保存式そのものであり、観測値 sort 上の成分が $`g`$ によって指定されている。
観測を固定する意味圏に対応するのは $`g=1`$ の垂直部分である。この区別により、可視変更と内部状態の変更の双方が同じ可換式の中に保持される。

次に、各連結成分 $`j`$ において根となる頂点 $`r_j`$ を一つ選び、根 $`r_j`$ から同じ成分内の各頂点 $`v`$ への符号付き経路 $`p_v:r_j\rightsquigarrow v`$ を一つずつ選ぶ（ただし $`p_{r_j}`$ は空経路とする。例えば各成分の全域木の経路を選べばよい）。
以下の定理ではこの選択を固定データとし、頂点・辺・ファイバーの有限性は仮定しない。
$`P_v=T_{p_v}`$ と略記する。各辺 $`e:v\to w`$ に対応する根のループとその作用を

**式(9.8)**

```math
\ell_e=p_w^{-1}ep_v,\qquad
L_e=P_w^{-1}T_eP_v\in\mathrm{Sym}(X_{r_j})
```

と定める（経路の合成は右端から先に実行する）。
根 $`r_j`$ に始まり根 $`r_j`$ に戻るすべての経路の作用がなす $`\mathrm{Sym}(X_{r_j})`$ の部分群を **holonomy 群**と呼び、$`\mathrm{Hol}_j`$ と書く。

**補題9.11（名前付き辺による holonomy の生成）.**
各連結成分 $`j`$ の holonomy 群 $`\mathrm{Hol}_j`$ は、その成分内のすべての辺 $`e`$ に対する $`L_e`$ によって生成される。

**証明.**
各 $`L_e`$ は根のループ $`\ell_e`$ の作用であるため、$`\mathrm{Hol}_j`$ に属する。
逆に、根 $`r_j`$ に始まり根 $`r_j`$ に戻る任意の符号付き経路を取り、各辺の通過の前後にある頂点 $`v`$ ごとに恒等写像 $`P_vP_v^{-1}`$ を挿入する。
すると正向きに辺 $`e:v\to w`$ を通過する箇所は $`P_w^{-1}T_eP_v=L_e`$ となり、逆向きに通過する箇所は $`L_e^{-1}`$ となる。
隣り合う挿入は相殺し、両端の根では $`P_{r_j}=\mathrm{id}`$ であるため、根の任意のループの作用は $`L_e^{\pm1}`$ の有限積で表される。
経路等式（Law）を課した場合にも、作用がその等式を満たすため同じ計算が経路 groupoid の商の上でそのまま成り立つ。□

**定理9.12（すべての持ち上げの根での復元）.**
任意の可視変更 $`g\in G_{\mathrm{vis}}`$ について、持ち上げの集合 $`\mathrm{Lift}(g)`$ は、各連結成分の根に対する全単射の族 $`b_j:X_{r_j}\xrightarrow{\sim}X_{g r_j}`$ であって、

**式(9.9)**

```math
b_jL_e=L_e^g b_j\quad(\text{成分 }j\text{ のすべての辺 }e),\qquad
L_e^g=T_{g p_w}^{-1}T_{ge}T_{g p_v}
```

を満たすもの全体と全単射に対応する。
順方向の対応は根での制限 $`b_j=a_{r_j}`$ で与えられ、逆方向の復元は各頂点 $`v`$（成分 $`j`$ に属する）に対し

**式(9.10)**

```math
a_v=T_{g p_v}\,b_j\,P_v^{-1}
```

によって与えられる。

**証明.**
まず順方向を確認する。式(9.7)を逆射について解けば逆向きの辺に対しても同じ可換式が得られる。
したがって経路の長さに関する帰納法により、任意の符号付き経路 $`p:v\rightsquigarrow w`$ に対して $`a_wT_p=T_{gp}a_v`$ が成り立つ。
この等式を根のループ $`\ell_e`$ に適用すれば式(9.9)が得られ、根からの経路 $`p_v`$ に適用すれば式(9.10)が得られる。
ゆえに任意の持ち上げは各根での値 $`b_j=a_{r_j}`$ から一意に決まる。

逆に、式(9.9)を満たす全単射族 $`(b_j)`$ から式(9.10)によって全単射族 $`(a_v)`$ を構成する。
成分 $`j`$ の任意の辺 $`e:v\to w`$ に対して、式(9.8)の $`P_w^{-1}T_e=L_eP_v^{-1}`$ と式(9.9)を用いると、

```math
\begin{aligned}
a_wT_e
 &=T_{g p_w}b_jP_w^{-1}T_e\\
 &=T_{g p_w}b_jL_eP_v^{-1}\\
 &=T_{g p_w}L_e^g b_jP_v^{-1}\\
 &=T_{ge}T_{g p_v}b_jP_v^{-1}
 =T_{ge}a_v
\end{aligned}
```

が成り立つ。よって $`(a_v)`$ は $`g`$ の持ち上げである。
根では $`P_{r_j}=T_{g p_{r_j}}=\mathrm{id}`$ であるから、式(9.10)から復元した持ち上げを根で評価すると元の $`b_j`$ に戻る。
一方、元の持ち上げから根で制限して式(9.10)で再構成すると、すべての経路に対する可換式により各 $`a_v`$ が元に戻る。
以上により両方向の対応が互いに逆であることが示された。□

定理9.12を $`g=1`$ に特殊化すると、垂直変更のなす群が各連結成分の holonomy 群の中心化群の直積として記述される。

**系9.13（垂直変更群）.**
垂直変更の点ごとの合成による群 $`K=\mathrm{Lift}(1)`$ には群同型

**式(9.11)**

```math
K\ \cong\ \prod_j
C_{\mathrm{Sym}(X_{r_j})}(\mathrm{Hol}_j)
```

がある。ここで $`C_L(M)=\{c\in L\mid cm=mc\ \forall m\in M\}`$ は部分群 $`M`$ の $`L`$ における中心化群である。

**証明.**
$`g=1`$ のとき式(9.9)は、成分 $`j`$ のすべての辺 $`e`$ に対する可換式 $`b_jL_e=L_eb_j`$ となる。
すべての生成元と可換することは、それらの逆元および有限積とも可換することと同値であるから、補題9.11によりこれは $`b_j\in C_{\mathrm{Sym}(X_{r_j})}(\mathrm{Hol}_j)`$ と同値になる。
根での評価と式(9.10)による復元は恒等射と合成を保つ（合成については $`(P_vb_jP_v^{-1})(P_vc_jP_v^{-1})=P_vb_jc_jP_v^{-1}`$ と確かめられる）。よって式(9.11)の群同型を得る。□

**追加の観測を保持する場合.**
各頂点に追加の観測 $`\omega_v:X_v\to O_v`$ と、辺ごとの全単射 $`U_e:O_v\to O_w`$ が与えられ、$`\omega_wT_e=U_e\omega_v`$ および経路 Law を満たすとする。
可視変更に同型族 $`\eta_v:O_v\xrightarrow{\sim}O_{gv}`$（$`\eta_wU_e=U_{ge}\eta_v`$ を満たす）を含め、持ち上げに追加の保存式 $`\omega_{gv}a_v=\eta_v\omega_v`$ を課す。
定理9.12の対応の下で、このすべての頂点にわたる条件は根での条件 $`\omega_{g r_j}b_j=\eta_{r_j}\omega_{r_j}`$ と同値である。
実際、式(9.10)の左から $`\omega_{gv}`$ を合成し、$`\omega_vP_v=U_{p_v}\omega_{r_j}`$ および $`\eta_vU_{p_v}=U_{g p_v}\eta_{r_j}`$ を代入すればすべての頂点での保存式が従い、逆方向は根で評価するだけで得られる。
したがって $`g=1,\ \eta=\mathrm{id}`$ の垂直変更群においては、式(9.11)の各因子に $`\omega_{r_j}b_j=\omega_{r_j}`$ を追加すればよい。
このように、選んだ追加観測は中心化群の条件へそのまま反映される。

## 9.5 持ち上げのファイバーと選択の整合

最後に、すべての可視変更とその持ち上げを集めた変更全体の群を構成し、持ち上げを持つ各可視変更 $`g\in G_{\mathrm{lift}}`$ の上の持ち上げファイバーが垂直変更群の torsor になること、および定理9.12の記述が根と経路の選び方によらず整合することを示す。
さらに、各ファイバーが非空であっても群準同型となる切断が存在しない具体例と、その障害を記述するコサイクル方程式を導く。

**命題9.14（変更全体の群と持ち上げの torsor）.**
可視変更 $`g\in G_{\mathrm{vis}}`$ とその持ち上げ $`a\in\mathrm{Lift}(g)`$ の対 $`(g,a)`$ の全体は、積と逆元

**式(9.12)**

```math
(g,a)(h,b)=(gh,c),\qquad c_v=a_{hv}b_v,
\qquad
(g,a)^{-1}=(g^{-1},d),\quad d_v=a_{g^{-1}v}^{-1}
```

によって群 $`G_{\mathrm{chg}}`$ をなす。
第一成分への射影 $`\pi:G_{\mathrm{chg}}\to G_{\mathrm{vis}}`$ の核は垂直変更群 $`K`$ であり、像 $`G_{\mathrm{lift}}`$ は持ち上げ可能な可視変更からなる部分群である。
各 $`g\in G_{\mathrm{lift}}`$ に対し、ファイバー $`\pi^{-1}(g)=\mathrm{Lift}(g)`$ は右からの合成作用によって $`K`$-torsor となる。

**証明.**
積 $`(g,a)(h,b)`$ の状態族 $`c_v=a_{hv}b_v`$ について、任意の辺 $`e:v\to w`$ に式(9.7)を2回適用すると、

```math
c_wT_e=a_{hw}b_wT_e
 =a_{hw}T_{he}b_v
 =T_{ghe}a_{hv}b_v=T_{ghe}c_v
```

となり、$`c\in\mathrm{Lift}(gh)`$ が従う。逆元 $`(g,a)^{-1}`$ の族 $`d_v`$ の可換性も、式(9.7)を逆射について解くことで得られる。
全体の状態集合 $`S_X`$ 上では、これらは通常の全単射の合成と逆写像であり、可視成分も通常の群の合成なので群公理が成り立つ。
射影 $`\pi`$ は群準同型であり、核が $`K`$、像が $`G_{\mathrm{lift}}`$ であることは定義から直ちに従う。

同じファイバー $`\pi^{-1}(g)`$ に属する二つの元 $`a,b`$ に対して $`a^{-1}b\in K`$ かつ $`a(a^{-1}b)=b`$ であるから、右作用は推移的である。
また $`ak=ak'`$ ならば左から $`a^{-1}`$ を掛けて $`k=k'`$ を得るため、作用は自由である。
以上により $`\pi^{-1}(g)`$ は $`K`$-torsor である。□

ここで扱ったファイバーは、可視変更、protocol、および両端の同定を固定した実際の持ち上げ全体である。
第8章の図式補完の枠組みでは、辺の可換正方形、状態の全単射とその逆、および指定した観測の比較を原始宣言に含めることでこのファイバーが得られる。
比較の際にも両端の固定自明化を保つため、これは解集合を離散 groupoid として読む問題になる。
$`K`$ の作用は一つの持ち上げから別の持ち上げを生み出す作用であり、固定データを忘れて軌道を同一視する問題を選ぶ場合には、その商を別途取ることになる。

**命題9.15（根と経路の選択への整合）.**
同じ連結成分 $`j`$ において根を $`r_j`$ から別の頂点 $`r'_j`$ に変更し、根どうしを結ぶ符号付き経路 $`q_j:r_j\rightsquigarrow r'_j`$ を選ぶ。
このとき、定理9.12における根のデータの比較は

**式(9.13)**

```math
b'_j=T_{gq_j}\,b_j\,T_{q_j}^{-1}
```

によって与えられる。新しい根 $`r'_j`$ からの経路をどの全域木（あるいは任意の経路選択）から選んでも、式(9.13)の比較の後に定理9.12で復元される持ち上げは元の持ち上げに厳密に一致する。
垂直変更群の比較は $`b_j\mapsto T_{q_j}b_jT_{q_j}^{-1}`$ という群同型になり、変更全体の群の積、射影、および各ファイバーの $`K`$ 作用もこの比較の下で一致する。

**証明.**
旧根のデータ $`(b_j)`$ から定理9.12によって実際の持ち上げ $`a`$ を復元する。
すべての経路に対する可換式を $`q_j:r_j\rightsquigarrow r'_j`$ に適用すると、新根 $`r'_j`$ での値 $`a_{r'_j}`$ は式(9.13)の右辺 $`T_{gq_j}b_jT_{q_j}^{-1}`$ に等しい。
新根と新しい経路選択について定理9.12を適用すると、同じ実際の持ち上げ $`a`$ を新根で評価してから再復元することになるため、すべての頂点において元の $`a`$ が回復される（これにより全域木の変更も同時に吸収される）。

垂直変更（$`g=1`$）の場合、ループの作用も $`T_{q_j}`$ による共役で移るため、中心化群の比較は上記の群同型 $`b_j\mapsto T_{q_j}b_jT_{q_j}^{-1}`$ となる。
2回の選択変更の比較は、途中で実際の持ち上げへの復元と評価が互いに相殺するため合成に一致する。
群演算と torsor 作用はいずれも同じ実際の状態写像の合成から定義されているため、この比較によって完全に保たれる。□

次に、すべての可視変更が個別に持ち上げを持つ（各ファイバーが非空である）にもかかわらず、合成を保つ群準同型としての切断が存在しない具体例を与える。

**例9.16（各可視変更の持ち上げと群切断の非存在）.**
頂点集合を $`\{0,1\}`$、辺を $`e:0\to1`$ と $`f:1\to0`$ の2本とし、追加の経路 Law は課さない。
両頂点のファイバーをともに $`\{0,1\}`$ とし、その交換置換を $`\kappa`$ として、$`T_e=\mathrm{id}`$、$`T_f=\kappa`$ と定める（2状態を $`\mathbb F_2`$ と見なせば $`\kappa(x)=x+1`$ であり、有限アフィン変換網の例にもなっている）。
可視変更群 $`G_{\mathrm{vis}}`$ は、2頂点と2辺を同時に交換する位数が2の対合 $`g`$（$`g^2=1`$）で生成される群とする。

まず垂直変更 $`(b_0,b_1)`$ を求める。辺 $`e`$ の可換式は $`b_1=b_0`$、辺 $`f`$ の可換式は $`b_0\kappa=\kappa b_1`$ である。
2点集合の置換は $`\mathrm{id}`$ と $`\kappa`$ のみなので、垂直変更群 $`K`$ は恒等と $`k=(\kappa,\kappa)`$ の2元からなる（根を $`0`$、木の辺を $`e`$ に取ればループ $`fe`$ の holonomy は $`\kappa`$ であり、中心化群もこの2元群に一致する）。

次に $`g`$ の持ち上げ $`(a_0,a_1)`$ の式を書き下すと、

```math
a_1=\kappa a_0,\qquad a_0\kappa=a_1
```

となる。したがって $`g`$ の持ち上げは $`(a_0,a_1)=(\mathrm{id},\kappa)`$ と $`(\kappa,\mathrm{id})`$ のちょうど二つ存在する。
しかし、式(9.12)を用いてどちらの持ち上げについても2乗を計算すると、両頂点成分がともに $`\kappa`$ となる。
すなわち、$`g`$ の二つの持ち上げはいずれも2乗すると $`k\ne1`$ になり、4乗して初めて恒等になる。
結果として、変更全体の群 $`G_{\mathrm{chg}}`$ は4元巡回群、可視変更群 $`G_{\mathrm{vis}}`$ は2元巡回群、射影 $`\pi`$ はその剰余写像となる。

もし群準同型となる切断 $`s:G_{\mathrm{vis}}\to G_{\mathrm{chg}}`$ が存在したとすれば、$`s(g)^2=s(g^2)=1`$ でなければならないが、これは $`g`$ のすべての持ち上げの2乗が $`k\ne1`$ であることに矛盾する。
したがって、すべての可視変更が個別に持ち上げを持つにもかかわらず、合成を保つ大域的な選択（群切断）は存在しない。

**選択の合成条件.**
より一般に、射影 $`\pi:G_{\mathrm{chg}}\to G_{\mathrm{lift}}`$ に対し、集合としての切断 $`g\mapsto a_g`$ を $`a_1=1`$ と正規化して選ぶ（無限群でその存在を用いる場合には、各非空ファイバーからの選択に選択公理を用いる）。この段階では $`g\mapsto a_g`$ が群準同型であることは仮定しない。
積のずれを表す元 $`c(g,h)`$ と共役作用 $`\alpha_g`$ を

```math
c(g,h)=a_ga_ha_{gh}^{-1}\in K,\qquad
\alpha_g(k)=a_gka_g^{-1}
```

と置くと、群の結合律からコサイクル条件

```math
c(g,h)c(gh,\ell)=\alpha_g(c(h,\ell))c(g,h\ell)
```

が成り立つ（実際、両辺へ右から $`a_{gh\ell}`$ を掛けると、左辺は $`(a_ga_h)a_\ell`$、右辺は $`a_g(a_ha_\ell)`$ となる）。
切断の選択を $`a'_g=b_ga_g`$（$`b_g\in K,\ b_1=1`$）へ変更すると、直接の積の展開によって新しいずれは

```math
c'(g,h)=b_g\alpha_g(b_h)c(g,h)b_{gh}^{-1}
```

へと変換される。
したがって、合成を保つ群切断が存在するかという問題は、すべての $`g,h\in G_{\mathrm{lift}}`$ に対して右辺を恒等元 $`1`$ にする族 $`(b_g)`$ の同時方程式が解を持つかという問題に帰着する。
これにより、個々のファイバーの非空性（個別の持ち上げの存在）と、この同時方程式の可解性（整合する切断の存在）とを明確に区別できる。

**問題9.17（部分操作を含む商と代表選択）.**
名前付き部分操作とその定義域を持つ任意の状態集合について、どの操作合同関係が、定義域の保存・反射を伴う商とすべての操作語の観測保存とを同時に与えるかを決定せよ。
さらに、そのうち保存切断を持つものを、原始的な定義域と操作の条件から分類せよ。
全域操作に関する定理9.5および定理9.8に対応する合同関係の区間と冪等射の分裂を求めることが課題である。

**問題9.18（持ち上げの整合する選択）.**
名前付きグラフ、可逆な辺作用、経路 Law、および可視部分群を入力とし、上の同時方程式 $`c'(g,h)=1`$ のすべての解を原始入力から構成せよ。
グラフとすべてのファイバーが有限であり、可視部分群が有限表で与えられる場合にはすべての持ち上げの列挙から判定できるが、一般の入力に対して必要十分な構造条件と、表示の変更に自然なすべての選択の記述を求めることが課題である。

本章で構成した商・分裂・持ち上げは、いずれも具体的な操作と観測の保存式を保持している。
第11–12章では固定部分を持つ修正作用とその持ち上げをこの形で比較し、第15章では分裂を reading の変更に沿って輸送する。
さらに第17–18章では、可視情報を固定したときに残る解の自由度を、同じファイバーの上で詳しく調べる。
