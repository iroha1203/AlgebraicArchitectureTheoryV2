# 第8章 条件を満たす変更と図式補完

変更元、固定する部分、許す変更、満たすべき評価を指定すると、一つの変更問題が定まる。
その解には実際の状態写像と操作の翻訳が含まれ、固定部分の同定も保持される。
この章では、それらの全解を構成し、原始規則から生成した候補との対応を証明する。
固定図式の補完、変更の経路、状態の移送も、同じ対象と比較射を用いて扱う。

## 8.1 許容規則の構文・意味・同一視

**定義8.1（許容規則と独立な許容条件）.**
第7章の意味圏 $`\mathcal A`$ と変更groupoid $`\mathcal C`$ を用いる。
許容規則 $`H`$ には次のデータを指定する。

1. 動かしてよい宣言と固定する宣言、その型・Lawの支持・固定部分への対応。
2. 型付きterm代入、補助sort・演算・phaseの導入と忘却の規則。
   各規則の入力・出力・parameter・適用条件と、その担体・写像による解釈式。
3. 規則の合成、候補どうしの比較の生成規則、およびそれらの間の同一視。
4. 意味側の許容条件。これは両端の実現、実際の状態写像、語翻訳、固定データから述べる。
   指定した同型で運ぶと同じ条件になることを要求する。

例えば「状態担体の階数を $`n`$ にする」「操作を次数 $`d`$ 以下にする」
「指定sortの比較を恒等にする」は意味側の条件である。
指定されたsectionや固定部分の同型も問題の入力・解に含まれるなら、その実写像を保持する。
係数・文脈の変更を使う場合は、全データの移し方と許容条件の保存も指定する。

構文候補は、規則を型の合う順に適用した有限式と、そのparameter、状態写像、語翻訳、
必要なwitnessである。比較規則から自由groupoidを作り、指定した関係で割ったものを
$`\mathcal E_H`$ と書く。parameterに係数を使うときは、その環での等号も用いる。
各規則の式を評価し、複合候補は第7章の合成で評価する。
比較生成元を両端の同型へ送り、各関係の両辺が同じ可換な同型となることを確認すれば、
評価は候補groupoid上の関手になる。
全端点のLaw、操作・観測保存、適用条件を満たす候補の部分groupoidを
$`\mathrm{Syn}_H`$ とする。
合成した候補の許容条件も指定する。一段の条件が合成で閉じない場合には、
各段のwitnessを持つ経路として扱うか、合成後の条件を改めて課す。

一方、$`\mathrm{Adm}_H`$ の対象は独立な意味射と定義8.1の許容条件・固定データであり、
射はそれらを保つ可換な同型である。
こちらは「構文候補の像に入る」という条件で定義しない。
規則の解釈式が意味側の条件を満たすことを各規則について確かめると、関手

```math
\mathrm{ev}_H:\mathrm{Syn}_H\longrightarrow\mathrm{Adm}_H
```

を得る。term代入の保存には第1章の代入評価、合成の保存には定理7.7を使う。
補助sortやphaseを導入する規則では、そのdomain・操作の式も検査する。
この構成で得た健全性に加え、全対象の復元と全比較射の復元が完全性の内容となる。

**例8.2（構文witnessを忘れるとき）.**
同じ恒等変更を作る二つの規則名 $`r_0,r_1`$ を置き、比較を恒等だけにすると、
候補groupoidには同じ意味射に対応する二対象がある。
意味側で規則名を保持しない場合、両者の間の恒等比較は候補側に持ち上がらず、評価は充満でない。
二規則を結ぶ比較と、その比較が一意になる関係を加えると、この余分な区別を消せる。
逆に規則名自体を選ぶことが問題の一部なら、意味側にもそのデータを残す。
対象の到達可能性と比較射の完全性は、ここで別々に検査される。

## 8.2 候補生成と条件付き変更族

### 多項式実現での全候補の復元

**補題8.3（一般元による係数と行列の抽出）.**
任意の可換環 $`R`$ と有限な $`m,n`$ に対し、全 $`R`$-代数 $`S`$ 上の自然写像
$`F_S:S^m\to S^n`$ は、一意な $`n`$ 個の多項式
$`p_i\in R[x_1,\ldots,x_m]`$ の評価である。
各 $`F_S`$ が $`S`$-線形なら、一意な行列 $`M\in\mathrm{Mat}_{n\times m}(R)`$ の評価である。

**証明.**
多項式環 $`P=R[x_1,\ldots,x_m]`$ の一般元 $`\boldsymbol x`$ に対し
$`(p_1,\ldots,p_n)=F_P(\boldsymbol x)`$ と置く。
任意の $`\boldsymbol a\in S^m`$ に対する代入環射 $`P\to S`$ の自然性から
$`F_S(\boldsymbol a)=(p_i(\boldsymbol a))_i`$ となる。
逆に多項式の評価は環射に自然であり、一般元に戻せば係数が元へ戻る。
線形な場合は $`F_R`$ の標準基底の像を行列の列とする。
自然性で各代数上の基底の像もその列の像となり、線形性で全入力の値が決まる。
逆に行列評価は線形かつ自然であり、基底への評価で元の行列に戻る。□

ここで次数 $`d`$ 以下とは、抽出した多項式の $`|\nu|>d`$ の係数が全て0であることとする。
零多項式もこの条件を満たす。この定義は基礎体の点だけで測る次数を用いない。

**定理8.4（有限自由多項式族の候補生成の完全性）.**
次のデータを固定する。

- 有限sort、有限個の頂点・生成射・関係で表示された図式形、各頂点の有限自由担体の階数。
- 各頂点の有限個の全域操作・量・観測とその次数上限、有限個の多項式Law。
- 各生成射の型付きterm・語翻訳。複数の翻訳を許す場合はその添字と同一視を指定する。
- 固定する宣言・図式・その同定、および宣言した式による適用条件。

意味側では、担体を全 $`R`$-代数 $`S`$ 上の $`S^{n_s}`$ とし、
操作を補題8.3の意味で次数制限を満たす自然写像、状態比較を線形な自然写像とする。
Law、保存式、図式関係は全代数上の等式とする。
比較は固定データと可換する自然な線形同型である。
この独立な意味のgroupoidに対し、以下の原始規則 $`H_{\mathrm{poly}}`$ で生成した候補の評価は同値となる。
同値は係数変更、支持を保つ文脈制限に自然である。

**構成と証明.**
各操作 $`f`$ の各出力成分に、入力変数の単項式 $`\boldsymbol x^\nu`$、
$`|\nu|\le d_f`$ の係数 $`c_{f,i,\nu}`$ を導入する。
候補の操作は有限和 $`\sum_\nu c_{f,i,\nu}\boldsymbol x^\nu`$ で生成する。
各状態比較には全サイズの行列変数を置く。
固定部分のtrivializationにも行列と逆行列を置き、両積が恒等という式を課す。
Law、term翻訳、保存式、図式関係をこれらの式へ代入し、
全出力成分の全単項式係数を残差として0にする。
固定宣言は指定係数への等式に、固定図式は可換式にする。
追加の適用条件も宣言された式のまま課す。

構文の和・積の式は係数配列の多項式へ展開し、その配列が等しい式を同一視する。
比較の生成元は、各担体の可逆行列と、操作・全辺・固定データに対する可換式である。
可逆性は逆行列を持つことを式として表し、比較の関係には行列積、恒等行列、逆行列の式を用いる。
したがって比較を一部の特別な行列だけに限らず、全ての可逆行列を候補にする。
逆行列は存在すれば一意なので、その表示に追加の選択は残らない。

これらを評価すると、残差係数が0であるため任意の代数の任意の入力でLawと保存式が成り立つ。
図式の関係式も成立するので、生成射の合成は表示された圏上の図式に降りる。
行列の可換式が比較を与え、行列積の関係も成分で成立する。これで健全性を得る。

逆に独立な意味の実現を取る。
各操作の一般元への値から補題8.3で係数を抽出し、各状態比較から行列を抽出する。
次数条件が指定した有限単項式内に全係数があることを保証する。
Lawと保存式を多項式環の一般元で評価すると、全残差係数が0になる。
図式と固定部分の同定も行列として読め、その可換性が対応する式を満たす。
よって構文候補を得る。評価後の全自然写像は補題8.3により元の写像であり、
抽出後の係数は元の配列である。これで全対象を復元した。

意味側の任意の比較同型も、補題8.3で一意な可逆行列族となる。
その自然性と固定条件の可換式は、一般元への評価により候補の比較式になる。
逆に全ての候補比較はその同型へ評価される。
二比較が同じなら標準基底への値が等しいため行列が等しく、関係で同一視される。
従って全Hom集合の対応は全単射であり、恒等と合成も行列積で一致する。

環射 $`R\to R'`$ に沿う変更は、抽出した係数と行列の各成分を送ることで作る。
補題8.3により、これは元の自然写像を $`R'`$-代数に制限したものと一致する。
和・積・term代入・残差係数の生成と可換するので、flatnessを仮定せず自然である。
文脈制限では、残す宣言とその支持の係数を取るだけで、同じ抽出になる。
翻訳を動かす場合も添字と指定された比較を保ってこの構成を行う。
以上で評価と復元の自然な同値を得た。□

固定図式を持つ場合の対象と比較式の全記述は8.3節で与える。
この定理は第6章の多重線形演算を次数制限された多項式演算へ広げている。
有限局所自由の担体では自由化するchart上でこの抽出を行い、
基底変更の式と第6章の加群・射のdescentで同じ対象へ戻す。
具体的には次数 $`d`$ 以下の多項式写像 $`E\to F`$ の係数は
$`F\otimes\bigoplus_{i=0}^d\mathrm{Sym}^i(E^\vee)`$ の切断である。
自由なchartで単項式係数とこの切断が対応し、基底変更の線形代入も一致する。
有限局所自由加群とその切断のdescentをこの係数加群へ適用すれば操作が降下し、
Lawと保存式は忠実平坦性によって残差係数の零性から降下する。
有限個の係数と多項式等式のみならaffine chart、単元条件を加えればその基本開部分を得る。
基底を忘れた比較も、上で復元した可逆行列の作用groupoidに保持される。

**例8.5（台帳の全線形比較）.**
単一台帳 $`D=R`$ と分割台帳 $`R^2`$ の加群構造を固定し、
線形写像 $`p:R^2\to R`$、$`i,j:R\to R^2`$ を動かす。
applyを $`v\mapsto v+i(u)`$、compactを $`v\mapsto v+j(t)`$ とし、readを $`p`$ とする。
単一台帳への比較を $`p`$、compactの翻訳を空語と指定する。
意味側では全代数上の自然な線形写像 $`p,i,j`$ を量化する。
補題8.3により一意に

```math
p=(a,b),\qquad i=(c,d)^{\mathsf T},\qquad j=(r,s)^{\mathsf T}
```

と書ける。applyとcompactの保存は、それぞれ

```math
ac+bd=1,\qquad ar+bs=0
```

に等しい。必要性は入力 $`v=0,u=1,t=1`$ で得られ、十分性は線形な代入で得られる。
したがってこの変更問題の全係数候補は
$`\mathrm{Spec}\,R[a,b,c,d,r,s]/(ac+bd-1,ar+bs)`$ である。
比較同型はこれらの写像を保つ可逆行列であり、定理8.4はその全体も復元する。
基底と $`p=(1,1)`$ を固定すると
$`i=(\lambda,1-\lambda)^{\mathsf T}`$、$`j=(\mu,-\mu)^{\mathsf T}`$ となり、
全候補の係数は $`R[\lambda,\mu]`$ で表される。
この固定された表示の下で、例7.3の全操作語の保存を得る。

### 評価条件を満たす全変更

**構成8.6（条件付き変更族）.**
独立な許容変更のgroupoidを $`\mathcal C_H=\mathrm{Adm}_H`$ と書く。
候補で計算する際には $`\mathrm{Syn}_H`$ と評価関手を併せて用いる。
集合値の関手 $`E`$、部分関手 $`V\hookrightarrow E`$、評価 $`v:\mathcal C_H\to E`$ を指定する。
評価は候補同型で不変であり、使う係数変更に自然とする。
$`E,V`$ を離散groupoidとして読む。
係数環 $`R`$ と実現 $`a\in\mathcal M(R)`$ に対し、全 $`R`$-代数上で

**式(8.1)**

```math
\mathcal F_{a,H,V}
=\left(\mathcal C_H\mathbin{\times^{(2)}_{s,\mathcal M,a}}\mathrm{Spec}\,R\right)
 \mathbin{\times^{(2)}_{E_R}}V_R
```

を作る。ここで $`\mathrm{Spec}\,R`$ は $`R`$-代数上の終対象関手である。
$`S`$ 上の対象を具体的に書けば

```math
(c,\alpha,e),\qquad
\alpha:s(c)\xrightarrow{\sim}a_S,\quad e\in V(S),\quad v(c)=e\text{ in }E(S)
```

である。射 $`(c,\alpha,e)\to(c',\alpha',e')`$ は
$`\gamma:c\xrightarrow{\sim}c'`$ で
$`\alpha' s(\gamma)=\alpha`$、$`e'=e`$ を満たすものとする。
$`c`$ に固定図式の同定が含まれるなら、$`\gamma`$ はその同定も保つ。
部分関手であるため、$`e`$ は存在すれば一意であり、新たな選択を増やさない。

**系8.7（独立な全解と候補からの回復）.**
式(8.1)のgroupoidは、始域を $`a`$ と同定し、許容・固定条件を満たし、
評価が $`V`$ に属する独立な全変更のgroupoidである。
定理8.4の族では、構文候補に同じ条件を課したgroupoidからの評価は自然な同値になる。

**証明.**
上の対象・射の記述が独立な全解を与える。
候補側では、定理8.4で復元した状態写像・語翻訳・可逆行列に、$`\alpha`$ の行列と
その逆行列、評価条件を加える。
復元は全比較射に忠実充満で、$`\alpha' s(\gamma)=\alpha`$ も同じ可換式になる。
評価は同型で不変なので、同値で運ばれた候補にも同じ $`e`$ がある。
この抽出と評価は元の $`c,\alpha,e`$ へ戻り、係数変更と可換する。□

幾何的表示を得る場合は評価にも条件を課す。
定理8.4の有限chart上で $`v`$ が多項式評価であり、$`V`$ が有限個の
$`f_i=0`$、$`g_j\in S^\times`$ で指定されるとする。
始域の指定同型と逆同型の行列を加え、その可換式を課し、
さらに $`f_i(v)=0`$ と新しい変数 $`t_j`$ による $`t_jg_j(v)=1`$ を課す。
逆元は一意なので、このaffine chartの点から式(8.1)の全データが回復する。
比較同型は定理8.4の行列式と $`\alpha' s(\gamma)=\alpha`$ を満たすものを全て残す。
したがって基底を保つ問題のschemeと、基底を忘れた問題のgroupoid表示をそれぞれ得る。
一般の $`E,V`$ については式(8.1)の解関手を用いる。

固定始域を厳密に $`a_S`$ とした表示も使える。
$`h:s(c)\to t(c)`$ を $`h\alpha^{-1}:a_S\to t(c)`$ に置き換え、
固定witnessを同じ同型で運ぶと、始域上の比較は恒等になる。
許容条件の同型不変性によりこれも許容変更であり、$`\alpha`$ を持つ表示と同値である。

一般の写像 $`V\to E`$ を使うと、式(8.1)はliftの選択も分類する。
例えば定数関手 $`E=\{*\}`$、$`V=\{0,1\}`$ では一つの候補に二つのliftがある。
部分関手を使った場合の「条件を満たす」という意味と区別する。

$`\mathcal F(R)`$ の対象は固定環上の解であり、被覆後の解は局所解である。
各fiberが非空という主張と、基底の全点にわたり自然に解を選ぶsectionの存在も別の主張である。
例えば群準同型の各fiberに元があっても、群準同型であるsectionは存在しないことがある。
その具体例を第9章で構成する。

**問題8.8（一般の許容規則の完全性）.**
補助sort、phase、関係、部分操作、無限担体を含む任意の $`H`$ について、
独立に指定した $`\mathrm{Adm}_H`$ の全対象と全比較を $`\mathrm{Syn}_H`$ から復元せよ。
各許容クラスの可定義性、normal form、意味の問題自体に含まれるwitnessを調べ、
不足する生成規則または比較の関係を特定せよ。
例えば自然な $`x\mapsto x^2`$ を許す意味に次数1以下の候補だけを置くと、
$`R=\mathbb Z`$ の一般元で二次係数を比較して対象の欠落が分かる。
例8.2は比較の欠落を示す。これらの検査を通じ、一般の場合にも
系8.7の候補表示から全解への同値とその自然性を構成することが課題となる。

## 8.3 固定図式とtrivializationを保つ全補完

**定義8.9（固定図式の補完）.**
小圏 $`J`$、部分圏 $`K_{\mathrm{fix}}\hookrightarrow J`$、
図式 $`d:K_{\mathrm{fix}}\to\mathcal A`$ を固定する。
補完は図式 $`D:J\to\mathcal A`$ と自然同型
$`\alpha:D|_{K_{\mathrm{fix}}}\xrightarrow{\sim}d`$ の対である。
比較 $`\beta:(D,\alpha)\to(D',\alpha')`$ は自然同型 $`D\to D'`$ で

**式(8.2)**

```math
\alpha'\circ\beta|_{K_{\mathrm{fix}}}=\alpha
```

を満たすものとする。そのgroupoidを $`\mathcal D_{J,K_{\mathrm{fix}},d}`$ と書く。
図式の各辺には非可逆な意味射を許す。

**定理8.10（原始表示からの全補完の回復）.**
各頂点の原始表示、各射の比較表示、合成の関係、固定部分の同定から、
補完の比較表示を構成できる。そのモデルと全比較射を読む関手は
$`\mathcal D_{J,K_{\mathrm{fix}},d}`$ への同値である。
その帰結として自然な同値

```math
\mathcal D_{J,K_{\mathrm{fix}},d}
\simeq\mathrm{Fun}(J,\mathcal A)^{\simeq}
\mathbin{\times^{(2)}_{\mathrm{Fun}(K_{\mathrm{fix}},\mathcal A)^{\simeq}}}\{d\}
```

を得る。厳密固定 $`D|_{K_{\mathrm{fix}}}=d`$、$`\alpha=\mathrm{id}`$ の部分groupoidも
このgroupoidと同値であり、その比較は固定部で恒等である。

**証明.**
各 $`j\in J`$ に担体・操作・Lawの宣言を置き、各射 $`e:j\to l`$ に
構成7.5の写像宣言 $`H_e`$ と保存式を置く。
さらに $`H_{\mathrm{id}_j}=\mathrm{id}`$、$`H_{fe}=H_fH_e`$ を課す。
理論変更を含む場合は理論成分の合成も記録し、状態成分には第2章の引戻しを入れる。
固定部分の各頂点では、$`D(j)`$ と $`d(j)`$ の間の写像 $`A_j,B_j`$ を宣言し、
双方の構造保存、$`A_jB_j=\mathrm{id}`$、$`B_jA_j=\mathrm{id}`$ を課す。
固定部分の各辺には $`A_lH_e=d(e)A_j`$ を課す。

モデルから各頂点の独立な実現と各射の実写像を読む。
合成関係によりこれは関手 $`D`$ となる。
$`A_j`$ とその逆 $`B_j`$ が自然同型 $`\alpha`$ を与える。
逆に任意の $`D,\alpha`$ の全成分を宣言へ代入すると、上の全関係が成り立つ。
各宣言へ戻るので対象の相互回復を得る。

表示の同型は頂点ごとの構造同型 $`\beta_j`$ で、
各 $`H_e`$ との可換性と $`A_j'\beta_j=A_j`$ を満たすものになる。
前者は自然性、後者は式(8.2)である。
従って全ての比較を一意に回復し、恒等・合成も一致する。
右辺の2-fiber積の対象・射を書けば、まさにこの $`D,\alpha,\beta`$ である。
有限表示された $`J`$ なら生成辺と関係だけを宣言しても、経路評価の一意性により同じ復元を得る。
小さい一般の $`J`$ では全頂点・全射・全合成関係を保持する。

厳密固定への復元は次で与える。
$`j\in K_{\mathrm{fix}}`$ なら $`D^s(j)=d(j)`$、$`a_j=\alpha_j`$、
それ以外なら $`D^s(j)=D(j)`$、$`a_j=\mathrm{id}`$ と置く。
全辺について $`D^s(e)=a_lD(e)a_j^{-1}`$ とする。
中間の $`a_j^{-1}a_j`$ が消えるので関手となり、固定部分では $`\alpha`$ の自然性により
$`D^s(e)=d(e)`$ である。
$`a:D\cong D^s`$ は補完間の同型となる。
比較は $`\beta_j^s=a_j'\beta_ja_j^{-1}`$ で運び、式(8.2)から固定部で恒等になる。
厳密固定から出発すれば元へ戻り、これが同値を与える。□

係数変更や文脈制限を全頂点・全辺・$`\alpha`$ に適用すると、
同じ方程式と同じ読戻しを得る。図式形を部分図式へ制限する場合も同様である。
原始表示を別の表示へ変える場合は、対象と全射の評価・復元を持つ比較を各頂点へ適用し、
各辺と固定同定をその関手で運ぶ。準逆と単位・余単位の自然性が図式と式(8.2)にも作用するため、
補完groupoidの比較同値を得る。
定理8.4の基底変更と多項式のnormal formはこの具体例である。

このgroupoidに $`H`$ の許容条件と $`V`$ の評価条件を課すと、固定図式付きの条件付き変更族になる。
定理8.4の有限自由族では、上の頂点・辺・逆行列・関係の構成によってその全候補も復元される。
定理8.10の厳密化を用いるときは、$`H`$ のwitnessも同型で運び、評価の不変性を使う。

**例8.11（固定された二辺を持つ正方形）.**
図式形を $`0\to1\to3`$、$`0\to2\to3`$ とその合成の等式とし、
固定部分を $`f:A\to B`$、$`g:A\to C`$ の二辺とする。
厳密固定の補完は $`Z`$ と $`u:B\to Z`$、$`v:C\to Z`$ で $`uf=vg`$ を満たすもの。
比較は同型 $`z:Z\to Z'`$ で $`zu=u'`$、$`zv=v'`$ を満たすものとなる。
非厳密な表示では $`A,B,C`$ への三つの同定も記録し、式(8.2)で保つ。
例えば裸の集合の意味圏で $`A=B=C=\{*\}`$、$`f=g=\mathrm{id}`$ なら、
補完は一点 $`z_0\in Z`$ を選んだ集合であり、比較は $`z_0`$ を保つ全単射である。
固定した二辺とその同定から、この対象と全比較を直接回復できる。

## 8.4 許された一段変更と経路

一段の許容規則から、実写像と必要なwitnessを持つgroupoid
$`\mathcal E\to\mathcal C`$ を作る。
長さ $`n`$ の経路は

```math
\mathcal P_n=
\underbrace{\mathcal E\mathbin{\times^{(2)}_{\mathcal M}}\cdots
\mathbin{\times^{(2)}_{\mathcal M}}\mathcal E}_{n\text{ 個}},\qquad
\mathcal P_0=\mathcal M
```

に始点・終点・中間段の固定条件と評価を課したgroupoidである。
接続には終域と次の始域の指定同型を使う。
その同型を挟んで辺を合成する写像 $`\mathcal P_n\to\mathcal C`$ は定理7.7で構成される。
二経路を接続すると辺の列が連結し、全変更への写像はその合成になる。
単位と結合の整合も同じ定理から従う。

一段の評価条件が、合成後の変更にも成立するかは各条件による。
例えば一段の長さを1と指定した場合、二段の経路の長さは2である。
一段を細分するには、新しい辺それぞれの許容性、合成が元の射に等しいこと、
追加した中間状態の評価を保持する。
こうして同じ端点射を与える経路の違いも扱える。

**例8.12（係数点の合法性とphaseの状態Law）.**
係数 $`\delta,\mu`$ に $`\mu\delta=0`$ を課す。
Idleの状態を $`(B,C)`$、Busyの状態を
$`(B,C,z)`$ で $`\mu(z-C)=0`$ を満たすものとし、

```math
\begin{aligned}
\mathrm{begin}(B,C)&=(B,C,C),\\
\mathrm{apply}^{\mathrm{Busy}}_u(B,C,z)&=(B+(1-\delta)u,C+\delta u,z),\\
\mathrm{finish}(B,C,z)&=(B+\mu z,(1-\mu)C)
\end{aligned}
```

とする。Idleでのapplyも最初の二成分と同じ式である。
begin後の状態Lawは0、Busyのapply後の左辺は
$`\mu(z-C)-\mu\delta u=0`$ である。
readを $`B+C`$ とすると、beginはreadを保ち、applyは $`u`$ だけ増やし、
finishのread差は $`\mu(z-C)=0`$ となる。
beginとfinishを空語へ送ることで、定理7.2の全許可経路の保存を得る。

$`R=\mathbb Q`$ で係数点を $`(\delta,\mu)=(1,0),(0,0),(0,1)`$ の順に選ぶ。
三点とも係数Lawを満たす。
最初の点で合法なBusy状態 $`(B,C,z)=(0,1,0)`$ を最後まで同じ三成分で保持すると、
最後では $`\mu(z-C)=-1`$ となり状態Lawを満たさない。
Idleにはこの追加条件がなく、共通readを保って切り替えられる。
係数の経路から実状態の移送を得るには、各phaseで次節の移送条件を満たす写像を作る必要がある。

## 8.5 状態移送と操作domainのlift

**定理8.13（移送後の全操作語と合成）.**
意味射 $`h:X_1\to X_0`$ が、$`X_1`$ の操作語を $`X_0`$ の語へ送る翻訳 $`\tau`$ と
観測について定理7.2の条件を満たすとする。
移送を許す状態の部分集合 $`\iota_D:D\hookrightarrow X_0`$ と写像 $`m:D\to X_1`$ が

**式(8.3)**

```math
h\circ m=\iota_D
```

を満たすなら、$`x\in D`$ で $`w_1(m(x))`$ が定義される全有限語について

```math
o_1(w_1(m(x)))=o_0(\tau(w)_0(x))
```

が成り立ち、右辺の語も定義される。
旧側の指定語を移送後にも実行するには、その語への翻訳lift $`w`$ と
$`m(x)\in\mathrm{Dom}_{X_1}(w)`$ を指定する。
特に生成domainの反射がある場合は、翻訳語の旧側での実行可能性からこのdomain条件が従う。

二段の意味射 $`h_{01}:X_1\to X_0`$、$`h_{12}:X_2\to X_1`$ と移送
$`m_{01}:D_0\to X_1`$、$`m_{12}:D_1\to X_2`$ があり、
$`m_{01}(D_0)\subseteq D_1`$ なら、$`m_{12}\circ m_{01}`$ は
$`h_{01}h_{12}`$ に沿う移送である。語翻訳は二つの翻訳の合成になる。

**証明.**
定理7.2を $`m(x)`$ に適用すると
$`h(w_1(m(x)))=\tau(w)_0(h(m(x)))=\tau(w)_0(x)`$ である。
観測の可換性 $`o_1=o_0h`$ が結論を与える。
実行可能性の前向き保存と反射も同じ定理で従う。
二段では中間像の包含が合成を定義し、
$`h_{01}h_{12}m_{12}m_{01}=h_{01}m_{01}=\iota_{D_0}`$ となる。
合成した意味射の操作保存は定理7.7で得られ、同じ観測計算を適用できる。□

移送 $`m`$ 自体に操作保存を要求する問題では、その可換式も別に課す。
式(8.3)だけを課す移送と、全操作を保つ代表選択は区別され、後者を第9章で扱う。

**構成8.14（全移送のfiberと自然性）.**
固定した $`h,D`$ に沿う全移送は

```math
\mathrm{Tr}(h,D)=
\mathrm{Map}(D,X_1)\mathbin{\times_{\mathrm{Map}(D,X_0)}}\{\iota_D\},
\qquad m\longmapsto hm
```

である。domainのlift、許容規則、評価を要求するときは、対応する条件をこのfiberに課す。
この対象は定理8.10の可換三角形の補完でもある。
底辺 $`D\to X_0`$ と辺 $`X_1\to X_0`$ を固定し、残る辺を $`m`$ とする。
ここでは状態集合の写像の圏を使い、必要なら追加の構造保存式を課す。

固定データも動かす場合、比較は同型 $`a_i:X_i\to X_i'`$、$`b:D\to D'`$ で
$`h'a_1=a_0h`$、$`\iota_{D'}b=a_0\iota_D`$、$`m'b=a_1m`$ を満たすものとする。
これが全移送と全比較のgroupoidを与える。

係数の族では $`X_0,X_1,D`$ を全代数上の状態関手と部分関手として取り、
各 $`S`$ 上の $`m`$ を全 $`S`$-代数上で自然な写像とする。
環射 $`S\to S'`$ でこの自然写像を $`S'`$-代数へ制限すれば係数変更となる。
式(8.3)、domain包含、比較の可換式はその制限でも同じ式なので保存される。
二段移送も写像の合成の制限となり、係数変更に自然である。
文脈制限では残す状態・語・domainの宣言を全て保持し、同じ式を読む。
表示変更についても8.3節の評価と復元をこの三角形に適用すれば、全移送と比較を回復できる。

ここで得た $`\mathcal F_{a,H,V}`$、固定図式の $`\alpha`$、全比較射は、
局所変更の組立てと修復を扱う第IV部へ渡すデータとなる。
**問題8.15（修復作用との比較）.**
固定部分と変更可能な範囲を指定した実修復を原始操作から構成し、
本章の補完groupoidのどの条件付きfiberに対応するかを求めよ。
対象の修復だけでなく、式(8.2)を保つ再同定と評価・復元の自然性まで構成せよ。
