# 第8章 条件を満たす変更と図式補完

変更元、固定する部分、許す変更、満たすべき評価を指定すると、一つの変更問題が定まる。
その解には実際の状態写像と操作の翻訳が含まれ、固定部分の同定も保持される。
この章では、それらの全解を構成し、原始規則から生成した候補との対応を証明する。
固定図式の補完、変更の経路、状態の移送も、同じ対象と比較射を用いて扱う。

## 8.1 許容規則の構文・意味・同一視

**定義8.1（許容規則の型と意味条件）.**
設定7.1の意味圏 $`\mathcal A`$ と変更groupoid $`\mathcal C`$ を用いる。
係数を固定した許容規則 $`H`$ は次のデータからなる。

1. 小さい型集合 $`I`$、各型の実データの集合 $`X_i`$、許すデータの部分集合 $`Q_i\subseteq X_i`$。
   出力型 $`*\in I`$ のデータは、両端の担体・原始構造、状態写像、語翻訳、
   固定宣言の対応、選んだ写像やparameterなどのwitnessを持つ記録とする。
   この段階ではLawや保存式を満たさない記録も許す。
2. 各生成規則 $`r:(i_1,\ldots,i_m)\to j`$ のparameter集合 $`P_r`$、
   適用域 $`\Delta_r\subseteq P_r\times\prod_\nu X_{i_\nu}`$、
   解釈式 $`F_r:\Delta_r\to X_j`$。$`m=0`$ も許す。
   sort・演算・phaseの追加や忘却は、その担体・写像を返すこの型の規則で指定する。
3. $`X_*`$ の記録の間の比較。これは両端の構造同型と固定データ・witnessの対応であり、
   状態写像と可換するものとする。記録と全比較でgroupoid $`\mathcal B_H`$ を作る。
   $`Q_*`$ は、両端のLaw、状態射の保存条件、その他の許容条件を独立に満たす記録の集合とし、
   比較で不変とする。その充満部分groupoidを $`\mathrm{Adm}_H`$ と書く。
   $`Q_*`$ を「生成規則の像に入る」という条件では定めない。
4. 生成規則から作る有限の型付き式、同じ出力型 $`*`$ の二式を結ぶ比較生成元、
   および同始点・同終点の比較語どうしの関係。
   各比較生成元には、その両端の式を評価した記録の間の $`\mathcal B_H`$ の同型を指定する。

式の評価は、部分式を順に評価し、その値が $`\Delta_r`$ に入るとき $`F_r`$ を適用する帰納法で定める。
各適用が定義される閉式を候補とする。候補の記述をnormal formに取る場合も、その規則を指定する。
出力型 $`*`$ の候補を頂点、比較生成元を辺とするグラフの自由groupoidを
$`\mathcal E_H`$ とし、指定関係で割ったgroupoidを $`\mathrm{Syn}_H`$ とする。
ここで自由groupoidは、辺と形式的逆辺の有限列を、恒等と隣り合う逆の消去で割って作る。
さらに指定関係を合成と逆に閉じて課す。

係数や文脈を動かす場合は、$`X_i,P_r,\Delta_r,Q_i`$ と記録の比較の運び方も指定する。
係数変更と宣言制限は型を保ち、適用域と許容部分集合を保ち、$`F_r`$ と可換するものとする。
比較生成元とその関係も同じ記号の変更へ送り、設定7.1の単位・合成比較と整合させる。
記録上のこの輸送から $`\mathcal B_H`$ と $`\mathrm{Adm}_H`$ の擬関手が定まる。
これは意味側の原始条件の保存であり、構文候補の完全性を仮定するものではない。

**命題8.2（生成規則の健全性と評価関手）.**
定義8.1の各規則が、許容入力から許容出力を作る、すなわち

```math
F_r\left(\Delta_r\cap\left(P_r\times\prod_\nu Q_{i_\nu}\right)\right)
 \subseteq Q_j
```

を満たすとする。0引数規則もこの条件に含める。
さらに、指定した比較関係の両辺は $`\mathcal B_H`$ の同じ同型に評価されるとする。
このとき記録の評価と比較語の合成は関手

```math
\mathrm{ev}_H:\mathrm{Syn}_H\longrightarrow\mathrm{Adm}_H
```

を定める。定義8.1の輸送条件の下で、この関手は係数変更・文脈制限に擬自然である。

**証明.**
閉式の構文木で帰納する。葉は0引数規則の条件により許容データになる。
各内部頂点では、帰納法で入力が $`Q_{i_\nu}`$ に入り、規則の条件から出力が $`Q_j`$ に入る。
よって出力記録は $`\mathrm{Adm}_H`$ の対象であり、Law・保存式・許容条件が成立する。
比較語は指定同型の合成へ、逆辺はその逆同型へ送る。
恒等と逆の消去はgroupoidの等式で保たれ、指定関係も仮定から同じ同型となる。
従って商groupoid上で定まり、恒等と合成を保つ。

輸送と評価の可換性も構文木で帰納する。
葉のparameterを運び、各 $`F_r`$ の可換性を一段ずつ使えば、対象の二通りの評価が一致する。
比較語では生成同型の輸送が合成・逆を保つので同じことが成り立つ。
単位と二段の輸送比較は各記録の成分で定義8.1の比較に一致し、三段の整合も成分で成立する。
よって擬自然性を得る。□

この命題の仮定は各生成式と比較関係について検査する局所条件である。
任意に書いた規則の健全性を自動で結論するものではなく、以下の多項式族では原式から検査する。
一段の許容条件が合成で閉じない場合には、各段のwitnessを持つ経路を出力とするか、
合成後の条件を適用域に課す。

**例8.3（構文witnessを忘れるとき）.**
同じ恒等変更を作る二つの規則名 $`r_0,r_1`$ を置き、比較を恒等だけにすると、
候補groupoidには同じ意味射に対応する二対象がある。
意味側で規則名を保持しない場合、両者の間の恒等比較は候補側に持ち上がらず、評価は充満でない。
二規則を結ぶ比較と、その比較が一意になる関係を加えると、この余分な区別を消せる。
逆に規則名自体を選ぶことが問題の一部なら、意味側にもそのデータを残す。
対象の到達可能性と比較射の完全性は、ここで別々に検査される。

## 8.2 候補生成と条件付き変更族

### 多項式実現での全候補の復元

**補題8.4（一般元による係数と行列の抽出）.**
任意の可換環 $`R`$ と有限な $`m,n`$ に対し、全 $`R`$-代数 $`S`$ 上の自然写像
$`F_S:S^m\to S^n`$ は、一意な $`n`$ 個の多項式
$`p_i\in R[x_1,\ldots,x_m]`$ の評価である。
各 $`F_S`$ が $`S`$-線形なら、一意な行列 $`M\in\mathrm{Mat}_{n\times m}(R)`$ の評価である。

**証明.**
多項式環 $`P=R[x_1,\ldots,x_m]`$ の一般元 $`\boldsymbol x`$ に対し
$`(p_1,\ldots,p_n)=F_P(\boldsymbol x)`$ と置く。
任意の $`\boldsymbol a\in S^m`$ に対する代入環射 $`P\to S`$ の自然性から
$`F_S(\boldsymbol a)=(p_i(\boldsymbol a))_i`$ となる。
逆に多項式の評価は環射に自然であり、一般元に戻せば係数が元へ戻る。
線形な場合は $`F_R`$ の標準基底の像を行列の列とする。
自然性で各代数上の基底の像もその列の像となり、線形性で全入力の値が決まる。
逆に行列評価は線形かつ自然であり、基底への評価で元の行列に戻る。□

ここで次数 $`d`$ 以下とは、抽出した多項式の $`|\nu|>d`$ の係数が全て0であることとする。
零多項式もこの条件を満たす。この定義は基礎体の点だけで測る次数を用いない。

**定義8.5（多項式候補と独立な意味の族）.**
基礎可換環 $`k`$ 上の次の有限データを固定し、環射ではその係数も運ぶ。

- 有限sort、有限個の頂点・生成射・関係で表示された図式形、頂点 $`v`$ のsort $`s`$ ごとの階数 $`n_{v,s}`$。
- 各頂点の全域操作・量・観測の型と次数上限、有限個の多項式Law。
  観測値と外部parameterの固定sortは命題7.9と同じ共有担体とする。
- 各生成射の型付きterm・語翻訳、固定宣言・固定図式とその同定。
- 抽出した係数・行列・保持したparameterに対する有限個の多項式等式 $`f_i=0`$ と
  単元条件 $`g_j\in R^\times`$。$`f_i,g_j`$ の係数は $`k`$ に取り、
  この条件は固定データを保つ比較で不変とする。
  座標に依存する条件ではその座標も固定データに含める。

まず翻訳を固定する。$`\mathrm{Adm}_{\mathrm{poly}}(R)`$ の対象は、全 $`R`$-代数 $`S`$ 上の
担体 $`S^{n_{v,s}}`$、次数上限を満たす自然な操作・量・観測、線形な自然状態写像、
および固定データの同定であり、Law・保存式・図式関係を全代数上で満たすものとする。
次数と追加条件は補題8.4の一般元・標準基底から得る係数・行列で読む。
射は各担体の自然な線形同型で、全原始写像・辺・固定同定・保持parameterと可換するものとする。
これは自然写像から定義され、構文候補から生成されることを条件に含めない。

$`\mathrm{Syn}_{\mathrm{poly}}(R)`$ の対象は、次数内の全単項式係数、全状態行列、
固定同定の行列と逆行列、単元条件の逆元 $`t_j`$ の配列であり、次を満たすものとする。
Law・保存式・図式関係の全残差係数は0、固定宣言の係数は指定値、
固定同定の両積は恒等、さらに $`f_i=0`$、$`t_jg_j=1`$ である。
射は全可逆行列族で、原始写像・全辺・固定同定・parameterとの可換式を満たすもの。
恒等・合成は恒等行列と行列積で定める。

この候補を生成する $`H_{\mathrm{poly}}`$ は、有限和と積による多項式式を単項式係数へ展開し、
係数配列をnormal formにする規則である。
全サイズの行列を状態写像に、可逆行列と逆行列を固定同定と比較に用いる。
適用域には上の残差方程式と単元方程式を置き、比較の関係には行列積・恒等・逆を置く。
これは定義8.1の型として係数配列・行列・記録を、$`P_r`$ として係数を、
$`F_r`$ として多項式評価・行列評価を使う指定である。
従ってnormal formで表した候補groupoidが上の $`\mathrm{Syn}_{\mathrm{poly}}`$ になる。
単元の逆元は一意であり、選択を追加しない。追加の任意witnessを忘れる規則はこの族に含めない。

複数の翻訳を許す場合は、それらの添字groupoidも指定する。
添字間の比較は各頂点の理論同型とsort対応を持ち、対応する階数を一致させ、
term代入が次数上限と固定・追加条件を保つものとする。
その比較に沿う状態行列は $`S^{n_{v,s}}\to S^{n'_{v,\alpha_v(s)}}`$ の型を持つ。
対象には翻訳添字を残し、射はこの理論同型と全可逆状態行列の組とする。
二通りの辺の翻訳は定理7.6の比較式を満たすものをすべて取る。
これにより、sortの置換を含む指定比較も、構文側と意味側で同じ添字として扱える。

**定理8.6（有限自由多項式族の候補生成の完全性）.**
定義8.5の評価は、全可換 $`k`$-代数 $`R`$ でgroupoidの同値

```math
\mathrm{ev}_{\mathrm{poly}}:
\mathrm{Syn}_{\mathrm{poly}}(R)\xrightarrow{\sim}\mathrm{Adm}_{\mathrm{poly}}(R)
```

を与える。対応は任意の係数変更と、翻訳・固定・追加条件の支持を残す
構成7.5の文脈制限に自然である。基底を局所的に選ぶ有限局所自由族にも、
命題7.9のdescentを通じて同じ全対象・全比較の回復を与える。

**構成と証明.**
各操作 $`f`$ の各出力成分に、入力変数の単項式 $`\boldsymbol x^\nu`$、
$`|\nu|\le d_f`$ の係数 $`c_{f,i,\nu}`$ を導入する。
候補の操作は有限和 $`\sum_\nu c_{f,i,\nu}\boldsymbol x^\nu`$ で生成する。
各状態比較には全サイズの行列変数を置く。
固定部分のtrivializationにも行列と逆行列を置き、両積が恒等という式を課す。
Law、term翻訳、保存式、図式関係をこれらの式へ代入し、
全出力成分の全単項式係数を残差として0にする。
固定宣言は指定係数への等式に、固定図式は可換式にする。
追加条件は定義8.5の $`f_i=0`$ と $`t_jg_j=1`$ を課す。

構文の和・積の式は係数配列の多項式へ展開し、その配列が等しい式を同一視する。
比較の生成元は、各担体の可逆行列と、操作・全辺・固定データに対する可換式である。
可逆性は逆行列を持つことを式として表し、比較の関係には行列積、恒等行列、逆行列の式を用いる。
したがって比較を一部の特別な行列だけに限らず、全ての可逆行列を候補にする。
逆行列は存在すれば一意なので、その表示に追加の選択は残らない。

これらを評価すると、残差係数が0であるため任意の代数の任意の入力でLawと保存式が成り立つ。
図式の関係式も成立するので、生成射の合成は表示された圏上の図式に降りる。
行列の可換式が比較を与え、行列積の関係も成分で成立する。
追加の多項式条件は同じ係数で成り立ち、$`t_jg_j=1`$ が単元条件を与える。
これは命題8.2の生成規則と比較関係の条件を原式で検査したものであり、健全性を得る。

逆に独立な意味の実現を取る。
各操作の一般元への値から補題8.4で係数を抽出し、各状態比較から行列を抽出する。
次数条件が指定した有限単項式内に全係数があることを保証する。
Lawと保存式を多項式環の一般元で評価すると、全残差係数が0になる。
図式と固定部分の同定も行列として読め、その可換性が対応する式を満たす。
追加条件は意味側でもこの抽出係数で読んでいるので、$`f_i=0`$ が成立する。
各 $`g_j`$ は単元であり、その一意な逆を $`t_j`$ として読むと候補側の追加方程式も満たす。
よって構文候補を得る。評価後の全自然写像は補題8.4により元の写像であり、
抽出後の係数は元の配列である。これで全対象を復元した。

意味側の任意の比較同型も、補題8.4で一意な可逆行列族となる。
その自然性と固定条件の可換式は、一般元への評価により候補の比較式になる。
逆に全ての候補比較はその同型へ評価される。
二比較が同じなら標準基底への値が等しいため行列が等しく、関係で同一視される。
従って全Hom集合の対応は全単射であり、恒等と合成も行列積で一致する。

環射 $`R\to R'`$ に沿う変更は、抽出した係数と行列の各成分を送ることで作る。
補題8.4により、これは元の自然写像を $`R'`$-代数に制限したものと一致する。
和・積・term代入・残差係数の生成と可換し、等式を保つ。
単元の逆元も環射で逆元へ移るため追加条件を保ち、flatnessを仮定せず自然である。
文脈制限では、残す宣言とその支持の係数を取るだけで、同じ抽出になる。
翻訳を動かす場合は、定義8.5の理論同型のsort対応に従って各行列の型を移す。
term代入の評価は係数の代入と可換し、指定比較が次数・追加条件を保つ。
意味側の任意の比較は同じ理論添字と一意の状態行列へ戻るので、添字間の全Homも回復する。
以上で評価と復元の自然な同値を得た。□

固定図式を持つ場合の対象と比較式の全記述は8.3節で与える。
この定理の多項式実現方式は命題7.9で構成した方式である。
有限局所自由な場合は、自由化の重なり上で係数抽出と基底変更が可換するため、
命題7.9の対象・全ての射のdescentを適用する。追加等式の零性は忠実平坦性で反映される。
単元条件も降下する。実際、局所の逆元は一意なので重なり上で一致し、
切断のdescentにより大域の逆元になる。
このため候補と意味の局所同値はdescent dataにも同値を与え、全局所自由族の同値となる。

**例8.7（台帳の全線形比較）.**
単一台帳 $`D=R`$ と分割台帳 $`R^2`$ の加群構造を固定し、
線形写像 $`p:R^2\to R`$、$`i,j:R\to R^2`$ を動かす。
applyを $`v\mapsto v+i(u)`$、compactを $`v\mapsto v+j(t)`$ とし、readを $`p`$ とする。
単一台帳への比較を $`p`$、compactの翻訳を空語と指定する。
意味側では全代数上の自然な線形写像 $`p,i,j`$ を量化する。
補題8.4により一意に

```math
p=(a,b),\qquad i=(c,d)^{\mathsf T},\qquad j=(r,s)^{\mathsf T}
```

と書ける。applyとcompactの保存は、それぞれ

```math
ac+bd=1,\qquad ar+bs=0
```

に等しい。必要性は入力 $`v=0,u=1,t=1`$ で得られ、十分性は線形な代入で得られる。
したがってこの変更問題の全係数候補は
$`\mathrm{Spec}\,R[a,b,c,d,r,s]/(ac+bd-1,ar+bs)`$ である。
比較同型はこれらの写像を保つ可逆行列であり、定理8.6はその全体も復元する。
基底と $`p=(1,1)`$ を固定すると
$`i=(\lambda,1-\lambda)^{\mathsf T}`$、$`j=(\mu,-\mu)^{\mathsf T}`$ となり、
全候補の係数は $`R[\lambda,\mu]`$ で表される。
この固定された表示の下で、例7.3の全操作語の保存を得る。

### 評価条件を満たす全変更

**構成8.8（固定同定を持つ条件付き変更族）.**
独立な許容変更のgroupoidを $`\mathcal C_H=\mathrm{Adm}_H`$ と書く。
始域・終域を取る関手の一方 $`\partial\in\{s,t\}`$ を選ぶ。
係数環 $`R`$ と実現 $`a\in\mathcal M(R)`$ に対し、全 $`R`$-代数上で

```math
\mathcal B^{\partial}_{a,H}
 =\mathcal C_H\mathbin{\times^{(2)}_{\partial,\mathcal M,a}}\mathrm{Spec}\,R
```

と置く。$`\mathrm{Spec}\,R`$ は $`R`$-代数上の終対象関手である。
$`S`$ 上の対象は $`(c,\alpha)`$、$`\alpha:\partial(c)\cong a_S`$ であり、
射は $`\gamma:c\cong c'`$ で $`\alpha'\partial(\gamma)=\alpha`$ を満たすものとする。

集合値の関手 $`E`$ と部分関手 $`V\hookrightarrow E`$、固定同定も入力に取る評価
$`\widetilde v:\mathcal B^{\partial}_{a,H}\to E_R`$ を指定する。
評価は上記の比較で不変、係数変更に自然とし、$`E,V`$ は離散groupoidとして読む。
このとき条件付き変更族を

**式(8.1)**

```math
\mathcal F^{\partial}_{a,H,V}
 =\mathcal B^{\partial}_{a,H}\mathbin{\times^{(2)}_{E_R}}V_R
```

で定める。具体的な対象は

```math
(c,\alpha,e),\qquad
\alpha:\partial(c)\xrightarrow{\sim}a_S,\quad e\in V(S),\quad
\widetilde v(c,\alpha)=e\text{ in }E(S).
```

射は $`\alpha'\partial(\gamma)=\alpha`$、$`e'=e`$ を満たす $`\gamma`$ である。
$`c`$ に固定図式の同定が含まれるなら、$`\gamma`$ はそれも保つ。
部分関手であるため、$`e`$ は存在すれば一意である。
$`\partial=s`$ の場合は $`\mathcal F_{a,H,V}`$ と略す。
固定同定を用いない評価 $`v:\mathcal C_H\to E`$ は
$`\widetilde v(c,\alpha)=v(c)`$ と引き戻す特例である。
固定した $`a`$ 上の要求は一般に $`\alpha`$ に依存するため、まずこのfiberを作ってから評価する。
係数の族を用いない場合は、$`\mathrm{Spec}\,R`$ を一点groupoidに替え、
$`E,V`$ を集合として同じ構成を行う。

同型で運んだ記録も保持する表示を構成する。
記録から実際の変更を取る忘却関手を $`\Phi_H:\mathcal C_H\to\mathcal C`$ とし、
$`\widehat{\mathcal C}_H`$ の対象を
$`(c,b,\theta:\Phi_H(c)\xrightarrow{\sim}b)`$ とする。
ここで $`b`$ は $`\mathcal C`$ の任意の対象である。
比較は $`(\gamma:c\to c',\delta:b\to b')`$ で
$`\delta\theta=\theta'\Phi_H(\gamma)`$ を満たす対とする。
恒等・合成は成分で定め、始域・終域は $`b`$ から取る。
元の記録 $`c`$ を残すので、その固定データとwitnessも保持される。

この表示での端点固定fiberの対象は
$`(c,b,\theta,\alpha:\partial b\cong a_S)`$ であり、評価を
$`\widehat v(c,b,\theta,\alpha)=\widetilde v(c,\alpha\,\partial\theta)`$ とする。
$`\delta\theta=\theta'\Phi_H(\gamma)`$ と $`\alpha'\partial\delta=\alpha`$ から
$`(\alpha'\partial\theta')\partial\Phi_H(\gamma)=\alpha\partial\theta`$ なので、
これは元の評価の比較不変性を引き継ぐ。
係数変更・宣言制限は全成分を運び、忘却関手の比較同型も挿入する。

元の $`\mathcal C_H`$ の内部で端点を厳密固定できるとは限らない。
集合の意味圏で唯一の記録を $`\mathrm{id}_{\{0\}}`$、比較を恒等だけとすると、
$`a=\{1\}`$ への同定を持つfiberは非空だが、始域が厳密に $`a`$ である元の記録はない。
$`\widehat{\mathcal C}_H`$ は、この場合にも同型で運んだ変更を元の記録とともに扱う表示である。

**系8.9（独立な全解と候補からの回復）.**
式(8.1)のgroupoidは、選んだ始域または終域を $`a`$ と同定し、許容・固定条件を満たし、
評価が $`V`$ に属する独立な全変更のgroupoidである。
定理8.6の族では、構文候補に同じ条件を課したgroupoidからの評価は自然な同値になる。
さらに、$`\widehat{\mathcal C}_H`$ を用いて $`\partial b=a_S`$、$`\alpha=\mathrm{id}`$ と
厳密固定した条件付きgroupoidも、式(8.1)の全解と同値である。

**証明.**
上の対象・射の記述が独立な全解を与える。
候補側では、定理8.6で復元した状態写像・語翻訳・可逆行列に、$`\alpha`$ の行列と
その逆行列、評価条件を加える。
復元は全比較射に忠実充満で、$`\alpha'\partial(\gamma)=\alpha`$ も同じ可換式になる。
候補側の評価は $`\widetilde v`$ をこの全データの復元に沿って引き戻したものである。
その比較不変性から、同値で運ばれた候補にも同じ $`e`$ がある。
この抽出と評価は元の $`c,\alpha,e`$ へ戻り、係数変更と可換する。

まず $`\widehat{\mathcal C}_H`$ の同型付きfiberから元のfiberへ
$`(c,b,\theta,\alpha,e)\mapsto(c,\alpha\,\partial\theta,e)`$ と送る。
逆に $`(c,\beta,e)`$ から $`b=\Phi_H(c),\theta=\mathrm{id},\alpha=\beta`$ として戻す。
比較 $`\gamma`$ に対する $`\delta`$ は
$`\delta=\theta'\Phi_H(\gamma)\theta^{-1}`$ と一意に決まり、
端点の可換条件は元のfiberの条件と同値である。
従って全Homを回復し、$`(\mathrm{id}_c,\theta)`$ が往復の自然同型を与える。
評価の定義から $`e`$ も同じである。

次に $`b`$ の実際の射を $`h:A\to B`$ と書く。
始域固定なら $`h^s=h\alpha^{-1}:a_S\to B`$ とし、
$`\rho=(\alpha,\mathrm{id}_B):b\cong b^s`$ を作る。
終域固定なら $`h^t=\alpha h:A\to a_S`$ とし、
$`\rho=(\mathrm{id}_A,\alpha):b\cong b^t`$ を作る。
いずれも $`\partial\rho=\alpha`$ である。
$`(c,b,\theta,\alpha,e)`$ を
$`(c,b^{\partial},\rho\theta,\mathrm{id},e)`$ へ送る。
元の記録 $`c`$ は変えず、新しい実変更と同定を表示に加えるため、これは常に対象となる。
評価も $`\widetilde v(c,\partial(\rho\theta))=\widetilde v(c,\alpha\partial\theta)`$ で一致する。
比較 $`(\gamma,\delta)`$ は $`(\gamma,\rho'\delta\rho^{-1})`$ へ送り、
その端点成分は $`\alpha'\partial\delta\alpha^{-1}=\mathrm{id}`$ となる。
厳密な対象ではこの操作は恒等であり、一般の対象には $`(\mathrm{id}_c,\rho)`$ が往復の自然同型を与える。
これで厳密固定との同値を得る。全構成は合成・逆・成分の輸送からなるので、
係数変更と許された宣言制限に、設定7.1・定義8.1の比較同型と整合して擬自然である。□

幾何的表示を得る場合は評価にも条件を課す。
固定同定の行列と逆行列を加えた定理8.6の有限chart上で $`\widetilde v`$ が多項式評価であり、$`V`$ が有限個の
$`f_i=0`$、$`g_j\in S^\times`$ で指定されるとする。
選んだ端点の指定同型と逆同型の行列を加え、その可換式を課し、
さらに $`f_i(\widetilde v)=0`$ と新しい変数 $`t_j`$ による $`t_jg_j(\widetilde v)=1`$ を課す。
逆元は一意なので、このaffine chartの点から式(8.1)の全データが回復する。
比較同型は定理8.6の行列式と $`\alpha'\partial(\gamma)=\alpha`$ を満たすものを全て残す。
したがって基底を保つ問題のschemeと、基底を忘れた問題のgroupoid表示をそれぞれ得る。
一般の $`E,V`$ については式(8.1)の解関手を用いる。

$`\mathcal C_H`$ 自身について、端点同型に沿う記録・witnessの輸送が構成され、
許容条件を保つと分かっている場合は、運んだ記録を $`\mathcal C_H`$ の対象として使う厳密化もできる。
一般の $`H`$ では、系8.9の同値は $`\widehat{\mathcal C}_H`$ の厳密固定表示を用いる。

一般の写像 $`V\to E`$ を使うと、式(8.1)はliftの選択も分類する。
例えば定数関手 $`E=\{*\}`$、$`V=\{0,1\}`$ では一つの候補に二つのliftがある。
部分関手を使った場合の「条件を満たす」という意味と区別する。

$`\mathcal F(R)`$ の対象は固定環上の解であり、被覆後の解は局所解である。
各fiberが非空という主張と、基底の全点にわたり自然に解を選ぶsectionの存在も別の主張である。
例えば群準同型の各fiberに元があっても、群準同型であるsectionは存在しないことがある。
その具体例を第9章で構成する。

**問題8.10（一般の許容規則の完全性）.**
補助sort、phase、関係、部分操作、無限担体を含む任意の $`H`$ について、
独立に指定した $`\mathrm{Adm}_H`$ の全対象と全比較を $`\mathrm{Syn}_H`$ から復元せよ。
各許容クラスの可定義性、normal form、意味の問題自体に含まれるwitnessを調べ、
不足する生成規則または比較の関係を特定せよ。
例えば自然な $`x\mapsto x^2`$ を許す意味に次数1以下の候補だけを置くと、
$`R=\mathbb Z`$ の一般元で二次係数を比較して対象の欠落が分かる。
例8.3は比較の欠落を示す。これらの検査を通じ、一般の場合にも
系8.9の候補表示から全解への同値とその自然性を構成することが課題となる。

## 8.3 固定図式とtrivializationを保つ全補完

**定義8.11（固定図式の補完）.**
小圏 $`J`$、部分圏 $`K_{\mathrm{fix}}\hookrightarrow J`$、
図式 $`d:K_{\mathrm{fix}}\to\mathcal A`$ を固定する。
補完は図式 $`D:J\to\mathcal A`$ と自然同型
$`\alpha:D|_{K_{\mathrm{fix}}}\xrightarrow{\sim}d`$ の対である。
比較 $`\beta:(D,\alpha)\to(D',\alpha')`$ は自然同型 $`D\to D'`$ で

**式(8.2)**

```math
\alpha'\circ\beta|_{K_{\mathrm{fix}}}=\alpha
```

を満たすものとする。そのgroupoidを $`\mathcal D_{J,K_{\mathrm{fix}},d}`$ と書く。
図式の各辺には非可逆な意味射を許す。

**定理8.12（原始表示からの全補完と自然性）.**
設定7.1の意味圏を用い、構成7.5の混合解釈で各頂点の表示と各辺の比較表示を読む。
固定図式 $`d`$ の原始構造は、定義2.2の固定部分の意味で固定する。
全体圏では、各頂点の理論、各辺の翻訳、固定同定の理論成分とそれらの可換式を添字にもつ
表示族を取る。このとき補完の全比較表示を原始宣言から構成でき、その評価は
$`\mathcal D_{J,K_{\mathrm{fix}},d}`$ への同値を与える。さらに

```math
\mathcal D_{J,K_{\mathrm{fix}},d}
\simeq\mathrm{Fun}(J,\mathcal A)^{\simeq}
\mathbin{\times^{(2)}_{\mathrm{Fun}(K_{\mathrm{fix}},\mathcal A)^{\simeq}}}\{d\}
```

であり、厳密固定 $`D|_{K_{\mathrm{fix}}}=d`$、$`\alpha=\mathrm{id}`$ の部分groupoidとも同値である。
厳密固定の比較は固定部で恒等である。
これらの評価・復元は、設定7.1と構成7.5の係数変更・文脈制限、図式形の制限に擬自然である。
対象と全ての意味射の評価・復元を持つ表示変更が意味圏の同値を与えるなら、
固定図式をその同値で運んだ補完groupoidも同値になり、この同値は制限・合成を保つ。

**証明.**
まず一つの理論を固定する。各 $`j\in J`$ に原始構造の宣言を置き、各射 $`e:j\to l`$ に
構成7.5の写像宣言 $`H_e`$ と保存式を置く。
共有する固定sortは複製せず、$`H_{\mathrm{id}_j}=\mathrm{id}`$、$`H_{fe}=H_fH_e`$ を課す。
固定部分の各頂点には $`D(j)`$ と指定された構造 $`d(j)`$ の間の写像 $`A_j,B_j`$ を置く。
$`d(j)`$ の担体・原始写像は固定し、その上の比較も恒等とする。
両写像の保存式と $`A_jB_j=\mathrm{id}`$、$`B_jA_j=\mathrm{id}`$ を課す。
固定部分の辺については $`A_lH_e=d(e)A_j`$ を課す。
これは各宣言群を別に読む混合解釈であり、追加写像に両端と共通の局所split性を課さない。

全体圏の場合には、射影 $`\pi:\mathcal A_{\mathrm{tot}}\to\mathbf T_\sigma`$ を使う。
添字は関手 $`\vartheta:J\to\mathbf T_\sigma`$ と自然同型
$`\gamma:\vartheta|_{K_{\mathrm{fix}}}\cong\pi d`$ である。
頂点 $`j`$ には $`\vartheta(j)`$ のモデル、辺 $`e:j\to l`$ には
$`H_e:D(j)\to\vartheta(e)^*D(l)`$ の混合解釈を置く。
合成条件は $`H_{fe}=\kappa_{\vartheta(e),\vartheta(f)}\,\vartheta(e)^*H_f\,H_e`$、
恒等条件は設定7.1の $`\eta`$ を使う。
固定辺の意味射を $`d(e)=(\delta_e,k_e)`$、
$`\delta_e=\pi d(e)`$、$`k_e:d(j)\to\delta_e^*d(l)`$ と分解する。
固定部では $`A_j:D(j)\cong\gamma_j^*d(j)`$ とその逆を置き、

```math
\kappa_{\vartheta(e),\gamma_l}\,\vartheta(e)^*A_l\,H_e
 =\kappa_{\gamma_j,\delta_e}\,\gamma_j^*k_e\,A_j
```

を課す。両辺の終域は $`(\gamma_l\vartheta(e))^*d(l)=(\delta_e\gamma_j)^*d(l)`$ である。
添字間の比較は自然同型 $`\lambda:\vartheta\cong\vartheta'`$ で
$`\gamma'\lambda|_{K_{\mathrm{fix}}}=\gamma`$ を満たすもの。
その上に各頂点の状態同型を置き、定理7.6の全体圏の可換式を全辺と固定同定に課す。
従って理論同型も全ての比較の一部として保持される。

これらを評価すると、恒等・合成の式から実関手 $`D`$ を得て、
$`A_j`$ とその逆から $`\alpha`$ を得る。
逆に任意の $`(D,\alpha)`$ は、全体圏なら $`\vartheta=\pi D,\gamma=\pi\alpha`$ を定め、
その担体・原始写像・全辺・同定の成分を代入すると全関係を満たす。
両方向は全成分を戻す。比較は各頂点の同型で全辺と可換し、
$`\alpha'\beta|_{K_{\mathrm{fix}}}=\alpha`$ を満たすものなので、全Homも相互回復する。
固定理論の表示ではこの最後の式は $`A_j'\beta_j=A_j`$ となる。
右辺の2-fiber積の対象・射も同じデータであり、同値を得る。
有限表示の $`J`$ では生成辺と関係で同じ構成を行い、一般の小圏では全ての辺と合成関係を残す。

厳密固定には、$`j\in K_{\mathrm{fix}}`$ で $`D^s(j)=d(j),a_j=\alpha_j`$、
それ以外で $`D^s(j)=D(j),a_j=\mathrm{id}`$ と置き、
$`D^s(e)=a_lD(e)a_j^{-1}`$ とする。この式は全体圏でもその圏の合成で読む。
中間の $`a_j^{-1}a_j`$ が消えるため関手となり、固定辺では自然性から $`D^s(e)=d(e)`$ となる。
比較は $`\beta_j^s=a_j'\beta_ja_j^{-1}`$ へ送り、固定部では式(8.2)により恒等になる。
$`a:D\cong D^s`$ が往復の自然同型を与えるので、厳密固定との同値を得る。

自然性を成分で確認する。係数変更または許された宣言制限の関手を $`F`$ とすると、
各辺は $`F(D(e))`$、固定同定は $`F(\alpha_j)`$ となる。
表示から先に読んでも各原始成分に同じ $`F`$ が作用する。
合成式は $`F(H_fH_e)=F(H_f)F(H_e)`$ に、厳密化は
$`F(a_lD(e)a_j^{-1})=F(a_l)F(D(e))F(a_j)^{-1}`$ により保たれる。
全体圏の $`\kappa,\chi`$ を含む式も、設定7.1の整合で同じ可換図式へ移る。
二段・三段の変更比較は各頂点と各辺で同設定の比較に一致する。
部分図式への制限は頂点・辺の一部を残すので、全ての式とこれらの比較をそのまま保つ。

最後に表示変更の意味圏同値を $`F:\mathcal A\simeq\mathcal A'`$、
固定対象の指定比較を $`\delta:Fd\cong d'`$ とする。
補完を $`(D,\alpha)\mapsto(FD,\delta\,F\alpha)`$、比較を $`\beta\mapsto F\beta`$ と送る。
各可換式は関手性で保存される。
準逆 $`G`$ と単位 $`\eta:\mathrm{Id}\cong GF`$ を取ると、
$`(D',\alpha')`$ から $`GD'`$ と
$`\eta_d^{-1}G(\delta^{-1}\alpha'):(GD')|_{K_{\mathrm{fix}}}\cong d`$ を作れる。
単位・余単位の自然性が全辺と固定同定を保つ往復の自然同型を与える。
全比較の回復は $`F`$ の忠実充満性による。
二つの表示変更の合成は成分関手の合成と一致し、図式の制限とも可換する。
多項式候補の場合は、定理8.6の係数抽出と評価を全頂点・全辺・同定へ適用することが
この構成そのものである。□

このgroupoidに $`H`$ の許容条件と $`V`$ の評価条件を課すと、固定図式付きの条件付き変更族になる。
定理8.6の有限自由族では、上の頂点・辺・逆行列・関係の構成によってその全候補も復元される。
一般の $`H`$ を課した後に厳密化するときは、構成8.8の忘却先を補完groupoidへ替え、
元の許容記録・実補完・その同定を持つ表示を使う。
定理8.12で作る $`D\cong D^s`$ をこの同定へ後合成すれば、元のwitnessを保持したまま
厳密補完を得る。評価は元の記録への同定に沿って読み、系8.9と同じ比較式で全解を回復する。

**例8.13（固定された二辺を持つ正方形）.**
図式形を $`0\to1\to3`$、$`0\to2\to3`$ とその合成の等式とし、
固定部分を $`f:A\to B`$、$`g:A\to C`$ の二辺とする。
厳密固定の補完は $`Z`$ と $`u:B\to Z`$、$`v:C\to Z`$ で $`uf=vg`$ を満たすもの。
比較は同型 $`z:Z\to Z'`$ で $`zu=u'`$、$`zv=v'`$ を満たすものとなる。
非厳密な表示では $`A,B,C`$ への三つの同定も記録し、式(8.2)で保つ。
例えば裸の集合の意味圏で $`A=B=C=\{*\}`$、$`f=g=\mathrm{id}`$ なら、
補完は一点 $`z_0\in Z`$ を選んだ集合であり、比較は $`z_0`$ を保つ全単射である。
固定した二辺とその同定から、この対象と全比較を直接回復できる。

## 8.4 許された一段変更と経路

一段の許容規則から、実写像と必要なwitnessを持つgroupoid
$`\mathcal E\to\mathcal C`$ を作る。
長さ $`n`$ の経路は

```math
\mathrm{Path}_{H,n}=
\underbrace{\mathcal E\mathbin{\times^{(2)}_{\mathcal M}}\cdots
\mathbin{\times^{(2)}_{\mathcal M}}\mathcal E}_{n\text{ 個}},\qquad
\mathrm{Path}_{H,0}=\mathcal M
```

に始点・終点・中間段の固定条件と評価を課したgroupoidである。
接続には終域と次の始域の指定同型を使う。
その同型を挟んで辺を合成する写像 $`\mathrm{Path}_{H,n}\to\mathcal C`$ は定理7.7で構成される。
二経路を接続すると辺の列が連結し、全変更への写像はその合成になる。
単位と結合の整合も同じ定理から従う。

一段の評価条件が、合成後の変更にも成立するかは各条件による。
例えば一段の長さを1と指定した場合、二段の経路の長さは2である。
一段を細分するには、新しい辺それぞれの許容性、合成が元の射に等しいこと、
追加した中間状態の評価を保持する。
こうして同じ端点射を与える経路の違いも扱える。

**例8.14（係数点の合法性とphaseの状態Law）.**
係数 $`\delta,\mu`$ に $`\mu\delta=0`$ を課す。
Idleの状態を $`(B,C)`$、Busyの状態を
$`(B,C,z)`$ で $`\mu(z-C)=0`$ を満たすものとし、

```math
\begin{aligned}
\mathrm{begin}(B,C)&=(B,C,C),\\
\mathrm{apply}^{\mathrm{Busy}}_u(B,C,z)&=(B+(1-\delta)u,C+\delta u,z),\\
\mathrm{finish}(B,C,z)&=(B+\mu z,(1-\mu)C)
\end{aligned}
```

とする。Idleでのapplyも最初の二成分と同じ式である。
begin後の状態Lawは0、Busyのapply後の左辺は
$`\mu(z-C)-\mu\delta u=0`$ である。
readを $`B+C`$ とすると、beginはreadを保ち、applyは $`u`$ だけ増やし、
finishのread差は $`\mu(z-C)=0`$ となる。
beginとfinishを空語へ送ることで、定理7.2の全許可経路の保存を得る。

$`R=\mathbb Q`$ で係数点を $`(\delta,\mu)=(1,0),(0,0),(0,1)`$ の順に選ぶ。
三点とも係数Lawを満たす。
最初の点で合法なBusy状態 $`(B,C,z)=(0,1,0)`$ を最後まで同じ三成分で保持すると、
最後では $`\mu(z-C)=-1`$ となり状態Lawを満たさない。
Idleにはこの追加条件がなく、共通readを保って切り替えられる。
係数の経路から実状態の移送を得るには、各phaseで次節の移送条件を満たす写像を作る必要がある。

**例8.15（許容規則と評価条件から修正式を回復する）.**
基礎可換環 $`k`$ を固定し、$`R`$ を任意の $`k`$-代数とする。
単一台帳 $`D=R`$、外部入力、read $`p(B,C)=B+C`$ と、
Idle・Busyのambient担体の名前付き座標を固定する。
比較 $`p`$ は各phaseの状態から単一台帳へ向くため、
ここでは構成8.8の $`\partial=t`$、$`a=D`$ とした終域固定fiberを用いる。
固定部分の全比較はこれらの座標と単一台帳の上で恒等とする。

許容規則を広げ、係数 $`\delta,\mu,\rho`$ を独立な名前付きparameterとして持つ候補を作る。
begin、両phaseのapply、read、語翻訳は例8.14の式を用いる。
変更可能な宣言は、finishが差し引く量とBusyの状態Lawである。
差し引く量を現在値 $`C`$ と取得済みの値 $`z`$ のaffineな組合せとし、
その係数 $`\rho`$ を保持した規則

```math
\mathrm{finish}_{\rho}(B,C,z)
 =\bigl(B+\mu z,\ C-\mu((1-\rho)C+\rho z)\bigr)
```

を許す。finishによるreadの差を計算すると
$`g_\rho=\mu(1-\rho)(z-C)`$ となる。
Busyの状態を、この原式から生成するLaw $`g_\rho=0`$ の解とする。
従って状態Lawも候補の実際の担体に反映され、finishの式とともに動く。
全代数上でこの担体と操作を読み、parameterを環射で運ぶ。

原始操作を代入すると

```math
\mathrm{begin}^*g_\rho=0,\qquad
(\mathrm{apply}^{\mathrm{Busy}}_u)^*g_\rho
 =g_\rho-\mu\delta(1-\rho)u,\qquad
p\,\mathrm{finish}_\rho-p=g_\rho.
```

従って $`\mu\delta(1-\rho)=0`$ なら、全操作が指定された状態を保ち、
applyはreadを $`u`$ だけ増やし、begin・finishはreadを保つ。
定理7.2により全許可経路が単一台帳の対応する語と同じ観測を持つ。
逆に全てのapplyをBusy上の操作とするには、beginで作る状態 $`(0,0,0)`$ に
$`\mathrm{apply}^{\mathrm{Busy}}_1`$ を施した状態でもLawが成立する必要がある。
その残差は $`-\mu\delta(1-\rho)`$ であるから、この係数は0でなければならない。
同じ式は、原始式としてbegin・apply・finishを合成したreadの差でもある。
これで、操作の閉性と全語の保存に必要十分な条件を原式から得た。

宣言したparameter付き規則の全候補は

```math
Z=\mathrm{Spec}\,k[\delta,\mu,\rho]/(\mu\delta(1-\rho))
```

で表される。点からparameterと状態Law、全操作、比較 $`p`$、語翻訳を上の式で戻し、
候補から名前付きparameterを読むと元の点へ戻る。
座標とparameterを固定する比較は恒等なので、この問題の全比較も回復する。
parameterを忘れる問題を選ぶ場合には、同じ操作式となる候補の比較を別に加える。
例えば $`\mu=0`$ での $`\rho`$ の値はfinishからは読めず、名前付きparameterの保持がここで効く。

評価を $`v:Z\to E=\mathbb A^2_k`$、$`v=(\delta,\mu)`$ とし、
部分関手 $`V=\mathbb G_m^2\hookrightarrow E`$ を選ぶ。
これは各代数で両係数が単元であるという条件であり、係数変更に自然である。
その全解の座標環では

```math
k[\delta^{\pm1},\mu^{\pm1},\rho]/(\mu\delta(1-\rho))
 \cong k[\delta^{\pm1},\mu^{\pm1}],\qquad \rho=1.
```

逆元を掛けて $`1-\rho=0`$ を得ることと、$`\rho=1`$ を代入することが互いに逆である。
従って全解は $`\mathbb G_m^2`$ であり、求めた修正式は

```math
\mathrm{finish}_{1}(B,C,z)=(B+\mu z,C-\mu z)
```

となる。同時に $`g_1=0`$ は恒等式となるため、Busyの担体は全 $`R^3`$ へ広がる。
この状態Lawの変更と実際のfinishを、同じ解から回復した。
式の代入と単元の逆元は環射と可換するので、この回復は係数変更に自然である。

比較として、旧Busy Law $`\mu(z-C)=0`$ を固定した許容規則を取る。
finishを変更しても、begin後のapplyの閉性は依然として $`\mu\delta=0`$ を要求する。
両係数を可逆にすると座標環は零環となり、解schemeは空になる。
一方、旧合法係数 $`\mu\delta=0`$ の上では旧Busyから $`R^3`$ への包含があり、
旧Lawから $`\mu z=\mu C`$ なので旧finishと $`\mathrm{finish}_1`$ はその包含上で一致する。
begin・apply・readも同じ式である。
これにより、状態Lawを変更可能にすることがどの新しい解を許すか、
既存の合法状態と操作をどの写像で回復するかが、同じ固定データの下で分かる。

## 8.5 状態移送と操作domainのlift

**定理8.16（移送後の全操作語と合成）.**
意味射 $`h:X_1\to X_0`$ が、$`X_1`$ の操作語を $`X_0`$ の語へ送る翻訳 $`\tau`$ と
観測について定理7.2の条件を満たすとする。
移送を許す状態の部分集合 $`\iota_D:D\hookrightarrow X_0`$ と写像 $`m:D\to X_1`$ が

**式(8.3)**

```math
h\circ m=\iota_D
```

を満たすなら、$`x\in D`$ で $`w_1(m(x))`$ が定義される全有限語について

```math
o_1(w_1(m(x)))=o_0(\tau(w)_0(x))
```

が成り立ち、右辺の語も定義される。
旧側の指定語を移送後にも実行するには、その語への翻訳lift $`w`$ と
$`m(x)\in\mathrm{Dom}_{X_1}(w)`$ を指定する。
特に生成domainの反射がある場合は、翻訳語の旧側での実行可能性からこのdomain条件が従う。

二段の意味射 $`h_{01}:X_1\to X_0`$、$`h_{12}:X_2\to X_1`$ と移送
$`m_{01}:D_0\to X_1`$、$`m_{12}:D_1\to X_2`$ があり、
$`m_{01}(D_0)\subseteq D_1`$ なら、$`m_{12}\circ m_{01}`$ は
$`h_{01}h_{12}`$ に沿う移送である。語翻訳は二つの翻訳の合成になる。

**証明.**
定理7.2を $`m(x)`$ に適用すると
$`h(w_1(m(x)))=\tau(w)_0(h(m(x)))=\tau(w)_0(x)`$ である。
観測の可換性 $`o_1=o_0h`$ が結論を与える。
実行可能性の前向き保存と反射も同じ定理で従う。
二段では中間像の包含が合成を定義し、
$`h_{01}h_{12}m_{12}m_{01}=h_{01}m_{01}=\iota_{D_0}`$ となる。
合成した意味射の操作保存は定理7.7で得られ、同じ観測計算を適用できる。□

移送 $`m`$ 自体に操作保存を要求する問題では、その可換式も別に課す。
式(8.3)だけを課す移送と、全操作を保つ代表選択は区別され、後者を第9章で扱う。

**構成8.17（全移送のfiberと自然性）.**
固定した $`h,D`$ に沿う全移送は

```math
\mathrm{Tr}(h,D)=
\mathrm{Map}(D,X_1)\mathbin{\times_{\mathrm{Map}(D,X_0)}}\{\iota_D\},
\qquad m\longmapsto hm
```

である。domainのlift、許容規則、評価を要求するときは、対応する条件をこのfiberに課す。
この対象は定理8.12の可換三角形の補完でもある。
底辺 $`D\to X_0`$ と辺 $`X_1\to X_0`$ を固定し、残る辺を $`m`$ とする。
ここでは状態集合の写像の圏を使い、必要なら追加の構造保存式を課す。

固定データも動かす場合、比較は同型 $`a_i:X_i\to X_i'`$、$`b:D\to D'`$ で
$`h'a_1=a_0h`$、$`\iota_{D'}b=a_0\iota_D`$、$`m'b=a_1m`$ を満たすものとする。
これが全移送と全比較のgroupoidを与える。

**命題8.18（全移送の族と比較の自然性）.**
$`X_0,X_1,D`$ を $`k`$-代数上の状態関手、$`D\hookrightarrow X_0`$ を部分関手、
$`h:X_1\to X_0`$ を自然写像とする。
$`S`$ 上の移送を、全 $`S`$-代数上の自然写像 $`m:D\to X_1`$ で $`hm=\iota_D`$ を満たすものと定める。
この全移送と構成8.17の自然な比較は、係数変更に沿うgroupoidの族を作る。
定理8.16の語保存と二段移送の合成も、この係数変更と可換する。
状態・語・domain・翻訳と保存式を残す宣言制限にも自然である。
状態写像の圏の対象と全ての射を回復する表示変更は、全移送と全比較を回復する。

**証明.**
環射 $`S\to S'`$ では、$`S`$-代数上の全データを $`S'`$-代数へ制限する。
$`hm=\iota_D`$、domainの包含、比較の三つの可換式は各代数で同じ式なので保存される。
制限の恒等と合成は恒等と合成そのものである。
固定データの同型 $`a_i,b`$ による移送の輸送は $`m'=a_1mb^{-1}`$ であり、

```math
h'm'=h'a_1mb^{-1}=a_0hmb^{-1}
 =a_0\iota_Db^{-1}=\iota_{D'}
```

となる。逆同型で元へ戻り、比較の合成も式の合成に一致する。
係数制限はこの積・逆・等式と可換するため、対象と全比較の族を得る。
二段の移送は $`m_{12}m_{01}`$ であり、制限後も同じ合成になる。
中間像のdomain包含は各代数で保たれ、定理8.16の観測等式も各成分で同じ等式となる。
宣言制限では残す状態sortの担体と写像を変えず、語・domainとその保存式を残すので、
同じ等式を読む。二方向の制限は残した各成分で可換する。

表示変更では、この三角形の固定二辺と残る一辺 $`m`$ を全て評価・復元する。
定理8.12の図式の同値を状態写像の圏へ適用すると、$`hm=\iota_D`$ と
全ての比較も相互回復される。与えられたdomainや語の条件を持つ場合はそれも運ぶ。
復元関手が全ての射を回復することが、$`m`$ 自身に操作保存を追加せず全移送を回復する理由である。□

ここで得た $`\mathcal F_{a,H,V}`$、固定図式の $`\alpha`$、全比較射は、
局所変更の組立てと修復を扱う第IV部へ渡すデータとなる。

**問題8.19（修復作用との比較）.**
固定部分と変更可能な範囲を指定した実修復を原始操作から構成し、
本章の補完groupoidのどの条件付きfiberに対応するかを求めよ。
対象の修復だけでなく、式(8.2)を保つ再同定と評価・復元の自然性まで構成せよ。
