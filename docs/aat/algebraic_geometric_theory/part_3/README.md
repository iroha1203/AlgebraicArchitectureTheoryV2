# 第III部 意味を保つ変更の全体

第I部の意味圏と第II部の係数的実現を用い、実現間の全変更を構成する。
変更元、固定部分、許容規則、評価条件を加えたときの全解を、
実際の状態写像とその比較まで保持して調べる。

| 章 | 構成する対象 | 主な結果 |
| --- | --- | --- |
| [第7章 意味保存変更と合成の幾何](chapter_7_semantic_changes_and_composition.md) | 全変更groupoid、比較表示、nerve | 全操作語の保存、全Homの回復、合成の整合、線形状態射のaffine表示 |
| [第8章 条件を満たす変更と図式補完](chapter_8_constrained_changes_and_completions.md) | 許容候補、条件付き変更族、固定図式の補完、状態移送 | 多項式族の候補生成の完全性、全補完と厳密固定の比較、全移送のfiber |
| [第9章 商・対称性・持ち上げの分類](chapter_9_quotients_symmetry_and_lifts.md) | 商修復、保存section、可逆protocolのlift | 合同関係区間による分類、保存冪等射の分裂、根での復元とtorsor |

記号は[共通記号](../notation.md)に従う。
第7章の変更groupoid $`\mathcal C`$ は、意味圏の非可逆射も対象として持ち、
その間の比較を同型とする。第8章の $`\mathcal F_{a,H,V}`$ は、
始域の同定、固定図式のtrivialization、評価条件を保つ全比較を持つ。
第9章ではこれらの条件を商、代表選択、持ち上げに特殊化する。

第IV部へは、固定データ付きの全変更と比較、経路、移送の構成を渡す。
第V部でreadingを比較する際には、商と冪等射の分裂の保存・回復を用いる。
第VI部へは、観測に関して残る合同関係と持ち上げの自由を渡す。
一般の許容規則の完全性と一般実現方式の表現は、対象と求める結論を各章の問題で述べる。
